## 摘要
改善大型语言模型知识使用的方法通常分为两种体系。非参数检索提供了对外部知识的灵活访问，但增加了检索延迟、上下文开销，并且与主干的集成较浅。参数化适应在推理时高效，但将知识与模型权重纠缠在一起，难以更新、审计或迁移。Engram风格的哈希记忆占据了一个中间体系：它将学习到的信息存储在外部可寻址表中，但通过一个小型学习读取器来消费该表。这引发了一个基本问题：当这样的记忆跨主干移动时，冻结的记忆本身和目标端读取器哪个更重要？我们通过跨模型冻结记忆提取来研究这个问题，其中在源模型上训练的记忆被冻结并附加到不同的目标模型上，仅训练轻量级读取器。消融实验表明，学习到的记忆内容和正确的寻址都很重要，但迁移的表只有通过与目标模型对齐的读取器才变得有用。在下游问答任务中，一个双层四分支读取器几乎弥合了同模型和跨模型重用之间的差距，在我们受控评估协议下平均得分为38.8。此外，当提供者读取器与目标接口直接兼容时，冻结的工件可以在没有目标端训练的情况下提供实质性效用，而可选的读取器适应则带来进一步改进。这些结果表明，只要目标能够访问兼容的读取器接口，Engram就可以作为可重用的外部知识工件；当直接读取器重用不足时，目标端适应可以进一步改善对齐。

## Abstract
Methods for improving knowledge use in large language models typically fall into two regimes. Non-parametric retrieval offers flexible access to external knowledge, but adds retrieval latency, context overhead, and only shallow integration with the backbone. Parametric adaptation is efficient at inference time, but entangles knowledge with model weights and can be hard to update, audit, or transfer. Engram-style hashed memory occupies a middle regime: it stores learned information in an external, addressable table, yet consumes that table through a small learned reader. This raises a basic question: when such a memory is moved across backbones, what matters more, the frozen memory itself or the target-side reader? We study this question through cross-model frozen-memory extraction, in which a memory trained on a source model is frozen and attached to a different target model, with only a lightweight reader trained. Ablations show that learned memory content and correct addressing both matter, but the transferred table becomes useful only through a reader aligned to the target model. In downstream question answering tasks, a dual-layer, four-branch reader nearly closes the gap between same-model and cross-model reuse, achieving an average score of 38.8 under our controlled evaluation protocol. Moreover, when the provider reader is directly compatible with the target interface, the frozen artifact can provide substantial utility without target-side training, while optional reader adaptation yields further improvement. These results suggest that Engram can serve as a reusable external knowledge artifact, provided that the target has access to a compatible reader interface; target-side adaptation can further improve alignment when direct reader reuse is insufficient.

## 一、论文的核心问题与整体含义

### 研究背景与动机

- 大型语言模型（LLM）的知识使用方式存在两条传统路线：
  - **非参数方法（如RAG、kNN-LM）**：知识存储在外部，更新灵活，但引入检索延迟、上下文开销，且与主干模型集成较浅。
  - **参数化方法（如继续预训练、微调）**：推理时高效，但知识与模型权重纠缠，难以更新、审计和跨模型迁移。
- **Engram风格哈希记忆**的提出代表了一种中间路线：将学习到的信息存储在**外部可寻址表**中，通过一个小型学习型读取器（reader）消费该表，兼顾模块性与学习表示的效率。
- **核心研究问题**：当Engram记忆从源模型迁移到目标模型时，**冻结的记忆本身**与**目标端读取器**哪个更关键？记忆是否真正可移植，还是仅仅是与训练它的模型共同适应的扩展？
- **整体意义**：将记忆可移植性转化为一个**可操作、可度量**的评估框架——外部记忆工件是否值得复用，取决于新主干能否在不重训存储表的前提下进行寻址、对齐并提取有效信号。

## 二、论文提出的方法论

### 核心思想

- 提出**跨模型冻结记忆提取**（Cross-Model Frozen-Memory Extraction）框架：
  - 将记忆功能显式分解为三个角色：**寻址（addressing）**、**存储（memory）** 和**读取（reader）**。
  - 标准化寻址、冻结记忆表、仅训练目标端读取器。
  - 核心主张：**记忆的存在本身不够，成功复用取决于目标主干寻址并消费存储表示的接口（即读取器）**，但记忆内容同样重要。

### 关键技术细节

1. **Tokenizer无关的寻址（Tokenizer-Agnostic Addressing）**
   - 目标：解决跨模型tokenizer差异导致的地址不匹配问题。
   - 方法：对解码后的文本前缀进行共享规范化（NFKC标准化、小写化、去重音符号），提取规范化的词边界单元，并在其上计算n-gram哈希。
   - 对于无空格分隔的语言（如中文、日文），改用规范化的非空白Unicode字符跨度（character span）进行哈希。
   - 效果：不同tokenizer的目标模型可以读取相同的迁移记忆条目。

2. **目标端读取器（Target-Side Reader）设计**
   - 共享值投影 + 分支特定键投影：
     - 键投影 \( W_{K,\ell,r}^{(B)} \)：分支特定的键投影
     - 值投影 \( W_{V,\ell}^{(B)} \)：所有分支共享的值投影
   - 上下文感知门控：\( \alpha_{t,\ell}^{(r)} = \sigma(\text{RMSNorm}(h_{t,\ell})^\top \text{RMSNorm}(k_{t,\ell}^{(r)}) / \sqrt{d_B} + \beta_{\ell,r}) \)
   - 多分支聚合：\( o_{t,\ell} = \frac{1}{R} \sum_{r=1}^{R} \alpha_{t,\ell}^{(r)} \cdot v_{t,\ell} \)，通过残差连接注入 \( h_{t,\ell} \leftarrow h_{t,\ell} + o_{t,\ell} \)
   - 支持**多层注入**（如层2和层10双层注入）和**多分支**（R=1到R=4）变体。

3. **训练流程（两阶段）**
   - **Phase 1（源端记忆训练）**：在源模型上以标准下一词预测目标训练Engram记忆。
   - **Phase 2（目标端读取器适配）**：冻结源记忆和目标主干，仅训练目标端读取器参数。
   - 两种部署模式：
     - **直接工件复用**：提供者导出冻结记忆及兼容读取器，消费者无需任何目标端优化。
     - **读取器适配复用**：在可用适配流上训练轻量级目标特定读取器。

## 六、论文的主要结论与发现

1. **冻结记忆可跨模型迁移**：在所有3×3主矩阵组合中，转移记忆均优于无记忆基线，相对PPL降低1.6%–15.7%。即使源与目标共享极低的表示相似性（CKA仅0.007–0.013），迁移仍然有效。
2. **读取器设计是一阶因素**：从单层读取器到双层读取器，平均QA准确率从34.2提升至37.5；从R=1到R=4分支，进一步提升至38.5。读取器架构比记忆存储本身更能决定迁移性能。
3. **跨模型迁移几乎追上同模型复用**：在最强配置（{2,10}-R4）下，跨模型（38.5）与同模型（38.5）QA准确率几乎无差距。增加训练预算至30/30时达到38.8，成为新的SoTA。
4. **兼容接口下无需训练亦可复用**：当提供者读取器与目标接口直接兼容时，冻结工件可使QA从32.1提升至38.3（无任何目标端训练）；可选的目标端适配进一步将其提升至38.5。
5. **迁移收益是任务依赖的**：对事实型和证据导向任务（NQ、TriviaQA、WebQA、RTE、SciQ）收益明显；对常识阅读理解（RACE）基本无提升；对TruthfulQA（需要校准的真相性）呈现轻微负效应。
6. **迁移主要改善数据效率而非渐近上限**：从头训练的模型最终可达到与迁移相近的性能（38.4 vs 38.5），但迁移在远更少的目标端数据（约3%的可训练参数）下即可达到竞争性能。
7. **增益不能由参数数量或PPL单独解释**：FFN-only对照获得最低PPL（7.4）但QA平均仅34.5，远低于转移记忆（PPL 8.7，QA 38.5），说明转移增益来自记忆内容、寻址完整性和读取器接口的协同作用。
8. **转移记忆提升的是整体事实支持而非直接答案注入**：答案位置消融显示，转移的增益来自改善模型整体的答案支持状态，而非在预测位置直接注入正确答案token。

## 七、优点

- **问题定义清晰且具有开创性**：首次将外部记忆的可移植性转化为可操作、可度量的评估框架，明确区分了寻址、存储与读取三个角色。
- **方法设计巧妙**：基于tokenizer无关的规范化方案解决了跨模型寻址的核心障碍；轻量级读取器设计（线性、多分支、门控）使提取能力与存储能力解耦。
- **实验体系严谨**：
  - 多层控制条件（随机记忆、置换键、FFN-only、无门控）有效隔离了各种解释。
  - 同时报告PPL和下游QA指标，揭示了二者不一定一致（FFN-only PPL最优但QA最差；随机记忆PPL与转移相同但QA大幅落后）。
  - 对TruthfulQA的负结果进行了诚实报告和归因，没有选择性忽略。
- **工程上完整**：提供了评估集重叠审计、计算成本分析、摊销分析、多语言扩展（中文、日文验证），增加了研究的可信度。
- **发现具有实际指导意义**：直接工件复用与读取器适配两种部署模式的区分，为记忆作为可复用外部知识工件的实际应用提供了明确路径。

## 八、不足与局限

- **规模覆盖有限**：实验覆盖最大9B参数模型，未系统研究更大规模下读取器容量应如何随主干/记忆规模扩展，未建立关于读取器深度、分支数、注入位置与参数量的缩放定律。
- **寻址的语言覆盖有限**：默认词边界寻址仅适用于类英语的空格分隔语言；虽然字符跨度变体在中日文上得到验证，但代码、嘈杂Unicode、混合文字、字节级tokenizer等情形仍可能需更强的键管线。
- **读取器设计空间探索有限**：仅评估了轻量级线性读取器变体；非线性变换、自适应分支聚合、层相关值投影、学习注入位置等可能提升异构配对性能的扩展未探索，也可能混淆"可复用的记忆内容"与"读取器引入的容量"。
- **评估集重叠风险**：尽管进行了重叠审计，但底层基础模型的预训练语料不可用，QA结果应视为受控比较而非完全无污染的SoTA声明。存在少部分TriviaQA重复行和TruthfulQA题目微重叠。
- **OOD影响分析有限**：分布偏移实验仅覆盖了LAMBADA、WikiText-103、C4三个语料，范围较窄；门控机制在何种分布/模型组合下为必需、何时简单读取器足够，仍缺乏系统刻画。
- **渐近性能的判定受训练预算限制**：从头训练在50M token预算下已接近迁移性能，但两者在不同预算和模型规模下的渐近差距仍需更大规模验证。
- **两阶段协议的局限**：未探索主干、记忆、读取器联合训练的替代方案，无法说明两阶段协议与端到端训练的优劣关系。

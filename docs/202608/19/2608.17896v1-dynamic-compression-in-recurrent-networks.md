## 摘要
递归模型通过将历史压缩为固定大小的状态来高效处理长上下文，但现代架构通常以单次因果遍历的方式处理序列。因此，每个输入必须在模型知道其后续用途之前就被压缩，这迫使有限的状态在可能的未来需求之间进行折衷。我们引入了动态压缩，它允许递归模型选择性地重新访问过去的令牌，并通过额外的递归更新来修正其固定大小的状态。模型无需在其递归状态中以均匀的高保真度保留历史的每个部分，因为当低保真度信息变得相关时，可以从保留的原始序列中重新访问它。我们在一个受控环境中研究这一点：模型首先在上下文中学习多个函数，然后在同一序列的后面遇到一系列少样本任务，每个任务要求模型识别并重用其中一个函数。单遍模型必须为任何未来任务以足够的保真度保留每个函数，而选择性重新扫描允许模型仅重新访问和细化当前需要的函数。我们发现，动态压缩显著减少了准确重用所需的递归状态，并且随着存储函数数量的增加，其扩展性更为有利。这些结果展示了一种计算-内存权衡，其中递归模型可以花费更多计算来重新访问其历史，从而更有效地利用固定大小的状态。

## Abstract
Recurrent models process long contexts efficiently by compressing their history into a fixed-size state, but modern architectures typically do so in a single causal pass over the sequence. Each input must therefore be compressed before the model knows how it will later be used, forcing a limited state to compromise across possible future demands. We introduce dynamic compression, which allows a recurrent model to selectively revisit past tokens and revise its fixed-size state through additional recurrent updates. The model need not preserve every part of the history at uniformly high fidelity in its recurrent state, because lower-fidelity information can be revisited from the retained raw sequence when it becomes relevant. We study this in a controlled setting where the model first learns multiple functions in-context and, later in the same sequence, encounters a series of few-shot tasks that each require it to identify and reuse one of those functions. A single-pass model must preserve every function at sufficient fidelity for any future task, whereas selective re-scanning allows the model to revisit and refine only the function currently needed. We find that dynamic compression substantially reduces the recurrent state required for accurate reuse and scales more favorably as the number of stored functions grows. These results demonstrate a computation--memory tradeoff in which recurrent models can spend more computation revisiting their history to make more effective use of a fixed-size state.

### 1. 论文的核心问题与整体含义（研究动机和背景）

递归模型（RNN）因其 O(1) 的恒定状态内存和 O(1) 的逐令牌计算，在处理长上下文时比 Transformer（O(t) 内存和计算）更具扩展优势。然而，递归模型面临一个核心矛盾：**固定大小的递归状态如何支撑不断增长的可重用信息？**

传统递归模型以单次因果传递（single left-to-right pass）的方式处理序列：每个输入在被处理时，模型还不知道该信息未来是否会被用到、以及会以何种方式被用到。因此，模型被迫在固定大小的状态中为所有可能的未来需求**均匀分配保真度**，导致状态利用率低下。当需要存储多个函数或技能以便后续重用时，单遍模型的状态容量瓶颈尤为严重。

作者提出**动态压缩（Dynamic Compression）**：保留原始序列作为无损记录，允许模型在后续上下文揭示了哪些信息重要之后，**选择性重访（selective revisit）过去的部分令牌**，通过额外的递归更新来修订固定大小的递归状态，从而仅对当前任务相关的部分提高保真度。这揭示了一种**计算–记忆权衡**：用更多重访计算换取更小的状态容量需求。

### 2. 论文提出的方法论：核心思想、关键技术细节

**（1）核心思想**

动态压缩的核心在于构建一个两级记忆层次架构：
- **原始序列**：提供无损的历史访问能力；
- **递归状态**：作为紧凑的工作记忆，可随任务需求被修订。

模型不再是“一次压缩、永不回头”，而是在获知任务后，通过额外递归更新重新编码历史中的关键部分。

**（2）基础模型：Gated DeltaNet**

使用 Gated DeltaNet 作为核心递归架构，其状态更新规则为：

> S_t = S_{t-1} ⊙ α_t ⊙ (I − β_t k_t k_t^T) + β_t v_t k_t^T，o_t = S_t q_t

- 状态 S_t ∈ R^{d_v × d_k} 为矩阵值状态；
- α_t 控制全局遗忘；β_t 控制键特定 delta 更新的强度，即**写入强度信号**；
- β_t 在后文被用作自监督重扫目标的来源。

**（3）选择性重扫描（Selective Re-scanning）**

- 在查询阶段，每个少样本块之后，一个**选择头**输出一个基底索引 î ∈ {1, ..., K}；
- 模型随后重新扫描该基底的全部 b 个令牌，将其以更高保真度写回状态；
- 后续查询从修订后的状态读取并生成预测。

**（4）自监督重扫目标（去除 oracle 监督）**

由于 oracle 监督（真实基底索引）在实际场景中不可用，作者设计了三步自监督流程：

1. **重复上下文中提取重扫信号**：训练一个“repeat model”，在查询前重播整个前缀（basis + few-shot），使得写入可依赖已揭示的任务信息；记录此时最终层的 β 写入强度模式。
2. **构建重扫码本**：对大量序列的 β 模式做 k-means 聚类（C=3），每个簇质心代表一个重扫选择，固定选择 n=21 个位置构成重扫块。

## 摘要
递归线性注意力模型（RLAs）如Mamba，作为Transformer的替代方案，提供了高效的线性时间序列建模，但其固定容量的递归状态限制了长序列建模。受人类层次记忆的启发，我们提出了层次记忆Mamba（HMM）来解决这一限制。基于预训练的Mamba骨干网络，HMM集成了一个轻量级的工作记忆，从骨干网络隐藏状态中的快速感觉记忆中提取慢速段落级语义（PLS）。随后，PLS被压缩为持久的长时记忆，用于任务相关的检索。语义信息的层次化处理克服了RLAs的表示瓶颈，并通过参数化学习赋予HMM跨任务泛化能力，这在其他长上下文增强的Mamba变体中未观察到。在Passkey Retrieval和LongBench-E任务上的评估表明，与强大的基于Mamba的模型相比，HMM的检索成功率提高了34.3%–37.1%，推理准确率提高了1.6%–14.2%，同时仅增加了2%的额外参数，且训练开销极小。

## Abstract
Recurrent linear attention models (RLAs) such as Mamba offer efficient linear-time sequence modeling as an alternative to Transformers, yet their fixed-capacity recurrent states limit long-sequence modeling. Drawing inspiration from hierarchical human memory, we propose Hierarchical Memory Mamba (HMM) to address this limitation. Building upon a pre-trained Mamba backbone, HMM integrates a lightweight working memory that extracts slow paragraph-level semantics (PLS) from the fast sensory memory embedded in the backbone's hidden states. The PLS is subsequently compressed into persistent long-term memory for task-relevant retrieval. The hierarchical processing of semantic information overcomes the representation bottleneck of RLAs and endows HMM cross-task generalization through parametric learning, which is not observed in other long-context enhanced Mamba variants. Evaluations on Passkey Retrieval and LongBench-E tasks demonstrate that HMM improves retrieval success by 34.3--37.1% and reasoning accuracy by 1.6--14.2% over strong Mamba-based models, while adding only 2% extra parameters and with minimal training overhead.

- **背景**：Transformer 架构凭借强大的表示能力成为大语言模型（LLM）的主导选择，但其自注意力的平方级计算复杂度（O(L²)）为长上下文建模带来了严重挑战。递归线性注意力模型（RLA），如 Mamba、RWKV 和 DeltaNet 等，通过线性复杂度的循环更新提供了替代方案。
- **核心问题**：尽管 RLA 在理论上支持无限上下文长度，但实证研究表明，其固定容量的循环状态在长序列上存在固有的表示瓶颈。近年来研究多聚焦于缓解循环中的数值衰减，但本文首先通过实验揭示了一个关键现象：**单纯改善 PPL（困惑度）并不等同于提升长上下文推理能力**——即"低困惑度的假象"（The Illusion of Low Perplexity）。即便数值衰减被抑制，模型在复杂推理任务中的表现仍可能较差。
- **理论根源——语义混叠（Semantic Aliasing）**：论文证明该瓶颈本质上不可调和。固定维度的循环状态将指数增长的历史语义空间非内射地映射到有界的低维流形上，导致不同的历史轨迹在状态空间中变得不可区分。即便不存在数值衰减，当上下文长度超过某一阈值时，两个不同历史产生"语义混叠"的情况在数学上不可避免。
- **整体含义**：RLA 的长上下文失效不仅源于累积衰减，更源于缺乏对高层语义信息进行组织、保存和选择性重用的显式机制。论文从人类层次记忆模型（感觉记忆→工作记忆→长时记忆）汲取灵感，提出**层次记忆 Mamba（HMM）**来绕过固定循环状态的表示瓶颈，实现跨任务泛化。

## 2. 论文提出的方法论

### 2.1 总体架构
HMM 建立在**冻结的预训练 Mamba 骨干网络**之上，将其视为"感觉记忆"层负责 token 级表示；新增一个轻量级**工作记忆**网络，负责提取段落级语义（PLS）并将其编码为长时记忆（LTM）以供检索。整体包含两大核心流程：

- **语义编码（Semantic Encoding）**：从骨干网络的隐藏状态中提取慢速演化的段落级语义（PLS），并压缩为紧凑的长时记忆（LTM）。
- **语义检索（Semantic Retrieval）**：根据当前语义相关性选择历史 LTM 元素，并广播注入回骨干网络的深层，增强长上下文推理能力。

### 2.2 语义编码流程

- **分词/分段（Segmentation）**：通过余弦相似度衡量当前隐藏状态 h_t 与当前语义原型 S_k 的一致性。若 cos(S_k, h_t) ≥ τ，则将该 token 归入当前段并通过EMA更新原型。若低于阈值 τ 且持续 p 个 token（patience 参数），则视为语义漂移，开启新段。最终得到 PLS 序列 {S_k} ∈ R^{K×D}。
- **压缩（Compression）**：每个 PLS 元素通过轻量前馈网络降维为长时记忆表示：M_k = LN(W₂·σ(W₁S_k))，其中 M ≪ D 以确保存储开销极小。

### 2.3 语义检索流程

- **选择（Selection）**：计算当前 LTM 元素与历史元素间的余弦相似度，通过 Top-K 排序选出最相关的历史记忆索引。
- **注入（Injection）**：将选中的 K 个 LTM 元素平均成稳定表示后，广播到当前段落的所有 token 上，并通过上采样投影 W_p 加到骨干输出上：ỹ_t = y_t + W_p·M_t^{tok}。

### 2.4 理论分析

- 标准 SSM 的雅可比矩阵 ∂y_T/∂x_t 随距离指数衰减（由谱半径约束导致）。HMM 将总雅可比分解为**循环路径**与**层次记忆路径**之和。由于 PLS 通过局部时间聚合构建，后者的敏感性仅取决于段长度而与总序列长度无关，从而保证了即使在循环雅可比塌缩时仍存在非零敏感性路径——从理论上证明了层次记忆可缓解语义混叠。

## 6. 论文的主要结论与发现

1. **PPL 与长上下文推理能力之间存在"脱钩"**：降低 PPL 不等于提高推理有效性。数值稳定只是必要条件而非充分条件。
2. **"语义混叠"是 RLA 长上下文失效的结构性根源**：固定维度状态对不断增长的语义历史进行有损压缩，必然导致不同历史变得不可区分，这在理论上不可避免。
3. **层次记忆架构可有效绕过表示瓶颈**：HMM 通过工作记忆提取 PLS、压缩为 LTM、按需检索注入，提供了不随序列长度衰减的语义访问路径，在理论和实验上均验证了有效性。
4. **跨任务泛化能力是 HMM 的独特优势**：HMM 仅在 Pile 上适应训练便可在其他下游任务上表现出色，而其他 Mamba 变体（如 LongMamba、MambaExtend）多在训练中使用了目标数据集。
5. **成本可控**：仅增加约 2% 的可训练参数，峰值内存不增加，预填充吞吐仅有适度开销，解码阶段与 Mamba 持平。

## 7. 优点

- **理论深度**：不仅提出新方法，还从数学上证明了语义混叠的必然性（定理 A.1）以及 HMM 的雅可比秩保持性（定理 C.1），同时论证了两种替代方案（扩大隐藏维度、内部捷径）在计算效率和秩恢复方面的不足。
- **认知启发的创新架构**：将人类多阶段记忆模型映射为感受记忆→工作记忆→长时记忆的计算框架，思路新颖且具有可解释性；解耦语义记忆与循环动态，从架构而非模型规模入手解决瓶颈。

## 8. 不足与局限

- **不擅长精确事实检索**：论文自述 HMM 侧重于提高信息的"可访问性"而非"细粒度精确检索"，对于法律、监管等需要精确访问大量事实信息的场景，当前分割和检索机制可能不够充分，需要更先进的检索或索引策略。

- **训练数据量与可扩展性存疑**：论文称"仅用 300 条序列即有改善，报告 6,000 条序列的结果"，但对训练样本量、序列多样性以及更大规模模型上的行为缺乏更系统的研究。

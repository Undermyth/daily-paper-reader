## 摘要
检索增强生成（RAG）提高了事实性，但在服务时增加了延迟和工程开销。我们提出了RING（检索内化生成），一种涵盖架构和训练的整体范式，将大规模外部知识注入到\textit{混合记忆专家}中，并通过强化学习学习对此内部记忆的参数化搜索，从而完全移除外部检索器。训练分三个阶段进行：持续预训练通过我们新颖的\textit{双因果注意力}将新语料注入知识专家；监督微调教会长"先搜索后回答"的模式；以及使用分层奖励的强化学习优化参数化记忆上的路由与搜索策略。与先前将内部记忆与固定或基于规则的检索器配对的参数化注入方法不同，RING直接从任务信号中学习其检索策略。我们进一步从理论上将RING构建为经典RAG目标的无搜索近似。为了评估在不发生测试时泄漏的情况下真正\textit{新}知识的大规模注入，我们进一步构建了News-2025，这是一个基于严格晚于基础LLM预训练截止日期的新闻构建的基准。RING在准确性和效率上匹配或超越了基于搜索的RAG和参数化注入基线。

## Abstract
Retrieval-augmented generation (RAG) improves factuality but adds latency and engineering overhead at serving time. We propose RING (Retrieval-Internalized Generation), a holistic paradigm spanning both architecture and training that injects large-scale external knowledge into a \textit{Mixture-of-Memory Experts} and learns parametric search over this internal memory via reinforcement learning, removing the external retriever entirely. Training proceeds in three stages: continued pre-training injects new corpora into a Knowledge Expert via our novel \textit{Dual Causal Attention}; supervised fine-tuning teaches a ``search-then-answer'' pattern; and reinforcement learning with hierarchical rewards optimizes the routing-and-search policy over the parametric memory. Unlike prior parametric injection methods that pair internal memory with a fixed or rule-based retriever, RING {learns} its retrieval policy directly from task signals. We further frame RING theoretically as a search-free approximation to the classical RAG objective. To evaluate large-scale injection of genuinely {new} knowledge without test-time leakage, we further construct News-2025, a benchmark built from news strictly post-dating the base LLM's pretraining cutoff. RING matches or surpasses both search-based RAG and parametric injection baselines in accuracy and efficiency.

## 1. 核心问题与整体含义

- **研究背景**：检索增强生成（RAG）虽然能显著提升大模型的事实准确性，但依赖外部检索器，在服务时引入额外延迟和工程复杂度。纯参数化知识注入虽可缓解该问题，但已有方法（如知识编辑、持续学习、模块化注入、参数化RAG等）存在灾难性遗忘、记忆开销线性增加、仍依赖外部搜索引擎、或采用固定/规则化检索机制等瓶颈。
- **核心问题**：*如何在不依赖外部检索器、不显著增加服务时延的前提下，实现大规模新知识的持续注入与有效利用？*
- **核心含义**：论文提出 RING（Retrieval-Internalized Generation，检索内化生成）范式，将“索引”与“检索”整体内化进 LLM 参数，通过混合记忆专家结构和强化学习训练，使模型能够“从自身参数中搜索知识”，从而在保持较低推理成本的同时达到接近甚至超越传统 RAG 的性能。

## 2. 方法论

### 2.1 核心思想
- 将传统 RAG 的外部检索流程（索引→检索→生成）转译为参数化过程：  
  - **索引**：通过持续预训练（CPT）将大规模外部语料写入专用“知识专家”参数中；
  - **检索**：通过监督微调（SFT）和强化学习（RL），让模型学会在参数内部“搜索并回答”，不再需要外部向量库或搜索引擎。

### 2.2 模型架构
- 在稠密 LLM 基础上构建稀疏 **Mixture-of-Memory Experts**：
  - **Basic Expert**：保留原始 LLM 权重，维持基础能力、缓解灾难性遗忘；
  - **Knowledge Expert**：参数化记忆新语料，内部又分为 **Memory Up/Down**（存储与索引）和 **Search Gate**（查询相关重加权）；
  - **可学习 Router**：在 token 级别选择访问哪个专家。
- 知识专家可视为可微的 Key-Value 记忆：Up/Down 投影分别对应 Key 与 Value，Search Gate 提供查询相关的注意力权重。

### 2.3 三阶段训练
1. **持续预训练（CPT）**：
   - 将长文档切分为三句片段，与标题拼接成 JSON 格式记忆单元；
   - 提出 **Dual Causal Attention（DCA）**：用三种掩码（α=1、1/2、1/4）在保持自回归生成的同时，让目标块能利用互补块的双向信息，增强记忆效率；
   - 训练时仅更新 Knowledge Expert 的 Memory Up/Down，路由强制全部分配给知识专家，避免污染基座参数。
2. **监督微调（SFT）**：
   - 构造“Search-then-Answer”范式：模型先输出 `<retrieval>` 相关片段，再输出 `<answer>` 答案；
   - 训练时冻结 Memory Up/Down，只更新 Router 和 Search Gate，确保学到的检索行为不覆盖已记忆内容。
3. **强化学习（RL）**：
   - 使用 GSPO 算法，设计**分层奖励**：
     - 格式奖励（Format）：强制符合检索-回答格式；
     - 搜索奖励（Search）：通过归一化最长公共子串（LCS）、精确匹配等稠密奖励，引导输出与正确答案最匹配的记忆单元；
     - 回答奖励（Answer）：由评判模型判断答案是否正确；
   - 最终总奖励为三者的加权和，使模型同时学习“路由选哪个专家”“检索哪个记忆子区域”和“如何基于证据生成”。

### 2.4 理论基础
- 将 RING 建模为离散隐变量模型，把传统 RAG 目标重写为对证据变量 z 的边缘化；
- 证明 Knowledge Expert 结构同构于可微 Key-Value 检索机制；
- 将 CPT、SFT、RL 分别解释为变分推断中的 Evidence Maximization、Posterior Alignment 和 Policy Generalization，即最大化 ELBO 的三个步骤。

## 3. 实验设计

- 划分：
  - CPT 集：全部文档作为需注入的外部知识库；

## 6. 主要结论与发现

- RING 在 **Qwen3-8B** 上达到 35.08%/32.36%（英/中），**超越所有参数化注入基线**，相比最强基线 SR-KI 提高约 3.2 个点；
- 在 **Qwen3-14B** 上优势扩大，英文准确率 41.19%，优于部分强 RAG 管线，中文与最强 RAG 差距小于 2 个点；
- 推理速度方面，RING 的 TTFT 与 Full-Tuning 持平，比各类 RAG 变体**快 3–19 倍**，比 KV 注入基线快 3–6 倍；
- RL 对“记忆→利用”的转化至关重要：在低 PPL（记忆质量高）区域，RL 使准确率从 SFT 的约 20% 提升到 32% 以上；
- DCA 和参数分离结构有效缓解了灾难性遗忘，连续注入 10 万文档时准确率稳定在 30% 以上。

## 7. 优点

- **范式创新**：首次将检索策略端到端地用强化学习从任务信号中习得，而非依赖固定相似度规则，理论上可逼近并可能超越外部检索；
- **架构设计巧妙**：参数分离（记忆/搜索）避免了训练阶段互相干扰，基础专家保留原有能力，知识专家专注新语料；
- **理论扎实**：从离散隐变量、ELBO、Key-Value 记忆同构性等角度给出 RING 为何有效的解释；
- **评测严谨**：News-2025 确保测试知识不泄漏；同时考察准确率与延迟，突出 Pareto 优势；
- **可扩展性**：推理成本只随模型 FLOPs 增长，不随索引规模增长。

## 8. 不足与局限

- **动态知识更新困难**：知识库若频繁新增/删除文档，RING 需要重新训练，比可在线增删索引的传统 RAG 更不灵活；
- **证据可审计性较弱**：生成的 `<retrieval>` 片段可能被压缩、改写甚至扭曲，不同于外部数据库的逐字返回，严格引用和溯源场景受限；
- **训练成本高**：CPT + SFT + RL 的完整管线需要大量精心构造的数据和计算资源，论文也承认 upfront cost 显著；
- **实验场景有限**：仅覆盖知识密集型问答，未验证多跳搜索、快速变化事实、多语言知识库、长文生成等多类检索场景；
- **评价偏单一**：主要报告 Accuracy 与 TTFT，对生成内容的忠实度、记忆内容的保真度、安全与隐私风险等缺乏深入评测。

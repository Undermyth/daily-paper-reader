## 摘要
视觉-语言模型（VLMs）在处理高分辨率图像时面临关键的计算瓶颈，因为Softmax多头注意力（MHA）的$O(N^2)$内存复杂度。虽然用独立的MLP替换MHA可以实现$O(N)$扩展，但它剥夺了架构的空间序列路由能力，严重降低了全局场景理解和物体持久性。在本文中，我们提出了线性多时间尺度保持（LIA-MTR）模块，一种内存高效的跨模态桥梁。通过将基于ELU的正特征映射与自适应写入门控和对数线性分布的循环衰减相结合，LIA-MTR将连续视觉序列数学上压缩为有界记忆状态。理论分析证明该架构以严格的$O(N)$序列交互复杂度运行。实证上，合成检索评估表明，LIA-MTR能在16,000个token中完美路由上下文，消除了朴素线性注意力典型的“中间迷失”退化。硬件基准测试揭示了无限上下文扩展能力，在11.2 GB VRAM内原生处理262,144个视觉块，而标准MHA在16,384个块时就会内存不足。此外，在665K对话样本上进行指令微调后，LIA-MTR在MME基准上显著优于行业标准MLP基线（71.00% vs 68.11%），这得益于物体持久性10%的绝对提升和更优的全局语义提取。这项工作为无限上下文的视觉-语言整合奠定了数学上严谨、计算上平坦的基础。

## Abstract
Vision-Language Models (VLMs) face a critical computational bottleneck when processing high-resolution imagery due to the $O(N^2)$ memory complexity of Softmax Multi-Head Attention (MHA). While substituting MHA with independent Multi-Layer Perceptrons (MLPs) achieves $O(N)$ scaling, it strips the architecture of spatial sequence routing, severely degrading global scene understanding and object permanence. In this paper, we propose the Linear Multi-Timescale Retention (LIA-MTR) module, a memory-efficient cross-modal bridge. By integrating an ELU-based positive feature mapping with adaptive write-gating and log-linearly distributed recurrent decays, LIA-MTR mathematically compresses continuous visual sequences into bounded memory states. Theoretical analysis proves the architecture operates with strict $O(N)$ sequence-interaction complexity. Empirically, synthetic retrieval evaluations demonstrate that LIA-MTR flawlessly routes context across 16,000 tokens, eliminating the "Lost in the Middle" degradation typical of naive linear attention. Hardware benchmarking reveals infinite-context scaling capabilities, natively processing 262,144 visual patches within an 11.2 GB VRAM footprint, whereas standard MHA suffers out-of-memory failure at 16,384 patches. Furthermore, following instruction tuning on 665K conversational samples, LIA-MTR significantly outperforms an industry-standard MLP baseline on the MME benchmark (71.00% vs. 68.11%), driven by a 10% absolute improvement in object permanence and superior global semantic extraction. This work establishes a mathematically rigorous, computationally flat foundation for infinite-context Vision-Language integration.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉-语言模型（VLMs）在处理高分辨率图像时面临严峻的内存瓶颈。标准 Softmax 多头注意力（MHA）因需计算稠密的 $N \times N$ 亲和矩阵而具有 $O(N^2)$ 的序列交互复杂度，当视觉 token 序列超过16K时通常在标准硬件上触发显存溢出（OOM）。
- **现有方案的不足**：
  - 用独立 MLP 替代 MHA 虽将复杂度降至 $O(N)$，但因其对每个视觉 patch 独立处理，缺少跨 token 的空间/时间路由机制，导致全局语义理解能力下降、物体持久性（object permanence）失效（MME Existence 仅83.33%）。
  - 朴素线性注意力在长序列上存在“中间迷失”（Lost in the Middle）问题——早期视觉特征被后续 token 覆盖。
  - 标准状态空间模型（SSM）使用单一学习衰减，难以同时兼顾短期空间细节与长期全局语义。
- **整体含义**：本文提出 LIA-MTR 模块，在严格 $O(N)$ 复杂度下实现跨模态序列路由，为无限上下文（infinite-context）视觉-语言集成提供了数学上严谨、计算上平坦的解决方案。

## 二、论文提出的方法论

- **核心思想**：以"门控、固定大小的循环记忆状态"取代二次方成对注意力，通过多时间尺度衰减将连续视觉序列压缩为有界记忆表示。
- **系统架构**：由预训练视觉编码器（CLIP-ViT-Large-Patch14）、交叉模态桥（LIA-MTR）和因果 LLM（Qwen-2.5-3B-Instruct）三部分组成，视觉编码器与 LLM 保持冻结，仅训练 LIA-MTR 桥。
- **关键技术细节**：

1. **查询/键/值投影与 ELU 正特征映射**：
   - 对视觉序列 $X=[x_1,\dots,x_N]$，计算 $q_t = W_q x_t$，$k_t = \varphi(W_k x_t)$，$v_t = W_v x_t$，其中 $\varphi(z)=ELU(z)+1$ 保证键表示的**非负性**，防止递归累积中的分母坍塌。

2. **自适应写门控与尺度混合器**：
   - 计算 $g_t = \sigma(W_g x_t^{conv})$（sigmoid 写门控），用于过滤空间冗余噪声，避免记忆饱和（内部探针显示激活均值≈0.5053，标准差0.0444）。
   - 计算 $\alpha_t = \text{softmax}(W_{mix} x_t^{conv})$（尺度混合器），动态加权不同时间尺度的记忆。

3. **多时间尺度循环状态更新**：
   - 维护 $S$ 个并行记忆状态，每个由固定衰减常数 $\lambda_s \in (0,1)$ 控制：
   $$M_{t,s} = \lambda_s M_{t-1,s} + u_t, \quad u_t = g_t \odot (k_t \odot v_t)$$
   - $\lambda_s$ 在对数线性范围内分布于 $[0.70, 0.995]$，对应记忆半衰期从 $t_{1/2}=1.94$ 步到 $t_{1/2}=138.28$ 步，可同时捕捉短期空间细节与长期全局语义。

4. **读出与输出**：
   - 通过尺度混合器加权聚合：$m_t = \sum_{s=1}^S \alpha_{t,s} \odot M_{t,s}$，最终输出 $y_t = W_o (q_t \odot m_t)$。

- **理论保障**（四个定理/引理）：
  - **定理1**：证明 LIA-MTR 严格具有 $O(N)$ 渐近序列交互复杂度。
  - **引理1/定理2**：证明记忆状态可展开为几何加权和，且在无穷上下文中严格有界（$\lim_{t\to\infty}\|M_{t,s}\| \le \|M_{0,s}\| + \frac{U}{1-\lambda_s}$），确保数值稳定。
  - **引理2**：LIA-MTR 在特定约束（$S=1, \alpha_{t,1}=1, g_t=1$）下可退化为标准一阶线性注意力，说明其是该类模型的广义形式。
  - **定理3**：证明 $O(N)$ 达到了自回归全序列读取的理论下界 $\Omega(N)$，即**阶数最优**。

## 六、主要结论与发现

- LIA-MTR 在合成 NIAH 检索中取得完美 1.0 检索分数，实现 16,000 token 的无损上下文路由，彻底消除朴素线性注意力的"Lost in the Middle"问题。
- 硬件测试中 LIA-MTR 呈严格 $O(N)$ 扩展，原生处理 262,144 个视觉 patch 仅耗 11.2 GB 显存；而标准 MHA 在 16,384 patches 时即发生 OOM。
- MME 基准上，指令微调后 LIA-MTR 总分为 71.00%，显著超越 MLP 基线的 68.11%。
- Phase 1（仅特征对齐）后，MLP 虽总体略高（62.30% vs 58.42%），但其 Existence 指标仅 81.67%，而 LIA-MTR 达 91.67%，证明循环状态解决了物体持久性缺陷。
- Phase 2 后，LIA-MTR 场景识别达 90.40%（MLP 为 78.75%），压缩视觉上下文对全局语义提取至关重要；但局部空间定位（Spatial Positioning 35.00%）略低于 MLP（43.33%），体现出压缩导致的空间精度权衡。
- 内部探针确证：写门控激活均值 0.5053（低方差）、多时间尺度半衰期跨度 1.94–138.28 步，证明记忆系统在带宽和稳定性之间取得了平衡。

## 摘要
现代语言模型主要基于Transformer、循环模型及其混合架构构建。Transformer依赖词元级别的注意力记忆，而循环模型如状态空间模型（SSMs）和线性注意力则维护紧凑的循环状态。这些架构通常分别实例化或在层级别交错，尚不清楚共享记忆表示是否能同时支持循环压缩和注意力式检索。我们通过Mamba-2的状态空间对偶（SSD）视角来研究这一问题，其中SSM状态可解释为压缩的关联键值（KV）缓存。我们观察到Mamba-2从该状态解码词元条件化的值，但不解码词元条件化的键。基于这一观察，我们提出DART（对循环状态的解码注意力），它保留Mamba-2分块扫描产生的块状态贡献作为块状态记忆，从这些记忆解码词元条件化的键和值，并对生成的KV对执行状态记忆注意力（SMA）。检索到的输出随后通过门控残差连接与原生Mamba-2输出结合。DART通过复用Mamba-2分块扫描并将SMA实现为FlashAttention风格的计算来支持实际训练。我们的分析和实验表明，与匹配的注意力基线相比（例如，当块大小S=256且状态大小N=128时节省75%），DART显著减少了依赖长度的推理缓存。与Mamba-2相比，DART在保持一般语言建模质量的同时，显著改善了关联召回和检索。

## Abstract
Modern language models are built primarily from Transformers, recurrent models, and their hybrid architectures. Transformers rely on token-level attention memories, while recurrent models such as state space models (SSMs) and linear attention maintain compact recurrent states. These architectures are typically instantiated separately or interleaved at the layer level, leaving open whether a shared memory representation can support both recurrent compression and attention-style retrieval. We study this question through the state space duality (SSD) view of Mamba-2, where the SSM state can be interpreted as a compressed associative key--value (KV) cache. We observe that Mamba-2 decodes token-conditioned values from this state but does not decode token-conditioned keys. Based on this observation, we propose DART (Decoded Attention over Recurrent sTates), which retains the chunk state contributions produced by the Mamba-2 chunked scan as chunk state memories, decodes token-conditioned keys and values from these memories, and performs state-memory attention (SMA) over the resulting KV pairs. The retrieved output is then combined with the native Mamba-2 output through a gated residual connection. DART supports practical training by reusing the Mamba-2 chunked scan and implementing SMA as a FlashAttention-style computation. Our analysis and experiments show that DART substantially reduces the length-dependent inference cache compared with a matched attention baseline (e.g., $75\%$ savings when the chunk size is $S=256$ and the state size is $N=128$). Compared with Mamba-2, DART substantially improves associative recall and retrieval while preserving general language-modeling quality.

- 如果也能从压缩状态中解码键，则注意力无需作用于全部词元级 KV 对，而只需作用于少量压缩记忆。

**整体含义：**
- 论文提出 DART 架构，在 Mamba-2 的分块状态记忆上执行注意力式检索，弥合了"循环压缩"与"注意力检索"之间的鸿沟，为高效长上下文建模提供了新方向。

## 2. 论文提出的方法论

### 2.1 核心思想

DART 在 Mamba-2 分块扫描（chunked scan）的基础上，增加一个**状态记忆注意力（State-Memory Attention, SMA）**分支：

- 将 Mamba-2 分块扫描产生的**块状态贡献** $\Delta H[c] \in \mathbb{R}^{N \times P}$ 保留为**块状态记忆**。
- 从这些记忆中解码出词元条件化的键（key）和值（value）。
- 对解码后的 KV 对执行注意力，检索结果作为**门控残差修正**叠加到原生 Mamba-2 输出上。

### 2.2 关键技术细节

**（1）双侧重构：**

矩阵 $\Delta H[c]$ 具有键轴 $N$ 和值轴 $P$：

- **值侧读出**：$C_t \Delta H[c] \in \mathbb{R}^{1 \times P}$（与原生 Mamba-2 共享读向量 $C_t$）
- **键侧读出**：$\Delta H[c] E_t \in \mathbb{R}^{N \times 1}$（$E_t$ 是值侧验证器，将块记忆转变为词元条件化的键）

**（2）三个投影向量（每个 SSM head）：**

- $Q_t = U_t W_Q$：查询向量，用于块路由
- $C_t = U_t W_C$：原生 Mamba-2 读向量（SMA 分支共享）
- $E_t = (U_t W_E)^\top$：值侧验证器

**（3）SMA 计算流程：**

- 对每个历史块 $c$：
  - $V_{t,c} = C_t \Delta H[c] \in \mathbb{R}^{1 \times P}$
  - $K_{t,c} = \Delta H[c] E_t \in \mathbb{R}^{N \times 1}$
  - 块 logit：$\ell_{t,c} = \frac{Q_t K_{t,c}}{\sqrt{N}}$
- 对历史块做 softmax 归一化：$g_{t,c} = \text{softmax}_{c < c(t)}(\ell_{t,c})$
- SMA 读出：$R_t = \sum_{c < c(t)} g_{t,c} V_{t,c}$

**（4）门控残差融合：**

$$Y_t = C_t H_t + G_t R_t, \quad G_t = \text{SiLU}(U_t W_G)$$

其中 $W_G$ 零初始化，保证训练开始时 SMA 从零残差开始学习。

**（5）工程实现：**

- 复用 Mamba-2 分块扫描算法产生块状态记忆
- SMA 采用 FlashAttention 风格的自定义 kernel，在线 softmax + 重计算，前向仅写出 SMA 读出和 logsumexp 统计量

## 6. 论文的主要结论与发现

1. **共享记忆可以同时支持压缩与注意力检索**：DART 证明同一个循环状态表示既能实现高效压缩，又能执行注意力式检索，无需将两种记忆形式分离。

2. **推理缓存显著降低**：在 $S=256, N=128$ 时，DART 的推理缓存仅为匹配注意力基线的 25%（**节省 75%**）。

3. **联想回忆能力大幅提升**：在 MQAR 任务上，DART（$N=64$）在所有测试序列长度和宽度上接近完美准确率；$N=16$ 时甚至超过 Mamba-2 的 $N=64$ 配置——SMA 使受限状态下的记忆可访问性大幅提升。

4. **保持语言建模质量**：在 Pile 验证集上，DART 的困惑度与 Mamba-2 相当（甚至略优），Pile 准确率有小幅提升；零样本下游平均准确率在三个规模上均优于 Mamba-2。

5. **检索能力显著改善**：DART 在 SWDE、FDA 等提取型任务上远超 Mamba-2（如 780M 规模 SWDE 从 39.9% 提升至 56.5%）；NIAH-Single-2/3 的中等难度设置中恢复大量 Mamba-2 丢失的召回能力。

6. **$C_t$ 共享是训练成功的关键**：独立参数化的 SMA 读向量在 $N=16$ 设置下完全无法学习（准确率为 0），共享原生 Mamba-2 读向量则快速收敛。

7. **SMA 分支本身贡献显著**：评估时移除 SMA 残差读出会严重损害 MQAR 和真实世界提取性能，证明检索增益主要来自块状态记忆的可寻址性。

8. **系统效率优势**：SMA kernel 在 1k–64k 序列长度范围内前向时间始终低于 FlashAttention-2（最多降低约 37.5%），推理缓存分配最多降低约 74%。

## 7. 优点

1. **概念新颖性**：将 SSD 视角推进了一步——不仅把状态视为压缩 KV 缓存，还实现了"键侧解码"，使同一记忆表示同时支持压缩和检索。

2. **设计优雅且高效**：
   - 复用 Mamba-2 分块扫描，无需额外计算产生记忆
   - FlashAttention 风格 kernel 实现，适合 GPU 训练
   - 参数开销极小（<3% 参数量增加）

3. **工程实践性强**：
   - $C_t$ 共享设计既有理论直觉支撑，又有实证验证（独立参数化失败）
   - 零初始化门控保证训练稳定性
   - 推理缓存节省显著且理论清晰（$N/(2S)$ 比值）

4. **实验覆盖全面**：从合成任务到真实检索，从下游评估到系统性能，形成完整验证链条。

5. **对比公平性较好**：与 Mamba-2 在相同骨干、相同预训练 token、相同状态大小下对比。

## 8. 不足与局限

1. **大规模验证缺失**：最大模型仅 795M 参数；缺乏 1B/7B 等更大规模上的验证，无法确定结论在更大模型上是否成立。

2. **训练成本信息不透明**：未说明 Pile 100B token 预训练所需的 GPU 数量与训练时长，难以评估额外的计算开销（SMA 引入的 $O(L^2 NP/S)$ 训练复杂度在长序列下可能显著增加训练成本）。

3. **块大小评估存在不一致性**：预训练 $S=256$，但评估时使用 $S=32/64$ 未经训练适配，可能低估 DART 在这些块大小下的真实潜力或高估其泛化能力。

4. **NIAH 最困难设置仍无法解决**：4096 token 的 NIAH-Single-2/3 中，DART 准确率仍然很低（多数在 1.4%–5.8% 区间），与全注意力 Pythia 存在明显差距。

5. **SMA 受限于块数量**：计算复杂度随块数 $M$ 线性增长，对于极长上下文（如 100k+ tokens），M 很大时训练成本可能过高。

6. **对 $C_t$ 共享的依赖具有脆弱性**：独立 $C_t$ 完全无法学习，表明该架构设计选择的敏感性较高，理论上对这种依赖性的解释还不够深入。

8. **下游评估以短上下文为主**：表 2 的标准下游任务大多为 256 token 以内输入，对长上下文能力的评估主要依赖合成 NIAH 和有限的真实检索任务，实际长文档理解能力的证据相对薄弱。

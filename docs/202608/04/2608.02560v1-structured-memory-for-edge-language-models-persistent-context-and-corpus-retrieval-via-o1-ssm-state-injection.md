## 摘要
检索增强生成（RAG）会带来与检索上下文长度成正比的预填充成本，并且——对于Transformer主干——还会产生随每个生成token增长的KV缓存。状态空间模型（SSMs）从结构上避免了第二项成本；我们消除了第一项成本，将每次查询的预填充从O(L_context)降至O(1)。我们提出了PRECOG（预计算上下文注入），一种利用SSM独特属性——固定大小、与位置无关的循环隐藏状态是对模型已读内容的完整总结——的检索机制。PRECOG离线将文档语料库预编码为SSM隐藏状态，并在查询时直接注入最佳匹配状态，完全绕过了上下文重新摄入。相同的状态注入机制还实现了SMC（结构化记忆整合）：一种具有认知域聚类的分层持久记忆，具备可调的保真度与存储量调节旋钮以及O(1)会话初始化，它能将短期情节状态整合为长期语义记忆，并在查询时将二者与检索到的语料库状态融合。我们在TENNs-LLM上演示了该系统，这是一个具有192 KB隐藏状态的12亿参数门控SSM语言模型。PRECOG在回答质量上与上下文RAG相当，在边缘硬件上将预填充延迟从约27秒降至不到6毫秒——约4500倍的加速，使其从不可用跨越到交互式。该机制在架构上对于Transformer KV缓存是不可能的，因为KV缓存与位置纠缠且随上下文长度线性增长。

## Abstract
Retrieval-augmented generation (RAG) imposes a prefill cost proportional to retrieved context length, and -- with Transformer backbones -- a KV-cache that grows with each generated token. State-Space Models (SSMs) avoid the second cost by construction; we eliminate the first, collapsing prefill from $O(L_{context})$ to $O(1)$ per query. We introduce PRECOG (Pre-Computed Context Injection), a retrieval mechanism that exploits a property unique to SSMs: the fixed-size, position-agnostic recurrent hidden state is a complete summary of everything the model has read. PRECOG pre-encodes document corpora offline as SSM hidden states and injects the best-matching state directly at query time, bypassing in-context re-ingestion entirely. The same state-injection mechanism enables SMC (Structured Memory Consolidation): a hierarchical persistent memory with cognitive-domain clustering, an adjustable fidelity-vs-storage dial, and $O(1)$ session initialization, which consolidates short-term episodic states into long-term semantic memory and fuses both with retrieved corpus states at query time. We demonstrate the system on TENNs-LLM, a 1.2B-parameter gated-SSM language model with a 192 KB hidden state. PRECOG matches in-context RAG answer quality, reducing prefill latency from $\sim$27 s to $<$6 ms on edge hardware -- a $\sim$4500$\times$ speedup that crosses the threshold from unusable to interactive. The mechanism is architecturally impossible for Transformer KV-caches, which are position-entangled and grow linearly with context length.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景问题**：检索增强生成（RAG）的预填充（prefill）成本随上下文长度线性增长；对于 Transformer 架构，KV 缓存还随生成的 token 数线性膨胀，且与位置纠缠（position-entangled），导致跨上下文无法复用。
- **核心矛盾**：这种结构特性使 Transformer 在长上下文边缘部署场景下效率低下——边缘设备上为 1.2B 模型摄入 512-token 检索块预填充耗时约 27 秒，超出交互式响应窗口，体验上"不可用"。
- **关键洞察**：状态空间模型（SSM）具有固定大小、与位置无关的循环隐藏状态，该状态是对模型已读内容的完整摘要；利用这一属性可将 RAG 的上下文摄入成本从 O(L) 降为 O(1) 的"状态注入"，这在 Transformer 架构上结构性不可行。
- **整体意义**：论文提出了一种 SSM 独有的检索与记忆范式，大幅降低边缘侧语言模型的推理延迟，并统一了语料库检索与持久化个人记忆两条线路。

## 2. 方法论

### 核心思想：PRECOG（Pre-Computed Context Injection）
- **离线阶段**：将文档语料库切块（默认 512 token），每个块经 SSM 模型推理一次，捕获 24 层最终隐藏状态 h̄(i)（FP16 下共 192 KB/块，与块长无关）；同时用轻量句编码器（all-MiniLM-L12-v2，384 维）生成检索键 kᵢ。键索引存入 FAISS（DRAM 中），完整隐藏状态存于闪存（UFS），按需加载。
- **查询阶段**：查询向量经同一编码器编码，FAISS 检索 top-k 块（默认 k=3），从闪存加载对应状态，作为 SSM 循环状态的初始条件注入；模型仅处理查询 token，不再摄入任何上下文 token。
- **理论保证（Theorem 1）**：SSM 更新映射 Φ(h, x) = h⊙α(x) + β(x) 仅依赖当前 token 与当前状态，与位置无关（时间平移不变性）。因此 S(h₀, c ⊕ q) = S(S(h₀, c), q)——先编码上下文再注入状态，与在上下文中直接摄入，计算轨迹在精确算术下逐位一致。即 PRECOG 是"同一计算的重构"，而非近似。
- **对比 Transformer**：RoPE/绝对位置编码使 KV 缓存更新依赖位置，预计算的缓存换位即失效，重算等同于重新摄入，消除任何预填充收益。
- **复杂度**：预填充上下文摄入为 O(1)；检索为 O(log M)；生成保持 O(N)/token 不变。

### 扩展机制：SMC（Structured Memory Consolidation）
- **分层聚类**：会话流按块编码得到状态轨迹 H̄(c)；按 5 个认知域（情感、时间、社交、空间、事实）两阶段路由（先域、再子簇），子簇分为偏好精确回忆的 Type-A 与偏好压缩摘要的 Type-B。
- **保真度-存储旋钮 K**：可保留全部状态（K=Nc，无损情节）、间隔采样（K=Nc/k）或仅留最终状态（K=1，语义级，与 PRECOG 状态等价），按子簇类型配置。
- **语义整合**：各子簇维护一个语义状态 s，按指数移动平均（EMA）不断吸收新块贡献，存储上限约为 M·Jmax·192 KB（默认约 4 MB），与历史量无关。
- **O(1) 会话初始化**：会话开始时通过路由确定主导子簇，直接注入其语义状态作为初始条件，无需重新摄入任何历史 token。
- **联合检索**：查询时并行检索情节记忆与语料库状态，经 softmax 加权融合后注入，统一了持久记忆与语料检索两种场景。

## 3. 实验设计

### 主实验（第 6 节）
- **数据集**：SQuAD v1.1 开发集随机抽取 1,000 问（固定随机种子）。
- **任务**：抽取式问答；评估指标为官方脚本的 token 级 EM 和 F1。
- **对比设置**（同一 TENNs-LLM 权重、同一 FP16 推理精度）：
  - ① 上下文 RAG（金段落直接拼接到问题前）；
  - ② PRECOG top-1 状态注入；
  - ③ PRECOG top-3 softmax 加权状态合成。
- **结果**：上下文 RAG（EM 58.2 / F1 73.6）vs PRECOG top-1（EM 58.0 / F1 73.4）——差距 0.2，在 FP16 量化误差界内；top-3 组合（EM 56.4 / F1 71.8）下降 1.6 F1，反映合成规则的非精确性。

### 消融实验（附录 G）
- **G.1 注入深度（SQuAD v1.1）**：8 种层子集配置（全 24 层、底层 18/12/6 层、顶层 12/6 层、隔层 12 层、零上下文基线）。发现底层 12 层即保留 99% F1（72.5 vs 73.4），存储减半；仅注入顶层效果差（top_6 仅 58.0 F1）。
- **G.2 top-k 组合（HotpotQA-distractor，1,000 问）**：k=1,2,3,5,10。F1 以 k=3 为峰（55.5），之后随低相关块注入噪声而下降；Recall@k 单调上升至 0.98，说明退化的确源于合成启发式的非精确性。
- **G.3 块长（Natural Questions）**：按 token 长度分 6 档。块长 <600 token 时 PRECOG 与上下文 RAG 差距 ≤0.5 F1；超过后差距拉大，≥2,400 token 档差距达 15 F1——实证刻画了骨干模型的有效记忆长度边界。

### 附加验证
- **SMC 聚类验证（附录 I.2）**：用《哈利·波特》前 6 部电影对白建聚类原型，第 7 部作留存测试集；5 个认知域的子簇分离度（簇间/簇内平均距离比）均 >1.5（空间域最高 3.77）；还检测到了"Others"分组中的涌现型新子簇（≥20 段的密集连续分组）。
- **部署与延迟验证**：在神经形态边缘处理器（FPGA 原型验证 + 12 nm 模拟功耗）上测得 19 token/s、约 1W、19 tokens/J；PRECOG 将 TTFT 从约 27 秒降至约 585 ms（其中检索等开销约 6 ms）。

## 6. 主要结论与发现

- **检索范式**：PRECOG 将 SSM-RAG 的上下文摄入从 O(L) 降为 O(1)，在边缘硬件上 TTFT 从约 27 s 降至 <6 ms（约 4,500 倍加速），回答质量与上下文 RAG 等价（top-1 下由定理保证并实测 0.2 F1 内差距）。
- **结构性边界**：该机制对 Transformer 结构性不可行（位置纠缠 + 线性 KV 缓存），属于 SSM 架构独有能力。
- **记忆整合**：在相同状态注入基座上，SMC 实现了层次化持久记忆——短时情节记忆经 EMA 整合为长时语义记忆，会话初始化 O(1)，记忆足迹有界（默认 <4 MB 语义部分），且 5 域认知聚类在虚构语料上显示良好的分离度与涌现簇检测能力。
- **设计原则**：作者提出——随 SSM 质量逼近 Transformer，其独特的结构属性可用于实现注意力架构无法实现的高效检索、缓存与记忆算法。

## 7. 优点

- **理论严谨**：以 Theorem 1 的形式干净证明 PRECOG 与上下文 RAG 的计算等价性，将"实验验证"变为"实现审计"，科学论证强度高。
- **新颖方向**：从"缓存 token 表示"转向"缓存完整因果状态"，并提供明确的复杂度与存储优势分析（85 倍于同规模 KV 缓存，随上下文长度差异扩大至 21,845 倍）。
- **工程实用**：统一的"状态注入"基座同时支撑语料检索与持久记忆，简洁通用；如注入深度消融所示，存储可再减半（96 KB）而不损质量。
- **消融设计清晰**：三组消融分别把"层间信息分布""组合启发式代价""骨干记忆边界"这三类问题与核心声明分离，反映作者对系统薄弱环节有清醒认识。
- **边缘部署落地**：提供从带宽/存储/延迟多轴平台分析（UFS→HBM3）到实际神经形态硬件的完整闭环，显示方法在真实约束环境下的可操作性。

## 8. 不足与局限

- **继承记忆上限**：PRECOG 完全继承骨干 SSM 的有限记忆长度；当块长超出约 600 token 的有效记忆范围时，性能随距离加速衰减（NQ 最长档差距 15 F1），需配合更长记忆骨干或块切分策略。
- **top-k 组合是启发式**：Theorem 1 仅对 top-1 单块注入严格成立，top-k 的 softmax 线性组合无理论保证，且实测在 k>3 后由于低相关块污染而下降；如何最优合成多块状态仍是开放问题。
- **存储开销**：状态级检索每块 192 KB，比纯文本 RAG（约 1 KB/块）高约 200 倍；适用于"摄入延迟为瓶颈"的场景，不适合存储受限或高频访问小块语料的场景。
- **评价体系单薄**：主实验仅一个数据集（SQuAD 1,000 问）、单一抽取式问答任务、无置信区间；SMC 的聚类验证仅用虚构影视剧本，没有自然对话、多用户、长时跨会话数据。
- **硬件数据部分模拟**：功耗与能耗数据来自 12 nm 工艺点仿真而非流片实测；FPGA 验证与模拟数据混合，且未与其他边缘 NPU/移动 SoC 在同等条件下做基准对比，作者也承认这一点。
- **外部对比缺失**：与 State Soup、PICASO、xRAG、EM-LLM 等方法只有定性讨论，缺少统一基准下的定量对照，因此"相对最优性"证据不足。

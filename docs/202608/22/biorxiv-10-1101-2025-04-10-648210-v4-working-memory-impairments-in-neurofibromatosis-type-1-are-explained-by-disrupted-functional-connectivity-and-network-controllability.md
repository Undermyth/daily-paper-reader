## 摘要
1型神经纤维瘤病(NF1)是一种罕见的单基因疾病，与工作记忆处理损伤相关。然而，这些损伤在多大程度上可由功能脑网络的组织和状态转换破坏来解释尚不清楚。本研究描述了NF1工作记忆期间功能连接(FC)和网络可控性如何改变，并探讨这些改变是否能预测个体认知表现。我们将这些分析应用于53名NF1青少年和36名年龄匹配的神经典型对照者的功能MRI数据。与对照组相比，NF1参与者在额顶网络内(特别是左前额叶皮层和左顶内沟之间)的连接减少，默认网络和边缘网络之间的连接减少，而控制网络和感觉运动区域之间的连接增加。网络可控性分析显示，前额叶皮层、楔前叶和眶额皮层的平均可控性增加，但模态可控性和激活能量降低，表明在NF1中这些区域驱动网络向易达状态转换的能力增强，并且在当前网络组织内容易被激活。在躯体感觉区域、纹外皮层和颞顶皮层发现相反模式，即平均可控性降低但模态可控性和激活能量增加，反映这些区域驱动大脑向难达状态转换的能力增强。这些改变准确预测了NF1状态，所有可控性模型的ROC曲线下面积超过80%。此外，在具有显著组间差异的区域，平均可控性准确预测了NF1组的工作记忆表现，并可泛化到样本外数据。特别是，左外侧腹侧前额叶皮层、右外侧背侧前额叶皮层和双侧顶上小叶在所有测量中均一致地作为工作记忆表现的预测因子。通过证明NF1中区域网络可控性的改变可预测工作记忆表现，本研究为NF1认知困难背后的功能网络改变提供了一种新的机制性解释，并建立了一个通过其对脑网络控制的影响来评估未来治疗干预措施的框架。

## Abstract
Neurofibromatosis type 1 (NF1) is a rare, monogenic condition associated with impairments in working memory processing. However, to what extent these impairments are explained by disrupted organisation and state transitions of the functional brain networks is unknown. This work characterises how functional connectivity (FC) and network controllability are altered during working memory in NF1 and investigates whether these alterations predict individual cognitive performance. We applied these analyses to functional MRI data from 53 NF1 adolescents and 36 age-matched neurotypical controls. Compared to controls, NF1 participants showed reduced connectivity within frontoparietal networks (particularly between the left prefrontal cortex and left intraparietal sulcus), reduced connectivity between default and limbic networks, and increased connectivity between control and somatomotor regions. Network controllability analysis revealed increased average controllability but reduced modal controllability and activation energy in prefrontal cortex, precuneus, and orbital frontal cortex, indicating that in NF1 these regions have enhanced capacity to drive the network toward easy-to-reach states and are readily activated within the current network organisation. The opposite pattern of reduced average controllability but increased modal controllability and activation energy was found in somatosensory areas, extrastriate cortex and temporal parietal cortex, reflecting enhanced capacity of these regions to drive the brain towards difficult-to-reach states. These changes accurately predicted NF1 status, with an area under the ROC curve exceeding 80% across all controllability models. Furthermore, average controllability in regions with significant group differences accurately predicted working memory performance in the NF1 group, generalising to out-of-sample data. In particular, left lateral ventral prefrontal cortex, right lateral dorsal prefrontal cortex, and bilateral superior parietal lobule consistently emerged as predictors of working memory performance across all measures. By demonstrating that altered regional network controllability in NF1 predicts working memory performance, this study provides a novel mechanistic account of the functional network alterations underlying cognitive difficulties in NF1, and establishes a framework for evaluating future therapeutic interventions through their effects on brain network control.

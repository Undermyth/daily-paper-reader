## 摘要
状态空间模型（SSMs）作为线性Transformer的一个主流研究方向，旨在长上下文建模中实现比标准Transformer更高的效率。然而，现有的SSMs存在输入适应性有限和记忆容量受限的问题，导致在建模超长序列时出现信息丢失。为解决这些局限性，我们提出了MixFormer，一种新颖的线性Transformer，它集成了混合记忆专家（MoE）机制。具体而言，该模型通过多个协作的记忆专家维护差异化的记忆状态，并采用一种新颖的时间感知线性注意力（TALA）机制，利用可学习的指数衰减函数和位置偏置来动态更新记忆。这种设计使模型能够选择性地强化重要的历史信息，同时有效缓解记忆稀释，显著提升长程依赖建模能力。在长序列文本和图像生成任务上的实验表明，MixFormer不仅取得了显著的性能提升，还为下一代网络基础设施提供了更具可持续性的计算骨干。

## Abstract
State Space Models (SSMs), as a mainstream research direction of linear Transformers, aim to achieve higher efficiency than standard Transformers in long-context modeling. However, existing SSMs suffer from limited input adaptivity and constrained memory capacity, leading to information loss when modeling ultra-long sequences. To address these limitations, we propose MixFormer, a novel linear Transformer that integrates a Mixture-of-Memory-Experts (MoE) mechanism. Specifically, the model maintains differentiated memory states through multiple collaborating memory experts and employs a novel Time-Aware Linear Attention (TALA) mechanism, which leverages learnable exponential decay functions and positional biases to dynamically update memory. This design enables the model to selectively reinforce important historical information while effectively mitigating memory dilution, substantially improving long-range dependency modeling. Experiments on long-sequence text and image generation tasks demonstrate that MixFormer not only achieves significant performance gains but also provides a more sustainable computational backbone for the next generation of web infrastructure.

## 1. 核心问题与研究动机

- **背景**：标准 Transformer 的 softmax 自注意力机制具有 O(n²) 的时间和空间复杂度，难以支撑超长上下文建模。线性 Transformer 和状态空间模型（SSM）通过将注意力重写为递归形式、维护固定大小的"记忆状态矩阵"，将复杂度降至 O(n)。
- **现有方法的缺陷**：
  1. **输入适应性不足**：现有 SSM 通常使用固定衰减系数或少量可学习参数来更新记忆状态，无法根据当前输入的语义重要性动态决策"记住什么、忘记什么"。
  2. **记忆容量受限**：大多数 SSM 仅使用单一记忆状态矩阵存储历史信息，在超长序列中，早期关键信息容易被后续输入覆盖或稀释，导致长程依赖建模中的不可逆信息丢失。
- **论文的核心主张**：将混合专家（MoE）思想引入 SSM 的记忆状态建模，通过多个差异化记忆专家协作，突破单一记忆状态的容量瓶颈，提升超长序列建模能力。

## 2. 方法论

### 2.1 核心思想
MixFormer 在传统 Transformer 块（线性注意力 + FFN）中引入 **Mixture of Memory Experts（MoME）** 机制，并设计了 **Time-Aware Linear Attention（TALA）** 层，在保持 O(n) 复杂度的同时实现并行训练和递归推理双模式。

### 2.2 关键技术细节

**（1）TALA（时间感知线性注意力）**
- 对 Q、K 施加核变换保证非负性：φ(Q) = e^{Q/||Q||}, φ(K) = e^{K/||K||}
- 结合指数衰减权重 ω 和可学习成对位置偏置 G，公式为：
  - TALAtt(Q_t, K_t, V_t) = φ(Q_t) ⊙ [Σᵢ φ(Kᵢ)(ωGᵢ)^{t−i} Vᵢ] / [Σᵢ φ(Kᵢ)(ωGᵢ)^{t−i}]
- **并行表示**（训练）：TALAtt(Q,K,V) = Q ⊙ (Kᵀ ⊙ D)V，其中 D 为因果掩码矩阵，D = {ω^{n−m}G_{nm}, n≥m; 0, n<m}
- **递归表示**（推理）：S_n = ωG ⊙ S_{n−1} + K_nᵀV_n, O_n = Q_nS_n
- **分块递归表示**：支持 chunkwise 训练，兼顾并行加速与跨块长程依赖传播
- 支持多头版本：ω = 1 − e^{−h}，各头独立衰减参数，输出经 GroupNorm 处理

**（2）MoME（混合记忆专家）**
- 在 SSM 中首次引入多记忆专家架构，将记忆状态从"单一矩阵"扩展为"多个专门化专家"
- 路由器通过 Softmax 对当前输入（K_nV_n）计算专家权重：E_i = Softmax(K_nV_nW_g)，输出为 Y_ms = Σ E_i · MS_i
- 各专家在 TALA 中采用差异化记忆策略，分别捕捉短时动态、长程依赖等不同时间模式
- 内容自适应的激活机制选择性强化重要信息、抑制冗余信号

**（3）整体架构**
- 堆叠 N 个 MixFormer Block（TALA + FFN + GroupNorm，采用 pre-norm 策略）
- 复杂度分析：总成本 = 4Nd²（投影）+ Nd²（TALA）+ Nk（MoME）+ 2dd′（FFN），长上下文下收敛至 O(n)

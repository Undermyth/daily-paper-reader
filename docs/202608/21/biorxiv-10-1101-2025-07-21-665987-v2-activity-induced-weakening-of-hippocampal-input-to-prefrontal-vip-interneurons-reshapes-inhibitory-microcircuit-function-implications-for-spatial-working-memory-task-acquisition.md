## 摘要
从腹侧海马（vHPC）到内侧前额叶皮层（mPFC）的长程投射支持包括空间工作记忆（SWM）在内的认知功能。vHPC输入靶向多种前额叶中间神经元类型，然而海马输入在体内如何招募这些群体、这种招募是否具有可塑性，以及这种可塑性如何影响认知仍不清楚。在此，我们将小鼠vHPC输入的光刺激与离散mPFC中间神经元群体的钙记录相结合，揭示了前额叶抑制性微环路中海马招募的持续性活性诱导重加权。离体电生理和计算建模表明，在该环路重构中，海马对表达血管活性肠多肽（VIP）的中间神经元的单突触驱动减弱。先前的vHPC输入刺激以及与精神分裂症相关的Df(16)A+/-突变（该突变也导致海马输入至VIP中间神经元减少）产生了任务相关VIP中间神经元活动的趋同改变，并与较差的SWM任务学习相关联。这些发现表明，海马输入至VIP中间神经元是能够重构抑制性微环路活性的关键可塑性位点，其与工作记忆任务学习受损相关。

## Abstract
Long-range projections from ventral hippocampus (vHPC) to medial prefrontal cortex (mPFC) support cognitive functions including spatial working memory (SWM). vHPC input targets multiple prefrontal interneuron classes, yet how hippocampal input recruits these populations in vivo, whether this recruitment is plastic, and how such plasticity influences cognition remain unknown. Here, we combined optical stimulation of mouse vHPC inputs with calcium recordings from discrete mPFC interneuron populations, revealing persistent activity-induced reweighting of hippocampal recruitment across prefrontal inhibitory microcircuits. Ex vivo electrophysiology and computational modeling implicated weakened monosynaptic hippocampal drive onto vasoactive intestinal polypeptide (VIP)-expressing interneurons in this circuit reconfiguration. Prior vHPC input stimulation and the schizophrenia-associated Df(16)A+/- mutation, which also yielded reduced hippocampal input onto VIP interneurons, produced convergent alterations in task-related VIP interneuron activity associated with poorer SWM task learning. These findings implicate hippocampal input to VIP interneurons as a key locus of plasticity capable of reconfiguring inhibitory microcircuit activity linked to impaired working memory task learning.

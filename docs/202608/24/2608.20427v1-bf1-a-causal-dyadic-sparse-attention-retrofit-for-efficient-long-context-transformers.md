## 摘要
即使采用高度优化的精确内核，密集因果注意力在长上下文下仍然昂贵。我们研究了BF1，一种确定性的块对齐二元稀疏注意力路径，它结合了小的精确局部邻域、全局第一块和对数间隔的历史块。该路径与先前的对数稀疏和扩张注意力模式相关；我们的贡献是一种正确性门控的预训练模型改造、匹配的拓扑控制研究，以及将每层稀疏性与整体模型延迟联系起来的系统表征。对于固定的块宽度，每个转换后的层使用O(n log n)次选定的令牌交互，并具有O(log n)的图通信深度。在NVIDIA RTX PRO 6000 Blackwell GPU上，优化的BF16实现在2K到4K令牌之间超越密集注意力，并在32K时达到10.91倍的逐层预填充加速。改造28层Qwen3-0.6B中的8层注意力层，在8K、16K和32K下，将整个模型的首令牌时间分别降低7.7%、11.3%和15.3%，而其余的密集层保持完整模型的渐近二次复杂度。在匹配的1,000步、16.384M令牌适应协议下，BF1在三个训练种子中排名第一：平均报告困惑度为1.68639，而匹配的静态随机非局部图为1.69154，密集继续训练为1.69258，相等预算的局部滑动为1.81505。在种子1234下，打包报告配对间隔将Dense-CT置于BF1上方0.3169-0.4055%，静态随机图17置于BF1上方0.2441-0.3642%。这些结果确立了BF1作为一种可复现的稀疏算子和选择性改造原语，具有实际的长上下文系统价值。本文评估了数值正确性、选定的交互扩展、内核性能、部分模型推理和匹配的下一令牌语言建模。

## Abstract
Dense causal attention remains expensive at long context even when implemented with highly optimized exact kernels. We study BF1, a deterministic block-aligned dyadic sparse-attention route that combines a small exact local neighborhood, a global first block, and logarithmically spaced historical blocks. The route is related to prior log-sparse and dilated attention patterns; our contribution is a correctness-gated pretrained-model retrofit, a matched topology-control study, and a systems characterization that connects per-layer sparsity to whole-model latency. For fixed block width, every converted layer uses O(n log n) selected token interactions and has O(log n) graph communication depth. On an NVIDIA RTX PRO 6000 Blackwell GPU, an optimized BF16 implementation crosses dense attention between 2K and 4K tokens and reaches a 10.91x per-layer prefill speedup at 32K. Retrofitting eight of 28 Qwen3-0.6B attention layers lowers warm whole-model time to first token by 7.7%, 11.3%, and 15.3% at 8K, 16K, and 32K, respectively, while the remaining dense layers keep the complete model asymptotically quadratic. Under a matched 1,000-step, 16.384M-token adaptation protocol, BF1 ranks first across three training seeds: mean report perplexity is 1.68639 versus 1.69154 for a matched static-random nonlocal graph, 1.69258 for dense continued training, and 1.81505 for equal-budget local sliding. At seed 1234, the packed-report paired interval places Dense-CT 0.3169-0.4055% above BF1 and static-random graph 17 0.2441-0.3642% above BF1. These results establish BF1 as a reproducible sparse operator and selective retrofit primitive with real long-context systems value. This paper evaluates numerical correctness, selected-interaction scaling, kernel performance, partial-model inference, and matched next-token language modeling.

## 2. 论文提出的方法论

### 核心思想
将序列划分为宽度为 b 的等长块，每个 query 块只与三类块交互：
1. **自身块**（带 token 级因果掩码三角形）及邻近两个局部块；
2. **全局首块（block 0）**，保证任何位置都能直接访问序列最早的信息；
3. **按幂次递减的历史块**（距离为 4, 8, 16, ...），实现对远距离的对数稀疏覆盖。

### 关键技术细节

**块选择公式：**  
对于 query 块 j，选择的 predecessor 块集合为：

> P(j) = {j, j−1, j−2, 0} ∪ {j−2^r : r ≥ 2}

并去除无效和重复索引。默认配置为：块宽 b=64，两个局部前驱块，全局首块，dyadic 偏移从 4 个块开始，不使用 scale-dependent score bias。

**复杂度保证（Proposition 1）：**  
每个块 j 最多选择 4 + ⌊log₂j⌋ 个前驱块，总块对数为 O(B log B)，每对贡献至多 b² 个 token 对，因此总交互数为：

> O(b²B log B) = O(nb log(n/b)) = **O(n log n)**（固定 b 时）

**通信深度（Proposition 2）：**  
非全局块间距离 δ 可按二进制分解为若干不同的 2 的幂，每步跨越一个 dyadic 或局部边，因此任意早块到后块的最短路径长度为 popcount(δ) ≤ ⌊log₂B⌋。在 B=512 的验证图（32K 上下文）中，最大最短路径为 **8 层**（δ=511 因 i=0 直接由全局边服务，故比上界 9 少 1）。

**混合栈复杂度（Proposition 3）：**  
若模型中存在至少一层全密集全局注意力层，则全模型注意力复杂度仍为 Ω(n²)。因此本论文的 8/28 层改造只提供**常数因子加速**，而非全模型 O(n log n) 的渐近改进。

- **评估报告集**：固定的 174 条打包序列，共 356,178 个预测 token，在所有训练种子间复用。

## 6. 论文的主要结论与发现

1. **系统性能**：
   - BF1 在 2K 至 4K 之间交叉超越密集注意力，在 32K 时达到 **10.91× 单层预填充加速**（选中交互数减少 26.98×，实现约 40% 的 pair-reduction 效率转化）。
   - 8/28 层实际改造后，热启动全模型首 token 延迟（TTFT）在 8K/16K/32K 分别降低 **7.7% / 11.3% / 15.3%**（1.08×/1.13×/1.18×），峰值显存不变。
   - 全层 timing-only 天花板在 32K 达到 2.14×，说明在更多层转换后仍有提升空间。

2. **图结构特性**：
   - 32K 时三种等预算稀疏图的通信深度分别为：BF1=8 跳，静态随机=14 跳，滑动=59 跳。BF1 的图深度优势不在于运算更便宜，而在于结构可达性更好。

3. **语言建模质量**：
   - BF1 在三个训练种子中平均报告困惑度 1.68639，优于 Dense-CT（1.69258，+0.37%）、静态随机（1.69154，+0.31%）以及滑动窗口（1.81505，+7.63%）。
   - 配对区间审计（seed 1234）：Dense-CT 相对 BF1 的困惑度增加 +0.3599%（95% CI [+0.3169, +0.4055]%）；静态随机为 +0.3030%（CI [+0.2441, +0.3642]%）。
   - 继续域内适应是增益的主要来源（恢复约 92.6–92.7% 的绝对改善），BF1 的额外增益为独立但小量的残余改进。

4. **非局部性至关重要**：等预算的局部滑动窗口被远远甩开，证明非局部稀疏连接在该协议下是"承载力性"设计。

5. **解码现状**：选页注意力算术本身可快至 12–23μs 残差执行，但每 token 100–121μs 的计划开销使低 batch 端到端解码无法赢得优势；仅 batch 32 时在 32K/64K 达到 2.67×/3.05×。

## 7. 优点

- **正确性门控严格**：在性能评估之前执行了 8 项正确性检查（路由会计、未来 token 隔离、BF16 与物化参照一致性、前后向梯度有限性、部分最后块覆盖、密集路径等价、缓存解码与逐块参照一致等），目标案例最大绝对误差仅 0.00390625，均值为 7.1×10⁻⁵ 以下。
- **系统归因清晰**：将"算子稀疏性"与"全模型复杂性"分开处理，区分真实 8 层改造 vs 全层 timing-only 天花板，避免误导性结论。
- **匹配化实验设计**：四个训练臂在可训练参数、选块预算、token 顺序、目标函数和评估程序上完全对齐，使对比结论无混淆变量。
- **多种子复制**：三个训练种子下 BF1 均排名第一，且非局部-局部差异稳定，结论鲁棒性较好。
- **诚实划定边界**：明确不声称全模型次二次、不宣称 KV 存储压缩、不报告检索/聚合/状态跟踪能力，学术诚信度高。

## 8. 不足与局限

- **模型覆盖窄**：仅用 Qwen3-0.6B 一种规模和 ORCA 一个训练家族，未能说明对更大/更小模型、其他预训练数据体的适用性。
- **非自适应、确定性路由**：不建模 query 特异性或 head 异质性；不学习选块策略，对内容相关的稀疏性需求不敏感。
- **全模型非稀疏**：28 层中仅改 8 层，剩余 20 层仍为密集注意力，全模型保持 O(n²) 复杂度；全层条件只是 timing ceiling，并非已训练和功能验证的模型。
- **KV 存储不压缩**：BF1 保留精确的 O(n) 历史 KV 存储，不实现内存压缩；图通信深度的理论保证不等同于任何下游任务能力的保证。
- **解码端到端无优势**：低 batch 端到端解码未获收益，planning 生命周期是主要瓶颈；paged 后端执行数为"估算值"而非持久计划下的直接实测完整生成结果。
- **随机图复制不足**：静态随机图仅用 1 个图种子，无法对随机稀疏图总体做分布级声明。
- **无能力级评测**：未报告检索、多源聚合、可变状态追踪、任意长上下文推理等能力指标，无法直接判断实际应用中功能的保留程度。
- **开放资源有限**：代码与构造工具等未公开，复现依赖私有基础设施。

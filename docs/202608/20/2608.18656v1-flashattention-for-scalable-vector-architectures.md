## 摘要
在CPU上进行Transformer模型推理变得越来越重要，尤其是对于小语言模型（SLM），在这些场景中，向量架构正成为一种有前途的执行载体。由于高内存带宽需求，注意力模块是一个主要瓶颈；FlashAttention通过融合操作来改善数据局部性并减少中间内存流量，从而缓解了这一问题。在本文中，我们提出了FlashAttention-V，一种用于可扩展向量架构的分块FlashAttention，它通过利用跨注意力头的并行性、头间打包以在超过头维度时有效利用向量长度，以及改进向量寄存器利用率和内存访问局部性，高效地适应从短到非常长的向量。我们将FlashAttention-V集成到llama.cpp中的ggml中，并使用gem5和Banana Pi BPI-F3在TinyLlama、Llama 3.2、Qwen2.5和Pythia-410M上对其进行了评估。在Banana Pi BPI-F3上，我们确认了跨注意力头的循环重排和循环展开是有效的优化原则，其性能提升随模型增大而扩展，并且在短上下文和解码过程中最为显著。基于仿真的分析表明，在预填充阶段，FlashAttention-V在512位向量长度下相比标量FlashAttention实现了22倍到42倍的加速，并在扩展到64通道和4096位向量长度时额外获得2倍到2.5倍的提升。在解码阶段，FlashAttention-V使用512位向量长度相比标量FlashAttention实现了8倍到11倍的加速，但由于单token、内存受限的执行，性能对向量宽度和通道数的敏感性逐渐降低。我们进一步发现了Q8_0量化线性层中的结构性瓶颈，这些瓶颈限制了长向量执行下的算术摊销，并且在RVV和Arm SVE中表现一致，这表明当前的量化格式对长向量可扩展性构成了根本性挑战。

## Abstract
Inference with transformer models on CPUs is increasingly important, especially for Small Language Models (SLMs), where vector architectures are emerging as a promising execution substrate. The attention module is a major bottleneck due to high memory bandwidth requirements; FlashAttention mitigates this by fusing operations to improve data locality and reduce intermediate memory traffic. In this paper, we present FlashAttention-V, a blocked FlashAttention for scalable vector architectures that adapts efficiently from short to very long vectors by exploiting parallelism across attention heads, inter-head packing to enable efficient utilization of vector lengths beyond the head dimension, and improving vector register utilization and memory access locality. We integrate FlashAttention-V into ggml within llama.cpp and evaluate it on TinyLlama, Llama 3.2, Qwen2.5, and Pythia-410M using gem5 and a Banana Pi BPI-F3. On the Banana Pi BPI-F3, we confirm that loop reordering and loop unrolling across attention heads are effective optimization principles, scaling performance gains with larger models and most pronounced with short contexts and during decoding. Simulation-based analysis shows that FlashAttention-V achieves 22x-42x speedup over scalar FlashAttention at 512-bit VL in prefill, with an additional 2x-2.5x gain scaling to 64 lanes and 4096-bit VL. During decode, FlashAttention-V achieves 8x-11x speedup using 512-bit vector lengths over scalar FlashAttention, with performance showing diminishing sensitivity to vector width and lane count due to single-token, memory-bound execution. We further identify structural bottlenecks in Q8_0 quantized linear layers that limit arithmetic amortization under long-vector execution, consistent across RVV and Arm SVE, indicating that current quantization formats pose a fundamental challenge to long-vector scalability.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：Transformer 模型在 CPU 上的推理日益重要，尤其是对于 1B–10B 参数规模的小语言模型（SLM），这类模型通常部署在边缘设备上。与此同时，支持变长向量长度的可扩展向量架构（如 RISC-V 的 RVV 和 ARM 的 SVE）正成为有前景的执行载体。
- **核心问题**：注意力模块是 Transformer 推理的主要瓶颈，源于其高内存带宽需求。FlashAttention 通过 tiling 和算子融合有效缓解了这一问题，但现有 CPU 上的 FlashAttention 实现有一个关键设计限制：**向量长度（VL）被绑定在注意力头维度 D 上**（通常 D=64 或 128）。当硬件向量长度超过 D 时，单个注意力头内没有足够的元素来填满向量寄存器，导致 SIMD 资源利用率严重不足。
- **整体含义**：现有实现无法利用超长向量架构的潜力，向量长度超过头维度后的额外计算宽度被浪费。本文致力于弥合这一差距，使 FlashAttention 能够在从短到极长的向量架构上高效扩展，并揭示量化层在长向量执行下的结构性瓶颈。

## 2. 论文提出的方法论

### 2.1 核心思想

提出 **FlashAttention-V**，一种面向可扩展向量架构的分块 FlashAttention 算法，核心思路是**利用跨注意力头的并行性**来填充长向量寄存器，而非局限于单个头内部的向量化。

### 2.2 关键技术细节

- **跨头并行与头间打包（Inter-head Packing）**：当 VL > D 时，将多个注意力头的 Q、K、V 数据打包进同一个向量寄存器。例如，FP16 精度下，4 个头的 4 个元素可打包进一个 256 位寄存器。推导关系：`itr = VL ÷ D` 决定一个向量寄存器能容纳多少个注意力头。
- **循环重排（Loop Reordering）**：将注意力头循环提升到内层循环之外，利用 ggml 内存布局中 Q、K、V 张量在头间连续存储的特性，提高空间局部性和单位步长内存访问效率。
- **循环展开（Loop Unrolling）**：对注意力头循环进行展开（最优因子 U = 4），提升向量寄存器占用率和指令级并行度（ILP），隐藏内存延迟。
- **寄存器复用与缓存感知阻塞**：使用 cache-aware 的 block_N 和 block_K（经调优为 64×64），Q 向量提前加载到寄存器组中最大限度复用，减少内存带宽压力。
- **原生 MHA/GQA 支持**：GQA 场景下，共享的 K/V 只需加载一次，然后使用 `vslideup` 指令在寄存器内复制以填充完整向量，避免冗余内存访问。
- **在线 Softmax 向量化**：基于 streaming softmax 公式，使用向量化指数函数 `exp_v`（源自 SIXTE 库，适配 FP16 和掩码），向量化维护运行最大值 M、运行和 Sum 以及 VKQ 累积。
- **统一两种执行模式**：VL > D 时使用头间打包；VL ≤ D 时保持头内向量化，但同样应用循环重排、展开和 GQA 优化。

### 2.3 对自注意力（Self-Attention）的优化

- QK^T 阶段：将多个 token 的 Query 打包进长向量寄存器，单个 Key 行加载后复用多次，摊销 K 的加载成本。
- Softmax 阶段：注意力分数矩阵为 N×N（N 为序列长度），天然适配长向量；头间循环展开因子为 16。
- QKV 累积阶段：16 行分数矩阵与单个 Value 行相乘，同时产生 16 个输出，最大化 Value 复用；展开因子超过 16 会引发寄存器溢出。

## 6. 论文的主要结论与发现

- **FlashAttention-V 在预填充阶段**（512-bit VL，gem5）：相比 ggml-scalar 实现 22×–42× 加速；扩展到 64 lanes + 4096-bit VL 可再获得 2×–2.5× 提升；8192-bit VL 在固定延迟模型下可再提升约 3 倍。
- **在解码阶段**：512-bit VL 下实现 8×–11× 加速；但由于单 token 顺序执行和内存受限，对向量宽度和 lane 数量不敏感，缩放增益仅约 1.2×。
- **64 lanes + 4096-bit VL 是最优配置**：在现实延迟缩放模型下，超过 4096-bit 后 VL 相关延迟惩罚抵消吞吐增益。
- **硬件验证**：BPI-F3（256-bit VL）上 FlashAttention-V 相比 ggml-scalar 实现 12×–14× 加速（预填充）、4×–5×（解码）；相比 ggml-vec 快约 2×。
- **FP16 优势**：长向量下相比 FP32 约 2 倍加速，短向量下仅 11%，因软顶瓶颈限制了 FP16 收益。
- **Q8_0 量化与长向量不兼容**：packing（vslideup）和 masked reduction（vwredsum_m）在 2048-bit VL 时合计消耗约 60% 周期，抵消了算术加速；该瓶颈在 RVV 和 Arm SVE 上表现一致，源于 Q8_0 的权重-缩放交错布局（AoS）——结构性限制而非架构特定问题。

## 7. 优点

## 8. 不足与局限

- **未评估**：未涉及多核并行、批处理推理、更长的序列长度（4096+ tokens 的实际硬件效果）、BF16 支持（RISC-V 缺乏该指令）等对实际部署重要的维度。

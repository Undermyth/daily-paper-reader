## 摘要
皮层计算具有惊人的低维特性：少量潜在变量承载于神经群体的活动中，引导单个神经元的高维响应。我们的目标是样本效率——从有限数据和较小参数预算中实现良好解码的模型。在标准Transformer层中，前馈模块对每个词元应用相同算子。我们提出一种受冯·诺依曼启发的有效计算假设，作为神经解码的替代方案：控制器解码指令，然后执行特定于词元的算子；通常的实现——专家混合——仅混合其输出，而非算子本身。我们引入冯·诺依曼状态空间变换器（VN-SST），一种记忆增强型Transformer，其前馈模块为低秩指令库：共享基础算子加上少量学习到的低秩指令，每个词元通过代码合成实际使用的权重矩阵。该代码从携带的状态空间记忆的低维投影中读取，因此缓慢的潜在轨迹充当指令指针——反映了低维动态可能如何路由皮层计算。在三个运动皮层神经解码基准上，VN-SST相比现代Transformer具有更高的数据效率，每个模型同时预测尖峰和行为解码。该模型在最稀缺基准上以显著优势获胜，在另外两个基准上领先，并将更长上下文转化为精度提升而非下降。我们评估了网络将大型指令库压缩为每词元几比特，因此程序容量作为控制通道而非精度杠杆。同一模型在两个用于语言建模（LLM）的小型文本基准上也更具参数效率，表明其具有通用机制。

## Abstract
Cortical computation is strikingly low-dimensional: a handful of latent variables, carried in a neural population's activity, steer the higher-dimensional responses of individual neurons. Our aim is sample efficiency-models that decode well from limited data and at small parameter budgets. In a standard Transformer layer, the feed-forward block applies the same operator to every token. We suggest a von-Neumann inspired hypothesis of efficient computation as an alternative for neural decoding: a controller decodes an instruction and then executes a token-specific operator; the usual realization-a soft mixture of experts-only blends their outputs, not operators. We introduce a von-Neumann State-Space Transformer (VN-SST), a memory-augmented Transformer whose feed-forward block is a low-rank instruction bank: a shared base operator plus a small set of learned low-rank instructions, from which a per-token code synthesizes the weight matrix actually used at that token. The code is read from a low- dimensional projection of a carried state-space memory, so a slow latent trajectory acts as an instruction pointer-mirroring how low-dimensional dynamics may route cortical computation. On three motor-cortex neural-decoding benchmarks, VN-SST is far more data-efficient than a modern Transformer, each jointly predicting spikes and decoding behavior. This model wins by a wide margin on the scarcest benchmark, leads on the other two, and turns longer context into rising rather than falling accuracy. We evaluated that the network compresses a large instruction bank to a few bits per token, so program capacity acts as a control channel, not an accuracy lever. The same model is also more parameter-efficient on two small text benchmarks used for language modeling (LLMs), suggesting a generic mechanism.

**研究动机与背景：**

- **皮层计算的低维性**：神经科学证据表明，虽然神经元群体活动维度很高（数千个神经元），但其实际组织方式却是低维的——少量潜在变量（latent variables）携带着驱动个体神经元高维响应的核心信息，且这些潜在变量随时间缓慢演化。
- **神经解码的现实瓶颈**：运动皮层神经解码面临典型的小数据、小参数困境——单次会话记录的数据量有限，模型需要从少量样本中实现准确的行为解码（如手部/手指速度）。
- **标准Transformer的结构局限**：标准Transformer的前馈网络（FFN）对序列中的每个token施加相同的固定权重算子。作者认为这是一种低效的计算模式——如果计算"程序"能够因输入而异，则有望大幅提升样本效率。
- **冯·诺依曼（存储程序）架构的启发**：冯·诺依曼机器由一个小而慢的控制器取指并解码指令，随后执行单元运行该指令指名的算子——紧凑的程序驱动大型且输入特定的计算。作者将其类比于皮层：缓慢的低维轨迹（如同程序计数器）路由高维的计算操作。
- **核心研究问题**：能否将"可编程算子"思想引入Transformer的前馈模块，使神经解码模型在小数据、小参数下显著提升准确率？

## 2. 方法论

**核心思想：**

VN-SST 将冯·诺依曼存储程序架构的角色映射到一个Transformer层中：
- **内存（Memory）**：持续性选择性状态空间（SSM）与快速权重（fast-weight）路径，跨token携带状态；
- **指令指针（Instruction Pointer）**：低维SSM状态的读出信号；
- **控制器（Controller）**：将指针解码为每token的指令代码；
- **执行单元（Execution Unit）**：可编程的SwiGLU前馈算子，其权重由代码实时合成。

**技术细节：**

**（1）三条并行记忆通路（替代标准注意力）：**

- **通路1：局部感觉缓冲**——带宽为w的因果局部注意力，成本O(Tw)，只捕获短程结构；
- **通路2：选择性状态空间（慢动力学）**——对角输入依赖的SSM，携带逐通道状态s∈R^(d×n)跨段传递，其输出y_ssm是慢状态的**低维投影**，兼作指令指针；
- **通路3：快速权重联想记忆（情景式）**——delta规则矩阵记忆M，写入预测误差而非原始值，实现内容寻址的读取。

三条通路经控制器的读门（read gates）加权融合后残差连接到主网络。

**（2）可编程计算：低秩指令库（核心创新）：**

每个SwiGLU投影的权重矩阵按token合成：

W(t) = W₀ + Σₖ c_{t,k} · UₖVₖᵀ, c_t ∈ R^K

- W₀为共享基算子，{UₖVₖᵀ}为K个秩为r的学习到的低秩"指令"；
- 关键实现技巧：**无需物化任何token特定权重矩阵**——先投影到低秩库，按代码缩放，再读出，计算成本仅为O(Kr(d+d_ff))；
- Uₖ和U_dk初始化为零，保证训练刚开始时层恰好等于共享基SwiGLU。

**（3）指令指针（manifold-conditioned code）：**

c_t = tanh(MLP([u_t; P·y_ssm_t])) ∈ [−1,1]^K，P ∈ R^(m×d), m≪d

→ 慢速、低维的SSM潜在轨迹选择每个token实际执行的算子，形成"取指-解码-执行"回路。

**（4）训练方式：** 截断BPTT，分段长度L，携带状态跨段传递并在每几段后detach；SSM和delta规则记忆使用精确并行形式（log深度结合扫描和chunkwise WY三角求解），GPU上无逐时间步循环。

## 6. 主要结论与发现

1. **数据效率大幅提升**：在有限数据预算下，VN-SST显著优于Transformer——MC RTT上解码R²达0.351 vs 0.207，而记忆无关线性解码器R²为负（−0.236）。三个基准上全部领先。
2. **数据规模效应**：数据越稀缺，差距越大；随数据量增长差距缩小，但VN-SST始终保持至少持平。
3. **长上下文的独特优势**：在数据稀缺的MC RTT上，Transformer随上下文长度上升精度下降（0.61→0.57，出现过度拟合和过宽感受野问题），而VN-SST单调上升（0.60→0.68）——携带的SSM状态将长上下文整合为解码信息，而非单纯扩大注意力感受野。
4. **控制通道而非精度杠杆**：程序容量K的变化几乎不影响解码精度（R²随K波动的范围很小），但网络实际使用的指令数远小于库容量——32条指令被压缩为每token约2.5–3.2比特（等效3.4–6.5条有效指令），低于log₂32=5的上限。
5. **跨模态通用性**：在语言建模上VN-SST同样更参数高效（tiny-Shakespeare PPL 49 vs 61；WikiText-2 PPL 45 vs 52），且斜率更陡——表明每token算子合成是一个通用增益机制。

## 7. 优点

- **概念创新的可测量性**：将"程序化计算"这一抽象概念转化为可量化的控制比特诊断——这是传统MoE（仅混合输出）无法报告的信息；通过谱熵和参与比可度量网络实际使用的程序复杂度。

- **问题定位于真实场景**：聚焦小数据、小模型这一实际神经解码场景，而非追求大数据上限。

## 8. 不足与局限

**实验覆盖方面：**
- **缺乏正式消融研究**：指令库、SSM指针、快速记忆三条通路的相对贡献未被单独量化，无法判断性能提升的主要来源到底是哪种机制；

**应用限制方面：**
- **超参数敏感性与搜索未报告**：窗口w、SSM状态大小n、记忆维度d_k/d_v、流形读出维度m等默认超参数（K=8, r=8, m=8）的敏感性未被探讨；

## 摘要
语法知识及其经验测试通常被认为对表达中词汇项目的频率具有稳健性。然而，基于神经网络的语法模型表现出对词汇频率的高度敏感性。我们利用互补学习系统理论来检验一个假设：对词汇频率的稳健性可能通过海马体情景记忆机制产生，该机制能够快速编码和检索具体经验，并允许学习者在处理罕见模式时利用这些经验。我们使用检索增强语言模型作为这种情景记忆机制的实例化（具体为k近邻语言模型，通过显式实例存储增强参数模型），并测试这种增强是否有助于缩小普通语言模型在句法对比测试中表现出的词汇频率差距。通过使用频率分层测试项目的句法对比，我们发现检索增强缩小了高、低频项目之间的性能差距，这与情景记忆补偿弱参数表征的观点一致。这种收益在不同句法现象以及在不同预训练数据（儿童现实数据和大型数据）上预训练的模型中都保持一致。此外，我们表明结构信息对于有效检索至关重要，而仅语义相似性几乎无益。虽然这些是支持我们假设的有前景的概念验证结果，但频率差距是缩小而非完全消除。基于我们的分析，我们提出对检索实例进行优先重新加权、为结构信息提供更好的表征和检索策略，以及存储和检索的灵活配置，作为改进语言模型中情景记忆实现的有前景的未来方向。

## Abstract
Grammatical knowledge and how it is empirically tested are typically considered robust to the frequency of the lexical items in the expressions. However, neural network-based models of grammaticality exhibit high sensitivity to lexical frequency. We draw upon Complementary Learning Systems theory to test the hypothesis that robustness to lexical frequency can arise via a hippocampal episodic memory mechanism, which enables rapid encoding and retrieval of specific experiences and allows learners to leverage them when processing rare patterns. We use retrieval-augmented language models as an instantiation of such an episodic memory mechanism (specifically, $k$-nearest-neighbor language models that augment parametric models with explicit instance storage), and test whether this augmentation helps close the lexical frequency gap that vanilla language models exhibit in syntactic contrast tests. Using syntactic contrasts with frequency-stratified test items, we find that retrieval augmentation narrows the performance gap between high- and low-frequency items, consistent with episodic memory compensating for weak parametric representations. This benefit is consistent across different syntactic phenomena and across models pretrained on child-realistic and large-scale data. Additionally, we show that structural information is critical for effective retrieval, whereas semantic similarity alone provides little benefit. While these are promising proof-of-concept results supporting our hypothesis, the frequency gap is narrowed rather than fully closed. Based on our analyses, we propose preferential reweighting of retrieved instances, better representations and retrieval strategies for structural information, and flexible configurations of storage and retrieval as promising future directions for improving the implementation of episodic memory in language models.

## 1. 核心问题与整体含义

- **研究背景**：语言模型在句法对比测试中表现出系统性的词汇频率偏差——当测试项目包含低频词汇时，模型性能显著下降，即使底层语法对比与高频情况完全相同。这种偏差在以往文献中已被广泛证实（Wei et al., 2021; Kim et al., 2022; Diehl Martinez et al., 2024）。
- **核心问题**：人类在语法判断中对词汇频率表现出稳健性（Christensen & Kizach, 2024），那么是什么机制造成了人与模型之间的这种差距？本文提出了一个具体假设：**海马体情景记忆机制可能是人类频率稳健性的来源**。
- **整体含义**：本文基于互补学习系统（CLS）理论，将 kNN-LM（检索增强语言模型）作为情景记忆的功能类比实现，首次从经验层面检验“情景记忆能否补偿参数化模型的词汇频率偏差”这一假设。研究结果表明检索增强确实能显著缩小频率差距，为理解人类语法处理机制和提升语言模型鲁棒性提供了新视角。

## 2. 方法论

- **理论基础**：CLS 理论（McClelland et al., 1995; Kumaran et al., 2016）认为大脑拥有两个互补的记忆系统：
  - **海马体系统**：快速编码、检索具体经验（情景记忆）
  - **新皮层系统**：缓慢提炼可泛化的统计规律（参数化知识）
  - 当参数化知识薄弱时（如低频项目），情景记忆可通过直接检索相关过往经验来补偿。

- **具体实现**：采用 kNN-LM（Khandelwal et al., 2020）作为情景记忆的代理模型：
  - **数据存储**：为训练集中每个 token 存储键值对 `(fθ(x<t), xt)`，其中 `fθ(x<t)` 是最终 Transformer 块第二层归一化后的上下文表征（即 MLP 输入）。
  - **推断流程**：
    1. 计算查询向量 `qt = fθ(x<t)`
    2. 通过平方 L2 距离检索 k 个最近邻
    3. 计算 kNN 概率分布：`pkNN(xt|x<t) ∝ Σ exp(-d(k, qt)/τ)`
    4. 与参数模型分布插值：`p(xt|x<t) = λ·pkNN + (1-λ)·pLM`
  - 固定 λ = 0.25，变化 k ∈ {1, 16, 1024}，使用 FAISS 进行检索。
  
- **三种数据存储变体**（用于区分结构与语义信息贡献）：
  1. **全量检索（Full Retrieval）**：标准上下文嵌入，同时编码语义和句法信息。
  2. **语义仅-平均（Semantics-only, averaged）**：对上下文嵌入做位置平均。
  3. **语义仅-非上下文（Semantics-only, uncontextualized）**：使用 GloVe 和 fastText 嵌入求和，仅捕获词汇语义。

- **检索配置参数**：检索粒度（token/短语/序列）、上下文窗口大小 τ ∈ {1, 3, 10}、检索邻居数 k ∈ {1, 16, 1024}。

## 6. 主要结论

1. **检索增强总体有效**：kNN-LM 在所有三种句法现象和两种模型规模上均提升句法对比准确率，关系从句（RC）获益最大（大规模模型：0.65→0.84），表明检索在参数化表征最薄弱的场景下帮助最大。
2. **频率差距显著缩小但未完全消除**：低频项目获得大幅相对提升（错误率减少最高达 49.2%），自举置信区间确认低频增益与高频增益的区间不重叠，混合效应模型显示显著的频率×模型类型交互（β=0.52, p<0.001）。但低频准确率仍系统性低于高频。
3. **结构信息是关键驱动因素**：仅语义检索（GloVe、fastText）基本无效；结构匹配的检索实例是频率选择性收益的主要来源，基于相似度的选择只能起到次要补充作用。
4. **最优检索配置因现象而异**：序列级检索总体最强但效应量小；上下文窗口对关系从句偏好 τ=10、对主谓一致偏好 τ=3；k=16 为最优邻居数，过大（1024）引入噪声导致退化；没有普适的最佳配置。
5. **概念验证支持 CLS 假设**：结果支持“情景记忆可补偿弱参数表征”的假设，但 kNN-LM 仅是功能类比，不承诺具体神经机制实现。

## 8. 不足与局限

- **覆盖范围有限**：
  - 仅涉及英语的三种句法现象，结论向其他语言、其他句法结构、自然主义语言理解与产出的推广性未知。
  - 仅测试了两种规模的 GPT-2 模型，未覆盖其他架构（如编码器模型、MoE 模型）和更大规模的当代模型（如 Llama、Mistral 等）。
  
- **实验混杂因素**：
  - **语义-结构分离不彻底**：上下文嵌入的位置平均并不完全去除句法信息，结构匹配率也可能反映数据存储覆盖率而非检索质量。这意味着“结构关键、语义无助”的结论需要更干净的对照组来加固。
  - **频率阈值定义**：高频（f>10⁴）与低频（f<10³）的阈值选择是任意的，不同阈值下结论的稳健性未做敏感性分析。
  
- **理论与机制解释的局限**：
  - kNN-LM 只是 CLS 的功能类比，不模拟真实的海马体机制，包括在线情景编码、巩固过程、重放机制等。
  - 无法区分“检索帮助是因为直接记忆相关实例”还是“检索帮助是因为提供了更好的概率估计线索”，机制层面仍然是黑盒。

- **实证应用限制**：
  - 频率差距只是缩小而非完全关闭，意味着检索增强不能完全解决语言模型的频率偏差问题。

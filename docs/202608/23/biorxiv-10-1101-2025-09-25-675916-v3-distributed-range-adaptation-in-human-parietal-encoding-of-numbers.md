## 摘要
大脑的表征编码在神经群体的集体活动中，其非单调调谐特性定义了群体编码。适应行为要求随着刺激统计在不同情境中的变化，灵活地重新调谐这种编码。然而这种适应是如何发生的尚不清楚。通过在一个可变数字范围的数值估计任务中使用fMRI，我们展示了人类顶叶皮层中的数字表征动态地重新校准以适应情境，从而实现情境敏感的行为准确性。神经群体的调谐特性随范围集体移动和重新缩放。这种分布式范围适应实现了实时的高效编码：神经精度随范围缩放，并预测行为精度的相应变化。神经适应更强的个体表现出更大的行为调整。这些发现将静态的感觉高效编码扩展到抽象幅度适应的表征。这种灵活的群体调谐可能构成编码网络的一种典型机制，使大脑能够维持精确、适应的行为。

## Abstract
The brain's representations are encoded in the collective activity of neural populations, whose non-monotonic tuning properties define the population code. Adaptive behavior calls for flexible retuning of this code as stimuli statistics change across contexts. Yet how such adaptation occurs is unknown. Using fMRI during a numerosity-estimation task with variable number ranges, we show that number representations in human parietal cortex dynamically recalibrate to context, enabling context-sensitive behavioral accuracy. The tuning properties of neural populations collectively shift and rescale with the range. This distributed range adaptation achieves efficient coding in real time: neural precision scales with the range and predicts corresponding changes in behavioral precision. Individuals with stronger neural adaptation show larger behavioral adjustments. These findings extend static sensory efficient coding to adaptive representations of abstract magnitudes. Such flexible population tuning may constitute a canonical mechanism of encoding networks that enables the brain to sustain precise, adaptive behavior.

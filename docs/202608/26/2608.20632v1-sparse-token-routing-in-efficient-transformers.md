## 摘要
高效Transformer研究经常以并非所有令牌都需要同等计算量为由，推动令牌剪枝和自适应计算。我们使用SEWN——一种双流Transformer，通过学习的门控将令牌路由到轻量级或全容量处理——端到端地检验了这一主张。在我们的实验中，与参数匹配的基线相比，路由引入的准确率变化可忽略不计，而门的令牌重要性信号关键取决于其学习方式。静态词典初始化的先验在BoolQ上未能通过反事实忠实性测试，而全上下文门控在两个评估任务上均实现了高度显著的区分（$p<10^{-10}$），且不改变任务准确率。

## Abstract
Efficient-transformer research often motivates token pruning and adaptive computation with the claim that not all tokens require equal computational effort. We test this claim end to end using SEWN, a two-stream Transformer that routes tokens through either lightweight or full-capacity processing using a learned gate. Across our experiments, routing introduces negligible accuracy change relative to parameter-matched baselines, while the gate's token-importance signal depends critically on how it is learned. A static lexicon-seeded prior fails a counterfactual faithfulness test on BoolQ, whereas a fully contextual gate achieves highly significant separation ($p<10^{-10}$) on both evaluated tasks without changing task accuracy.

### 1. 核心问题与整体含义（研究动机和背景）

高效Transformer研究通常基于一个核心假设：**并非所有输入令牌（token）都需要同等的计算量**——功能词、样板文本和冗余上下文可以廉价处理，而内容承载令牌才需要全模型处理。这一假设支撑了大量令牌剪枝（如PoWER-BERT、TR-BERT）、令牌合并（ToMe）和自适应深度计算（Mixture-of-Depths）等工作，并捆绑了两个分属不同层面的声明：

- **效率声明**：跳过或廉价处理"不重要"的令牌可以节省计算量，且几乎不损失准确性；
- **可解释性声明**：决定哪些令牌"重要"的信号可以同时作为模型行为的可读解释。

本文的核心贡献在于**将这两个声明分离，并分别进行严格、诚实的检验**，而非像多数现有研究那样将二者捆绑预设为成立。作者明确指出：他们不声称SEWN是新的SOTA高效架构（事实上DistilBERT在同等或更小参数预算下原始准确率全面胜过SEWN），论文的价值在于方法论和机制层面的验证。

### 2. 方法论：核心思想、关键技术细节

#### 2.1 SEWN核心架构（Stream-Efficient Word Network）

- **双流设计**：令牌嵌入（词+位置+类型）后，通过一个小型MLP（SoftmaxRoutingGate）计算每个令牌的门控分数 $g \in [0,1]$，解释为"路由到廉价流的概率"。
- **轻量函数词流**（2层，256维）：接收门控值 $g$ 缩放的令牌嵌入；
- **全容量内容流**（4层，768维，BERT-base权重直接移植）：接收 $(1-g)$ 缩放的令牌嵌入；
- **层次交叉注意力融合**：融合两个流的表征后送入分类头。

#### 2.2 门控的两种变体

| 门控类型 | 设计 |
|---------|------|
| **静态先验门** | MLP输出加一个基于手工构建的封闭类词（功能词）词典初始化的词表偏置（BERT下269个token id） |
| **上下文门** | 完全无词典偏置，门控完全从训练信号中学习令牌优先级 |

#### 2.3 三个衍生变体

- **SEWN-sparse**：硬选择top-k令牌（始终包含[CLS]）送入昂贵的内容流；廉价流仍处理全序列以保持上下文；跨注意力块恢复必要上下文，避免昂贵流中的 $O(n^2)$ 注意力。**这是真正能节省FLOPs的版本**。
- **SEWN-lean**：移除第二流和融合模块，门控作为唯一逐令牌机制（单流）。
- **SEWN-random-topk**（纯消融）：与SEWN-sparse架构相同，但top-k选择为均匀随机，用于隔离"学到排序"与"硬选择瓶颈"各自的贡献。

#### 2.4 忠实性测试协议（反事实掩码法）

- 在验证子样本（n=200）上，按每种方法的令牌重要性排序，分别掩码top-20%、bottom-20%和五个随机20%的令牌；
- 测量掩码后模型对原始预测的softmax置信度下降；
- **严格忠实性判据**：top掩码的置信度下降显著大于bottom和random掩码（$p<0.05$，配对t检验），且random掩码下降显著大于bottom掩码（即需满足 **top > random > bottom** 的单调次序）。

### 6. 主要结论与发现

#### 6.1 通过检验的四项声明

1. **手工语言先验的危害**：基于功能词词典的静态先验可以静默地破坏学习到的重要性信号可靠性，且**在准确率指标上完全无迹可寻**——两种门控在BoolQ上准确率几乎无差（68.85 vs. 69.20），但忠实性判若云泥。
2. **硬top-k选择的计算收益真实且可扩展**：SEWN-sparse相对BERT-base达到 **5.2–8.7×** 加速，相对DistilBERT **2.6–4.4×**，且从BoolQ到PubMedQA（3倍数据+3倍序列长度）比率保持稳定。
3. **忠实性的关键在于"选择标准是内容的稳定函数"**：随机top-k（相同架构、相同瓶颈）忠实性完全不显著（$p=0.45$），证明贡献来自**学习到的排序本身**而非硬稀疏性；蒸馏从忠实教师转移的正是这种稳定排序属性，而非准确率。
4. **SEWN-sparse的反事实分离最干净**：相比直接重实现的Mixture-of-Depths（其router有真实信号但bottom和random无法排序），SEWN-sparse是唯一满足严格 top > random > bottom 次序的方法。

#### 6.2 未通过检验的四项声明

1. **路由/门控本身并不能提升任务准确率**：在BoolQ上SEWN与统一50/50门控统计上不可区分；在SWAG上双流增益来自并行容量而非自适应性。
2. **路由重要性信号并非稠密Transformer结构上无法获得的**：原始注意力（几乎零成本）即可通过忠实性测试，SEWN的门控并不提供结构性不可替代的解释能力。
3. **效率/忠实性包并非跨任务类型均匀成立**：在二元QA和情感分类上稳健，但在**长段落多项选择阅读理解（RACE）上整体崩塌**——DistilBERT相对BERT-base掉13.1点，SEWN-sparse仅为42.97（随机下限25%），这是压缩模型共有的容量限制而非路由特有问题。
4. **"上下文门比静态先验门更忠实"不具主干泛化性**：在RoBERTa/BoolQ上，BERT上干净通过的配置（$p=1.7\times10^{-10}$）失败（$p=0.177$），且完整的先验大小/覆盖/内容扫描均无法解释此差异——这是一个诚实的**主干依赖结果**。

### 7. 优点：方法与实验设计的亮点

1. **声明分离测试**：将效率声明与可解释性声明拆开，分别检验，并各自给出"通过/未通过"的明确判据——这比笼统宣称"既快又可解释"严谨得多。
2. **审慎诚实的负面报告**："我们应该报告一些负面结果，因为我们自己的多个工作假设在研究过程中被证伪了，我们相信这些证伪比一个过滤过的成功故事对社区更有用。"这种态度在当前顶会论文中极为稀缺。
3. **严格的三方对照**：random-topk消融干净地证明了"瓶颈本身不足以解释忠实性"，attn-topk揭示了非学习排序的实际成本（额外完整前向传递），MoD直接重实现而非启发式代理。
4. **成本意识贯穿始终**：对可解释性声称的评估不是孤立的忠实性分数，而是放在"为获得该分数需支付多少额外推理成本"的联合前沿上（图5）；积分梯度在20步下并不更忠实，却贵46倍。
5. **机制性修补演示**：SEWN-lean忠实性失败后，通过蒸馏教师门控分数（ $\mathcal{L}=\mathcal{L}_{\text{task}}+\alpha\cdot\mathcal{L}_{\text{logit-KD}}+\beta\cdot\mathcal{L}_{\text{gate-MSE}}$，$\alpha=1.0,\beta=2.0$）从 $p=0.205$ 修复到 $p=1.6\times10^{-7}$，证明忠实性是可选转移的属性，与准确率可分离。

### 8. 不足与局限

1. **未直接对比主流剪枝实现的真实代码**：PoWER-BERT、TR-BERT、Learned Token Pruning、ToMe均未纳入benchmark；MoD是双向适配版而非原训练流程复现，SEWN-attn-topk只是同类思想的代理——表X不应被解读为替代对这些方法发布代码的直接基准测试。
2. **PubMedQA使用自定义平衡子集**：不是标准pqa_labeled协议，绝对值与PubMedQA排行榜不可比。
3. **主干规模限制**：全部实验限于55–110M参数的BERT级主干，对十亿级参数模型的经济性和可解释性成本结构不适用。
4. **忠实性判据的行为性局限**：通过反事实掩码测试仅说明"掩码这些令牌比其他令牌更能改变预测"，不等于这些令牌是唯一或真正因果的解释——多个有效排序可能通过同一测试（Jain & Wallace意义上的行为性而非机制性）。
5. **统计严谨性细节**：每组条件n=200且未做多重比较校正；作者估算标准校正不会改变任何PASS/FAIL结论，但更小n的重复 + 校正能进一步加强结论。
6. **任务配方未单独调优**：RACE和Winogrande使用BoolQ松调节的单一配方，可能低估了这些任务上的潜力（尽管DistilBERT的类似崩塌弱化了纯SEWN特有解释）。
7. **主干依赖的不确定性**：RoBERTa/BoolQ上的无法复制结果，作者做了穷举式confound扫描后仍无法解释——这是如实报告的开放问题，但意味着"上下文门更忠实"这一核心发现的泛化边界尚未明确。

## 摘要
基于注意力的序列模型在处理长上下文时面临二次方成本，这促使了越来越多关于基于记忆的模型的研究，这些模型可以将上下文压缩为紧凑的状态。然而，现有的大多数记忆模型在整个序列中暴露静态记忆。由于早期的标记没有压缩压力，它们占据了过多的自由度并“污染”了记忆状态，使得留给后续上下文的空间很少，并增加了存储内容与后续到达内容之间的干扰。我们研究了一种新的增量记忆激活范式，其中记忆的有效容量随上下文增长而逐步扩展。施加早期瓶颈迫使模型更有效地压缩历史，而随时间解锁新的容量则减少干扰并改善对后续上下文的保留。我们将这一范式实例化为Proteus，这是一种简单的机制，可以无额外成本地融入广泛的神经记忆架构。我们将Proteus应用于最先进的模型，包括SWLA、Comba、Titans和Hope-Attention，并观察到在标准语言建模和推理以及长上下文检索和理解方面的一致改进，且增益在更长的上下文长度下增长。总体而言，我们的结果表明静态记忆是次优的，安排有效容量是序列建模中一个简单且广泛适用的工具。

## Abstract
The quadratic cost of attention-based sequence models for long contexts has motivated a growing line of research on memory-based models that can compress context into a compact state. However, most existing memory models expose a static memory throughout the entire sequence. Because early tokens face no compression pressure, they occupy too many degrees of freedom and "pollute" the memory state, leaving little capacity for later context and increasing interference between what is stored and what arrives next. We study a new paradigm of incremental memory activation, where the effective capacity of memory is progressively expanded as the context grows. Imposing an early bottleneck forces the model to compress history more effectively, while unlocking fresh capacity over time reduces interference and improves retention of later context. We instantiate this paradigm in Proteus, a straightforward mechanism that can be incorporated into a broad class of neural memory architectures at no additional cost. We apply Proteus to state-of-the-art models, including SWLA, Comba, Titans, and Hope-Attention, and observe consistent improvements on standard language modeling and reasoning, as well as on long-context retrieval and understanding, with gains that grow at longer context lengths. Overall, our results show that static memory is suboptimal and that scheduling effective capacity is a simple and broadly applicable tool for sequence modeling.

## Proteus：用于长上下文序列建模的增量记忆激活

### 1. 论文的核心问题与整体含义

- **研究背景**：基于注意力（Attention）的 Transformer 模型在处理长上下文时计算成本呈二次方增长，促使研究者探索基于记忆（Memory）的模型，将上下文压缩到固定大小的紧凑状态中。
- **核心问题**：现有记忆模型普遍采用**静态记忆**——即在整个序列处理过程中，记忆容量保持不变。这导致两个严重问题：
  - **早期记忆污染**：早期的 token 到达时记忆近乎空白、竞争压力小，不存在压缩压力，因而会占用过多的自由度，形成“过度记忆”而非“有效压缩”，从而污染记忆状态。
  - **后期干扰（Interference）**：后期的 token 只能在所剩不多的容量中被写入，写入过程不断覆盖或干扰先前存储的信息，导致模型难以吸收和保留后续上下文。
- **整体含义**：论文提出"静态记忆是次优的"这一核心论断，主张记忆的有效容量应当**随上下文长度逐步扩展**，而非从一开始就全部暴露。这为长上下文序列建模提供了一种全新的、正交于具体模型架构的改进视角。

### 2. 论文提出的方法论

- **核心思想：增量记忆激活（Incremental Memory Activation）**
  - 和固定容量静态记忆不同，Proteus 将记忆容量视为一个**可调度的资源**：在上下文初期施加瓶颈以强迫压缩，在上下文增长过程中逐步解锁新容量以承接新信息。
- **形式化定义（容量调度关联记忆）**：在每一步 $t$，引入激活算子 $G_t$（以掩码 $g_t$ 实现），只允许记忆的活跃子集参与读取和写入：
  - 更新：$M_t = M_{t-1} - \theta_t \, G_t\left( \nabla \tilde{L}(M^{(g)}_{t-1}; k_t, v_t) \right)$，其中 $(1-g_t) \odot M_t = (1-g_t) \odot M_{t-1}$（锁定的块保持不变）
  - 读取：$y_t = \text{Read}(M^{(g)}_{t-1}, q_t)$
- **Proteus 的具体实现**：
  - 将记忆参数划分为 $E$ 个等大的连续块（默认 $E=16$）。
  - 使用**均匀增长的前缀调度**：在位置 $t$，激活前 $k(t) = \min(E, 1 + \lfloor (t-1)/\Delta \rfloor)$ 个块，其中 $\Delta = \max(1, \lfloor N/E \rfloor)$，$N$ 为训练上下文长度（8K）。
  - 掩码 $g_t$ 为对应前缀掩码：激活区内为 1，其余为 0。
  - 超过训练窗口后全部块激活，推理时不引入任何额外开关。
- **扩展到 MLP 块（Nested Learning 视角）**：将 MLP 块参数的梯度更新也视为一种"在线记忆"，通过同样的门控机制调度参数更新：$\theta_{i+1} = \theta_i - \eta_{i+1}(g_{i+1} \odot e_i)$。这使得 Proteus 可应用于 Hope-Attention 等架构。
- **关键优势**：Proteus 不改变记忆的内部目标函数、优化器或记忆架构，只控制哪些参数在每个位置被暴露，因此可以**零额外成本**即插即用于广泛的记忆模型。

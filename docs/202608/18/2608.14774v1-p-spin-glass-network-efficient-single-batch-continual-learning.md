## 摘要
现代序列模型严重依赖大规模内存占用和大批量随机优化，这些障碍限制了样本效率和持续学习。我们引入了p-自旋玻璃网络（p-Spin Glass Network），一种新颖的架构，它克服了这些限制，在结构上管理优化方差，并产生了四个显著能力：1. 它强制内存效率：原生三元量化将内部参数压缩8倍，而精确的隐式梯度将激活内存严格限制为O(B·T·D)。2. 它展示了样本效率，在利用8倍更少训练序列的情况下，达到了与Transformer基线相当的性能。3. 该方法在随机微批量大小为1时实现了单批次稳定性和平滑、单调的收敛。4. 最后，这种稳定性被证明是模态无关的，在离散子词和长视界未压缩原始字节流上均保持了稳健的时间信用分配。最终，这项工作消除了稳定深度学习对大批量的需求，为持续学习和边缘AI奠定了基础。

## Abstract
Modern sequence models heavily rely on massive memory footprints and large-batch stochastic optimization, barriers that restrict sample efficiency and continual learning. We introduce the $p$-Spin Glass Network, a novel architecture that overcomes these limitations, structurally manages optimization variance and yields four noticeable capabilities: 1. It enforces memory efficiency: native ternary quantization compresses internal parameters by $8\times$, while exact implicit gradients strictly bound activation memory to $\mathcal{O}(B \cdot T \cdot D)$. 2. it demonstrates sample efficiency, matching the asymptotic performance of a Transformer baseline while utilizing $8\times$ fewer training sequences. 3. Method enables single-batch stability and smooth, monotonic convergence at a stochastic micro-batch size of $1$. 4. Finally, this stability proves modality-agnostic, maintaining robust temporal credit assignment across both discrete subword and long horizon uncompressed raw byte streams. Ultimately, this work removes large batch requirement for stable deep learning, establishing a foundation for continuous learning and edge AI.

**研究动机与背景：**

- 大批量（large-batch）梯度累积是训练稳定性的关键前提，但这一要求极大地阻碍了低资源场景、边缘设备部署和**持续学习**（continual learning）的发展。
- 虽然线性时间状态空间模型（SSM，如 Mamba）和极端量化技术（如 1.58-bit）分别缓解了序列长度内存瓶颈和参数压缩问题，但它们**未能解决小批量（甚至单样本）训练时的梯度方差与优化不稳定问题**。
- 论文的核心主张：通过结合**隐式深度学习**（Implicit Deep Learning）和**物理学启发的自旋玻璃吸引子**（Spin Glass Attractor），可从根本上消除大批量训练的硬性要求，同时实现样本高效、内存高效和模态无关的序列建模。

## 2. 论文提出的方法论

**核心思想：** 将序列建模重新定义为连续时间状态空间积分与 p-自旋玻璃平衡吸引子的耦合系统，并借助隐式函数定理（IFT）获得精确的解析梯度，使激活内存与迭代深度无关。

**关键技术细节：**

- **连续 ODE 积分（门控状态空间）：**
  - 对输入进行 RMSNorm 归一化。
  - 计算 Q、K、V 和门控 G（softplus 负域约束，保证因果衰减）。
  - 将序列划分为 N 个 chunk（chunk size = C），在 SRAM 中物化 C×C 的因果衰减掩码，避免 O(T²) 内存。
  - 通过**chunk 内因果注意力**与**跨 chunk 全局状态记忆 h** 结合，实现线性复杂度的长序列上下文建模。

- **p-自旋玻璃高阶相互作用（隐式平衡吸引子）：**
  - 将外部投影矩阵 W_ext 和内部平衡矩阵 W_int **三值量化**为 {−1, 0, 1}（1.58-bit，实际打包为 2-bit），通过 STE（Straight-Through Estimator）保持可微。
  - 通过 K 次微步迭代求解能量最小点 Y*：
    - Y = tanh(U) ⊙ σ(G)
    - H = Z + (γ ⊙ Y)(W_int^Q)⊤
    - 其中 γ 为可学习的自旋受挫率（frustration rate），约束为 0.5·tanh(γ_param)。
  - 该迭代过程本质上是一个**有界 Lipschitz 常数的隐式平衡层**。

- **精确隐式梯度（IFT）：**
  - 不使用 O(K) 层的反向传播图展开，而是通过**Neumann 级数**近似逆 Jacobian。
  - 梯度仅依赖收敛状态 Y* 和最终迭代步的中间变量，激活内存严格为 O(B·T·D_int)，**与迭代次数 K 无关**。

**算法流程（文字概括）：**
1. 输入文本经 tokenizer（子词或字节级）编码为离散 ID。
2. 嵌入层映射得到 X⁽⁰⁾。
3. 每层依次执行：RMSNorm → SSM 连续积分（chunk 内注意力 + 跨 chunk 状态更新）→ 残差 → p-spin 隐式平衡求解（K 次微步）→ 下投影 → 残差。
4. 最终经 RMSNorm 和 tied embedding 投影到词表空间，计算交叉熵损失。

## 摘要
长视野机器人策略需要紧凑地访问近期观察和可复用经验，而不扩展视觉-语言-动作（VLA）上下文。我们引入了Remember Smarter（RS），一个即插即用模块，具有互补的视觉历史和双曲经验记忆分支。其视觉分支使用双向空间Mamba和因果时间Mamba压缩多视图补丁历史，然后通过残差交叉注意力将生成的记忆暴露给面向动作的隐藏状态，同时保持VLM视觉标记流不变。其经验分支将成功的最终层VLM状态存储在庞加莱VAE空间中，分层组织它们，并异步将检索到的经验转换为测地线提示标记，而不阻塞动作推理。当适配到pi0时，RS将LIBERO-Plus上的总成功率从53.6%提高到70.6%，并在设计用于评估记忆保持和经验利用的真实机器人实验中取得了显著的性能提升。

## Abstract
Long-horizon robot policies require compact access to recent observations and   reusable experience without expanding the vision-language-action (VLA)   context. We introduce Remember Smarter (RS), a plug-and-play module with   complementary visual-history and hyperbolic experience-memory branches. Its   visual branch compresses multi-view patch histories using bidirectional   spatial Mamba and causal temporal Mamba, then exposes the resulting memory to   action-facing hidden states through residual cross-attention while leaving the   VLM visual-token stream unchanged. Its experience branch stores successful   final-layer VLM states in a Poincare VAE space, organizes them hierarchically,   and asynchronously converts retrieved experience into geodesic prompt tokens   without blocking action inference. When adapted to pi0, RS increases total   success on LIBERO-Plus from 53.6% to 70.6% and   achieves substantial   performance gains in real-robot experiments designed to evaluate memory   retention and experience utilization.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构
- RS 是一个即插即用模块，由两个互补分支组成：
  - **视觉历史分支（Visual-History Branch）**：处理近期多视角观测的压缩与记忆注入。
  - **双曲经验分支（Hyperbolic Experience-Memory Branch）**：存储并检索长期成功经验。
- 设计目标：**保持 VLM 视觉标记流（visual-token stream）完全不变**，仅通过残差方式向动作相关的隐状态注入记忆信息。

### 2.2 视觉历史分支：Mamba 压缩 + 残差交叉注意力
- **输入**：多视角（multi-view）的图像 patch 历史序列。
- **空间压缩**：采用**双向空间 Mamba**（bidirectional spatial Mamba），沿空间维度聚合多视角 patch 间的相关性，提取紧凑的空间特征。
- **时间压缩**：在空间压缩之上，采用**因果时间 Mamba**（causal temporal Mamba），沿时间维度对历史帧进行因果压缩，输出固定长度的记忆表征。
- **记忆注入**：通过**残差交叉注意力（residual cross-attention）**，将压缩后的记忆表征暴露给面向动作的隐状态（action-facing hidden states）。此过程不修改 VLM 原有的视觉 token 计算路径，仅向动作决策路径附加额外信息，从而保证 VLM 主体结构不受扰动。

### 2.3 双曲经验分支：庞加莱 VAE + 层级组织 + 异步提示
- **经验存储**：将成功轨迹对应的 VLM **最终层隐藏状态**存入**庞加莱变分自编码器（Poincaré VAE）**所定义的双曲空间中。
- **层级组织**：双曲空间的树状几何特性天然适合对经验进行层级化组织，使相似经验在测地距离上更接近，支持更高效的分层检索。
- **异步检索与提示生成**：检索到的经验被转换为**测地线提示词（geodesic prompt tokens）**，并通过**异步机制**注入策略，避免阻塞动作推理过程。
- **算法流程概述**：训练时，收集成功轨迹 → 提取最终层 VLM 状态 → 在庞加莱空间中进行编码与层级聚类；推理时，当前观测经视觉分支得到记忆，同时按测地距离检索最相关的历史经验，将二者融合为动作决策的附加条件。

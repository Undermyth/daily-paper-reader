## 摘要
实时长篇数字人生成依赖因果模型来扩展音视频内容，同时在连续片段中保持主体外观和音视频同步。有界缓存保留局部运动和语音上下文，但丢弃较早的证据，而关注完整生成历史计算成本高且可能传播累积误差。我们提出 \method，一种用于少步骤联合音视频生成的锚定引导持久记忆框架。该框架保持不可变的视觉锚定，将已完成的视频和音频块压缩为固定容量的动态状态，并通过模态特定的残差注意力检索这些状态，而无需扩展活动缓存。一种参考感知调制方法还根据动态和锚定外观统计来调节视频特征。锚定保持的因果上下文蒸馏改变推演范围、前缀来源和缓存历史可靠性，同时保持不可变的视觉锚定不受干扰。通过将持久记忆与阶段局部去噪依赖分离，\method 进一步允许跨块阶段并行执行，无需针对特定管线的重新训练即可加速自回归推理。我们使用外观、时间、同步、面部和语音诊断指标评估长篇视频延续。结果表明，\method 在提示条件片段中保持稳定的外观，并在自回归生成下保持强烈的音视频同步。我们的项目页面是 https://taoliveaigc.github.io/TaoMate。

## Abstract
Real-time long-form digital-human generation relies on causal models to extend audio-visual content while preserving subject appearance and audio-video synchronization across successive segments. A bounded cache retains local motion and phonetic context but discards older evidence, whereas attending to the complete generated history is computationally expensive and can propagate accumulated errors. We present \method, an anchor-guided persistent-memory framework for few-step joint audio-video generation. The framework preserves an immutable visual anchor, compresses completed video and audio blocks into fixed-capacity dynamic states, and retrieves those states through modality-specific residual attention without extending the active cache. A reference-aware modulation method additionally conditions video features on dynamic and anchor appearance statistics. Anchor-preserving causal-context distillation varies rollout horizon, prefix provenance, and cache-history reliability while keeping the immutable visual anchor unperturbed. By separating persistent memory from stage-local denoising dependencies, \method further admits stage-parallel execution across blocks, accelerating autoregressive inference without pipeline-specific retraining. We evaluate long-form video continuations with appearance, temporal, synchronization, facial, and speech diagnostics. Results show that \method preserves stable appearance across prompt-conditioned segments and strong audio-visual synchronization under autoregressive generation. Our project page is https://taoliveaigc.github.io/TaoMate.

- **研究领域**：联合音视频扩散模型在数字人生成领域取得了显著进展，能够在统一生成过程中建模语音、面部动作和身体动态。
- **关键挑战**：长时段（long-form）自回归生成中，需要在一系列有序文本提示驱动下，让动作和语音持续演变，同时保持目标主体、场景和声学特征与早期生成内容一致。

### 两大核心挑战

1. **长时音视频一致性（Long-term audio-visual consistency）**
   - 有界 KV 缓存只保留近期运动与语音上下文，早期主体、场景和声学证据最终会离开缓存；
   - 若保留完整生成历史，注意力和存储将随时间增长，且模型会反复基于旧的、不完美的预测进行条件生成，导致错误在递归延续中传播（面部结构、颜色、场景布局、发音等微小误差被累积放大）；
   - 因果蒸馏本身不能消除该问题，因为教师轨迹提供的是干净的双向上下文，而部署时学生必须消费自己生成的因果输出。

2. **高效自回归推理（Efficient autoregressive inference）**
   - 每个时间块必须在一个大规模联合音视频模型中遍历多个去噪阶段；
   - 传统逐块执行方式需等一个块的所有阶段完成后再推进下一个块，浪费了跨块的因果就绪计算。

### 核心思路

TaoMate 将时间条件分解为**有界、带位置的活动上下文（active context）** 和**固定容量的持久记忆（persistent memory）**，前者保留细粒度局部运动与语音连续性，后者保留离开缓存后的与时长无关的视觉和声学证据，从而在保持条件成本不随生成时长增长的前提下，实现稳定的递归生成和实时推理。

## 2. 论文提出的方法论

### 2.1 总体框架：锚定引导的持久记忆（Anchor-Guided Persistent Memory）

系统以如下因果分解方式工作：

```
zt ~ pθ(zt | et, Ct-1, Mt-1)
Mt = U(Mt-1, sg(zt))
```

- **Ct−1**：有界活动上下文，保留带位置编码的近期令牌，用于局部连续性；
- **Mt−1**：固定容量持久记忆，压缩已分离的历史证据；
- **sg(·)** 表示停止梯度，避免通过无界记忆更新链反向传播；
- 存储和条件计算成本均不随已生成时长增长。

### 2.2 记忆的因子化表征

持久记忆分为**固定参考**和**自适应模态特定状态**：

```
Mt = (av, aa, mvt, mat, κt, πt)
```

| 组件 | 含义 | 更新时间规则 |
|---|---|---|
| **av（视觉锚）** | 初始块的规范视觉证据 | 不可变 |
| **aa（音频参考）** | 初始块的规范声学特征 | 不可变 |
| **mvt（视频内容记忆）** | 演变的空间结构 | 自适应，门控更新 |
| **mat（音频内容记忆）** | 演变的声学结构 | 自适应，无门控更新 |
| **κt, πt（外观状态）** | 通道级和低频外观统计 | 自适应，门控+硬拒绝 |

### 2.3 关键公式与技术细节

#### （1）因子化块表征

将每个生成的块分解为归一化内容表征和未归一化的外观表征：

```
svt = Pv[NormHW(z̄vt)],  z̄vt = Fv⁻¹ Σ_f zvt,f
sat = Pa[NormFa(zat)]
κ*t = K(zvt),  π*t = Pc(z̄vt)
```

- `NormHW` 按空间维度标准化视频通道，`NormFa` 按时间维度标准化音频通道；
- 归一化内容保留相对空间/声学结构，外观观测保留颜色、对比度和粗粒度空间统计。

#### （2）锚约束的记忆演化（Anchor-constrained memory evolution）

采用**加权欧几里得重心**（barycenter）形式进行在线估计：

```
E(m, a, s; β, λ) = (1−λ)[(1−β)m + βs] + λa
```

- **β** 控制证据同化速率；
- **λ** 施加持久参考先验（锚被每次更新重新引入）；
- 历史证据和孤立误差以几何速率衰减 `(1−λ)β[(1−λ)(1−β)]^k`。

#### （3）视频观察置信度门控

视频记忆更新受**锚一致性**约束：

```
ρt = B⁻¹ Σ_b cos(vec(svt,b), vec(avb))
gt = gmin + (1−gmin)σ((ρt − τ)/Tg)
mvt = E(mvt−1, av, svt; βv·gt, λv)
```

- 与视觉锚的一致性低时，视频更新速率被抑制，限制结构不一致生成的影响；
- 非零门控下限避免在姿势或场景合法变化导致相似度下降时不可逆地冻结更新；
- 音频更新**不加门控**，因为快速的语音变化是预期行为而非身份漂移；
- 外观状态（κt, πt）使用相同的软置信门控外加基于与锚统计归一化偏差的**硬拒绝规则**。

### 2.4 记忆条件化（Memory Conditioning）

持久记忆不转换为额外位置历史，而是通过**结构匹配条件化**方式影响生成：

1. **模态特定记忆注意力（Modality-specific memory attention）**：
   ```
   ehmℓ = hmℓ + MemAttn_mℓ(RMSNorm(hmℓ), umt−1)
   ```
   内容记忆支持查询相关的检索，记忆 K/V 处于活动缓存之外。

2. **参考感知 FiLM 调制（Reference-aware FiLM）**：
   ```
   bvℓ = evℓ + γℓ(ct−1) ⊙ RMSNorm(evℓ) + bℓ(ct−1)
   ```
   动态与锚定通道统计的拼接通过 FiLM 残差调制视频特征。

两条路径均为残差且初始化为恒等映射。

### 2.5 因果上下文蒸馏（Causal-Context Distillation）

**目标**：弥合教师轨迹（干净双向上下文）与学生部署（自身不完美因果历史）之间的上下文分布差距。

**关键策略**：
- 混合 rollout 视野（5 块概率 0.8，10 块概率 0.2）；
- 部分使用分离的学生生成前缀（概率 0.1）；
- 对中间非锚块沿前向流匹配路径施加扰动（`σ ~ U(0, 0.15)`），但**持久视觉锚保持干净**；
- 采用分布匹配蒸馏（DMD）+ 视频 PCM（Phased Consistency Models）正则化；
- 持久记忆更新从优化图中分离，支持扩展因果 rollout 而不需在完整历史中保留梯度。

### 2.6 记忆感知阶段并行推理（Memory-Aware Stage-Parallel Inference）

- 视频被划分为有界窗口序列，跨窗口条件对 `Sn−1 = (Pn−1, Mn−1)` 传播；
- 每个管线 rank 分配一个去噪阶段，维护独立的视频-音频 KV 缓存；
- 每个窗口生成前，各阶段从统一干净前缀 `Pn−1` 预填充缓存；
- 任务 `(b, k)` 依赖前一阶段的同块 `(b, k−1)` 和本阶段的前块 `(b−1, k)`，满足 `b + k = d` 的任务形成**反对角波前**，实现不同块在不同去噪阶段同时处理；
- 只有最终阶段的干净块才更新跨窗口记忆；
- 无需管线特定重训练即可实现，区别于 HiAR 等方法。

## 7. 结论与贡献总结

### 主要贡献

1. **提出锚定引导的持久记忆机制**：将长时上下文压缩为固定容量、因子化的记忆状态，以有界成本维持无限历史的视觉与声学一致性，从机制上解决了有界缓存丢失早期证据与无限历史导致误差累积的双重困境。  
2. **设计锚约束的记忆演化规则**：通过加权重心在线更新、置信度门控与硬拒绝规则，使得记忆更新既能吸收合理演变，又能抑制结构不一致的错误生成。  
3. **提出因果上下文蒸馏**：将训练时的双向教师上下文与部署时学生自回归因果上下文之间的差距显式纳入优化，配合记忆分离策略支持扩展 rollout 训练。  
4. **设计记忆感知阶段并行推理**：通过跨块、跨去噪阶段的反对角波前调度，在不重训练的情况下实现 3×RTX PRO 5000 下 35.0 FPS 的实时协同推理，超过 24fps 播放率 45.8%。  
5. **构建长时音视频数字人生成基准**：提供中英文单主讲人、60 秒/768×512、由文本提示序列驱动的评测协议与一致性指标（Color Δ、Long Consistency、Face Consistency 变体），后续可复用。

## 8. 批判性分析与个人评价

### 8.1 方法设计的合理性

- **概念优雅**：将“长时一致性”问题转化为“如何构建与更新一个压缩记忆”的控制论问题，锚定参考提供了稳定吸引子，门控机制提供了对噪声预测的鲁棒性。  
- **工程实用**：记忆更新不依赖梯度（sg 分离），推理阶段无需重训练即可获得并行加速，具有较高的落地潜力。  
- **理论自洽**：加权重心更新对应的几何衰减误差上界分析，为“历史错误不会无限累积”提供了理论支撑基础，在数字人长时生成文献中不多见。

### 8.2 主要局限

- **全合成数据验证**是当前最显著的弱点。教师模型 LTX-2.3 本身尚未收敛到完美，学生模型在合成轨迹上蒸馏的能力上限受教师质量制约；真实视频上的泛化能力完全未知。  
- **“实时”定义需谨慎**：单卡 11.1 FPS 并不实时，多卡 35.0 FPS 是 3×72GB 高端卡集群下的结果，与端侧或消费级部署仍有距离。  
- **条件设计中对“声音一致性”的处理较浅**：仅用初始音频块做锚（aa）+ 内容记忆（mat），未见对音色、说话风格等更高层声学身份的显式建模。  
- **长时视频的物理合理性欠缺**：60 秒测试场景中，手势、视线、表情能否在长时间内自然演变而非“记忆中相似内容的重现”，论文未做细粒度分析。  

### 8.3 未来方向

1. 在真实视频数据上扩展训练与评估，验证跨域泛化能力；  
2. 引入多说话人、多场景、多相机轨迹，增强记忆的适应性；  
3. 将记忆机制扩展到音频身份（音色）与语义内容分离建模；  
4. 探索单卡实时部署的蒸馏与剪枝方案；  
5. 增加人类感知评估（如 MOS、A/B 偏好）与长时间回看的逐帧错误分析。

## 9. 一句话总结（核心贡献）

> TaoMate 通过“锚定引导的持久记忆 + 锚约束门控更新 + 因果上下文蒸馏 + 记忆感知阶段并行”，在不随生成时长增长的条件成本下，实现了中英文长时音视频数字人的稳定递归生成与多卡实时推理，但其验证目前局限于合成数据，真实场景泛化与单卡实时性仍待进一步工作。

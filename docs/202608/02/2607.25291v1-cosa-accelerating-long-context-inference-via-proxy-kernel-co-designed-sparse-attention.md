## 摘要
自注意力的二次方成本使得长上下文推理变得极其昂贵，而基于代理的块稀疏注意力已成为一种实用的补救措施。现有方法通常依赖代理来预测二值稀疏掩码，并通过内核来消费该掩码并执行稀疏注意力计算。这类方法在中等预算下有效。然而，随着预算收紧，估计的代理不可避免地丢失一些显著块，而内核只能机械地应用稀疏掩码，导致模型准确度明显下降。我们提出CoSA，一种代理-内核协同设计的、两阶段免训练的稀疏注意力机制，它结合了内核感知代理（KAP）与有序跳跃内核（OSK）。在第一阶段，KAP在中等预算下选择块，并生成一个有序掩码，该掩码规定了内核内循环中KV页的访问顺序。在第二阶段，OSK应用该掩码，并根据在线softmax统计在收紧的预算下跳过多余的块。在主流大语言模型骨干网络和长上下文基准测试中，CoSA在更低预算下获得了更高的准确度。令人印象深刻的是，在128K上下文长度下，CoSA实现了4.93倍的注意力加速，并将端到端首令牌时间减少了2.53倍，同时性能下降可忽略不计。

## Abstract
The quadratic cost of self-attention makes long-context inference prohibitively expensive, and proxy-based block-sparse attention has become a practical remedy. Existing methods typically rely on a proxy to predict a binary sparse mask and a kernel to consume this mask and perform sparse attention computation. Such an approach is effective under moderate budgets. However, as the budget tightens, the estimated proxy inevitably drops some salient blocks, while the kernel can only apply the sparse mask mechanically, leading to an evident drop in model accuracy. We propose CoSA, a two-stage training-free Sparse Attention under proxy-kernel CO-design, which couples a Kernel-Aware Proxy (KAP) with an Ordered-Skipping Kernel (OSK). In the first stage, the KAP selects blocks under a moderate budget and produces an ordered mask that prescribes the order in which KV pages are visited in the kernel inner loop. In the second stage, the OSK applies this mask and skips more blocks under a tightened budget given online-softmax statistics. Across mainstream LLM backbones and long-context benchmarks, CoSA attains higher accuracy at lower budgets. Impressively, CoSA achieves a 4.93$\times$ attention speedup and reduces end-to-end Time-to-First-Token by 2.53$\times$ under a context length of 128K with negligible performance degradation.

  - **代理保真度随预算下降**：当稀疏预算收紧时，代理估计的掩码会遗漏真正显著的块，导致模型精度明显下降。
  - **内核只能机械应用掩码**：内核无法利用计算过程中获得的真实注意力统计来进一步修正稀疏决策，且无法改变块的访问顺序来优化跳过条件。
- **核心问题**：如何在更激进的稀疏预算下，同时保持高精度和高效率？论文指出，**代理与内核之间的脱节**是制约稀疏注意力精度-效率权衡的根本瓶颈。

## 2. 论文提出的方法论

### 2.1 核心思想：代理-内核协同设计（Proxy-Kernel Co-Design）

CoSA 提出两阶段免训练的稀疏注意力机制，核心理念是让代理和内核不再是孤立设计，而是通过一个**计算顺序掩码（computation-order mask）**作为桥梁相互塑造：

- **代理塑造内核**：KAP 不仅告诉内核哪些块要计算，还规定这些块的访问顺序。
- **内核塑造代理**：OSK 消费有序掩码，并利用在线 softmax 统计进一步跳过块，实现更低的稀疏预算。

### 2.2 内核感知代理（KAP）

KAP 在预计算阶段执行以下步骤：

1. **块排名**：
   - 对查询（Queries）和键（Keys）进行步幅下采样（stride-downsampling）。
   - 构建近似注意力分数：$$\hat{S} = \text{Softmax}(\tilde{Q}\tilde{K}^\top / \sqrt{d})$$
   - 对每个块的键进行 **MaxPool** 聚合，再对每个采样查询行进行 **Max 归一化**，形成块级别的估计分数 $$S^{KAP}_{ij}$$（对块内所有查询行求和）。
   - 同时生成 **HRM 标志（Have-RowMax flag）** $$H_{ij}$$，标记某查询块的行最大值是否落在对应的键块内。

2. **标志分组排序（Flag-grouped sorting）**：
   - 将候选键块按 HRM 标志分为两组，HRM 块优先。
   - 每组内部按估计分数降序排序，拼接形成访问顺序 $$\rho_i$$。
   - 这保证了含行最大值的块**最先被访问**，使在线 softmax 的运行最大值（running max）尽早收敛到全局最大值。

3. **第一阶段的 Top-p 块选择**：在中等预算下确定保留下来的块数量，生成有序掩码 $$M^{KAP}$$，明确记录每个块的访问排名。

### 2.3 有序跳跃内核（OSK）

OSK 是内核侧的协同设计，包含三个关键技术：

1. **物理页面跳跃（Physical page jumping）**：与传统逻辑掩码跳过不同，OSK 通过轻量级的 **KV 页表重映射（page-remapping）**直接跳到下一个保留的页，消除了掩码跳过块的循环控制和同步开销。
2. **内核内逻辑跳过（In-kernel logic skip）**：对于经过第一阶段过滤保留下来的块，OSK 利用真实的在线 softmax 统计，应用 BLASST 式跳过条件：
   $$\text{skip}(i,j) \iff \max_r \left(m^{\text{loc}}_{ij}[r] - m_{ij}[r]\right) < \ln \frac{\Delta}{N}$$
   即当某个键块的所有行都远低于当前运行最大值时，跳过该块的值侧计算。
3. **任意顺序页面访问（Any-order page visiting）**：由于在线 softmax 的计算结果与块的访问顺序无关（顺序不变性），OSK 可以按照 KAP 规定的顺序访问页——HRM 块先访问，让运行最大值提前逼近全局最大值，从而使后续块的内核跳过决策更安全、更激进。

### 2.4 算法流程概述

1. 第一阶段（KAP）：下采样 → 近似分数计算 → 块级 MaxPool/归一化 → 块分数与 HRM 标志 → 标志分组排序 → 生成有序掩码。
2. 第二阶段（OSK）：根据有序掩码重映射 KV 页面 → 逐个访问保留块 → 计算真实 QK 分数 → 更新运行最大值 → 根据阈值决定是否跳过值侧计算 → 更新输出。

## 8. 不足与局限

- **仅针对预填充（Prefilling）阶段**：论文明确将稀疏化限定在预填充阶段，解码阶段保持密集注意力。而长上下文推理的延迟瓶颈在长输出场景（如思维链、智能体推理）下同样存在于解码阶段，后续扩展到解码需要新的代理和内核设计。
- **对超参数 Δ（跳过阈值）有一定敏感性**：不同模型需要不同的 Δ 设置（Qwen 用 2000，Llama 用 200），Δ 的选择缺少自动化的校准方法，依赖于人工调参或经验判断。

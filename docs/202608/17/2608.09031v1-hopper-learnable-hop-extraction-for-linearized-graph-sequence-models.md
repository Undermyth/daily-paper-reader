## 摘要
图神经网络通常通过重复的消息传递层传播信息，将信息传播的距离与非线性变换的层数耦合在一起。这种耦合可能使深层架构难以优化，并导致过度平滑、过度挤压以及长程信息的丢失。线性化图序列模型（LGSM）通过将信息深度与处理深度分离，并将每个节点的连续传播状态视为序列来解决这一问题。然而，现有的LGSM使用固定的图算子构造这些序列，限制了其适应输入图、节点特征和下游任务的能力。我们提出了HOPPER，一种端到端可学习的LGSM扩展，它在现代状态空间模型处理之前学习如何提取跳序列。我们的框架支持特征条件、结构感知、图和跳自适应的传播机制，同时保持置换等变性。标准的基于邻接和非回溯的LGSM序列是我们所提出的提取器族的特例。我们展示了HOPPER在ECHO-Synth基准上达到了最先进或具有竞争力的性能，并且改变消息回溯取消的最大邻域大小（即结构记忆窗口）可以在基于物理的LRIM长程依赖基准上优化准确率。这些结果表明，可学习的序列提取为长程图表示学习提供了一种灵活且有效的方法。

## Abstract
Graph neural networks typically propagate information through repeated message-passing layers, coupling the distance over which information travels with the number of nonlinear transformations applied. This coupling can make deep architectures difficult to optimize and can lead to over-smoothing, over-squashing, and the loss of long-range information. Linearized Graph Sequence Models (LGSMs) address this issue by separating information depth from processing depth and treating the successive propagation states of each node as a sequence. However, existing LGSMs construct these sequences using fixed graph operators, limiting their ability to adapt propagation to the input graph, node features, and downstream task. We introduce HOPPER, an end-to-end learnable extension of LGSM that learns how hop sequences should be extracted before they are processed by a modern state-space model. Our framework supports feature-conditioned, structure-aware, graph- and hop-adaptive propagation mechanisms while preserving permutation equivariance. Standard adjacency-based and non-backtracking LGSM sequences arise as special cases of our proposed extractor family. We show that HOPPER is state-of-the-art or competitive across the ECHO-Synth benchmark, and that varying the maximum neighborhood size of message backtracking cancellation (i.e. structural memory window) can optimize accuracy on the LRIM physics-based long-range dependency benchmark. These results demonstrate that learnable sequence extraction provides a flexible and effective approach to long-range graph representation learning.

## 1. 核心问题与整体含义（研究动机与背景）

图神经网络（GNN）的标准消息传递范式存在一个根本性的结构缺陷：**信息深度与处理深度被强制耦合**。每一层消息传递同时完成两件事——将信息在图上多传播一跳、施加一次非线性变换。这意味着要让信息跨越 r 条边，至少需要 r 层网络，从而引发一系列问题：

- **过平滑（Over-smoothing）**：深层节点表征趋于一致，丧失判别力；
- **过挤压（Over-squashing）**：固定维度表征被迫压缩指数级增长邻域信息；
- **优化困难**：深层堆叠非线性变换导致梯度消失/爆炸。

**线性化图序列模型（LGSM）** 提供了部分解决方案：将每个节点在不同信息深度下的传播状态视为一个序列，交给现代状态空间模型（如 Mamba2）沿"深度轴"独立处理，从而解耦信息传播与非线形处理。**然而，现有 LGSM 的序列提取器是固定的**——例如使用邻接矩阵幂 `A_sym^l H` 或非回溯递归——这些固定算子无法根据输入图的结构、节点特征和下游任务自适应调整传播方式，可能为下游序列模型提供次优的跳序列。

**HOPPER 的目标**：将 LGSM 中固定的序列提取器替换为**端到端可学习的跳数提取器**，在保留 LGSM"信息深度与处理深度分离"核心优势的同时，使传播方式具备图自适应、跳自适应的能力，并严格保持置换等变性。

## 2. 方法论

### 2.1 核心思想

HOPPER 的总体架构为：

```
H = X·W_in → SEQ_θ(A,D) 学习跳序列 S∈R^{n×L×d}
→ N_blk 个 Mamba2 序列处理块 Φ_ω 逐节点处理
→ 任务相关读出 ρ → 预测 ŷ
```

其中 `SEQ_θ` 为可学习跳提取器，`Φ_ω` 对每个节点沿信息深度维度独立处理其序列。

### 2.2 四大关键技术

**① 线性结构状态递归（Linear Structural-State Recurrence）**

- 结构状态 `U(k)` 在整个递归中**不进行归一化、不施加非线性**，保持其为 H 的线性函数；
- 递归形式为（用 A、D、I 算子的 M 阶线性递归）：

```
U(k) = Σ_{j=1}^M [ α_A(k)[j]·A + α_D(k)[j]·D + α_I(k)[j]·I ] · U(k−j)
U(0) = H, U(i<0) = 0
```

**② 超网络条件化的系数生成（Hypernetwork-Conditioned Coefficients）**

- 先构造**置换不变的图摘要** `h_graph`：将节点特征与一跳邻居信息拼接 `H_str = [H | A_rw H]`，用 K 个可学习种子查询做交叉注意力聚合，得到固定维度 `h_graph ∈ R^{Kd}`；
- 将 hop 嵌入 `e_k` 与 `h_graph` 拼接，由 MLP 输出 `3M+1` 个标量系数 `[α_A, α_D, α_I, β_k]`；
- 由此实现**图自适应**（系数依赖图摘要）和**跳自适应**（系数依赖跳数）。

**③ 有限结构记忆窗口（Finite Memory Window M）**

- 递归只保留最近 M 个结构状态，限制"消息回溯取消"的邻域范围；
- M 是一个可调节的超参数，影响序列提取的性能。

**④ 输出侧特征注意力校正（Feature-Attention Correction）**

- 在递归之外，用原始节点特征计算注意力矩阵作为门控校正：

```
F_k = softmax(Q_k K_k^T / √d),  S(k) = LayerNorm( U(k) + β_k·F_k·U(k) )
```

- 注意力只作用于**输出状态 S(k)**，不引入递归内部非线性，从而保留多项式结构。

### 2.3 理论性质（核心定理）

| 定理 | 内容 |
|------|------|
| 4.1.1 | **置换等变性**：尽管系数依赖图摘要，HOPPER 对整个节点排列保持等变，图级预测保持置换不变 |
| 4.2.1 | **自适应多项式结构**：固定系数时，U(k) 是 A、D 的次数 ≤ k 的非交换多项式，且 `d_G(u,v) > k ⇒ [Γ(k)]_uv = 0`，即保留 k 跳局域性 |
| 4.3.1 | **经典方案包含性**：邻接传播、非回溯传播、Chebyshev 传播均可通过特定系数设定精确恢复为特例，且 Chebyshev 传播满足谱稳定性 `‖T_k(S)‖₂ ≤ 1` |
| 4.4.1 | **最优稳定长程敏感性**：在所有谱稳定度 ≤ r 的多项式传播器中，Chebyshev 多项式实现最大的首达灵敏度，比幂传播提升因子 `2^(r−1)`；正则图上差异随距离指数增长（q=2 时灵敏度从 `2^(−r)` 提升到常数 `1/2`） |

## 8. 缺点与局限性

1. **可学习传播系数的可解释性不足**：尽管论文证明了固定系数时 U(k) 是 A、D、I 的多项式，但**学习到的系数如何随图结构、跳数变化，缺乏可视化与量化分析**。读者无法得知在何种图上 HOPPER 学会了"类似 Chebyshev"的传播、在何种图上又退化为邻接幂传播，理论优雅性与实际行为的对应关系并未在实验中被验证。

2. **图摘要的置换不变性以牺牲信息为代价**：`h_graph` 通过交叉注意力将整图压成 K 个固定维度向量，虽然保证了置换等变/不变，但这一压缩过程可能丢失对任务关键的局部结构信息（如特定子图模式）。论文未对 K 的取值进行敏感性分析，也未与直接使用全局图池化的替代方案对比。

3. **输出侧特征注意力缺乏理论刻画**：虽然形式上给出 `S(k)=LayerNorm(U(k)+β_k·F_k·U(k))`，但**该非线性和注意力门控对多项式结构、局域性、置换等变的影响并未被纳入任何定理的假设或结论**。换言之，理论性质只对"提取器内部"成立，而实际送入 Mamba2 的状态已经过了额外非线性修正，理论−实践的缝隙没有被正面讨论。

4. **与 LGSM 的比较不够公平/深入**：HOPPER 声称改进 LGSM，但 LGSM 的序列提取器是固定的（邻接幂等），实验中两者的序列长度、隐藏维度、训练预算是否完全一致，论文未给出明确的消融控制说明；此外也没有报告"将 LGSM 的固定提取器换成可学习提取器"这一最小改动之外，其他架构差异（如特征注意力）带来的增量贡献。

5. **对 Mamba2 的依赖未经验证**：论文完全采用了 Mamba2 作为序列处理器，但未与 Transformer、线性注意力、S4 等其他序列模型在同一可学习提取器下对比。读者无法判断增益来自"可学习跳序列"还是"Mamba2 本身"。

6. **数值稳定性与可扩展性的隐忧**：论文承认 L>20 时必须改用归一化路径（Arw、I−D⁻¹）以保证数值稳定，这意味着**不同序列长度下模型实际定义的传播算子不同**，超参数 L 的选择不只是"截断深度"，还隐含着算子语义的切换，增加了方法的应用复杂度。

| **理论** | 序列级谱过平滑的刻画（4.4.2） | 首次在"传播序列"而非"单一表征"层面定义并分析谱信息保持，提供了可验证的避免过平滑机制 |
| **统一性** | 邻接、非回溯、Chebyshev 传播的递归实现 | 将三类经典传播算子纳入同一可学习框架，为传播算子设计提供了统一语言 |
| **实践** | 有限结构记忆窗口 M 的引入 | 将"消息回溯取消"范围作为可调超参数，在 LRIM-16 上实证了 M 的影响 |

## 10. 综合评价与适用场景

### 总体定位

HOPPER 是一篇**理论驱动、架构创新、实验聚焦**的研究工作。它的价值不在于某个数据集上的百分比提升，而在于为"图神经网络如何传播信息"这一问题提供了一个新的、可学习的、有理论保证的算子族，并成功继承了 LGSM 解耦信息深度与处理深度的范式优势。论文的写作结构清晰，定理—方法—实验三者对应关系明确，属于图学习领域质量较高的方法学贡献。

### 适用场景

- **长程结构推理任务**：直径预测、离心率、最短路径、能量回归等需要信息跨越 20+ 跳的场景是 HOPPER 的主战场；
- **大规模图**：由于提取器是稀疏传播（O(L·M·|E|·d)），且可沿节点维度并行，适合边数可控的大规模图；
- **需要置换等变保证的应用**：如分子、点云等无自然节点排序的数据。

### 不适用或待验证的场景

- **小直径图/短程任务**：当图直径很小（<5 跳）时，LGSM 与经典 MPNN 已足够，可学习提取器的复杂度收益不明显；
- **异质图/多关系图**：方法针对单一同质图定义，扩展到异质边类型需重新设计递归算子；
- **真实世界大规模基准**：尚未在 OGB、ZINC、QM9 等标准真实数据集上验证，泛化能力存疑。

### 后续研究方向（论文隐含的开放问题）

1. 将可学习递归提取器推广到异质图、时序图与多尺度图；
2. 用真实分子/社交网络数据验证方法，并探索与预训练的结合；
3. 对学习到的系数进行可解释性分析，建立"图结构 → 传播策略"的映射规律；
4. 将 Mamba2 替换为其他序列模型，解耦"传播提取"与"序列处理"两个创新点的各自贡献；
5. 理论层面将特征注意力校正也纳入统一的形式化框架，消除理论−实践缝隙。

## 一句话总结

**HOPPER 用一个超网络条件化的线性结构状态递归取代了 LGSM 的固定跳序列提取器，在严格保持置换等变与多项式局域性的同时，通过 Chebyshev 型稳定传播在理论上证明了其对长程信息敏感度的指数级增益，并在合成长程基准上取得了领先或极具竞争力的结果——它的问题在于实验场景局限、组件贡献未拆解，以及理论保证与最终输入序列模型之间的状态存在一段未完全弥合的间隙。**

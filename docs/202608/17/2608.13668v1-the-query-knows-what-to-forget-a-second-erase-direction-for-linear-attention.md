## 摘要
线性注意力保持一个固定大小的状态。在长上下文中，许多存储的项共享该状态，它们之间的干扰会降低检索质量。Gated DeltaNet-2（GDN-2）与之前所有的增量规则模型一样，其擦除向量来源于当前词元的键。然而，其读取中的干扰是通过查询来衡量的，而擦除步骤无法触及查询。我们引入了查询派生的擦除方向（QED）。QED 添加了第二个从查询派生且与键正交的擦除方向。在快速权重视角下，定向于键的增量编辑无法改变读取中键正交部分。它利用可编辑部分来消除沿查询测量的旧状态内容。它还能在每个超过训练窗口的长度上改善检索，并在 S-NIAH-1 上将可用上下文长度大约翻倍。

## Abstract
Linear attention keeps a state of fixed size. At long context, many stored items share this state, and interference between them degrades retrieval. Gated DeltaNet-2 (GDN-2), like every delta-rule model before it, derives its erase vector from the key of the current token. However, the interference in its reads is measured through the query, and the erase step cannot reach it. We introduce the Query-derived Erase Direction (QED). QED adds a second erase direction derived from the query and orthogonal to the key. In the fast-weight view, a key-directed delta edit cannot change the key-orthogonal part of a read. It uses the editable part to cancel old-state content measured along the query. It also improves retrieval at every length past the training window, and it about doubles the usable context length on S-NIAH-1.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：线性注意力将softmax注意力的序列长度相关缓存替换为固定大小的循环状态，从而在自回归解码中实现恒定内存和每token常数级的序列混合成本[2,5]。然而，这种高效性要求所有存储的关联共享同一个有界状态。
- **核心问题**：随着上下文增长，大量存储项共享固定大小的状态，相互之间的干扰会导致从循环线性模型中的检索质量下降[7,6]。所有delta规则模型（包括Gated DeltaNet-2）的擦除向量都来源于当前token的键，但读取中的干扰却是通过查询来衡量的——键派生的擦除向量无法直接修改查询可见状态中键正交的部分，这就形成了读取与编辑之间的不匹配。
- **整体含义**：该论文试图解决线性注意力在长上下文场景下的干扰问题，使模型能够更好地遗忘不再需要的旧状态内容，从而延长有效上下文长度。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
- 在快速权重视角下，一个定向于键的delta编辑无法改变读取中键正交部分的内容。
- QED为GDN-2中的擦除向量增加一个从查询派生的、与键正交的**第二个擦除方向**。
- 在标准键派生擦除向量旁，额外添加一个来自查询的校正项，使模型能够直接移除沿查询方向读取到的旧状态内容。

### 关键技术细节

**（1）基础架构回顾**

- **DeltaNet**：状态更新为 \(S_t = (I - β_t k_t k_t^T)S_{t-1} + β_t k_t v_t^T\)
- **Gated DeltaNet (GDN)**：加入标量衰减 α_t
- **KDA (Kimi Delta Attention)**：衰减变为逐通道向量
- **GDN-2**：分离擦除门 \(a_t = b_t \odot k_t\) 和写入门 \(w_t\)：
  \[
  S_t = (I - k_t a_t^T) \text{Diag}(\exp g_t) S_{t-1} + k_t (w_t \odot v_t)^T, \quad o_t = S_t^T q_t
  \]

**（2）QED核心公式**

修改后的擦除向量：
\[
a_t = b_t \odot k_t + \lambda_h P^\perp_{k_t}(b_t \odot q_t), \quad P^\perp_k(x) = x - k(k^T x)
\]

其中：
- \(\lambda_h \ge 0\)：每个头的可学习强度（设 \(\lambda_h = \lambda_{\max} \times \text{sigmoid}(\theta_h)\)，\(\lambda_{\max} = 0.25\)）
- 第二项是来自查询方向的擦除校正
- \(P^\perp_{k_t}\)：与键正交的投影，确保不改变 \(I - k_t a_t^T\) 的非平凡特征值

**（3）快速权重视角（在线学习视角）**

- 令 \(\bar S_t = \text{Diag}(\exp g_t)S_{t-1}\) 表示衰减后的状态。
- 标准GDN-2的更新为：
  \[
  S_t^{\text{GDN2}} = \bar S_t + k_t[w_t \odot v_t - \bar S_t^T(b_t \odot k_t)]^T
  \]
- 关键观察到：对任何与键正交的探针x，delta编辑无法改变其响应：
  \[
  (S_t^{\text{GDN2}})^T x - \bar S_t^T x = (x^T k_t)[w_t \odot v_t - \bar S_t^T(b_t \odot k_t)]
  \]
- 将查询分解为 \(q_t = \rho_t k_t + q_t^\perp\)（其中 \(\rho_t = q_t^T k_t\)），读出为：
  \[
  o_t^{\text{QED}} = o_t^{\text{GDN2}} - \lambda_h \rho_t \bar S_t^T d_t, \quad d_t = P^\perp_{k_t}(b_t \odot q_t)
  \]
- 该校正采样键正交方向上的旧状态，沿键写入负采样，再通过键-查询重叠到达查询。

**（4）稳定性与成本**

- 保持秩一更新结构，非平凡特征值与GDN-2相同。
- 额外计算仅为一个点积和一次减法（每token每头）。
- 门控防止每次读取都擦除内容；正交投影保持特征值稳定。

## 6. 论文的主要结论与发现

1. **QED显著提升长上下文检索**：在两个随机种子下，QED在训练窗口外的一切评估长度上都优于GDN-2基线。在S-NIAH-1上，QED将可用上下文长度大约翻倍（从约8K扩展到约16K）。
2. **最一致的消融结论**：使用查询作为擦除方向是稳定有益的——QED在两种种子下在所有外推长度上均优于QED-rand随机方向控制。
3. **门控和正交投影的贡献尚不确定**：这两个组件的消融效果在种子间不一致，论文承认未确立其必要性。
4. **语言建模质量不受影响**：验证损失无明显变化（全部10次运行跨度仅为0.0034 nats），SQuAD-completion也无明显变化。
5. **FDA文档回忆提升**：所有包含投影的臂在FDA上均超过基线（种子0提升3.4点，种子1提升3.7点）。
6. **投影在实际训练中几乎不提供额外约束**：特征值分析表明，在观察到的训练状态下，无投影校正已经与键具有极低的对齐（特征值变化小于10⁻³），投影在当前规模下是安全保护而非关键约束。

## 7. 优点：方法与实验设计亮点

- **方法新颖且简洁**：从读取侧（查询）而非仅从写入侧（键）导出擦除方向，针对长期被忽视的“读取-编辑不匹配”问题，切入点清晰、有解释力。
- **保持秩一更新与稳定性**：通过正交投影确保不影响非平凡特征值，保持了GDN-2的架构优势，额外计算成本几乎为零。

- **实验设计有对照意识**：设计了QED-rand作为方向控制，能直接回答“查询方向是否必要”这一核心问题。

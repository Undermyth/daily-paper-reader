## 摘要
KV缓存压缩通常以具有少数大权重的注意力图为依据。但这并不完整：大权重未必包含大部分概率质量，被省略的值可能相互抵消，而且保持注意力输出未必能保持任务性能。我们将这些问题区分开来。全局分数差距——而非阈值计数——决定了保留目标质量所需的token数量。对于一个实际行，被省略值的加权和正是缺失的精确统计量。一个受控的检索-聚合模型解释了截断何时有益，何时有害。这些结果促使了CertKV，一种无需训练的压缩器，它为每个注意力头保留一个尾部摘要槽，并根据值的离散度分配其余槽位。在匹配的预算下，CertKV在LongBench-v2的九个设置中有七个进入前二名，在128K RULER上保持领先的压缩层级，并在一个打包的Llama原型中实现了十倍的缓存预算。可压缩性取决于概率质量、值、未来查询和任务——而不仅仅取决于看似稀疏的图。

## Abstract
KV-cache compression is often justified by attention maps with a few large weights. This is incomplete: large weights may not contain most of the mass, omitted values can cancel, and preserving the attention output may not preserve the task. We separate these questions. Global score gaps -- not threshold counts -- determine how many tokens are needed to retain a target mass. For a realized row, the weighted sum of omitted values is the exact missing statistic. A controlled retrieval--aggregation model explains when truncation helps and when it hurts. These results motivate CertKV, a training-free compressor that reserves one tail-summary slot per head and allocates the rest by value dispersion. Under matched budgets, CertKV is top-two in seven of nine LongBench-v2 settings, remains in the leading compressed tier on 128K RULER, and realizes a ten-fold cache budget in a packed Llama prototype. Compressibility depends on the mass, values, future queries, and task -- not on a sparse-looking map alone.

## 1. 论文的核心问题与整体含义

**核心问题**：KV缓存压缩通常以“注意力图存在少数大权重”作为理论依据，但该论文指出这一论证链条不完整。具体而言，它区分了四个在文献中常被混淆的对象：

- **计数稀疏性**：一行中超过某个绝对阈值的注意力权重个数很小；
- **覆盖率稀疏性**：为达到目标概率质量（如 90%）需要保留的 token 数很少；
- **输出保真度**：截断后的注意力输出仍能还原完整注意力输出；
- **任务实用性**：保持的注意力输出能完成下游任务（检索、聚合等）。

论文证明，在没有额外假设的情况下，三个蕴含关系均不成立：

> 计数稀疏性 ≠> 覆盖率稀疏性 ≠> 输出保真度 ≠> 任务实用性

**整体含义**：注意力可压缩性不是注意力热力图的标量属性，而是由**分数几何、值几何、未来查询分布和任务目标**共同决定的“契约”（contract）。这一结论推翻了简单“稀疏即压缩”的设计直觉，为 KV 缓存压缩提供了更严谨的理论框架，并在此框架上提出了一个新的无训练压缩器 CertKV。

## 2. 论文提出的方法论

### 2.1 三个理论分离

#### （1）定理 3.6：全局分数差距包络决定覆盖率（计数 ≠> 覆盖率）

对于排序后的 logits，定义差距剖面 \( G(j) = \ell_{(1)} - \ell_{(j)} \)。

- 若存在 **全局下包络** \( G(j) \ge \gamma \log j - b \)，且 \( \gamma > 1 \)，则目标质量覆盖率所需的 token 数是**与上下文长度 n 无关的常数**（p-series 可和性）；
- 若存在 **全局上包络** \( G(j) \le \gamma' \log j + b' \)，且 \( 0 \le \gamma' < 1 \)，则所需 token 数**随上下文长度多项式增长**；
- 边界 \( \gamma = 1 \) 的行为取决于更低阶结构。

经典例子：独立同分布高斯 logits 在 \( \sigma = 1, \eta = 0.1 \) 时，渐近保留分数约 0.61——只有 1.6× 压缩率，尽管其大权重计数是 \( O(\log n) \) 的。大权重计数小 ≠ 覆盖率压缩率高。

#### （2）定理 3.7：定点行尾部分解（覆盖率 ≠> 输出保真度）

对保留集 S 和省略集 T：

\[
O = p_S \tilde{O}_S + (1 - p_S) \bar{V}_T
\]

其中被省略值的加权和 \( u^* = \sum_{j \in T} A_j V_j = (1-p_S)\bar{V}_T \) 是唯一的加法校正项。覆盖率只控制标量 \( p_S \)，无法说明被省略的值是抵消、增强还是与保留集方向一致。在更强的线性草图要求下，保留值加上一个尾部聚合达到匹配的 \((|S|+1)d\) 维度下界（定理 C.2）。

#### （3）定理 3.8：任务相关效用（输出保真度 ≠> 任务实用性）

在植入 token 模型中（一个信号 token + 大量噪声 token），当信号 token 进入 top-k 但尚未主导完整 softmax 时，**重归一化 top-k 可以抑制散乱的质量主体**，在检索类任务中优于精确注意力；而精确注意力在聚合类任务中仍占优。两者在 \( \alpha^* = (w_e + w_s)/2 \) 处交换排序。

### 2.2 CertKV 压缩器

- **核心思想**：利用定点分解原理，把被省略尾部的关键信息保留下来。
- **尾部摘要**：每个 KV head 预留一个合成 KV 槽位（synthetic KV pair），存储被逐出 token 的按重要性加权的 key/value 质心。
- **分配策略**：根据每个 head 的值离散度（centered dispersion）\( c_h(b) = m_h(b) \sqrt{E_{j\sim r_h(b)}[\|v_{h,j} - v^*_h(b)\|^2]} \) 分配实时 token 槽位数。
- **精确预算**：总槽位数（实时 token + 合成槽）严格遵守物理缓存预算约束 \( B_{\text{real}} = B_{\text{live}} - H \)，使用拉格朗日加确定性最佳边际修复实现。
- **分数来源**：复用 SnapKV 的 observation window 打分。

## 6. 论文的主要结论与发现

1. **计数稀疏性不是覆盖率预算**：实测注意力剖面显示，大权重计数随长度亚线性增长（96%–99.9% 的 head），但短上下文拟合的覆盖率剖面无法预测 128K 实际预算（误差 >1.5×）。
2. **覆盖率不等于输出保真度**：定点尾部聚合是唯一能精确重建完整输出的加性统计量；其他替代（随机、协方差匹配、跨文档混洗）均比不保留任何额外统计量更差。
3. **输出保真度不等于任务实用性**：受控实验验证了定理 3.8 的预测——在 \( \alpha^* = 0.50 \) 处精确注意力（聚合胜）与 top-k（检索胜）交换顺序；但真实任务无法用单一坐标预测方法排序。
4. **CertKV 是有效的实际压缩器**：在匹配预算下与领先方法竞争（LongBench-v2 七个前二、RULER 128K 领先层级），并能实现 10× 物理缓存减量。
5. **可压缩性的完整判据**：注意力可压缩性取决于概率质量、值几何、未来查询分布和任务目标——稀疏图只是线索，不是证书。

## 8. 不足与局限

**理论局限：**
1. **固定行结果不直接适用于未来查询**：定理 3.7 的精确性仅对实现行成立；未来查询保证（定理 C.1）需要被逐出的 key 进行后验计算，无法在逐出前操作化。
2. **缺乏多层传播定理**：作者自认仍缺少将行级省略质量/值离散误差通过 transformer 块传播的多层稳定性定理（6.2 节开放问题）。
3. **定理 3.8 依赖保留主体弥散性（diffuseness）假设**：该假设不是由 rank inclusion 蕴涵的，在部署时需要逐头验证。

**实验局限：**
1. **不确定性宽**：RULER 128K 的任务自举半宽达 ±18 点，无法支撑强方法的排序结论。
2. **消融功效有限**：单因素消融中组件替换的点估计差异很小，无法检测细微但真实的性能变化。
3. **从零训练实验尺度小**：仅验证了 3–4M 参数 byte-LM，不能外推到数十亿参数的 LLM。
4. **跨模态检查不通过**：视觉/音频编码器未呈现语言模型中观察到的双峰结构，说明注意力剖面结构可能是语言模型特有的，而非通用现象。

**应用局限：**
1. CertKV 的尾部摘要槽是否真正优于将同一槽位分配给一个真实 token，取决于具体场景（表 5 显示在定点重建任务中尾部摘要反而略差）。
2. 论文没有报告延迟（latency）优势；物理内存降低不等同于端到端推理加速。
3. “Cert” 仅指精确槽位核算，不构成无条件未来查询保证，用户在实际部署时需注意这一边界。

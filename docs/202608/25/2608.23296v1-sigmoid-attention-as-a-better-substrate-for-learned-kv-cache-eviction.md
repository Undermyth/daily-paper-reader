## 摘要
学习型KV缓存驱逐常常面临软到硬的失配：在训练期间，可微分的门控通常衰减token贡献，而推理仅在KV条目被物理移除时节省内存。我们探究注意力基底是否影响这种软到硬的过渡。使用在OpenWebText上训练的GPT-2规模Transformer，我们对注意力类型、学习门控和位置编码进行了受控的2×2×2比较。尽管sigmoid注意力作为密集语言模型时表现更差，但学习型硬驱逐改变了有用的操作点：相对于其自身的无驱逐参考，sigmoid门控模型删除KV条目时困惑度变化可忽略。在相同密集骨干上的匹配实时缓存协议下，学习型sigmoid门控获得的困惑度低于我们实现的H₂O和KeyDiff，而softmax门控并不均匀优于这些事后方法。结果表明，注意力归一化可以显著影响训练时软门控是否干净地迁移到硬KV删除。

## Abstract
Learned KV-cache eviction often faces a soft-to-hard mismatch: during training, differentiable gates typically attenuate token contributions, whereas inference saves memory only when KV entries are physically removed. We ask whether the attention substrate affects this soft-to-hard transition. Using GPT-2-scale Transformers trained on OpenWebText, we run a controlled $2\times2\times2$ comparison over attention type, learned gating, and positional encoding. Although sigmoid attention is worse as a dense language model, learned hard eviction changes the useful operating points: sigmoid-gated models delete KV entries with negligible PPL change relative to their own no-eviction references. Under a matched live-cache protocol on the same dense backbones, learned sigmoid gates obtain lower PPL than our H$_2$O and KeyDiff implementations, whereas softmax gates do not uniformly beat these post-hoc methods. The results suggest that attention normalization can substantially affect whether a training-time soft gate transfers cleanly to hard KV deletion.

- **软到硬失配问题**：学习型KV缓存驱逐存在根本性矛盾——训练时模型只能通过可微分的软门控*衰减*（attenuate）token对注意力输出的贡献；而推理时只有*物理删除*（physically remove）KV条目才能真正释放内存。一个可用的学习型驱逐策略必须具有**阈值稳定性**（threshold-stable），即在某个阈值τ下用硬删除替换软衰减，不应带来明显的预测质量损失。
- **既往研究未触及的问题**：大多数KV缓存压缩工作（如H₂O、KeyDiff等后处理方法）把注意力基底视为固定因素，专注于设计更聪明的驱逐策略，但没有人系统性回答一个前置问题：**注意力归一化方式本身是否会影响软门控到硬删除这一过渡的可学习性？**

- **整体含义**：KV驱逐不应仅被视为推理时的启发式工程问题，而应被视为**注意力机制与KV保留策略的联合架构协同设计**（co-design）问题。

### 2. 方法论：核心思想、技术细节与公式

#### 2.1 核心思想
论文采用**因子化实验设计**，在保持模型架构、训练数据、训练配置完全一致的条件下，系统操纵三个二元因素，以隔离注意力归一化方式对学习型KV驱逐可学性的因果影响。

#### 2.2 2×2×2 因子设计
| 因素 | 取值 | 说明 |
|------|------|------|
| 注意力类型 | softmax / sigmoid | 核心操纵变量 |
| 门控 | 稠密（无门控）/ 学习型门控 | 是否有可学习的软保留信号 |
| 位置编码 | RoPE / NoPE | RoPE旋转是否应用于Q/K |

共 8 个模型，全部共享 GPT-2 规模架构（12层、12头、d_model=768、d_ff=3072、上下文长度512）。

#### 2.3 注意力变体
- 所有变体先应用**逐头QK-RMSNorm**：$\tilde{q}_i = \text{RMSNorm}(q_i)$, $\tilde{k}_j = \text{RMSNorm}(k_j)$。
- **Softmax注意力**：$A_{ij} = \text{softmax}_j(\bar{q}_i^\top \bar{k}_j / \sqrt{d_h})$。
- **Sigmoid注意力**：$A_{ij} = \sigma(\bar{q}_i^\top \bar{k}_j / \sqrt{d_h} + b(i))$，其中 $b(i) = -\log(i+1)$。该逐查询位置的负偏置用于稳定sigmoid注意力在不同位置上的期望行质量（因因果注意力位置i只看到i+1个key）；该偏置在softmax下是数学上的无效操作（被归一化抵消），但在sigmoid下起到关键稳定作用。

#### 2.4 学习型门控机制
- 每个非最后层 $\ell < L-1$ 产生逐token门控信号：$g_j^{(\ell)} = \sigma(w_\ell^\top x_j^{(\ell)} + b_\ell) \in (0,1)$。
- **双通道注入**（对两种注意力类型使用同一规则）：
  - 注意力logits通道：$z_{ij}^{(\ell+1)} \leftarrow z_{ij}^{(\ell+1)} + \log(g_j^{(\ell)} + \varepsilon)$
  - 值向量通道：$v_j^{(\ell+1)} \leftarrow g_j^{(\ell)} v_j^{(\ell+1)}$
- 双通道设计是对硬删除的**可微模拟**：当 g→0 时，两个通道共同将token j的贡献驱向零，与硬删除的极限行为一致。
- 门控初始化为 $w_\ell=0, b_\ell=5$，即 $g=\sigma(5)\approx0.993$，使早期训练接近无门控模型。
- **推理时硬驱逐**：以阈值τ对门控值做硬判决，删除 g_j < τ 的KV条目；保留的条目仍然使用学习到的logit和值缩放。

#### 2.5 训练目标
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda \bar{g}, \quad \bar{g} = \frac{1}{(L-1)T} \sum_{\ell=0}^{L-2} \sum_{j=1}^{T} g_j^{(\ell)}$$
- 交叉熵 + 平均预算项（λ=0.03），预算项将门控拉向小值，鼓励稀疏保留。

- **数据集**：
  - 训练：OpenWebText 1B-token 训练子集，3个epoch（约3B token曝光）
  - 验证：100K tokens（用于阈值选择）

- **测试协议**：每个序列拆分为 384-token prefix（预填充）+ 128-token decode窗口；PPL在decode窗口上计算。
- **阈值选择**：在15点验证集阈值网格上扫描，选择满足 ΔPPL < 0.1（相对该门控模型τ=0参考）的最高压缩率对应的 τ*，冻结后用于测试。
- **对比方法**：
  - **H₂O（Heavy-Hitter Oracle）**：累积注意力分数保留"重击者"token + 近期token，在对应稠密骨干上运行，匹配相同最终实时缓存大小。

### 6. 主要结论与发现

1. **稠密基线**：softmax注意力在稠密无驱逐情况下明显更强（RoPE下PPL低0.361，NoPE下低1.205），sigmoid不是更好的语言模型基底。
2. **主要结果（基底特异性）**：同样的简单软到硬学习规则，在softmax下较弱，在sigmoid下变得有用：
   - **Sig+G RoPE**：删除19.8%的KV条目，PPL从22.440略微改善至22.424，且低于匹配缓存大小的H₂O（22.480）和KeyDiff（22.474）。
   - **Sig+G NoPE**：删除32.2%的KV条目，PPL仅小幅增加（24.637 vs 24.603），明显优于H₂O（25.107）和KeyDiff（25.786）。
   - **softmax门控模型**：在匹配缓存下均不如H₂O。
3. **不是任意的删除鲁棒性**：随机删除K/V支撑时，sigmoid注意力的输出扰动反而更大（50%删除率下相对扰动3.666 vs 1.131），优势出现在**学习型删除模式**下。
4. **机制解释（行和自由度）**：softmax每行归一化到1，抑制一个token会强制将注意力质量重新分配给该行其他token；sigmoid无此约束，行质量可随查询、层、序列变化，软门控能实现对被门控token的局部衰减而不强制行重归一化——这使得训练时的软操作更接近硬删除。
5. **门控形成可阈值化的结构**：sigmoid门控形成近二值结构（尤其Sig+G NoPE二值化率达43.3%），但二值化本身不充分（SM+G RoPE二值化率更高但迁移更差），需要与行和自由度共同作用。
6. **Token选择性驱逐**：所有门控模型一致地赋予停用词和换行符低门控值（倾向删除），赋予空白符最高门控值（倾向保留）；sigmoid模型在各类别上赋予更高门控值，优势来自硬阈值化后形成更有用的保留/删除划分。

### 7. 优点

- **回答了一个未被直接研究过的关键问题**：将注意力基底本身作为操纵变量，而非仅关注驱逐策略设计。
- **严格的受控设计**：2×2×2全因子实验，所有模型共享同规模、同数据、同配置，因果可归因性强。
- **公平的后处理对比协议**：匹配最终实时缓存大小运行后处理方法，直接控制内存这一部署关键变量，且后处理方法在对应稠密骨干上运行，隔离了门控与注意力类型的影响。
- **排除替代解释**：通过随机删除探针排除了"sigmoid只是更鲁棒"的平庸解释；通过token选择性分析排除了"门控只是均匀压缩"的解释。
- **机制分析层层递进**：从行为层面（PPL）→ 表征层面（随机删除扰动）→ 结构层面（行和CV与二值化）→ 语义层面（token类别），形成了完整的因果链条。
- **审慎的结论表述**：不将Sig+G RoPE的负ΔPPL过度解读为语言建模增益，而视为选择性缓存去噪；明确声明结果不构成端到端推理速度声明。

### 8. 不足与局限

- **算力细节缺失**：未报告GPU型号、数量和训练时长，无法评估实验成本与可复现性中的资源需求。
- **规模与泛化性有限**：仅123M参数、上下文512 tokens、单一种子、单数据分布（OpenWebText），能否推广到更大规模模型、更长上下文仍是开放问题。
- **上下文过短**：512 token的上下文远低于现代LLM的实际部署长度（通常数千至数万token），KV驱逐在长上下文场景下的行为可能有本质差异。
- **未测试下游任务**：仅报告PPL和压缩率，未验证在长上下文基准（如RULER、LongBench等）上的端到端表现。
- **门控设计缺乏消融**：未分离logits通道与values通道的独立贡献，未测试不同λ值、逐头门控、逐层阈值等替代设计，无法确认sigmoid优势在何种门控参数化下依然成立。
- **后处理基线未充分调优**：H₂O的heavy-hitter/recent比例固定为1:1，未在验证集上调优；作为"SOTA基准"参考而非全面优化的基线对比，结论力度有限。
- **未实现推理加速内核**：没有为门控sigmoid注意力路径实现生产级融合内核（如FlashAttention风格的实现），因此结果仅说明缓存质量与可学性，不构成端到端推理速度声明。
- **阈值选择规则的武断性**：ΔPPL < 0.1的截止值是一个设计选择，更细的阈值网格或不同操作准则（如匹配PPL而非匹配缓存大小）可能选出不同的操作点。

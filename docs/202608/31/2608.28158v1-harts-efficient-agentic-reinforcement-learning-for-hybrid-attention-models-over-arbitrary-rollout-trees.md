## 摘要
智能体强化学习（RL）常常产生具有共享历史的非规则展开树。独立训练从根到叶的轨迹会重复计算这些共享前缀。现有系统主要面向全注意力模型，缺乏与激活重计算兼容的稠密、可微分的混合注意力执行。我们提出了 HARTS（基于树结构的混合注意力强化学习）。HARTS 联合规划微批次、数据并行（DP）副本分配以及微批次时隙调度，利用前缀压缩后的非重放紧凑令牌工作。对于分块线性注意力，一种线性时间算法协调块边界状态恢复与重放，并在我们的打包执行模型下产生最少数量的顺序线性注意力调用。HARTS 保留了逐轨迹训练的分块状态分区：它不重复投影、MLP/MoE 计算或最终输出，仅执行有界状态重放以实现数值对齐。每轮中，HARTS 将所有分支批处理为一个打包调用，通过可微分的状态交接传播梯度，支持激活重计算，并恢复每个令牌的对数概率。对于确定性的、无令牌丢弃的 top-$k$ MoE 路由，语义多重性恢复了 MoE 目标的令牌权重和负载统计。现有的 RL 目标保留其接口。据我们所知，HARTS 是首个在真实混合注意力模型上展示任意展开树前缀共享加速的系统。在由 SWE-bench 任务生成的智能体 RL 工作负载上，HARTS 在多种并行配置下通过激活重计算实现了 $4.81$--$4.87\times$ 的前向/后向/梯度加速。其数值差异与基线自我重运行的变异性相当，并且在 $\tau^3$-Bench 训练的前 120 步中，其奖励趋势与基线相似。

## Abstract
Agentic reinforcement learning (RL) often produces irregular rollout trees with shared histories. Training root-to-leaf trajectories independently recomputes these shared prefixes. Existing systems primarily target full-attention models and lack dense, differentiable hybrid-attention execution compatible with activation recomputation. We present HARTS (Hybrid-Attention RL over Tree Structures). HARTS jointly plans microbatches, data-parallel (DP) replica assignments, and microbatch-slot schedules using non-replay compact-token work after prefix compression. For chunkwise linear attention, a linear-time algorithm coordinates chunk-boundary state recovery and replay and produces the minimum number of sequential linear-attention calls under our packed execution model. HARTS preserves the chunkwise state partitioning of trajectory-wise training: it does not repeat projections, MLP/MoE computation, or final outputs, and performs only bounded state replay for numerical alignment. Per round, HARTS batches all branches into one packed call, propagates gradients through differentiable state handoffs, supports activation recomputation, and restores per-token log-probabilities. For deterministic, no-token-drop top-$k$ MoE routing, semantic multiplicities restore MoE-objective token weights and load statistics. Existing RL objectives retain their interface. To our knowledge, HARTS is the first system to demonstrate arbitrary-rollout-tree prefix-sharing speedups on a real hybrid-attention model. On an Agentic RL workload generated from SWE-bench tasks, HARTS achieves $4.81$--$4.87\times$ forward/backward/gradient speedup with activation recomputation across multiple parallel configurations. Its numerical differences are comparable to baseline self-rerun variation, and its reward trend is similar to the baseline over the first 120 steps of $τ^3$-Bench training.

## 1. 论文的核心问题与整体含义

- **研究背景**：智能体强化学习（Agentic RL）中，智能体通过多轮交互、工具调用和并行探索产生训练数据，采样结果往往不是独立的线性序列，而是具有不规则深度、扇出和分叉位置的**展开树（rollout tree）**。每条根到叶的路径都是训练轨迹，多条轨迹会共享任务描述、环境状态和早期交互历史。
- **核心问题**：传统逐轨迹训练（trajectory-wise training）对每条根到叶轨迹独立展开执行，导致共享前缀的前向和反向计算被重复执行。论文测得的实际工作负载中，逐轨迹展开包含的非重放 token 行约为紧凑执行的 **5.63 倍**，共享前缀冗余是主要训练开销。
- **现有方案的不足**：
  - **Tree Training**：主要面向全注意力模型，其线性注意力/GDN 路径在树节点粒度执行，产生大量小碎片调用；其严格零冗余分区与主流激活重计算（activation recomputation）冲突；且缺乏真实混合注意力模型的训练实验和并行训练支持。
  - **AReaL-DTA**：仅面向标准全注意力 Transformer，仅支持数据并行（DP），不提供混合注意力模型的稠密执行。
  - **核心难点**：混合注意力模型包含全注意力层和分块线性注意力层（如 KDA），全注意力树的掩码无法满足分块线性注意力的状态恢复与执行约束。分叉通常不落在固定块边界上，需要状态恢复、调用规划、可微分性和计算密度等多重问题的联合求解。
- **论文意义**：HARTS 是**首个**在真实混合注意力模型上展示任意展开树前缀共享加速的系统，为 Agentic RL 训练效率提升提供了系统级解决方案。

## 2. 论文提出的方法论

### 2.1 核心思想

HARTS 的核心思想是：在包含全注意力层（MLA）与分块线性注意力层（KDA）的混合注意力模型上，通过**前缀压缩 + 紧凑令牌（compact token）表示 + 最小化顺序线性注意力调用**，实现共享前缀只计算一次，同时保持数值对齐（分块状态分区一致）、可微分性和激活重计算兼容性。

### 2.2 关键技术细节

1. **紧凑令牌模型（Compact Token Model）**：
   - 维护映射$m: \mathcal{S} \to \mathcal{C}$，将语义位置（semantic position）映射到紧凑令牌行。共享相同 token 前缀的语义位置共享同一个紧凑行。
   - 紧凑令牌行存储唯一的隐藏状态、logits 等，但保留每个语义位置的训练目标（不同的 next-token label、优势值、损失权重等）。

2. **前缀感知微批次规划（Prefix-Aware Microbatch Planning）**：
   - 联合优化微批次划分、DP 副本分配和微批次时隙调度。
   - **目标函数**（字典序）：
     - 总紧凑令牌工作量$\sum w(M)$
     - 各时隙的 slot-critical 工作量（最重副本的负载）$\sum_j \max_d w(M_{d,j})$
     - 每个副本的累积工作最大值$\max_d \sum_j w(M_{d,j})$
   - **自然划分**：递归地在相邻 LCP 极小值处拆分超容量区间。
   - **精确搜索**（小输入 $N \le 512$）：基于动态规划公式$F[k,e] = \min_{s} \{F[k-1,s] + W(s+1,e)\}$寻找最优连续划分。
   - **启发式搜索**（大输入 $N > 512$）：采样 K 值 + 合并/分裂演化 + trie-aware 贪心放置（best-fit 与 max-shared 两种策略 × 四种处理顺序）。
   - **局部细化（Local Refinement）**：边界移动和稀疏修复（非连续成员更新），进一步降低紧凑工作量。
   - 通过 lexicographic 比较选出最终规划，保证可行性（容量约束、$K \bmod D = 0$、精确覆盖）。

3. **最小调用规划（Minimum-Call Planning）**（§3.3，核心创新之一）：
   - 将 rollout 树按无内部分叉的极大连续段（segment）压缩为段树。
   - 关键概念：当分叉落在块内时，侧分支从最近的块边界状态 $S_{a(p)}$ 恢复，重放（replay）少于一个块的祖先状态更新。
   - **两种最小调用计数**：$T^{pre}(v)$（入口状态在调用前可用）和 $T^{in}(v)$（入口状态在当前调用内传播）。
   - **核心递推**：
     - 叶子段：$T^{pre}(v) = T^{in}(v) = 1$
     - 内部段：$T^{in}(v) = \min_o \max(T^{in}(o), 1 + \max_{u \neq o} T^{pre}(u))$
     - $T^{pre}(v)$ 取决于出口位置是否跨越块边界：若 $e_v < a_v + B$ 则所有孩子可在同轮启动；否则退化为 $T^{in}(v)$。
   - 复杂度 $O(|V|+|E|)$，恢复过程（Recovery）构造实际执行计划。
   - 每轮中所有独立序列被打包为**一次** varlen 线性注意力调用，最小化顺序调用深度。

4. **混合注意力执行（Hybrid-Attention Execution）**：
   - **可微分状态交接**：扩展 ChunkLA 接口，可选地返回请求的块边界状态，后续序列以这些状态为初始状态，反向传播时梯度通过该状态流向生产者。
   - **全注意力（MLA）执行**：紧凑 token 的投影和 RoPE 只算一次，构造非对称 Q/KV 视图——Q 只含当前分支的 ℓ 个 token，KV 包含 ℎ 个祖先 + ℓ 个当前 token，使用 bottom-right 因果对齐，以实现正确的祖先可见性。
   - **KDA 执行**：直接消费按执行轮组织的物理排序，每轮一个打包调用；因果卷积通过临时预置真实祖先上下文、segmented identifiers 防止跨序列污染，且不重复执行卷积。
   - **激活重计算兼容**：所有边界状态在单个微批次的单层前向中产生和消费，不跨微批次保留父图；重计算时从固定规划重新物化，无需重新规划。

5. **RL 与 MoE 语义恢复**（§3.5）：
   - **紧凑到语义的 log-probability 计算**：每个紧凑 logit 行只做一次词表级 row-max 和 sum-exp，然后按语义位置逐行读取目标 logit，复杂度 $O(CV + S)$，不展开 $S \times V$ 的张量。
   - **梯度累积**：多个语义位置对同一紧凑行的梯度贡献自动求和。
   - **MoE 语义多重性**：$q_c = |\{s \in \mathcal{S} : m(s) = c\}|$，用 $q_c$ 加权 router z-loss、负载均衡辅助损失和 expert-bias 更新，但路由决策和专家计算保持紧凑。

## 6. 论文的主要结论与发现

1. **规划质量**：HARTS 在 10 个 rollout-tree 批次上全部优于 OR-Tools 基线，紧凑 token 总缩减 3.28%（80,213,867 → 77,581,958），规划时间加速 7.24–9.73 倍；同时提升了 slot 内和当前步累积两种 DP 工作平衡（如 P95 imbalance 从 OR-Tools 的 34.64% 降至 2.14%）。
2. **端到端效率**：5.62–5.63 倍的非重放紧凑行压缩率转化为：
   - **4.81–4.87× F/B/Grad 加速**
   - **4.39–4.63× Core 加速**（含规划时间）
   - 不同并行配置下加速比保持稳定。
3. **数值保真度**：HARTS Replay 在**所有** handoff 深度（d=0 至 d=5）均与基线自 rerun 噪声接近；No-replay 在 d=4–5 处超出基线噪声 32.4%–36.1%（SymKL）和 17.0%–18.7%（|ΔNLL|）——证明块边界状态恢复是必须的。
4. **全模型 logit 相似性**：平均 token 级词表 logit cosine > 0.9997（有/无重计算均成立），绝对损失差异 < $10^{-8}$。
5. **学习趋势**：前 120 步 $\tau^3$-Bench 在线训练中，HARTS 与基线的奖励曲线趋势和波动范围相似。

## 7. 优点

1. **首次系统性解决混合注意力模型上的 rollout-tree 前缀共享问题**：同时处理了 MLA（全注意力）和 KDA（分块线性注意力）两种注意力路径的差异化依赖。
2. **具有理论保证的最小调用规划**：在给定执行模型约束下，线性时间算法产生**最小可能**的顺序线性注意力调用次数，且不重复投影、MLP/MoE、最终输出。
3. **可微分与激活重计算兼容**：边界状态交接的梯度路径清晰，且规划固定、前向图不跨微批次保留，与标准全层激活重计算完美兼容（这一点优于 Tree Training 的零冗余分区设计）。
4. **不破坏 RL/MoE 语义的紧凑计算**：mapped log-probability 直接从紧凑 logit 行恢复原始顺序的 per-token log-prob，MoE 语义多重性恢复 router losses 与 expert-bias 权重，全程无需展开 $S \times V$ 张量。
5. **实验设计细致**：将重放消融按 handoff 深度分层分析、将压缩率与实测加速比分离解释、同时覆盖效率与数值保真度两个维度。
6. **良好的并行兼容性**：与 DP/TP/SP/PP/EP/CP 多种并行方式协同工作，不因 CP（DeepSpeed-Ulysses）注意力实现而受影响。

## 8. 不足与局限

1. **实验规模受限**：模型为 Ling-3.0-tiny（24 层，1536 隐藏维，8 张 H20 GPU），未在更大规模模型和更多 GPU 上验证。论文推测更大模型收益更明显，但这是推论而非实验证据。
2. **在线 RL 验证较浅**：仅 120 步 $\tau^3$-Bench 训练和单次运行，未报告多次种子的均值和方差，不能完全排除随机波动影响。
3. **后端依赖**：仅实现了 KDA 一种线性注意力后端。其他线性注意力变体（如 GLA、DeltaNet、RetNet）的理论兼容性虽已声明，但未实际实现和评估。
4. **搜索空间的启发式局限**：精确 DP 仅覆盖连续划分空间和约束 K 范围；非连续成员（trie-aware greedy）和局部细化均为启发式，无最优性保证。
5. **规划开销与规模的关系**：虽然规划时间比 OR-Tools 快 7–9 倍，但其绝对时间是否随轨迹数和树复杂度线性增长、在大规模生产训练中是否仍可忽略，仍需进一步评估。
6. **紧凑布局的前提要求**：MLA 执行依赖注意力后端支持不对称 packed Q/KV 视图和 bottom-right 因果对齐；若缺乏此类后端支持，其通用性受限。
7. **未量化执行时延细节**：论文未单独报告 KDA 重放时间、MLA 祖先 KV 视图扩展开销、状态物化与梯度通信的时间占比，这些因素对最终加速比的影响是推断性的，缺乏 profile 数据的支撑。

## 摘要
基于上下文学习的表格基础模型近期已成为任务特定模型拟合的有力替代方案。然而，当前性能前沿仍由注意力密集型架构主导，注意力贯穿于整个建模流程。这引出一个自然问题：在表格上下文学习的每个阶段是否都需要注意力？我们提出SOMTab，一种用于高效表格上下文学习的集合序Mamba架构。SOMTab将表示构建与查询条件检索分离。对于行和列表示，它将无序表格标记映射为稳定的潜在槽，并应用基于Mamba的状态空间混合来构建紧凑表示。对于最终预测，它保留基于注意力的上下文学习，以保持对标注上下文示例的查询条件检索。我们进一步引入DCH-TailMix，一种合成先验，将度校正图异质性与混合重尾机制相结合，以多样化合成依赖结构。在多个表格基准上，SOMTab在接近强Transformer表格基础模型性能的同时，实现了更快的推理和更低的GPU内存占用，产生了有利的效率-准确性权衡。

## Abstract
Tabular foundation models based on in-context learning have recently emerged as strong alternatives to task-specific model fitting. However, the current performance frontier remains dominated by attention-heavy architectures, where attention is used throughout the modeling pipeline. This raises a natural question: is attention necessary at every stage of tabular in-context learning? We introduce SOMTab, a Set-Order Mamba architecture for efficient tabular in-context learning. SOMTab separates representation construction from query-conditioned retrieval. For row and column representations, it maps unordered table tokens into stable latent slots and applies Mamba-based state-space mixing to construct compact representations. For final prediction, it retains attention-based in-context learning to preserve query-conditioned retrieval from labeled context examples. We further introduce DCH-TailMix, a synthetic prior that combines degree-corrected graph heterogeneity with mixed heavy-tailed regimes to diversify synthetic dependency structures. Across tabular benchmarks, SOMTab approaches the performance of strong Transformer-based tabular foundation models while achieving faster inference and lower GPU memory usage, yielding a favorable efficiency--accuracy trade-off.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：表格数据是科学和工业机器学习中最常见的数据格式之一。近年来，基于上下文学习（In-Context Learning, ICL）的表格基础模型（如TabPFN、TabPFNv2、TabICL、TabICLv2）已成为传统任务特定模型拟合（如树模型）的有力替代方案。这类模型基于先验数据拟合网络（PFN）框架，通过在合成任务上预训练来摊销跨数据集的预测，无需在目标数据上更新参数。
- **核心问题**：当前性能前沿仍由注意力密集型（attention-heavy）架构主导，注意力被贯穿用于整个建模流程（包括表表示构建和最终预测），带来了二次方计算成本。论文提出一个关键疑问：**表格上下文学习的每个阶段是否都需要注意力？** 具体而言，注意力是否主要在查询-上下文匹配（query-context matching）阶段才必不可少，而在早期表格表示构建阶段可以被更高效的线性复杂度算子（如状态空间模型）替代？
- **整体含义**：论文主张将表格ICL分解为两种计算角色——**表示构建**（representation construction）与**查询-上下文匹配**（query-context matching），并据此有选择性地分配注意力资源，而非将其作为全流程的默认算子。这一视角为设计更高效的表格基础模型提供了新思路：用线性复杂度的Mamba进行表示压缩，而在最终预测阶段保留注意力以维持查询条件检索能力。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### （1）核心思想：注意力按阶段取舍

SOMTab将表格ICL分解为两个阶段，并赋予不同算子：

- **表示构建阶段**：使用基于Mamba的集合序（Set-Order）混合机制，将无序表格令牌映射为有序潜在槽（latent slots），以线性复杂度构建紧凑的行/列表示。
- **查询-上下文匹配阶段（最终预测）**：保留基于注意力的ICL读取器，使测试示例能够从标注上下文示例中按查询条件检索标签相关信息。

#### （2）Set-to-Order Mamba Block（集合序Mamba块）

解决Mamba无法直接处理无序表格的问题。核心流程如下：

- 输入无序令牌集合 $S \in \mathbb{R}^{N \times d}$，引入 $K$ 个可学习种子槽 $U \in \mathbb{R}^{K \times d}$，其固定索引定义潜在序列顺序。
- **Set Read（集合读取）**：通过交叉注意力将输入集合聚合到种子槽（$O(NK)$ 复杂度），再加FFN：$Z' = U + \text{Attn}(\text{LN}(U), \text{LN}(S), \text{LN}(S))$，$Z_0 = Z' + \text{FFN}(\text{LN}(Z'))$。由于输入令牌无位置编码，该操作对输入置换保持不变。
- **Mamba-2混合**：沿有序潜在序列应用预归一化的Mamba-2残差块：$\tilde{Z} = Z_0 + \text{Mamba2}(\text{LN}(Z_0))$，$Z = \tilde{Z} + \text{FFN}(\text{LN}(\tilde{Z}))$。
- **Readback（回读，可选）**：将潜在槽信息通过交叉注意力传回原始输入令牌：$\tilde{S}' = S + \text{Attn}(\text{LN}(S), \text{LN}(Z), \text{LN}(Z))$，$\tilde{S} = \tilde{S}' + \text{FFN}(\text{LN}(\tilde{S}'))$。

此设计中，集合读取是置换不变的，回读是置换等变的，从而解决表格无自然顺序的问题。

#### （3）SOMTab整体架构

- **初始令牌构建**：对每个活跃特征位置构建初始细胞令牌。采用重复特征分组（circular feature grouping，偏移量(0,1,3)）缓解特征对称性。上下文行注入早期标签嵌入：$e_{ij}^{(0)} = W_x \tilde{x}_{ij} + b_x + \mathbf{1}[i \le n_{\text{tr}}] \psi_{\text{early}}(y_i)$。
- **变量级（列级）编码器**：对每个特征 $j$，仅用上下文行的令牌集合 $S_j^{\text{ctx}}$ 做Set Read + Mamba-2 + Readback（共 $L_v=3$ 层），生成条件化细胞表示。查询行只从特征摘要中读取信息而不影响摘要本身。
- **样本级（行级）编码器**：对每行 $i$，将其 $m$ 个特征令牌与 $K_r=4$ 个共享行摘要令牌合并为集合，映射到 $K_s=4$ 个有序潜在槽，经3层Mamba-2块混合后展平为行表示 $h_i \in \mathbb{R}^{4d}$。
- **注意力ICL读取器**：上下文行表示加入第二个标签嵌入，随后所有行（上下文+查询）通过12层Transformer块进行上下文受限注意力（context-only attention，K/V仅来自标注上下文），最终由MLP输出查询行的类别概率。

#### （4）复杂度分析

- 表示构建阶段：$O(Nm(K_v + K_s))$，即与观测单元格数呈**线性**关系。
- 最终ICL读取器：$O(n_{\text{tr}}^2 + n_{\text{tr}} n_{\text{te}})$，受限于 $O(N^2)$，但只在行级别的小规模上执行。

#### （5）DCH-TailMix合成先验

用于预训练阶段生成多样化的合成任务，由两部分组成：

- **度校正图采样（DCH）**：从带拓扑排序的潜在DAG中采样边，边概率由多种结构项决定：$p_{ij} = \sigma(\tau + g + a_i^{\text{out}} + a_j^{\text{in}} + b_{c_i,c_j} + \lambda \langle u_i, v_j \rangle / \sqrt{r} + \epsilon_{ij})$。涵盖基稀疏度、任务级密度变化、出/入度异质性、模块块结构、低秩相关连接等。四种图族：受控重尾、模块重尾、低秩相关连接、稠密弱依赖。
- **重尾机制混合（TailMix）**：三种尾部分布基于混合比例采样：独立Student-t（0.70）、层次Student-t（0.20）、对称Pareto（0.10），控制图偏置的尾部行为。

生成流程：采样潜在节点 → 采样DAG → 截断父节点集 → 根节点初始化与潜变量传播（函数族包括线性、神经网络、树集成、离散化、GP-like、二次型、EM-like、乘积等8类）→ 选择目标节点与观测特征 → 特征转换器（数值/分类）→ 目标离散化为类别标签 → 无效任务过滤。

### 6. 主要结论与发现

- **效率-精度权衡**：SOMTab的归一化对数损失（0.054）接近TabICLv2（0.029），显著优于TabPFNv2（0.100）、TabICL（0.105）和所有非基础模型基线（0.309~0.716），而运行时（0.019 s/1K）比TabICLv2快约24倍、比TabICLv2（1估算器）快约8倍，实现了有利的精度-效率权衡。
- **上下文长度扩展性**：SOMTab在所有评估上下文长度上具有最低的端到端ICL时间，且随上下文增长优势不断扩大。内存方面小上下文略高（因潜变量模块开销），但大上下文下注意力二次方内存增长占据主导，SOMTab更具优势。
- **注意力按阶段分配有效**：消融实验显示，DCH-TailMix先验优于Cauchy先验和SCM-Tree先验；注意力读取器优于Mamba读取器，验证了"Mamba用于表示构建、注意力用于最终ICL预测"的设计原则。
- **合成先验的重要性**：DCH-TailMix在相同预训练预算下取得最高平均准确率，说明更丰富的依赖结构多样性有助于提升模型泛化能力。

### 7. 优点

- **问题视角新颖**：明确区分"表示构建"与"查询-上下文匹配"两种计算角色，提出注意力应选择性分配而非全程使用的架构设计原则，为表格基础模型的高效化提供了新思路。
- **方法设计巧妙**：Set-to-Order机制优雅地解决了Mamba无法直接处理无序表格结构的问题，通过种子槽将无序集合映射为有序潜在序列，同时保持置换不变性/等变性。
- **先验设计丰富**：DCH-TailMix综合了度校正图异质性（四个图族）与混合重尾机制（三种尾部分布），结合8种函数族和多种特征转换器，显著提升了合成任务的多样性。
- **效率优势显著**：表示构建阶段为线性复杂度，推理时间比强Transformer基线降低一个数量级以上，内存扩展性也更优。
- **实验设计较为全面**：涵盖主要基准、TabArena扩展对比、上下文扩展实验、受控消融实验，并对TabArena的硬件不匹配问题进行了透明说明。

### 8. 不足与局限

- **训练成本较高**：主模型训练约需4×A100 GPU、23天（400K步），预训练成本显著高于部分基线方法，可能限制其实际采用。
- **消融实验规模受限**：受控消融仅训练20K步、评估15个数据集子集（且偏向SOMTab较弱的数据集），可能与完整训练后的表现不完全一致；消融仅报告准确率，缺少对数损失和F1对比。
- **精度仍有差距**：SOMTab的归一化对数损失（0.054）仍明显高于TabICLv2（0.029），在预测质量上尚未完全达到最强Transformer基线的水平。
- **架构复杂性增加**：对小上下文场景，SOMTab的显存占用略高于注意力基线，说明潜变量表示模块存在固定开销，对小规模任务可能不够友好。
- **TabArena对比的硬件不匹配**：公开基线为H100测量，SOMTab为H200/A100测量，作者虽明确说明这是参考性比较，但严格意义上缺乏硬件匹配的公平性。
- **需要更多下游验证**：论文主要聚焦分类任务，未涉及回归任务、多模态表格数据或真实大规模工业场景的验证。

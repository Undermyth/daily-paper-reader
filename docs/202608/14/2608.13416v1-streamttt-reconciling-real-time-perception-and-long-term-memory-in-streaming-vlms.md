## 摘要
人类能够轻松地感知当下，同时记住过去，然而流式视觉语言模型（VLMs）往往需要在实时感知与长期记忆之间做出权衡。先前的研究表明，缩短上下文可以增强对当前场景的感知，但代价是降低长期回忆能力。为了协调这两种能力，我们引入了StreamTTT，它将长期历史写入注意力上下文之外、在线更新的快速权重中。这样便留下一个专用于近期证据的短滑动键值缓存，从而减轻注意力稀释问题。我们在离线长视频问答和新构建的实时问答语料库上联合训练StreamTTT。在OVO-Bench上，StreamTTT-4B在实时感知方面比SimpleStream-4B高出1.4个百分点，在反向追踪方面高出3.7个百分点。同时，在StreamingBench的实时视觉理解（RTVU）子集上，它也能与更大的SimpleStream-8B保持竞争力。我们的代码将予以发布。

## Abstract
Humans effortlessly perceive the present while remembering the past, yet streaming VLMs often trade off real-time perception against long-term memory. Prior work shows that shortening the context can sharpen current-scene perception at the expense of long-range recall. To reconcile these abilities, we introduce StreamTTT, which writes long-range history into online-updated fast weights outside the attention context. This leaves a short sliding key-value cache dedicated to recent evidence, mitigating attention dilution. We train StreamTTT jointly on offline long-video QA and a newly constructed real-time QA corpus. On OVO-Bench, StreamTTT-4B outperforms SimpleStream-4B by 1.4 points in real-time perception and 3.7 points in backward tracing. It also remains competitive with the larger SimpleStream-8B on the Real-Time Visual Understanding (RTVU) subset of StreamingBench. Our code will be released.

## 1. 核心问题与整体含义

- **研究动机**：流式视觉语言模型（Streaming VLM）需要在“实时感知当前场景”与“长期记忆过去信息”之间取得平衡，但现有方法常陷入“感知–记忆权衡”：缩短上下文能提升对当前场景的感知，却会损害长程回忆；注入历史上下文虽能改善回忆，又可能稀释近期证据的注意力。
- **核心问题**：如何在有限注意力上下文中，同时保留“近期精确证据”与“长程压缩历史”，实现实时感知与长期记忆的和谐统一。

## 2. 方法论

- **核心思想**：将长程历史写入注意力上下文之外的“在线更新快速权重”（Test-Time Training / TTT 状态），让短滑动键值缓存（KV cache）只负责近期证据，从而避免历史 token 挤占或稀释近期上下文。
- **架构设计**：
  - 基于 Qwen3-VL，将每个自注意力块改造为“混合层”：保留预训练滑动窗口注意力（SWA）路径，并新增并行 TTT 记忆分支。
  - 每条解码器层携带两种互补记忆：短滑动 KV 缓存 K（近期上下文）和固定大小的循环 TTT 状态 S（跨窗口压缩历史）。
  - 两个分支输出通过可学习的通道级门控 tanh(α) 融合，α 初始化为接近零，使模型初始行为接近预训练路径。
  - TTT 分支采用 Large-Chunk TTT 的 apply-then-update 顺序：每 C 个 token 聚合一次更新；使用 momentum 和输入依赖的 decay；状态 S 包含快速权重 W、动量 M、卷积前缀及 partial-chunk 缓冲，均在固定上限内，不随视频长度增长。
- **流式推理**：
  - 视频按墙钟时间划分为连续时间窗口；每窗口的视觉 token 输入一次 LLM 前向。
  - 窗口间携带两种记忆：KV 缓存裁剪到最近 L 个 token；TTT 状态完整保留。
  - 通过 M-RoPE 的全局连续位置偏移（式 6），保持跨窗口位置一致。
- **训练数据**：
  - 离线长视频监督：从 LLaVA-Video-178K 的 2–3 分钟子集中采样约 119K 对。
  - 实时感知监督：构建 112.4K 实时问答语料，将 Streamo 的主动问答（proactive QA）问题时间移动到“答案可得时刻”（tq := ta），并添加动作、空间推理、字幕等监督；来源包括 LLaVA-Video、QVHighlights、EgoTimeQA、ActivityNet、HowToCaption、Aria Digital Twin、Ego4D STA 等。

## 6. 主要结论与发现

- StreamTTT-4B 在 OVO-Bench 上达到两任务平均 68.59，比同规模的 SimpleStream-4B（66.06）提升 2.53 点：实时感知提升 1.4 点（78.9 vs 77.5），反向追踪提升 3.7 点（58.3 vs 54.6）。
- 在 StreamingBench RTVU 上达到 80.48，超过 HERMES-7B（79.44），并以约一半参数量逼近 SimpleStream-8B（80.59，差 0.11 点）。
- 消融表明：只有“混合架构（KV+TTT）+ 联合训练”能同时取得最高实时感知与最高回忆指标；仅离线训练会大幅降低实时感知（65.08），仅实时训练则 ER 略低。
- 窗口预算分析显示：固定大小 TTT 状态能弥补大量缺失上下文（如 4K 窗口下 OVO-EPM 恢复约 97% 的 64K 窗口差距），但当完整视频可放入注意力上下文时，TTT 是补充而非替代。

## 7. 优点

- 方法设计巧妙：将“近期感知”与“长期记忆”分离到不同存储机制，直接在架构层面化解注意力稀释问题。
- 数据构造有创新：将“主动问答”转为“答案可得时刻提问”，并利用无模型标注（ground truth）生成空间推理、未来动作预测等实时感知监督。
- 实验对比兼顾公平性和匹配性：同规模对标 SimpleStream-4B，同内存对标启发式记忆方法，机制归因清晰。
- 消融系统全面：覆盖架构、数据、记忆机制、窗口预算四个维度，能清楚支持“分离 + 联合训练”的核心主张。

## 8. 不足与局限

- 算力与训练细节未披露（GPU、时长、超参搜索范围等），复现需依赖后续开源代码。

- 固定大小 TTT 状态仍是“有损摘要”：在回忆密集的视频上，其能力不足以完全替代全视频注意力；论文也承认需继续提升状态的容量与选择性。

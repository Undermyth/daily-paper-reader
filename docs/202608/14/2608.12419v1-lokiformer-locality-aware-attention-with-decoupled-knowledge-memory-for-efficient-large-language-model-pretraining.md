## 摘要
大语言模型（LLMs）在各种应用中取得了显著突破。然而，它们的架构在预训练中仍然效率低下，主要原因有两个限制：（i）自注意力缺乏对局部性的显式归纳偏置，导致对序列内部局部信息的冗余建模；（ii）专家混合（MoE）隐式地将知识存储与计算路径耦合，阻碍了对序列外部全局知识的灵活访问。为了克服这些限制，我们提出了LoKiFormer，一种新颖的大语言模型架构，它通过两个专用模块增强了标准解码器：1）局部融合注意力（LFA），它将卷积融合纳入注意力机制，显式地捕捉局部模式，并使注意力能够基于更具信息量的表示进行操作；2）知识记忆模块（KMM），它引入了一个参数化的键值记忆，将全局知识显式地存储在可寻址的槽中，将存储与计算解耦，并实现直接的知识检索。这些模块共同使LoKiFormer能够在两个层面上实现更高效、更有效的信息整合。实验结果表明，LoKiFormer在预训练中的收敛速度比基线模型快1.33倍，凸显了其相对于现有大语言模型架构的优越性。

## Abstract
Large language models (LLMs) have achieved remarkable breakthroughs across various applications. However, their architectures remain inefficient in pretraining due to two main limitations: (i) self-attention lacks an explicit inductive bias for locality, leading to redundant modeling of sequence-internal local information; (ii) mixture-of-experts (MoE) implicitly couples knowledge storage with computational pathways, hindering flexible access to sequence-external global knowledge. To overcome these limitations, we propose LoKiFormer, a novel LLM architecture that augments the standard decoder with two dedicated modules: 1) Local Fusion Attention (LFA), which incorporates a convolutional fusion to attention, explicitly capturing local patterns and allowing the attention to operate on more informative representations; 2) Knowledge Memory Module (KMM), which introduces a parametric key-value memory that explicitly stores global knowledge in addressable slots, decoupling storage from computation and enabling direct knowledge retrieval. Together, these modules enable LoKiFormer to achieve more efficient and effective integration of information at both levels. Experimental results show that LoKiFormer converges 1.33x faster in pre-training than baseline models, underscoring its superiority over existing LLM architectures.

# LoKiFormer 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

现代大语言模型（LLM）的预训练效率受制于两个根本性瓶颈：

- **注意力缺乏局部性归纳偏置**：标准的 self-attention 和 Multi-Head Latent Attention (MLA) 以无差别的全量成对交互方式同时建模短程与长程依赖。对于相邻 token 之间的局部模式（如语法结构、相邻词依赖），这种全量交互是冗余且计算低效的。
- **MoE 将知识存储与计算路径隐式耦合**：Mixture-of-Experts 将知识以分布式方式编码在专家网络的权重中，知识检索必须经过线性变换才能间接触发，导致知识访问不透明、不灵活，难以直接复用和更新特定知识。

论文的核心主张是：**现有架构在预训练阶段整合"序列内部局部信息"与"序列外部全局知识"时计算效率低下**，亟需一种能够显式、解耦地处理这两类信息的架构设计。

## 2. 方法论：核心思想与关键技术细节

论文提出 **LoKiFormer**——一种增强型 decoder 架构，在标准解码器块上叠加两个互补模块：

### 2.1 Local Fusion Attention (LFA)：显式局部归纳偏置

- **核心思想**：在 MLA 之前引入**因果一维组卷积**，对相邻 token 表示进行融合，显式建模短程依赖，使注意力层专注于更复杂的全局上下文关系。
- **关键技术细节**：
  - 将隐藏状态 `U ∈ R^{L×d}` 沿特征维度分为 `h` 组（`h` 与注意力头数一致），每组维度为 `d_h = d/h`。
  - 对每组应用因果 1D 卷积，核大小为 `k`，每个位置仅聚合前 `k` 个近邻 token，保持因果性（不访问未来 token）。
  - 卷积后的增强表示 `Û` 再用于构建 Q、K、V（经 MLA 的降维投影）。
- **参数开销极小**：仅占总参数的 0.41%（7B 模型），属于轻量级修改。

### 2.2 Knowledge Memory Module (KMM)：解耦的显式知识记忆

- **核心思想**：将全局知识显式存储在**参数化的键值字段**（Key-Value Fields）中，使知识存储与计算路径解耦，支持直接查询和显式检索。
- **关键技术细节**：
  - 以 MLA 的中间潜表示 `c_KV` 为输入，经投影矩阵 `W_H` 映射到查询空间。
  - 记忆存储为可学习参数 `K ∈ R^{F×d_u}` 和 `V ∈ R^{F×d_v}`（`F` 为知识字段数）。
  - 采用**多组检索**（multi-group retrieval）：查询和键值沿特征维度分为 `c` 组，在每组内计算缩放点积相似度，经 softmax 加权聚合对应值，最后拼接各组输出。
  - 检索结果与 MLA 输出简单相加，再送入 MoE 层。

### 2.3 架构整体流程（Algorithm 1）

1. `Û = Conv(U)`（LFA 局部融合）
2. `c_Q = Û W_QD, c_KV = Û W_KVD`（MLA 潜投影）
3. `O_A = MLA(c_Q, c_KV)`（注意力计算）
4. `H = c_KV W_H, Z = KMM(H; K, V), O_K = Z W_O`（KMM 知识检索）
5. `O = MoE(O_A + O_K)`（最终输出）

### 2.4 与现有方法的关键区别

| 对比对象 | 核心区别 |
|---|---|
| 滑动窗口注意力 | LFA 不截断全局上下文，仅增强局部输入表示 |
| 显式/隐式记忆（如 MemLLM、MemoryLLM） | KMM 聚焦于训练期知识内化，而非上下文扩展 |
| DeepSeek Engram | Engram 用静态离散 n-gram 查找；KMM 完全参数化、端到端可微 |
| LM2 | LM2 是输入相关的动态 KV；KMM 是固定的可寻址记忆，参数增量更小 |

## 6. 主要结论与发现

1. **预训练收敛速度显著提升**：LoKiFormer 达到基线 10k 步 PPL（31.82）仅需 7.5k 步（验证集），实现 **1.33× 加速**。

- **问题诊断精准**：明确指出了 LLM 预训练低效的两个结构根源（局部信息冗余建模、知识存储耦合计算），并针对性地设计解决方案。

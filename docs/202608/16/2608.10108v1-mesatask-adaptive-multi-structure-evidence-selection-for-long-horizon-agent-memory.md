## 摘要
长时程智能体会累积跨越数百个交错推理、行动和观察步骤的轨迹，其中回答查询可能依赖于深埋在历史中的证据。外部记忆将这些轨迹存储为结构化表示，但每种结构提供了不同且不完整的视角。现有的多记忆系统要么为每个查询读取固定的结构集，这膨胀上下文并引入噪声；要么将每个查询路由到单一结构，从而阻碍互补证据的组合。对AMA-Bench的控制分析表明，最佳记忆配置通常既不是单一结构，也不是全部结构的并集，而是随查询和任务需求变化的多结构记忆的定制组合。受这些发现启发，我们提出了结构级动态选择：从专门记忆结构库中选择并融合一个查询自适应的子集。我们提出了MESA（面向长时程智能体的多结构证据选择框架），该框架为每条轨迹构建五个互补的结构视图，并从端到端的答案级反馈中学习，以选择并融合针对特定查询的子集，供冻结的答案模型使用。为了在这种弱监督下学习，MESA采用带有先验引导搜索和UCB引导调度的框架优化，以平衡探索与利用。在AMA-Bench上，MESA比最强基线高出8.5%，同时比全结构方案少使用41%的证据标记。

## Abstract
Long-horizon agents accumulate trajectories spanning hundreds of interleaved reasoning, action, and observation steps, where answering a query may depend on evidence buried far back in the history. External memory stores such trajectories as structured representations, yet each structure provides a distinct and incomplete view. Existing multi-memory systems either read a fixed set of structures for every query, inflating context and introducing noise, or route each query to a single structure, preventing the composition of complementary evidence. A controlled analysis on AMA-Bench shows that the optimal memory configuration is typically neither a single structure nor the full union, but a tailored composition of multiple structural memories that varies with query and task demands. Motivated by these findings, we formulate structure-level dynamic selection: selecting and fusing a query-adaptive subset from a library of specialized memory structures. We propose MESA (a Multi-structure Evidence Selection framework for long-horizon Agent), which builds five complementary structure views of each trajectory and learns from end-to-end answer-level feedback to select and fuse a query-specific subset for a frozen answer model. To learn under this weak supervision, MESA employs harness optimization with prior-guided search and UCB-guided scheduling to balance exploration and exploitation. On AMA-Bench, MESA outperforms the strongest baseline by 8.5% while using 41% fewer evidence tokens than the all-structure alternative.

## 1. 论文的核心问题与整体含义

- **研究背景**：长时程智能体（Long-horizon Agent）会累积跨越数百步的轨迹，其中包含推理、动作、观察和工具调用。回答后续查询时，关键证据往往深藏于较早的历史中。
- **已有方法的缺陷**：
  - 直接将完整历史输入长上下文 LLM：成本高，且长上下文中易出现“中间丢失”问题，不能稳定利用远端证据。
  - 外部记忆系统常采用单一结构表示，如文本摘要、时序存储、知识图谱、向量数据库、原始轨迹切片等；但每种结构都只提供“不完整且片面”的视角。
  - 现有多记忆系统要么对所有查询固定读取全部结构，导致上下文膨胀和噪声；要么把查询路由到单一结构，无法组合互补证据。
- **控制性实验发现**：在 AMA-Bench 上遍历 31 种非空结构子集后，最优配置通常既不是单一结构，也不是全结构并集，而是“中间状态”的、随任务和查询变化的多结构组合。
- **核心问题**：如何为每个查询动态选择并融合一组互补的记忆结构，实现“结构级动态选择”，同时兼顾证据质量与 token 成本。

## 2. 方法论

- **整体框架**：MESA 为每个交互历史离线构建五种互补记忆结构，并在推理时学习一个查询自适应的选择策略，从函数库中挑选记忆结构子集，检索并融合证据后交给冻结的答案模型。
- **五种记忆结构**：
  1. 文本摘要（Summary）：压缩的高层状态记忆；
  2. 时序存储（Temporal KV）：保留原始动作-观察序列和步骤索引；
  3. 知识图谱（Knowledge Graph）：实体/关系三元组，支持跨步关系连接；
  4. 向量数据库（Vector DB）：逐步稠密向量索引，用于语义检索；
  5. 原始轨迹切片（Raw Episodic）：BM25 检索的窗口化原始内容。
- **形式化建模**：
  - 选择向量 \(z \in \{0,1\}^K\)，非空，\(K=5\)，动作空间大小 \(2^5-1=31\)。
  - 选择器 \(S_\rho(q_i,c_i)\) 根据查询和上下文输出子集；
  - 被选结构的证据统一合并后，由冻结答案模型生成答案；
  - 优化目标为正则化的验证目标：\(\tilde{J}_{val}(\rho)=J_{val}(\rho)-\lambda C_{val}(\rho)\)，权衡准确率与证据 token 成本。
- **弱监督下的策略学习**：没有“最优结构子集”或“单结构效用”的监督信号，只有稀疏的端到端答案反馈。
- **Prior-Guided Harness Optimization**：
  - 初始化策略档案为“全结构”策略；
  - 定义若干先验方向（如需求推断、结构效用估计、子集构建、证据感知、鲁棒性与成本控制），限制搜索空间；
  - 使用 UCB 调度在探索与利用间平衡：对每个先验方向计算 \(UCB(a)=\tilde{J}_{val}(a)+\beta\sqrt{\log(N+2)/(n_a+1)}\)；
  - 每轮由 LLM 提案生成三个候选：利用型、探索型、失败修复型；
  - 候选策略在训练集上拟合，在验证集上评价，迭代更新档案，最终返回验证目标最高的策略。
- **说明**：MESA 只优化选择器；记忆构建器、检索器、证据合成器和答案模型均固定。

## 3. 实验设计

- **数据集与基准**：
  - **AMA-Bench**：208 条长时程智能体轨迹，12 个专家标注 QA/轨迹，共 2496 个问题；覆盖 6 个智能体领域（Web 任务、开放世界工具问答、Text2SQL、软件工程、游戏、具身 AI）和 4 类记忆能力（回忆、因果推断、状态更新、状态抽象）。
  - **LoCoMo**：10 个多会话长对话，排除对抗性问题后保留 1540 个问题（单跳、多跳、时序、开放域），用于验证框架可迁移到会话记忆。
- **对比方法**：
  - 长上下文直接读取；
  - BM25、Qwen3-Emb-4B 检索；
  - 长期记忆系统：MemGPT、HippoRAG2、Mem0、MemoRAG、A-Mem、EMem、Hindsight；
  - 多结构基线 AMA-Agent（该基准当前最强方法）。
  - 所有方法在统一答案模型、统一评测提示下比较。
- **评测指标**：
  - AMA-Bench：LLM-as-judge 准确率（Qwen3-32B 为主判断模型，额外用 Gemma-4-31B、GPT-5.4 验证鲁棒性）；
  - LoCoMo：Token-F1；
  - 同时报告每查询证据 token 数。
- **划分方式**：AMA-Bench 按 episode 级 2:2:6 划分为训练/验证/测试，随机重复 5 次；LoCoMo 按对话级 2:2:6 划分。

## 6. 主要结论与发现

- **核心结论**：长时程智能体记忆的最优读取方式应当是对多记忆结构进行“查询自适应的中间子集选择”，而不是读全部或只读一种。
- **性能提升**：
  - 在 AMA-Bench 上，MESA（Qwen3-32B）以 65.1% 总体准确率超过最强基线 AMA-Agent（56.6%）8.5 个百分点；同时比全结构方案少用 41.2% 证据 token。
  - 在 Gemma-4-31B 上，MESA 总体准确率 69.4%，比最强基线高 6.4%。
  - 在 LoCoMo 上，MESA F1 为 49.0%，比最强基线高 1.8%。
- **能力层面上**：MESA 在 Recall、State Updating、State Abstraction 上均最优；Causal Inference 略低于 AMA-Agent，说明跨事件/跨结构依赖建模仍有改进空间。
- **领域层面上**：在 Web、Text2SQL、Software、Embodied AI 上优势明显，尤其 Software 和 Text2SQL 提升最大，符合组合“全局状态 + 精确标识符 + 时序定位事件”的需求。
- **消融结论**：
  - 单一最强结构 Summary 仅 57.7%，MESA 通过选择组合达到 65.1%；
  - Route-to-one 明显下降（57.0%），说明“组合互补结构”是关键；
  - 去掉先验方向或去掉 UCB 均导致性能下降和方差增大；
  - 学习出的策略是可解释的、显式的关键词/规则条件映射。

## 7. 优点

- **问题定义清晰**：首次系统化提出“结构级动态选择”，并通过穷举子集实验提供充分经验依据。
- **方法设计合理**：将优化限制在“先验方向”上，缓解弱监督下搜索空间过大问题；UCB 调度提升探索-利用平衡与稳定性。
- **兼顾性能与效率**：在提升准确率的同时显著降低证据 token 数，说明选择不只是节省成本，还能减少噪声干扰。

## 8. 不足与局限

- **结构种类有限**：只用了五种代表性记忆结构，未覆盖所有可能的表示（如分层记忆、多模态记忆等）。
- **未做联合优化**：固定记忆构建、检索、答案模型，只优化选择器，未考虑记忆构建与选择之间的耦合。

- **LoCoMo 规模小**：仅 10 个长对话，跨对话泛化结论的证据强度有限；论文对基线的 LoCoMo 结果未做多折划分，可能影响比较的稳健性。
- **算力信息不透明**：只说明使用 A100，未给出 GPU 数量、训练/优化总时长、推理成本等关键资源信息。
- **评价依赖 LLM judge**：即使做了多 judge 鲁棒性检验，不同 judge 之间的绝对分数差异仍较大（如 GPT-5.4 下 MESA 降到 52.9%），主观评估偏差难以完全消除。
- **基线适配问题**：部分基线原本不是为轨迹/长对话记忆设计，进行 prompt 或记忆格式适配后可能未达到其最佳表现，对比结果存在一定偏差风险。

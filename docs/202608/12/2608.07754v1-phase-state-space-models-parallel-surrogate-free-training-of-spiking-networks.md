## 摘要
状态空间模型（SSM）为循环网络的并行训练提供了强大的理论框架。我们在先前将SSM应用于尖峰模型的工作基础上进行了扩展，为谐振-放电（R&F）神经网络提供了一种新的解释，该解释与真实输入和尖峰输入兼容，支持并行和循环执行，与超维（HD）计算有明确联系，并保持生物现实特征。我们展示了该方法的一种实现，它将STFT、循环记忆和注意力特征集成在单个尖峰兼容网络中。

## Abstract
State-space models (SSMs) provide a powerful theoretical framework to enable parallel training of recurrent networks. We expand on previous work adapting SSMs to spiking models to provide a novel interpretation of resonate-and-fire (R\&F) neural networks which is compatible both with real and spiking inputs, parallel and recurrent execution, has clear connections to hyperdimensional (HD) computing, and maintains biologically-realistic features. We demonstrate an implementation of this approach which integrates an STFT, recurrent memory, and attentional features within a single spike-compatible network.

## 相位状态空间模型（φ-SSM）论文详细总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：尖峰神经网络（SNN）虽具有生物合理性和低功耗潜力，但传统训练方法（如基于替代梯度的 BPTT）存在梯度稀疏、时间步长受限制等难题。状态空间模型（SSM）为循环网络的并行训练提供了强大的数学框架，但此前将 SSM 适配到尖峰模型的工作仍局限于特定输入类型或执行模式。
- **研究动机**：希望将 SSM 的理论优势（连续/离散/卷积三视图等价）拓展到谐振-放电（R&F）神经元网络，同时解决三个关键问题：① 支持真实值与尖峰两类输入；② 兼顾并行训练与循环推理；③ 避免替代梯度（surrogate gradient）带来的超参数调优与梯度信息稀疏问题。
- **整体含义**：提出一种新的解释框架 **相位状态空间模型（φ-SSM）**，将 R&F 神经元以"频率锁定 + 相对相位"的方式重新定义，建立与超维计算（HD Computing）的明确联系，并证明该方法可集成 STFT、注意力等现代计算模块，为类脑计算与高效深度学习之间搭建了一座理论桥梁。

### 2. 论文提出的方法论

#### 2.1 核心思想

论文将 R&F 神经元的复数势能视为二维极坐标量，通过**固定谐振频率 ω** 使神经元间"相对相位"随时间保持不变，从而：
- 用相对相位编码信息，替代传统尖峰脉冲；
- 在任意时刻都能解码全部神经元的相位值（即使未放电）；
- 用自动微分（AD）直接求梯度，完全绕开替代核（surrogate kernel）。

#### 2.2 关键技术步骤

1. **R&F 神经元的 SSM 化**：连续微分方程 `dU/dt = A·U(t) + B·I(t)`，其中 A 为对角矩阵（保持信息局部性），U 为复数势能张量。
2. **尖峰输出改造**：输出由 `Y = C·U + D·X` 改为 `Y(t) = S(U(t))`，其中 S 为尖峰函数；随后进一步改为**相对相位输出** `Y_θ(t) = θ_rel(U(t), ω, t) = ∠(U·e^(-iωt))`，该输出是连续的实数角度。
3. **三种等价执行模式**：
   - **连续模式**：微分方程求解器（ODE solver）；
   - **离散模式**：等间隔采样（周期 T = 2π/ω），迭代公式 `U[n+1] = e^(kT)·U[n] + B·U'(T, θ, k)`；
   - **卷积/FFT 模式**：将递归展开为因果卷积 `U[n] = (K*H)[n]`，核为 `K[n] = e^(k·n·T)`，输入编码为 `H[n] = B·U'(T, θ_n, k)`，通过 FFT 在频域相乘实现并行计算。
4. **HD 计算连接**：离散更新可等价为超维算子 `Y_θ[n+1] = bundle(bind(Y_θ[n], α), θ_rel(H[n], ω, nT))`，其中 α 为每步旋转量。这一映射使得 SSM 与 FHRR（傅里叶全息压缩表示）的算子（捆绑/绑定/相似度）完全对应。

#### 2.3 公式说明

- 神经元动态：`dU/dt = k·U + w·I`，`k = λ + iω`（λ<0 为漏电，ω 为角频率）
- 相位表示：`θ(t) = ∠(U(t)) ∈ [-1, 1]`（单位：半圈）
- 相对相位：`θ_rel(u, ω, t) = ∠(u·e^(-iωt))`
- 离散更新：`U[n+1] = e^(kT)·U[n] + B·e^(k·δt(θ,k))`
- 卷积核：`K[n] = e^(k·n·T)`
- HD 相似度：`sim(θ1, θ2) = (1/C)Σ cos(π(θ1,c − θ2,c))`

### 6. 论文的主要结论与发现

1. **相对相位可作为 SNN 的连续信息载体**：通过频率锁定 R&F 神经元，可以在不放电的情况下读出并传播相位信息，实现"无代理梯度"的端到端训练。
2. **SSM 三视图等价性在 R&F 网络上成立**：连续微分、离散迭代、卷积/FFT 三种执行方式在数值精度范围内输出一致（图 1 d-f），从而兼顾并行训练与循环推理。
3. **HD 计算与 SSM 的自然融合**：φ-SSM 的离散更新恰好是超维计算的捆绑+绑定运算，为两个领域提供了双向技术迁移的通道。
4. **模块化集成可行**：STFT 适配器与注意力模块都能以相对相位形式融入网络，且为复制任务带来了明确的性能增益。

### 7. 优点

- **理论创新性强**：首次将 R&F 神经元的复数动力学与 SSM 形式体系系统结合，并揭示其与 HD 计算的深层同构关系。
- **规避替代梯度问题**：用相对相位代替离散脉冲，所有神经元（包括静默神经元）都能提供梯度信号，无需设计或调优替代核。
- **三种执行模式高度灵活**：支持物理实现（连续）、数字芯片（离散）与大规模并行加速（FFT），这为从神经形态硬件到 GPU 训练的统一框架提供了可能。
- **生物合理性保留**：R&F 神经元本身就是比 I&F 更生物真实的模型；频率锁定与脑内振荡同步现象（traveling waves）呼应；对角矩阵 A 保证了信息不直接跨神经元传递的生理限制。
- **表 1 的理论复杂度分析清晰**：为不同部署场景提供了明确的计算/存储权衡指导。
- **代码开源**：有利于复现和后续研究。

### 8. 不足与局限

- **实验规模太小**：仅 2 个任务、20 epochs、64 神经元/层，不足以证明方法的可扩展性；FashionMNIST 本身就是相对简单的基准。
- **缺乏与主流方法的直接对比**：未报告与 S4、Mamba、Spiking S4、P-SpikeSSM 或传统 SNN（替代梯度）方法的性能/开销比较，削弱了说服力和实际定位。
- **注意力机制尚未完全"无代理"**：虽然 φ-SSM 本身免替代梯度，但注意力模块中的 `exp(β·sim)` 和 `argmax` 等操作引入了非线性与不可微的读出步骤，其训练细节（如码本选择、损失设计）仍较简单，可能与真实场景有距离。
- **训练仅支持离线并行模式**：论文指出可扩展训练依赖卷积/FFT 模式；连续和离散模式的在线学习（如资格迹）只作展望，没有实验验证。
- **对长序列的稳定性尚无充分验证**：相对相位在频率锁定下虽保持不变量，但未分析长序列下的数值精度、噪声鲁棒性和误差累积。
- **未处理多频带通信**：论文提到生物神经系统存在多频带协同，但多频带 φ-SSM 留作未来工作，当前框架在模数混合场景下的适用性未知。

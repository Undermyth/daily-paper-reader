## 摘要
我们引入了一种带有固定大小记忆的循环Transformer架构\ours{}，它推广了滑动窗口注意力，同时在训练期间保持可并行化。\ours{}由两个耦合模型组成：一个预填充器$Q$，它利用完全注意力\footnote{在实践中，我们对$Q$使用交错的全注意力和滑动窗口注意力，因为这能产生更强的性能。基本要求是$Q$比$P$更具表现力，并能访问完整历史。}来产生记忆目标$m'_t$；以及一个解码器$P$，它仅使用滑动窗口注意力和循环K/V注入来产生用于下一个词元预测的解码器记忆$m_t$。我们使用记忆一致性损失来训练\ours{}，该损失使$m_t$与$m'_t$对齐，从而允许推理时仅使用$P$。实验上，\ours{}在验证损失和下游预训练基准上优于滑动窗口和潜在循环Transformer基线。此外，在$P$和$Q$之间共享参数减少了参数内存，同时保留了大部分收益。

## Abstract
We introduce \ours{}, a recurrent Transformer architecture with fixed-size memory that generalizes sliding-window attention while remaining parallelizable during training. \ours{} consists of two coupled models: a prefiller $Q$, which leverages full attention\footnote{In practice, we use interleaved full and sliding-window attention for $Q$, as this yields stronger performance. The essential requirement is that $Q$ be more expressive than $P$, with access to the full history.} to produce memory targets $m'_t$, and a decoder $P$, which uses only sliding-window attention and recurrent K/V injection to produce decoder memories $m_t$ for next-token prediction. We train \ours{} with a memory consistency loss that aligns $m_t$ with $m'_t$, allowing inference to use $P$ alone. Empirically, \ours{} improves validation loss and downstream pretraining benchmarks over sliding-window and latent recurrent transformer baselines. Moreover, sharing parameters between $P$ and $Q$ reduces parameter memory while preserving most of the gains.

# 论文总结：Maglev: 滑动循环记忆（Sliding Recurrent Memory）

## 1. 论文的核心问题与整体含义

- **研究动机**：Transformer 虽具有强大的上下文建模能力，但其全注意力机制的计算成本随序列长度线性增长；滑动窗口注意力（SWA）虽能限制计算与缓存规模，却无法保留窗口之外的长期信息；传统 RNN/LSTM 虽有固定大小的循环状态，但状态容量小且无法序列并行训练；线性注意力与状态空间模型（如 Mamba）虽然并行化良好，但其更新规则受限于线性/仿射结构，缺乏非线性表达能力。
- **核心问题**：如何让**非线性 Transformer** 具备**逐 token 更新的持久记忆**，同时保持**训练时序列可并行**、**推理时计算与缓存有界**？这正是论文希望补上的空白。
- **整体含义**：Maglev 提出了一种具备固定大小记忆的循环 Transformer 架构，它通过"预填充器（Prefiller）提供监督、解码器（Decoder）学习复现"的训练策略，在不牺牲并行训练的前提下，让推理阶段以纯循环方式运行，兼具 Transformer 的表达力与 RNN 的固定开销。

## 2. 方法论

### 核心思想

- Maglev 将记忆的**构造（训练阶段）**与**传播（推理阶段）**解耦：
  - **预填充器 Q**：在训练时以因果方式、序列并行地处理整段序列，利用更强的注意力（如交错全注意力+滑动窗口）生成一组"记忆目标" \( m'_{1:T} \)。
  - **解码器 P**：仅使用滑动窗口注意力，并接收**移位后的预填充器记忆** \( m'_{0:T-1} \) 作为额外输入，完成下一 token 预测，同时产出自身的记忆 \( m_{1:T} \)。
  - **一致性损失**：使解码器自身产生的记忆 \( m_t \) 逼近预填充器的目标记忆 \( m'_t \)，从而在推理时去掉 Q，仅用 P 闭环运行。

### 技术细节

- **两遍并行训练**：
  \[
  m'_{1:T} = Q_\phi(x_{1:T}), \quad m_{1:T} = P_\theta(x_{1:T}, m'_{0:T-1})
  \]
  相比直接展开 \( T \) 步循环，Maglev 只需两次序列并行前向传播。
- **损失函数**：
  \[
  L(\Theta)=\frac{1}{|I|}\sum_{t\in I}\left[ \mathrm{CE}(p_\Theta(\cdot|x_{\le t}), y_t) + \lambda \frac{\|m_t - m'_t\|_2}{\sqrt{d}} \right]
  \]
  其中第一项为语言建模交叉熵，第二项为记忆一致性损失，\(\lambda\) 控制对齐强度。
- **循环 K/V 注入**：解码器不引入额外记忆 token，而是通过共享投影将移位记忆映射为循环 K/V 特征，与局部 token 的 K/V 经门控混合后进入滑动窗口注意力，缓存规模与普通 SWA 一致。
- **参数共享**：Q 与 P 默认共享 Transformer 块，仅残差缩放参数独立；也可使用完全独立的 Q 堆叠作对照。

## 6. 主要结论与发现

- Maglev 在 FineWeb-Edu 验证 BPB 上优于纯滑动窗口与 LRT 基线：最佳分离参数模型（\(\lambda=1\)）BPB 为 0.7251（基线 SWA 为 0.7413、LRT-SSSS 为 0.7331）。
- 下游平均准确率上：最佳分离参数模型达 56.4%（SWA 为 54.1%、LRT-SSSS 为 55.0%）。
- **共享参数有效**：Q 与 P 共享大部分参数时仍保留大部分收益，显著降低额外参数量。
- **\(\lambda\) 的影响非单调**：对分离参数模型，增大 \(\lambda\) 有益；对共享参数模型，过大 \(\lambda\) 会损害性能——因为过度强制一致性会约束解码器表征空间。
- 额外预填充器容量可提升一致性目标质量，但共享模型在参数效率和性能间取得更优平衡。

## 7. 优点

- **新颖的训练范式**：用"并行预填充器 + 一致性损失"替代显式循环展开，巧妙解决了非线性循环模型难以并行训练的问题。
- **部署友好的推理**：推理时仅需解码器 P，缓存大小与普通滑动窗口注意力完全一致，无额外记忆 token，边界开销为零。
- **通用性强**：Q 可为任意因果模型（甚至可用预训练模型），P 保持标准 Transformer 结构，便于复用现有基础设施。
- **参数共享设计**：大幅降低额外参数成本，使该方案在实际模型中的可行性更高。
- **实验控制良好**：统一 nanochat 栈、共享评测脚本，对比信度较高。

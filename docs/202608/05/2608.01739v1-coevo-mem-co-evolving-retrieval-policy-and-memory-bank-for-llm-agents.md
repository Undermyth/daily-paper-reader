## 摘要
随着记忆在任务与会话间不断积累，长期LLM智能体的性能同时依赖于查询特定的检索与持续的记忆精炼。然而，现有方法通常要么通过迭代查询改写或自适应检索策略来优化记忆访问，要么通过结构更新等方式优化记忆进化。这种分离忽视了一个基本的反馈循环：检索决定了哪些记忆获得使用信号，而更新后的记忆库又重塑未来的检索。我们提出CoEvo-Mem，一个用于协同进化检索策略与记忆库的闭环框架。对于每个查询，冻结的LLM生成路径特定的查询改写和路由先验，轻量残差路由器在线对其进行修正。检索到的上下文作为两个学习过程之间的耦合接口：任务结果将信用分配给路由决策，而轨迹条件反馈更新记忆值与图关系。这些更新改变了后续查询对记忆的排序与选择，从而闭合反馈循环。为减轻耦合引起的非平稳性，CoEvo-Mem在固定记忆库更新路由器与固定检索策略进化记忆库之间交替进行。在七个多样化的基准上，CoEvo-Mem取得了最先进的性能，证明了检索-记忆协同进化的重要性。

## Abstract
As memories accumulate across tasks and sessions, the performance of long-term LLM agents depends jointly on query-specific retrieval and continual memory refinement. However, existing methods typically optimize either memory access, through iterative query refinement or adaptive retrieval policies, or memory evolution such as structural update. This separation overlooks a fundamental feedback loop: retrieval determines which memories receive usage signals, while updated memory bank reshape future retrieval. We propose \textbf{CoEvo-Mem}, a closed-loop framework for co-evolving the retrieval policy and memory bank. For each query, a frozen LLM generates route-specific query rewrites and a routing prior, which a lightweight residual router corrects online. The retrieved context serves as the coupling interface between the two learning processes: task outcomes assign credit to routing decisions, while trajectory-conditioned feedback updates memory values and graph relations. These updates alter how memories are ranked and selected for subsequent queries, thereby closing the feedback loop. To mitigate coupling induced non-stationarity, CoEvo-Mem alternates between updating the router with the memory bank fixed and evolving the memory bank with the retrieval policy fixed. Across seven diverse benchmarks, \textbf{CoEvo-Mem} achieves state-of-the-art performance, demonstrating the importance of retrieval-memory coevolution.

## 2. 论文提出的方法论

### 2.1 核心思想
- 构建闭环反馈：检索策略决定记忆曝光集合，任务结果和轨迹反馈更新记忆价值与图结构，更新后的记忆库再影响下一次检索。
- 保持回答 LLM 冻结，仅学习一个轻量残差路由器，避免大规模微调。
- 采用**交替训练**（Router 阶段固定记忆库、Memory 阶段固定路由器）以缓解耦合带来的非平稳性。

### 2.2 关键技术细节
- **Self-Routed Query Rewriter (SR-QR)**：冻结 LLM 针对每个查询生成：
  - dense 改写（保留语义意图）；
  - sparse 改写（保留实体和精确词）；
  - 初始 dense-sparse 路由先验 \(p_t^0\)；
  - 置信度特征 \(\xi_t^0\)。
- **残差路由器（Residual Router）**：
  - 可训练编码器 \(\phi_\psi\) 与策略头 \(f_\omega\) 基于查询和 SR-QR 输出生成修正量 \(\Delta_t\)；
  - 最终路由策略 \(\pi_t = \operatorname{softmax}(\log \bar{p}_t^0 + \Delta_t)\)，其中输出层零初始化以保证初始策略等于 LLM 先验；
  - Router 阶段用 Beta 分布采样混合权重进行探索，测试/记忆阶段用确定性均值。
- **混合检索器（Q-Weighted Hybrid Retriever）**：
  - dense 检索（嵌入相似度）与 sparse 检索（BM25）分别返回候选；
  - 采用加权倒数秩融合（RRF）融合路由权重与学习到的记忆效用 \(Q_t\)；
  - 对初始 top-k 做时间图邻居扩展，并在扩展池上重算排序。
- **关系记忆图（Typed Relational Memory Graph）**：
  - 节点存储经验内容、稠密描述、稀疏关键词、时间元数据、来源轨迹和效用值；
  - 边类型为 Dense / Sparse / Time，分别对应检索通道；
  - 记忆构建从完整轨迹中蒸馏，保留来源轨迹与标量奖励。
- **TD 式价值更新与关系信用传播**：
  - 对曝光记忆计算残差 \(\delta_t(m)=R_t u_t(m)+\gamma \hat{Q}_t(m^{new}_t)-Q_t(m)\)；
  - 通过有向路径传播信用，路径衰减系数由边的类型决定；
  - 同步更新旧节点价值，新节点继承上下文均值作为初始效用。
- **交替协同进化**：
  - Router 阶段冻结记忆图，采样路由并更新路由器参数；
  - Memory 阶段冻结路由器，使用确定性路由并顺序更新图结构；
  - 每个阶段完整遍历训练集，反复切换使两个组件逐渐适应彼此最新状态。

### 2.3 公式/算法流程要点
- 系统目标：最大化期望任务奖励 \(J = \frac{1}{N_{ph}T}\sum_{r,t} R_{r,t}\)；
- 路由器损失 = score-function 优势项 + KL 正则项（约束偏离 LLM 先验）；
- 记忆更新为同步 TD 风格投影更新：\(Q_{t+1}(v)=\Pi_{[Q_{\min},Q_{\max}]}(Q_t(v)+\alpha_Q \Delta_t(v))\)；
- 总体训练由交替阶段执行，每个阶段调用完整的 Router 或 Memory 更新。

## 6. 论文的主要结论与发现

- 检索策略与记忆库之间的反馈循环是真实存在的，且对长期智能体性能有实质性影响。
- 将两者联合优化（CoEvo-Mem）在所有评估基准上均超过单独优化检索或记忆的方法，验证了协同进化的优势。
- SR-QR 对 GPQA Diamond、LoCoMo-MC 和 LongMemEval-MC 的提升明显，说明查询改写和路由先验对硬检索场景至关重要。
- 记忆进化（关系图与价值传播）对 GPQA、LiveCodeBench、BFCL-thinking 等任务贡献显著。
- 交替训练优于同时更新和两阶段训练，能够有效缓解耦合非平稳性。

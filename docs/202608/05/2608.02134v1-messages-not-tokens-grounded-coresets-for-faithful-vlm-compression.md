## 摘要
现代视觉语言模型（VLM）将高分辨率图像转换为长序列的视觉标记。每个标记都经过语言解码器并持续存在于其提示KV缓存中，这增加了推理成本并促使进行激进的视觉压缩。现有的基于评分的方法为每个标记分配一个独立的重要性分数并保留Top-K。然而，文本查询消耗来自视觉群体的集合性、带符号的注意力消息，而不是孤立的补丁。因此，同等大小的Top-K集合可能重复覆盖一个显著区域，遗漏稀疏但互补的证据，并丢弃被移除群体携带的信息。因此，我们将忠实的视觉压缩表述为为解码器消息构建一个紧凑的核心集，并引入我们的无训练扎根消息核心集剪枝（GMC），它联合在查询锚定、外观和坐标感知证据之间分配支持，然后在物理压缩和原生注意力恢复之前，将丢弃的状态传输到其原始多模态位置中的选定代表中。这将忠实压缩分解为两个耦合组件，包括选择覆盖所需消息模式的载体，以及在这些载体上实现有符号群体消息。我们进一步推导出将它们的错误与有符号消息失真、视觉创新和候选边缘稳定性联系起来的界限。跨多个VLM家族和不同基准的实验证明了强大的性能，GMC-H2在使用80.2%更少的视觉标记的情况下，在Qwen2.5-VL-7B上保持了97.78%的全相对平均能力，而GMC-L16达到了100.36%。受控干预验证了集体支持和群体实现共同驱动了这些增益。

## Abstract
Modern vision language models (VLMs) turn high-resolution images into long sequences of visual tokens. Every token traverses the language decoder and persists in its prompt KV cache, inflating inference cost and motivating aggressive visual compression. Existing score-based methods assign each token an independent importance score and retain the Top-K. However, text queries consume collective, signed attention messages from the visual population, not isolated patches. Consequently, equally sized Top-K sets can repeatedly cover one salient region, omit sparse but complementary evidence and discard information carried by the removed population. We therefore formulate faithful visual compression as constructing a compact coreset for decoder messages, and introduce our training-free Grounded Message Coreset Pruning (GMC) which jointly allocates support across query-grounded, appearance, and coordinate-aware evidence, then transports discarded states into selected representatives at their original multimodal positions before physical compaction and native attention resume. This decomposes faithful compression into two coupled components, including selecting carriers that cover the required message modes and realizing the signed population message on those carriers. We further derive bounds connecting their errors to signed-message distortion, visual innovation, and candidate-margin stability. Experiments across multiple VLM families and diverse benchmarks demonstrate strong performance, with GMC-H2 retaining 97.78% Full-relative mean capability on Qwen2.5-VL-7B using 80.2% fewer visual tokens, while GMC-L16 reaches 100.36%. Controlled interventions verify that collective support and population realization jointly drive these gains.

## 一、核心问题与研究动机

- **背景**：现代视觉语言模型（VLM）将高分辨率图像编码为长序列视觉 token，每个 token 都会经过语言解码器并长期占用 prompt KV 缓存，导致推理成本随分辨率急剧上升。视觉压缩成为加速 VLM 推理的关键手段。
- **现有方法的不足**：主流方法（如 FastV、VisionZip 等）将压缩归结为一个标量问题——为每个 token 计算独立重要性分数并保留 Top-K。但这类方法有三个核心缺陷：
  1. 同等大小的 Top-K 集合可能重复覆盖同一个显著区域，忽略互补但稀疏的证据；
  2. 文本查询实际上消费的是视觉群体的*集体性、带符号的注意力消息*，而非孤立 patch 的独立分数；
  3. 硬删除直接丢弃剩余视觉群体携带的信息，而独立选择支持后拼接也无法解决"在何处保留证据"与"每个代表应携带什么"的解耦问题。
- **核心洞察**：忠实压缩应当构建一个"扎根消息核心集"（Grounded Message Coreset）——支持分配（在哪里保留互补证据）与消息实现（每个代表承载什么信息）是两个耦合组件，缺一不可。

## 二、方法论：GMC（Grounded Message Coreset Pruning）

### 2.1 核心思想
将忠实视觉压缩形式化为：构建解码器消息的紧凑核心集，联合确定互补证据的保留位置与删除信息的迁移方式，并保留原始多模态坐标。

### 2.2 边界消息几何（Boundary Message Geometry）
- 在解码器第 p 层前，使用原生 RMS 归一化、M-RoPE、因果掩码和 Q/K/V 投影计算视觉列注意力切片 Aₕ。
- 对每个头 h 和组件 c，定义投影消息原子：u = A[t,i]·[(V[i]Oₕ)P; σ]，其中 P 为固定 rank-4 正交探针，σ 为注意力质量齐次坐标。
- 将正能量注意力行的归一化范数作为非负载体责任分布 P_G，用于支持分配；带符号的向量本身则用于传输与消息实现。

### 2.3 三类客户端（Clients）——支持分配的来源
- **查询扎根客户端（Grounded Clients）**：基于原生 head-query 注意力贡献，覆盖已被文本查询访问的证据。
- **外观客户端（Appearance Clients）**：基于归一化特征余弦相似度（Gibbs 核），保护尚未被 prompt 激活的视觉结构。
- **空间客户端（Spatial Clients）**：基于原始网格坐标的径向锚点，防止支持坍缩到单一显著区域，保留空间关系。

### 2.4 互补覆盖求解器
- 目标函数为加权设施选址覆盖：F(S) = Σₘ maxᵢ∈S C̄ₘᵢ（归一化、单调、子模）。
- 使用批量贪心：每轮计算残差责任，构建 top-4b 候选池，通过 softmax 分配责任，b=16 个 token 同时进入，逐轮迭代至预算 K。
- 多图 prompt 每图先初始化一个代表 token，保证图像兼容。
- 支持提供 (1-e⁻¹) 型批量进度证书和最终覆盖饱和度审计。

### 2.5 群体传输（Population Transport）
- 每个源 token 分配给图像兼容的最近代表：基于余弦相似度 + 空间门控项（清晰语义匹配全局传输，模糊局部细节就近分配）。
- 计算加权质心：cⱼ = Mⱼ⁻¹ Σ mᵢhᵢ，再用 RMS 恢复保持载体原始尺度。
- 传输前，群体会在任意线性映射下精确保持有符号一阶矩（ΣMⱼWcⱼ = ΣmᵢWhᵢ），即不丢失方向性取消信息。
- 删除未选定视觉位置，保留代表 token 的原始多模态位置 ID，从第 p 层起以 K 个视觉状态继续原生前向。

### 2.6 理论分析
- **Prop.1**：部署的批量求解器具有归一化、单调、子模性质，给出批量进度证书。
- **Prop.2（消息接口界）**：压缩误差分解为两个可审计项——覆盖控制的载体量化误差与传输/紧凑注意力控制的带符号消息误差；候选排序稳定性由余量不等式和全词汇概率界刻画。
- 区分了**非负载体能量**（用于分配）与**带符号消息实现**（用于传输），指出 {v,v} 与 {v,-v} 责任相同但消息和分别为 2v 与 0。

## 六、主要结论与发现

1. **支持分配与群体实现是两个不可互相替代的组件**：覆盖误差与传输误差加性地进入同一消息界；交叉干预验证了二者独立贡献。
2. **GMC 在严重预算下显著超越现有方法**：K=128 时 Qwen 宏平均领先 HAWK 约 6 个点；K=256 时 L16 达到甚至超过 Full 水平。
3. **L16 为高保真紧凑提示点，H2 为计算高效点**：两者共享同一最终 K 但解码器工作量不同（L16 保留 61.38% 视觉 token 层工作，H2 仅 16.31%）。
4. **群体消息具有可迁移性**：在 LLaVA 不同视觉编码器/投影仪/解码器上同样有效，低预算下消息通路增益 +4.00（TextVQA）。
5. **候选对数几率误差是伤害性翻转的最强预测因子**（AUROC 约 0.83-0.89），支持了消息级误差传播到决策边界的理论路径。

## 七、优点

1. **问题重新定义深刻**：将压缩从"独立 token 重要性"提升到"群体消息核心集"，切中 VLM 注意力聚合的本质。
2. **训练免费、即插即用**：无需微调、无外部模型/检测器/OCR、无梯度，仅访问原生 Q/K/V 和注意力切片，易于部署到现有模型。
3. **保留原始多模态坐标**：M-RoPE 位置不变，让原生紧凑注意力在正确的几何上下文中工作，避免位置扰动带来的额外误差。
4. **理论支撑完整**：从子模覆盖到消息传输到候选余量，给出了端到端的误差分解与可审计证书，而非仅凭经验调参。
5. **实验严谨**：配对统计、Holm 校正、共享 Full 分母、等 Work 比较、same-path 对照，多维度验证了机制而非仅比分数。
6. **长前缀文档场景验证真实落地的收益**：在 KV 缓存减少 74% 的同时实现加速，说明方法不仅学术有效且有工程价值。

## 八、不足与局限

1. **固定配置可能非最优**：所有超参数（质量 0.5、空间 0.25、τv=0.2、τs=0.02 等）为全局冻结，对不同数据集/模型可能存在更优组合，未做逐数据集的随机搜索。
2. **H2 的推理开销未完全披露**：在 1,296 token 标准前缀下，压缩阶段耗约 64-66 ms，其中选择占 38-41 ms。短任务下端到端加速有限（GMC-H2 在 K=128 时仅 1.031×，且速度未必优于 FastV-style 的 1.146×）。
3. **长前缀加速依赖缓存实现**：端到端 1.258× 加速来自缓存 A800 路径，且质量评估仅基于 300 个 DocVQA 样本（质量全集用于通路消融，但部署质量集较小）；H800 无缓存路径的最大加速仅 1.041×。
4. **"Full 为上限"的隐含假设可能不成立**：GMC-L16 在多个数据集上超过 Full（如表 1 中 ChartQA 102.49%），说明压缩偶然去除了某些干扰信息，但这与"忠实压缩"的定义存在张力——超 Full 性能可能意味着 Full 本身并非理想参照。
5. **理论界依赖 Lipschitz 常数与局部假设**：Prop.2 的界中包含局部 Lipschitz 常数（未系统测量）、RMS 恢复残差、紧凑注意力质量差等，实际可操作性与预测性有限；输出无翻转证书仅覆盖 21.6% 的案例。
6. **单一步骤的共享历史分析**：VIE 诊断使用共享提示历史，而真实自回归解码中历史会发散；与全输出指标的连接主要依赖经验关联而非严格传播界。
7. **外部泛化验证有限**：仅测试两个模型家族（Qwen2.5-VL-7B 与 LLaVA-1.5-7B），未覆盖更大规模（如 70B+）或更新架构（如 Qwen3-VL、LLaVA-1.6+）；也未报告多图复杂交互场景的系统评估。
8. **论文的时间戳与描述存在自查风险**：arXiv 编号（2608.02134）与发表时间（2026 年）暗示这是一篇 preprint，部分引用的对比方法（如 HAWK、MMTok）也指向 2026 年发表，读者需警惕内容中的虚构元素或未来的非标准审阅状态。

## 九、一句话总结

GMC 将 VLM 视觉压缩重新定义为"构建解码器消息的扎根核心集"，通过互补支持分配与群体传输共同保存带符号的集体注意力消息，在 80-90% 的 token 缩减下达到接近乃至超过 Full 的性能，为该领域提供了新的理论视角与实用基线。

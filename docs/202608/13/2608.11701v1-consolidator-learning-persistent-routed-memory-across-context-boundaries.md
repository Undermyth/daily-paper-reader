## 摘要
将短期记忆（STM）复制到较慢的存储中可以跨上下文边界保持状态，但仅保持并不能确保保留的状态影响后续的记忆访问。我们在相量记忆网络（PMNet）中使用整合器（Consolidator）来测试这一区别。整合器是一种共享的槽位局部算子，在将路由的STM累积到长期记忆（LTM）之前对其进行变换，而不重放源令牌。每次整合后，KV缓存和STM都被清除。保留的LTM仍可被读取，并且也被馈送到分层路由器，从而调节后续输入所访问的显式记忆槽位。我们在一个两段式的模10映射任务上评估该机制，其中第二段在同一记忆地址更新映射。在第二次整合和重置之后，一个留出的查询必须从LTM中恢复更新后的映射。骨干网络和记忆接口被冻结，只剩下12.35K个可训练的整合器参数（占29.95M模型的0.041\%）。在来自相同STM预训练检查点的五组成对运行中，直接LTM路由将更新映射的召回率从$44.38\pm1.94\%$提高到$87.02\pm1.76\%$（+$42.64\pm1.10$个百分点），而两种条件下的即时STM召回率均保持89.90\%；两者都训练了单独的整合器并保留相同的LTM读取路径。学习到的整合在无路由情况下比强制恒等累积高$21.40\pm1.91$个百分点，在有路由情况下高$68.70\pm1.76$个百分点。因此，在此任务上，整合后的LTM既作为可检索的内容，又作为影响后续槽位选择的访问状态。

## Abstract
Copying short-term memory (STM) into a slower store can preserve state across a context boundary, but persistence alone does not ensure that the retained state influences subsequent memory access. We test this distinction in a Phasor Memory Network (PMNet) using Consolidator, a shared slot-local operator that transforms routed STM before accumulating it into long-term memory (LTM), without replaying the source tokens. After each consolidation, the KV cache and STM are cleared. The retained LTM can still be read and is also fed into the hierarchical router, thereby conditioning which explicit-memory slots subsequent inputs access. We evaluate this mechanism on a two-segment modulo-10 mapping task in which the second segment updates the mapping at the same memory address. Following a second consolidation and reset, a held-out query must recover the updated mapping from LTM. The backbone and memory interface are frozen, leaving only 12.35K Consolidator parameters trainable (0.041\% of a 29.95M model). Across five paired runs from the same STM-pretraining checkpoint, direct LTM routing raises updated-mapping recall from $44.38\pm1.94\%$ to $87.02\pm1.76\%$ ($+42.64\pm1.10$ percentage points), while immediate STM recall remains 89.90\% in both conditions; both train separate Consolidators and retain the same LTM read paths. Learned consolidation outperforms forced identity accumulation by $21.40\pm1.91$ percentage points without routing and $68.70\pm1.76$ with routing. Thus, on this task, consolidated LTM serves as both retrievable content and an access state that shapes subsequent slot selection.

## 1. 论文的核心问题与整体含义

- **研究动机**：Transformer 的上下文本质上是"只追加"的 token 和 KV 历史记录，难以在上下文边界之后保留状态并影响后续计算。虽然将短期记忆（STM）复制到慢速存储（如长时记忆 LTM）可以实现跨边界的状态保留，但**仅仅持久化并不能保证保留的状态会影响后续的记忆访问**（即"持久性 ≠ 可用性"）。
- **核心研究问题**：
  1. 固定的预训练记忆接口是否需要**学习到的转换**来修订冲突内容，而非原始累积？
  2. 保留的 LTM 是否不仅通过读路径提供值，还能作为**访问状态**（access state）影响路由器对后续写入/读取槽位的选择？
- **整体含义**：该论文在机制层面验证了一个"记忆生命周期"概念——短期记忆经由学习到的整合算子变为长期记忆，而长期记忆本身又作为层级路由器的输入，影响未来的记忆访问。这是对"持久化路由记忆"功能链的受控验证，而非面向自然语言或大规模系统的工程声明。

## 2. 论文提出的方法论

- **基础架构**：以 Phasor Memory Network（PMNet）为基础。PMNet 将记忆维度表示为相位角，通过分层路由器将 token 写入显式记忆槽位；写入是软性的（所有兄弟节点都获得可微相位更新），而层级间的遍历是硬 top-1。
- **核心组件：Consolidator（整合器）**
  - 一个**共享的、槽位局部的门控相位变换算子**，参数仅 12.35K（占 29.95M 模型的 0.041%）。
  - 输入为被占用的 STM 槽位相位向量 S，先转换为 [cos S; sin S] 的复数坐标形式，经门控 MLP（SiLU 门控 + 元素级复数乘法）处理后，通过 atan2 变换回相位角：
    - 变换初始化为**恒等映射**（零输出权重 + 单位相量偏置），因此训练从精确复制开始。
  - 该算子**不依赖于树拓扑**，无论记忆容量大小，参数量固定，不随层级/槽位规模增长。
- **记忆生命周期流程**
  1. Token 写入被路由的 STM（短期记忆）。
  2. 在段边界，Consolidator 将 STM 变换后**累积**到 LTM（按占用掩码决定哪些组被整合）：$L^+ = (L + C_\psi(S)) \bmod 2\pi$。
  3. 随后清除 KV 缓存和 STM，但**保留 LTM**。
  4. 后续段中，LTM 既可通过读路径被读取，也被直接加到路由器的候选槽位得分中：$a_{t,b,g,j} = u_{t,b,g,j} + e_{b,g,j} + L_{b,g,j}$，使固定路由器获得经验依赖的槽位选择能力，形成循环路径 $S_t \xrightarrow{C_\psi} L_t \to a_{t+1} \to S_{t+1}$。
- **"无重放"的含义**：每个演示段沿主序轨迹只出现一次，Consolidator 仅接收路由后的 STM 和占用掩码，不重新编码原始 token，也不从回放缓冲区取回内容。但无重放不等于免 BPTT——两段式实验保留了跨两个整合边界的可微图。
- **训练目标**：主实验仅优化第二段整合后、重置前的最终查询损失（updated-mapping LTM recall）。另有双目标实验，添加了每段整合前的即时 STM 查询损失，检验两种能力能否共存于一组参数。

## 3. 实验设计

- **任务场景**：受控的两段式"顺序同地址更新"任务（Sequential Same-Address Update Task）。
  - 记忆片段由两个上下文段组成，每段 8 个演示 + 1 个留出查询，编码为 [地址, 规则族, 输入 x, 分隔符, 答案 y]。
  - 规则族有两种：**ADD10**（y = (x + k) mod 10）和 **AFFINE10**（y = (ax + b) mod 10），参数逐片段重新采样。
  - 第二段在同一地址更新映射（不同函数参数）；最终查询在两个映射下答案不同，因此不能靠复制旧答案或观察到的答案得分。
  - 每片段 40 个 token，均在局部注意力窗口（128）内。
- **两阶段训练协议**：
  - Phase 1（STM 预训练）：训练同段规则归纳（STM 读取能力），Consolidator 冻结；所有条件共享同一检查点。
  - Phase 2（整合训练）： 两段依次处理、每段后整合并清除 KV/STM，最终查询仅能依赖 LTM。
- **对比条件**：
  - **Learned full**（全模型可训练，学习型整合）vs **Identity full**（全模型可训练，恒等累积）。
  - **Consolidator only**（仅 12.35K Consolidator 可训练，直接 LTM 路由开启）vs **Consolidator only, routing off**（移除式 7 中的直接 LTM 项，其余保留）。
  - **强制恒等**：同一检查点下用原始 STM 直接累积替换学习型变换。
  - **错配经历控制**（mismatched experience）：用相同规则族但不同参数的他人经历替换，保留地址和规则族提示。
  - **新鲜记忆控制**（fresh LTM）：无持久记忆。
  - **双目标实验**：仅更新 LTM 目标 vs 更新 LTM + 即时 STM 目标（全模型可训练）。
  - **Memory + Consolidator**：训练记忆读写/路由路径 + Consolidator。
- **评估数据集**：程序生成的记忆片段，验证集与测试集各 1K 片段，训练每 epoch 100K 片段。主对比使用五个固定种子（42–46）的配对运行和共享固定测试流。
- **基准指标**：更新映射 LTM 召回率（最终查询准确率）、第二段即时 STM 召回率、平均即时 STM 召回率、错配/新鲜 LTM 控制。

## 6. 论文的主要结论与发现

1. **学习型整合能实现持久的同地址更新**：仅训练 12.35K 参数（0.041%），更新映射 LTM 召回率达 87.02%，而同一检查点强制恒等累积仅 18.32%（+68.70 个百分点）。
2. **LTM 是"访问状态"而非仅为存储内容**：直接 LTM 路由开启使召回率从 44.38% 提升至 87.02%（+42.64 个百分点），而两条件的即时 STM 召回率均恰好一致（89.90%），说明提升来自路由路径而非 STM 质量差异。
3. **无直接路由时，学习型整合仍优于恒等累积**（+21.40 个百分点），说明 LTM 经读路径已提供价值；直接路由增益更大。
4. **召回依赖正确的经历内容**：用错配经历替代正确经历后，召回率从 87.02% 跌至 9.30%（接近 10% 随机水平），排除固定地址关联解释。
5. **STM 与 LTM 能力可共存**：添加即时 STM 监督后，平均即时召回从 11.39% 升至 95.76%，更新 LTM 召回保持 95.58%（变化无统计学意义）。
6. **机制级证明，非系统级声明**：全模型可训练条件下学习型并未显著优于恒等（+2.36 pp，p 不显著），因此结论限定于冻结骨干 + 学习边界的场景。

## 7. 优点

- **概念清晰、机制分离**：将"携带状态过重置、修订既有记忆、检索保留内容、用 LTM 指导槽位选择"四种记忆功能拆分为可独立检验的实验设计。
- **参数效率与可扩展性**：Consolidator 是共享槽位局部算子，参数不随树容量增长；从恒等初始化保证训练稳定性。
- **严格的参数隔离**：冻结 99.959% 模型、只训练边界算子，能干净地将增益归因于整合变换而非骨干调整；路由开关保持相同参数量，进一步隔离访问状态的作用。
- **控制实验全面**：错配经历、新鲜记忆、强制恒等、双目标等从多个角度排除了混淆解释。
- **诚实定位**：论文明确声明这是"机制层面的概念验证"，不夸大对自然语言长上下文、持续学习或系统效率的适用性，并明确列出局限。

## 8. 不足与局限

- **任务与场景狭窄**：仅两段短上下文、单地址、模 10 规则；演示上下文全部落在局部注意力窗口内，未测试极端长上下文、多地址竞争、自然语言或持续学习场景。
- **统计效力有限**：n = 5，置信区间和 t 检验为描述性；五个 Consolidator-only 种子共享单个 STM 预训练表示，未包含 Phase-1 训练的随机性。
- **训练未截断**：保留跨两个整合边界的完整 BPTT 图，未测试截断或解耦的长时间训练；在更长记忆片段上的可扩展性未知。

## 摘要
全自注意力是不规则域上PDE代理模型的强大标记混合器，但其二次成本限制了其在高分辨率问题上的使用。诸如快速低秩注意力路由引擎(FLARE)之类的高效潜在注意力模型通过将所有N个标记路由到M << N个学习到的潜在查询来避免该成本，但这些查询是参数：一旦训练完成，相同的学习查询模板将服务于每个输入。我们通过FLARE++（一种具有动态标记路由的低秩注意力架构）消除了这一限制。FLARE++重用FLARE自身的编码器来构建其路由查询：学习到的潜在种子驱动一次额外的编码调用，将N个输入标记聚合成M个输入条件查询，然后这些查询决定相同标记如何被压缩和重新分配。这保留了FLARE的显式低秩分解和线性O(NM)复杂度，并且仅用标准缩放点积注意力(SDPA)调用即可表达完整的路由操作。我们还提供了一种多GPU上下文并行实现，该实现将输入标记分片到不同设备上，而无需在任何一个设备上收集完整的标记序列。FLARE++在一组标准PDE代理基准上具有竞争力，比固定查询FLARE平均提高24%，并在Long Range Arena上平均准确率提高2.3个百分点。

## Abstract
Full self-attention is a strong token mixer for PDE surrogates on irregular domains, but its quadratic cost limits its use on high-resolution problems. Efficient latent-attention models such as the Fast Low-rank Attention Routing Engine (FLARE) avoid that cost by routing all N tokens through M << N learned latent queries, but those queries are parameters: once trained, the same learned query templates serve every input. We remove this restriction with FLARE++, a low-rank attention architecture with dynamic token routing. FLARE++ reuses FLARE's own encoder to build its routing queries: learned latent seeds drive one extra encode call that gathers the N input tokens into M input-conditioned queries, and those queries then determine how the same tokens are compressed and redistributed. This preserves FLARE's explicit low-rank factorization and linear O(NM) complexity, and expresses the complete routing operation with standard scaled dot-product attention (SDPA) calls alone. We also provide a multi-GPU context-parallel implementation that shards input tokens across devices without ever gathering the full token sequence on one of them. FLARE++ is competitive across a set of standard PDE surrogate benchmarks, improving on fixed-query FLARE by 24% on average, and it gains 2.3 points of average accuracy on Long Range Arena.

# FLARE++：具有动态注意力路由的低秩注意力——论文详细总结

## 1. 核心问题与研究动机

- **背景**：全自注意力（Full Self-attention）是不规则域上 PDE（偏微分方程）代理模型（surrogate）的强大 token 混合器，能让每个离散化点与其他所有点通信；但其 **O(N²) 复杂度**在工程实际网格规模下不可行。
- **已有方案**：FLARE（Fast Low-rank Attention Routing Engine）通过 **M ≪ N 个学习到的潜在查询** 实现低成本路由，将所有 N 个 token 压缩到 M 个潜在槽位再分发回去，复杂度降为线性的 O(NM)。FLARE 的查询是**学到的参数**，训练完成后对所有输入使用同一组固定模板——即压缩模板永远看不到它要压缩的场（field）。
- **核心问题**：FLARE 的固定查询模板与输入无关，限制了秩-M 瓶颈的分配方式。作者认为，模板的来源（固定参数 vs 由输入动态构造）才是区分各种高效注意力方法的关键维度。
- **解决思路**：FLARE++ 让输入 token 自身参与构造压缩模板——每个样本、每一层都重新合成随输入变化的路由查询，同时保持低秩分解、线性复杂度和纯标准 SDPA 实现。

## 2. 方法论

### 核心思想
FLARE++ **复用 FLARE 自己的编码器**来构建路由查询：用学习到的潜在种子（latent seeds）作为查询，额外执行一次编码调用，将 N 个输入 token 聚合成 M 个**输入条件化查询**；这些动态查询再用于后续的编码-解码（gather-scatter）路由操作。

### 关键技术细节

**1. FLARE 回顾（固定查询路由）**：
- 每头独立持有学习查询 Qh ∈ R^{M×D}，键和值来自当前输入：Kh = XW^{K,h}, Vh = XW^{V,h}
- 两次 SDPA 调用构成秩至多 M 的编码-解码分解：
  - 编码：Zh = SDPA(Qh, Kh, Vh)（N token → M 潜在值）
  - 解码：Yh = SDPA(Kh, Qh, Zh)（M 潜在值 → N token）
- 有效路由矩阵 Weff,h = Wdec,h · Wenc,h ∈ R^{N×N}，秩 ≤ M，从不显式物化

**2. FLARE++ 动态查询合成**：
- 额外的键值投影：ẽKh = X fW^{K,h}, ẽVh = X fW^{V,h}
- 一次 SDPA 调用合成路由查询：
  Qh(X) = SDPA(ẽQh, ẽKh, ẽVh) = softmax(ẽQh ẽKhᵀ / √D) ẽVh ∈ R^{M×D}
- 合成的查询随后用于 FLARE 算子的两个因子：Zh = SDPA(Qh(X), Kh, Vh), Yh = SDPA(Kh, Qh(X), Zh)
- 等效路由矩阵 Wdec,h(X)·Wenc,h(X) 秩 ≤ M，但由输入决定

**3. 架构不变性**：所有修改仅限于路由查询的构造；残差流（residual stream）的块数 B、宽度 C、归一化、残差连接和输入/输出投影均与 FLARE 相同。查询合成分支的输出仅作为查询使用，不加入 token 表示，因此不增加残差深度，也没有引入潜在工作区（latent-workspace）模型的潜在自注意力阶段。

**4. 复杂度**：
- FLARE：O(N(3C² + 2MC))；FLARE++：O(N(5C² + 3MC))
- 两者在时间上都是 N 的线性，空间 O(NC)；全自注意力为 O(N²C)
- 额外开销来自两个 C×C 投影和一次额外的 token-潜在 SDPA 调用

**5. 多 GPU 上下文并行**：
- 将 token 维按 R 个 rank 分片，点式投影、归一化、FFN 均为局部操作
- 唯一全局耦合的原语是编码器：每个 rank 计算局部 SDPA 输出 Or 和行对数归一化器 Lr，通过 log-sum-exp 精确合并：L = logsumexp_r(Lr), Z = Σr exp(Lr − L)·Or
- 通信负载 O(BHM(D+1))，与 N 无关；无需 all-gather 完整 token 序列
- 反向传播必须对全局归一化注意力求导（含跨分片的概率质量再分配项），而非各 rank 独立归一化

## 6. 主要结论与发现

1. **动态路由全面优于固定查询**：在 21 个匹配的 (M,B) 单元中，FLARE++ 全部优于 FLARE，相对误差降低 21–53%。
2. **固定查询在 M 上饱和，输入条件化查询不饱和**：Elasticity 上增大 M 从 32→128 时 FLARE 在多数深度下变差，而 FLARE++ 持续改善；说明固定模板增大的路由在跨输入时大量冗余。
3. **动态路由可替代深度**：在 B=4 时 FLARE++ 比 B=8 的 FLARE 更准确（潜在预算 7 个单元全部成立），即"减半深度"可成立。
4. **成本可控**：FLARE++ 步时间约为 FLARE 的 1.3–1.5×、峰值内存 1.18×，随 N 持平；低于算术预测的 1.6×，因为额外工作主要是接近峰值性能的稠密投影而非注意力。
5. **上下文并行扩展性优秀**：4 rank 下时间效率 ≥0.92、内存效率 ≥0.95，通信负载与 N 无关，支持更大网格训练。
6. **误差结构不变**：FLARE 与 FLARE++ 的点误差图结构相似、仅幅度不同，说明动态路由改变的是"秩-M 算子消除多少固定误差结构"，而非能表示哪些特征。

## 7. 优点

- **方法极简优雅**：完全复用 FLARE 已有的编码机制，仅增加一次标准 SDPA 调用，无需新内核、无自定义注意力算子
- **理论性质保持**：显式秩-M 编码-解码分解、线性复杂度、每个头独立通路、融合 SDPA 实现全部保留
- **干净的归因设计**：将改动严格限制在模板构造，残差流不动，使精度差异可归因于路由机制本身
- **诚实的成本报告**：不回避 1.3–1.5× 速度代价，并给出操作计数、实测时间、内存的多层对照
- **精确的分布式实现**：上下文并行的 log-sum-exp 合并是代数等价的精确算法，通信负载与 N 无关
- **深入的分析维度**：涵盖精度、成本、消融、精度敏感性和定性误差分布，分析全面

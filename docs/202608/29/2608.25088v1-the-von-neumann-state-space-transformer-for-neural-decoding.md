## 摘要
皮层计算具有惊人的低维性：少量潜在变量承载于神经群体的活动中，引导着单个神经元的高维响应。我们的目标是样本效率——即从有限的数据和较小的参数预算中实现良好解码的模型。在标准 Transformer 层中，前馈块对每个词元应用相同的算子。我们提出一个受冯·诺依曼启发的假设，将高效计算作为神经解码的一种替代方案：控制器解码指令，然后执行特定于词元的算子；通常的实现——专家软混合——仅混合它们的输出，而非算子。我们引入了冯·诺依曼状态空间 Transformer（VN-SST），一种记忆增强的 Transformer，其前馈块是一个低秩指令库：一个共享基算子加上一小组学习到的低秩指令，每个词元的编码从中合成该词元实际使用的权重矩阵。该编码从携带的状态空间记忆的低维投影中读取，因此缓慢的潜在轨迹充当指令指针——反映了低维动力学如何引导皮层计算。在三个运动皮层神经解码基准上，VN-SST 比现代 Transformer 的数据效率高得多，每个基准都联合预测脉冲和解码行为。该模型在数据最稀缺的基准上以很大优势获胜，在其他两个基准上领先，并将更长的上下文转化为准确率的提升而非下降。我们评估了网络将大型指令库压缩为每个词元几个比特，因此程序容量充当控制通道，而非准确率杠杆。同一模型在两个用于语言建模（LLM）的小型文本基准上也更具参数效率，这表明了一种通用机制。

## Abstract
Cortical computation is strikingly low-dimensional: a handful of latent variables, carried in a neural population's activity, steer the higher-dimensional responses of individual neurons. Our aim is sample efficiency-models that decode well from limited data and at small parameter budgets. In a standard Transformer layer, the feed-forward block applies the same operator to every token. We suggest a von-Neumann inspired hypothesis of efficient computation as an alternative for neural decoding: a controller decodes an instruction and then executes a token-specific operator; the usual realization-a soft mixture of experts-only blends their outputs, not operators. We introduce a von-Neumann State-Space Transformer (VN-SST), a memory-augmented Transformer whose feed-forward block is a low-rank instruction bank: a shared base operator plus a small set of learned low-rank instructions, from which a per-token code synthesizes the weight matrix actually used at that token. The code is read from a low- dimensional projection of a carried state-space memory, so a slow latent trajectory acts as an instruction pointer-mirroring how low-dimensional dynamics may route cortical computation. On three motor-cortex neural-decoding benchmarks, VN-SST is far more data-efficient than a modern Transformer, each jointly predicting spikes and decoding behavior. This model wins by a wide margin on the scarcest benchmark, leads on the other two, and turns longer context into rising rather than falling accuracy. We evaluated that the network compresses a large instruction bank to a few bits per token, so program capacity acts as a control channel, not an accuracy lever. The same model is also more parameter-efficient on two small text benchmarks used for language modeling (LLMs), suggesting a generic mechanism.

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- 将冯·诺依曼存储程序机结构映射到 Transformer 层中：
  - **持久化状态空间/快速权重通路** = 存储器（memory），承载跨 token 状态；
  - **低维状态读出** = 指令指针（program counter），选择下一个算子；
  - **控制器** = 将指针解码为每 token 的指令编码；
  - **可编程 SwiGLU** = 执行单元（execution unit），其权重由该指令编码实时合成。

#### 模型结构：VN-SST 的三条并行记忆通路
- **通路 1——局部感觉缓冲**：因果带状注意力（LocalAttn），仅捕获窗口内局部短程结构，复杂度 O(Tw)。
- **通路 2——选择性状态空间（SSM）**：对角输入依赖 SSM，携带逐通道隐状态，构成跨片段的**慢动力学**通路。关键公式：
  - 状态更新：`st = Āt ⊙ s(t-1) + (Δt xt) ⊗ Bt`
  - 读出：`yssm_t = ⟨st, Ct⟩ + D ⊙ xt`
  - 该读出 `yssm` 是慢状态的低维投影，被用作**指令指针**。
- **通路 3——快速权重联想记忆**：δ-规则矩阵记忆，进行内容寻址的读写操作。关键公式：
  - 记忆更新：`Mt = M(t-1) + wMt kt(vt − kt^T M(t-1))^T`
  - 读取：`ymem_t = Wo(qt^T Mt)`
- **融合**：三条通路的输出由控制器读门加权融合，加回残差流。

#### 可编程计算：低秩指令库（核心创新）
- 公式核心：`W(t) = W0 + Σ(k=1...K) c(t,k) · Uk · Vk^T`
  - 共享基础算子 `W0` 加上 `K` 个低秩"指令"（秩为 r），由每 token 编码 `ct` 选择合成实际权重矩阵。
- **关键实现细节**：不显式物化每 token 权重，而是通过"先投影到低秩库、按编码缩放、再投影读出"的方式等效计算，每 token 额外开销仅 O(Kr(d+dff))。
- **指令指针的具体实现**：`ct = tanh(MLP([ut ; P·yssm_t]))`——编码由 token 与 SSM 慢状态的低维投影共同决定，从而让慢轨迹选择每个 token 实际执行的算子。

#### 训练策略
- 截断的反向传播（truncated BPTT）：序列按段处理，状态跨段传递，每几段分离梯度。
- SSM 和 δ-规则记忆均使用精确并行形式（对数深度结合扫描、分块 WY 三角求解），实现 GPU 向量化训练。

### 6. 论文的主要结论与发现

1. **数据效率显著领先**：
   - 在有限数据预算下（最稀缺的 MC RTT），VN-SST 解码 R² = 0.351 vs 0.207（Transformer），线性解码器为负值（-0.236），优势巨大；
   - 在全部三个数据集、所有数据预算下，VN-SST 至少不弱于 Transformer，且在数据最紧时优势最大。

2. **更长的上下文物有所值（VN-SST 独有）**：
   - 在 MC RTT 上，Transformer 增长上下文时解码精度下降（0.612→0.57），而 VN-SST 反而上升（0.60→0.68），形成交汇点——携带的状态将额外上下文转化为精度；
   - 在数据充足的 MC Maze 和 Area2 Bump 上两者均接近饱和，VN-SST 略高且更平缓。

3. **指令库是控制通道，不是精度杠杆**：
   - 给定 K=32 条指令，网络实际仅使用约 2.55–3.20 bit 的编码（上限 5 bit），有效算子数为 3.4–6.5 个；
   - 解码 R² 在 K 变化时基本平坦非单调——程序容量不驱动精度，而是作为压缩/控制信号。

4. **跨模态泛化（语言建模补充验证）**：
   - 同一 VN-SST 在 tiny-Shakespeare 和 WikiText-2 上均比 Transformer 更参数高效，且具有更陡的幂律斜率；
   - 在最大预算下达到最佳困惑度（49 vs 61；45 vs 52），约需 2–3 倍更少的参数即可达到 Transformer 的最佳表现。

5. **整体论断**：在小数据、小模型的实际神经记录场景下，有用的归纳偏置不是更多参数，而是**由低维动力学引导的可编程算子**——计算像其建模的皮层一样，运行在少量精选的指令上。

### 7. 优点

#### 方法创新方面
- **概念转化清晰**：将冯·诺依曼存储程序架构映射到现代深度序列模型，不是比喻层面而是真正的机制实现——"合成算子而非混合输出"；
- **低秩指令设计精巧**：基础算子+低秩修正，避免物化大矩阵，每 token 额外计算量 O(Kr(d+dff)) 远低于 MoE 专家的成本，接近"免费"实现可编程；
- **指令指针选择自然**：直接采用 SSM 慢状态的低维投影，完美呼应神经科学中"低维动力学路由皮层计算"的直觉。

#### 实验设计方面
- **三轴缩放分析**（参数、数据、上下文）系统全面，且上下文实验中匹配了更新步骤数，严谨避免了常见混淆；
- **控制位诊断实验独树一帜**，让"程序使用率"可量化——这是任何输出混合方法无法报告的属性，增强了冯·诺依曼论断的可信度；
- **跨模态验证**扩展了结论的适用范围；固定深度+宽度缩放的协议去除形状混杂。

#### 结果方面
- 在数据最匮乏的场景给出了极大的收益（R² 0.35 vs 0.21），这正是神经科学实际应用中最重要的使用场景；
- 长上下文→精度提升的性质对实践具有重要意义。

- 参数匹配策略（VN-SST 窄宽 + Transformer 宽宽对齐总参数）可能使 Transformer 处于不利状态——FFN 更宽但层形态受限，未排除"Transformer 在该参数范围内本身处于欠拟合"的混淆；
- 未报告单次 seed 的方差，无法评估优势的统计显著性；
- 固定深度为 4 层的选择不一定对 Transformer 最优。

#### 理论/应用层面的局限
- 论文未对该方法在模型容量极大、数据极多时的行为给出预测——指令合成在高计算预算下是否仍优于简单的大 FFN 开放；
- 控制位诊断仅证明模型"使用"少量指令，未提供关于这些实际指令内容、语义及其可解释性的分析（作者也承认这是未来工作）；
- 单作者机构（BrainCo）验证，缺乏独立第三方复现。

## 摘要
本文提出了一种基于集合论和超维计算的全新心智计算理论。与依赖连续权重和矩阵乘法的传统神经网络不同，该框架处理稀疏二进制数据，将信息表示为离散集合，直接模拟生物神经群体编码。研究表明，联想记忆自然产生于具有组合扩展隐藏层的网络拓扑结构中，学习由拓扑可塑性而非标量权重调整驱动。该架构将自联想学习和异联想学习统一于单一核心算法：通过子集模式匹配和精确最近邻搜索实现信息检索。在常数时间复杂度下运行，这些机制架起了感知数据（稀疏分布式表示）与符号（稀疏全息表示）之间的桥梁，无需连续瓶颈。将该框架映射到神经解剖学，我们提出小脑和新皮层均实现了该算法的变体，使子集模式匹配成为认知的基本引擎。由于依赖离散逻辑而非矩阵运算，该算法可直接转化为内存计算硬件，为构建具有人类水平能效的合成智能开辟了新路径。

## Abstract
This work introduces a new computational theory of mind grounded in set theory and hyperdimensional computing. Whereas traditional neural networks rely on continuous weights and matrix multiplication, this framework works with sparse binary data. It represents information as discrete sets, directly modeling biological neural population codes. I demonstrate that associative memory emerges naturally from network topologies featuring a combinatorially expanded hidden layer. Learning is driven by topological plasticity rather than scalar weight adjustments. This architecture unifies auto-associative and hetero-associative learning under a single core algorithm: information retrieval via subset pattern matching and exact nearest-neighbor search. Operating with constant-time complexity, these mechanisms bridge perceptual data (sparse distributed representations) and symbols (sparse holographic representations) without continuous bottlenecks. Mapping this framework to neuroanatomy, I propose that both the cerebellum and the neocortex implement variants of this algorithm, making subset pattern matching the fundamental engine of cognition. Because it relies on discrete logic rather than matrix arithmetic, this algorithm translates directly into in-memory hardware. This opens a new route toward synthetic intelligence with human-level energy efficiency.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：信息以稀疏二进制集合（子集）形式表示，嵌入高维超空间（典型维度1000~10000）。联想记忆自然产生于具有**组合扩展隐藏层**的网络拓扑中：隐藏层节点接收固定数量的输入连接（至少2个），并通过二元开关（开/关）与输出层动态连接。学习就是打开或关闭这些连接的拓扑过程，而非调整连续权重。
- **关键技术细节**：
  - **数据表示**：
    - **稀疏全息表示（SHR）**：任意子集代表相同的语义信息，用于符号令牌。通过随机生成保证正交性。
    - **稀疏分布式表示（SDR）**：重叠元素反映共享语义特征，用于感知数据。
  - **网络拓扑**：
    - **异联想拓扑**：前馈结构，输入层与输出层分离，隐藏层有O(N²)个节点（N为输入维度）。适用于A→B映射（如小脑）。
    - **自联想拓扑**：循环结构，输入/输出共享同一层，隐藏层通过递归实现模式补全（如新皮层）。
  - **核心算法**：存储与检索均在常数时间复杂度O(|A|²)内完成，与记忆密度无关。
    - **存储**：对输入集合A的每个2-子集(i,j)，将对应的隐藏节点M_ij更新为M_ij ∪ B（按位逻辑或）。
    - **检索**：通过子集模式匹配和精确最近邻搜索，迭代找出输入A的最大一致子集X→Y。关键步骤包括：扩展编码 → 聚合响应 → k-winners-take-all（kWTA）选择 → 收敛检查与细调。
  - **学习与遗忘**：
    - **拓扑可塑性**：二元信号路径的开启/关闭，避免全局梯度反传。
    - **遗忘机制**：随机关闭存储比特，实现局部、优雅的信息衰减，而非灾难性遗忘。
  - **子集模式匹配**：检索时要求输入与存储模式有一定重叠度（模式匹配阈值T），低于T则返回空集，从而有效区分已知与未知，抑制幻觉。

## 3. 实验设计：数据集、场景、基准与对比方法

- **手写数字分类（MNIST）**：
  - 数据集：MNIST手写数字（70,000张28×28灰度图）。
  - 方法：图像经高斯模糊后，通过稀疏二进制随机投影映射至10,000~16,000维SDR，再经kWTA获得稀疏表示。类别（0-9）编码为非重叠SHR（P=15）。使用异联想记忆进行单次训练（60,000张），测试10,000张。

  - 方法：使用异联想或自联想记忆存储SHR间的关联，通过子集匹配、随机子采样、迭代分解实现关系查询、相似性计算和知识遍历。

  - 定性实验：若干互动式命令行演示（存储/检索、噪声容错、模式补全、迭代分解等），以及知识图谱随机游走可视化。
  - 容量与性能理论模拟：通过数学推导和蒙特卡洛仿真验证容量公式、检索准确性与密度关系等。
- **充分性与客观性**：
  - **不足**：实验覆盖非常有限，缺乏与深度学习方法（如CNN、Transformer）的系统性对比，缺乏大规模多模态或复杂推理任务的评估。MNIST本身已被CNN轻松达到99%以上精度，96%并不突出。
  - **偏差风险**：SHR的随机生成假设在真实生物系统中尚无法验证；所有演示均为简单人造场景，未涉及真实噪声和动态环境。
  - **公平性**：未与任何已有SDR或HDC方法进行硬性对比，自比为“干净室内”架构，但未证明其效率或精度优于前人方法。

## 6. 主要结论与发现

- 联想记忆可以从具有组合扩展隐藏层的二元拓扑中自然涌现，无需连续权重矩阵。
- 子集模式匹配（精确最近邻搜索）是认知的核心计算机制，统一了感知与符号处理。
- 学习是局部的、一次性的（单次存储），避免了灾难性遗忘；遗忘则是随机的、优雅的衰减。
- 记忆存储密度达到50%时容量最优，超过后检索性能平滑下降，而非崩溃。
- 该框架可映射至小脑（异联想）和新皮层（自联想）的神经结构，为神经科学的算法解释提供新假设。
- 二元逻辑和位运算可直接融入内存硬件（DRAM/NAND），有望实现人脑级别的能效（约20瓦）。

## 7. 优点

- **生物合理性**：全程基于离散脉冲、稀疏编码和拓扑可塑性，与spiking神经网络高度一致，避免了连续权重和反向传播的生物学争议。
- **计算高效**：存储和检索均为常数时间复杂度（与数据集大小无关），适合实时在线学习。
- **统一性**：将自联想、异联想、交叉关联等统一于一个核心算法，并支持SDR/SHR的无缝互转。
- **数学清晰**：以集合论和超维组合数学为基础，容量、错误概率等均有解析公式，便于理论分析和工程实现。
- **硬件友好**：无浮点运算，可定向内存中计算，有望突破冯·诺依曼瓶颈，实现极低功耗。
- **可解释性**：操作透明（子集匹配），易于调试和追踪原因。

## 8. 不足与局限

- **实验验证严重不足**：仅有MNIST一个标准分类任务，且未与当时最强方法对比。缺乏NLP、视觉、持续学习等AGI关键问题的评估。
- **理论假设有待验证**：SHR、SDR编码、模式匹配阈值等参数均基于理想随机假设，真实生物系统能否完美满足尚不确定。
- **容量限制**：当前模型在P=10、N=1000时标称容量约96万条关联，但实际部署中考虑噪声和重叠后容量会下降；超大规模（如互联网级）知识存储未验证。
- **序列建模能力有限**：虽然提出了指针链、储备池等机制，但未展示长序列（如数千步）学习与生成，且需要额外组件（bigram编码），复杂度较高。
- **缺乏复杂推理测试**：知识表示演示仅局限于简单场景图、语义关联和框架匹配，未检验多步推理、常识推理或逻辑一致性。
- **可扩展性担忧**：隐藏层节点数为O(N²)，当N很大时（如10,000），隐藏层达到约5,000万，纯软件实现的内存和逻辑代价较高，而硬件实现目前仅为构想。
- **缺失与深度学习的直接对比**：未说明在类似资源下如何优于Transformer或CNN，也未讨论与HDC其他变体（如FHRR、BSC）的优劣。

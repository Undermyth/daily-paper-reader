## 摘要
上下文学习是变换器的一个显著特性，最近受到了广泛关注。在许多上下文学习的研究中，已经表明变换器能够实现线性和非线性回归问题的求解器，其中大多数实现了梯度下降算法。然而，这些实现是否真正通过训练获得仍不清楚。在本文中，我们构建了一个具有线性自注意力的变换器，它在简单回归任务中在线学习最小二乘估计。关键在于，闭式（解析）解是通过使用层归一化近似获得的，而不是基于梯度下降算法的近似解。然后，我们展示了一个实验示例，其中当目标输出是最小二乘估计时，我们的实现主要使用l1正则化训练的变换器。

## Abstract
In-context learning is a remarkable property of transformers and has recently received a lot of interest. In many studies of in-context learning, it has been shown that transformers are capable of implementing solver for linear and non-linear regression problems, in which the most of them implement gradient descent algorithm. However, it is still unclear whether those implementations have actually been acquired through training. In this paper, we construct a transformer with linear self-attention, which in-context learns the least squares estimate in a simple regression task. The point here is that the closed form (analytical) solution is approximately obtained by using layer normalization rather than an approximate solution based on gradient descent algorithm. Then, we show an experimental example, in which our implementation is mainly used in the transformer trained with l1 regularization when the target output is the least squares estimate.

- **整体意义**：该工作首次提供了实验证据，表明 Transformer 可以在训练后主要依赖于**闭式解的近似计算**（而非梯度下降步骤）来执行线性回归任务的上下文学习，为理解 Transformer 内部学习机制提供了新视角。

## 2. 论文提出的方法论

### 核心思想
- 离线（构造性）设计一个极简的 Transformer 模型 `TF(4,2,2)`（模型维度 D=4，层数 L=2，头数 K=2），该模型在数学上可以逐层计算简单线性回归最小二乘估计的闭式解（公式 8）。
- 关键技巧是**利用层归一化（Layer Normalization）** 来实现除法运算（除以输入方差 V_m），从而避免对矩阵求逆或迭代梯度下降的需要。这一灵感来自 Akyürek 等人的工作（参考文献[1]）。
- 通过 ℓ1 正则化训练，期望模型在众多可能实现方式中倾向于采用这种紧凑、接近构造的解。

### 关键技术细节（文字说明）
1. **输入嵌入**：将输入 prompt（包含 N 个上下文样本和 1 个查询点）通过一个精心设计的权重矩阵 Win 映射为 4 维嵌入，使得后续计算可以提取出必要的统计量（如均值、交叉积）。
2. **第一层**：通过两个注意力头（第二个头输出为零），利用矩阵乘法聚合上下文信息，计算出样本均值相关项和偏差项，再通过层归一化进行缩放，最终输出每个 token 的标准化表示。第一层输出包含了样本的均值中心化信息。
3. **第二层**：使用两个注意力头。第一头利用第一层输出中蕴含的协方差和方差信息，结合第二层的权重结构，计算出包含 `C_m / V_m`（回归系数）的项；第二头提取方差 V_m。经过层归一化后，第二头的输出在对序列进行归一化时，**隐式地完成了除以 V_m 的操作**（因为层归一化会除以本 token 的标准差，而该标准差被构造为正比于 √V_m）。
4. **输出层**：将最后一个 token（即查询点位置）的第三维输出（其值正好是 `- (ȳ_m + (C_m/V_m)(u_m - x̄_m))`）通过权重 Wout 映射为最终预测值。Wout 被设计为除该位置外全零，从而只提取该数值并反号得到最小二乘预测。

### 公式流程（文字说明）
- 目标：计算 `ŷ(u) = ȳ + (C/V)(u - x̄)`。
- 构造确保第二层输出在查询 token 处的第三维近似为 `- (ȳ + (C/V)(u - x̄))`，从而通过简单的线性输出层得到正确值。

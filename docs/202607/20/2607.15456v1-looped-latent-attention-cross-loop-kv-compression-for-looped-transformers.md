## 摘要
循环、权重绑定的Transformer通过重复使用一个模块来减少参数，但在解码时每个循环步骤仍需存储独立的K/V缓存。我们发现这种循环索引的缓存具有高度结构性。对于固定的词元、层和头，K/V向量在循环间形成一条短的低秩轨迹，而头轴和层轴则平坦得多。我们提出了循环潜在注意力（LLA），一种训练后的缓存编解码器，它存储紧凑的K和V潜在变量，并仅在注意力读取时重构出特定循环的K/V向量。默认的每头编解码器压缩循环维度，而LLA-2D则将多个头合并为一个潜在向量，以实现极端压缩。编解码器通过教师激活的SVD初始化，并经过KL散度和注意力输出蒸馏进行优化。在匹配的缓存预算下，每头LLA优于头轴MLA、跨层共享、KV量化和最终循环复用，表明循环缓存是低秩的，但不能安全地折叠为单一状态。相同的轴优势在Ouro-2.6B-Thinking上保持，并迁移到Huginn-3.5B，其中SVD编解码器在解码器独立评估中在32倍压缩下仍接近无损。缓存缩减是精确的。在一张H200上，潜在存储路径将Ouro-1.4B在4k上下文下的测量批处理容量从32个序列提升至768个序列，压缩比为21.3倍。对于长数学推理过程，基于学生生成前缀的策略内微调将MATH-500在4倍压缩下从0.43提升至0.66，并减少了无回答生成。

## Abstract
Looped, weight-tied Transformers reduce parameters by reusing a block, but decoding still stores a separate K/V cache for every recurrence step. We show that this loop-indexed cache is highly structured. For a fixed token, layer and head, K/V vectors trace a short low-rank trajectory across loops, while the head and layer axes remain much flatter. We introduce Looped Latent Attention (LLA), a post-training cache codec that stores compact K and V latents and reconstructs loop-specific K/V vectors only when attention reads them. The default per-head codec compresses recurrence, while LLA-2D also folds heads into one latent for the extreme-compression regime. The codec is initialized from SVD of teacher activations and refined with KL and attention-output distillation. At matched cache budget, per-head LLA outperforms head-axis MLA, cross-layer sharing, KV quantization and final-loop reuse, showing that the recurrent cache is low-rank but not safely collapsible to a single state. The same axis advantage holds on Ouro-2.6B-Thinking and transfers to Huginn-3.5B, where an SVD codec remains near-lossless to 32x in decoder-independent evaluation. The cache reduction is exact. On one H200, the latent-store path increases measured Ouro-1.4B batch capacity at 4k context from 32 to 768 sequences at 21.3x compression. For long math rollouts, on-policy refinement on student-generated prefixes raises MATH-500 at 4x from 0.43 to 0.66 and reduces no-answer generations.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：循环权重共享 Transformer（如 Ouro、Huginn）通过重复使用一个模块来减少参数，但在推理时，每个循环步骤仍需独立存储 K/V 缓存。这导致缓存大小随循环步数线性增长，成为长上下文和大批量推理的主要内存瓶颈。
- **背景**：现有压缩方法（如 MLA 压缩头轴、跨层共享、量化、词元驱逐）主要针对单次前馈 Transformer，而循环模型特有“循环轴”未得到充分利用。作者发现循环轴具有高度结构性：对于固定词元、层和头，K/V 向量在循环间形成低秩轨迹，而头轴和层轴则平坦得多。
- **整体含义**：利用这种低秩结构，可以在几乎无损的情况下大幅压缩循环轴缓存，从而在有限显存下支持更长上下文和更大批量，提升推理效率。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程
### 核心思想
- **Looped Latent Attention (LLA)**：一种后训练编解码器，将每个循环步的 K/V 向量压缩为跨循环共享的少量潜在变量，并在注意力读取时重构出特定循环的向量。
- **两种变体**：
  - **Per-head LLA**（默认）：保留每头的独立潜在变量，仅压缩循环轴。
  - **LLA-2D**：进一步将头轴也合并到同一潜在变量中，实现极端压缩。

### 关键技术细节
- **编解码结构**：
  - 对于每层、每头、每轴（K 或 V），定义教师输出向量 `x = [x1; ...; xT] ∈ R^{T*d_head}`。
  - 存储一个居中低秩潜在变量 `c = (x - μ)W_down`，其中 `μ` 是校准集均值，`W_down ∈ R^{T*d_head × r}`。
  - 重构：`ˆx_t = c W_up,t^⊤ + μ_t`，其中 `W_up,t ∈ R^{d_head × r}` 是循环特异的。
  - K 和 V 使用不同秩，且 `r_v > r_k`（V 收敛更慢）。
- **压缩比**：`ρ = 2T d_head / (r_k + r_v)`，仅对每个词元每层存储 `(r_k + r_v)H` 个标量。
- **RoPE 兼容**：潜在变量在预-RoPE 内容投影上拟合，旋转位置编码在重构后应用（同一词元各循环共享同一旋转相位），无需解耦 RoPE 分支。
- **初始化与优化**：
  - 使用教师 K/V 激活在 255 个提示上的 SVD 初始化 `W_down`（取 top-r 右奇异向量），`W_up,t` 为对应循环切片。
  - 目标函数：`L = KL(p_teacher || p_swap) + λ_attn * Σ||a_t,d - ˆa_t,d||²`，仅更新编解码器参数。
  - 训练 3000 步（消融实验 300 步），batch size 8，序列长度 512，AdamW，学习率 1e-3，预热 100 步后余弦退火。
- **策略内微调 (on-policy refinement)**：为缓解生成时暴露偏差，在教师前缀上训练后，额外使用学生自身采样前缀进行 KL 蒸馏，仅更新编解码器参数，梯度停止在采样上。

## 6. 主要结论与发现
1. **循环轴是最可压缩的轴**：在相同缓存预算下，LLA（压缩循环轴）在生成准确率和 KL 散度上均优于压缩头轴、层轴、精度的基线。
2. **循环缓存低秩但不可折叠为单状态**：最终循环复用控制（零参数）在相同 4× 预算下 GSM8K 降至 0.000，证明轨迹不能由单一终点替代。
3. **K/V 轨迹不同**：V 收敛更慢，需要更高秩（`r_v > r_k`）；不对称秩分配带来增益。
4. **SVD 初始化至关重要**：随机初始化下 KL 显著更高。
5. **策略内微调稳定长生成**：MATH-500 在 4× 压缩下从 0.43 提升至 0.66，大幅减少无回答生成。
6. **精确的内存节省转化为服务能力**：21.3× 压缩下，4k 上下文批容量从 32 序列升至 768 序列。
7. **结构迁移**：Ouro-2.6B-Thinking 和 Huginn-3.5B 均重现循环轴低秩优势，表明方法具有普适性。

## 7. 优点
- **方法创新**：首次专门针对循环 Transformer 的循环轴设计后训练缓存压缩编解码器，利用了独特的结构冗余。
- **精确压缩**：压缩比公式直接对应标量减少，无近似，易于集成。
- **便于部署**：提出“快速路径”（重构后缓存，保持吞吐）和“容量路径”（存储潜在变量，实现内存节省），并可组合词元驱逐。
- **全面消融与迁移**：设计消融分离因素重要性，多模型验证泛化性。

## 8. 不足与局限
- **吸收注意力实现未作为主结果**：文中提到可吸收 up-projection 到 query 侧实现更高效计算，但仅作为可选路径，未与重构路径充分对比准确率影响。
- **极压缩比下质量受限**：超过 10× 后长上下文检索和长形式推理明显下降，仅适用于容量导向场景。
- **依赖教师结构**：方法假设教师模型已训练好，且循环轴确有低秩结构；若教师未收敛或循环步数极少（如 T=1），则优势减弱。
- **未验证非循环模型**：方法天然适用于循环模型，不适用于普通单次前馈 Transformer。
- **训练阶段仍需教师激活**：需要额外校准集进行 SVD 和蒸馏，对黑盒模型可能不便。

- **实验覆盖**：未在更大模型（如 7B+）上验证，也未在多种硬件架构下全面测试。

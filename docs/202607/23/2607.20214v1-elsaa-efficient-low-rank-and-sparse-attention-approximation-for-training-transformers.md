## 摘要
二次型 $N\times N$ 注意力分数矩阵仍然是扩展Transformer至更长输入长度的核心障碍。现有的高效注意力方法通常通过施加稀疏性（使每个查询仅关注少量键）或使用低秩/核方法（将全局交互压缩到低维表示中）来减少这一瓶颈。本文提出\emph{ELSAA}，一种高效的注意力的低秩和稀疏近似。重要的是，ELSAA 并\emph{不}将Transformer的学习投影矩阵或输出矩阵分解为稀疏和低秩因子。相反，在密集投影产生 $Q,K,V$ 后，ELSAA 近似了诱导出的注意力分数算子本身：一个稀疏分支捕获选定的高相似性交互，而一个低秩分支总结扩散的全局交互。由于这两个分支可以在具有非常不同分母质量的支撑集上进行归一化，ELSAA 引入了一个分母感知融合项，根据相对于低秩分支估计的注意力质量来缩放稀疏分支。这提供了一个实用的框架，可以在不生成完整二次型分数矩阵的情况下构建低秩和稀疏的注意力输出，旨在实现更长上下文的训练，同时保留尖锐的令牌级交互和广泛的上下文混合。

## Abstract
The quadratic $N\times N$ attention score matrix remains a central obstacle to extending Transformers to longer input lengths. Existing efficient attention methods usually reduce this bottleneck by either imposing sparsity, so that each query attends to only a small subset of keys, or by using low-rank/kernel sketches, so that global interactions are compressed into a lower-dimensional representation. We propose \emph{ELSAA}, an efficient low-rank and sparse approximation of attention. Importantly, ELSAA does \emph{not} decompose the learned projection or output matrices of the Transformer into sparse and low-rank factors. Instead, after dense projections produce $Q,K,V$, ELSAA approximates the induced attention score operator itself: a sparse branch captures selected high-similarity interactions, while a low-rank branch summarizes diffuse global interactions. Since the two branches can be normalized over supports with very different denominator mass, ELSAA introduces a denominator-aware fusion term that scales the sparse branch according to its estimated attention mass relative to the low-rank branch. This gives a practical framework for constructing low-rank and sparse attention outputs without materializing the full quadratic score matrix, aiming to enable longer-context training while preserving both sharp token-level interactions and broad contextual mixing.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：Transformer的自注意力机制计算复杂度为 \(O(N^2)\)，其中 \(N\) 是序列长度。随着长上下文建模需求增长，这一二次瓶颈严重限制了模型训练和推理的可扩展性。
- **现有方法局限**：
  - **稀疏注意力**（如局部窗口、哈希、聚类）仅选择部分键，能捕捉高相似性交互，但可能丢失全局背景信息。
  - **低秩/核注意力**（如Linformer、Performer、RACE）通过压缩表示捕获全局交互，但会平滑尖锐的令牌级依赖。
- **互补性观察**：注意力矩阵通常兼具尖锐局部模式和扩散全局结构，单一方法难以兼顾。少量关键令牌可能主导注意力输出，而其余部分需要全局混合。
- **本文目标**：提出一种同时利用稀疏性和低秩性的混合注意力近似方法，在不构造完整二次矩阵的前提下，既保留高置信度交互，又提供全局上下文。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- ELSAA 不分解学习的投影矩阵，而是在投影生成 Q、K、V 后，**近似注意力分数算子本身**：一个稀疏分支精确计算选定的高相似性交互，一个低秩分支通过压缩摘要提供全局背景。
- 引入**分母感知融合**（denominator-aware fusion），解决两个分支归一化尺度不匹配问题。

### 关键技术细节
1. **稀疏分支**：使用 sortLSH（排序局部敏感哈希）选择高相似性的查询-键对。将序列按哈希值排序并分块，在每个块内计算精确注意力。块大小 b 固定，复杂度 \(O(Nb)\)。支持因果变体（递归分治结构）。
2. **低秩分支**：基于 RACE 注意力（可微分哈希摘要）。每个哈希表将查询和键软分配到超立方体桶中，累积键/值统计量，查询从桶摘要中读取。复杂度 \(O(NL_s 2^\gamma)\)，其中 \(L_s\) 是哈希表数，\(\gamma\) 是哈希位数。
3. **分母感知融合**：
   - 对于查询 i，稀疏分支的归一化输出依赖于其分母 \(d_{\text{sparse},i}\)，低秩分支分母为 \(d_{\text{lr},i}\)。
   - 融合公式：
     \[
     m_{\text{sparse},i} = \frac{d_{\text{sparse},i}}{d_{\text{sparse},i} + \lambda_i d_{\text{lr},i} + \varepsilon}, \quad \mathbf{O}_i = g_{\text{sparse},i} m_{\text{sparse},i} \mathbf{O}_{\text{sparse},i} + g_{\text{lr},i} \mathbf{O}_{\text{lr},i}

     其中 \(\lambda_i\) 可固定、学习或查询依赖，\(g\) 是学习门控。
4. **理论分析**（第4节）：

### 算法流程（非因果版本）
1. 输入 X，投影得 Q, K, V。
2. 低秩分支：RACE 返回 \(\mathbf{O}_{\text{lr}}, \mathbf{d}_{\text{lr}}\)。
3. 稀疏分支：sortLSH 返回 \(\mathbf{O}_{\text{sparse}}, \mathbf{d}_{\text{sparse}}\)。

6. 融合输出 \(\mathbf{O}_{\text{head}}\)。
7. 经输出投影 \(W_O\) 返回最终输出。

## 6. 主要结论与发现
1. **分母感知融合有效**：ELSAA 在长上下文视觉任务上平均测试准确率比 Sort Lsh RACE（无分母感知）高1.33pp（46.81% vs 45.48%），证明该校正对尺度不匹配的关键作用。
2. **视觉任务比长文本更依赖稀疏分支**：ELSAA 在 Oxford-IIIT Pet、Flowers-102、Food-101 上优于 RACE 约 4-7pp；而在 ArXiv @ 32K 上 RACE 略优（95.05% vs 93.93%），表明长文本主题分类受益于全局低秩聚合。
3. **极长上下文中精确注意力失败**：在 Text Retrieval @ 64K 上，Exactflash 训练和测试准确率均跌至 50%（随机），而 ELSAA 和 RACE 达到 65-66%，说明近似注意力在极长序列中提供了结构化先验，稳定优化。
4. **NIAH 长度外推**：ELSAA 是唯一在所有长度 (512-65536) 上保持高准确率的方法（97.88%平均）；RACE 在超出训练长度后崩溃（36.23%）；Sparse LSH 在短于训练长度时失败（512：24.6%）。
5. **因果变体效果相当**：因果 ELSAA 在 ArXiv @ 64K 上以 91.47% 超越因果 Exactflash (87.44%) 和因果 RACE (91.46%)，平均测试准确率 72.15% 最高。
6. **复杂度线性**：ELSAA 的注意力交互数为 \(O(N(s + L_s 2^\gamma))\)，在典型参数下比精确注意力减少约 99%。

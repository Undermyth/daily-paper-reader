## 摘要
主流的视觉-语言-动作（VLA）模型在马尔可夫假设下主要根据当前观测预测动作，因此难以应对长时域、时间依赖的任务。现有的增强记忆VLA要么扩展观测窗口，要么从记忆库中检索历史作为辅助策略端上下文。然而，它们将记忆置于VLA推理的固有潜在嵌入空间之外，阻碍了历史经验与多模态推理及动作形成的流畅交织。为此，我们提出LaMem-VLA，一种潜在记忆原生框架，将历史经验重构为潜在记忆令牌，并直接与VLA推理交织。LaMem-VLA的核心引入了四个协调组件：（i）一个策展器，将历史经验组织成互补的短期和长期记忆库；（ii）一个搜索器，利用多模态认知查询两个记忆库以检索上下文相关证据；（iii）一个凝缩器，将检索到的证据重构为紧凑的短期和长期潜在记忆令牌；（iv）一个编织器，将这些记忆令牌与当前观测和指令注入到一个连续的嵌入序列中。通过完全在相同的连续潜在空间中表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理并在有界上下文中指导动作生成。在SimplerEnv和LIBERO上的大量实验证明了我们LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

- **现有方法局限**：
  - 扩展观测窗口或使用历史帧拼接会带来计算和内存开销的线性增长，且固定窗口存在记忆天花板。
  - 通过外部记忆库检索历史作为策略侧辅助上下文，但历史记忆被存储于模型原生嵌入空间之外，无法与多模态推理和动作形成过程流畅交织。
- **研究动机**：将历史经验表示为**上下文原生的潜在记忆**，使其与当前观测、指令和动作查询在同一个连续嵌入空间中进行存储、检索和消费，从而直接参与VLA推理和动作生成。

## 2. 方法论
### 核心思想
- 将机器人历史经验组织为**互补的短期和长期潜在记忆库**，通过四个协调组件实现记忆的存储、检索、压缩和注入，使记忆成为模型推理的原生部分而非外部辅助条件。

### 关键技术细节
1. **潜在记忆策展器（Curator）**：
   - **短期记忆库**：存储当前回合的视觉感知证据（视觉令牌），使用SE-bottleneck压缩模块对每帧视觉令牌进行压缩，并以其均值池化作为检索键。容量限制L=16，超出时合并最相似相邻单元。
   - **长期记忆库**：存储动作隐藏状态（动作令牌），记录任务进度和动作连续性，直接写入每步的隐藏状态。使用相同更新策略。

2. **潜在记忆搜索器（Seeker）**：
   - 基于当前多模态认知表示（视觉令牌+指令令牌）构建上下文感知查询Qcon_t，附加可学习查询槽Qinit，通过轻量Transformer查询构建器B更新获得全局查询qt。
   - 分别对短期和长期记忆库进行**余弦相似度Top-K检索**（K=8），得到检索证据Zshort和Zlong。

3. **潜在记忆凝缩器（Condenser）**：
   - 将检索到的冗余证据**压缩为固定长度**的潜在记忆令牌：短期记忆令牌M_short（Ls=8）和长期记忆令牌M_long（Ll=4）。
   - 使用轻量Transformer记忆形成器Fv和Fc，以查询Qt和检索证据为条件更新可学习记忆槽，输出与VLA嵌入空间兼容的令牌。

4. **潜在记忆编织器（Weaver）**：
   - 将凝缩后的短期和长期记忆令牌**注入到VLA输入序列**之前，与当前视觉令牌、指令令牌和动作查询令牌拼接：St = [M_short; M_long; Xt; I; Qaction]。
   - 记忆令牌通过可学习源嵌入添加位置偏置，参与后续自注意力，形成记忆驱动的动作令牌Zaction。

5. **扩散动作专家**：
   - 采用基于扩散的策略（DiT架构），将记忆驱动的动作令牌作为条件，通过DDIM采样（10步）生成连续7-DoF动作块（chunk size=16）。

## 6. 主要结论与发现
- LaMem-VLA在**两个基准上均取得最优**：

- **双重记忆互补性显著**：短时记忆提供细粒度视觉证据，长时记忆提供任务进程和动作连续性语义，两者缺一不可。
- **潜在原生注入优于策略侧条件**：将记忆令牌直接作为VLA输入序列的一部分，相比作为外部条件或原始检索拼接，性能提升明显。
- 检索数量K=8、记忆令牌数(Ls=8, Ll=4)为最优平衡点。

## 7. 优点
- **范式创新**：首次提出将机器人历史经验作为**上下文原生的潜在记忆**，与VLA推理在同一连续空间内无缝交织，突破了外部条件注入的限制。
- **双尺度互补设计**：短期视觉记忆与长期语义记忆分工明确，覆盖不同时间粒度的历史信息需求。
- **固定长度记忆接口**：通过凝缩器将可变长度检索结果压缩为固定令牌数，保持推理上下文有界，避免计算成本随历史增长。
- **综合消融**：对记忆源、注入方式、检索预算、令牌数量等关键因素进行全面分析，验证设计合理性。

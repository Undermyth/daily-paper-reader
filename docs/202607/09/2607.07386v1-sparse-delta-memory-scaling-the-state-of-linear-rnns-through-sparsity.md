## 摘要
线性注意力模型允许固定的状态大小和每个token固定的计算量。然而，由于其有限的状态大小，线性注意力模型在长上下文回忆方面落后于基于softmax注意力的Transformer架构。增加线性注意力的状态大小可以提高回忆性能，但代价是更高的FLOPs。在这项工作中，我们引入了稀疏Delta记忆（SDM），这是一种通过稀疏寻址方案将门控线性RNN的隐藏状态扩展到更高数量级容量的架构。SDM通过用稀疏读写操作替换密集的键值外积，扩展了门控DeltaNet架构，使其拥有一个大型显式记忆。我们表明，在等FLOP约束和相同参数数量下，更高的状态记忆容量显著提升了上下文学习和长上下文检索任务的性能。此外，通过学习SDM记忆的初始状态并将其用作参数化记忆，我们表明该模型在广泛常识和推理任务上进一步改进。

## Abstract
Linear attention models allow a fixed state size and a fixed amount of compute per token. However, due to their limited state size, linear attention models fall behind in long-context recall compared to softmax-attention-based transformer architectures. Increasing the state size of linear attention improves recall performance but at the cost of higher FLOPs. In this work, we introduce Sparse Delta Memory (SDM), an architecture that scales the hidden state of gated linear RNNs to orders of magnitude higher capacity using a sparse addressing scheme. SDM extends the Gated DeltaNet architecture by replacing the dense key-value outer product with sparse reads and writes to a large explicit memory. We show that, under an isoFLOP constraint and with an identical number of parameters, a higher state memory capacity significantly improves performance on in-context learning and long-context retrieval tasks. Moreover, by learning the initial state of the SDM memory and therefore using it as a parametric memory, we show that the model further improves on a wide range of common-knowledge and reasoning tasks.

# 论文详细中文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：线性 RNN（如 Mamba2、Gated DeltaNet）通过固定大小的隐状态实现常量计算和内存，避免了 Transformer 中 KV 缓存随序列长度线性增长的问题。但其极小的状态容量严重限制了长上下文回忆能力，在 RULER 等基准上远不及 softmax 注意力 Transformer。
- **问题**：增大线性 RNN 的状态大小理论上可提高回忆性能，但现有的密集更新规则（如 Gated DeltaNet 的矩阵外积）会导致计算量（FLOPs）随状态大小线性增加，无法高效扩展。
- **核心挑战**：如何在保持等 FLOP 和参数量不变的前提下，大幅提升线性 RNN 的状态内存容量，从而弥补长上下文回忆差距，并探索大状态记忆作为参数化记忆的可能性。

## 2. 论文提出的方法论

### 2.1 核心思想
基于 Gated DeltaNet（GDN）的更新规则，利用稀疏寻址替代密集的键-值外积，将状态从密集矩阵 **M_t ∈ R^{d_qk × d_v}** 扩展为一张大型显式记忆表 **M_t ∈ R^{N × d_v}**，其中 **N**（slot 数量）可达数百万量级，而每 token 的计算量仅通过少量（W 个写、R 个读）稀疏操作完成，与 N 无关。

### 2.2 关键技术细节（文字描述）
- **稀疏键选择**：输入 **x_t** 分别通过可学习投影生成写键 **k'_t** 和读查询 **q'_t**，每个向量拆分为两个子向量（维度 √N），通过外积得到 **N** 个候选分数。利用 Product-Key Memory（PKM）的 Top-k 技巧（仅需 O(√N·d + W² + R²)），选择 **W** 个写槽位索引 **I_wt** 和 **R** 个读槽位索引 **I_rt**。
- **门控 Delta 写操作**：对每个选中写槽位 i，应用遗忘门 α_t 和输入门 β_t，执行 delta 更新：  
  *M_t[i] ← α_t · M_{t-1}[i] + β_t · k^{(i)}_t · (v_t - M_{t-1}[i])*，其中 k^{(i)}_t 是稀疏写权重。未选槽位保持不变。
- **稀疏读操作**：通过查询权重 q^{(i)}_t 对选中读槽位的值加权求和：*y_t = Σ_{i∈I_rt} q^{(i)}_t · M_t[i]*。
- **规范化与门控**：读出向量经 RMS-Norm 和门控，再经输出投影混合多头。
- **可学习初始状态 M0**：将 **M0** 作为模型可学习参数，使模型在预训练中存储知识并在推理时复用，不增加额外 FLOPs。

### 2.3 与 GDN 的联系
当 N = d_qk、W = R = d_qk（即选择所有槽位）时，SDM 退化为 GDN（差别仅在于 SDM 省略了 GDN 的 1D 卷积）。

### 2.4 等 FLOP 设计
保证 SDM 与 GDN 具有相同的参数数量和每 token FLOPs，通过设置 W = R = 64（与 GDN 的 d_qk 一致），使得 SDM 的 FLOP 主项 O((W+R)×d_v) 与 GDN 的 O(d_qk×d_v) 匹配。PKM 的 Top-k 计算开销不足 1%。通过控制头数 H 来限制状态大小膨胀，使状态-参数比约为 1:1。

## 6. 论文的主要结论与发现

- SDM 在所有计算水平（FLOPs）上 **一致优于** GDN，训练损失更低，验证 NLL 更好。
- 在 8B 规模下，SDM 的预训练损失 **低于** FullAttn，且短上下文平均准确率略高于 FullAttn（56.84% vs 56.65%）。
- **长上下文回忆**：RULER 平均准确率：SDM（1.4B 31.2%，8B 50.2%）远高于 GDN（20.0%，34.2%），部分任务接近甚至超过 FullAttn（76.2%）。
- **代码 perplexity**：随序列长度（512→1M tokens）持续下降至 ~2.0，而 Mamba2/GDN 基本停滞在 ~2.2-2.3。
- **可学习初始状态 M0** 显著提升短上下文任务表现，而 GDN 因状态太小即使学习 M0 也无明显改进，证明大状态容量是关键。
- 记忆大小增大带来性能单调提升，且 SDM 在极小记忆（27MB）下仍优于 GDN。
- 稀疏读写模式自适应：当读容量充足时，写分布更尖峰；读分布通常更均匀。

## 7. 优点

- **创新性**：首次将 PKM 稀疏寻址与门控 delta 更新结合，实现线性 RNN 状态的极大规模扩展，同时保持等 FLOPs。
- **实验设计公平**：严格 isoFLOP 对比，排除参数量作弊；混合架构统一，避免结构偏向。
- **可解释性**：通过熵、槽位利用率等分析揭示了模型的自适应内存访问模式。
- **实用性**：可作为纯黑箱替换现有线性 RNN 层，支持学习初始状态作为参数记忆，提供额外的知识存储。
- **鲁棒性**：即使在 8B 规模下训练 1T+ tokens 仍保持稳定，scaling law 高度线性。

## 8. 不足与局限

- **训练效率低**：当前 CUDA kernel 的 MFU 远低于优化的 GDN kernel（来自 FLA 库）。8B 模型训练吞吐比 GDN 慢 1.49 倍，推理比 GDN 慢约 10%，但比 FullAttn 快 6 倍。
- **内存占用大**：SDM 的显存状态可能与模型参数相当（8B 模型约 8GB），不适用于极端资源受限场景。作者指出其状态大小相当于 FullAttn 处理 203400 token 的 KV 缓存占用，但 FullAttn 在超长上下文时内存膨胀更严重。
- **长上下文微调需量化**：在 128k 微调时，内存快照过大，需采用 fp8/int4 量化，虽无明显损失，但增加复杂度。
- **部分 RULER 任务表现差**：对多键组合（multikey_2）、频繁写入（fwe）等任务，SDM 仍远不如 FullAttn，表明固定大小记忆的信息压缩瓶颈依然存在。
- **模态局限**：仅在文本和代码数据上验证，未探索视频、音频等长序列任务。
- **头数 H 与状态大小权衡**：为控制状态大小，需减少头数（H 小），可能影响多头的表示能力，但 FLOPs 不变；消融显示单头仍有良好性能，但更深层次影响未充分讨论。

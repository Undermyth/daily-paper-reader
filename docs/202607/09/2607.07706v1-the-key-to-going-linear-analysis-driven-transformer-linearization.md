## 摘要
因果自注意力的二次复杂度严重制约了长上下文Transformer的推理。虽然存在许多事后线性化流程，但难以确定哪些组件能保持模型质量。本文在严格的冻结主干框架下，分离了状态更新设计的影响。我们表明softmax依赖于键相关的秩1正交投影，阐明了为什么delta式网络优于纯门控累积。我们识别了近似误差的一个潜在来源，并引入了结构性的干预措施，特别是sink token、短卷积和固定预算缓存路由，从而缩小了剩余的差距。我们将这种线性化方法扩展到具有高达320亿参数的LLaMA和Qwen模型，在MMLU上优于先前的事后基线，并匹配了复杂自适应缓存框架的长上下文检索能力。

## Abstract
The quadratic cost of causal self-attention severely bottlenecks long-context transformer inference. While numerous post hoc linearization pipelines exist, it is difficult to identify which components preserve model quality. This work isolates the effect of state update design in a strict frozen-backbone regime. We show that softmax relies on key-dependent, rank-1 orthogonal projections, elucidating why delta-style networks outperform purely gated accumulation. We identify a potential source of approximation errors and introduce structural interventions, specifically sink tokens, short convolutions, and fixed-budget cache routing, which reduces the remaining gap. We scale this linearization approach across LLaMA and Qwen models up to 32B parameters, outperforming prior post hoc baselines on MMLU and matching the long-context retrieval of complex adaptive-caching frameworks.

## 1. 论文的核心问题与整体含义（研究动机和背景）

因果自注意力的计算复杂度随序列长度呈二次增长，且 KV 缓存不断增大，使得长上下文 Transformer 推理变得极其昂贵。事后线性化（post hoc linearization）是一种有吸引力的解决方案：在不从头预训练的情况下，将已有的全注意力模型转换为线性时间架构。然而，现有方法通常同时采用多种干预（如低秩适配 LoRA、滑动窗口注意力 SWA、混合路由、蒸馏等），这些混杂因素掩盖了一个基本设计问题：**哪种线性状态更新规则最能近似预训练的 softmax 注意力？**

本文旨在系统隔离并回答这一问题——在严格的**冻结骨干网络（frozen-backbone）** 设定下，仅训练新引入的替换机制参数，从而独立评估线性注意力替换机制的近似能力。论文还从理论上证明 softmax 自然隐含键相关的秩 1 正交投影，而 delta 式机制（如 Gated Delta Network）恰好能捕捉这一几何特性，纯门控累积（如 Gated Linear Attention）则缺失该校正。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将 pretrained 的 softmax 注意力替换为线性复杂度的机制，同时**冻结所有原始参数**（Wq, Wk, Wv, RMSNorm），仅训练新增的参数。
- 通过对 softmax 进行一阶泰勒展开，推导出 softmax 注意力权重可近似为：
  \[
  P_i^{\text{full}} \approx \frac{1}{t\sqrt{d}} q_t^\top \left( \prod_{j} (I - \beta_j k_j k_j^\top) \right) k_i + \frac{1}{t}
  \]
  该形式与 delta 规则（Gated DeltaNet）的线性注意力权重结构一致，从而从理论上解释了 delta 式更新的优越性。

### 2.2 关键技术细节
- **对比的线性注意力机制**（图1）：
  - Hedgehog：核化线性注意力，用特征映射近似 softmax 核。
  - Gated Linear Attention (GLA)：使用输入依赖的对角遗忘门累积状态。
  - Gated DeltaNet (GDN)：在 GLA 基础上增加 delat 规则，利用键的秩 1 更新矩阵 \((I - \beta_t k_t k_t^\top)\) 实现正交投影。
  - 还提出了一种变体 kGLA（Key-Gated Linear Attention），将 delta 规则的秩 1 投影近似为对角形式，以兼容 GLA 的高效内核。

- **为补偿近似误差引入的结构干预**：
  - **滑动窗口注意力 (SWA)**：固定预算 64 token，其中 8 个分配给 sink tokens（序列开头），56 个用于滑动窗口。
  - **Sink tokens**：针对线性注意力难以近似序列开头 token 的注意力模式（类似 attention sink 效应），在 SWA 中保留前 s 个 token 的精确注意力。
  - **短卷积 (Short Convolution)** 或 **LoRA**：对 Q/K/V 投影进行轻量级适配（冻结原参数，新增可训练支路）。
  - **混合架构**：仅替换部分层为 GDN，其余保留全注意力，并利用键集中度/投影残差等信号选择最难线性化的层。

## 3. 实验设计

### 3.1 数据集与基准

- **评估基准**：
  - 常识推理（CR）：PIQA, ARC Easy, ARC Challenge, HellaSwag, WinoGrande（零样本）。
  - MMLU（5-shot）。
  - Lambada OpenAI（零样本）。
  - 长上下文：S-NIAH 和拓展的 RULER 基准（4K 上下文）。

### 3.2 对比方法
- 全注意力基线模型：LLaMA 3.1-8B, Qwen3-0.6B/1.7B/4B/8B/14B/32B。
- 其他事后线性化基线：Llamba (12B tokens 全模型微调), LoLCATs, Liger-GLA, Lizard, LoLA, STILL (concurrent)。
- 自身消融：不同线性核（Hedgehog, GLA, kGLA, GDN）、有无 SWA、有无 sink tokens、有无短卷积 / LoRA。

### 3.3 实验设置
- 训练：batch size 1, 2500 步迭代，lr=2e-3（余弦调度，100步 warmup），AdamW，权重衰减 0。
- LoRA 训练时 lr 降至 5e-4。
- 每个实验取 3 个随机种子求平均和标准差。

## 4. 资源与算力
- 训练使用单张 **NVIDIA H100 GPU**。
- 训练时长：
  - GLA/GDN 变体：约 **1 小时**。
  - Hedgehog（缺少 Triton 实现）：约 **8 小时**。
- 推理时，线性注意力允许在 32K 上下文下运行（FA2 在相同显存限制下 OOM）。

## 5. 实验数量与充分性
- **充分的消融实验**：在冻结骨干下比较 4 种线性机制（Hedgehog, GLA, kGLA, GDN）；逐步引入 SWA, sink tokens, 短卷积, LoRA；并跨 LLaMA 和 Qwen 两个模型族验证。
- **规模实验**：Qwen3 从 0.6B 到 32B 共 6 个尺寸，一致的趋势表明线性化性能随模型增大而提升。
- **混合实验**：保留 10%-50% 全注意力层，比较均匀选择与基于硬度信号的选择。
- **长上下文实验**：不同缓存预算（128, 256, 512, 896 tokens）下的 S-NIAH 和 RULER 分数。
- **公平性**：与基线比较时采用相同缓存预算（64 token 或 128 token）并控制训练 token 数（仅 10M tokens vs. 基线多使用 20M-80M tokens），但指出 LoRA 训练可能因学习率较低而不够充分。
- 实验较充分，但部分结论（如 LoRA 与短卷积比较）受限于训练步数设置。

## 6. 论文的主要结论与发现
1. **Delta 式更新是最优的近似**：在严格的冻结骨干设定下，Gated DeltaNet (GDN) 始终优于 GLA、kGLA 和 Hedgehog，其更低近似误差（MSE）与一阶泰勒分析预测一致。
2. **softmax 本质是键相关的秩 1 正交投影**：理论推导揭示 delta 规则通过 \((I - \beta k k^\top)\) 实现了类似 softmax 的隐式遗忘机制。
3. **Sink tokens 和 SWA 有效缩小误差**：分配 8 个 sink tokens 即可大幅提升 Lambada 等依赖上下文的任务，且优于纯滑动窗口。
4. **短卷积效果好于 LoRA（给定约束）**：在 10M tokens 训练下，短卷积使所有线性核性能趋同，而 LoRA 则表现出不稳定和知识遗忘（MMLU 提升有限）。
5. **可扩展性良好**：从 0.6B 到 32B 的 Qwen3 模型上线性化性能与全注意力性能正相关；混合架构中保留少量困难层即可显著恢复性能。
6. **长上下文竞争力**：使用相同缓存预算（128 tokens）时 GDN 超过 LoLCATs 和 Liger-GLA；扩大缓存（896 tokens) 可使平均 RULER 分数接近 STILL / LoLA 等复杂自适应缓存方法，但多查询/多值检索等子任务仍有差距。

## 7. 优点
- **分析驱动**：通过理论推导（一阶泰勒展开、投影近似、秩 1 乘积近似）解释实验现象，不是纯经验调参。
- **严格的实验隔离**：冻结骨干 + 仅训练新增参数，避免了其他组件（LoRA、蒸馏等）的干扰，清晰揭示各线性机制本身的能力。
- **结构干预的定量贡献**：逐步添加 SWA、sink tokens、短卷积，并报告每个步骤的性能变化，有助于指导实际设计。
- **规模验证**：在 6 个不同尺寸的 Qwen3 模型上测试，证明线性化方法不限于特定大小。
- **可复现性**：提供了详细的超参数表、初始化细节（如门控偏置设定、LogSigmoid 使用），以及所有随机种子结果。

## 8. 不足与局限
- **理论假设的局限性**：一阶近似依赖于键的 L2 归一化和集中性假设，论文在实验中验证了这些假设（键集中度、投影残差与 MSE 的相关性），但作者承认假设并非在所有层或短前缀下均匀成立。
- **训练数据量小**：仅使用 10M tokens（约 2500 步）进行训练，远少于基线方法（如 Llamba 使用 12B tokens）。LoRA 实验中可能因学习率降低而欠拟合，这也许导致短卷积优于 LoRA 的结论有偏。
- **长上下文检索的局限**：固定预算缓存（仅包含 sink + sliding window）无法处理需要同时记忆多个分散信息的位置，因此在 MQ/MV/VT 等任务上表现较弱。论文指出未来应结合内容感知的 token 选择。
- **未考虑蒸馏**：未使用知识蒸馏损失，而许多基线依赖蒸馏来保留知识。尽管这有助于隔离分析，但导致 MMLU 等知识密集型任务仍有约 6% 的差距。
- **指令微调模型**：32B 参数模型仅有 instruction-tuned 版本，影响比较公平性。
- **无推理时的自适应缓存**：缓存策略（sink + sliding）是静态的，与 STILL/LoLA/Lizard 等动态选择方法不对等，从而使得长上下文对比中“相同缓存预算”的设置仍有不公平成分（因为对方可能更有效地利用 cache）。

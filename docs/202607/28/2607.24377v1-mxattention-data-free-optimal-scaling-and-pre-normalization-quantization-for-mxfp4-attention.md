## 摘要
注意力的二次成本是基于扩散的视频生成模型的主要瓶颈。MXFP4注意力提供了一条通往高效推理的有希望路径，但直接的MXFP4量化常因两个数值问题而降低生成质量：二的幂缩放带来的截断-下溢权衡，以及softmax循环中引入的行级归一化误差。我们提出MXAttention，一种针对MXFP4注意力的无数据后训练量化框架。MXAttention包含两个组件：通用最优缩放（UOS），利用二的幂微缩的周期结构，无需校准或搜索即可推导出与分布无关的最优缩放边界Qmax=7.25；预归一化量化（PNQ），在行级求和之前量化未归一化的softmax指数，从而通过构造保留归一化。在Wan2.2和HunyuanVideo上的实验表明，MXAttention至少弥合了OCP MXFP4与FP16之间VBench成像质量差距的95%，显著提升了帧级相似度，并在所有报告的VBench指标上保持了FP16级别的生成质量，绝对退化小于0.01。当融合到注意力流水线中时，MXAttention还以可忽略的开销实现了与基于强NVFP4的基线相竞争的性能。该实现已在MindIE-SD中公开提供。

## Abstract
The quadratic cost of attention is a major bottleneck in diffusion-based video generation models. MXFP4 attention provides a promising path toward efficient inference, but direct MXFP4 quantization often degrades generation quality due to two numerical issues: the clipping-underflow trade-off from power-of-two scaling and the row-wise normalization error introduced in the softmax loop. We propose MXAttention, a data-free post-training quantization framework for MXFP4 attention. MXAttention introduces two components: Universal Optimal Scaling (UOS), which exploits the periodic structure of power-of-two microscaling to derive a distribution-independent optimal scaling boundary Qmax=7.25 without calibration or search, and Pre-Normalization Quantization (PNQ), which quantizes unnormalized softmax exponentials before row-wise summation to preserve normalization by construction. Experiments on Wan2.2 and HunyuanVideo show that MXAttention closes at least 95% of the VBench Imaging Quality gap between OCP MXFP4 and FP16, substantially improves frame-level similarity, and preserves FP16-level generation quality with less than 0.01 absolute degradation on all reported VBench metrics. MXAttention also achieves performance competitive with strong NVFP4-based baselines with negligible overhead when fused into the attention pipeline. The implementation is publicly available in MindIE-SD.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：视频扩散 Transformer 中的注意力计算成本高昂（二次复杂度）。MXFP4（基于 OCP MX 规范的 4-bit 微缩放格式）提供了一条低精度加速的可行路径，但其在注意力机制中的直接应用会导致生成质量严重下降。
- **核心问题**：识别出两个主要的数值失效模式：
  - **截断–下溢权衡**：MXFP4 的 32 元素块共享一个二的幂次缩放因子。标准 OCP 转换将归一化块最大值映射到 [4,8)，但 E2M1 元素格式最大可表示值为 6，导致 (7,8) 内的值饱和截断；而 Truncation-Free Scaling (TFS) 将最大值映射到 (3,6] 以避免截断，却加剧了小值的舍入和下溢。两者构成对立权衡。
  - **逐行归一化误差**：在 FlashAttention 的在线 softmax 循环中，直接做法使用未量化的指数块更新行和 ℓ，却用量化后的块更新输出累加器 Ō，导致最终注意力权重的行和不为 1（实验中平均为 0.9336），引入行相关的缩放误差。
- **研究动机**：开发一种无需校准数据（data-free）、无需量化感知训练（QAT）或逐层搜索的后训练量化（PTQ）方法，解决上述失效模式，实现 MXFP4 注意力接近 FP16 的生成质量。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 Universal Optimal Scaling（UOS）

- **核心思想**：基于二的幂次缩放引入的周期结构，证明最优缩放边界（Qmax）与块最大值分布无关，仅由 E2M1 网格决定。从而推导出封闭形式的全局最优解 Qmax = 7.25。
- **关键细节**：
  - 定义归一化块最大值 \(X_q = M / 2^{\lceil \log_2(M/q) \rceil}\)，其取值范围为 \((q/2, q]\)。
  - 定义全局量化误差目标函数 \(J(q) = \mathbb{E}[D(X_q)]\)，其中 \(D(x) = \frac{1}{x^3} \int_0^x (v - \Pi_{G^+}(v))^2 dv\) 是 E2M1 网格的归一化累积投影误差。
  - 关键引理：由于周期化密度 \(H(t) = \sum_{k} f_U(t+k)\) 具有周期 1，端点处满足 \(g(q/2) = 2g(q)\)。代入 Leibniz 积分规则后，导数符号简化为 \(J'(q) = g(q)[D(q) - D(q/2)]\)，完全由网格决定。
  - 针对 E2M1 精确积分得到：在 \(6 \leq q \leq 7\) 时 \(J'(q) < 0\)，在 \(7 \leq q \leq 8\) 时 \(J'(q) = g(q)(4q-29)(4q-27)/(8q^3)\)，唯一过零点为 \(q = 29/4 = 7.25\)。再加上全域分析，证明为全局最优。
- **算法流程**：对于每个非零 MXFP4 块，计算最大绝对值 M；取 \(e = \lceil \log_2(M/7.25) \rceil\)，共享缩放因子 \(\sigma = 2^e\)；然后用 \(\sigma\) 归一化后投影到 E2M1 网格。

### 2.2 Pre-Normalization Quantization（PNQ）

- **核心思想**：在在线 softmax 循环中，将未归一化的指数块 **先量化**，然后将同一个量化后的块同时用于行和更新和输出累加器更新，从而保证最终注意力权重的行和精确为 1（精确算术下）。
- **关键细节**：
  - 直接放置的问题：行和使用未量化指数 \(\tilde{P}_{ij}\)，输出更新使用量化指数 \(\hat{P}_{ij}\)，导致不一致。
  - PNQ 做法：\(\hat{P}_{ij} = Q^*(\tilde{P}_{ij})\)，然后 \(\ell_i \leftarrow \alpha \odot \ell_i + \hat{P}_{ij} \mathbf{1}\)，\(\tilde{O}_i \leftarrow \text{Diag}(\alpha) \tilde{O}_i + \hat{P}_{ij} \hat{V}_j\)。所有更新使用相同的量化值。
  - 命题 1：在该流程下，最终诱导的注意力权重满足 \(P^{\text{PNQ}}_i \mathbf{1} = 1\)（精确算术）。
  - 注意：PNQ 不改变元素级 MXFP4 量化器，仅改变量化结果的复用位置。
- **整体管线（Algorithm 2）**：对 Q/K 应用固定 Hadamard 旋转降异常值；所有 MXFP4 量化（Q, K, V, 以及 softmax 指数块）均使用 UOS 边界 Qmax=7.25；在在线 softmax 循环中使用 PNQ。

### 2.3 理论贡献总结

- 证明了 UOS 的最优边界是全局的、分布无关的，首次为 MXFP4 缩放提供了闭合形式最优解。
- PNQ 通过构造性方法消除了归一化误差，无需额外全局缩放或后处理。

- **主要结论**：MXAttention 作为一种无数据的后训练量化框架，成功解决了 MXFP4 注意力的两个关键数值问题，使得 4-bit 注意力的生成质量接近 FP16 水平。

## 8. 不足与局限

- **模型覆盖有限**：仅测试了两个视频扩散模型，未在图像扩散、LLM、Transformer-based 分类器等场景验证，通用性待确认。
- **资源信息缺失**：未报告推理所需的 GPU 型号、显存占用、延迟加速比等具体硬件指标，无法评估实际部署效率。
- **混合精度策略**：Wan2.2 的主实验使用了部分高精度保留（Block 0 + 最后两步），可能掩盖了全 4-bit 下的真实退化情况（虽然消融实验已展示全 4-bit 结果，但主实验对比并未基于公平的全 4-bit 设置）。
- **理论假设风险**：UOS 依赖周期化密度 \(H(t)\) 的 Fourier 表示，虽然结论在几乎所有分布下成立，但极端分布（如 Dirac delta）可能导致边界密度为零，导数判据失效。作者没讨论这种退化情况。
- **数值 overflow 边界**：UOS 允许 (7, 7.25] 的窄 overflow-rounding 区间，理论证明平衡是最优的，但实际中少量饱和仍可能累积误差，尤其在长序列或深模型中未充分验证。
- **PNQ 的算术假设**：PNQ 保证精确算术下的行归一化，但实际浮点运算仍会引入微小误差（文中提及但未量化）。此外，若最大指数值因量化被破坏（文中证明在 UOS 下 1 可精确表示），整体归一化因子为正数，但奇异场景（如全零块）可能需额外处理。
- **未对比更早的 MXFP4 量化方法**：如 TetraJet（TFS）、OAS 等，虽然提到了 OAS 与 UOS 的关系，但缺乏直接实验对比。
- **消融实验仅覆盖一个降噪步**：UOS 边界验证和 PNQ 机制验证仅分析了初始降噪步或少量步骤，未评估在完整推理链中的累积效应。

## 摘要
基础模型为脑电图（EEG）分析提供了一种有前景的范式，能够利用来自海量未标注数据集的泛化表征。然而，基于Transformer的架构面临一个关键瓶颈：全局注意力机制将注意力内存状态与信号持续时间耦合，导致连续监测期间出现内存溢出。为解决这一问题，我们引入了S-CEReBrO（流式CEReBrO），它是专为连续监测设计的CEReBrO架构的演进版本。我们提出的新颖窗口化交替注意力机制将注意力计算分解为固定大小的时空窗口，确保KV缓存内存恒定，因为只有活动窗口需要驻留注意力图。实证缩放分析证实，窗口化交替注意力可以处理比全自注意力长100倍、比低秩线性注意力长3倍的信号。与低秩线性注意力在长上下文上的表现相比，窗口化交替注意力仅需55%的内存，同时推理吞吐量提升2.1倍。S-CEReBrO在超过12,000名受试者的25,000多小时记录上进行预训练，在11个下游任务中的7个任务上达到了最先进的性能，且参数量最多减少60%。这项工作向着实现高效、可泛化且连续的脑电监测迈出了重要一步。附带的代码仓库已公开可用。

## Abstract
Foundation models offer a promising paradigm for Electroencephalography (EEG) analysis, leveraging generalizable representations from vast unlabeled datasets. Yet, Transformer-based architectures face a critical bottleneck: global attention mechanisms couple the attention memory state to the signal duration, causing memory overflow during continuous monitoring. To address this, we introduce S-CEReBrO (Streaming CEReBrO), an evolution of the CEReBrO architecture designed for continuous monitoring. Our novel Windowed Alternating Attention mechanism factorizes attention computation into fixed-size spatiotemporal windows, guaranteeing constant KV cache memory as only the active window requires resident attention maps. Empirical scaling analysis confirms that windowed alternating attention can process signals 100X longer than full self-attention and 3X longer than low-rank linear attention. Compared to low-rank linear attention on long contexts, windowed alternating attention requires 55% of the memory while increasing inference throughput by 2.1X. Pre-trained on >25,000 hours of recordings from >12,000 subjects, S-CEReBrO achieves state-of-the-art performance on 7 of 11 downstream tasks, with up to 60% fewer parameters. This work represents a significant step toward the realization of efficient, generalizable, and continuous EEG monitoring. An accompanying code repository is available.

## 1. 论文的核心问题与整体含义

论文聚焦于**连续脑电监测（Continuous EEG Monitoring）**中的内存瓶颈问题。其核心背景与驱动动机如下：

- **EEG数据的长期挑战**：EEG信号以 `C通道 × T时间步` 形式呈现。硬件限制了通道数 `C`（通常为2–64），但时间长度 `T` 在长期监测中无限增长（如癫痫检测等应用场景），构成数据规模的主要挑战。
- **Transformer的致命瓶颈**：基于Transformer的EEG基础模型（如LaBraM、CBraMod等）依赖全局注意力机制，其注意力内存状态（KV Cache）与信号时长 `T` 耦合，导致连续监测时内存需求线性（甚至平方级）增长，最终溢出，无法在可穿戴设备等资源受限的硬件上持续运行。
- **现有方案的不足**：当前SOTA模型（LaBraM等）具备强表达能力，但均保持全局感受野，驻留内存随 `T` 缩放；部分模型被迫采用固定窗口分块处理，割裂了信号的连续性。文本语言中的窗口注意力方法无法直接迁移至脑电信号，因为EEG是**2D非线性的时空结构**，而非文本的1D线性语法。
- **整体含义**：论文提出S-CEReBrO（Streaming CEReBrO），通过引入**窗口化交替注意力（Windowed Alternating Attention）**，将驻留内存与信号时长解耦，实现内存恒定（O(1) KV Cache）的计算，在连续监测场景下兼顾效率与精度。

## 2. 论文提出的方法论

### 核心思想

S-CEReBrO的核心设计原则是**算法局部性（Algorithmic Locality）**：将注意力计算分解为固定大小的时空窗口，仅有当前活动窗口需要驻留内存，旧token被及时驱逐（evict），从而保证KV缓存内存与`T`无关。

### 关键技术细节

**（1）时空Token化（Spatiotemporal Tokenization）**
- **Patching**：对每个通道应用长度`L`、步长`S`的滑动窗口，得到patch张量 `P ∈ R^{C×Np×L}`。
- **特征投影**：共享卷积编码器将每个patch映射为潜在嵌入 `E_{c,i} ∈ R^{de}`。
- **时空嵌入**：使用索引式时间嵌入矩阵 `W_pos` 和基于3D电极坐标（x,y,z）经共享MLP映射的连续空间嵌入 `W_chan`，最终输入张量为：
  `H^{(0)}_{c,i} = E_{c,i} + W_pos,i + W_chan,c`

**（2）窗口化时间注意力（WTA, Windowed Temporal Attention）**
- 每个通道独立建模时间依赖，query `q_{c,i}` 仅关注局部时间邻域 `N_t`（大小 `wt`）。
- 通过**逐层膨胀因子（dilation `d_l`）** 与**偏移因子（shift `s_l`）** 扩展有效感受野，不增加内存开销：
  `N_t(i,l) = {k | k = i + (j·d_l + s_l), j ∈ [−⌊(wt−1)/2⌋, ..., ⌈(wt−1)/2⌉]}`

**（3）窗口化空间注意力（WSA, Windowed Spatial Attention）**
- 在固定时间索引上促进跨通道信息交换，空间邻域 `N_s` 大小为 `ws`。
- 同样使用逐层膨胀与偏移因子，让不同深度下空间距离较远但生理相关的通道能够间接交互。

**（4）长程依赖的间接传播机制**
关键巧妙之处在于：尽管单个WTA窗口是局部的，但交替排列的WSA层在时间步之间混合通道特征，使信息在模型深度传播中跨窗口间接交互，从而近似全局感受野。

**（5）流式处理策略**
采用**FIFO（First In First Out）流式处理**维持连续状态化感受野，与当前SOTA模型被迫采用的固定窗口分块（将信号视为孤立片段）形成鲜明对比。

### 注意力复杂度对比

| 方法 | 注意力复杂度 | KV Cache内存 |
|------|------------|-------------|
| 全自注意力（LaBraM） | O((CT)²) | O(T) |
| 交替注意力（CEReBrO） | O(CT(C+T)) | O(T) |
| 低秩线性注意力（BIOT） | O(CT) | O(T) |
| **S-CEReBrO（窗口化交替）** | **O(CT)** | **O(1)** |

### 预训练策略

采用掩码自编码（MAE）范式：随机替换固定比例的patch为共享可学习的`[MASK]` token，通过线性投影层重建原始patch，损失函数为masked与visible位置的加权均方误差之和。

**（1）窗口化交替注意力在内存效率上具有压倒性优势：**

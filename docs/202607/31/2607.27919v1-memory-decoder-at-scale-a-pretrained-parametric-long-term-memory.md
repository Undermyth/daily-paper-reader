## 摘要
仅解码器语言模型将长期记忆与推理纠缠在单一参数集中，使得难以独立扩展记忆容量。记忆解码器引入了一种参数化的长期记忆模块，但仅在相对较小的规模上进行了研究。在本工作中，我们提出了大规模记忆解码器，将记忆模型扩展至6.9B参数，并在300B令牌上进行了预训练。在此数据规模下，索引与搜索的联合成本使得标准Faiss流水线不可行。我们通过分布式Faiss索引与检索流水线，以及稀疏、按批次加载的kNN分布，解决了这一瓶颈。在不同模型规模下，我们发现，将更多参数分配给记忆相比仅扩展基础模型能带来更好的参数-性能权衡。在17个基准测试中，将一个6.9B的通用记忆与Pythia-410M配对，其平均得分从29.86提升至37.34，以总参数减少39%的优势超越了Pythia-12B（37.24）。对于范围从0.6B到14B的Qwen3基础模型，1.7B的领域记忆在每个规模下将三个领域的平均得分提升了超过9个点。总体而言，我们的结果表明，独立扩展预训练记忆为提升语言模型性能提供了一条更具参数效率的路径。

## Abstract
Decoder-only language models entangle long-term memory and reasoning in a single parameter set, making it difficult to scale memory capacity independently. Memory Decoder introduces a parametric long-term memory module but only studies it at a relatively small scale. In this work, we present Memory Decoder at Scale, scaling memory models up to 6.9B parameters and pretraining them on 300B tokens. At this data scale, the combined cost of indexing and search makes a standard Faiss pipeline infeasible. We address this bottleneck with a distributed pipeline for Faiss indexing and retrieval, together with sparse, batch-wise loading of kNN distributions. Across model scales, we find that allocating more parameters to memory yields a better parameter-performance tradeoff than scaling the base model alone. On 17 benchmarks, pairing a 6.9B general memory with Pythia-410M raises its average score from 29.86 to 37.34, surpassing Pythia-12B (37.24) with 39% fewer total parameters. For Qwen3 Base models ranging from 0.6B to 14B, 1.7B domain memories improve the average score across the three domains by more than 9 points at every scale. Overall, our results demonstrate that independently scaling pretrained memory offers a more parameter efficient path to improving language model performance.

  - RAG 和 kNN-LM 依赖外部检索，推理时需要额外的存储和检索开销；

## 2. 方法论

### 2.1 整体框架

- **模块组成**：
  - 冻结的基础语言模型 \( M_\theta \)（负责推理）；
  - 可独立预训练、可插拔的参数化记忆模块 \( M_\psi \)；
  - 离线构建的 kNN 检索分布作为监督信号。
- **推理方式**：基础模型与记忆模块并行处理同一上下文，输出分布线性插值：
  \[
  p_{final}(y|c_t) = (1-\alpha) p_\theta(y|c_t) + \alpha p_\psi(y|c_t)
  \]
  无需在线检索。

### 2.2 训练目标

- 采用分布对齐 + 语言建模的联合损失：
  \[
  \mathcal{L}_{mem} = \beta \cdot D_{KL}(p_{ret}(\cdot|c_t) \| p_\psi(\cdot|c_t)) + (1-\beta) \cdot [-\log p_\psi(x_t|c_t)]
  \]
  - KL 项：让记忆模块模仿 kNN 检索分布（捕捉多种合理的续接）；
  - 语言建模项：防止偏离语料真实分布。

### 2.3 大规模 kNN 分布构建（关键技术）

在 207B token 规模下，标准 Faiss 管线因索引和搜索的二次复杂度而不可行，本文提出**分布式 Faiss 管线**：

1. **嵌入压缩**：用 OPQ（Optimized Product Quantization）将 4096 维 hidden state 压缩至 256 维，降低存储与距离计算开销；
2. **索引分片**：用 HNSW 作为 quantization 器，将向量划分为 IVF 分片，每片覆盖连续质心区间，支持独立 GPU 搜索；
3. **大规模并行搜索**：HNSW 路由查询到对应分片队列，GPU 并行执行局部 IVFPQ 搜索，最后合并候选并取 top-K。

### 2.4 稀疏存储与分布式加载

- **稀疏 kNN 分布存储**：仅保留概率超过阈值 𝜖 的 token，存储量从 \(O(N|V|)\) 降为 \(O(N+M)\)，在 Pile 上每行平均仅保留 64.95 个 token-概率对，约为稠密存储的 250 倍压缩比；
- **分布式流式加载**：利用内存映射数组和偏移量，按批次只读取训练所需条目，保持与标准语言模型预训练相同的接口。

  - 训练预算（20% vs 100%）的影响；
  - 训练目标控制（记忆 vs 附加 CPT）；
  - 可提取记忆化评估（两种探针 × 1,024 个训练样本）；
  - 记忆对检索监督的保真度（4 个指标，1,024 个样本）。

### 5.2 充分性评估

- **优点**：覆盖了多个模型家族（Pythia、Qwen3、OLMo）、多种规模、多种领域，且包含从端到端下游任务到内部机制（记忆保真度、可提取性）的多层次评估，实验设计较为全面；
- **潜在不足**：
  - 所有实验均在英文或特定领域数据上进行，未验证多语言泛化；
  - 未与其他记忆增强预训练方法（如 RETRO、TRIME、LMLM）进行直接对比；
  - 部分消融实验仅在特定配置下进行，跨配置的结论推广需谨慎。

## 6. 主要结论与发现

1. **记忆扩展比骨干扩展更参数高效**：
   - Pythia-410M + Mem-6.9B 达到 37.34 平均分，超过 Pythia-12B 的 37.24，总参数减少 39%；
   - 在相同总参数下，Base+Memory 配置在多个规模点上优于单一大模型。

2. **通用记忆在知识密集型任务上提升最大**：
   - TriviaQA 最高提升 8.81 分（2.8B 骨干）；
   - 2WikiMultiHopQA 最高提升 5.68 分（1.4B 骨干）；
   - 51 个"任务×规模"组合中，记忆改进 47 项、持平 1 项。

3. **领域记忆跨骨干和跨词汇表有效**：
   - 1.7B 领域记忆在 0.6B~14B 的 Qwen3 骨干上平均提升均超过 9 分；
   - 仅用 20% 训练预算即可从 Qwen3 词汇迁移至 OLMo 词汇，OLMo-3 上平均提升 7.77 分。

4. **记忆在 few-shot 下仍有效**：3-shot 和 5-shot 设置下增益保持稳定（1.39~1.52 分）。

5. **记忆能力的来源是训练目标而非接口**：与匹配容量的附加 CPT 模块相比，记忆目标在四个对比中均占优。

6. **记忆使训练内容更可提取**：严格 EM@8,16 从 42.4% 提升至 49.7%，领域锚点补全从 22.6% 提升至 56.5%。

7. **记忆对检索监督的保真度高**：top token 匹配率 86.62%，Pearson r=0.917，表明记忆学到了分布结构而非仅 argmax。

---

## 7. 优点

- **工程创新突出**：分布式 Faiss 管线（嵌入压缩 + 分片 + 并行搜索）和稀疏 kNN 分布存储，使 207B token 规模的记忆预训练成为可能；
- **模块化架构设计优雅**：记忆可独立预训练、独立扩展、跨模型复用、推理时可拔插切换领域，无需改动骨干；
- **结论一致性强**：多个实验互相印证（匹配参数预算、匹配训练预算、跨模型传输），令人信服地证明了"记忆扩展优于骨干扩展"；
- **客观的控制实验**：通过附加 CPT 模块排除插值接口的混淆；通过 kNN 保真度分析揭示记忆的内部工作机制；
- **对实践有直接指导意义**：给出了参数分配建议（小骨干 + 大记忆）和领域适配方案（领域记忆银行）。

## 8. 不足与局限

### 8.1 训练开销

- 虽然推理无需外部检索，但 **kNN 分布构建的离线开销巨大**（索引 + 检索），该成本随语料规模增长，是额外的预处理负担，论文仅提及"压缩和分片缓解了瓶颈"而未给出具体成本数字。

### 8.2 超参数敏感性

- 插值系数 α 依赖验证集调优，且不同任务最优 α 差异大（从 0 到 1.0），在实际部署中缺乏自适应机制；
- 固定 α 可能并非最优，尤其在任务分布变化时。

### 8.3 实验覆盖范围

- **未进行多语言评估**；所有领域均为英文；
- 未与同类记忆增强预训练方法（RETRO/TRIME/LMLM）直接对比；
- 领域记忆仅覆盖生物、法律、金融三个领域，对其他高价值领域（如代码、医学）的泛化未知；
- 未报告 6.9B 记忆与 14B+ 骨干搭配的行为。

### 8.4 记忆提取风险

- 论文自身展示了记忆增强**增加了训练数据的可提取性**（EM@8,16 提升 7.3 个百分点，领域锚点补全提升 33.9 个百分点），这带来显著的数据隐私与合规风险，论文未给出缓解措施。

### 8.5 理论解释不足

- 论文实证表明记忆对知识密集型任务最有效，但未从理论层面解释"为什么小骨干 + 大记忆优于大骨干"的机制；
- 未讨论记忆容量与知识覆盖率的饱和曲线。

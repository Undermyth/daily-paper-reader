## 摘要
固定状态序列模型将无限的历史压缩至有限状态，使其联想记忆能力大致受限于状态维度；注意力机制通过为每个标记保留一个键值条目来突破这一限制，但计算复杂度为二次，且缓存随序列增长。我们研究中间地带：一个稀疏缓存，仅当输入为新颖时才分配一个槽位，因此其大小追踪不同项目的数量而非标记数量。分配规则是DP均值聚类规则，即狄利克雷过程混合的小方差极限，但不是作为隐变量推断，而是作为深度递归主干的键值记忆算子。我们以两种形式开发它：具有固定浓度的静态缓存和浓度跟随近期新颖率的惊奇自适应变体。在一个具有冗余度的受控联想记忆基准上，我们展示了该缓存在仅存储不同项目时匹配全注意力记忆，在记忆与大小前沿上优于固定预算的驱逐缓存，并且在状态空间主干上，它以所有测试模型中最低的记忆成本同时回答了一个记忆查询和一个长程聚合问题。该分配是端到端可学习的：一个仅由任务损失训练的双参数新颖阈值门精确恢复该规则，而一个过参数化的门则失败，因此有效成分是归纳偏置而非容量。证据是一系列中等规模的受控机制研究，在四个真实数据流（推荐、系统日志、临床事件和保险索赔）上确认了不同项目属性；真实主干、真实语料库的语言验证在配套研究中进行。

## Abstract
Fixed-state sequence models compress an unbounded past into a bounded state, which caps their associative recall at roughly the state dimension; attention escapes the cap by keeping a key-value entry for every token, at quadratic compute and a cache that grows with the sequence. We study the middle ground: a sparse cache that allocates a slot only when an input is novel, so its size tracks the number of distinct items rather than the number of tokens. The allocation rule is the DP-means clustering rule, the small-variance limit of a Dirichlet-process mixture, used not as latent-variable inference but as the key-value memory operator for a deep recurrent backbone. We develop it in two forms, a static cache with a fixed concentration and a surprise-adaptive variant whose concentration follows the recent novelty rate. On a controlled associative-recall benchmark with redundancy we show that the cache matches full-attention recall while storing only the distinct items, that it dominates a fixed-budget eviction cache on the recall-versus-size frontier, and that on a state-space backbone it answers both a recall query and a long-range aggregate at the lowest memory of any model tested. The allocation is learnable end to end: a two-parameter novelty-threshold gate trained on the task loss alone recovers the rule exactly, whereas an over-parameterized gate fails, so the operative ingredient is the inductive bias rather than capacity. The evidence is a family of controlled mechanism studies at modest scale, with the distinct-items property confirmed on four real streams (recommendation, systems logs, clinical events, and insurance claims); a real-backbone, real-corpus language validation is pursued in a companion study.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有序列模型在记忆能力与计算成本之间存在根本性矛盾：
  - **固定状态模型**（如结构化状态空间模型 S4、Mamba）将无限历史压缩到有界状态，运行代价低（线性时间、常数推断内存），但状态维度决定了其联想记忆能力上限——无法有效执行超出状态维度的内容寻址召回。
  - **注意力机制**（Transformer）通过为每个 token 保留一个键值条目突破了该上限，实现了出色的召回，但代价是缓存随序列线性增长、计算复杂度为二次。
- **动机**：真实序列中大量重复和冗余项（如单词、ID）重复出现，真正需要记忆的是**不同项（distinct items）** 而非所有 token。因此存在自然中间地带：稀疏缓存，仅在输入新颖时分配槽位，大小正比于不同项数目而非 token 数目。
- **整体含义**：论文旨在提出并验证一种“不同项缓存”（Dirichlet-Process Cache），作为固定状态与全注意力之间的折中方案，在保持低成本（缓存小、读取快）的同时实现与全注意力相当的召回能力。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 利用 **DP-means 聚类规则**（Dirichlet Process mixture 的小方差极限）作为键值记忆的操作符：
  - 当新输入与所有现有槽位（slot）的键都不相似（超过阈值 τ）时，**分配一个新槽位**；
  - 否则，**合并到最相似的已有槽位**（更新其值或保持首次出现）。
- 缓存大小 ≈ 数据中不同项的数量，而非 token 数量。

### 2.2 关键技术细节
- **新颖性度量**：`nov_t = 1 - max_i sim(k_t, κ_i)`，其中 sim 为余弦相似度。
- **分配规则**（DP-means）：
  ```
  若 nov_t > τ → 新建槽位 (k_t, v_t)
  否则 → 合并至 argmax_i sim(k_t, κ_i)
  ```
- **读取**：查询 q 通过注意力（softmax）与所有槽位键交互，加权平均槽值。
- **成本**：
  - 建立缓存：O(N·|slots|)（需计算每个 token 与所有现有槽的相似度）；
  - 读取：O(|slots|) ≈ O(K)（K 为不同项数目），远小于全注意力的 O(N)。
- **可学习门控**（Approach I 变体）：
  - 将硬阈值替换为可微门：`g_t = σ(a · (nov_t - b))`，两参数 a,b 由任务损失训练；
  - 训练时通过软掩码（将 log g_t 加到注意力 logits）保持可微；
  - 推理时保留 top-M 高 g 的 token 作为硬缓存。
- **惊奇自适应浓度**（Approach II）：
  - 维持一个温度 T_t（以新奇率 o_t 的指数滑动平均更新）；
  - 槽位预算 M_t = M_0 + β T_t，随新奇率动态增减；
  - 当槽数超过 M_t 时，驱逐使用次数最少的槽位。
  - 适应非平稳需求，在平稳流中则与固定预算相当。

## 6. 主要结论与发现

1. **DP 缓存匹配全注意力召回，仅存储不同项**：在 4 倍冗余度下，存储量减少 4 倍（64 槽 vs 256 槽），召回率为 1.00，而固定预算驱逐缓存（H2O）在同一预算下只有 0.92。
2. **召回-大小前沿上 DP 缓存优于所有固定预算驱逐缓存**：受控合成数据和真实 MovieLens 任务均证明。
3. **分配是可端到端学习的**：仅两参数的新颖阈值门即可从任务损失中自动学习 DP 规则，而过参数化的门失败，表明关键因素是**归纳偏置**（新颖特征+低容量阈值），而非容量。
4. **与状态空间模型结合时，混合体同时满足召回和长期聚合，总缓存为不同项数目**，优于 SSM（仅聚合）和全注意力（缓存大）。
5. **自适应浓度变体在非平稳流上优于匹配固定预算**：当工作集波动时，自适应预算动态调整，以相同平均缓存实现更高召回；在平稳流上两者持平，验证了自适应设计的合理性。
6. **不同项属性在四个真实域恒成立**：缓存槽数基本等于不同实体数（电影、日志模板、药物、诊断码），与阈值无关（在 0.5–0.8 宽范围内稳定）。
7. **成本权衡**：建立缓存需 O(N·|slots|) 扫描（较重），但读取仅为 O(K)（K 为不同项数），在长序列多次读取场景中明显优于注意力的 O(N)。

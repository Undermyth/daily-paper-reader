## 摘要
一个智能体如何仅从持续的原始感官输入及其自身运动序列中构建其世界的结构化地图，尤其是在自然变异意味着精确感官模式很少重复的情况下？克隆结构因果图算法（CSCG）作为一种规范的 hippocampus 模型，展示了如何从别名观测中学习可解释的地图。然而，CSCG 需要预定义的离散字母表，其期望最大化公式不易与现有神经网络模块结合，从而阻碍了原始图像序列的端到端处理。我们通过将 CSCG 重新表述为单一、完全可微的模块 gradCSCG，并将其与学习的向量量化变分自编码器（VQ-VAE）感知前端相结合，消除了这一障碍。软发射前向传播允许地图学习目标回流到感知中，而一组损失平衡机制则缓解了联合训练期间的模块崩溃。我们首先证明，梯度训练通过从严重别名的观测中恢复房间拓扑，在原始符号网格世界上再现了 CSCG 的结果。其次，我们表明在 MNIST 图像序列上，地图恢复仍然稳健，其中每次访问一个位置都会生成其分配数字的新采样图像。在四个高度别名的环境中，端到端管道成功地从视觉输入中直接发现了底层邻接图，具有高边精度和召回率。这项工作提供了 CSCG 可以作为深度学习架构中可组合构建模块的原理验证。

## Abstract
How can an agent build a structured map of its world from nothing but an ongoing sequence of raw sensory input and its own movements, especially when natural variation means exact sensory patterns rarely repeat? The Clone-Structured Causal Graph algorithm (CSCG), a normative hippocampus model, shows how an interpretable map can be learned from aliased observations. However, CSCG requires a predefined discrete alphabet, and its expectation-maximization formulation is not easily combined with existing neural network modules, preventing the end-to-end processing of raw image sequences. We remove this barrier by reformulating CSCG as a single, fully differentiable module, gradCSCG, and coupling it to a learned vector-quantized variational autoencoder (VQ-VAE) perceptual front-end. A soft emission forward pass allows the map-learning objective to flow back into perception, while a set of loss-balancing mechanisms mitigates module collapse during joint training. We demonstrate, first, that gradient training reproduces CSCG's results on original symbolic grid worlds by recovering room topology from heavily aliased observations. Second, we show that map recovery remains robust on MNIST image sequences, where each visit to a location yields a newly sampled image of its assigned digit. Across four heavily aliased environments, the end-to-end pipeline successfully uncovers the underlying adjacency graph with high edge precision and recall, directly from visual input. This work provides a proof of principle that CSCG can serve as a composable building block in a deep learning architecture.

## 2. 论文提出的方法论

### 核心思想
将CSCG重写为完全可微的模块**gradCSCG**，并与一个学习的向量量化变分自编码器（VQ-VAE）感知前端耦合，使得地图学习目标（负对数似然）可以反向传播到视觉编码器，同时保持CSCG的克隆机制和可解释性。

### 关键技术细节
1. **感知前端（VQ-VAE）**：
   - 卷积编码器 \(E_\phi\) 将每张图像映射到连续向量 \(z_t\)。
   - 通过最近邻搜索量化到码本 \(\{e_k\}_{k=1}^K\)，得到离散 token \(k_t\) 和对应嵌入 \(q_t\)。
   - 直通估计器（straight-through estimator）允许梯度从量化后的表示反向传播。
   - 同时输出一个**软码本后验** \(\log \rho_t(k) = \log \text{softmax}_k(-\|z_t - e_k\|^2/\tau)\)，用于与后续序列模型的软耦合。
   - 损失：重建损失 \(L_{\text{rec}}\) + 承诺损失 \(L_{\text{commit}}\)；码本通过指数移动平均（EMA）更新。

2. **序列模型（gradCSCG）**：
   - 基于动作条件克隆HMM（hidden Markov model），每个 token 可以分配多个“克隆”状态（clone），这些克隆发出相同的观察但处于不同的转换上下文，从而消除观察别名（aliasing）。
   - 状态空间 \(S\) 包含 \(N = 1 + \sum_k C_k\) 个状态（含一个 sink 状态）。
   - 发射矩阵是确定性的：状态 \(s\) 只发出其对应的 token。
   - 参数：初始状态 logits \(\pi\) 和动作条件转移 logits \(\Theta \in \mathbb{R}^{A \times N \times N}\)。
   - **前向递归**（对数空间）：
     \[
     \log \alpha_1(j) = \log \bar{\pi}_j + \log B_{j,o_1}
     \]
     \[
     \log \alpha_{t+1}(j) = \text{logsumexp}_i [\log \alpha_t(i) + \log T_{a_t,i,j}] + \log B_{j,o_{t+1}}
     \]
   - 损失为平均负对数似然 \(\tilde{L}_{\text{gradCSCG}} = -\frac{1}{|B|} \sum \frac{1}{T} \ell^s(o_{1:T}|a_{1:T-1})\)。

3. **软发射耦合**：
   - 在 soft forward pass 中，用 \(\log \rho_t(\omega(j))\)（软后验）代替硬发射项 \(\log B_{j,o_t}\)，使得序列损失关于编码器参数可微。
   - 当温度 \(\tau \to 0\) 时退化为硬发射。

4. **联合训练与损失平衡**：
   - **三阶段训练**：① VQ-VAE 独立预热；② 端到端联合训练（包含重建、承诺、归一化序列损失、多样性惩罚）；③ 冻结编码器，微调 gradCSCG（硬发射）。
   - **长度归一化**：序列损失除以序列长度 \(T\)，防止长序列湮没重建损失。
   - **权重退火**：序列损失权重 \(\lambda_t\) 线性增加，先稳定视觉编码。
   - **多样性惩罚**：\(L_{\text{div}} = \log K - H(\bar{\rho})\)，鼓励码本均匀使用。
   - **防崩溃机制**：监控码本 perplexity，保存最佳检查点，可选阈值限制和死代码复活。

### 算法流程（单步联合训练）
1. 编码图像得到 \(z_t\)
2. 量化得到 \(q_t, \tilde{q}_t\)，EMA更新码本
3. 计算重建/承诺损失
4. 计算软后验 \(\log \rho_t\)
5. 运行 soft forward pass 得到似然，计算归一化序列损失和多样性损失
6. 联合损失 \(L_{\text{joint}} = L_{\text{rec}} + \beta L_{\text{commit}} + \lambda_t \tilde{L}_{\text{gradCSCG}} + \alpha_{\text{div}} L_{\text{div}}\)
7. 用 Adam 更新编码器、解码器、序列模型参数

### 地图提取与评估
- 解码：Viterbi 算法获得最可能状态路径 \(s^*_{1:T}\)。
- 状态到地点分配：每个状态映射到多数占用的真实地点 \(\chi(s)\)。
- 评估指标：状态到地点纯度、动作下一地点准确率、地图边精确率/召回率/F1（从 Viterbi 路径或投影转移图得到）。

## 6. 主要结论与发现

1. **梯度训练再现 CSCG 结果**：在符号网格世界中，gradCSCG 通过反向传播而非 EM 训练，同样能恢复房间拓扑、将同名观察拆分为正确位置的克隆。
2. **端到端从图像恢复地图**：联合 VQ-VAE 在四个高别名 MNIST 图像环境中，成功恢复底层邻接图，获得 1.00 的 recall 和 0.95-1.00 的 Viterbi 路径 F1 分数；状态到地点纯度达 0.95-1.00，动作准确率 0.97-1.00。
3. **损失平衡机制至关重要**：长度归一化、权重退火和多样性惩罚防止了码本崩溃，使联合训练稳定。
4. **Viterbi 路径读取地图精度高**：相比投影转移图（大量弱假边），Viterbi 路径加最低流量截断（如 >0.2% 步数）可获得高精度地图。
5. **per-observation clone 预算可手动调整**：`room` 环境中为混淆数字分配更多 clone 可显著减少总状态数而不牺牲性能。

## 7. 优点

- **方法创新**：首次将 CSCG 转换为完全可微模块，实现了与神经网络前端的端到端联合训练，打开了 CSCG 作为深度学习可组合构建块的道路。
- **可解释性与结构化**：保留了 CSCG 的克隆机制和可解释图结构，同时能够处理高维、可变图像输入。
- **损失平衡设计实用**：提出的长度归一化、退火、多样性惩罚等机制有效解决了联合训练中的模块竞争问题，可推广至类似 hybrid 模型。
- **评估指标**：设计了形式化的拓扑恢复评估套件（purity, action accuracy, edge F1 from Viterbi path），对意图恢复地图的任务合理。
- **代码开源**：提供完整实现和环境，研究可复现。

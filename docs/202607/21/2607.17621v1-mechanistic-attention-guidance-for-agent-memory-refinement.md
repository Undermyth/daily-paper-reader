## 摘要
现有的自演化记忆系统主要基于文本输出（如任务轨迹和反思）来改进智能体记忆。然而，这种基于文本的范式很少融入内部机制信号，导致检索到的记忆在任务执行过程中如何被实际利用这一问题尚未被充分探索。这一局限可能导致不可靠的错误归因和幻觉性记忆修改。在本工作中，我们表明检索-头部注意力提供了揭示片段级记忆利用的机制性信号。通过聚合记忆片段和决策步骤上的注意力，我们构建了一个上下文利用矩阵，该矩阵能暴露重复出现的记忆使用模式并指示相应的精炼策略。基于这一发现，我们提出了注意力引导记忆精炼（AGMR）框架，该框架利用注意力揭示的使用模式来指导目标性片段级记忆更新。AGMR针对失败执行修正或增强记忆，针对成功执行简化记忆，并通过重新执行验证每次更新。在交互式决策基准上的实验表明，与纯文本记忆精炼基线相比，AGMR同时提升了任务性能和记忆效率。代码可在 https://anonymous.4open.science/r/AGMR_code-3262/ 获取。

## Abstract
Existing self-evolving memory systems mainly improve agent memory based on textual outputs, such as task trajectories and reflections. However, this text-based paradigm rarely incorporates internal mechanistic signals, leaving how retrieved memory is actually utilized during task execution underexplored. This limitation can lead to unreliable error attribution and hallucinated memory modifications. In this work, we show that retrieval-head attention provides a mechanistic signal for revealing segment-level memory utilization. By aggregating attention over memory segments and decision steps, we construct a context utilization matrix that exposes recurring memory-use patterns and indicates corresponding refinement strategies. Building on this observation, we propose Attention-Guided Memory Refinement (AGMR), a framework that uses utilization patterns revealed by attention to guide targeted segment-level memory updates. AGMR corrects or enhances memory for failed executions, simplifies memory for successful executions, and verifies each update through re-execution. Experiments on interactive decision-making benchmarks show that AGMR improves both task performance and memory efficiency over text-only memory refinement baselines. - **背景**：现有的大语言模型（LLM）智能体依赖外部记忆系统存储和复用经验。这些记忆常通过文本形式（任务轨迹、反思总结）自我演化，即执行任务→记录文本轨迹→通过模型生成的文本分析错误、提取经验并改写记忆。
- **核心问题**：这种纯文本驱动的记忆演化范式存在两个关键缺陷：
  - **缺乏内部机制信号**：文本只记录模型的输出，而不揭示驱动其决策的内部注意力流。LLM生成的解释可能看似合理但不忠实（后验合理化），导致错误归因不可靠。
  - **忽略记忆实际利用情况**：现有工作研究如何组织、更新记忆，却很少探究检索到的记忆在执行过程中是否被真正利用、如何利用。因此记忆精炼缺乏结构化证据框架，容易产生幻觉性修改。
- **整体含义**：本文试图填补这一空白，通过在模型内部挖掘检索头注意力的机制性信号，构建更可靠的记忆利用证据，从而引导更精准、更高效的记忆更新。

#### 2. 方法论：核心思想、关键技术细节

- **核心思想**：检索头注意力（retrieval-head attention）可以作为记忆利用的机制性代理。通过识别并聚合检索头部对记忆片段的注意力，构建**上下文利用矩阵**（Context Utilization Matrix），揭示段级记忆利用模式，再根据不同模式采取针对性的精炼策略。
- **关键技术细节**：
  1. **检索头选取**：
     - 构造一个监督数据集 D_ret，包含 (key_context, formatted_prompt) 对，其中 key_context 是理想应被检索到的记忆片段，formatted_prompt 是决策步前的完整模型输入。
     - 对每个注意力头，计算其从 prompt 最后一个 token 到 key_context 所有 token 的总注意分数，选取 top-5 头部作为检索头集合 H_ret。
     - 通过遮盖实验验证这些头部对记忆增强效果的重要性。
  2. **上下文利用矩阵构建**：
     - 给定检索到的轨迹记忆 m* 分段为 [s0, s1, ..., sL]，智能体执行任务得到轨迹 τ = [u0, ..., uT]。
     - 对于第 t 步生成前，取最后一个 prompt token qt，聚合 H_ret 中每个头对每个片段 sℓ 中非观测部分（¯sℓ）的注意力，并除以当前 prompt 长度 nt 进行归一化，得到 step-level 利用分数 ˜a_{t,ℓ}。
     - 将各步向量堆叠得到矩阵 C ∈ R^{(L+1)×(T+1)}，C_{ℓ,t} 即为片段 ℓ 在第 t 步的利用强度。
  3. **记忆利用模式诊断**（失败执行）：
     - 先通过语义反光镜（Semantic Reflector）定位最早的关键错误步 uj 及支持正确动作的记忆片段 si。
     - 再通过注意力引导精炼器（Attention-Guided Refiner）比较理想利用 (uj→si) 与观察到的利用列 C_{:,j}，判断属于三种模式之一：
       - **Attended but wrong（关注但错误）**：模型关注了相关片段但其中含有误导内容 → 原地修正/澄清。
       - **Missed relevant memory（遗漏相关记忆）**：相关片段存在但未被关注 → 增强该片段的显著性（如添加关键关键词、明确指令结构）。
       - **Distracted by irrelevant memory（被无关记忆干扰）**：无关片段吸引了异常注意力干扰决策 → 加强目标片段并重写干扰片段，将其转化为防护栏。
  4. **低利用冗余简化**（成功执行）：
     - Semantic Reflector 首先识别语义冗余的片段候选列表 R。
     - Attention-Guided Refiner 利用 C 中的统计量（平均利用 ¯c_ℓ 和最大利用 c^{max}_ℓ），只有当片段既语义冗余又低利用率（低于阈值）时才被删除或压缩。
  5. **重新执行验证**（Re-execution Verification）：
     - 所有候选更新都通过用精炼后的记忆 m′ 重新执行任务来验证。
     - 失败分支：若成功或性能提升超过阈值则接受；否则最多重试3次（WebShop为2次）。
     - 成功分支：仅当保持成功才接受，否则立即回滚。

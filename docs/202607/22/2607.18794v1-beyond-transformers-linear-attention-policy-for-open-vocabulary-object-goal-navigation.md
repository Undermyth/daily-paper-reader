## 摘要
开放词汇物体目标导航（Open-Vocabulary Object Goal Navigation, OVON）要求智能体在部分可观测条件下运行，因此有效的内部状态更新对导航性能至关重要。这种更新由策略网络实现，近期方法采用基于Transformer的骨干网络，通过在上下文窗口上应用自注意力来整合时序信息。然而，我们的控制实验表明，在基于Transformer的策略下，性能并不随上下文长度扩展，这质疑了自注意力在导航状态整合中的适用性。为此，我们提出基于线性注意力的导航（Linear Attention-based Navigation, LANav），采用线性注意力（LA）作为策略骨干，以维护结构化的状态更新，而非在上下文窗口上使用自注意力。在相同设置下评估的多种LA变体中，LANav始终优于基于Transformer的基线。随着状态更新机制变得更加结构化和规范化，性能得到提升，凸显了状态更新设计的重要性。为了提升状态更新效果，我们引入加权状态扩展线性注意力（Weighted State-Expansion Linear Attention, WSLA），它将每个注意力头的状态扩展为多个子状态，并使用可学习的加权读出机制来聚合扩展后的子状态。配备WSLA后，LANav在HM3D-OVON上实现了36.4%的平均成功率（SR），在宏观平均SR上比基于Transformer的对应方法高出6.3个百分点，同时保持了计算效率。按距离分层的结果显示，在长距离场景中增益更大，而HSSD迁移和微调则展示了跨场景分布的鲁棒性。在Unitree Go2上的实际部署中，经过50次试验实现了82%的成功率，支持了LANav的实际可行性和仿真到现实的迁移。

## Abstract
Open-Vocabulary Object Goal Navigation (OVON) requires agents to operate under partial observability, making effective internal state updates critical for navigation performance. This update is implemented by the policy network, where recent approaches adopt Transformer-based backbones with self-attention over a context window to integrate temporal information. However, our controlled experiments show that performance does not scale with context length under Transformer-based policies, questioning the suitability of self-attention for state integration in navigation. To this end, we propose Linear Attention-based Navigation (LANav), which adopts linear attention (LA) as the policy backbone to maintain a structured state update rather than self-attention over the context window. Across multiple LA variants evaluated under identical settings, LANav consistently outperforms Transformer-based baselines. Performance improves as state update mechanisms become more structured and regulated, highlighting the importance of state update design. To improve state update effectiveness, we introduce Weighted State-Expansion Linear Attention (WSLA), which expands each attention head's state into multiple sub-states and uses learnable weighted readout to aggregate expanded sub-states. Equipped with WSLA, LANav achieves 36.4% average success rate (SR) on HM3D-OVON, outperforming Transformer-based counterparts by 6.3 percentage points in macro-averaged SR, while maintaining computational efficiency. Distance-stratified results show larger gains in long-distance episodes, while HSSD transfer and fine-tuning demonstrate robustness across scene distributions. Real-world deployment on a Unitree Go2 further achieves an 82% success rate over 50 trials, supporting the practical feasibility and sim-to-real transfer of LANav.

## 2. 方法论：核心思想、关键技术细节

### 核心思想

- 采用线性注意力代替Transformer自注意力作为策略骨干，通过增量式状态更新（而非全上下文自注意力）来维护历史信息。
- 提出**加权状态扩展线性注意力（WSLA）**，通过将每个注意力头扩展为多个子状态，并引入可学习加权读出，增强状态表达能力和调控能力。

### 关键技术细节

1. **整体架构（LANav）**：
   - 输入：当前RGB图像 \(I_t\)（用冻结SigLIP视觉编码器提取768维特征）、目标语言描述 \(G\)（冻结SigLIP文本编码器提取768维特征）、上一动作 \(a_{t-1}\)（32维可学习嵌入）。
   - 三者拼接后线性投影到512维隐藏维度，构成每步嵌入 \(\tilde{o}_t\)。取最近 \(l\) 步形成上下文窗口 \(Z_t\)，输入4层解码器式骨干网络 \(\Phi\)，取当前时间步的输出 \(y_t\)，经动作头预测动作分布。
   - 动作空间：move-forward, turn-left, turn-right, look-up, look-down, stop。

2. **线性注意力骨干 vs Transformer骨干**：
   - **Transformer**：每个时间步对上下文窗口内所有token进行自注意力（二次复杂度 \(O(l^2)\)），查询与所有键相互作用。
   - **LA**：每个注意力头维护状态矩阵 \(S_t \in \mathbb{R}^{d_k \times d_v}\)，按更新规则 \(S_t = \text{Update}(S_{t-1}, k_t, v_t)\) 增量更新，查询读出 \(o_t = q_t^\top S_t\)。复杂度 \(O(l)\)。
   - 不同LA变体（Linear Transformer, DeltaNet, Gated DeltaNet）主要区别在于状态更新规则（累积、基于预测误差修正、门控衰减等）。

3. **WSLA（加权状态扩展线性注意力）**：
   - **状态扩展**：每个头 \(h\) 通过线性投影将查询和键扩展为 \(E=4\) 个子头（\( \tilde{q}_t^{(h,e)}, \tilde{k}_t^{(h,e)}\)），值向量共享。
   - **门控更新**：每个子头独立预测门控因子 \(\beta_t^{(h,e)}, \gamma_t^{(h,e)}\)，先对上一状态衰减，计算预测误差，再用门控Delta规则更新子状态。
   - **加权读出**：引入可学习logit向量 \(\lambda \in \mathbb{R}^E\)，用softmax归一化权重聚合各子头输出 \(o_t^{(h,e)}\)，得到头输出 \(u_t^{(h)}\)。
   - 头输出拼接后经RMSNorm和SiLU门控，作为当前层输出。

## 6. 主要结论与发现

1. **线性注意力骨干一致优于RNN和Transformer**：在HM3D-OVON上，所有LA变体（Linear Transformer, DeltaNet, Gated DeltaNet, WSLA）的SR均高于GRU和Transformer基线，尤其是在语义泛化（VAL SEEN SYN）上优势明显。
2. **线性注意力受益于更长训练上下文，Transformer不**：图2显示，增大训练上下文长度 \(l_{train}\) 能提升LA的性能，而Transformer的高峰SR反而可能下降；LA在测试时对上下文长度变化更稳定。
3. **结构化状态更新是关键**：从Linear Transformer到DeltaNet、Gated DeltaNet再到WSLA，性能逐步提升，证明更精细的写入、保留、读出机制对导航历史整合至关重要。
4. **WSLA达到最佳性能**：在HM3D-OVON上平均SR 36.4%（比最强Transformer基线30.1%高6.3个百分点），同时在线FLOPs（~0.048G/action）远低于Transformer（42.53G，\(l=1000\)时）。
5. **长距离任务增益更大**：距离分层评估显示WSLA在15m以上场景比Transformer提升7.68 SR、4.21 SPL。
6. **跨数据集和真实世界有效**：HSSD零样本和微调均优于Transformer；真实机器人82%成功率，验证了sim-to-real迁移能力。

- **方法设计优雅**：WSLA通过简单的子状态扩展和可学习加权读出，在不显著增加参数和算力的前提下大幅提升性能。

## 8. 不足与局限

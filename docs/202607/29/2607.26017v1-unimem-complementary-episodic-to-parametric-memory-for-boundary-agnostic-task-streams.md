## 摘要
记忆对于LLM智能体积累任务经验和重用特定任务执行策略至关重要。然而，在边界无关且不断演化的任务流中实际部署时，会暴露出基本的稳定性-可塑性困境。基于外部检索的记忆可以快速吸收新证据，但往往无法内化重复出现的执行模式，并产生推理时的检索开销。参数记忆一旦学习，能够实现稳定高效的执行，但通常依赖于明确的任务边界和固定的参数预算。受人类大脑通过互补的情景存储和渐进巩固来平衡可塑性与稳定性的启发，我们提出了UniMem，一种用于自主记忆管理的自路由框架。UniMem使用可学习路由令牌作为记忆控制器，实现互补记忆通路之间的自适应协调：新颖或稀疏的任务保留在情景缓冲区中用于检索增强执行，而重复出现的可靠模式则被巩固到可扩展的参数记忆中。通过使用路由令牌和参数记忆块将任务识别与任务执行解耦，UniMem在部署期间无需任务标签即可按需扩展记忆，同时避免无控制的参数增长。在长时流式任务序列上的实验表明，UniMem在保持执行保真度的同时始终优于基线，在三个骨干模型上平均提升4.0个EM点。

## Abstract
Memory is essential for LLM agents to accumulate task experience and reuse task-specific execution strategies. However, real-world deployment over boundary-agnostic and evolving task streams exposes a fundamental stability-plasticity dilemma. External retrieval-based memory can rapidly absorb new evidence, but it often fails to internalize recurring execution patterns and incurs inference-time retrieval overhead. Parametric memory enables stable and efficient execution once learned, but typically relies on explicit task boundaries and fixed parameter budgets. Inspired by the human brain, which balances plasticity and stability through complementary episodic storage and gradual consolidation, we propose UniMem, a self-routing framework for autonomous memory management. UniMem uses learnable routing tokens as memory controllers, enabling adaptive coordination between complementary memory pathways: novel or sparse tasks are retained in an episodic buffer for retrieval-augmented execution, while recurring and reliable patterns are consolidated into expandable parametric memory. By decoupling task identification from task execution with routing tokens and parametric memory blocks, UniMem expands memory on demand without task labels during deployment or uncontrolled parameter growth. Experiments on long-horizon streaming task sequences show that UniMem consistently outperforms baselines while maintaining execution fidelity, achieving an average gain of 4.0 EM points across three backbone models.

## 2. 论文提出的方法论

- **核心思想**：通过可学习的**路由令牌**作为记忆控制器，将任务识别与任务执行解耦。路由令牌决定每个输入查询走哪条记忆通路——  
  - **已知/重复模式** → 对应的参数记忆块（Procedural KV Memory）进行稳定执行。  
  - **新颖/稀疏任务** → 送入情景缓冲（Episodic Buffer）进行检索增强执行（RAG），待积累足够证据后通过无监督聚类和筛选，再巩固为新的参数记忆单元。

- **关键技术细节**：
  1. **路由令牌矩阵**：包含 `K` 个已知任务令牌 `e₁...e_K` 和一个新颖哨兵令牌 `e_NOVEL`。  
  2. **路由规则**：根据查询最后一层隐藏状态与各令牌的点积计算分布，仅当最高已知令牌概率 > 新颖哨兵概率且 > 阈值 τ_route（默认0.7）时才激活参数记忆，否则走情景通路。  
  3. **参数记忆块**：每个已知任务关联一个 Procedural KV Memory——每层可学习的键值对，通过交叉注意力注入冻结的主干模型，并用可学习门控 `g^(l)` 控制注入强度。  
  4. **优化目标**：分解为路由损失 `L_route`（仅更新路由令牌）和执行损失 `L_exec`（仅更新选中的参数记忆块与门控）。  
  5. **增量扩展阶段**：  
     - Phase I：初始化已知任务路由令牌，并通过保留一部分伪未见任务校准新颖哨兵。  
     - Phase II：情景缓冲满时触发无监督聚类（NCD距离 + HDBSCAN），通过嵌入质心离群过滤和NCD内聚性检查筛选高质量簇，为每个合格簇分配新路由令牌+新参数记忆块并进行SFT。不合格簇保留在缓冲区等待后续证据。

- **公式/算法流程**（文字说明）：
  - 推理时：对查询 q，计算 `p(e_k|q) = softmax(h_q^T e_k)`，若 `max(p_known) > p_novel` 且 `max(p_known) ≥ τ_route`，则选中对应参数记忆块，否则走RAG。
  - 训练时：总体损失 `L_total = L_route + L_exec`，其中 `L_route` 学习路由选择，`L_exec` 学习使用选定记忆生成响应。

## 6. 论文的主要结论与发现

- UniMem在**所有设定下一致优于基线**，平均提升4.0 EM点。  
- 分离路由与执行（参数记忆块）是性能关键：相比TOKMEM（单令牌），UniMem在SNI-100任务上提升约7% EM。  
- 情景缓冲的RAG回退为稀疏任务提供了有效覆盖，门控机制防止了参数干扰。  
- 记忆单元按需增长，而非每新任务分配：在16K样本/100新颖任务中仅创建76个新参数单元，10个稀疏任务留在缓冲区。  
- 路由令牌精度随任务数增加略有下降但仍保持85%+（LlaMA-3.1-8B），表明路由空间可扩展。

## 7. 优点

- **创新性**：首次将互补学习系统理论系统应用于LLM智能体记忆管理，实现“情景→参数”的自洽生命周期。  
- **实用性**：无需任务标签部署，无需固定参数预算，能在开放流式任务中自主扩展记忆。  
- **设计优雅**：路由令牌仅作轻量选择器，参数记忆块采用可插拔KV Memory，仅需极少量额外参数（约60K/任务）。  
- **实验充分**：多骨干、多任务、多指标，并做了详尽的消融和动态分析。

## 8. 不足与局限

- **保守的巩固策略**：当前只有高质量簇（达到NCD阈值且样本数≥50）才被巩固，可能低估了低密度但有用模式的利用价值，影响记忆效率。  
- **参数记忆实例化单一**：仅使用Procedural KV Memory，未探索其他PEFT模块（如LoRA、adapter）的兼容性及不同容量/效率权衡。  
- **未考虑隐私与安全**：在现实部署中，情景缓冲可能保留敏感用户信息，缺乏过滤与审计机制。  
- **计算开销**：NCD全对计算在高缓冲量时（>2000）虽采用锚点近似但仍有成本；聚类步骤依赖超参数（如阈值），鲁棒性需进一步验证。  
- **实验范围**：只在英文NLP基准上评估，未涉及多模态、长文档或更复杂的具身/环境类任务。  
- **长期遗忘与记忆间干扰未深入分析**：随着记忆单元增多，路由准确性是否会进一步下降？参数记忆块间的交叉干扰？

## 摘要
有状态的多模态助手对图像进行一次编码，但可能在多个轮次后回答关于图像的问题。注意力引导的视觉KV驱逐假设当前不相关的证据在未来仍然可忽略，尽管未来的问题未知。我们探讨何时遗忘视觉事实实际上是安全的，并引入因果视觉记忆审计（CVMA），这是一个配对的单预填充框架，用于测试当视觉区域、整个图像或先前的助手文本变得不可用时，后续答案会损失什么。在VisDial和ConvBench上，当前注意力可能将未来有用的区域排得比随机还差，尽管诊断性边际效用控制显示有相当大的选择空间。当后续轮次不需要视觉时，聚合分数隐藏了这种失败；受控和库存生成的历史揭示了第二条逃避路线，其中助手文本KV替换了图像KV，用于已经陈述过的事实，但对于未陈述的事实不可靠。在测试的堆栈中，安全遗忘依赖于低的未来视觉依赖性或者事实特定的语言表达——而不是低的当前注意力。

## Abstract
Stateful multimodal assistants encode an image once but may answer questions about it many turns later. Attention-guided visual-KV eviction assumes that evidence irrelevant now will remain dispensable, although future questions are unknown. We ask when a visual fact is actually safe to forget and introduce the Causal Visual Memory Audit (CVMA), a paired single-prefill framework that tests what later answers lose when a visual region, the whole image, or prior assistant text becomes unavailable. On VisDial and ConvBench, current attention can rank future-useful regions worse than random even though a diagnostic marginal-utility control shows substantial selection headroom. Aggregate scores hide this failure when later turns do not need vision; controlled and stock-generated histories reveal a second escape route, in which assistant-text KV replaces image KV for facts already stated but not reliably for unstated facts. In the tested stacks, safe forgetting is supported by low future visual dependence or fact-specific verbalization---not by low current attention.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：多模态助手（VLM）在对话中会对图像进行一次编码并保持视觉KV缓存。当前的视觉KV缓存压缩策略（如注意力引导的驱逐）假设：当前轮次不相关的视觉证据，在未来轮次也会不相关。但未来的问题未知，这种假设可能导致重要视觉信息被过早遗忘，从而损害后续问答质量。
- **研究动机**：真实场景中，一张图像可能包含多个视觉事实（如红色杯子和时钟），第一问只关注杯子，将时钟区域驱逐；然而几轮后用户问时钟时间，时钟曾被“看见”但未被“保留”也未“说出来”，导致遗忘。现有工作认识到未来问题可能改变重要性，但聚合指标无法区分三种情况：视觉证据被正确保留、后续轮次不需要视觉、或者视觉事实已通过助手文本表达。本文旨在解耦这些机制。
- **整体含义**：论文对“安全遗忘”进行因果审计，提出一个可重用的分析框架，揭示当前注意力作为未来效用代理的失败条件，并明确视觉记忆与文本记忆之间的转换边界。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **Causal Visual Memory Audit (CVMA) 框架**：
    - 将对话视为一个持久记忆轨迹：图像仅在首轮预填充，后续轮次扩展同一缓存。CVMA对同一对话应用配对的干预，测量因果效用。
    - **三个测试组件**：
        1. **代理测试（Proxy Test）**：检验当前注意力是否预测未来因果效用。计算每个视觉区域的注意力得分，与“移除该区域后未来轮次NLL损失”的相关性。
        2. **依赖性测试（Dependence Test）**：通过移除全部图像KV，测量整个对话对视觉的依赖程度（Dd）。据此分组分析不同依赖性水平下的性能损失。
        3. **来源测试（Source Test）**：通过2×2阶乘设计（图像KV是否可用 × 助手文本KV是否可用），检验视觉事实是否已转移到文本记忆中。特别地，控制事实是否被明确说出，区分“口头化”与“仅暴露”。
- **关键技术细节**：
    - 使用教师强迫（teacher forcing）保持未来轨迹固定。
    - 因果估计量：`Ud,r = Ld(-r) - Ld(full)` 表示移除区域r后未来平均NLL变化。
    - 视觉依赖性：`Dd = Ld(-image) - Ld(full)`。
    - 代理遗憾：`Rp-cd,q = Ld(retain(p,q)) - Ld(retain(c,q))` 比较两种排序策略。
    - 图像-文本交互：`Id,b` 通过四个条件的NLL组合衡量冗余/替代。
- **压缩控制**：比较五种选择器（静态top-k, LOOK-M, PrefixKV, SnapKV, NACL）和一种非删除量化覆盖（coverage，基于KIVI风格的低比特KV量化），在相同视觉预算下做公平比较。

## 6. 论文的主要结论与发现

1. **注意力不是未来效用**：当前注意力与未来区域因果效用呈负相关（Spearman -0.103, 4×4）；注意力排序比随机还差；而边际效用控制显示存在选择空间——说明代理失效，而非选择不可为。
2. **驱逐失败仅当且仅当后续需要视觉**：聚合损伤均值不大，但隐藏了依赖视觉的对话严重受损、低依赖对话甚至去噪改善（Q1 vs Q4差异显著）。损伤-依赖性相关性在0.399~0.682之间，跨模型、跨预算一致。
3. **口头化定义图像-文本记忆边界**：只有被明确说出的视觉事实才能可靠地转移到助手文本KV中，从而替代图像KV；仅仅看到但未说出口的事实不会留下可用的文本踪迹。替换增益对已陈述事实为+2.215 nats，对未陈述事实为-0.177 nats（接近零）。
4. **低当前注意力不能作为安全遗忘的证书**；安全遗忘条件为：低未来视觉依赖 或 事实已被口头化。

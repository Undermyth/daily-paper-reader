## 摘要
线性注意力模型允许固定的状态大小和每个token固定的计算量。然而，由于其有限的状态大小，线性注意力模型在长上下文召回方面落后于基于softmax注意力的Transformer架构。增加线性注意力的状态大小可以提升召回性能，但代价是更高的FLOPs。在这项工作中，我们提出了稀疏Delta记忆（SDM），这是一种通过稀疏寻址方案将门控线性RNN的隐藏状态扩展到数个数量级更高容量的架构。SDM扩展了Gated DeltaNet架构，用对大显式记忆的稀疏读写替换了密集的键值外积。我们表明，在isoFLOP约束和相同参数数量下，更高的状态记忆容量显著提升了上下文学习和长上下文检索任务的性能。此外，通过学习SDM记忆的初始状态从而将其用作参数化记忆，我们展示了该模型在广泛的常识和推理任务上进一步改进。

## Abstract
Linear attention models allow a fixed state size and a fixed amount of compute per token. However, due to their limited state size, linear attention models fall behind in long-context recall compared to softmax-attention-based transformer architectures. Increasing the state size of linear attention improves recall performance but at the cost of higher FLOPs. In this work, we introduce Sparse Delta Memory (SDM), an architecture that scales the hidden state of gated linear RNNs to orders of magnitude higher capacity using a sparse addressing scheme. SDM extends the Gated DeltaNet architecture by replacing the dense key-value outer product with sparse reads and writes to a large explicit memory. We show that, under an isoFLOP constraint and with an identical number of parameters, a higher state memory capacity significantly improves performance on in-context learning and long-context retrieval tasks. Moreover, by learning the initial state of the SDM memory and therefore using it as a parametric memory, we show that the model further improves on a wide range of common-knowledge and reasoning tasks.

## 1. 论文的核心问题与整体含义

- **研究动机**：线性注意力模型（包括Gated DeltaNet、Mamba2等）通过固定大小的压缩隐状态保持恒定计算和内存消耗，但受限于极小的状态容量，在长上下文召回任务上远落后于使用softmax注意力的Transformer（后者KV缓存随序列长度线性增长）。增大状态可提升召回，但传统密集更新方式使计算量线性增加。
- **核心问题**：如何在保持FLOPs不变的前提下，大幅提升线性RNN的隐状态容量，从而弥补长上下文召回差距？
- **整体含义**：论文提出**稀疏Delta记忆（SDM）**，通过稀疏读写机制将状态大小扩展数千倍（在1.4B模型中状态从GDN的98KB提升至211MB），在等计算预算下显著提升长上下文检索、上下文学习以及常识推理能力，甚至超过全注意力模型。

## 2. 方法论

- **核心思想**：将Gated DeltaNet（GDN）中的密集键值外积更新替换为**稀疏读写**。维护一个显式的大内存表 \(M_t \in \mathbb{R}^{N \times d_v}\)（\(N\) 远大于常规状态维度），每次只选择前 \(W\) 个槽位进行写入、前 \(R\) 个槽位进行读取，其余槽位保持不变。
- **关键技术细节**：
  - **稀疏索引（Product-Key Memory, PKM）**：将读写键/查询投影为两个 \(\sqrt{N}\) 维向量，通过外积和 top-k 操作高效选出 \(W/R\) 个槽位，避免全量打分。
  - **Gated Delta Write**：对选中的写入槽位应用遗忘门 \(\alpha_t\) 和输入门 \(\beta_t\)，并使用Delta规则更新 \(M_t[i] \leftarrow \alpha_t M_{t-1}[i] + \beta_t \cdot k_t^{(i)} \cdot (v_t - \tilde{M}_t[i])\)，未选中槽位保持不变。
  - **Sparse Read**：对选中的读取槽位按softmax权值加权求和得到输出 \(y_t = \sum_{i\in I_t^r} q_t^{(i)} M_t[i]\)。
  - **可学习的初始状态 \(M_0\)**：将 \(M_0\) 作为可训练参数，模型可在预训练中将知识存入记忆，推理时零额外开销。
  - **等FLOP设计**：通过设置 \(W = R = d_{qk}^{\text{GDN}}\)，并使用少量头数（头数 \(H\) 作为容量调节超参），确保SDM与GDN具有相同的理论FLOPs和参数量。
  - **高效训练**：采用块级WY表示实现块内并行，块间递推，并通过稀疏二指针合并计算交互矩阵，以及使用in-place更新+反向恢复实现内存高效反向传播。

## 6. 主要结论与发现

- **SDM在所有计算规模下一致优于GDN**：缩放定律显示SDM损失曲线始终低于GDN，且在8B参数下超过FullAttn。
- **长上下文召回大幅提升**：在RULER基准上，SDM（1.4B：31.2分，8B：50.2分）显著高于GDN（20.0/34.2），部分任务甚至达到或超过FullAttn。
- **短上下文性能**：SDM在15个推理/常识任务上的平均准确率优于GDN，8B时高于FullAttn，得益于可学习初始状态编码的预训练知识。
- **学习初始状态仅对SDM有效**：GDN因状态太小无法从可学习 \(M_0\) 获益，而SDM凭借大容量显式内存能从初始状态中提取有用信息。
- **稀疏访问自适应**：模型自动调整读写分布的锐度，根据任务需求在均匀访问和集中访问间平衡。
- **训练开销可接受**：尽管内核优化不足，SDM 8B模型训练速度仅比GDN慢1.49倍，推理解码速度仅慢10%，但比FullAttn快6倍。

## 7. 优点

- **创新性稀疏扩展方案**：首次将Product-Key Memory与Gated DeltaNet结合，在恒定FLOP下实现状态容量指数级增长。
- **系统化的等FLOP设计**：严格确保对比公平，证明提升主要来自容量而非参数。
- **广阔而深入的实验**：覆盖从0.2B到8B的多个规模，并进行了详细消融，验证了容量、初始状态、稀疏配置等关键因素。
- **实用的训练算法**：设计了高效块级并行和稀疏交互计算，使大状态记忆可以实际训练。
- **开源的代码**：提供可复现的代码仓库。

## 8. 不足与局限

- **内核效率低**：当前SDK的MFU远低于GDN，HBM访问成为瓶颈，训练速度慢约1.49倍（1.4B下），在大规模生产部署前需要更优的CUDA/汇编内核。
- **内存占用大**：SDM状态大小与模型参数相当（8B模型状态约8 GB），在资源受限设备上可能不适用。论文指出其状态占用相当于204万token的KV缓存，但对于超长序列仍有优势。
- **部分任务依然困难**：在RULER的多键任务（multikey_2）上，SDM和GDN均远低于FullAttn，表明稀疏记忆在复杂组合检索上仍有短板。
- **混合架构尚未充分优化**：FullAttn+SDM交替的混合实验仅做初步探索（1.4B），未在更大规模验证；且混合设计可能带来额外的工程复杂性。
- **未评估绝对长序列（>1M token）**：虽然代码数据上测试到1M token，但RULER最大128k，对极限极长上下文的性能未知。
- **消融控制**：虽然对比了不同读写窗口，但在8B规模下仅测试了默认配置，未对更大窗口/更多头数做全面消融，容量-效率的Pareto前沿未完整探索。

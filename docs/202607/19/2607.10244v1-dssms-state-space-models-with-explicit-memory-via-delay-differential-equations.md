## 摘要
状态空间模型（SSMs）已成为高效长序列建模的强大范式，提供并行训练和快速的线性时间递归推理。然而，与其他递归架构一样，SSMs必须将无界历史压缩为固定大小的状态，这限制了上下文保留，并使长程上下文中的精确检索变得固有地困难。为了克服这一限制，我们提出了延迟状态空间模型（DSSMs），这是一种受延迟微分方程（DDE）启发的对角SSMs扩展，通过显式的延迟状态反馈增强离散SSM递归。使显式延迟反馈实用化需要新的稳定性参数化、历史管理和FFT训练工具。我们通过一种基于简单延迟无关稳定性条件的实用离散化和参数化来应对这些挑战。为了绕过直接时域核构造，我们推导了DSSM传递函数并在频域中计算核，使用核轮廓移位抑制混叠并恢复准确的FFT训练。实验上，DSSMs在针对性延迟检索任务上显著改进，同时在大多数标准序列指标上优于S4D，并在其他指标上保持接近。

## Abstract
State Space Models (SSMs) have emerged as a powerful paradigm for efficient long-sequence modeling, offering parallel training and fast linear-time recurrent inference. However, like other recurrent architectures, SSMs must compress an unbounded history into a fixed-size state, which limits context retention and makes precise retrieval over long-range context inherently difficult. To overcome this limitation, we propose Delay State Space Models (DSSMs), a delay differential equation (DDE)-inspired extension of diagonal SSMs that augments discrete SSM recurrences with explicit delayed-state feedback. Making explicit delayed feedback practical requires new stability parameterization, history management, and FFT-training tools. We address these challenges with a practical discretization and parameterization grounded in a simple delay-independent stability condition. To bypass direct time-domain kernel construction, we derive the DSSM transfer function and compute kernels in the frequency domain, using a kernel contour shift to suppress aliasing and recover accurate FFT training. Empirically, DSSMs substantially improve targeted delayed-retrieval tasks while outperforming S4D on most standard sequence metrics and remaining close on the others.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：状态空间模型（SSMs）是高效的长序列建模框架，支持并行训练和线性时间递归推理。但与其他递归架构一样，SSMs 必须将无限的历史压缩到一个固定大小的状态中，导致长程上下文保留不足，精确检索（如 copy、associative recall）变得困难。
- **动机**：注意力机制（Transformers）在长程记忆上表现优异，但推理代价高。SSMs 虽有高效推理，但长程精确检索能力弱。受延迟微分方程（DDE）启发，论文认为引入显式延迟状态反馈可以增强 SSM 的显式记忆能力，同时保持并行训练和快速推理优势。

## 2. 论文提出的方法论

- **核心思想**：将 SSM 的连续 ODE 动力学扩展为 DDE，即`\dot{h}(t) = A h(t) + A_d h(t - \tau) + B x(t)`。离散化后，递归更新中增加一个来自历史缓冲区的延迟项 `\tilde{h}_{t-\tau}`。
- **关键技术细节**：
  - **对角结构**：A 和 A_d 限定为对角矩阵，解耦为 N 个独立标量 DDE。
  - **离散化与稳定性**：引入共享连续基参数 ζn（Re(ζn)<0），通过 ZOH 风格离散化得到离散预算 `\bar{\zeta}_n = exp(ζn Δt)∈(0,1)`。再用 sigmoid 门控 `p_n` 在主线系数 `\bar{\lambda}_n = (1-p_n)\bar{\zeta}_n` 和延迟线系数 `\bar{\mu}_n = p_n \bar{\zeta}_n e^{i θ_n}` 之间分配预算，确保 `|\bar{\lambda}_n|+|\bar{\mu}_n|<1` 从而满足离散稳定性。
  - **历史管理**：维护固定大小缓冲区（`L_max` 个最近状态），通过线性插值从非整数延迟位置取近似状态。
  - **参数化**：延迟 τ 通过 bounded ratio q = sigmoid(ντ) 参数化，τ = Δt + q·(τ_max - Δt)。延迟分支相位 θ 可在 0 或 π 附近初始化，产生不同偏置（增强对齐/强调变化）。
  - **频域训练（FFT）**：由于延迟反馈破坏了时域闭式核，作者推导出 Z 域传递函数 `K(z) = c [1 - z^{-1}\bar{λ} - z^{-k}D(z)\bar{μ}]^{-1} \bar{b}`，其中 `D(z)=(1-α)+αz^{-1}`。为避免时域混叠，引入**核轮廓移位**：对核施加指数阻尼 `ρ^t`（`ρ^M = ε_shift`），在傅里叶网格计算，再通过 `ρ^{-t}` 恢复线性核，平衡混叠抑制与数值误差。
  - **算法流程**：对每个通道，在 FFT 网格上评估移位传递函数，IFFT 得到阻尼循环核，恢复线性核，然后用标准频域卷积计算输出。

## 6. 主要结论与发现

- DSSM 在合成延迟检索任务上显著优于 S4D、Mamba 和 LSTM，在固定延迟下接近甚至超越 Transformer 基线，在可变延迟下更鲁棒。

- 参数分析表明 DSSM 保持了一个分布式的延迟通道库，而非坍缩到单一延迟。
- 核轮廓移位技术有效解决了延迟反馈导致的时域混叠，FFT 训练与标准 SSM 速度相当，解码吞吐量近乎常数。

## 7. 优点

- **方法创新**：首次将延迟微分方程的思想系统引入 SSM，为 SSM 赋予了显式记忆机制，同时保留了并行训练（FFT）和 O(1) 解码效率，克服了传统 SSM 长程检索瓶颈。
- **完备的稳定性与离散化工具**：通过共享预算 + sigmoid 门控保证稳定性，支持任意连续延迟的线性插值。
- **高效的频域训练**：通过核轮廓移位解决混叠问题，无需修改 SSM 基础架构即可用 FFT 训练。
- **实验设计严谨**：合成任务精准测试延迟记忆能力，通用任务验证迁移性，消融和参数分析揭示机制。

## 8. 不足与局限

- **任务适应性**：当任务不依赖延迟结构时，DSSM 相比 S4D 增益有限（如 Speech Commands 双向变体反而略低 0.14%）。
- **解码内存**：需缓存过去 L_max 个隐藏状态，内存随历史窗口线性增长（尽管不随总序列长度增长），比标准 SSM 的常数状态更大。
- **FFT 训练中的精度折衷**：核轮廓移位依赖于 ε_shift 的选择，需要在混叠抑制和浮点放大误差之间权衡，极端长序列可能影响数值精度。
- **初始化与超参数敏感**：延迟分支的相位（θ≈0 或 π）、初始门控 p_n 以及延迟位置初始化需根据任务启发式设定，缺乏自动调优策略。
- **未涵盖大规模语言模型**：实验仅聚焦于分类/回归和小型合成任务，尚未在大型自回归语言建模（如 Mamba 或 GPT-2 规模）上验证，限制了其在实际 NLP 应用中的说服力。
- **缺乏与最新混合架构（如 Jamba、Samba）的对比**：论文未与结合注意力和 SSM 的混合模型进行对比，它们同样致力于改进 SSM 的记忆能力。

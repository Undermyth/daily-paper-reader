## 摘要
HiPPO通过在线多项式投影的系数赋予循环状态记忆语义，但仅限于固定通道坐标。相比之下，现代选择性SSM依赖于令牌相关的控制和通道交互。我们提出SHiPPO（Sylvester HiPPO），一种传输投影记忆先验，将HiPPO系数记忆提升到移动的通道框架中。对于任何固定或实现的右传输路径，SHiPPO同时传输近似族和通道度量；在该路径条件下，状态在绑定移动框架中表现为普通HiPPO，并遵循Sylvester系数动态，保留了左在线记忆算子，同时增加了右作用传输。为了实现选择性SSM，我们推导了一种受限的群局部实现，包含与控制器兼容的右作用、指数调整更新、精确块仿射扫描和循环解码。我们还给出了一个同时可约性准则，用于识别右传输何时退化为静态混合加上独立标量或块状库。受控诊断表明，更大的当前令牌写入秩改善了普通预测误差，但无法恢复已写入记忆中顺序敏感的变化；传输记忆变体恢复了这一信号，而传输通路移除后信号消失。一个具有交错绑定、操作和查询的有限域关联召回诊断提供了互补的自回归证据，同时保留偏好的右作用实现。综上所述，这些结果支持SHiPPO作为一种基于机制的传输记忆先验，证据集中于记忆机制而非广泛的序列建模主导性。

## Abstract
HiPPO gives recurrent states memory semantics as coefficients of online polynomial projections, but in fixed channel coordinates. Modern selective SSMs, by contrast, rely on token-dependent control and channel interaction. We introduce SHiPPO (Sylvester HiPPO), a transported projection-memory prior that lifts HiPPO coefficient memories into a moving channel frame. For any fixed or realized right-transport path, SHiPPO transports the approximation family and channel metric together; conditional on that path, the state is ordinary HiPPO in a tied moving frame and follows Sylvester coefficient dynamics, preserving the left online-memory operator while adding right-action transport. For selective-SSM execution, we derive a restricted group-local realization with controller-compatible right actions, exponential-adjusted updates, exact block-affine scan, and recurrent decoding. We also give a simultaneous-reducibility criterion identifying when right transports collapse to static mixing plus independent scalar or blockwise banks. Controlled diagnostics show that larger current-token write rank improves ordinary prediction error but cannot recover order-sensitive changes to already-written memory; transported-memory variants recover this signal, which disappears when the transport pathway is removed. A finite-field associative-recall diagnostic with interleaved bindings, operations, and queries provides complementary autoregressive evidence while leaving the preferred right-action realization open. Taken together, these results support SHiPPO as a mechanistically grounded transported-memory prior, with evidence focused on memory mechanisms rather than broad sequence-modeling dominance.

- **核心问题**：能否让通道交互成为在线逼近记忆语义的一部分，即在记忆系数层面直接实现通道层面的顺序敏感变换，而不只是后加的混合器？高秩当前步写入（source/write）能否替代未来对已写入记忆的右传输操作？
- **整体意义**：论文提出了 SHiPPO（Sylvester HiPPO），通过右传输路径使 HiPPO 的记忆系数在移动通道框架中演化，保持了左在线记忆算子，增添了右作用项，使记忆本身具备通道交互能力。该工作为理解记忆机制提供了更精确的理论基础，而非追求广泛序列建模优势。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将 HiPPO 的在线投影问题扩展为传输投影问题。定义右传输路径 \(A_R(t)\)，其对应的状态转移矩阵 \(P(t,\tau)\) 驱动通道度量 \(M_P(t,\tau)=P(t,\tau)P(t,\tau)^\top\) 和近似族同时移动，从而保持共轭性。得到的系数矩阵 \(C_S(t)\) 满足 Sylvester 系数动力学：
  \[
  \dot{C}_S(t) = A_L(t)C_S(t) + B_L(t)f(t)^\top + C_S(t)A_R(t)
  \]
  其中左算子 \(A_L, B_L\) 继承自 HiPPO，右作用项 \(C_S A_R\) 解释为移动框架的规范项。

- **关键技术细节**：
  - **传输共轭**：SHiPPO 等价于对传输后的信号做普通 HiPPO，即 \(\text{shippo}_t(f) = \text{hippo}_t(P(t,\cdot)^\top f)\)。
  - **路径意义**：当 \(A_R\) 由控制器生成时，路径条件成立，状态路径上仍是传输投影系数。
  - **扫描兼容实现**：为适配 Mamba 风格选择性 SSM，采用受限群局部实现：通道分为宽度为 \(P\) 的组，左动力学对角化且组内共享，右传输群局部且与控制器兼容。离散更新为：
    \[
    H_t = L_tH_{t-1}R_t + \tilde{U}_t
    \]
    使用指数调整的二点源离散，支持精确块仿射前缀扫描。
  - **可约性准则**：如果所有右生成器可同时块对角化（经固定基变换），则传输退化为静态混合加上独立标量或块状库。这激励使用非可约的右传输族。

## 6. 主要结论与发现

- 增加当前步写入秩（无右传输）虽可降低整体预测误差，但**无法**恢复已写入记忆中因顺序不同引起的配对差异信号（Pair Δ NMSE 始终为 1）。
- SHiPPO 的传输记忆变体（oracle、learned、selective）**能**恢复该信号（Pair Δ NMSE 接近 0），且当评估时将 Rt 置为单位阵，信号立即消失，证明差异**完全依赖于右传输**。
- 高秩写入和未来右传输是**不同机制**，不可相互替代。
- Transport-MQAR 中，DirectGen-SingleExp 在精确准确率上明显优于无右传输基线，StructGen-Split 在坐标准确率上略有改进，但绝对数值仍较低（约 3-4% 准确率），表明长序列传输召回仍具挑战。

## 8. 不足与局限

- **实验覆盖偏窄**：仅使用合成诊断，未在真实语言建模、长程依赖（如 Long Range Arena）、图像或音频等任务上验证 SHiPPO 的实际性能。

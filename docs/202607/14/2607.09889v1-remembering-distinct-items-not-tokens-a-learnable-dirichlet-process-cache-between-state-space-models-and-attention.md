## 摘要
固定状态序列模型将无限过去压缩为有限状态，这将其关联回忆能力限制在大致状态维度内；注意力通过为每个词元保留键值条目来突破这一限制，但计算量呈二次增长，且缓存随序列增长。我们研究了一种折中方案：一种稀疏缓存，仅当输入是新颖时才分配槽位，因此其大小跟踪独特项的数量而非词元数量。分配规则是DP-means聚类规则，即狄利克雷过程混合的小方差极限，我们不将其用作潜变量推断，而是用作深度循环骨干网络的键值记忆算子。我们以两种形式开发它：具有固定集中度的静态缓存，以及其集中度跟随近期新颖率的惊喜自适应变体。在一个具有冗余性的受控关联回忆基准上，我们展示了该缓存仅存储独特项就匹配了全注意力回忆，在回忆-大小前沿上主导了固定预算的驱逐缓存，并且在状态空间骨干网络上，它以所有测试模型中最低的记忆回答了回忆查询和长程聚合。分配是可端到端学习的：仅靠任务损失训练的双参数新颖性阈值门精确恢复了该规则，而过度参数化的门则失败，因此操作要素是归纳偏差而非容量。证据是中等规模的一系列受控机制研究，独特项属性在四个真实流（推荐、系统日志、临床事件和保险索赔）上得到了确认；在配套研究中进行了真实骨干网络、真实语料库的语言验证。

## Abstract
Fixed-state sequence models compress an unbounded past into a bounded state, which caps their associative recall at roughly the state dimension; attention escapes the cap by keeping a key-value entry for every token, at quadratic compute and a cache that grows with the sequence. We study the middle ground: a sparse cache that allocates a slot only when an input is novel, so its size tracks the number of distinct items rather than the number of tokens. The allocation rule is the DP-means clustering rule, the small-variance limit of a Dirichlet-process mixture, used not as latent-variable inference but as the key-value memory operator for a deep recurrent backbone. We develop it in two forms, a static cache with a fixed concentration and a surprise-adaptive variant whose concentration follows the recent novelty rate. On a controlled associative-recall benchmark with redundancy we show that the cache matches full-attention recall while storing only the distinct items, that it dominates a fixed-budget eviction cache on the recall-versus-size frontier, and that on a state-space backbone it answers both a recall query and a long-range aggregate at the lowest memory of any model tested. The allocation is learnable end to end: a two-parameter novelty-threshold gate trained on the task loss alone recovers the rule exactly, whereas an over-parameterized gate fails, so the operative ingredient is the inductive bias rather than capacity. The evidence is a family of controlled mechanism studies at modest scale, with the distinct-items property confirmed on four real streams (recommendation, systems logs, clinical events, and insurance claims); a real-backbone, real-corpus language validation is pursued in a companion study.

## 1. 核心问题与整体含义

**研究动机**：序列模型需要处理无限长的历史信息。结构化状态空间模型（如 S4、Mamba）使用有界状态，计算高效但关联召回（associative recall）能力受限于状态维度；注意力机制通过为每个词元保留键值条目，召回能力强但缓存随序列线性增长、计算量二次方。两者之间缺乏一种**折中机制**：以稀疏缓存存储信息，其大小仅取决于序列中**独特项（distinct items）**的数量，而非词元总数。

**核心问题**：如何设计一种可学习的稀疏缓存，使其在召回性能与存储/计算成本之间取得平衡，并且能够端到端学习分配策略。

**整体含义**：本文提出一种基于狄利克雷过程（Dirichlet Process）的在线聚类规则（DP-means）作为键值缓存的操作算子，仅在输入“新颖”时分配新槽位，否则合并到最近槽位。该缓存大小自动收敛到独特项的数量，从而在关联召回任务上匹配全注意力性能，同时大幅降低缓存开销。这是对固定状态模型与注意力之间“中间地带”的首次系统性机制研究。

## 2. 方法论

### 核心思想
- 将缓存视为一组**槽位（slots）**，每个槽位存储一个键和值，附带使用计数器。
- 对每个输入键，计算其与所有现有槽位键的最大余弦相似度，定义**新颖度**：`nov_t = 1 - max_i sim(k_t, κ_i)`。
- 应用 DP-means 规则（即狄利克雷过程混合模型的小方差极限）：
  - 若 `nov_t > τ`（阈值），则**分配新槽位**，存储该键值对。
  - 否则**合并到最近槽位**（更新值或维持首次键）。
- 查询时，通过对所有槽位进行注意力（带 softmax）读出值。

### 技术细节
- **形式 I：静态狄利克雷过程缓存**（Approach I）
  - 固定阈值 τ（相当于集中度参数）。
  - 缓存大小随序列增长但饱和于独特项数量，呈现狄利克雷过程特征（开头增长为 α ln N，但饱和于真实类型数）。
- **形式 II：惊喜自适应缓存**（Approach II）
  - 阈值（或预算）由近期分配率驱动：维护一个温度变量 `T_t`（指数移动平均），当分配率高（大量新颖内容）时提高预算 `M_t = M_0 + β T_t`，缓存超过预算时驱逐最少使用的槽位。
  - 适应非平稳流：在爆发期扩容量，在稳定期回收槽位。
- **可学习门控**：将阈值替换为可微分门控 `g_t = σ(a (nov_t - b))`，通过任务损失与预算惩罚训练参数 a, b，推理时保留 g>0.5 的槽位作为硬缓存。核心发现是**归纳偏置（新颖度特征+双参数阈值）**足以恢复规则，过度参数化门（如 MLP）失败。

### 算法流程（文字说明）
1. 初始化空槽集；
2. 遍历每个输入键值对：
   - 计算与所有槽位键的余弦相似度，得最大相似度；
   - 计算新颖度 = 1 - 最大相似度；
   - 若新颖度 > 阈值（或门控为1），创建新槽；
   - 否则并入最相似槽（更新值或计数）；
3. 查询时，对槽集执行 softmax 注意力读取。

## 6. 主要结论与发现

1. **缓存大小精确跟踪独特项数量**：在冗余序列上，存储槽位收敛到独特项数，而非词元数；在 4 倍冗余下，缓存大小为注意力的 1/4，召回率 1.0。
2. **在召回-大小前沿上优于所有固定预算驱逐缓存**：包括 H2O、StreamingLLM、SnapKV、近期性；在合成基准和真实 MovieLens 任务上均成立，优势来源于**覆盖稀有尾部**。
3. **可端到端学习**：仅通过任务损失训练的双参数新颖性阈值门控精确恢复 DP-means 规则；过度参数化门（MLP）失败，证明**归纳偏置而非容量**是关键。
4. **与状态空间骨干结合**：在同时需要召回和长程聚合的任务上，混合模型以**最低缓存成本**（独特项数）匹配注意力性能，而单独 SSM 召回差、注意力缓存巨大。
5. **自适应缓存优势仅在非平稳需求下显现**：在爆发-平稳交替的流上，自适应缓存以相等平均槽位取得更高召回；在平稳流上与匹配固定预算持平，验证其“为最困难时刻预留容量”的浪费避免。该边界在真实流（MovieLens 平稳、BGL 爆发）上得到确认。

## 摘要
线性注意力和状态空间语言模型将前缀压缩为固定大小的循环状态，实现了O(1)内存，但代价是丢失了精确记忆：当许多键-值关联竞争时，较早的事实会被覆盖，导致“针”检索能力下降。受互补学习系统的启发，我们为线性注意力增加了海马体补充。HOLA（海马体线性注意力）保留常规的delta规则状态作为压缩记忆，并添加了一个有界的精确KV缓存，形成了一种半参数化的测试时记忆：状态建模线性可压缩的结构，而缓存存储不应被迫通过该状态压缩的关联。缓存在没有学习驱逐模块的情况下进行写入，保留那些具有较大beta * ||e||（即实际提交到状态的预测残差）的标记；然后，解耦的RMSNorm-gamma缓存读取将这些精确的KV对转化为尖锐的检索，而非软平均。在150亿SlimPajama标记上训练的3.4亿参数模型上，HOLA将Wikitext困惑度从27.32降至22.92（-16.1%），低于全注意力Transformer++（26.88），并将LAMBADA困惑度从30.95降至30.26。它在线性上下文检索中取得了最佳效果，并且在RULER“大海捞针”召回测试中，直到32k标记（训练长度的16倍）时，仍然比GDN或匹配的HOLA+近期缓存更加鲁棒。

## Abstract
Linear-attention and state-space language models compress the prefix into a fixed-size recurrent state, yielding O(1) memory at the cost of a lossy exact memory: when many key--value associations compete, earlier facts are overwritten and needle recall degrades. Inspired by Complementary Learning Systems, we give linear attention a hippocampal complement. HOLA (Hippocampal Linear Attention) keeps the usual delta-rule state as a compressive memory and adds a bounded exact KV cache, forming a semiparametric test-time memory: the state models linearly compressible structure, while the cache stores associations that should not be forced through that state. The cache writes without a learned eviction module, keeping tokens with large beta * ||e||, the prediction residual actually committed to the state; a decoupled RMSNorm-gamma cache read then turns these exact KV pairs into sharp retrieval rather than soft averaging. At 340M parameters trained on 15B SlimPajama tokens, HOLA lowers Wikitext perplexity from 27.32 to 22.92 (-16.1%), below a full-attention Transformer++ (26.88), and improves LAMBADA perplexity from 30.95 to 30.26. It also achieves the best linear in-context retrieval and remains much more robust than GDN or a matched HOLA+recency cache on RULER needle-in-a-haystack recall out to 32k tokens (16x its training length).

# 论文总结：A Hippocampus for Linear Attention

## 1. 核心问题与整体含义（研究动机和背景）
线性注意力模型（如DeltaNet、Gated DeltaNet等）将历史上下文压缩为固定大小的循环状态，实现O(1)内存和线性时间计算，但这是**有损压缩**：当多个键-值关联竞争时，较早的事实会被覆盖，导致长距离精确回忆（如针检索、多项目关联回忆）严重退化。而全注意力虽能保持每个token的精确KV对，却需要O(T)内存和O(T²)计算。  
**核心洞察**：人类大脑依赖互补学习系统（CLS）——新皮层缓慢压缩泛化结构，海马体快速精确记录单次事件。线性注意力相当于新皮层（高效压缩但丢失细节），缺少海马体。论文旨在为线性注意力添加一个精确记忆补充，恢复其丢失的精确回忆能力。

## 2. 论文提出的方法论
### 2.1 核心思想：半参数测试时记忆
将记忆读取看作回归问题：**参数部分**——循环状态St负责线性可压缩的结构（类似新皮层）；**非参数部分**——有界精确KV缓存At存储不应强行压缩进状态的意外关联（类似海马体）。输出为两者之和（经混合系数λt加权）。

### 2.2 关键技术细节
- **写入策略（存什么）**：利用delta规则固有的“惊喜信号”——写入幅度β·||e||（e为预测残差，β为写入门控）。该分数衡量token对状态的实际改变量，改变大的token就是状态最需要帮助的地方。每个层维护一个容量w（默认64）的精确KV缓存，保留历史中该分数最大的w个token。
- **读取策略（如何读）**：直接复用循环状态的单位L2归一化q/k会导致缓存logit太小（~0.83），softmax近似均匀，缓存退化为软平均。改进：对缓存路径的q/k应用**解耦的RMSNorm-γ**，使其范数接近√d（~11），logit放大至~11cos，实现近似argmax的尖锐检索。该操作不影响循环状态的更新稳定（状态路径仍为单位范数）。
- **实例化**：基于Gated DeltaNet（GDN）骨干，缓存为逐层独立，仅增加约0.004%的参数量和约5%的峰值内存（31 MB额外缓存状态）。

## 6. 主要结论与发现
- **困惑度大幅降低**：340M下Wikitext从27.32降至22.92（-16.1%），低于全注意力Transformer++的26.88。
- **检索显著提升**：FDA从11.7→20.1（+72%），SWDE从29.0→35.9（+24%），为所有线性模型最优。
- **长上下文鲁棒性**：RULER S-NIAH-1在32k时HOLA达0.58，而GDN仅0.14、HOLA+recency仅0.24，优势巨大。多针任务亦有优势。
- **驱逐信号选择至关重要**：β·||e||优于纯残差、纯β或近期位置；**读取规范化是最大单一杠杆**（RMSNorm-γ比单位L2降低困惑度10+点）。
- **缓存机制不影响常识推理**：常识任务平均与其他强基线持平（约42.8），表明精确记忆的注入不损害泛化。

## 7. 优点
- **理论动机清晰**：从互补学习系统出发，将线性注意力与海马体类比，提供了可解释的设计原则。
- **参数无关驱逐**：利用delta规则已计算的预测残差作为惊喜信号，无需额外学习模块，简洁高效。
- **读取解耦设计巧妙**：RMSNorm-γ在缓存路径放大logit，同时不影响状态更新稳定性，实现尖锐检索。
- **近乎零额外参数**：仅增加12,480个标量（<0.004%参数），内存开销仅约5%。
- **实验覆盖广泛**：从困惑度到长上下文、从消融到跨规模，对照条件严格（相同骨干、相同食谱）。

## 摘要
长寿AI智能体需要跨交互的连续性，但连续性无法通过简单扩展提示窗口获得。智能体必须保留有用的先前经验，有选择地检索这些经验，区分个人背景与外部证据，并在底层情境变化时修正记忆。我们提出一种架构化的记忆基质，沿两个正交轴组织：一是涵盖结构化记录、向量表示和图关系的表征轴；二是涵盖短期痕迹、中期抽象和长期语义承诺的时间轴。其关键设计约束是同步的结构化-向量-图记忆：结构化记录决定资格，向量表示支持回忆，图关系在门控上下文投影之前裁决支持、矛盾与取代。其核心主张是：可靠的个性化是一个记忆设计问题——有用的记忆是结构化的、选择性暴露的、持续巩固的，并且带有认识论标签，而非存储为无差别的对话历史。除框架外，我们将MRMS实例化为一个轻量级原型，实现了结构化记录、向量检索、时间策略和基于图的修正。该原型在具有明确证据需求的受控长寿交互场景中，通过生成前记忆选择、修正、边界强制执行和证据归因来演练核心基质机制。

## Abstract
Long-lived AI agents require continuity across interactions, but continuity cannot be obtained by simply extending the prompt window. An agent must preserve useful prior experience, retrieve it selectively, distinguish personal context from external evidence, and revise memory when the underlying situation changes. We propose an architectural memory substrate organized along two orthogonal axes: a representational axis spanning structured records, vector representations, and graph relations; and a temporal axis spanning short-term traces, medium-term abstractions, and long-term semantic commitments. Its key design constraint is synchronized structured-vector-graph memory: structured records govern eligibility, vector representations support recall, and graph relations adjudicate support, contradiction, and supersession before gated context projection. Its central claim is that reliable personalization is a memory design problem: useful memory is structured, selectively exposed, continuously consolidated, and epistemically labeled rather than stored as undifferentiated conversation history. Beyond the framework, we instantiate MRMS as a lightweight prototype implementing structured records, vector retrieval, temporal policies, and graph-based revision. The prototype exercises the core substrate mechanisms through pre-generation memory selection, revision, boundary enforcement, and evidence attribution under controlled long-lived interaction scenarios with explicit evidence requirements.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：长生命周期AI智能体（long-lived AI agents）需要跨多次交互保持连续性，但简单扩展大语言模型的上下文窗口（context window）无法解决问题。上下文窗口存在成本高、长文本注意力不均、无关历史干扰等问题，更重要的是，一个对话转录本（transcript）不是一个记忆系统——它无法区分持久偏好与临时指令、已核实事实与推测、个人观察与外部证据。记忆错误在长生命周期智能体中会持续累积，尤其假阳性（比如过时的偏好、被取代的事实）会反复引入推理过程，造成更大损害。
- **核心主张**：可靠的个性化本质上是一个记忆设计问题。有用的记忆应该是**结构化的、选择性暴露的、持续巩固的、带有认识论标签的**，而非存储为无差别的对话历史。记忆系统必须在生成前（pre-generation）进行控制：决定哪些记忆应被允许影响下一步行动、如何暴露来源、如何处理新旧证据之间的冲突。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **两轴记忆基质（Two-Axis Memory Substrate）**：MRMS 沿两个正交轴组织记忆：
  - **表征轴**（representational axis）：涵盖结构化记录（structured records）、向量表示（vector representations）和图关系（graph relations）。
  - **时间轴**（temporal axis）：涵盖短期痕迹（short-term traces）、中期抽象（medium-term abstractions）和长期语义承诺（long-term semantic commitments）。
- **同步的结构-向量-图记忆（Synchronized Structured-Vector-Graph Memory）**：三个视图各有明确角色，并通过同步不变量协同工作：
  - 结构化记录：控制资格（eligibility）、生命周期状态、范围、来源、修订历史。
  - 向量索引：支持语义近似回忆（recall）。
  - 图关系：裁决支持（support）、矛盾（contradiction）和取代（supersession）。
- **门控上下文投影（Gated Context Projection）**：在生成前，通过边界投影（boundary projection）将记忆暴露范围限制在合适的主题、任务模式、来源类别、隐私策略等条件下。最终生成一个结构化的上下文包（context packet），包含局部任务状态、选定的情节证据、活跃语义声明、负上下文（被拒绝/过时的假设）等。

### 关键技术细节
1. **记忆对象**：每个记忆对象包含多个字段：层（layer）、文本声明、向量表示、来源时间、归属与溯源、范围、置信度、修订历史。
2. **状态类型**：原始（raw）、临时（provisional）、活跃（active）、被取代（superseded）、退休（retired）。修订不等于删除：过时的偏好作为“曾经说过的话”仍可保留。
3. **选择过程（Selection）**：分为四阶段：
   - 结构化门控 → 得到授权集 \(A_t\)；
   - 向量搜索 → 在授权集内取 top-k 语义候选 \(N_k(x_t)\)；
   - 图扩展 → 沿着类型边（支持、矛盾、取代等）得到证据子图 \(H_t\)；
   - 组装上下文包 \(C_t\)。
4. **评分函数**：对每个候选记忆计算得分 \(s_i = \alpha R + \beta C + \gamma F + \delta U - \eta N\)，其中 \(R\) 语义相关性、\(C\) 置信度、\(F\) 新鲜度、\(U\) 任务效用、\(N\) 冗余代价。
5. **巩固与修订**：低承诺写入→高承诺晋升（跨时间层），处理矛盾时通过保留历史记录实现塑形。
6. **同步不变量**：四个不变量确保三个视图一致，如：每个向量点必须解析到一个结构化记录；图节点必须对应有效记录；结构化状态主导选择等。

## 3. 实验设计

### 数据集/场景
- 论文构建了**诊断性基准（diagnostic benchmark）**，包含**800 个确定性生成的合成任务**，涵盖8个任务族：
  - 延迟回忆（delayed recall）
  - 边界控制（boundary control）
  - 源分离（source separation）
  - 修订（revision）
  - 过时抑制（stale suppression）
  - 证据归因（evidence attribution）
  - 矛盾处理（contradiction handling）
  - 时间承诺（temporal commitment）
- 每个场景平均包含 17.0 个记忆记录（最少13，最多21），总计 9503 个个人记忆记录和 4095 个外部指南记录。使用合成文本，无隐私数据、无外部API、无LLM裁判。

### Benchmark
- 评估标准为**生成前（pre-generation）记忆选择**的准确性，而非最终生成质量。金标签是记忆标识符。
- 指标：整体准确率、修订成功率、过时抑制、边界控制、归因、弃权准确率等。

### 对比方法（消融实验）
1. **Recent context only**：仅使用当前提示窗口中的短期痕迹。
2. **Vector only**：用户范围下的最近邻检索，忽略源、任务范围、状态、时间层、图关系。
3. **Structured + vector**：在向量搜索前应用用户、主题、任务、源的精确门控。
4. **Structured + vector + temporal**：加上活跃状态过滤、层感知排序、过时抑制、弃权。
5. **Full MRMS**：增加图解析（遍历取代、矛盾、支持、派生边）后组装上下文包。

## 6. 主要结论与发现

- **核心发现**：MRMS 在全参数设置下达成 98.8% 的整体准确率，显著优于消融变体。
- **每个机制的必要性**：
  - 向量检索改善回忆，但过时或越界的记忆仍可能被错误选中。
  - 结构化滤波改善了边界控制。
  - 时间策略修复了过时抑制和弃权。
  - 图扩展对矛盾处理和证据归因贡献最大。
- **紧凑性**：Full MRMS 平均只选择 1.11 个记忆对象（从 1.8 个打分候选中），生成前上下文包非常紧凑。
- **可靠个性化是记忆设计问题**：需要结构化状态、选择性暴露、持续巩固和认识论标签，而非无差别的历史存储。

## 7. 优点

1. **创新的架构设计**：两轴多分辨率记忆基质的提出，尤其是同步的结构-向量-图三视图，将授权（authorization）、语义检索和关系推理明确分离，提供了比现有系统更严格的记忆正确性保证。
2. **清晰的同步不变量**：四个同步不变量（稳定跨视图标识符、图节点有效性、证据支撑的边、结构化状态主导选择）确保了跨视图一致性，是核心理论贡献。
3. **诊断基准设计精巧**：专注生成前记忆决策，使用合成任务与金标签，避免LLM裁判偏差；消融设计系统化，能归因每个组件的作用。
4. **上下文包结构清晰**：将个人记忆、外部证据、负上下文等分开，有助于LLM正确区分信息来源。
5. **可审计性**：每个内存对象保留修订历史，过时记忆可保留为历史记录而不影响当前推理。

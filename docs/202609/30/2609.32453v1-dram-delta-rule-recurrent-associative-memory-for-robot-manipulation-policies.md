## 摘要
机器人操作本质上依赖于历史，但大多数预训练的机器人策略仅以当前观测或较短的时间窗口为条件。为这类策略配备长期记忆仍然具有挑战性：现有方法要么向骨干网络输入多帧观测窗口，这会显著增加推理成本；要么依赖预定义的语义特征，这限制了任务通用性，并且可能还需要重新训练骨干网络以适配记忆。我们提出DRAM（Delta规则循环联想记忆），一种即插即用的记忆模块，可附加到多种预训练机器人策略上，在不修改架构或重新训练骨干网络的情况下赋予其长时程记忆，仅需对记忆模块和动作专家进行任务特定的后训练。DRAM使用门控Delta规则线性注意力维护固定大小的联想记忆，并采用一种修改后的更新方式，并行地纳入每一帧内的所有token。一种与架构无关的读出机制将历史上下文集成到不同策略架构的动作预测中。实验表明，DRAM在短上下文基线和替代的紧凑记忆设计上持续提升冻结的预训练策略，验证了其作为固定大小、事后记忆模块并在骨干网络冻结下训练的有效性。

## Abstract
Robotic manipulation is inherently history-dependent, yet most pretrained robotic policies condition on only the current observation or a short temporal window. Equipping such policies with long-term memory remains challenging: existing approaches either feed the backbone multi-frame observation windows, which substantially increase inference cost, or rely on pre-defined semantic features, which limit task generality and may also require the retraining of the backbone to adapt to the memory. We introduce DRAM (Delta-rule Recurrent Associative Memory), a plug-and-play memory module that can be attached to a wide range of pretrained robotic policies, endowing them with long-horizon memory without architectural modification or backbone retraining, requiring only task-specific post-training of the memory module and action expert. DRAM maintains a fixed-size associative memory using gated delta-rule linear attention, with a modified update that incorporates all tokens within each frame in parallel. An architecture-agnostic readout integrates historical context into action prediction across different policy architectures. Experiments show that DRAM consistently improves frozen pretrained policies over short-context baselines and alternative compact memory designs, validating its effectiveness as a fixed-size, post-hoc memory module trained with the backbone frozen.

- **核心问题**：机器人操作本质上是历史依赖的（history-dependent），许多任务只具备部分可观测性——当前观测可能无法反映已被遮挡的物体、已完成的阶段或先前交互的结果。视觉上相似的观测在不同历史下需要不同动作。
- **现状矛盾**：大多数预训练机器人策略（VLA/扩散策略等）仅以当前观测或极短时间窗口为条件，无法利用窗口之外的历史信息，因而在长时程任务上表现受限。
- **现有方案的两条路径及其代价**：
  - 向骨干网络输入多帧观测窗口 → **推理成本显著上升**；
  - 依赖预定义语义特征构建记忆 → **限制任务通用性**，且往往需要**重新训练骨干网络**以适配记忆。
- **本文目标**：设计一种**固定状态大小、架构无关、即插即用**的记忆机制：在不修改原策略架构、不重训骨干的前提下，为冻结的预训练策略赋予长时程记忆，仅需后训练记忆模块与动作专家。
- **技术立足点**：线性注意力天然支持将历史键值关联压缩进固定尺寸矩阵的循环实现（Katharopoulos 等；Schlag 等）。但标准**加性更新**会不断叠加新关联，难以删除旧关联，相似键之间会相互干扰。因此本文采用 **Delta 规则**（先检索、再写入残差）作为记忆更新基础，并针对具身场景做帧级改造。

## 2. 方法论

### 2.1 核心思想

- **解耦时间粒度与空间粒度**：以**每个环境帧作为一个循环步**（frame-level recurrence），而**帧内每个视觉 patch 独立读写共享记忆**（patch-level access）。
- **READ → FUSE → WRITE 三原语**，其中关键是 **read-before-write**：当前帧先从 *写入前* 的记忆状态读取历史，之后才把本帧信息写入，避免当前观测泄漏进自身的检索，也避免人为给帧内 patch 强加顺序。
- **即插即用的残差接口**：DRAM 作为残差分支，保留原策略骨干与动作生成组件；读出通过零初始化的门控残差注入，架构无关。

### 2.2 关键技术细节

**记忆状态与表示**
- 骨干（冻结 VLM）输出帧级潜变量 token 序列 $X_t=\{X_t^Q, X_t^K, X_t^V\}$，经 LayerNorm 与线性投影得到每头 $Q_t\in\mathbb{R}^{H\times M\times d_k}$、$K_t,V_t\in\mathbb{R}^{H\times N\times d_v}$，键做行向 $\ell_2$ 归一化。
- 每层维护 $H$ 个联想记忆矩阵 $S_t=\{S_t^{(h)}\in\mathbb{R}^{d_k\times d_v}\}$，**尺寸与回合长度无关**。
- 明确强调：$K_t,V_t$ 的行索引**不是时间戳**（可能是空间位置、相机编号或语言顺序），同一帧所有 token 属于同一物理观测，构成**单一循环输入**——这是帧同步写入的前提。

**READ（帧级检索，基于写入前状态）**
- $R_t^{(h)} = Q_t^{(h)} S_{t-1}^{(h)} / \sqrt{d_k}$，再沿特征维拼接各头。
- 查询来自当前帧，而 $S_{t-1}$ 只包含过去帧，故检索条件于当前观测与任务，但当前帧不会泄漏进自身读出。

**FUSE（零初始化门控残差）**
- $Y_t = X_t^Q + f_O(\sigma(f_G(X_t^Q))\odot R_t)$，$f_G$ 为行向仿射门，$f_O$ 为输出投影。
- $f_O$ **零初始化**，使 FUSE 在初始时严格为恒等映射（记忆读出初始不改变查询表示）。
- 门与投影只作用于查询流；可选地在查询流内加一个帧内双向 mixer（attention + MLP）。

**WRITE（帧同步联合写入）**
- **门控**：
  - 每头每帧的标量保留门 $\gamma_t^{(h)}=\exp\{-\exp(a_h)\,\zeta(\bar g_t u_{\gamma,h}+b_{\gamma,h})\}\in(0,1)$，对继承状态做软衰减 $\bar S_{t-1}=\gamma_t S_{t-1}$（$\bar g_t$ 为掩码感知的写入源行均值）。
  - 每 token 写入门 $\beta_{t,i}^{(h)}=\sigma(g_{t,i}u_{\beta,h}+b_{\beta,h})$，并截断 $\hat\beta=\min(\beta,0.99)$；采用 **odds 重参数化** $w_{t,i}=p_i\hat\beta/(1-\hat\beta)$，使单键情形严格退化为强度为 $\hat\beta$ 的门控 delta 规则。
- **联合更新目标**（把一帧内 $N$ 个关联一次性写入）：
  - $\displaystyle S_t=\arg\min_{S}\ \tfrac12\|S-\bar S\|_F^2+\tfrac12\|W_t^{1/2}(K_tS-V_t)\|_F^2$
  - 第一项把更新锚定在保留历史上（保证未被当前键张成方向上的内容不被破坏，并保证解唯一），第二项要求**同一个候选状态同时解释本帧全部键值对**。
- **闭式解（法方程）**：$A_t S_t=\bar S+K_t^\top W_tV_t$，其中 $A_t=I_{d_k}+K_t^\top W_tK_t\succeq I\succ0$，唯一极小。
  - 聚合形式：$S_t=A^{-1}(\bar S+K_t^\top W_tV_t)$
  - **实际计算用修正形式**：$S_t=\bar S+\Delta,\ A\Delta=K_t^\top W_t(V_t-K_t\bar S)$，用 **Cholesky 分解**求解，**不显式构造 $A^{-1}$**。
  - 可理解为从 $\bar S$ 出发对二次目标做一步精确 Newton 步。
- **掩码与数值**：padding token 权重为 0，不进入 Gram 矩阵与右端项；全 padding 帧跳过更新（不施加衰减）；全零写权重的有效帧只返回衰减后的 $\bar S$。截断 $\hat\beta\le0.99$ 使 $w\le99$，条件数上界 $\kappa(A)\le 1+99N$，与数据无关。
- **反向传播**：通过**隐式微分**穿过求解器（复用前向 Cholesky 因子解转置系统 $A\Lambda=G$），而非对 Cholesky 算子求导；给出 $\partial L/\partial\bar S,\partial L/\partial V,\partial L/\partial w_i,\partial L/\partial K$ 的解析式，梯度可继续回流至保留门与上一状态。Gram 矩阵与求解在 **FP32、关闭 TF32** 下进行，持久状态以 FP32 存储。
- **单帧计算量**（每头）：$O(Nd_k^2+Nd_kd_v+d_k^3+d_k^2d_v)$，**与回合长度无关**。

**为什么不做逐 token 顺序写入**
- 逐 token 迭代等价于把一帧内 N 次更新串成 N 个循环状态，最终状态依赖帧内任意序列化顺序（附录给出标量最小反例：两个 token 顺序写入得到最后一个 token 的值，而联合拟合得到两者的均值）；分块核只是加速而非消除该依赖。
- 联合写入则保持**帧内置换不变性**。

**三条理论性质（附录 C 证明）**
1. **单 token 对应性**：$N=1$ 且 $\|k\|=1$ 时，联合写入严格退化为带截断门 $\hat\beta$ 的门控 delta 规则（严格推广）。
2. **帧内置换不变性**：对 $K_t,V_t$ 行与 $W_t$ 对角元素施加同一置换，$S_t$ 在精确算术下不变——帧内不存在序列化导致的近因偏置。
3. **有界证据累积**：同一关联重复 $n$ 次的有效强度为 $nw/(1+nw)$，单调递增但恒小于 1（重复证据强化而非稀释写入）。

### 2.3 训练流程

- **冻结骨干**：视觉塔与 VLM 骨干完全冻结；只训练记忆模块、策略适配器与动作专家。
- **TBPTT（截断时间反向传播）**：在窗口内沿历史读取、保留/写入门、融合与可微联合求解传播梯度；循环状态仅在**窗口边界** detach，而非激活检查点分段边界。
- **控制目标**：动作专家用 flow matching 训练（$\tau=0.999b+0.001,\ b\sim\mathrm{Beta}(1.5,1)$），损失 $L_{FM}=\mathbb{E}\|v_{\theta,\psi}(a_t^\tau,\tau;c_t,R_t)-u_t\|_2^2$；**不引入任何辅助重建/检索损失**，记忆内容完全由控制目标塑造。
- **部署**：每个新观测触发一次 read–write 转移；动作专家仅在新动作块需要时去噪；记忆跨动作块保持，回合间重置。
- 作者明确指出：**有界的持久状态不等于有界的训练期激活显存**，后者仍随 TBPTT 窗口长度增长。

### 2.4 两种集成模式

- **分离源（separate-source）——π0.5 宿主**：记忆层与 VLM 的 18 层对齐，写入源为骨干对应层特征；查询流为 $M$ 个可学习 query slot，读出作为 **attention prefix slot** 注入动作专家（使用保留 RoPE 索引 $-1$，跳过旋转，不干扰原 token 相对位置）。写入源有三种配置：Native KV（复用骨干自身 KV 投影）、Hidden Tokens（取中间层隐藏 token 并用 DRAM 自己的投影）、Last Hidden（仅用最终层隐藏序列作为所有记忆层共享写入源，只暴露最终读出）。
- **共享源（shared-source）——DiT 宿主**：当前帧 token 同时充当 Q/K/V（$M=N$），记忆层像普通 Transformer 一样堆叠，返回融合序列 $Y_t$ 给下一层，动作头通过其原始 cross-attention 接口消费，无需改动。
- 两条实践原则：承载历史的 token 不应干扰宿主的位编码方案；读出粒度与写入源选择正交（深层宿主适合层对齐读出，浅层/单层记忆用最终层读出即可）。

## 摘要
流式视频理解要求多模态大语言模型（MLLMs）在严格因果性和有限记忆约束下处理连续视觉输入并响应用户查询。现有方法通常将历史观察压缩到外部记忆库中，并检索与查询相关的证据作为额外视觉上下文。尽管这种存储-检索范式有效，但它将历史证据作为外部视觉上下文，使其无法被内化为一种紧凑、演化的潜在记忆，从而持续引导流式推理。为弥合这一差距，我们引入了LatentStream，一种渐进式潜在工作记忆框架，将流式记忆从“存储-检索”转变为“检索-内化”。具体而言，LatentStream包含三个协调组件。首先，查询无关的分层流式记忆通过Jenks引导的自适应整合，在固定记忆预算下将视觉历史组织为短期、中期和长期三个层级。一旦查询到达，分层潜在记忆演化机制为潜在记忆令牌组配备渐进扩展的记忆感受野，使其能够从其对应范围迭代检索历史证据，并将其内化为紧凑、固定长度的潜在记忆。最后，渐进式置信度引导的潜在记忆优化从分组预测熵中构建分层进度奖励，并联合细化潜在记忆令牌和检索证据，促使流式推理的置信度不断提高。大量实验表明，LatentStream在现有在线和离线视频基准上取得了新的最先进结果。

## Abstract
Streaming video understanding requires multimodal large language models (MLLMs) to process continuous visual inputs and respond to user queries under strict causality and bounded memory. Existing approaches typically compress historical observations into an external memory bank and retrieve query-relevant evidence as additional visual context. Though effective, this store-and-retrieve paradigm keeps historical evidence as external visual context, preventing it from being internalized into a compact, evolving latent memory that can continuously guide streaming reasoning. To bridge this gap, we introduce LatentStream, a progressive latent working memory framework that shifts streaming memory from store-and-retrieve to retrieve-and-internalize. Specifically, LatentStream comprises three coordinated components. First, Query-agnostic Hierarchical Streaming Memory organizes visual history into short-, mid-, and long-term levels under a fixed memory budget through Jenks-guided adaptive consolidation. Once a query arrives, Hierarchical Latent Memory Evolution equips groups of latent memory tokens with progressively expanding memory receptive fields, enabling them to iteratively retrieve historical evidence from their corresponding scopes and internalize it into a compact, fixed-length latent memory. Finally, Progressive Confidence-guided Latent Memory Optimization constructs a hierarchical progression reward from group-wise predictive entropy and jointly refines the latent memory tokens and retrieved evidence, encouraging increasingly confident streaming reasoning. Extensive experiments demonstrate that LatentStream achieves new state-of-the-art results on existing online and offline video benchmarks.

## 2. 论文方法论（核心思想、技术细节与主要流程）

LatentStream 在冻结基础 MLLM（Qwen2.5-VL）的前提下构建一个渐进式潜在工作记忆框架，由三个协同组件构成：

### 2.1 查询无关的分层流式记忆（HSM）

- 将历史视觉令牌组织为**短期（short-term）、中期（mid-term）、长期（long-term）**三档记忆，在固定令牌预算下运转。
- 短期记忆密集保留最新帧；中期记忆通过**Jenks 自然断点**引导的三类时间路由（Drop/Compress/Preserve）进行时间维度的压缩整合；长期记忆则对旧证据进行更强的空间合并。
- **Jenks 公式示意**（时间层级路由）：
  - 对时间重要性分数分布 `S_temp` 做三类 Jenks 划分，得到两个断点 `τ1、τ2`；
  - 低分者丢弃（Drop），中间者压缩（Compress），高分者保留（Preserve）。
  - 从中期到长期，则用二类 Jenks 划分空间距离分数，将邻近低距离令牌合并、高距离令牌单独保留。
- 该记忆构建**完全在查询到达前在线完成**，作为查询无关的历史基础。

### 2.2 分层潜在记忆演化（HME）

- 引入三类**潜在记忆令牌（LMTs）**，每组 K 个令牌，具有**层级递进的记忆感受野**：
  - `G1： C_s（仅短期记忆）`
  - `G2： C_m = 短期 + 中期`
  - `G3： C_l = 短期 + 中期 + 长期`
- 查询到达后，先做一次含分组注意力掩码的自举（bootstrap）前向传播，使初始 LMTs 获得查询条件化的语义信息。
- 在每轮演化迭代 `r` 中，各 LMT 组从各自的记忆感受野中计算与候选证据的最大余弦相似度，用 Top-K 检索选出 B 条证据：
  `I_g^(r) = TopK_B([a_{g,j}^(r)]_{m_j∈C_g})`
- 并将检索到的视觉证据复制为可优化副本，插入对应 LMT 组之后形成候选输入。
- 若新候选状态相较上一轮获得更高奖励 `R_cand > R_prev`，则将该轮检索证据并入保留池（证据门控更新）；否则保持上一轮池不变。

### 2.3 渐进式置信度引导的潜在记忆优化（PMO）

- 在每轮演化中对三个 LMT 组计算**归一化 top-δ 熵** `E_g(U)`，即检索到该组证据后、该分支末尾位置的预测分布熵（式 6）。
- 定义**分层进度奖励**（式 7）：
  - 包含绝对置信项：`Σ_g (1 − E_g(U))`；
  - 以及层次递进项：`[E_s − E_m]+ + [E_m − E_l]+`，鼓励熵随可访问范围扩展而递减（即 `E_s > E_m > E_l`）。
- 通过 REINFORCE 策略梯度法更新潜在状态：
  - 以高斯扰动 `ξ ~ N(0, σ²I)` 构造探索策略 `πσ(U′|U)`
  - 梯度估计为：`∇U J(U) = E[R(U′) · ξ/σ²]`
  - 对 LMTs 嵌入和检索证据嵌入一起做**测试时优化**，不更新模型参数。
- 优化结束后移除所有注入的视觉证据拷贝，最终解码序列为：`[外部记忆摘要；查询；优化后的 LMTs]`。

## 1. 核心问题与整体含义（研究动机与背景）

流式视频理解要求多模态大语言模型（MLLMs）在严格因果性和有限记忆预算下，持续处理连续到达的视觉输入并响应用户查询。这一能力对于实时监控、自动驾驶、智能眼镜和具身智能等应用至关重要。

现有方法普遍遵循"**存储—检索**"（store-and-retrieve）范式：先将历史观察压缩至外部记忆库，再用查询去检索相关证据，作为额外视觉上下文输入模型。虽然有效，但这种范式将历史证据始终作为**外部视觉上下文**，无法被内化为一种**紧凑、持续演化的潜在记忆**以直接参与后续推理。记忆留存与推理之间耦合松散，缺乏一个在模型潜在空间内不断积累并引导推理的中间表征。

LatentStream 的提出是为了推动一次范式改变：从"存储—检索"转变为"**检索—内化**"（retrieve-and-internalize）。历史证据被逐步内化为固定长度的潜在记忆令牌，并持续优化，最终直接参与流式视频推理，桥接外部记忆访问与潜在推理。

## 2. 方法论：核心思想、关键技术与流程

### 2.1 总体框架

LatentStream 由三大协同组件构成：

1. 查询无关的分层流式记忆（HSM）
2. 分层潜在记忆演化（HME）
3. 渐进式置信度引导的潜在记忆优化（PMO）

整体在冻结 Qwen2.5-VL 骨干的前提下进行测试时优化，不改动任何模型参数。

### 2.2 查询无关分层流式记忆（HSM）

- 记忆库分为短（short）、中（mid）、长（long）三个时间层级，固定令牌预算。
- 新到的视觉令牌先密集存入短期记忆；溢出时通过 Jenks 自然断点自适应压缩：
  - **短期→中期**：用三分类 Jenks 对时间重要性分数求两个断点 τ1/τ2，将令牌分为 Drop、Compress、Preserve 三档；
  - **中期→长期**：用二分类 Jenks 对空间距离分数分区，邻近低距离令牌合并，高距离令牌保留。
- 记忆构建完全在线、查询无关，为后续潜在记忆演化提供基础。

### 2.3 分层潜在记忆演化（HME）

- 引入 `K×D` 的潜在记忆令牌（LMTs），划分为三组，具有**逐级扩大的记忆感受野**：
  - 组 1 → 只看短期记忆
  - 组 2 → 短期+中期
  - 组 3 → 短期+中期+长期（完整记忆库）
- 查询到达时，先通过模型前向传播（bootstrap）将查询语义注入 LMTs 初始化。
- 每轮迭代 r：
  1. 各组从各自感受野内检索与 LMTs 最相似的历史视觉令牌（Top-K，预算 B）；
  2. 证据插入对应 LMT 组后方，形成候选输入；
  3. 优化新候选状态，若奖励优于当前保留状态则接受并积累本轮证据，否则丢弃；
  4. 更新后的 LMTs 引导下一轮检索。
- 检索是逐步条件化的，避免了单次检索的信息冗余，形成迭代的"检索—更新"演化闭环。

### 2.4 渐进式置信度引导优化（PMO）

- 对每组 LMTs 计算掩码语言建模头输出的 top-δ**归一化熵**，熵越低代表该组预测越自信。
- 构造**分层递进奖励**：绝对置信 + 层级递进（要求熵按短→中→长顺序递减，即短组熵 > 中组熵 > 长组熵）。
- 通过 REINFORCE 策略梯度（高斯扰动范围随 σ）优化 LMTs 和检索证据嵌入，以最大化期望奖励：
  - 梯度估计为 `∇U J(U) ≈ E[ R(U') × ξ/σ² ]`；
  - 每轮执行 `U ← U + η∇U J(U)`；
- 最终将检索证据从输入中移除，只用优化后的 LMTs 总结记忆并解码最终答案，即证据被"内化"，而非"拼接输入"。

- 在离线长视频基准 VideoMME、MLVU、LongVideoBench 上分别达到 66.6%、74.0%、62.1%，同样优于各对比方法；
- 通过实验验证：检索证据若仅是拼接输入则收益有限；必须在潜在空间内通过迭代优化"内化"进紧凑表示，效果才能最大化；
- 置信度递进优化比单纯绝对置信度优化更有效，表明引导熵逐级递减能更好地对齐分层记忆结构；
- 在峰值内存和 TPOT 上显著优于基座，证明潜在记忆方案很适合流式场景的固定预算约束。

---

## 7. 优点

1. 提出了一个新颖的范式转换（store-and-retrieve → retrieve-and-internalize），不只是工程式改进，有较强的概念贡献；
2. 将外部记忆与潜在空间推理良好结合起来，在冻结骨干模型的前提下完成知识内化，适合部署；
3. 分层记忆配合三组 LMT 的递进感受野设计很自然，查询条件化通过初始化注入，避免了为每帧重新计算完整的记忆编码；
4. 用预测熵作为内在奖励信号训练潜在状态，无需外部标注，自我监督，思路简洁且有效；
5. 测试时优化+分轮检索的门控机制令记忆逐步更新，兼具选择性和鲁棒性；
6. 实验覆盖流式与非流式长视频两类设置，并给出了较好的消融证据，证明各模块的必要性。

## 8. 不足与局限

1. **效率瓶颈并未完全消失**：虽然峰值内存和 TPOT 有降低，但 TTFT（首个令牌时延）增加约 0.8 秒；对于真正实时（毫秒级）交互应用，多次迭代的测试时优化仍偏重；
2. **3B 与 7B 结果不一致现象**（部分子任务 3B 高于 7B），说明优化的不稳定性或评测方差，论文未充分分析其成因；
3. **高度依赖冷启动基座能力**：LMT 初始化和置信度信号都受冻结视频骨干的固有不确定性影响；对弱基座改进可能有限；
4. **熵信号作为唯一导向存在潜在偏差**：模型可能通过"逃避"难以回答内容而非真正理解来提高置信度，进而不合理压低熵水平，这种伪置信现象论文未额外校准；
5. **查询相关的单轮设定**：虽支持流式视频输入，但未测试多轮对话中潜在记忆需要更新/重新初始化的情况；
6. **缺少与训练式方法的严格等成本比较**：免训练方法多出迭代前反向开销，并未显著计入总时延报告中，

6. **缺少与训练式方法的严格等成本比较**（续）：免训练方法多出迭代前反向开销，并未显著计入总时延报告中——若将每一轮潜在记忆演化的前向/反向传播耗时、多次检索与门控评估的累积延迟统一纳入端到端评测，LatentStream 的实际计算代价将明显高于表格中呈现的“免训练”印象。论文尚未提供在相同总算力预算下与训练式在线模型进行公平对照的实验，因此其声称的“无需训练成本”优势更准确地说应被理解为“无离线训练阶段”，而非“推理期间零额外开销”。

7. **潜在记忆的可解释性与可控性不足**：优化后的 LMTs 是连续嵌入向量，论文虽在检索层面给出了定量的证据选择分析，但缺少对“LMTs 究竟编码了哪些历史信息”“优化过程中哪些证据被最终内化或被丢弃”的可视化或归因研究。对应用于监控、自动驾驶等高风险场景的系统而言，这种黑箱式潜在记忆的审计难度较高，可能制约实际部署时的可验证性。

8. **跨会话与多轮连续交互尚未支持**：当前机制假设每轮查询到来时对潜在记忆做一次独立的初始化与演化，未涉及多轮对话中“上一轮已优化的 LMTs 是否应继续保留、如何增量更新”的问题。这会限制其在对话型智能体、长期交互式助手等场景中的复用能力。

## 9. 总结与展望

LatentStream 提出了一条区别于主流“存储—检索”范式的技术路线：通过查询无关的分层流式记忆保存完整的在线历史，再经查询条件化的潜在记忆令牌在冻结大模型内部完成多轮检索、内化与置信度引导演化，最终以紧凑状态参与解码。该方法在多个在线与离线长视频理解基准上取得了领先效果，并以充分的消融实验验证了“检索-内化”机制的有效性，为流式视频理解提供了新的研究视角。

展望方面，后续工作可从以下方向推进：

- **轻量化测试时优化**：通过更高效的演化步数调度、早期停止机制或蒸馏单步逼近多轮效果，降低首令牌延迟，使其向真正实时可用的系统靠近；
- **潜在记忆的可解释性分析**：结合注意力归因与检索轨迹可视化，揭示 LMTs 内化的具体内容，增强方法的可信度；
- **多轮动态更新**：研究跨查询的 LMTs 保留与增量演化策略，使潜在记忆能作为长期对话状态的统一载体；
- **弱基座适配**：探索如何在视觉编码或语言解码能力较弱的 MLLM 上仍保持稳定收益，拓宽方法的适用范围。

总体而言，LatentStream 在“外部历史证据如何内化为模型内部推理状态”这一关键问题上迈出了实质性一步，兼具概念上的启发意义与工程上的实用潜力。

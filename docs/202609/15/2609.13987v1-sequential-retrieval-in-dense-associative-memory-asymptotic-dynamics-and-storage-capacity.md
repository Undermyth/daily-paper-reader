## 摘要
我们研究了 n 体非对称密集联想记忆模型的检索动力学，其中序列检索通过在高阶 Hebbian 相互作用中移动一个模式索引来实现。该模型表现出对存储模式的序列检索，且检索状态对应于稳定的极限环吸引子。存储容量定义为使该极限环保持稳定的最大加载率。利用生成泛函分析，我们推导了描述序列检索状态的动力学方程。生成泛函分析表明，在非对称模型中延迟自相互作用项消失，由此得到的重叠动力学可由 Amari-Maginu 型信噪分析重现。此外，我们发现对于相互作用阶数 n ≥ 3，归一化存储容量随相互作用阶数的增加而单调递减，这与对称现代 Hopfield 模型形成对比。

## Abstract
We study the retrieval dynamics of an $n$-body asymmetric dense associative memory model, in which sequential retrieval is implemented by shifting one pattern index in the higher-order Hebbian interaction. The model exhibits sequential retrieval of the stored patterns, and the retrieval state corresponds to a stable limit-cycle attractor. The storage capacity is defined as the maximum loading rate for which this limit cycle remains stable. Using generating functional analysis, we derive the dynamical equations describing the sequential retrieval state. The generating functional analysis reveals that the retarded self-interaction term vanishes in the asymmetric model, and the resulting overlap dynamics is reproduced by an Amari-Maginu-type signal-to-noise analysis. Also, we find that for the interaction order $n\ge 3$, the normalized storage capacity decreases monotonically with increasing interaction order, in contrast to symmetric Modern Hopfield models.

## 摘要
最近，线性注意力层越来越多地被用于大规模替代 softmax 注意力以进行长上下文建模。然而，现有的上下文扩展方法通常直接应用持续预训练而不修改这些层，忽略了线性注意力状态动力学的谱特性。在本工作中，我们从转移矩阵的谱视角研究 Gated DeltaNet (GDN) 的长上下文扩展，并识别出决定长程信息检索的两个关键因素：(1) 与目标依赖长度对齐的足够宽的慢谱带；以及 (2) 保留用于状态清除和上下文切换的快衰减模式。基于这一观察，我们提出 SpectralShift，一种用于 GDN 长上下文持续预训练的谱重参数化方法。具体而言，SpectralShift 对 alpha 投影的初始化进行重参数化，通过增强慢速传播能力来重塑衰减谱，并进一步为 alpha 投影引入学习率缩放，以促进长上下文训练。实验表明，SpectralShift 在训练过程中持续提升长上下文能力，为扩展线性注意力模型的上下文窗口提供了一种有效且高效的解决方案。代码已开源于 https://github.com/RUCAIBox/GDN-SpectralShift。

## Abstract
Recently, linear attention layers have been increasingly adopted to replace softmax attention at scale for long-context modeling. However, existing context extension approaches typically apply continued pretraining directly without modifying these layers, overlooking the spectral properties of linear attention state dynamics. In this work, we study long-context extension of Gated DeltaNet (GDN) from a spectral perspective of transition matrix and identify two essential factors governing long-range information retrieval: (1) a sufficiently broad slow spectral band aligned with the target dependency length, and (2) the preservation of fast-decaying modes for state clearing and context switching. Based on this observation, we propose SpectralShift, a spectral reparameterization approach for long-context continual pretraining of GDNs. Specifically, SpectralShift reparameterizes the alpha projections initialization to reshape the decay spectrum by enhancing slow propagation capacity, and further introduces a learning-rate scaling for alpha projections to facilitate long-context training. Experiments show that SpectralShift consistently improves long-context capabilities over training, providing an effective and efficient solution for extending context windows of linear attention models. The code has been open-sourced at https://github.com/RUCAIBox/GDN-SpectralShift.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

通过对 GDN 中 **alpha 投影**（控制遗忘门 α_t 的线性层）进行**谱重参数化**，在长上下文持续预训练（CPT）中主动重塑衰减谱：拓宽慢谱带以增强长程传播能力，同时保留快衰减模式以维持状态清除能力。

### 2.2 关键概念与公式

- **有限时间转移矩阵**：对位置 i < j，ℓ = j − i，定义
  Φ_{i→j} = A_j A_{j−1} ⋯ A_{i+1}，其中 A_t = α_t (I − β_t k_t k_t^⊤)。
- **有限时间衰减率**：
  γ_r(i,j) = −(1/ℓ) log σ_r(Φ_{i→j})，分解为
  γ_r = γ_α + γ_{R,r}，
  其中 γ_α = −(1/ℓ) Σ log α_t 为头级共享分量，γ_{R,r} 为方向性分量。
- **慢谱带定义**：
  S_ℓ = { r : log σ_r(Φ_{i→j}) ≥ −1 }，即有效时间尺度 ≥ ℓ 的状态方向集合。|S_ℓ| 衡量慢谱带宽度。

### 2.3 方法组件

**（1）Alpha 重参数化（谱初始化）**

- 将 alpha 投影分解为共享幅度与输入相关偏差：
  a_t^ref = W_α^ref h_t = μ_α^ref J h_t + (W_α^ref − μ_α^ref J) h_t = c_t + ξ_t。
- 引入缩放：a_t(s₁) = c_t + s₁ ξ_t，0 < s₁ ≤ 1。
- **Lemma 1**：减小 s₁ 时，若 ξ_t > 0 则 α_t 增大（保留更强）；若 ξ_t < 0 则 α_t 减小（遗忘更快），形成**非均匀谱初始化**。
- **最优缩放因子**：基于尺度匹配条件推导得 s₁ = (L_ref / L_tar)^{0.5}（平方根律）。

**（2）长度缩放持续预训练（训练期谱保持）**

- 仅对 alpha 投影的学习率进行缩放：η_α^tar = s₂ η_ref，其余参数保持 η_tar。
- **Theorem 1**：更新幅度对共享衰减的影响满足 |γ_α^{(u+1)} − γ_α^{(u)}| ≤ C_α s₂ η_α^ref + O(s₂² η_α^ref)，即 s₂ 直接控制头级共享谱的移动幅度，防止整个头集体漂移。
- 实现上取 s₂ = s₁ = (L_ref / L_tar)^{0.5}。

**（3）整体算法流程（Algorithm 1）**

1. 计算 s ← (L_ref / L_tar)^{1/2}；
2. 提取参考 alpha 投影 W_α^ref，计算全局均值 μ_α^ref；
3. 重参数化初始化：W_α^* ← μ_α^ref J + s (W_α^ref − μ_α^ref J)；
4. 设置 η_α^tar ← s η_tar；
5. 目标长度 CPT：alpha 投影用 η_α^tar 更新，其余参数用 η_tar 更新。

**（4）理论支撑**

- **Theorem 2**：最终谱位移 D_r = δ_init + δ_CPT,α + δ_CPT,Δ，满足 D_r ≥ γ_r^ref − 1/ℓ 的模式进入最终慢谱带。
- 附录 F 给出正初始化裕度、CPT 更新预算、快头保持的充分条件，证明参考慢模式被保留、近边界模式进入慢带、快头可同时保持。

## 6. 主要结论与发现

1. **慢谱带是长上下文检索的关键**：长程信息保留不取决于单一最大记忆时间尺度，而取决于是否有足够多的状态方向具备与目标依赖长度对齐的衰减动力学。
2. **两个互补谱属性**：有效长上下文 GDN 需要同时满足——拓宽慢谱带以提供长程存储容量，以及保留快衰减模式以支持状态清除与上下文切换。
3. **SpectralShift 显著提升长上下文性能**：在 128K 两阶段 CPT 中，RULER 平均分达 55.18，基线为 52.38，相对提升约 5.35%；在各长度组、课程设置、评估长度上一致优于基线。
4. **通用能力保持或提升**：在短上下文基准上性能与基线相当或更好，说明快慢模式平衡良好。
5. **兼容多种位置编码**：在 DroPE、YaRN、ABF 下均有效，且在最大评估长度上一致优于对应基线。
6. **适用于纯线性注意力**：在纯 GDN 模型上扩展到 8K/16K/32K，RULER Single-1 分数从基线 11.11/8.00/6.43 提升至 11.96/11.25/10.63，且目标长度越长提升越明显。
7. **理论验证**：平方根缩放律（k = 0.5）通过消融实验验证为最优（配置⑤最佳），过大缩放（s）虽检索有竞争力但通用能力明显下降。

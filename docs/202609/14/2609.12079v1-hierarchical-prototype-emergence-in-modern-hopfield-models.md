## 摘要
层级相关性是任何现实数据模型的普遍特征，而联想记忆模型如何学习这些相关性，并在此基础上进行泛化以构建新的合理图像，这一问题对于理解扩散模型等更复杂的现代架构而言是重要一步。我们考虑一种记忆的层级模型，这些记忆在具有多项式激活的稠密 Hopfield 网络中被采样和存储。我们解析推导了该层级中每一层局部稳定的条件——即它们是局部能量极小值。我们将原型重构作为泛化的最小模型，并发现只需拟多项式量的信息即可泛化到特定记忆乃至层级中特定组之外。我们在 Fashion-MNIST 数据中观察到，在记忆数量、激活函数锐度（多项式次数）方面存在定性相似的相图。

## Abstract
Hierarchical correlations are a universal feature of any realistic model of data, and the question of how associative memory models may learn these correlations and generalize beyond them to construct new sensible images is an important step towards understanding more complex modern architectures such as diffusion models. We consider a hierarchical model for memories which are sampled and stored in a dense Hopfield network with polynomial activation. We analytically derive conditions for each level of this hierarchy to be locally stable - that is they are local energy minima. We use prototype reconstruction as a minimal model of generalization and we find that it takes only a quasi-polynomial amount of information to generalize beyond particular memories and even particular groups in the hierarchy. We observe a qualitatively analogous phase diagram in the number of memories, sharpness of the activation function (polynomial degree) for data from Fashion-MNIST.

## 2. 方法论

### 2.1 模型设定
- **网络**：二值神经元 σ ∈ {−1, 1}^N，能量函数为
  E(σ) = −Σ_{μ=1}^{M} F(ξ^μ · σ)，其中 F(x) = x^n（多项式激活），n 为偶数。
- **数据模型**：记忆按一棵深度为 h、度数为 K 的树组织。根原型 g_0 为 i.i.d. Bernoulli(1/2) 随机向量；每个原型通过逐位噪声生成子代：
  g_ℓ = g_{ℓ−1} ○ e，其中 e_i ∈ {±1} 独立同分布，P(e_i = −1) = p，记 q = 1 − 2p（0 < p < 1/2）。
- **关键约束**：网络**只存储叶子记忆 ξ^μ**（共 K(K−1)^{h−1} 个），祖先原型从未被显式存储。

### 2.2 稳定性分析框架
- 定义**能量间隙**：ΔE(σ) = E(σ − 2σ_i ê_i) − E(σ)，若对所有翻转均 > 0，则该模式为局部极小值。
- 稳定性由均值 ⟨ΔE⟩（严格为正）和**平方变异系数** (C_v)^2（方差/均值²，类信噪比倒数）共同决定；后者控制模式不稳定的概率。
- 利用 Chebyshev 不等式将 (C_v)^2 转化为不稳定概率上界：P(∪ ΔE_i < 0) ≤ N · (C_v)^2。

### 2.3 图解形式体系（Feynman 式）
- 为处理繁琐的组合计算，作者发展了类比费曼图的图解形式：
  - **实线（bulk propagator）**：代表 N^{n−1} q^{(n−1)d(A,B)}；
  - **虚线（单自旋传播子）**：代表 q^{d(A,B)}；
  - 虚线存在**抵消规则**：重叠的虚线可约化为更短的非重叠集合。
- 通过该体系推导出能量间隙的均值与方差公式（在 q^{2h} = ω(n/√N) 参数区间内精确到 o(1) 相对误差）。

### 2.4 三类记忆的稳定性分析
1. **祖先原型** g_ℓ (0 < ℓ < h)：对应**泛化**（原型重建）；
2. **叶子记忆** ξ^μ (ℓ = h)：对应**记忆**（召回）；
3. **根原型** g_0 (ℓ = 0)：被所有样本强化。

## 6. 主要结论与发现

- **祖先原型可成为局部能量极小值**：在 q^{−2} ≪ K ≪ q^{−(2n−1)} 的中等 K 区间，(C_v)^2 大致按 ~K^{−1} 下降，存在最优 K* ∝ q^{−4n/3}。
- **泛化只需拟多项式信息**：取 K ∝ N·κ(N)、n ∝ log N、h ∝ log N，则每个祖先原型不稳定概率趋于 0；即用 N^{Θ(log N)+o(1)} 量级训练样本，可重建深度达 log N 的原型。
- **三区间相图（K 依赖）**：
  - Kq² < 1：祖先记忆高度不稳定（样本不足）；
  - 中间区间：稳定性最优，可实现泛化；
  - 大 K 极限：所有层级 (C_v)^2 饱和至 q^{−2ℓ} − 1，靠近叶子的模式极不稳定，仅根稳定。
- **叶子 vs. 根的对立行为**：叶子记忆的 (C_v)^2 随 K **单调递增**（样本间干扰损害个体召回）；根原型的 (C_v)^2 随 K **单调递减**（所有样本共同强化根），是唯一绝对稳定的记忆。
- **最优锐度**：n*(K) ~ log K；在 n = n*(K) 时 (C_v)^2 ∝ 1/K（各深度同时最小化）。
- **Fashion-MNIST 定性一致**：随 n 减小或 K 增大，动力学从"记忆原图 → 靴子原型 → 鞋原型 → 空白根"演化，中间原型会借用相邻层级特征（如鞋原型带靴子前部特征），与树模型的记忆—泛化交叉相对应。
- **与自旋玻璃的联系**：模型产生"硬编码"的超度量（ultrametric）局部极小值结构，与 f-RSB 自旋玻璃中涌现的超度量结构形成有趣对照。

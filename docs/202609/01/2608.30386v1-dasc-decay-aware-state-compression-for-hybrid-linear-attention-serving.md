## 摘要
混合线性注意力架构最近已扩展到大型开放权重模型，在显著减少键/值（KV）缓存增长的同时，提供了与全注意力相当的质量。然而，它们的原地递归状态更新使缓存管理复杂化：前缀重用需要状态检查点以及全注意力KV，而完整存储状态检查点会增加内存压力，导致更多驱逐和重复预填充。通过分析Gated DeltaNet（GDN）和Kimi Delta Attention（KDA）的衰减结构，我们发现不同的头和通道在显著不同的时间尺度上保留前缀信息，我们称之为“保留视野”。这种变化表明，在持久状态检查点中具有很大的压缩潜力。基于这一观察，我们引入了衰减感知状态压缩（DASC），它从模型权重中推导保留视野，选择长视野状态单元，并将它们打包成不规则的状态检查点布局。为了高效集成张量并行推理引擎，DASC进一步在TP（张量并行）排名之间平衡压缩后的状态检查点。在重用过程中，DASC要么对省略的单元进行零填充，要么通过额外的计算成本从有界的后缀中刷新它们。在Kimi-Linear的检索和端到端推理基准上，保守的DASC配置在将KDA循环状态检查点压缩2.63倍的同时，仍接近完全缓存。在固定的状态检查点内存预算下，由此产生的容量增益将平均首令牌时间（TTFT）降低了42.6%，并将输入吞吐量提高了68.4%。在更大的压缩比下，后缀刷新恢复了因更激进的省略而失去的大部分准确性，但代价是额外的重放计算。带有GDN的Qwen表现出类似的质量-效率趋势，表明DASC从逐通道的KDA扩展到逐头的GDN。

## Abstract
Hybrid linear-attention architectures have recently scaled to large open-weight models, offering quality competitive with full attention while substantially reducing key/value (KV) cache growth. However, their in-place recurrent-state updates complicate cache management: prefix reuse requires state checkpoints alongside full-attention KV, while storing state checkpoints in full increases memory pressure, leading to more evictions and repeated prefill. By analyzing the decay structure of Gated DeltaNet (GDN) and Kimi Delta Attention (KDA), we find that different heads and channels retain prefix information over markedly different timescales, which we term \emph{retention horizons}. This variation suggests substantial compression potential in persistent state checkpoints. Building on this observation, we introduce \emph{Decay-Aware State Compression} (DASC), which derives retention horizons from model weights, selects long-horizon state units, and packs them into a ragged state checkpoint layout. To integrate efficiently with tensor-parallel inference engines, DASC furtherly balances compressed state checkpoints across TP ranks. On reuse, DASC either zero-fills omitted units or refreshes them from a bounded suffix with additional compute cost. Across retrieval and end-to-end reasoning benchmarks on Kimi-Linear, conservative DASC configurations remain close to full caching while compressing KDA recurrent state checkpoints by $2.63\times$. Under fixed state checkpoint memory budgets, the resulting capacity gains reduce mean Time to First Token (TTFT) by 42.6\% and improve input throughput by 68.4\%. At larger compression ratio, suffix refresh recovers much of the accuracy lost to more aggressive omission, at the cost of additional replay computation. Qwen with GDN exhibits a similar quality--efficiency trend, showing that DASC extends from channel-wise KDA to head-wise GDN.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：混合线性注意力架构（如 Qwen3.8-2.4T-A95B、Kimi K3 等万亿参数模型）已在大规模开放权重模型中广泛应用。此类模型将全注意力层与线性注意力层交错排列，线性注意力层以固定大小的循环状态（recurrent state）汇总前缀信息，在保持模型质量的同时显著减缓 KV 缓存增长。
- **核心矛盾**：与全注意力 KV 不同，循环状态会随 token 到来被覆写，不保留早期前缀边界。因此前缀缓存必须在 token 间隔处**定期物化完整的循环状态检查点**（state checkpoint），与 KV 块并列存储。频繁检查点会很快耗尽 HBM（高带宽显存），而稀疏检查点则增加重放（replay）或重复预填充（prefill）开销。
- **关键观察**：通过分析 Gated DeltaNet（GDN）与 Kimi Delta Attention（KDA）的衰减结构，作者发现**不同头（head）和通道（channel）保留前缀信息的时间尺度差异显著**，即"保留视界"（retention horizon）不同：许多单元快速遗忘远端 token，而少数子集保持持久。权重中存储的衰减参数可提供与输入无关的视界估计。
- **研究意义**：这种衰减异构性意味着持久状态检查点存在**可观的压缩空间**——若能在不显著损失质量的前提下压缩检查点，则可在固定内存下缓存更多前缀，提高命中率，降低 TTFT，减少重复计算。DASC 正是将这一观察转化为可落地的服务端缓存策略。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
DASC 从模型权重推导静态"保留视界"（retention horizon），据此构建**输入无关的压缩方案**：保留长视界（长期有用）的状态单元，省略短视界（快速遗忘）的单元，将保留单元以"不规则布局"（ragged layout）打包成压缩状态检查点，并在张量并行（TP）rank 间均衡负载；缓存命中时，省略单元可零填充（DASC-NR）或通过有界后缀重放刷新（DASC-WR）。

### 2.2 关键技术细节

**（1）衰减结构与静态视界推导**

- GDN 的 log-decay 参数化为：
  \[
  g = -\exp(A_{\log})\,\text{softplus}(a + d_t^{\text{bias}})
  \]
  其中 \(A_{\log}\)、\(d_t^{\text{bias}}\) 为学习参数，\(a\) 为输入相关门控 logit。
- **静态保留视界**（固定输入门控 \(a=-0.3\)，使指标与输入无关）：
  \[
  H_s = \frac{\ln\epsilon}{g},\quad \epsilon=10^{-3}
  \]
  即衰减因子降至 \(\epsilon\) 所需的 token 数。
- 选择粒度与架构衰减粒度对齐：GDN 按**头**选择（每头一个完整状态矩阵），KDA 按**通道**选择（每个 \((h,k)\) 通道列）。由于 90.6% 的 KDA 头内部同时含有快慢通道，头级聚合会掩盖差异，故 KDA 必须通道级选择。

**（2）选择与存储（SELECT & PACK）**

- 阈值比较：\(H_s(u) > W_{\max}\) 的单元为**全局（global）**单元，即保留；否则为**局部（local）**单元，即省略。
- **Ragged 布局**：每层仅打包自己的 \(r_l\) 个保留单元，用偏移量索引，而非 padding 到最大层宽 \(R_{\max}\)。压缩比公式：
  \[
  C_{\text{rag}}^{\text{temp}} = \frac{\sum_l n_l}{\sum_l r_l},\quad
  C_{\text{rag}}^{\text{ckpt}} = \frac{B_{\text{dense}}^{\text{temp}} + B_{\text{conv}}}{B_{\text{rag}}^{\text{temp}} + B_{\text{conv}}}
  \]
  其中 \(n_l\)、\(r_l\) 为第 \(l\) 层总/保留单元数，\(B\) 为卷积状态字节数。Ragged 布局相对 Padded 布局的增益为 \(R_{\max}/\bar{r}\)，KDA 因层间保留数极不均衡而增益显著。

**（3）加载策略**

- **DASC-NR（默认）**：省略单元直接零填充，不增加模型计算。优点是快速、无额外开销，但省略单元的历史信息丢失。
- **DASC-WR**：从零初始化的 scratch 状态重放有界后缀，仅刷新省略的局部单元。重放窗口：
  \[
  W_u = \text{clamp}(\text{next\_pow2}(H_s(u)), 4, W_{\max}),\quad
  W_{\text{replay}} = \max_{u \in \mathcal{L}_{\text{local}}} W_u
  \]
  该策略需要额外计算但可恢复大部分精度；仍属近似，因不恢复重放窗口之前的历史。

**（4）TP 均衡放置**

- 两阶段均衡：① 模型加载期置换（permutation）重新分配线性注意力头束到 TP rank，精确重索引，无额外逐 token 通信；② 存储期将整个 TP 组视为共享存储池，用变长 split all-to-all 重新分配状态单元，使各 rank 负载接近均衡（目标宽度 \(C = \lceil \sum_r U_r / T \rceil\)）。
- 通信仅发生在状态检查点的 STORE/LOAD 边界，不干扰常规预填充和解码；两阶段均精确无损。

## 6. 主要结论与发现

1. **衰减异构性是普遍存在的**：KDA 通道衰减中位 α=0.471（IQR[0.170,0.774]），GDN 头衰减中位 0.969（IQR[0.894,0.997]），90.6% 的 KDA 头内同时含有快慢通道。
2. **权重推导的静态视界有效**：与经验视界的 Spearman 相关中位数：GDN 0.801、KDA 0.856；与状态幅度/读出幅度的相关性中等（0.40–0.63），足以作为选择信号。
3. **保守压缩几乎无损**：Wmax=16 时 KDA 压缩 2.63×，RULER 聚合精度与 dense 差异 ≤0.01，端到端任务所有行均与 dense 差 ≤1.3 个百分点，且优于 count-matched random（15 个推理对比中全部超随机均值，7 个 Holm 校正后显著）。
4. **匹配 HBM 下收益显著**：Kimi-KDA 上 TP 均衡放置使 TTFT 降低 25.4–42.6%，输入吞吐提升 39.3–68.4%（Wmax=16 时 TTFT 568→326 ms，吞吐 33.25→55.98k tok/s）。
5. **激进压缩下 DASC-WR 恢复精度**：Wmax=128 时 DASC-WR 比 DASC-NR 提升 0.8–7.4 个百分点，MMLU-Pro 保持 66.59–67.19%（dense 67.50%）；Wmax=512 时仍比 dense 的 TTFT 低 25.4%，精度差距 ≤0.31 点。
6. **可组合性**：与 INT8 状态量化结合可达 8.11× 容量提升，且保持精度。

## 7. 优点：方法与实验设计亮点

- **输入无关的静态选择信号**：从模型权重直接推导保留视界，无需校准数据或在线 profiling，可离线一次构建、跨检查点复用，工程落地性极强。
- **通道级/头级粒度对齐**：根据架构衰减粒度自适应选择单元，避免头级聚合隐藏通道级异质性。
- **Ragged layout + TP 均衡**：解决了不规则布局下的存储碎片和 TP 负载不均问题；TP 均衡被单独验证（storage-balanced vs hybrid），证明收益来自 placement 而非容量变化。
- **两种恢复策略分离**：DASC-NR 保证了零额外计算开销的快速路径，DASC-WR 提供了激进压缩下的精度恢复机制，且重放窗口有理论上界。
- **实验严谨性**：配对问题级统计推断（bootstrap CI + Holm 校正）、count-matched random 对照组隔离排序收益、warm/replay 协议保证零驱逐、容量计算完整透明。
- **实用价值**：在 SGLang 中直接实现，与 RadixAttention 集成；与状态量化互补，可叠加使用。

## 8. 不足与局限

- **架构覆盖有限**：仅评估了混合线性注意力架构（KDA/GDN）；结论是否适用于纯线性注意力或 SSM 模型未验证。
- **TP 规模单一**：所有服务实验仅测试 TP8，更大 TP 规模下的通信开销、负载均衡效果未知。
- **GDN 收益较小**：头级衰减粒度导致 GDN 压缩率仅 1.10–2.48×，作者指出需要更细粒度的压缩机制，但论文未提供解决方案。
- **验证集偏差风险**：视界验证仅用 32 条 ShareGPT 前缀，样本量小且来源单一；选择阈值 ε 和输入门控 a=-0.3 为启发式设定，未做系统敏感性分析。

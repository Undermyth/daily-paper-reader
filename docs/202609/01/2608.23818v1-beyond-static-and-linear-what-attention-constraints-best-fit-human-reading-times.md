## 摘要
基于Transformer的语言模型被广泛用作人类语言处理的模型，然而其注意力机制允许无损访问全部前文上下文，这与人类的有限记忆系统不同。我们假设在Transformer的注意力机制中安装记忆约束可以改善其与人类行为数据的拟合度。虽然以往的研究孤立地探索了个别约束，但我们进行了跨不同模型大小和训练语料库的多种基于注意力的记忆机制的系统比较，并评估了其对人类阅读时间的心理测量预测能力和语法能力。我们还比较了静态约束（在整个训练过程中约束强度固定）与动态记忆课程。我们发现，对中间标记内容敏感的约束始终与人类阅读时间的对齐度最高，优于基于距离的约束。在动态记忆课程下，我们观察到心理测量拟合度与语法能力之间的分离，表明Transformer不能作为一种通用的认知模型。

## Abstract
Transformer-based language models are widely used as models of human language processing, yet their attention mechanisms allow lossless access to the full preceding context, unlike the limited memory systems of humans. We hypothesize that installing memory constraints into transformers' attention mechanisms can improve their fit to human behavioral data. While previous work has explored individual constraints in isolation, we conduct a systematic comparison of multiple attention-based memory mechanisms across different model sizes and training corpora, evaluating both psychometric predictive power for human reading times and grammatical competence. We additionally compare static constraints, in which the constraint strength is fixed throughout training, to dynamic memory curricula. We find that constraints that are sensitive to the content of intervening tokens consistently achieve the highest alignment with human reading times, outperforming distance-based constraints. We observe a dissociation between psychometric fit and grammatical competence under dynamic memory curricula, suggesting that Transformers cannot serve as a one-size-fits-all cognitive model.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究动机**：Transformer 语言模型在自然语言处理中已被广泛用作人类语言处理的认知模型，但其注意力机制的核心特征——对**全部前文上下文进行无损访问**——与人类有限的记忆系统（人类无法无损地记住所有历史输入）存在根本矛盾。生理学和心理语言学研究表明，人类的记忆存在容量限制和衰减机制，那么是否可以将这些记忆约束安装进 Transformer 的注意力中，从而提升模型对人类行为数据的拟合度？
- **核心问题**：哪种类型的注意力记忆约束最符合人类的阅读时间数据？即距离型约束（如线性时序衰减和固定窗口截断）还是内容型约束（如对中间干扰词特征敏感的机制）更能模拟人类语言处理的真实过程？
- **理论背景**：论文引用了认知科学中的"Less is More"假设（Newport, 1990; Elman, 1993），即认知约束并非纯粹的劣势，反而可能促进更好的泛化与鲁棒性。文章在 cue-based 记忆检索框架下区分了两类主要理论：
  - **基于距离的记忆理论**（activation decay）：记忆表征随时间衰减，可通过检索目标与线索之间的距离操作化，例如损失性上下文惊奇度（lossy context surprisal）。
  - **基于内容的记忆干扰理论**（content-based interference）：检索困难源于检索目标与记忆中其他项（尤其是线性插入项）之间的特征重叠（即相似性干扰）。
- **整体含义**：本研究超越以往仅测试单一记忆约束的做法，系统比较多种注意力约束机制，并检验"Transformer 能否作为一统性的认知模型"这一更广泛的命题。

### 2. 论文提出的方法论：核心思想、关键技术细节

**2.1 核心思想**

论文的核心方法是将不同的记忆约束实现为 Transformer 注意力机制的变体，比较其在拟人阅读时间数据和语法能力上的表现。通过修改注意力得分，将认知理论具体化为可计算的机制，然后通过训练目标为语言建模的模型，检验其预测人类行为数据的能力。

**2.2 注意力约束变体（关键技术细节）**

- **Vanilla Attention（基线）**：标准 softmax 注意力，无任何记忆约束：
  aᵢⱼ = softmax(qᵢᵀkⱼ/√d)
- **ALiBi（线性距离偏置）**：在注意力得分上增加一个随标记之间距离线性增加的负惩罚项，实现距离型记忆约束。头相关的斜率 mₕ 为固定值：
  aᵢⱼ = softmax(qᵢᵀkⱼ/√d − mₕ(i−j))
- **N-gram（滑动窗口）注意力**：仅允许模型关注前 N 个标记，超出窗口的注意力得分设为 −∞，实现硬截断式（但逐层来看是软截断）的距离约束：
  aᵢⱼ = softmax(qᵢᵀkⱼ/√d + Mᵢⱼ)（当 i−j ≥ N 时 Mᵢⱼ = −∞）
- **Forgetting Gate（FoX）**：注意力得分中引入一个可学习的遗忘项，该遗忘项对中间插入令牌的嵌入（通过可学习的权重 w 和偏置 b 变换）进行逐位置的 log 累加，从而对距离无关但对**实际出现于两个令牌之间的内容**敏感：
  aᵢⱼ = softmax(qᵢᵀkⱼ/√d + Σ_{k=j+1}^{i} log fₖ)
  其中 fₖ = σ(w^T xₖ + b)。论文将其视为内容型（intervener-based）记忆约束的实例化。
- **Stick-Breaking Attention**：基于已存在的高注意力中间令牌来按比例衰减注意力得分，利用门控机制（gᵢⱼ = σ(qᵢᵀkⱼ/√d)）：
  aᵢⱼ = gᵢⱼ Π_{j<k<i}(1−gᵢₖ)
  该机制不加额外可学习参数，但同样对中间内容敏感，被归类为内容型约束。

**2.3 动态 vs 静态记忆约束**

- **静态约束**：训练全程中约束强度固定（如固定的 ALiBi 斜率或固定的 N-gram 窗口大小）。
- **动态记忆课程 (Dynamic Memory Curricula)**：在训练过程中随时间改变约束强度，检验发育假说。
  - **Less-to-More（由少到多）条件（符合 Less is More 假设）**：初始约束强度大，随训练进行逐步放松（约束衰减），使用缩放因子 mₜ（或 λₜ）随 epoch 乘以衰减率 r=0.6。
  - **More-to-Less（由多到少）条件（反向课程）**：初始约束小，逐步增大约束强度（m₀=0.0101，r=1.6667）。
  - 仅 ALiBi 与 Forgetting Transformer 实现了动态版本；N-gram 与 Stick-breaking 的动态版本留待未来工作。

**2.4 模型架构细节**

- 基于 OPT (Open Pre-trained Transformer) 架构，Decoder-only，从随机初始化开始训练。
- 两种配置：2 层（隐藏维度 256，注意力头 4 个）和 4 层（隐藏维度 384，注意力头 6 个）。
- 训练 10 epochs、AdamW 优化器、学习率 0.001、权重衰减 0.1、cosine 学习率调度 + 1% warmup、fp16 混合精度、单一种子（42）。

### 6. 论文的主要结论与发现

1. **内容型注意力约束优于距离型约束**：
   - Forgetting Transformer（FoX）在 6 种训练设置中的 5 种中 Δllh 排名第一，显著优于 Vanilla 模型。
   - Stick-breaking 注意力稳定排名第二或第三，在 3 种设置中显著优于基线。
   - 距离型约束（ALiBi 和 N-gram）的结果不稳定：ALiBi 在 4 层模型中表现较好，但在 2 层模型中增益有限；N-gram 模型在所有设置中大多显著劣于 Vanilla。
   - 结论：基于中间干扰内容（intervener-based）的记忆约束是人类阅读时间更准确的模型。

2. **Perplexity 与 Δllh 的关系**：总体上二者存在负相关（r=−.69，p<.001），符合先前研究。但 FoX 和 Stick-breaking 模型在回归线之上，说明其认知拟合的提升不能仅由语言建模质量的改进来解释，机制本身确实更接近人类处理过程。

3. **动态记忆课程下的分离（Dissociation）**：
   - **语法能力（BLiMP）**：动态模型在最终 epoch 均优于静态模型。其中**More-to-Less（约束渐强）的 Forgetting Transformer** 在 epoch 10 达到最高 BLiMP 分数；Less-to-More 的 FoX 因约束放松性能下降。
   - **心理测量预测能力（Δllh）**：静态模型始终优于动态模型；没有任何动态模型在最终 epoch 能达到其静态对应物的 Δllh 水平。
   - 结论：优化语法能力与优化对实时阅读时间预测能力在 Transformer 架构下是不兼容的目标，需要不同的训练策略。

4. **对 "Less is More" 假说的挑战**：More-to-Less 动态课程（约束渐增）在语法能力上表现最好，这与直觉上的 Less-to-More 假说预测方向相反。作者推测这可能类似于模拟退火机制——模型先自由探索参数空间再收敛到约束解。但作者也谨慎指出这并不等于否定 "Less is More" 假说本身，差异可能来自模型与人类学习者在输入模态、社会互动等方面的根本不同。

5. **综合结论**：Transformer 无法成为"一统性"的人类语言认知模型，不同类型的行为数据可能需要不同的模型约束配置。但内容型/intervener-based 记忆机制值得在未来的计算建模研究中得到更多关注。

## 摘要
混合大语言模型将全注意力层与线性注意力层交错排列，以降低长上下文推理的成本。这种结构使前缀缓存复杂化：全注意力键值缓存可按令牌寻址，而线性注意力层维持的循环状态无法回滚到任意前缀边界。现有的混合前缀缓存方法通过存储循环状态检查点来解决这一不匹配问题。因此，令牌级匹配仅在存储检查点的位置处可直接使用，从而将前缀重用限制在离散的边界集合上。我们提出尾重放（Tail-Replay），一种前缀缓存机制，能够在混合大语言模型中实现无约束的令牌级前缀重用。关键洞察在于，如门控DeltaNet等线性注意力机制可视为输入前缀的一种结构化有损压缩：门控循环更新逐渐衰减早期输入的贡献。因此，匹配前缀的循环状态可通过仅重放该前缀的一小段近期后缀来很好地近似。尾重放利用这一特性，缓存精确的全注意力键值缓存，同时省略循环状态检查点。在缓存命中时，它通过重放匹配前缀的一小段近期后缀来重建线性注意力状态。因此，重用边界由共享令牌决定，而非循环状态检查点。我们使用LongBench和RULER基准评估了基于门控DeltaNet的三种混合模型上的尾重放。仅使用5%–10%的重放预算，它在LongBench和RULER上保留了全预填充质量的92.8%–99.9%。在服务效率方面，我们评估了多种匹配前缀长度（8K、16K和32K）下的首令牌时间加速比。加速比随前缀长度增长，在32K时相对全预填充达到9.1–14.3倍。

## Abstract
Hybrid large language models interleave full-attention layers with linear-attention layers to reduce the cost of long-context inference. This structure complicates prefix caching: full-attention key-value caches are token-addressable, whereas linear-attention layers maintain recurrent states that cannot be rolled back to arbitrary prefix boundaries. Existing hybrid prefix caching methods address this mismatch by storing recurrent-state checkpoints. As a result, token-level matches are directly usable only at positions aligned with stored checkpoints, constraining prefix reuse to a discrete set of boundaries. We present Tail-Replay, a prefix caching mechanism that enables unconstrained token-level prefix reuse in hybrid large language models. The key insight is that linear-attention mechanisms such as Gated DeltaNet can be viewed as a structured, lossy compression of the input prefix: gated recurrent updates progressively attenuate the contributions of earlier inputs. Consequently, the recurrent state of a matched prefix can be well approximated by replaying only a short, recent suffix of that prefix. Tail-Replay exploits this property by caching the exact full-attention key-value cache while omitting recurrent-state checkpoints. On a cache hit, it reconstructs the linear-attention states by replaying a short, recent suffix of the matched prefix. As a result, the reuse boundary is determined by the shared tokens rather than by recurrent-state checkpoints. We evaluate Tail-Replay on three Gated DeltaNet-based hybrid models using the LongBench and RULER benchmarks. With only a 5--10\% replay budget, it retains 92.8--99.9\% of full-prefill quality on LongBench and RULER. For serving efficiency, we evaluate time-to-first-token speedups across multiple matched-prefix lengths---8K, 16K, and 32K. The speedup grows with prefix length, reaching $9.1$--$14.3\times$ over full prefill at 32K.

# 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 应用正从单轮助手演化为多轮对话、RAG、工具调用与多智能体工作流，带来长上下文、重复调用与高并发需求，服务效率成为重要问题。
- **两个互补技术**：
  - **混合架构**（如 Jamba、Qwen3.5/3.6 等）：交织全注意力层与线性注意力层，以降低长上下文开销。
  - **前缀缓存**：复用多个请求间的共享前缀，避免重复预填充。
- **核心矛盾**：
  - 全注意力（FA）层的缓存是**令牌可寻址**的（token-indexed），可在任意 token 边界复用。
  - 线性注意力层将前缀压缩为**循环状态**（recurrent state），一旦推进无法回滚到任意早的前缀边界。
  - 这一不匹配使得“token 级别的前缀匹配”不再直接意味着“模型状态可复用”，作者称之为 **“线性注意力的诅咒”**。
- **现有方案局限**：Marconi 和 Sparse Prefix Caching 通过显式管理循环状态检查点来缓解问题，但前缀重用仍受限于检查点位置，而非共享 token 的边界。
- **Tail-Replay 的定位**：首个不受循环状态检查点约束、实现无约束 token 级前缀复用的混合模型前缀缓存机制。

## 2. 方法论（Method）

### 2.1 核心洞察

- 门控 DeltaNet（Gated DeltaNet, GDN）等线性注意力机制可视为**对输入前缀的结构化有损压缩**：
  - 门控循环更新（式 1）通过门控因子 αᵢ ∈ (0,1] **逐渐衰减早期 token 的贡献**；
  - 因此，匹配前缀的循环状态可以用其**近期短后缀重放**来高精度近似。
- 由此，无需缓存循环状态检查点，只需缓存 FA KV 缓存，命中时重放短后缀即可重建线性状态。

### 2.2 关键公式

GDN 的循环更新为：

```
Sᵢ = TᵢSᵢ₋₁ + βᵢvᵢ(kᵢ)ᵀ
Tᵢ = αᵢ(I − βᵢkᵢ(kᵢ)ᵀ)
```

其中 kᵢ、vᵢ 为第 i 个 token 的键与值，αᵢ 是习得门控，控制早期信息的衰减速率。

Tail-Replay 的重放过程为：对匹配前缀的前 m 个 token，选择最近 k = ⌈r·m⌉ 个 token 作为尾部，从零状态 Ŝₘ₋ₖ = 0 开始，对尾部应用以上 GDN 递推，得到近似状态 Ŝₘ。

### 2.3 方法流程

1. **缓存内容**：对每个已处理输入，缓存每个 FA 层的 KV 对（K_F A， V_F A）以及 FA 输出隐藏状态 hᵢ。
2. **分组架构划分**：将混合模型划分为若干组，每组包含一个 FA 层及其后连续的线性注意力层。缓存 FA 输出隐藏状态，确保每组第一个线性层的输入与其在原始预填充时完全一致，将重放误差限制在组内。
3. **缓存命中处理**：
   - 直接检索匹配前缀的 FA KV（精确复用）；
   - 仅取最近 k=⌈r·m⌉ 个缓存的 FA 输出隐藏状态作为重放输入；
   - 每组线性注意力层从零状态独立执行重放（Tail-Replay），重建匹配前缀边界处的循环状态；
   - 用重建的线性状态 + 检索到的 FA KV 继续处理未匹配后缀。
4. **独立性**：每个分组独立重放，互不依赖，支持并行。

### 2.4 两个效率优化

- **尾部 FFN 跳过（tail-FFN skip）**：重放时，组末层的 FFN 输出对状态重建不是必需的（下一组从精确的 FA 输出隐藏开始），因此重放时跳过 FFN，只计算线性注意力块以更新循环状态，降低计算开销。
- **传输/重放重叠（transfer/replay overlap）**：Tail-Replay 不依赖缓存 FA KV，因此主机到设备（H2D）的 FA KV 传输可与重放在同一设备的独立拷贝流上并发执行，仅在查询前向传播前同步，隐藏大部分数据移动开销。

## 3. 实验设计

  - H2D 重叠 + FFN 跳过（H2D-OVL+skip）
  - 每种均在 5% 和 10% 重放预算下测试。

## 6. 主要结论与发现

1. **Tail-Replay 使混合 LLM 实现无约束 token 级前缀复用**，突破了线性注意力状态检查点对前缀重用边界的限制。
2. **重放短尾即可高保真重建线性状态**：
   - r = 5% 时在 LongBench 保留全预填充质量的 92.8–98.9%，RULER 上保留 93.1–99.9%；
   - r = 10% 时 LongBench 保留 93.9–98.1%，RULER 保留 96.7–99.9%。
3. **ZERO-ONLY 质量显著下降**（如 LongBench 上仅 0.159–0.415、RULER 上低至 0.000–0.415），验证了状态重建的必要性——单纯复用 FA KV 不进行线性状态重建是不够的。
4. **TTFT 加速显著**：加速比随前缀长度增长，32K 前缀时 5% 重放 + 重叠传输达到 9.1×–14.3× 的 TTFT 加速。
5. **传输/重放重叠有效**：相对于串行 H2D 传输，OVL+skip 在 32K 时进一步降低 TTFT 18–42%。
6. **重放预算权衡**：10% 重放在短上下文时影响不大，但在 32K 时长上下文下重放成为主导成本，TTFT 明显上升。

## 7. 优点

- **方法新颖**：首次提出“省略检查点、短尾重放”的思路，从根本上突破检查点边界的限制，而非在检查点集合上做优化。
- **理论洞察清晰**：将门控线性注意力解释为“有损压缩器”，从机制层面论证了尾部重放近似的合理性。
- **设计干净有效**：通过缓存 FA 输出隐藏状态并分组独立重放，将误差限制在组内；不依赖 FA KV 传输的特点被利用为传输/计算重叠。
- **消融设计合理**：ZERO-ONLY 基线有效隔离了“FA KV 复用”与“线性状态重建”各自的贡献。
- **FFN 跳过优化巧妙**：利用组边界使用精确缓存隐藏状态的特性，避免重放中不必要的 FFN 计算。
- **报告相对质量**：以“占全预填充质量的百分比”报告结果，便于直观判断质量损失程度。

## 8. 不足与局限

- **方法适用范围有限**：
  - 仅验证了 Gated DeltaNet 一种线性注意力机制；
  - 对门控衰减较慢（α 接近 1）或依赖长程记忆的线性注意力，短尾重放的近似误差可能显著增大；
  - 方法的有效性依赖线性注意力“近期 token 主导”的性质，不适用于所有 SSM/线性注意力变体。
- **实验覆盖不足**：
  - 任务种类有限，未覆盖更长上下文（≥128K）与更多任务类型；
  - 效率评估为合成共享前缀场景，未在真实多用户、多请求并发负载下验证；
  - 未报告端到端吞吐量（tokens/s）或总延迟，只有 TTFT；
  - 未给出缓存存储开销（FA 输出 hiddens 的额外存储成本）的定量分析。
- **缺少与现有方法的直接对比**：未与 Marconi、Sparse Prefix Caching 等基于检查点的方法进行质量和效率的公平对比，无法定量说明 Tail-Replay 相对现有方法的增益幅度。
- **公平性问题**：论文声称“第一个无约束 token 级前缀复用”的混合缓存机制，但未与同期相近工作（如 LinearKV）做对比（仅列入参考文献）。
- **算力信息不透明**：未报告 GPU 数量、实验总耗时等资源信息。
- **近似误差未量化**：未直接测量重建状态与真实状态之间的距离（如余弦相似度或谱范数差距），只通过下游质量间接评估。

## 总结

Tail-Replay 通过“缓存精确 FA KV + 命中时重放近期短尾重建线性状态”的设计，有效解决了混合 LLM 中线性注意力循环状态无法任意回滚导致的前缀缓存受限问题，在 Gated DeltaNet 类模型上以极低的重放开销获得高质量与显著 TTFT 加速。但方法的通用性、与现有方法的直接对比、真实负载下的系统级验证仍有待加强。

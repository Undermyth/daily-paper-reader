## 摘要
随着上下文长度的扩展，注意力机制日益成为大型语言模型中的主要计算瓶颈。标准Transformer虽然功能强大，但计算效率低下，因为它对每个token分配相同的注意力预算，而不考虑其上下文需求。现有的局部-全局混合模型通过混合受限和全上下文注意力提供了一种更高效的替代方案，但它们通常跨层或跨头静态分配跨度。为解决这些局限性，我们提出了LoGo，一种令牌级动态局部-全局注意力机制，利用注意力跨度作为注意力预算分配的直接代理。每个LoGo层包含耦合的局部和全局分支：所有token在受限上下文窗口内接收高效的局部注意力，而学习得到的门控仅为需要长距离信息的token激活具有全上下文访问权限的全局注意力。一种基于阈值的预算控制器在无辅助损失的情况下维持目标全局比率，而渐进式掩蔽调度在稀疏路由生效前稳定训练。我们进一步实现了查询稀疏的Triton内核，将减少的全局注意力计算转化为实际的速度提升。大量实验验证了LoGo的有效性，表明它在不同模型规模下保持了全注意力Transformer的扩展行为。在受控比较中，LoGo优于全注意力Transformer和匹配预算的静态局部-全局混合模型，在长距离检索方面具有明显优势。进一步分析表明，LoGo学习了可解释的跨度分配模式。这些结果表明，学习到的令牌级跨度分配是改善长上下文性能-计算权衡的有效且可扩展的方法。

## Abstract
As context lengths scale, attention increasingly becomes a primary computational bottleneck in large language models. Standard Transformers remain powerful but computationally inefficient, as they allocate the same attention budget to every token regardless of its contextual demand. Existing local-global hybrids provide a more efficient alternative by mixing restricted- and full-context attention, but they typically allocate span statically across layers or heads. To address these limitations, we propose LoGo, a token-level dynamic local-global attention mechanism that uses attention span as a direct proxy for attention budget allocation. Each LoGo layer contains coupled local and global branches: all tokens receive efficient local attention over a restricted context window, while a learned gate activates global attention with full-context access only for tokens requiring long-range information. A threshold-based budget controller maintains a target global ratio without auxiliary losses, and a progressive masking schedule stabilizes training before sparse routing takes effect. We further implement query-sparse Triton kernels that convert reduced global-attention computation into practical speedups. Extensive experiments validate LoGo's effectiveness, showing that it preserves the scaling behavior of full-attention Transformers across model sizes. In controlled comparisons, LoGo improves over the full-attention Transformer and matched-budget static local-global hybrids, with clear gains on long-range retrieval. Analysis further shows that LoGo learns interpretable span allocation patterns. These results suggest that learned token-level span allocation is an effective and scalable way to improve the long-context performance-compute trade-off.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：标准Transformer对每个token分配**相同的注意力预算**，无论其上下文需求如何。随着上下文长度扩展，注意力成为主要计算瓶颈，这种均匀分配导致大量计算浪费在局部可预测的token上。
- **现有方案局限**：
  - **标准Transformer**：全注意力计算代价为O(T²d)，长上下文下不可负担。
  - **静态局部-全局混合模型**（层间混合或头间混合）：将注意力跨度设为固定模板，所有token遵循相同通路，无法根据token的实际需求动态分配全局注意力，常将全局计算浪费在局部可预测的token上。
  - **既有动态变体**：要么在注意力机制之间切换而非直接分配跨度，要么依赖手工设计的路由规则，要么缺乏匹配预算的大规模评估。
- **研究动机**：是否可以让模型**学习在token级别决定**哪些token需要全局（长程）注意力、哪些只需局部注意力，从而在保持性能的同时显著降低计算代价？
- **核心主张**：注意力跨度（attention span）是注意力预算分配的自然代理——它同时控制可访问上下文范围和计算代价，且其需求可从语言上下文中预判。

## 2. 方法论：LoGo机制

### 2.1 核心思想
- 每个LoGo层包含**耦合的局部和全局两个注意力分支**：
  - 所有token无条件获得局部注意力（滑动窗口，w=128）。
  - 一个**可学习的门控（gate）** 预测每个token对全局跨度的偏好，只有被选中的token才额外计算全局注意力。
- **关键区别**：LoGo保持注意力形式不变，直接学习token级的局部/全局跨度分配，而非在层间或头间预设固定模式。

### 2.2 技术细节

**（1）耦合的局部与全局分支**
- 共享主注意力投影（W_q, W_k, W_v）产生局部分支表示。
- 全局分支通过轻量变换（线性投影 LP 或缩放偏移 SO）从局部表示派生，仅增加约1%参数。
- 变换初始化为恒等映射，使两个分支从共享表示出发、在训练中逐步特化。

**（2）令牌级跨度分配与输出融合**
- 门控输出标量偏好p_t（sigmoid后的结果），与逐层阈值b_th比较产生硬决策z_t：
  - z_t=1：激活全局分支，输出 = (1−p_t)·局部输出 + p_t·全局输出（加权融合）。
  - z_t=0：跳过全局分支，输出 = 局部输出。
- 分支专用ContextNorm（头级RMSNorm）防止门控补偿分支间量级差异，使门控专注于学习跨度偏好。

**（3）预算控制与渐进掩码**
- **阈值控制器**：根据batch中实测全局激活比例F与目标比例ρ的差异，更新阈值：
  - b_th ← b_th + γ·sign(F − ρ)
  - 无需辅助损失即可维持目标全局比例，不修改LM目标本身。
- **渐进掩码（P-mask）**：训练初期将阈值初始化为负值，使所有token都激活全局分支；随着训练推进，阈值逐渐靠近门中心（0.5），稀疏路由逐步生效，避免早期路由信号不可靠导致全局分支训练信号受阻。

**（4）高效实现**
- **查询稀疏（query-sparse）内核**：只对选中的query行计算全局注意力，未选中的query进入密集KV缓存但不实例化全局query行。注意词：**KV是密集保留的**，因此选中的token仍保有精确的全上下文访问。
- 计算复杂度：O(T·w·H·d_h + ρ·T²·H·d_h)，与同比例静态混合模型的主导计算相同，但分配方式是动态的。
- 与前向无关的稀疏结构：所有头共享同一token级路由决策，避免头级负载不均；保持密集KV布局，兼容张量并行和序列并行。

1. **缩放行为保持**：从200M到3.3B，LoGo一致匹配或优于全注意力Transformer基线，训练损失、困惑度和常识推理均不落下风。

3. **效率转化**：查询稀疏内核在稀疏度50%时可达约1.99×加速（64k长度），接近理论值；稀疏度越高加速越显著。
4. **可解释的分配模式**：LoGo学习到5种可解释的词级分配模式：
   - 序列开头倾向局部；句子起始处倾向全局；
   - 固定短语后段转向局部；长程重复内容触发强全局激活；
   - 上下文切换后全局使用快速下降。
5. **比例鲁棒性**：在0.25~0.75全局比例范围内均优于同等预算的层间混合。
6. **兼容性**：与内存节约型静态混合结合可进一步降低计算量并提升召回（65.6/66.9 vs 65.1）。

## 7. 优点

- **问题定位精准**：直接针对静态混合的“一刀切”缺陷，将注意力跨度作为预算分配的代理，概念简洁有力。
- **方法设计精巧**：
  - 分支参数共享+轻量解耦（仅约1%参数，避免完全共享或完全解耦的缺陷）；
  - 阈值控制器无辅助损失，简单且有效；
  - 渐进掩码解决了“鸡生蛋”式冷启动问题（没有良好门控→无法路由；没有路由→门控无法学习）；
  - 加权融合使局部和全局输出显式竞争，优于加法融合。
- **实验严谨**：匹配参数和FLOPs的对比设计、多规模验证、消融覆盖全面，且包含模型行为（分配模式）的可视化分析，提供了除指标外更深层的洞见。
- **实现考虑充分**：查询稀疏内核的设计考虑了负载均衡（所有头共享token级决策）、因果掩码处理和并行兼容性。

## 8. 不足与局限

- **未披露算力细节**：GPU型号、数量、实际训练时长均未说明，削弱了结果的可复现性和对实际资源需求的理解。

- **内核效率差距**：Triton实现与CUDA FlashAttention相比仅在高稀疏度时更快，在不改变后端的情况下，实际应用的端到端收益打了折扣。

- **可解释性分析为定性观察**：词级模式分析主要为人工观察的定性描述，缺乏量化验证或对比实验来确认这些模式的因果作用。

## 摘要
大型推理模型（LRMs）通过扩展的思维链（CoT）生成实现卓越的问题求解能力，但由此产生的键值（KV）缓存随序列长度线性增长，造成严重的内存瓶颈，在长推理轨迹中往往超出GPU容量。现有的KV缓存压缩方法依赖近期查询来估计未来标记的重要性，隐含地假设这些查询可作为未来注意力模式的可靠代理。我们证明，这一假设在长视野推理中不成立：某些解码步骤会生成思维回溯标记（TRT），这些标记会重新关注较早的上下文，例如在轨迹早期制定的任务求解计划。通过系统分析，我们发现对应于TRT的查询在嵌入空间中聚集成少量相似性组。基于这一洞察，我们提出BeaconKV，一种免训练的KV缓存压缩方法，它维护信标查询，即每个全局查询簇的紧凑代表，以预判哪些KV对将被重新访问，而无需存储完整的查询历史。在四个开源LRM和多样化推理基准上，BeaconKV通常优于现有压缩方法，实现高达5.8倍的内存缩减，同时几乎保持完整缓存的准确性，并将吞吐量提升超过4.3倍。

## Abstract
Large Reasoning Models (LRMs) achieve superior problem-solving through extended Chain-of-Thought (CoT) generation, but the resulting key-value (KV) cache grows linearly with sequence length and creates severe memory bottlenecks, often exceeding GPU capacity for long reasoning traces. Existing KV cache compression methods rely on recent queries to estimate future token importance, implicitly assuming these serve as reliable proxies for future attention patterns. We demonstrate that this assumption fails in long-horizon reasoning: certain decoding steps generate Thought Revisiting Tokens (TRT) that re-attend to distant previous context, such as task-solving plans formulated early in the trace. Through systematic analysis, we discover that queries corresponding to the TRT cluster into a small number of similarity groups in the embedding space. Based on this insight, we propose BeaconKV, a training-free KV cache compression method that maintains beacon queries, compact representatives for each global query cluster, to anticipate which KV pairs will be revisited without storing the entire query history. Across four open-source LRMs and diverse reasoning benchmarks, BeaconKV generally outperforms existing compression methods, achieving up to $5.8\times$ memory reduction while nearly preserving full cache accuracy and improving throughput by over $4.3\times$.

## 1. 论文核心问题与研究动机

大型推理模型（LRM）通过**扩展思维链（CoT）** 来应对复杂推理任务，但在其长序列解码过程中会遭遇严重的**内存瓶颈**：

- 注意力机制需要对所有历史 token 进行键值（KV）缓存，KV 缓存随序列长度**线性增长**。
- 例如，Qwen3-4B 生成 32K token、batch size = 16 时，KV 缓存即超过 **77GB**，逼近甚至超出单张 80GB GPU 极限。

现有 KV 压缩方法（如 RPC、R-KV）**依赖近期查询（recent queries）** 来估计未来 token 的重要性，其隐含假设是“近期查询可以充当未来注意力模式的可靠代理”。论文论证了该假设在长程推理中并不成立：

- 推理过程中会出现**思维回溯标记（Thought Revisiting Tokens, TRT）**：某些解码 step 重新关注**远距离早期上下文**，例如任务求解计划、问题条件等。
- 属于 TRT 的查询在嵌入空间中**聚集成少量相似性组**，且与局部查询（集中于邻近 key 的查询）在几何结构上显著分离。
- 近期查询方法因其时间局部性，无法预测这些“远期回访”，会导致关键 KV 对在逐出时丢失，进而劣化推理质量。

## 2. 论文提出的方法论：BeaconKV

### 2.1 核心思想
利用 TRT 查询在嵌入空间的可聚类性，引入**信标查询（beacon queries）**：

- 将**最新查询**与**历史信标查询**结合，构成观察查询集。
- 以信标查询代表潜在的全局查询簇，从而在**不存储全部查询历史**的前提下预测未来可能被重访的 KV 对。

### 2.2 关键技术细节

#### (a) 观察查询集构成
- **近期查询**：保留局部连贯性。
- **信标查询**：通过几何采样保存全局查询方向的历史代表。
- 两类查询均使用**pre-RoPE 的查询向量**存储，避免位置编码影响相似度度量。

#### (b) Continual FPS（持续最远点采样）
- 对每个注意力头维护**有界缓冲区**，新查询不断加入。
- 当缓冲区达到上限 \( B_{max}^Q \) 时，运行 FPS 对其下采样至 \( B_{min}^Q \)，只保留最富几何多样性（最为分散）的查询。
- 相比朴素 FPS（遍历全部历史查询），可持续 FPS 同时降低了峰值显存，并基本保持离线采样精度（与 K-Means 聚类质心等基准对齐）。

#### (c) 注意力打分与逐出规则
- 当 KV 缓存达到预算 \( B_{max}^{KV} \) 时，将信标查询旋转到当前解码位置（RoPE），模拟未来 TRT 可能施加的注意力模式。
- 使用**最大值池化（Max Aggregation）**，跨查询、跨头聚合注意力权重，避免均值池化对稀疏 TRT 信号的稀释。
- 逐出策略保留前缀 token 与最近窗口 token，其余按分数补足 Top-K。

### 2.3 规避机制的对应关系
论文用“（b）BeaconKV（ours）”直接对比“（a）仅基于近期查询的传统压缩路线”，突出信标查询在注意力评分阶段起关键作用。

## 6. 主要结论与发现

1. **TRT 现象**：长程推理中存在分散在各个层/头中的“思维回溯”型查询，用于重新关注早期计划或问题约束。
2. **几何聚类假设成立**：这类全局查询在 pre-RoPE 空间聚类，少数信标即可覆盖。
3. **BeaconKV 持续有效**：相比 RPC、R-KV、SnapKV，在多数模型与预算配置下精度最高；

4. **融合式观测集最优**：16 近期查询 + 16 信标查询的配置在精度/延迟之间取得最佳平衡。
5. **Max 聚合强于 Mean 聚合**：TRT 信号本就稀疏且高幅，均值池化会稀释关键注意力证据。

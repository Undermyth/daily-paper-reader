## 摘要
线性注意力用固定大小的循环状态取代了标准注意力中不断增长的键值（KV）缓存，从而在上下文长度增加时大幅降低内存增长。然而，这种高效性改变了过往信息的存储方式：许多 token 必须共享并反复更新同一份记忆。我们研究这种循环状态如何作为一个记忆系统运作。我们结合解析分解与在预训练的 GLA 和 GDN 模型中的受控因果干预，追踪被召回的信息如何被写入、保留以及随后被访问。我们发现，事实特定信息通过集中的、依赖于内容的写入进入循环记忆，随后通过集中的查询时读取通路被访问。多个事实可以在同一状态中保持选择性可访问，但它们的内部表示表现出跨事实的因果耦合，而非独立的类 KV 存储。随着记忆负载增加，召回和定向编辑能力都会下降，而仅上下文流逝在测试范围内的影响要小得多。对后续写入的因果干预进一步表明，干扰受其与现有记忆重叠程度的塑造。最后，在将循环层与全注意力相结合的混合架构中，直接支持召回的运行时记忆主要转移到全注意力的 KV 状态。这些结果共同揭示了固定大小的循环记忆如何在共享存储的情况下支持选择性召回，同时暴露了使其有别于可按 token 寻址的 KV 记忆的干扰与容量限制。

## Abstract
Linear attention replaces the growing key--value (KV) cache of standard attention with a fixed-size recurrent state, substantially reducing memory growth with context length. This efficiency, however, changes how past information is stored: many tokens must share and repeatedly update the same memory. We study how this recurrent state functions as a memory system. Using an analytical decomposition together with controlled causal interventions in pretrained GLA and GDN models, we trace how recalled information is written, retained, and later accessed. We find that fact-specific information enters recurrent memory through concentrated, content-dependent writes and is later accessed through concentrated query-time read pathways. Multiple facts can remain selectively accessible within the same state, yet their internal representations exhibit cross-fact causal coupling rather than independent KV-like storage. As memory load increases, both recall and targeted editability degrade, whereas elapsed context alone has a substantially smaller effect within the tested regime. Causal interventions on subsequent writes further show that interference is shaped by their overlap with existing memory. Finally, in hybrid architectures that combine recurrent layers with full attention, the runtime memory directly supporting recall shifts predominantly to the full-attention KV state. Together, these results reveal how fixed-size recurrent memory supports selective recall despite shared storage, while exposing the interference and capacity limits that distinguish it from token-addressable KV memory.

# 《How Linear Attention Remembers》论文总结

## 1. 核心问题与整体含义

- **背景**：标准 Transformer 在自回归推理时保留每个历史 token 的键值（KV）缓存，缓存随序列长度线性增长，成为长上下文推理、批量服务以及移动端/边缘/机器人等资源受限场景的主要内存瓶颈。
- **线性注意力的替代方案**：以固定大小的循环状态替代逐 token 的 KV 表示，状态规模不随序列长度增长（GLA、DeltaNet、Gated DeltaNet 等）。
- **核心矛盾**：高效性改变了信息的存储方式——大量 token 必须共享并反复更新同一份有限状态。KV 缓存中单 token 表示始终显式可寻址，而循环状态中多来源信息被不断变换、叠加、聚合。
- **知识缺口**：已有的 KV 缓存研究（冗余、压缩、token 重要性、驱逐）依赖可寻址结构，无法直接迁移。尚不清楚：哪些状态更新承载被记住的内容、召回时如何被读取、多个事实如何共存、负载增加时保持为何退化，以及在混合架构中循环状态是否仍是主要记忆载体。
- **整体含义**：论文把循环状态当作一个“记忆系统”来研究，给出从写入到读取的因果解释，并刻画其相对可按 token 寻址的 KV 记忆的能力边界与容量限制。

## 2. 方法论

- **核心思想**：以解析分解刻画循环状态的来源构成，再用受控因果干预（donor/recipient 配对）在预训练模型上分离“写入—保持—读取”三个阶段。
- **解析框架**：
  - 循环更新：`S_t = T_t(S_{t-1}) + W_t`，其中 `T_t` 对前一状态线性（GLA 为 `T_t(S)=G_t⊙S` 的乘性门控；Delta 规则变体还会沿 token 相关方向修正旧状态），秩一写入形如 `W_t = u_t v_t^T`。
  - 读取：`o_t = q_t^T S_t`。
  - 来源分解：`C_i^(i)=W_i`，`C_i^(t)=(T_t∘…∘T_{i+1})(C_i^(i))`，则 `S_t = Σ_i C_i^(t)`；该分解在固定前向轨迹上精确，干预则度量端到端效应。
  - 三条推论：① 不同位置贡献共享同一状态；② 存储与访问分离（`o_t = Σ_i q_t^T C_i^(t)`）；③ 聚合状态到来源贡献的映射是多对一，单个来源不被显式分离；④ 保持不只看 token 年龄，还取决于后续每次变换 `T_j`。
- **因果干预流程（Figure 1）**：
  1. **事实时刻写入**：将接收方的写入置零（write block）测试必要性，或替换为供体写入（donor write）测试内容特异性。
  2. **状态演化**：后续 token 继续施加变换与新写入。
  3. **查询前状态**：将选中头的查询前循环状态替换为供体状态（state swap）。
  4. **查询时读出**：替换选中头的查询输出（output patch），或在供体状态交换后恢复干净输出（output restore），以检验该读取通路是否中介了行为效应。
  5. **多事实扩展**：多个事实共享同一状态，检验选择性召回与跨事实耦合。
- **头选择协议**：在独立开发集上扫描全部循环头（96/96/192 个），以单头状态交换后的 donor-margin 平均位移 `J_{ℓ,h}` 排序，取最高分头并冻结，后续确认实验绝不重新选择。
- **配对构造与统计**：接收方与供体输入共享前缀、仅目标键绑定值不同；报告四选一召回准确率与目标 logit margin；以源段落为统计单位，报告 source-bootstrap 95% 置信区间。
- **辅助分析**：Frobenius 内积将事实 A 的状态方向分解为平行/正交于事实 B 方向的分量；中性状态反事实（用目标事实被替换为填充文本的长度匹配执行）测试单事实选择性抑制；logit lens 逐层定位答案可读出性；状态特征校正模型诊断原生错误。

## 3. 实验设计

- **模型**：纯循环的 GLA-340M、GDN-340M、GDN-1.3B；近似匹配的混合 GDN-340M（24 层中 8 层替换为全注意力）；混合 Qwen3.5-4B 与 Qwen3.5-9B（3:1 GDN/全注意力）；泛化性补充 GLA-7B、RWKV7-2.9B、RWKV7-13.3B。全部使用预训练权重，不微调。
- **数据/场景**：受控联想召回——在自然文本上下文中嵌入一个或多个键值关联，随后查询恢复先前值；上下文取自 source-disjoint 的 WikiText-103 段落；四选一候选值、按条件似然评分。变体包括事实数量（K=1/4/8/16/32）、事实到查询距离（128/512/1024 填充 token）、模板、值词表、更新条件，以及 WikiText/PG19 填充的实体更新与 RULER single-NIAH（约 4K）。
- **Benchmark 与对照**：无外部公开榜单，核心基准是自建的受控四选一联想召回；对照包括 clean 运行、等范数随机更新、随机/对照头干预、正交化写入等。
- **主要实验组**：
  - 开发集全头筛选（16 个源组 × 4 个绑定 × 3 次呈现 × 512 填充 token）。
  - 写入必要性与内容特异性（write block / donor write）。
  - 非加性检验（Hub 头与次级头 B 的联合干预 vs 单独效应之和）。
  - 查询时中介检验（state swap / output patch / output restore）。
  - 四事实选择性召回与跨事实平行/正交分解。
  - 混合架构记忆载体归属（循环/局部 vs 全注意力 KV）。
  - 负载、距离、写入键重叠三类退化来源。
  - 保持/可编辑性/附带损伤三种失败模式随 K 变化。
  - 保留源上的全组件写入—读取景观、逐层 logit lens 定位、冻结头跨任务变体复用、颜色基转移。
  - 附加 checkpoint 的读取路径集中度、状态特征纠错诊断、散文检索能力预检。

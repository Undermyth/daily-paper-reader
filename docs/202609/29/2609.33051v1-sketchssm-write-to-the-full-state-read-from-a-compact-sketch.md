## 摘要
混合注意力模型用线性注意力替换大多数 softmax 注意力层，从而减少 KV 缓存增长，并支持更大的解码批次；在这种情况下，循环状态访问成为主要瓶颈。ReplaySSM 通过缓存键和值来摊销状态更新，但即便状态在两次状态更新之间保持不变，每个新查询仍需要读取完整状态。我们观察到，低秩的状态加权查询近似能够准确保持状态读取的输出。尽管未来查询未知，但用于近似它们的基向量可以离线固定。基于这一观察，我们提出 SketchSSM，它在保留完整状态更新的同时近似读取。在每次状态更新时，SketchSSM 读取一次完整状态，以预计算这些基向量的输出，并将其存储在紧凑草图中。后续每个解码步骤将草图向量与查询相关系数结合，以在不读取完整状态的情况下重建输出。在四个基于 Mamba-2、GDN 和 KDA 的模型上，SketchSSM 将状态访问流量减少约 10 倍，同时在四个解码基准上基本保持平均准确率，并在四个 RULER 检索任务上保持召回率。在一块 NVIDIA B300 上，相对于标准 vLLM 基线，Mamba-2、GDN 和 KDA 的线性注意力内核加速分别达到 7.78 倍、5.22 倍和 5.20 倍，在 Nemotron 3 Super 上解码吞吐量最高提升 2.64 倍。

## Abstract
Hybrid-attention models replace most softmax attention layers with linear attention, reducing KV-cache growth and enabling larger decode batches where recurrent state access becomes a major bottleneck. ReplaySSM amortizes state updates by buffering keys and values, but each new query still requires a full-state read even though the state remains unchanged between state updates. We observe that low-rank state-weighted query approximation accurately preserves state-read outputs. Although future queries are unknown, the basis vectors used to approximate them can be fixed offline. Based on this observation, we introduce SketchSSM, which preserves full-state updates while approximating reads. At each state update, SketchSSM reads the full state once to precompute outputs for these basis vectors, storing them in a compact sketch. Each subsequent decode step combines the sketch vectors with query-dependent coefficients to reconstruct the output without a full-state read. Across four Mamba-2-, GDN-, and KDA-based models, SketchSSM reduces state-access traffic by approximately 10x while largely preserving average accuracy across four decode benchmarks and recall on four RULER retrieval tasks. On one NVIDIA B300, linear-attention kernel speedups over the standard vLLM baseline reach 7.78x, 5.22x, and 5.20x for Mamba-2, GDN, and KDA, respectively, with up to 2.64x higher decode throughput on Nemotron 3 Super.

# SketchSSM 论文结构化总结

## 1. 核心问题与研究背景

- **背景**：混合注意力模型（hybrid attention）用线性注意力替换大多数 softmax 注意力层，把随上下文增长的 KV 缓存换成固定大小的循环状态，从而降低显存、支持更大的解码批次。
- **瓶颈转移**：在大批次解码场景下，每个解码步都要读取并更新整个循环状态，线性注意力成为主导瓶颈——在最大可容纳批次 Bmax 下占解码延迟的 **41–70%**（Nemotron 3 Super / Qwen3.8 Flash-Next / GLM 5.3 Flash）。
- **已有方案的局限**：
  - ReplaySSM / KVBuffer 通过缓冲 K/V 把状态**写**流量摊销到每 W 步一次，但**读**流量不变：每个新 query 仍需把 query 乘以完整状态（K×V 元素），即使状态在两次更新之间完全不变。
  - 状态量化（DSQ）与剪枝（GHOST / DRRQR）通过缩小状态降低流量，但引入的状态压缩误差会在后续状态更新中**传播累积**，精度显著退化（4× 流量缩减时平均精度下降 1.9–29.6 分（量化）或 73.1–87.9 分（剪枝））。
- **核心机会**：状态固定而 query 每步变化，因此不必反复读取全状态；只要用**固定的 query 基向量**配合状态/查询相关的系数，就能准确重构状态读取输出。

## 2. 方法论

### 2.1 核心思想

- **写用全状态，读用紧凑草图（sketch）**：状态更新保持精确、无损，只对「读」路径做低秩近似，从而避免压缩误差进入状态递推。
- **误差等价性**：状态读取输出误差
  `E = ||S0ᵀq̃ − S0ᵀΩc||² = ||(S0S0ᵀ)^{1/2}(q̃ − Ωc)||²`
  即输出重构误差等价于**状态加权的 query 近似误差**——在状态放大较弱的方向上允许较大的 query 误差。

### 2.2 三个关键计算

- **离线：草图矩阵 Ω**
  - 用校准集上的平均状态几何 `E0 = E_D[S0S0ᵀ]` 固定 Ω（避免为每个 S0 单独优化）。
  - 损失 `L_G(Ω) = E_D[min_c ||E0^{1/2}(q̃ − Ωc)||²]`，解为**未中心化 PCA**：`Ω* = E0^{−1/2} P_G`，其中 `P_G` 是 `C_z = E[z_t z_tᵀ]`（`z_t = E0^{1/2} q̃_t`）的前 G 个特征向量；最小残差为剩余 K−G 个特征值之和。
- **每窗口（flush 步）：草图 U**
  - 应用缓冲更新得到新的 S0，一次性计算 `U = S0ᵀΩ ∈ R^{V×G}`，每列是某个基向量对应的输出。
  - 该计算与 flush 更新内核**融合**，在状态写回前完成，因此只产生一次全状态读取、无额外全状态流量。
- **每步：系数向量 c_t**
  - `c*_t = argmin_c ||S0ᵀq̃_t − Uc||² = C q̃_t`，其中 `C = (UᵀU)†UᵀS0ᵀ ∈ R^{G×K}`。
  - C 在窗口内固定，每个 flush 计算一次；每步只做 `o_state ≈ U c_t` 的矩阵–向量乘。
  - 也可用离线系数图 `C_offline`（基于 E0），但消融显示精度显著变差（平均 −24.14 分），故不采用。
- **加速技巧：低秩+对角近似**
  - 用 P=4 个 pivot 与 Woodbury 恒等式把 G×G 稠密求逆替换为 p×p 求逆，配合对角能量补偿，把系数图构造复杂度降到 `O(KVp + Vp² + Gp² + p³)`。
  - 实测 flush 步加速 **4.02–4.83×**（三个模型），草图+系数图构造仅给 flush 步增加 11.5–17.0% 延迟。
- **秩分配（head 级）**
  - 对每个 head 与候选秩 G，用「输出重构误差 δo」与「损失梯度 g」的配对分数 `J_{l,h}(G) = E_t[(gᵀδo)²]` 评分（同时体现误差大小与其对 loss 的影响方向）。
  - 在平均秩预算 Ḡ 下建模为**多重选择背包问题**，用拉格朗日价格 μ 二分求解，可给出相对最优性 gap 证书；离线完成，推理时只用固定秩表。
- **算法流程（单 head）**：初始化全状态 → 窗口内 W−1 个非 flush 步（读 U、C，`o_t = U C q̃_t + o_buffer`）→ 1 个 flush 步（读全状态、精确更新、构造并写回 U/C、清空缓冲）。

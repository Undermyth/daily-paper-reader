## 摘要
门控线性注意力（GLA）Transformer 通过数据依赖的门控推进了线性循环模型，但面临一个核心局限：所有头中的固定容量记忆矩阵都在单一时间分辨率下运行，其中每个词元被单独处理，迫使它们同时编码局部句法模式和长程语义结构，从而造成仅靠门控不足以解决的表示瓶颈。我们提出多尺度门控线性注意力（MS-GLA），通过将注意力头分布到多个时间分辨率上来解决这一问题。较粗的分辨率池化更长的词元跨度，自然地专门化于长程依赖，而更细的头组则保持对局部句法结构的敏感性。一个可学习、输入依赖的融合层在每个时间步动态重组头组输出，在不增加每个头状态大小的情况下扩展有效记忆容量。这种多分辨率分解借鉴了多尺度状态空间模型（MS-SSM）的原理，并将其适配到门控线性注意力设定中。我们在语言建模、召回密集型任务和长上下文泛化上评估 MS-GLA。在所有设定中，MS-GLA 在参数量匹配时始终比 GLA 取得更高的准确率和更低的困惑度，在召回密集型任务上最高提升 18.9%，在语言建模基准上平均困惑度降低 9.5%，验证了多时间分辨率分解是门控线性注意力的一种有原则且有效的扩展。

## Abstract
Gated Linear Attention (GLA) Transformers advance linear recurrent models through data-dependent gating, but face a core limitation: the fixed-capacity memory matrices across all heads operate at a single temporal resolution, where each token is processed individually, forcing them to simultaneously encode local syntactic patterns and long-range semantic structure, creating a representational bottleneck that gating alone is insufficient to resolve. We introduce Multi-Scale Gated Linear Attention (MS-GLA), which addresses this by distributing attention heads across multiple temporal resolutions. Coarser resolutions pool longer token spans naturally specializing toward long-range dependencies, while finer head groups retain sensitivity to local syntactic structure. A learnable, input-dependent fusion layer dynamically recombines head group outputs at each timestep, expanding effective memory capacity without increasing per-head state size. This multi-resolution decomposition draws on principles from Multi-Scale State-Space Models (MS-SSM), adapting them to the gated linear attention setting. We evaluate MS-GLA on language modeling, recall-intensive tasks, and long-context generalization. Across all settings, MS-GLA consistently achieves higher accuracy and lower perplexity than GLA at matched parameter counts, with up to 18.9% improvement on recall-intensive tasks and 9.5% lower average perplexity on language modeling benchmarks, validating multi-temporal resolution decomposition as a principled and effective extension of Gated Linear Attention.

# MS-GLA 论文总结

## 1. 核心问题与研究动机

- **背景**：Transformer 的 softmax 注意力随序列长度呈二次复杂度；线性注意力、线性 RNN、状态空间模型（SSM，如 Mamba）、RetNet 等以线性递归实现高效序列建模，推理时具 O(1) 记忆占用并支持并行训练。
- **GLA 的进展与局限**：门控线性注意力（GLA）引入数据依赖的 2D 遗忘门，使模型能选择记住或遗忘上下文，显著缩小与标准 Transformer 的差距。但 GLA 的所有注意力头仍在**单一时序分辨率**下工作：每个 token 被单独处理，固定容量记忆矩阵必须同时编码局部句法模式与长程语义结构。
- **核心问题**：语言天然具有多尺度结构——快速变化的高频句法细节与缓慢演化的低频语义结构并存。门控只能决定“记什么/忘什么”，无法解决“有限记忆预算如何分配到不同时间尺度”的表示瓶颈。
- **整体含义**：论文提出 MS-GLA，将多尺度状态空间模型（MS-SSM）的多分辨率思想迁移到门控线性注意力中，在不增加参数总量和单头状态大小的前提下，通过头组跨时间分辨率分配来扩大有效记忆容量。

## 2. 方法论

### 2.1 核心思想

- 将基线 GLA 的注意力头预算重新分配到多个时间尺度上，而非增加新头或扩大单头状态。
- 粗分辨率分支对长 token 跨度做池化，感受野自然扩大，偏向长程依赖；细分辨率分支保留原始 token 粒度，偏向局部句法结构。
- 各分支输出经因果上采样后，由可学习、输入依赖的融合层在每个时间步动态重组。

### 2.2 关键流程与算法说明

1. **多尺度分解**：给定输入 \(X \in \mathbb{R}^{L \times d}\)，尺度集合 \(S\)（如 \(\{1,2,4\}\)）。对每个尺度 \(s\)，以非重叠平均池化将每 \(s\) 个连续 token 合并为一个 token，得到 \(X^{(s)}\)，长度约为 \(\lceil L/s \rceil\)。若提供掩码，则按有效 token 数做掩码归一化，避免 padding 影响。
2. **尺度专属 GLA 头**：总头数 \(H\) 分配到各尺度，\(\sum_{s \in S} h_s = H\)；KV 投影维度按 \(h_s/H\) 比例分配。每个分支是独立 GLA 模块，参数不共享，门控和投影可自由专门化到对应尺度。
3. **GLA 递归基础**：分支内部沿用 GLA 更新，\(S_t = \mathrm{Diag}(\alpha_t) S_{t-1} + k_t^\top v_t\)，其中 \(\alpha_t\) 为数据依赖门控向量。
4. **因果上采样**：对尺度 \(s\) 的分支输出，沿序列维度重复 \(s\) 次，再右移 \(s-1\) 位并在开头补零，实现因果零阶保持，确保池化块内所有 token 被观测后才释放输出。
5. **可学习尺度融合**：对每个时间步 \(t\)，由未池化隐状态 \(x_t\) 计算路由权重 \(w_t = \mathrm{Softmax}(W_{\text{fuse}} x_t + b_{\text{fuse}})\)，最终输出为 \(O_t = \sum_{s \in S} w_{t,s} \hat{Y}^{(s)}_t\)。
6. **训练兼容性**：池化为静态、非重叠操作，各分支仍处理连续序列，因此可保留 GLA 的 chunkwise 并行训练形式；粗分支序列更短，部分抵消额外分支开销。

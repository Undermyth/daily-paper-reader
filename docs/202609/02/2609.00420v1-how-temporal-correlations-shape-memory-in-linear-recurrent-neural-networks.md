## 摘要
线性递归神经网络（LRNN）是研究网络在训练过程中积累多少记忆的一个简单模型。对于不相关的输入，早期工作发现训练本身会使网络在保留过去与仅对当前作出反应之间取得平衡。真实序列是相关的，我们精确求解了相关输入下的学习动力学。在解中，保留过去带有代价。相关性的全部影响都落在这个代价上。当输入不相关时，该代价退化为早期形式，而一旦输入正相关，代价则增大。由此得到三个发现。（1）相关性重塑了学习过程，而不仅仅是其终点。记忆会建立、过冲并部分移除，最终稳定的网络保留的过去较少。（2）记忆在一个阈值处关闭，该阈值由单个数字决定，即每个输入与紧邻前一个输入的相似程度。序列长度或更长程相关性都不会改变此阈值。只有当任务需要的上一个输入超过当前输入通过与其过去的相关性已提供的信息时，记忆才值得保留。（3）最佳网络也会改变。零误差要求一个前馈通路，即一条将当前输入直接传递到网络输出且不记忆任何内容的路径，当给定一个备用的隐藏维度时，训练会自发构建该通路。我们的工作将输入的一个属性转化为网络是否学习记忆的预测，并解释了为什么相关数据会将递归网络转变为变化检测器。

## Abstract
The linear recurrent neural network (LRNN) is a simple model for studying how much memory a network builds up as it trains. For uncorrelated inputs, earlier work found that training itself settles the network between keeping the past and reacting only to the present. Real sequences are correlated, and we solve the learning dynamics exactly for correlated inputs. In the solution, keeping the past carries a cost. The whole effect of correlation lands on that cost. This cost reduces to the earlier one when inputs are uncorrelated and grows once they are positively correlated. Three findings follow. (1) Correlation reshapes the course of learning, not only its end. Memory builds, overshoots, and is partly removed, and the settled network keeps less of the past. (2) Memory switches off at a threshold set by one number, how much each input resembles the one just before it. Neither sequence length nor longer-range correlation moves this threshold. Memory is worth keeping only when the task needs the previous input more than the current input already supplies it through correlation with the past. (3) The best network changes too. Zero error demands a feedthrough, a path that passes the current input straight to the network's output and remembers nothing, and training builds it unprompted when given one spare hidden dimension. Our work turns one property of the input into a prediction of whether a network learns memory and explains why correlated data turns recurrent networks into change detectors.

## 1. 核心问题与研究背景

- **问题动机**：训练线性递归神经网络（LRNN）时，网络如何决定自己该“记住多少过去”？该记忆决策受输入数据时间结构的何种影响？
- **背景不足**：已有关于 RNN/SSM 学习动力学的理论工作在分析训练过程时几乎都假设输入在时间上互不相关（白噪声输入），难以解释真实世界中广泛存在的时间相关性（语言、物理、神经信号等）如何与记忆学习相互作用。
- **核心研究问题**：时间相关的输入（当前输入是过去输入的“部分副本”）会如何重塑网络的记忆学习轨迹、最终记忆强度，以及网络达成任务所需的结构？
- **整体含义**：本文展示了输入的可预测性本身会“替代”网络内部存储的记忆：输入越能由历史预测，网络就越没有必要记住过去；相关数据甚至会把递归网络训练成“变化检测器”而非“记忆存储器”。这一认识对现代状态空间模型（S4、Mamba、LRU 等）的架构设计和初始化具有直接参考意义。

## 2. 方法论与核心技术

- **建模框架**：
  - 使用线性递归网络（LRNN），结构为
    \(h_{i+1}=W_h h_i+W_x x_i,\ \hat{y}=W_y h_{T+1}\)；
  - 学习目标为最小化轨迹级平方误差（sequence-to-one 回归）；
  - 训练方式为梯度流（gradient flow）。
- **关键假设（前向可解性标准设定）**：
  - **假设1（奇异向量对齐）**：各时间步的输入-输出相关矩阵具有相同的左右奇异向量结构，仅奇异值随步数变化；
  - **假设2（特征白化）**：同一时刻内特征互不相关且方差为1；
  - **假设3（时间相关输入）**：不同时间步输入之间存在平移不变的协方差 \(C_{ij}=C_{|i-j|}\)；这是本文区别于此前工作的最重要拓展；
  - **假设4（初始化对齐）**：权重的初始化方向与任务奇异方向对齐。在这些条件下，高维学习问题可解耦为逐独立模式（per-mode）的标量学习。
- **核心推导与公式**：
  - 将每个任务方向的权重压缩成三个标量：输入增益 a、记忆拨盘 b、输出增益 c；
  - 推导出单方向上的梯度流方程（等式5-7），核心残余误差项为 \(s_i - ca \sum_j C_{ij}b^{T-j}\)（“必需相关”与“产生相关”之差）；
  - **引理1（per-mode 能量）**：每一方向的损失可闭合写为：
    \[
    E = \frac{1}{2}\sum_i (s_i^2 - 2s_i cb^{T-i}a) + \frac{1}{2} c^2a^2 \sum_{i,j} b^{T-i}C_{ij}b^{T-j}
    \]
    相关性完全改变了“记忆代价”项（正则化项），从白色成本(\(b^{2T-2i}\))变成完整二次型 \(v^\top Cv\)；
  - 由此严格证明了正相关输入使得正记忆更贵、改变检测（负 b）更便宜。
- **记忆边界判据**：
  - **引理2**：梯度流在小权重初始化下，向“保留正记忆”方向学习的充要条件为：
    \[
    \frac{s_{T-1}}{s_T} > \frac{C_{T-1,T}}{C_{T,T}}
    \]
    即“任务对上一时间步输入的依赖程度”必须超过“当前输入自身从上一时间步复制信息的程度”；
  - 序列长度 T 和所有更远期协方差均不影响该阈值；灰色对角线（边界）处网络回到零记忆。
- **最优性分析与直通项需求**：
  - 检验“单一隐藏模式”的几何尾巴 \(g b^{T-i}\) 是否足以实现零误差；
  - 零误差条件等价于求解 \(C w^* = s\)，给出 **Wiener 滤波**解 \(w^*=C^{-1}s\)；
  - AR(1) 输入 + 几何任务的解为“尾巴+一个最新步尖峰”：尾巴被缩放为只存“输入相关性补不足”，尖峰弥补当前输入的欠权重；
  - 文中证明了没有单一射线能表示“尾巴+尖峰”，因此需要额外的“直通（feedthrough/direct D term）”路径，即一个隐藏维度记忆拨盘为 0，直接把当前输入送到输出；
  - 当网络具有废弃维度时，训练会自发涌现出该直通结构（谱分裂成任务特征值和0）。
- 补充验证：使用 Lean 4/mathlib 形式化为部分核心引理做了机器验证。

## 6. 主要结论与发现

1. **相关性重建记忆学习动力学**：
   - 正相关输入使记忆从“仅存储”变成“存储在相关副本之外的新信息”，记忆训练轨迹出现“建立→过冲→部分移除”的过程；
   - 当输入相关性很高时，训练出来的网络使用负的记忆拨盘，成为变化检测器。
2. **明确的相变边界**：
   - 网络能否学习记忆只由一个比较决定：任务对前一时刻的需求 vs. 最近两时刻之间的经验相关比 \(s_{T-1}/s_T\ vs. C_{T-1,T}/C_{T,T}\)；
   - 序列长度 T 及其他长程相关对边界没有影响；
   - 在真实数据上，该边界预测也精确成立（19/19序列误差量在合理偏差范围内）。
3. **零误差要求“直通”结构**：
   - 单隐藏模式的指数尾巴永远无法精确实现最优 Wiener 解，必须有直通路径；
   - 每当网络拥有隐藏宽度超出任务方向数时，训练自动分裂出一个特征值为 0 的直通通道，吻合现代 S4/Mamba/LRU 架构中 D 项的设计合理性。

## 7. 方法亮点与优点

- **理论成果的普适性与显式提法**：将复杂的高维非凸学习问题归约为“引理1能量+引理2阈值+引理/滤波器分解”三个可操作的判据，结果可以用两个统计量在训练前直接读取；
- **精确解析解**：基于线性模型的精确求解比启发式/近似解释更有说服力；
- **定理得到多层面验证**：梯度流仿真、能量最小化比较、Lean 4 机器证明、随机初始化训练全矩阵验证相互一致；
- **对现代状态空间模型的架构启示**：解释了为什么 D 项/短期卷积/深度卷积项在 SSM 中是必需的，并表明这类直通项可以由梯度下降自动学习；
- **真实数据的可解释性**：用19个不同领域的序列验证理论的预测边界，同时坦白反例以划定理论适用边界，避免过度声称。

## 8. 不足与局限

- **模型限定于线性系统**：方法的精确解依赖线性递归结构与单线性读出；非线性 RNN 的记忆动态是否遵循相同规则不得而知；
- **输入时间统计的简单设定**：虽然允许了相关输入，但排除交叉特征相关、非平稳协方差、输入维度间不同相关等更复杂的分布；实际任务中输入往往具有各向异性或周期性（文中将强周期/强持续序列放在可靠性有限的“第一序”类别中）；
- **实验属于“受教师任务的控制性验证”，并非端到端性能试验**：不与其他 SOTA 递归或状态空间模型在真实序列预测任务上比较整体收益/精度，无法体现“更准确”而只体现“更可预测”；
- **真实数据上的教师任务构造模式**：要求精确的指数要求剖面（\(s_i=\lambda^{T-i}\)），是从对真实协方差的学习结构做验证；任务剖面本身不直接从数据学习；
- **无大规模算力或工业级基准测试**：计算的简单性既是优点也是局限：说明理论正确，却不能说明其在 LLM 级问题上的实际记忆/性能收益；
- **依赖对齐初始化假设**：实际实现中典型初始化并非如此对齐，尽管随机全矩阵训练对少数维度的补充实验结果与预测一致，但超出很少宽度情况的行为仍需检验；不同训练目标（如交叉熵或对比损失）下结论是否不变尚未讨论。

## 摘要
视觉 Transformer 将大部分参数分配给多层感知机（MLP）以进行通道混合，而 token 交互通常依赖二次复杂度的多头自注意力（MHSA）。线性注意力将序列复杂度降至 O(N)，但仍与 softmax Transformer 一样耦合固定激活的 MLP。Kolmogorov-Arnold 网络（KAN）则改为在边上放置可学习的一元映射，但此前的视觉 KAN 仍保留 MHSA 或完全省略注意力。我们提出 LKAT（Linear Kolmogorov-Arnold Transformer），一种各向同性 ViT 编码器，将分块门控线性注意力（GLA）与两层 KAN 前馈网络相结合，并为径向基网格映射提供 I/O 感知的融合 RBF-KAN 核。在共享的 DeiT 风格训练配方下，我们将 LKAT 与 ViT、ViT-5 和 MLP-Mixer 进行比较。LKAT-B 在 ImageNet-100 上超过 ViT-B/16、ViT-5-B 和 Mixer-B/16。Tiny/Small/Base LKAT 变体在 CIFAR-10/100 上表现出一致的可扩展性，且 ImageNet-100 预训练可迁移到 CIFAR 微调。结果表明，门控线性注意力和基于 KAN 的径向基函数可作为中等规模视觉表示学习的互补归纳偏置。

## Abstract
Vision Transformers allocate most parameters to multi-layer perceptrons (MLPs) for channel mixing, while token interactions usually rely on quadratic multi-head self-attention (MHSA). Linear attention reduces sequence complexity to O(N), but remains coupled with the same fixed-activation MLP as softmax Transformers. Kolmogorov-Arnold Networks (KANs) instead place learnable univariate maps on edges, yet prior vision KANs keep MHSA or omit attention entirely. We introduce LKAT (Linear Kolmogorov-Arnold Transformer), an isotropic ViT encoder that couples chunkwise Gated Linear Attention (GLA) with a two-layer KAN feed-forward, and we provide an I/O-aware fused RBF-KAN kernel for the radial-basis grid maps. Under a shared DeiT-style recipe we compare LKAT with ViT, ViT-5, and MLP-Mixer. LKAT-B exceeds ViT-B/16, ViT-5-B, and Mixer-B/16 on ImageNet-100. Tiny/Small/Base LKAT variants scale consistently on CIFAR-10/100, and ImageNet-100 pretraining transfers to CIFAR fine-tuning. The results support gated linear attention and KAN-based radial-basis functions as complementary inductive biases for mid-scale visual representation learning.

# 论文总结：Rethinking Vision Architectures with Gated Linear Attention and KAN

## 1. 核心问题与研究动机

- **背景**：视觉表征学习长期由卷积残差网络（ResNet、ConvNeXt）主导，Vision Transformer（ViT）则将图像视为 patch 序列，通过各向同性编码器处理，其 token 交互依赖**二次复杂度的多头自注意力（MHSA）**，通道混合则依赖固定激活的两层 MLP。
- **核心矛盾**：
  - ViT 将大多数参数分配给 MLP，但 token 交互仍是 O(N²) 瓶颈；
  - 线性注意力虽将序列复杂度降至 O(N)，但仍搭配与 softmax Transformer 相同的固定激活 MLP，未改变通道混合的归纳偏置；
  - Kolmogorov–Arnold 网络（KAN）在边上放置可学习一元映射，理论上更具表达力，但已有视觉 KAN 工作要么**保留 MHSA**（如 Hyb-KAN ViT、KAT），要么**完全不用注意力**（如 ViK 用 KAN 替代注意力），或仅用于 CNN 卷积核。
- **研究空白**：**同时用门控线性注意力替换 MHSA、用 KAN 径向基函数替换 MLP** 这一"双重替换"组合尚未被系统研究。
- **整体含义**：论文主张 GLA 与 KAN-RBF 是两种**互补的归纳偏置**，可在中等规模视觉表征学习中替代经典 ViT 块，且容量扩展性比 softmax MHSA 更稳定。

## 2. 方法论

### 2.1 核心思想
提出 **LKAT（Linear Kolmogorov–Arnold Transformer）**：保持各向同性 ViT 拓扑，仅重新设计 Transformer 块的两个算子——注意力路径用**分块门控线性注意力（GLA）**，通道混合路径用**两层 KAN 径向基函数网络**，并为 RBF 网格映射设计 **I/O 感知的融合 Triton 核**。

### 2.2 关键技术细节

- **注意力替换（GLA）**：
  - 线性注意力用特征映射 ϕ 分解相似度，结合律给出递归形式，序列代价从 O(N²) 降至 O(N)；
  - GLA 在递归状态上加入**数据依赖的遗忘门** G_t（低秩/逐元素参数化），提升表达力；
  - 训练采用**分块并行算法**：序列切分为 chunk，块内并行、块间串行传播状态，兼顾线性复杂度与硬件效率。
- **通道混合替换（RBF–KAN）**：
  - 基于 Kolmogorov–Arnold 表示定理，将可学习一元边函数 ϕ_{q,p} 放在边上，节点仅做求和；
  - 采用 **FastKAN** 思路，用**高斯径向基（RBF）**近似边函数，避免 B 样条递归求值开销；
  - 单标量激活的融合网格线性求值：对 G 个固定中心 {c_g} 与带宽 d，输出为 y = Σ_g w_g · exp(−((x−c_g)/d)²)。
- **I/O 感知融合核**：
  - 将 RBF 展开实现为**融合 Triton 核**，避免在 HBM 中物化形状为 [..., D, G] 的中间张量；
  - 前向核按 BLOCK 切分特征轴，片上累加高斯基，仅读写 x 与 y 各一次；
  - 反向核（Algorithm 2）实时重算 {φ_g}，在寄存器中累加 dx，用 atomic add 聚合 dw；
  - 自调优选择 BLOCK ∈ {256, ..., 4096}。
- **架构细节**：
  - 非重叠 patch 线性投影 + 可学习 register token + 置于序列末尾的 class token（兼容因果递归）；
  - 所有 token 加绝对位置编码，patch 的 Q/K 在 per-head RMSNorm 后加 **2D RoPE**；
  - 每块 pre-norm 残差结构：LayerNorm → GLA（Q/K/V/门独立投影，Q/K/V 上短卷积，value 流上 LayerNorm）→ 残差；LayerNorm → KAN-RBF → 残差；
  - 分类从最终 LayerNorm 后的 class token 读出。

## 6. 主要结论与发现

- **容量扩展性**：LKAT-T/S/B/L 在 CIFAR-10/100 与 ImageNet-100 上**单调提升**；而 ViT 在同一配方下**不单调**（ViT-S/16 在 CIFAR-10 和 ImageNet-100 上超过 ViT-B/16），说明经典 MHSA–MLP 堆栈在中等规模存在优化/容量失配。
- **主结果**：ImageNet-100 上 LKAT-B 超过 rbfKAT-B、ViT-B/16、ViT-5-B 和 Mixer-B/16；LKAT-L 在该列领先。
- **CIFAR 结果**：CIFAR-10 上 rbfKAT-B 领先 Acc@1；CIFAR-100 上 LKAT-L 领先，Base 级别中 rbfKAT-B 优于 LKAT-B、Mixer-B、ViT-B。
- **消融发现**：加入门控残差 γ⊙σ(γ) 可将 ImageNet-100 从 80.14% 提升至 82.02%（但参数大幅增加）；RBF 网格从 G=4 增至 G=6/8 也持续提升（81.08%/81.44%），说明默认网格**欠分辨**。
- **迁移性**：ImageNet-100 预训练显著优于从零 CIFAR 训练（RA 224² 达 93.01/78.20，RB 384² 达 95.45/78.63）。
- **边函数行为**：可视化显示学习到的一元映射在径向网格上保持局部化，且随深度**持续变化**，未坍缩为固定非线性。

## 摘要
视觉-语言-动作模型为通用机器人控制提供了坚实基础，但绝大多数策略并不保留和利用当前观测之外的回合级信息。这一局限在依赖历史信息的操作任务中尤为重要，因为这些任务依赖于仅存在于过去观测中的信息。将过去观测保留在上下文中有助于恢复此类信息，但代价是上下文不断增长、臃肿以及推理延迟显著增加。因此，我们提出 MemBodied，一种固定大小的情景记忆，包含两个互补组件：记录跨策略调用交互的联想状态，以及保留初始场景紧凑表示作为参考的情景锚点。在每次策略调用时，模型以当前输入和记忆组件为条件生成动作，而不是直接使用过去观测。在五个需要记忆的 RMBench 评估任务上，MemBodied 的平均成功率达到无状态策略的 7.81 倍、普通循环记忆的 2.98 倍，同时其新增参数少 10 倍，性能达到最强记忆增强基线的 1.3 倍。在完全可观测的 LIBERO-Long 套件上，它达到 90.6%，比无状态的 π_0 策略提升 5.4%。这些发现支持 MemBodied 作为扩展策略上下文以处理历史依赖操作任务的一种实用替代方案。

## Abstract
Vision-Language-Action models provide a strong foundation for general-purpose robot control, yet a vast majority of policies do not preserve and leverage episode-level information beyond the current observation. This limitation is consequential in history-dependent manipulation tasks that depend on information available only in past observations. Retaining past observations in context can aid in recovering this information, but at the significant cost of ever-growing, bloated context and inference latency. We thus introduce MemBodied, a fixed-size episodic memory with two complementary components: an associative state that records interactions across policy calls and an episode anchor that preserves a compact representation of the initial scene as a reference. At each policy call, the model conditions action generation on the current input and the memory components, rather than directly using past observations. Across five evaluated RMBench tasks requiring memory, MemBodied achieves $7.81\times$ the mean success rate of a stateless policy and $2.98\times$ of vanilla recurrent memory, while outperforming the strongest memory-augmented baseline by $1.3\times$ with $10\times$ fewer added parameters. On the fully observable LIBERO-Long suite, it reached 90.6%, a 5.4% improvement over the stateless $π_0$ policy. These findings support MemBodied as a practical alternative to expanding the policy context for history-dependent manipulation.

  - 压缩历史 token（HAMLET、NativeMEM）：上下文仍随保留观测数增长；
  - 循环隐状态（μVLA、ReMem-VLA、AVA-VLA）：尺寸固定，但只能隐式保留信息；
  - 记忆库/检索/语言草稿（SAM2Act、MemoryVLA、MAP-VLA、Notes-to-Self）：引入额外目标或处理管线。

- **论文含义**：MemBodied 提出以固定容量情景记忆替代"扩张上下文"，作为历史依赖操作任务的实用方案。

## 2. 方法论

### 2.1 核心思想

将操作建模为历史依赖的序列决策问题，回合记忆记为 $E_t=(M_t, A)$：
- $M_t$：**循环联想状态**，跨策略调用持续存在，每回合开始时重置为可学习的初始状态；
- $A$：**回合锚点**，由回合首帧观测构建，回合内保持不变。

策略在步骤 $t$ 以 $p_\theta(\cdot \mid I_t, s_t, \ell, E_{t-1})$ 生成动作块，**不直接使用过去观测**。

### 2.2 联想记忆机制

- **状态结构**：为动作网络每一层维护一个联想矩阵 $S^{(l)}_t \in \mathbb{R}^{B\times r\times r}$，实验中 $r=128$；状态大小在回合内固定，写入是**更新既有矩阵而非追加历史**。
- **写值构造（Write-Value）**：
  - 动作执行后，用投影后的机器人状态 $s_{t+1}$ 作为 query，对下一观测的视觉 patch token $X^{(c)}_{t+1}$ 做注意力，得到各相机编码 $e^{(c)}_{t+1}$；
  - 对相机取平均得到 $e^{\text{vision}}_{t+1}$（**视觉 patch token 处梯度被截断**）；
  - 与前一因果动作块之和拼接：$y_t = [e^{\text{vision}}_{t+1}; \sum_{h=1}^{H} a_{t,h}]$，再经层特定投影得到写值 $v^{(l)}_t$。
  - 因此写值表示的是**"动作—视觉后果"的动态交互转移**，而非孤立观测。
- **门控 delta 规则写入（Gated Delta Rule）**：
  - 写键 $k^{(l)}_t = \mathrm{L2Norm}(\tanh(W^{(l)}_k h^{(l)}_{t,\text{out}}))$；
  - 保留门 $\alpha^{(l)}_t$ 与写入门 $\beta^{(l)}_t$ 由层输出与写值经 sigmoid 得到；
  - 更新式：$S^{(l)}_t = \mathrm{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1} + \mathrm{Diag}(\beta^{(l)}_t)\big(v^{(l)}_t - \mathrm{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1}k^{(l)}_t\big)(k^{(l)}_t)^\top$。
  - 第一项保留旧状态，第二项以 delta 修正**已关联值**，可修正既有联想而不会无差别堆积。

### 2.3 检索与记忆注入方式（三种变体）

- 读查询 $q^{(l)}_t$ 由进入该层的状态 token 表示 $h^{(l)}_{t,\text{in}}$ 构造，读出 $r^{(l)}_t = S^{(l)}_{t-1} q^{(l)}_t$。
- **MemBodied-AS（注意力引导）**：读出经投影对动作网络的注意力 query 与输出做加性修正。
- **MemBodied-H（分层记忆）**：在 gated-delta 之外增加一个 LSTM 式慢速循环单元，由学习到的遗忘门控制（同时改变状态动力学与读出）。
- **MemBodied（记忆 token 读出，最终方案）**：动作网络后缀排布为 `[state token, memory token, H 个带噪动作 token]`。memory token 是每步重建的可学习向量，**不跨调用持久化**（持久化的是联想矩阵）。层 $l$ 的读出经线性变换并缩放 $\alpha_{\text{mem}}/r$，再乘以由当前状态表示导出的标量门 $g^{(l)}_t$ 后加到 memory token 上，参与自注意力。相比注意力引导，这种方式把检索内容作为**上下文内容**而非仅修改既有注意力计算。

### 2.4 固定回合锚点

- 动机：反复的 delta 更新可能**覆盖早期场景的细粒度细节**。
- 构造：取策略前缀中冻结的视觉 token，将每相机 $16\times16$ patch 网格平均池化为 $4\times4$ 并跨相机拼接，得到 $A \in \mathbb{R}^{N_A \times D}$。
- 使用：当前机器人状态 $s_t$ 对当前视觉 token 做池化得到 $z_t$，$z_t$ 通过 rank-$r_A$（实验 $r_A=64$）的交叉注意力查询锚点，结果 $c_t$ 投影到动作网络宽度并在动作时域上重复，经 $f_{\text{cond}}$ 融入动作表示。
- **不追加首帧或其完整 token 序列到前缀**，前缀长度、token 位置与注意力掩码结构保持不变。

### 2.5 读写因果协调与序列训练

- **延迟写入调度**：步骤 $t$ 先用 $M_{t-1}$ 读出并生成 $a_t$；执行后环境给出 $I_{t+1}$，再把 $t$ 步的隐藏状态/动作块与 $I_{t+1}$ 关联写入 $M_t$。这样存储的值包含动作的观测后果，却不把未来观测暴露给导致它的动作。推理时缓存前一层状态与最终去噪步采样的动作块，下一观测到达时执行写入。
- **序列训练**：每个训练样本是 $N$ 个观测—动作对序列，相邻对间隔一个动作时域 $H$；图像编码与策略输入构造在 batch 与序列维度并行，记忆状态沿序列串行传播，梯度穿过完整序列，使后续动作损失能优化早先的记忆操作。**记忆参数通过策略原生动作目标联合学习，无单独的记忆预测损失**。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark

| 基准 | 内容 | 评估规模 |
|---|---|---|
| **RMBench**（主基准） | 双臂仿真记忆基准，按记忆复杂度分类。选用 3 个 $M^{(1)}$ 任务（Put Back Block、Rearrange Blocks、Swap Blocks，需回忆单次过去事件）与 2 个 $M^{(n)}$ 任务（Battery Try、Block Ranking Try，需累积多次尝试结果） | 每任务 50 次 rollout |

- 主干网络：**π0** 与 **π0.5**（LIBERO 实验用全量微调以匹配已发布 π0 设定；RMBench 用 LoRA：PaliGemma rank 16/alpha 16，动作专家 rank 32/alpha 32）。

### 3.2 对比方法

- **本地 π0 主干基线**：π0-Stateless（无记忆）、π0-FrameStack（4 帧历史，间隔 50 环境步）、π0-Hint（推理时注入模拟器文本提示，特权信息参考）、π0-Vanilla Recurrent Memory（Delta-Mem 的联想记忆）、π0-μ-VLA（μVLA 的循环记忆 token，64 个 token）。
- **已发布结果**：Diffusion Policy、ACT、X-VLA、π0.5（作为全量微调 π0.5 基线）。
- **压缩历史方法**：NativeMEM（视频历史编码），及其与 MemBodied 的组合。
- **自身变体**：MemBodied-AS、MemBodied-H、MemBodied（记忆 token）、MemBodied w/o anchor。

### 3.3 主要结果

- **RMBench（5 任务均值）**：MemBodied **50.0%**，π0-Stateless 6.4%、π0-FrameStack 14.8%、π0-Vanilla Recurrent Memory 16.8%、π0-μ-VLA 0.0%、π0-Hint 2.0%、NativeMEM 38.4%；MemBodied-AS 20.8%、-H 23.2%、无锚点 37.6%。
- **相对增益**：无状态策略的 **7.81×**、普通循环记忆的 **2.98×**、最强记忆增强基线的 **1.3×**。
- **π0.5 主干**：MemBodied 48.0% vs π0.5 基线 12.4%（**3.87×**），Rearrange Blocks 从 13%→94%。
- **真机**：均值从 3.33% 提升到 26.67%（**8.0×**），三个任务均提升。
- **LIBERO**：四套件均值 95.1% vs π0 94.2%；**LIBERO-Long 90.6% vs 85.2%（+5.4 个百分点）**；Spatial −0.6、Object −1.0、Goal 持平。
- **推理效率**：延迟 129.2 ms vs NativeMEM 1593.7 ms（**降低 91.9%**）；峰值显存 18.61 GiB vs 20.57 GiB（**降低 9.5%**）；新增参数 **40M**（π0 的 1.26%），约为 NativeMEM 415M（12.81%）的**十分之一**。

### 3.4 消融与分析

- **记忆设计**：无锚点条件下，记忆 token 37.6% > 分层 23.2% > 注意力引导 20.8%；加入锚点后达 50.0%（Swap Blocks 16%→56%，但 Block Ranking 32%→22%，呈任务依赖）。
- **写值组成**：视觉+动作 46.7% > 仅视觉 42.7% > 仅动作 34.7%，三任务上组合值均最优。
- **记忆秩**：无锚点变体上 r=32/64/128 的两任务均值 27.0%/42.0%/55.0%，单调上升。
- **锚点表示形式**：首帧前缀拼接 22.0% vs 无锚点 34.0% vs 所提锚点 40.0%（Put Back Block）。
- **跨回合记忆携带**：均值从 50.0% 降至 36.8%（5 任务中 4 个下降，仅 Block Ranking +6）。
- **定性分析**：每任务 50 对同种子 rollout 手工标注失败模式，定位增益于"需要过去信息"的决策点（错误垫位返回 37/50→13/50；错误块选择；过早宣告交换完成 41/50→19/50；电池重复尝试；未验证就拆解排列）。

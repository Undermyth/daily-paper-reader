## 摘要
近期视频-语言模型越来越多地采用混合架构，将线性注意力层与全注意力层交错排列，以实现高效的长上下文处理。尽管线性注意力的循环状态大小保持固定，但全注意力的 KV 缓存会随视频流持续增长，因此在有限内存预算下必须进行驱逐。流式场景中的关键挑战在于，驱逐必须发生在问题到达之前，因此必须在没有问题的情况下决定保留什么。现有驱逐方法从 KV 缓存本身推导 token 分数，利用位置、注意力或键值表示，而基于注意力的分数还需要代理查询或额外计算。混合骨干网络提供了另一种信号来源。在门控 delta 线性注意力中，循环状态由每个输入与已可从该状态中检索到的内容之间的残差来更新，因此其在一段帧块上的变化反映了该帧块带来了多少新信息。我们提出 DeltaS，一种与查询无关、无需训练的方法，它保留引起更大归一化状态变化（即状态漂移）的视频块。在预算和保留策略保持固定的受控比较中，状态漂移优于基于位置、注意力和键值的信号。由于该信号仅耗费前向传播 1.9% 的开销，DeltaS 在六个长视频基准上平均超过最强的查询无关有限内存基线 2.1 分，并在最长基准上超过 5.6 分。这些结果表明，混合架构的两种记忆可以协同工作。代码见 https://github.com/MaumAI-Company/DeltaS。

## Abstract
Recent video-language models increasingly adopt hybrid architectures that interleave linear and full attention layers for efficient long-context processing. While the recurrent state of linear attention remains fixed in size, the KV cache of full attention continues to grow with the video stream, making eviction necessary under a bounded memory budget. The key challenge in streaming is that eviction must occur before the question arrives, so what to retain has to be decided without the question. Existing eviction methods derive token scores from the KV cache itself, using position, attention, or key-value representations, and attention-based scores further require proxy queries or extra computation. Hybrid backbones offer another source of signal. In gated-delta linear attention, the recurrent state is updated by the residual between each input and what can already be retrieved from the state, so its change over a chunk of frames reflects how much new information the chunk brings. We propose DeltaS, a query-agnostic, training-free method that retains video chunks inducing larger normalized state change, or state drift. In a controlled comparison with the budget and retention policy held fixed, state drift outperforms position-, attention-, and key-value-based signals. With a signal costing only 1.9% of the forward pass, DeltaS surpasses the strongest query-agnostic bounded-memory baseline by 2.1 points on average across six long-video benchmarks and by 5.6 points on the longest benchmark. These results suggest that the two memories of hybrid architectures can work cooperatively. Code is available at https://github.com/MaumAI-Company/DeltaS.

- **关键挑战**：流式场景中，问题（query）可能在任意时刻到达，而**驱逐必须发生在问题到达之前**，因此"保留什么"必须在无查询（query-agnostic）条件下决定。
- **现有方法局限**：现有 KV 驱逐方法从 KV 缓存本身推导 token 分数（位置、注意力、键值表示），其中注意力类方法还需代理查询或额外注意力计算。
- **新信号来源**：混合骨干网络本身提供了一个固定大小、多时间尺度、已在前向传播中计算好的信号——线性注意力层的循环状态。在**门控 delta 线性注意力**中，状态仅写入"输入与可从当前状态检索到的内容之间的残差"，因此一个视频块引起的状态变化反映了它带来的新信息量。
- **整体含义**：论文提出 DeltaS，用循环状态的归一化变化（**状态漂移 state drift**）作为 KV 保留信号，表明混合架构的两种记忆（固定循环状态 + 增长的 KV 缓存）可以协同工作。

## 2. 方法论

### 核心思想
- 将每个视频块处理前后循环状态的变化量（状态漂移 ∆S）作为该块的信息量度量，**优先保留状态漂移大的块**对应的 KV 条目。
- 该信号**与查询无关、无需训练**，且复用前向传播中已产生的状态，无需代理查询或额外注意力计算。

### 关键技术细节
- **门控 delta 规则**（单头，层/头索引省略）：
  - `S_t = S_{t-1}(α_t(I - β_t k_t k_t^T)) + β_t v_t k_t^T`
  - 重排为：`S_t = α_t S_{t-1} + β_t(v_t - α_t S_{t-1} k_t) k_t^T`
  - 其中 `k_t` 为 L2 归一化键，`v_t` 为值向量，`α_t` 控制状态衰减，`β_t` 为写强度。更新取决于"预测误差残差"与"写强度"的共同作用。
- **状态漂移定义**（公式 3）：
  - `∆S = (1/L) Σ_{i=1}^{L} ||S_after^i - S_before^i||_F / ||S_before^i||_F`
  - `L` 为线性注意力层数，用 Frobenius 范数，按处理前状态幅度归一化以保证跨层可比，再跨层平均得到每个视频块的单一分数。
- **多时间尺度观察**：不同头具有不同保留时长（有的仅几秒，有的 60 秒后仍保留一半以上贡献），跨 3 个基准的头保留时长排序几乎一致（ρ ≈ 0.998）。

### 算法流程（Alg. 1）
1. 每个新 chunk 到达时，先保存 `S_before ← S`。
2. Prefill 该 chunk，更新状态 `S`，并将 chunk 追加到 KV 缓存。
3. 计算 `∆S`，将同一分数赋给该 chunk 的所有 token。
4. 若 `|KV| > M`：
   - 保留前 `n_s` 个 sink token 与最近 `n_w` 个 token；
   - 其余候选按到达时间分成 `N` 个等长时间跨度（bucket），每个 span 平均分配剩余预算 `(M - n_s - n_w)/N`；
   - 每个 span 内按 `∆S` 取 top-k 保留，span 候选不足时用全局剩余高分补齐。
5. **保留原始位置索引**，不重新分配连续位置，避免重新旋转 key。
6. **问答前后保存/恢复状态**：处理每个问题前保存当前状态，回答后恢复到问题前配置，并丢弃问答产生的 KV 条目，保证 query-agnostic 行为。

### 关键超参数
- `n_s = 4`（sink tokens）、`n_w = 1024`（recent window）、`N = 4`（时间桶数），六个基准共享。

## 6. 主要结论与发现

- **性能领先**：`M=8,192` 时 DeltaS 在全部 6 个基准上为 query-agnostic、有界内存方法中最佳，平均超最强基线 StreamMem **2.1 分**；`M=16,384` 时 5/6 基准最佳，平均超 **1.7 分**。
- **紧预算优势更大**：LVBench（最长基准）上 `M=8,192` 超最强基线 **5.6 分**，`M=16,384` 超 **4.3 分**；DeltaS 在 `M=8,192` 的 58.7 分几乎追平 StreamMem 在双倍预算下的 58.8 分。保留率越低，优势通常越大。
- **信号对比结论**：状态类信号（DeltaS、β||e||）优于位置、注意力、键/值类信号；DeltaS 在三基准上排名第一，超最强缓存内信号 VaN **0.7–2.1 分**，超 β||e|| **0.5–1.2 分**。
- **时间桶作用**：无桶时保留明显偏向视频早期；加入时间桶后保留分布更接近均匀，精度提升，`N=4` 时平均增益最大。
- **效率**：状态漂移信号计算仅 **2.07 ms**，占 107 ms chunk 前向时间的 **1.9%**；含选择与驱逐的总额外成本 **6.4 ms**，为所有计算保留信号方法中最低（InfiniPot-V 为 15.4 ms；StreamMem/HERMES 超过一次前向时间；β||e|| 达 206.1 ms）。
- **流式基准的特殊发现**：在 StreamingBench/OVO-Bench 上，仅看最近帧的无记忆基线常超过 Full KV，说明这些基准的聚合分数未必反映长时记忆能力；在需早期信息的任务（如 EPM、Counting）上，DeltaS 表现更优（Counting 60.1 vs recency-4f 的 39.4）。

## 7. 优点

- **方法层面**：
  - 巧妙复用混合架构中**已存在的循环状态**作为保留信号，无需新增记忆模块、无需训练、无需代理查询。
  - **计算开销极低**（信号仅 1.9% 前向时间，总成本 6.4 ms/次驱逐），适合流式重复驱逐场景。
  - 通过"问答前后状态恢复"严格保证 query-agnostic，设计自洽。
  - 时间桶机制有效缓解了状态漂移对早期内容的偏好，并保持时间覆盖。
  - 保留原始位置索引，避免 key 重旋转，工程上优雅。
- **实验层面**：
  - 受控对比将"信号"与"策略"解耦，结论更具说服力。
  - 覆盖 6+2 个基准、两种预算，并额外分析保留率与增益的关系。
  - 诚实报告了基准的局限性（如无记忆基线超过 Full KV），并区分聚合分数与长时记忆任务。

## 8. 不足与局限

- **模型覆盖有限**：仅在单一混合骨干（Qwen3.5-9B）上验证，跨其他混合架构与模型规模的有效性未确立。
- **理论解释依赖特定规则**：状态漂移的解释基于门控 delta 规则的残差更新，在其他状态更新规则下是否有效尚需验证。
- **评分粒度粗**：同一 chunk 内所有 token 共享一个分数，无法区分 chunk 内部更有信息的区域；更细粒度评分是自然的扩展方向。
- **基准表现不一致**：Video-MME v2 上 DeltaS 优势未随预算收紧而扩大（约 0.5 分），该基准的证据整合与时间推理任务可能限制保留差异转化为精度增益；其报告使用逐题准确率而非官方分组非线性分数，与官方榜单不可直接比较。
- **公平性风险**：不同方法因架构差异需做适配（如 StreamMem、HERMES 的 chunk 大小与层级分配调整），可能影响对比公平性；Table 1 是完整系统对比，差异同时来自信号与保留策略。
- **应用限制**：依赖混合架构中线性注意力与全注意力交错的设计；对纯 dense 模型不适用。运行时测量中为公平比较统一使用 2 帧 chunk，与实际准确率评估设置不同。
- **算力信息不完整**：未明确 H100 数量与总评估时长。

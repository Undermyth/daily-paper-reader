## 摘要
扩散变换器（DiTs）实现了强大的视频生成质量，但其密集的时空自注意力随序列长度呈二次方扩展，并迅速成为主要的推理瓶颈。稀疏低秩混合方法通过将局部稀疏分支与全局压缩分支相结合来缓解这一成本。在配备3D旋转位置嵌入（RoPE）的视频DiTs中，全局分支面临结构兼容性问题：当RoPE在非线性特征映射之前应用时，旋转和非线性通常不可交换，这使得在保持相对旋转几何结构的同时保持查询无关的线性摘要变得困难。现有工作通常通过用坐标条件的替代或可学习的绝对位置模块替换真正的跨令牌全局聚合来回避此问题。这些折中方案可能有效，但它们从绝对坐标近似相对衰减并引入额外位置参数。我们提出\textbf{RoLA}，一种旋转定位的低秩线性注意力分支，它保持真正的跨令牌聚合，同时与可重用的线性摘要兼容。该设计在非线性低秩特征映射\emph{外部}应用RoPE，并重用与低秩瓶颈匹配的预训练旋转调度表的截断子集。这产生了一个具有设计上的相对位置行为的线性时间低秩全局分支，且无需额外位置参数；完整的稀疏-低秩模块仍包含固定稀疏性的稀疏分支。在开源视频DiTs上的实验表明，所提方法在90%稀疏度下保持有竞争力的生成质量，同时在Wan2.1-14B（720p，81帧，在NVIDIA H100 GPU上测量）上实现2.63$\times$的端到端推理加速。

## Abstract
Diffusion Transformers (DiTs) achieve strong video generation quality, but their dense spatiotemporal self-attention scales quadratically with sequence length and quickly becomes the dominant inference bottleneck. Sparse low-rank hybrids alleviate this cost by combining a local sparse branch with a global compressed branch. In video DiTs equipped with 3D Rotary Position Embeddings (RoPE), the global branch faces a structural compatibility issue: when RoPE is applied before a nonlinear feature map, the rotation and nonlinearity generally do not commute, making it difficult to keep a query-independent linear summary while preserving relative rotary geometry. Existing work often sidesteps this issue by replacing genuine cross-token global aggregation with coordinate-conditioned surrogates or learnable absolute positional modules. These compromises can be effective, but they approximate relative decay from absolute coordinates and introduce extra positional parameters. We propose \textbf{RoLA}, a rotary-positioned low-rank linear-attention branch that keeps genuine cross-token aggregation while remaining compatible with a reusable linear summary. The design applies RoPE \emph{outside} the nonlinear low-rank feature map and reuses a truncated subset of the pre-trained rotary schedule matched to the low-rank bottleneck.   This yields a linear-time low-rank global branch with relative positional behavior by design and no additional positional parameters; the full sparse--low-rank module still includes the fixed-sparsity sparse branch. Experiments on open-source video DiTs show that the resulting method remains competitive in generation quality at 90\% sparsity while achieving 2.63$\times$ end-to-end inference speedup on Wan2.1-14B (720p, 81 frames, measured on an NVIDIA H100 GPU).

- **背景**：扩散变换器（Diffusion Transformers, DiTs）已成为高保真视频生成的主导骨干架构，但其稠密时空自注意力的计算复杂度随序列长度呈**二次方增长**，当视频分辨率和时长增加时，推理成本迅速成为瓶颈。
- **既有解决方案及其局限**：
  - 纯稀疏注意力方法（VSA、SLA、VMoBA 等）：仅保留部分 query–key 交互，在适度稀疏度下有效，但**激进稀疏化会丢失保持语义一致性、运动连贯性和场景布局所需的全局交互**。
  - 稀疏–线性混合方法：在稀疏局部分支之外增加廉价全局分支，以恢复被丢弃的全局上下文。
- **核心矛盾（RoPE Dilemma）**：在配备 3D 旋转位置编码（RoPE）的视频 DiTs 中，设计一个真正的低秩全局线性分支面临结构性困难：
  - 线性注意力依赖**与查询无关的可复用全局摘要**；
  - 3D RoPE 通过位置相关旋转编码相对几何；
  - 当 RoPE 在非线性特征映射之前施加时，旋转与非线性一般**不满足交换律**，导致全局摘要与绝对位置纠缠，难以同时保持相对旋转几何与线性可复用性。
- **现有折中方案的缺陷**（以 RoPeSLR 为代表）：用坐标条件化替代物或可学习绝对位置模块替代真正的跨 token 全局聚合，虽然有效，但存在两个局限：
  1. 相对衰减是从绝对坐标**近似**出来的，而非由全局分支本身表示；
  2. 放弃了可复用的线性注意力视角，且引入了**额外位置参数**。
- **论文的核心问题**：能否构建一个真正的线性全局分支，使其与 3D 相对位置结构兼容、保持真正的跨 token 聚合，同时不引入额外的位置参数？

# 二、论文提出的方法论

## 2.1 总体框架

RoLA 采用**稀疏–低秩双分支分解**：

| 分支 | 作用 | 性质 |
|------|------|------|
| 稀疏分支（Sparse Branch） | 捕捉高能量的语义尖峰（top-k 交互） | 固定稀疏度的块稀疏注意力，非本文贡献 |
| 低秩全局分支（Low-rank Branch） | 重建平滑、可压缩的全局背景 | **RoLA 的核心贡献** |

最终通过**分布感知的门控融合**将两分支输出组合。稀疏分支沿用既有方法（如 SLA/VMoBA），实验中固定以隔离变量。

## 2.2 核心设计：旋转定位低秩线性注意力

**关键公式**：

- 低秩分支计算：

$$\tilde{q}_p = R_r(p)\,\mathrm{SiLU}(P_q q_p^n), \quad \tilde{k}_q = R_r(q)\,\mathrm{SiLU}(P_k k_q^n)$$

- 全局上下文聚合与读取：

$$C = \sum_{q=1}^{L} \tilde{k}_q v_q^\top \in \mathbb{R}^{r \times d_h}, \quad O^{lr}_p = \mathrm{RMSNorm}(\tilde{q}_p^\top C)$$

其中 $P_q, P_k \in \mathbb{R}^{r \times d_h}$ 为头特定投影，$R_r(p)$ 为限制在前 $r$ 个坐标上的 3D RoPE 旋转。

**两条核心性质**：

1. **RoPE 在激活函数之外应用**（outside-activation ordering）：
   - 旋转 $R_r$ 施加在低秩特征上而非全维度上；
   - 施加在 SiLU **非线性之后**，使非线性低秩映射提取与位置无关的内容特征，RoPE 只充当相对位置算子；
   - 保证了低秩成对交互是相对偏移的函数（shift-invariant），同时全局上下文 $C$ 仍可一次计算、供所有查询复用，维持 $O(Lr d_h)$ 的线性复杂度。

2. **旋转调度的维度截断**（rank-truncated rotary schedule）：
   - 低秩瓶颈为 $r$ 维（默认 $r=64$），只能携带 $r/2$ 个完整旋转坐标对；
   - 直接复用预训练骨干的 `freqs_cos, freqs_sin` 张量的前 $r$ 个条目，**不重排、不重新学习频率**；
   - 不新增任何位置参数，保持与骨干和稀疏分支相同的几何尺度。

## 2.3 关键设计动机（为什么可行）

- **旋转置于外部**：论文通过命题 B.1 验证了当非线性特征映射与位置无关时，旋转可移入相对偏移，同时保持线性可重用性；命题 B.4 则在理想化连续位置设定下证明了**内侧激活 SiLU 无法实现精确的相对分解**（结构性障碍），从而为"外侧激活"设计提供理论动机。
- **$r=64$ 的充分性**：论文在理想化嵌套设定下给出了截断误差界（命题 B.3：误差受丢弃子空间特征范数乘积控制），但声明这只是设计直觉而非严格保证；经验证据来自实特征上的算子保真度实验（图 4）。

## 2.4 门控融合

- 使用 token 级标量门控：$g = \sigma(XW_g + b_g)$；
- 采用 RMSNorm 归一化稳定融合：

$$O_p = \left( \frac{O^s_p}{r_p} + g_p\,O^{lr}_p \right) r_p$$

其中 $r_p$ 为稀疏输出逐 token 的 RMS。门控偏差 $b_g$ 初始化为负值，使模块初始状态接近稀疏基线，逐步引入低秩分支的贡献。

## 2.5 训练策略

- **单阶段全微调**（single-stage full fine-tuning），与 RoPeSLR 的两阶段策略不同。理由：新参数位于最终注意力的低秩路径上，且门控初始化为接近关闭状态，单阶段联合优化自然匹配推理路径，避免阶段失配；
- 初始化：投影层用 Kaiming，$W_g=0$，$b_g<0$；
- 新参数学习率高于骨干（骨干 $2\times10^{-6}$，新参数 $3\times10^{-5}\sim5\times10^{-5}$）。

- 通过**受控全局分支比较**（表 10）隔离了稀疏路由与全局分支的各自贡献；
- 通过**微调对照实验**（表 9）排除了"为微调而微调"的天真混淆解释；
- 在 6~7 个设计轴上的消融较为系统，覆盖了核心设计决策；
- 跨多个骨干（含 MoE 的 Wan2.2）验证泛化性。

**不足与有待加强之处**：
- **骨干覆盖仍然偏窄**：论文自己承认局限中限定于"两个 Wan 模型"（附加上 Wan2.2 实际上是 3 个变体，但均属 Wan 系列同一家族）。没有覆盖 CogVideoX、HunyuanVideo、LTX-Video 等主流开放模型；
- **训练数据规模有限**：仅使用 2,000 个样本微调，未报告完整 OpenVid-1M 或更大数据的效果，扩展趋势未知；
- **外部指标维度主要集中在 VBench 系列**，缺少人工评估（user study）和更细粒度的运动/语义指标；
- **帧级指标以 full attention 输出为参考**，未与真实视频 ground truth 对比，尽管这是后训练效率方法评估中的常见做法；
- 稀疏分支默认与对比方法保持一致，但 SLA 等方法可能有各自更优的稀疏模式，存在一定的不公平可能（论文声称会保留各方法特有的路由设计，但仍需注意对比公平性）。

总体判断：**实验设计在隔离混淆变量和验证机制方面是充足的，覆盖面在骨干多样性和外部泛化性上略显单薄，但就其定位为特定研究的后训练方法来说是合理的。**

# 六、论文的主要结论与发现

1. **结构性问题的确认**：在 3D-RoPE 视频 DiTs 中，真正的低秩全局线性分支必须同时满足"可复用线性摘要"与"相对旋转几何"两个要求，二者在通常的非线性线性注意力公式下存在冲突，这是论文所称的 RoPE Dilemma。

2. **外侧 RoPE 设计的有效性**：将 RoPE 施加在非线性低秩特征映射之外，是实现两个要求同时成立的充分条件。机制实验表明：
   - 无需 RoPE 的分支完全位置盲（偏移范围 0.0）；
   - 内侧放置泄漏绝对位置（平移残差 $3.7\times10^{-1}$）；
   - 外侧放置同时实现位置感知（偏移范围 0.47）与平移不变（残差 $1.8\times10^{-5}$）。

3. **秩截断的实践充分性**：保留 $r=64$（$d_h=128$ 的一半）即达到算子保真度的饱和点（时间轴余弦 0.93），下游生成质量与其保持一致的趋势，继续增大 $r$ 的收益边际递减。

4. **质量–效率优势**：
   - 在 Wan2.1-1.3B（480p）上，90% 稀疏度下延迟降至 21.7s（full attention 为 50.9s，约 2.35× 加速），VBench 指标与 full attention 相当甚至略优；
   - 在 Wan2.1-14B（720p，81 帧）上，90% 稀疏度下达 **2.63× 端到端推理加速**（409.3s vs 1075.7s），质量保持竞争性；
   - 相对于纯稀疏基线（VSA）和已有稀疏–线性混合（SLA）、稀疏–低秩基线（RoPeSLR），RoLA 在相同目标稀疏度下 VBench 指标更接近稠密基线。

# 七、优点

1. **问题定位精准**：论文识别了一个此前模糊、但实际存在的结构性矛盾——"相对旋转几何"与"可复用线性摘要"之间的张力，并给出清晰的命名（RoPE Dilemma），有助于推进领域对视频 DiT 高效化设计的结构性理解。

2. **设计简洁且优雅**：核心解决方案（RoPE 置于激活之外 + 秩截断复用预训练旋转调度）概念上简单清晰，不引入额外位置参数，不改变推理的线性复杂度，且无需重训练骨干从零开始。

3. **理论动机与机制验证匹配良好**：
   - 命题 B.1 验证了外侧设计同时满足相对性与线性可复用性；
   - 命题 B.4 给出了内侧设计无法精确分解的障碍论证，且经验观察与其预测完全吻合（内侧泄漏绝对位置）；
   - 命题 B.3 提供了截断误差的直觉边界。
   - 三个理论件均被作者谦逊地标注为 "sanity check" / "design intuition" / "structural obstruction"，而非过硬的理论贡献，展示了充分的学术诚态度。

4. **工程实现考虑周到**：
   - 将旋转坐标的奇偶行离线拆分，用纯 2D matmul 完成推理；
   - 双 Triton kernel 实现精确复现公式；
   - RMSNorm + 门控融合保证训练稳定，门控初始化保证从稀疏基线平滑过渡；
   - 在长序列下相对纯稀疏注意力的额外 FLOPs 为 $O(L^{-1})$，渐近可忽略。

5. **实验控制的严谨度高**：

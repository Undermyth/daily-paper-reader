## 摘要
动态分层路由通过为单个token学习跳过层来降低大型语言模型（LLM）的推理成本。然而，现有方法将每个路由决策视为仅由当前隐藏状态决定的局部操作，这种表述忽略了跨深度路由的序列性和路径依赖性：早期决策塑造了下游路由器所见到的表示，且层使用目标将所有决策联合耦合。我们提出历史感知路由（HeRo），一种动态路由框架，通过引入路由器记忆机制在模型深度上维护显式路由状态来解决这一不匹配问题。该记忆通过线性注意力构建，将先前的路由分数及其诱导的残差更新逐步聚合为紧凑的历史表示。在每个被路由的层中，路由器联合基于该累积状态和当前隐藏表示来决定执行的分支。实现为token级FFN路由时，HeRo仅在冻结主干上训练轻量级路由器和适配器，无需修改预训练参数。在Llama 3.1-8B、Llama 2-7B和Llama 2-13B上，HeRo在十个基线中始终实现最高的总体性能保持。在Llama 3.1-8B上，它绕过26.87%的模型参数，同时在七个基准上达到密集模型性能的100.24%；在更紧凑的计算预算下，绕过38.82%的参数时仍保持97.01%的性能。消融研究证实，移除路由历史会持续降低性能，尤其是在多步推理和代码生成任务上，这验证了显式路由记忆相比仅依赖于隐藏状态能实现更准确和自适应的动态路由。

## Abstract
Dynamic layer routing reduces the inference cost of Large Language Models (LLMs) by learning to skip layers for individual tokens. Existing methods, however, treat each routing decision as a local operation conditioned solely on the current hidden state which is a formulation that overlooks the sequential, path-dependent nature of routing across depth: earlier decisions shape the representations seen by downstream routers, and the layer-usage objective couples all decisions jointly. We propose History-Aware Routing (HeRo), a dynamic routing framework that resolves this mismatch by introducing a router memory mechanism to maintain an explicit routing state across model depth. The memory is constructed via linear attention, incrementally aggregating preceding routing scores and their induced residual updates into a compact history representation. At each routed layer, the router conditions jointly on this accumulated state and the current hidden representation to select the executed branch. Instantiated for token-wise FFN routing, HeRo trains only lightweight routers and adapters on a frozen backbone, requiring no modification to pretrained parameters. Across Llama 3.1-8B, Llama 2-7B, and Llama 2-13B, HeRo consistently achieves the highest aggregate performance retention among ten baselines. On Llama 3.1-8B, it bypasses 26.87% of model parameters while achieving 100.24% of dense model performance across seven benchmarks, and retains 97.01% while bypassing 38.82% of model parameters under a tighter computation budget. Ablation studies confirm that removing routing history consistently degrades performance, most notably on multistep reasoning and code generation, validating that explicit routing memory enables more accurate and adaptive dynamic routing than solely conditioning on hidden state.

## 1. 核心问题与研究动机

- **问题定义**：动态层路由（dynamic layer routing）逐 token 决定跳过哪些层的稠密计算，从而减少 LLM 推理开销。但现有方法将每个路由决策视为**仅依赖于当前隐藏状态 h^(l)_t 的局部操作**。
- **论文指出的 mismatch**：
  - 路由是**沿模型深度的顺序决策过程**：先前层的决策决定了后续路由器看到的表示（residual stream 更新），所以决策之间存在路径依赖；
  - 层使用目标函数对**所有路由层的决策联合施加约束**，使每个决策同时依赖"过去的历史"与"未来的剩余路由深度"；
  - 单一隐藏状态虽是累积结果的体现，但**并未显式记录已发生的路由分数与残差变化**，轻量路由头未必能从隐状态中可靠地反推出历史决策序列。
- **研究问题**：动态路由器是否需要显式记忆？答案与核心主张是**需要**——显式地跨层传输路由历史 state，比仅靠当前隐藏层条件化能实现更准确的自适应路由。

## 2. 方法与关键技术

- **核心思想**：提出 **HeRo（History-Aware Routing）**，在 Transformer 的深度方向引入**路由器记忆（router memory）**，利用线性注意力（linear attention）沿被路由层聚合前述路由分数与残差更新，形成紧凑历史表示，并与当前隐状态一起参与每个路由决策。
- **与现有方法关系**：
  - 类似 RMoE 跨层传递路由状态的思路，但先前多用于 MoE 的 expert 选择；HeRo 将其用于深度方向的 FFN 路由；
  - 类似 SkipGPT、MoD-D 等动态模块路由，但通过为路由历史加入显式状态解决了"局部静态路由"问题。
- **运行配置**：
  - 在 Decoder-only 架构中被路由块上做 **token-wise FFN 路由**：选择执行冻结的与原 FFN 还是轻量 bottleneck adapter（SiLU 激活，中间维度 896）；
  - 参数：状态维度 64（48 维表示 + 16 维路径特征），记忆单头 q,k,v∈R64，遗忘因子按块学习并初始化为约 0.98；
  - 冻结所有预训练参数，只训练路由器、状态编码器、深度记忆与 adapter，受完整语言建模 loss 与门使用率惩罚约束。
- **路径向量与特征**：路径特征含 6 标量——路由进度 j/L_R、剩余路由比例、最近两次决策点间 residual 变化的范数与方向余弦、上一次路由 score 与累计乘积 score——编码后与隐状态编码拼接成路由器状态。
- **记忆机制**：用 kernelized linear attention（ϕ=ELU+1）。
  - 读：先由当前状态生成 query，与已累积状态矩 S 和归一化向量 ζ 计算历史上下文；
  - 写：用 key/value 更新记忆，当前内存加入一个 block-specific 门控遗忘率 ρ；
  - 先读后写，当前路由决策只看**先前被路由块**的历史，保证因果性；
  - 在第一个被路由块上下文为空时，将历史评分设为默认值以避免未定义行为。
- **路由方程**：比较当前状态与上下文的余弦差异，并结合状态、上下文和差异分数生成历史 logit，本地 logit 同时作用于注意后的表示；两者合并后经 sigmoid 得到门值，并按阈值 τ_exec=0.5 选择 FFN 或 adapter。训练和推理使用同一个阈值化单分支计算，门缩放提供梯度路径。
- **训练目标**：L = L_LM + α_t L_skip，其中 L_skip 对一个序列中所有路由块的 FFN 门分数和进行平方，以惩罚大 FFN 总消耗。

## 6. 主要结论与发现

- 显式历史记忆有实质作用：**移除历史分支或移除对记忆的读取均会一致性地降低总体绩效**；受影响最大的是 GSM8K 与 HumanEval 等多步骤或结构化生成类任务。
- 跨家族与规模的泛化：在 Llama3.1-8B、Llama 2-7B 和 Llama 2-13B 上，HeRo 是全部对比方法中总体留存最高的系统。
- 强压缩场景收益更大：当从 25% 提升到 40% 目标跳过率时，架构相较第二强基线方法的优势从约六个百分点（SkipGPT-RT=94.14%，HeRo=100.24%）拉大至显著更高的区间（81.15% 对 97.01%），说明跳过的路径更多，内存带来的信息增益更大。
- 路由历史与本地表示互补——既非单独来自本地的门控可复现，也非单独来自全局注意层可以代替。

## 7. 方法/实验亮点

- **问题框架**准确对应现有动态路由方案的局限，并把"是否需要在跨深度路由中存储显式记忆"这个通用问题作为核心，使方法适用范围不限于 FFN。
- 用**线性注意力的读写顺序**自然构建因果历史状态，避免引入额外 RNN 或全局注意力结构，计算开销低、无未来泄漏；
- 同时依赖保留原 FFN 并加入轻量 adapter 分支，实现"路径选择"而非"二进制删层"，难度梯度连续且可微；
- 实验设置相对公平：比较中包含多种跨类基线，控制了预算目标并报告实际跳过率，且强调了多个 seeds 的结果，统计严谨性好。

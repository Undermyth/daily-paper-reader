## 摘要
多模态大语言模型（MLLMs）近来在视觉语言推理方面取得了显著进展，但其性能往往随着生成序列变长而下降。一个关键因素是，在单一且不断增长的上下文下，它们经常丢失早期的视觉证据和中间约束。受人类在解决复杂任务时分别回忆所见与所推的启发，我们提出了DLMR，一种参数高效的机制，为MLLMs配备双重潜记忆：一个压缩图像证据的视觉记忆和一个跟踪中间结论与约束的推理记忆。随后，路由器在推理过程中动态决定使用哪个记忆以及使用多少，既保持视觉依据，又维持连贯的长程推理。DLMR分三个阶段训练，从潜记忆构建到选择性路由器学习，同时保持基础MLLM冻结，仅用少量额外可训练参数便在通用与推理基准上带来了显著提升。分析进一步显示了具有专门记忆角色的可解释、状态依赖的路由，并在长序列生成中减少了解码标记。代码可在https://github.com/Hunter-Wrynn/DLMR获取。

## Abstract
Multimodal large language models (MLLMs) have recently made strong progress in vision-language reasoning, yet their performance often degrades as generations grow longer. A key factor is that they frequently lose track of earlier visual evidence and intermediate constraints under a monolithic growing context. Inspired by how humans separately recall what they see and what they infer when solving complex tasks, we propose DLMR, a parameter-efficient mechanism that equips MLLMs with Dual Latent Memories: a visual memory that compresses image evidence and a reasoning memory that tracks intermediate conclusions and constraints. A Router then dynamically decides which memory and how much to reuse during inference, preserving visual grounding while maintaining coherent long-horizon reasoning. DLMR is trained in three stages, from latent memory construction to selective router learning, while keeping the base MLLM frozen, yielding substantial gains on both general and reasoning benchmarks with only a small number of additional trainable parameters. Analyses further show interpretable, state-dependent routing with specialized memory roles and reduced decoding tokens over long generations. Code is available at https://github.com/Hunter-Wrynn/DLMR.

## 一、核心问题与研究动机

**核心问题：** 多模态大语言模型（MLLMs）在进行长程视觉—语言推理时，随着生成序列不断变长，模型会逐步"遗忘"早期的视觉证据与中间推导出的约束条件，导致最终答案质量严重下降。

**领域背景：**
- 现有 MLLM 在标准架构下依赖**单一持续增长的上下文**：图片被编码为前缀 tokens，后续仅靠已生成文本来承载体信息。由于因果自注意力需在越来越长的上下文中分配注意力权重，图像 token 的平均注意力权重随解码步数增加而趋于零（近似 O(Lv/nt)），模型有效丧失对早期视觉信息的"可及性"。
- 该现象对应长期上下文检索失败（"lost in the middle"）、注意力衰减与幻觉正相关等问题。
- 已有补救方法（如 CoT 提示、训练对齐、RAG 等）本质上都未跳出单一增长上下文框架，不能从根本上阻止多步遗忘。

**人类认知启发：** 人类的鲁棒多步推理依赖**解耦的工作记忆**——对"所见"（观测）和"所思"（约束）分开维护缓冲区，按需回访。当前 MLLM 缺少这一结构化替代机制，因此作者提出 DLMR，引入两个基本构件：① 可重用的视觉证据与演化推理约束的解耦表示；② 决定检索内容与检索量的状态依赖控制器。

## 二、方法论：DLMR

### 2.1 整体框架

DLMR 在**冻结的基础 MLLM** 之上增加三个轻量组件：

| 组件 | 作用 |
|---|---|
| 双潜记忆（Dual Latent Memories） | 两个输入无关的可学习潜记忆 \(Z^{(v)} \in \mathbb{R}^{M_v \times d}\)（视觉）与 \(Z^{(r)} \in \mathbb{R}^{M_r \times d}\)（推理） |
| 记忆注入器（Memory Injector） | 将选中的潜记忆向量上下文化为 k 个记忆 token 并追加至解码上下文 |
| 记忆路由器（Memory Router） | 在可注入的生成步骤上，依据当前上下文做出离散决策：选择什么记忆类型（视觉/推理）、分配多少 token 预算 |

### 2.2 关键技术细节

**（1）记忆生成：**
- 给定 token 预算 \(k \in K^+ = \{4, 8, 16\}\)，从选中的记忆库中取前 k 个潜向量 \(Z^{(s)}_{1:k}\)。
- 记忆注入器 \(g_\phi\) 采用 **LoRA 增强的基座副本**实现：先把当前上下文嵌入映射到注入空间，将潜向量与原 context 拼接后经注入器自注意力运算，最后取出后 k 个隐藏状态映射回原始维度，得到记忆 tokens \(M_t\)。

**（2）记忆路由：**
- **注入资格判定**：仅在解码前缀命中分隔符集合 \(D=\{“,”,“.”,“\n”\}\) 的步骤才允许注入；每个样本有最多注入次数上限 \(N_{\max}\)。
- **动作空间**：离散动作 \(a_t = (s_t, k_t)\)，其中 \(s_t ∈ \{v, r\}\)，\(k_t ∈ K^+\)（共 2×3=6 种动作 + 空动作）。
- **策略实现**：以 LoRA 增强的分类头基于最新前缀 token 的隐藏状态输出动作分布；训练时采样，推理时贪心选择。
- **提示末尾固定注入**：在每轮对话的 assistant 标记之前固定注入视觉潜记忆，提供稳定感知线索。

**（3）三阶段训练方案**（全程冻结基础骨干，仅训练少量记忆相关参数）：

1. **阶段一：潜记忆冷启动**——只优化两个潜记忆库 \(Z^{(v)},\,Z^{(r)}\)。用教师—学生对齐：未经注入的骨干产出教师池化表征（视觉/推理分别来自图像 token 与非图像 token 池化），随机注入的学生隐状态产出学生表征，使用两教师对齐损失（余弦对齐 + 交叉负项 hinge 惩罚 + 分离项），使两个记忆库各司其职。
2. **阶段二：注入器训练**——联合优化注入器参数 \(\phi\) 与潜记忆 \(Z\)，在中间插入点混合视觉/推理注入与不同预算。可用 SFT（下一 token 似然）或 GRPO（任务级奖励）变体，辅以弱正则项防止两记忆坍缩。
3. **阶段三：路由器学习**——冻结注入器和记忆，训练路由策略 \(\pi_\psi\)。使用 GRPO 优化带成本感知的目标函数；效率奖励仅在答案正确时计入，鼓励更小的注入预算。

**损失函数要点：**
- 阶段一两教师对齐损失：\(\mathcal{L}_{\text{stage1}} = \sum_s [1-\cos(z_s,t_s)] + \lambda_{\text{neg}} \sum_{s≠s'} [\cos(z_s,t_{s'})-m]_+ + \lambda_{\text{sep}} \cos(z_v,z_r)\)
- 阶段三成本感知目标：\(\max_\psi \mathbb{E}_{\tau \sim \pi_\psi}[R_{\text{task}}(\tau) + \lambda_{\text{eff}} R_{\text{eff}}(\tau)] - \beta \text{KL}(\pi_\psi \| \pi_{\text{ref}})\)

## 六、主要结论与发现

1. **双记忆架构显著改善长程推理。** 在双潜记忆设计下，视觉（"所见"）与推理（"所思"）信息由不同缓冲区分开维护、按需回访，相比单记忆设计在长程推理基准上大幅提升（MathVision 22.37→35.32）。
2. **可训练注入器是必要组件。** 冻结注入器使收益明显下降，说明仅注入位置是不够的，需要将潜记忆转换为上下文对齐、任务可用的信号。
3. **自适应路由优于固定预算。** 动态分配 token 预算可以在不显著增加生成长度的情况下取得更高精度；通用任务与推理任务在最优预算上限上存在差异（16 vs 32）。
4. **DLMR 在多个模型规模上一致有效**，且跨模态迁移到纯文本推理，表明该机制的核心思想具有通用性。
5. **Token 效率提升**——通过潜记忆替代冗余的文本重建，DLMR 用更少的生成 token 达到更高精度。

## 七、方法亮点

1. **理念先进**："视觉证据"与"推理状态"解耦，受认知科学中工作记忆模型的启发，直击长程遗忘结构性病因，区别于所有基于单一增长上下文的修补方法。
2. **参数高效**：骨干完全冻结，仅引入少量记忆 tokens 与 LoRA 组件（注入器+路由器），训练开销低、易于集成到已有 MLLM。
3. **可控的成本—精度权衡**：通过分隔符限定注入时机、上限限制注入次数、预算自适应分配，推理开销可配置且有明确机制约束。
4. **训练阶段设计精巧**：三阶段渐进式学习（记忆构建→注入器学习→路由器学习）降低联合优化的困难，且各阶段目标清晰。
5. **科学分析扎实**：理论上用注意力质量守恒公式解释了长程遗忘的必然性（Eq. 3），为方法提供了坚实的数学动机；并给出 router 在不同任务类型上的可解释行为差异。

## 八、不足与局限

1. **训练/评测数据重叠**：训练语料包含评测 benchmark 的训练 split，对最核心基准（如 MathVista/MathVerse）的性能提升存在数据泄漏风险。虽有 unseen 数据集补充，但主结果解读需谨慎。
2. **可训练参数细节不透明**：论文声称"只训练少量参数"，但具体新增参数量（latent memory + LoRA）未给出精确数字，路由器的总参数量亦未披露。
3. **硬件资源未报告**：无法评估 DLMR 三阶段训练的实际成本（GPU 时长、显存占用等），影响复现和实用性判断。
4. **基线公平性问题**：DLMR 的系统性增益可能部分来自更大的总训练计算量或训练语料差异，论文未提供控制计算预算的严格对比实验（如限制相同训练步数的对比）。
5. **大规模模型验证缺失**：仅在 2B–8B 开源模型上验证，未展示在更大参数规模上的拓展性。
6. **实际推理复杂度过高的隐患**：虽然平均 token 数下降，但每次注入都需重置 KV cache 并对全上下文重新前向，长序列下多次注入的累积开销需要更仔细的剖析（附录报告了端到端时间基本可控，但这方面的理论成本分析不足）。
7. **安全与偏差考量有限**：新增记忆机制在幻觉、偏见与分布漂移问题上更多继承骨干特性，论文对更细粒度的失败模式缺少研究。

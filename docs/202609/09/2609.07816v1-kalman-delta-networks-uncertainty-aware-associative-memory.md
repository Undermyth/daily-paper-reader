## 摘要
线性注意力在前沿语言模型中越来越广泛地被用于高效的长上下文推理和恒定内存解码。然而，其固定大小的循环记忆需要在每个词元处进行在线决策：在不知道未来查询将需要哪些信息之前，决定写入什么内容以及以何种强度覆盖现有关联。Delta规则模型从当前词元嵌入中学习这种强度，但并未跟踪记忆估计的置信度，使得每次写入无法适应累积的证据。为了显式表示这种不确定性，我们将循环联想记忆重新表述为一个线性-高斯状态空间模型，卡尔曼滤波器是该模型的最优递归估计器，并由此引入一个新的模型家族——卡尔曼Delta网络（KDNs）。在KDN中，转移过程同时传播记忆状态及其不确定性，使得卡尔曼增益能够根据累积证据和观测可靠性对每次残差写入进行加权。在此公式下，Delta风格更新作为特例出现，它用逐词元各向同性替代量取代预测协方差，并省略了协方差跟踪。然而，精确跟踪需要处理稠密的、状态相关的Riccati递归，这不太适合GPU并行的线性注意力扫描。为解决这一问题，我们提出了两种兼容扫描的KDN近似方法。对角KDN通过在线平均场变分推断将每一步后验投影到对角高斯族上，而各向同性KDN则使用各向同性近似，每个注意力头有一个不确定性标量。它们的不确定性递推是莫比乌斯映射，从而能够以对数并行深度进行关联扫描。在750M和1.3B参数的受控预训练中，KDN变体在困惑度和平均下游准确率方面持续优于最先进的线性注意力模型。

## Abstract
Linear attention is increasingly used in frontier language models for efficient long-context inference and constant-memory decoding. Its fixed-size recurrent memory, however, requires an online decision at each token: what to write and how strongly to overwrite existing associations before knowing which information future queries will require. Delta-rule models learn this strength from the current token embedding but do not track confidence in the memory estimate, preventing each write from adapting to accumulated evidence. To represent this uncertainty explicitly, we reformulate recurrent associative memory as a linear--Gaussian state-space model, for which the Kalman filter is the optimal recursive estimator, and introduce a new family of models, Kalman Delta Networks (KDNs). Within KDNs, the transition propagates both the memory state and its uncertainty, allowing the Kalman gain to weight each residual write by accumulated evidence and observation reliability. Under this formulation, Delta-style updates emerge as a special case that substitutes a token-wise isotropic surrogate for predictive covariance and omits covariance tracking. Exact tracking, however, entails a dense, state-dependent Riccati recursion that is poorly suited to GPU-parallel linear-attention scans. To address this issue, we introduce two scan-compatible KDN approximations. Diagonal KDN projects each one-step posterior onto the diagonal Gaussian family through online mean-field variational inference, whereas Isotropic KDN uses an isotropic approximation with a single uncertainty scalar per head. Their uncertainty recurrences are Mobius maps, enabling associative scans with logarithmic parallel depth. Across controlled pretraining at 750M and 1.3B parameters, KDN variants consistently improve perplexity and mean downstream accuracy over state-of-the-art linear-attention models.

## 1. 核心问题与整体含义

### 研究动机
- 线性注意力将 token 历史压缩为固定大小的循环记忆，能实现高效的**长上下文推理**与**恒定内存解码**，但其本质问题是**在线记忆编辑**：每个 token 必须在未来查询尚未可知的情况下，决定写入什么内容、以多大强度覆盖已有记忆。
- Delta-rule 模型（如 DeltaNet、Gated DeltaNet、KDA）通过残差写入提升选择性，但写入增益**从当前 token 嵌入直接预测**，**没有显式追踪记忆估计的不确定性**。
- 关键缺口：模型无法区分「一个值得被大额修订的暂定记忆」与「一个已被重复确认、应受保护的稳定记忆」。

### 核心思想/整体含义
- 将循环联想记忆重新表述为**线性-高斯状态空间模型**，其中隐藏状态为潜在的非平稳键-值映射。
- 在此架构下，卡尔曼滤波器是**最优递归估计器**；Delta 规则更新恰好是卡尔曼更新的特例。
- 通过显式传播**记忆状态 + 不确定度（协方差）**，使得每次写入的强度由累积证据和观察可靠性决定——这是该论文的统一理论贡献。

## 2. 方法论

### 2.1 卡尔曼联想记忆（Kalman Associative Memory）
- 模型假设：隐藏关联状态 $\tilde{S}_t$ 按下列方程演化，同时每个 token $(k_t, v_t)$ 是对该映射在方向 $k_t$ 上的一个带噪观测：

$$\tilde{S}_t = D_t \tilde{S}_{t-1} + W_t, \quad W_t \sim \mathcal{N}_{col}(0, \Omega_t)$$  

$$v_t = \tilde{S}_t^\top k_t + e_t, \quad e_t \sim \mathcal{N}(0, r_t I_{d_v})$$

- 通过卡尔曼滤波递归地计算后验均值/协方差，得到（Proposition 3.1）：
  - **预测步**：$\hat{S}_t = D_t S_{t-1}$，$\hat{P}_t = D_t P_{t-1}D_t^\top + \Omega_t$
  - **更新步**：$S_t = \hat{S}_t + \kappa_t(v_t - \hat{S}_t^\top k_t)^\top$，$P_t = (I - \kappa_t k_t^\top)\hat{P}_t$
  - **卡尔曼增益**：$\kappa_t = \frac{\hat{P}_t k_t}{r_t + k_t^\top \hat{P}_t k_t}$
- 关键发现：DeltaNet、Gated DeltaNet、KDA 对应卡尔曼公式在以下特例下退化的结果：
  - 将 $\hat{P}_t$ 替换为各向同性代理 $\hat{b}_t I$，增益退化为标量 $\beta_t k_t$；
  - 分别对应过程模型 $D_t = I$（DeltaNet）、$D_t = \alpha_t I$（GDN）、$D_t = \text{diag}(\alpha_t)$（KDA）——它们**共享相同的测量模型与残差写入，仅差在记忆预测上，并均省略不确定性追踪**。

### 2.2 对角 KDN（Diagonal KDN）
- 约束：$P_t = \text{diag}(p_t)$、$D_t = \text{diag}(\alpha_t)$、$\Omega_t = \text{diag}(\omega_t)$。
- **问题**：精确一阶后验协方差 $P_t^{\star} = (\lambda P^{-1} + k_t k_t^\top/r_t)^{-1}$ 是稠密矩阵，会离开对角族。
- **解决方案**：在线平均场变分推断（Proposition 4.1）：每次更新后将精确后验投影回对角高斯族（最小化反向 KL）。
- 结果（Proposition 4.2）：
  - 不确定性递推简化为**逐通道莫比乌斯映射（Möbius map）**，可以用 2×2 矩阵与结合前缀扫描（associative scan）实现，并行深度为对数级。
  - 增益：$\kappa_t = \frac{\hat{p}_t \odot k_t}{r_t + \sum_i \hat{p}_{t,i}k_{t,i}^2}$
  - 内存更新为仿射扫描：$S_t = (I - \kappa_t k_t^\top)D_t S_{t-1} + \kappa_t v_t^\top$
- **信息缩放（information scaling）**：由于对角投影会丢弃方向相关性，导致对未来覆盖过度自信，引入缩放因子 $\mu$：
  $$u_t = \frac{\mu}{r_t} k_t \odot k_t, \quad p_t = \frac{\hat{p}_t}{1 + u_t \odot \hat{p}_t}$$
  - 该缩放不会改变当前写入，但按分析可**单调降低未来的有效写入强度**，起到保护已存储关联的作用。

### 2.3 各向同性 KDN（Isotropic KDN）
- 进一步压缩不确定性状态至单标量/头：$P_t = b_t I$。
- 使用两次投影：预测后用**Frobenius 最近各向同性矩阵**，条件更新后采用**反向 KL 最小化/Variational update**（Proposition C.1）。
- 增益为标量形式但源于不确定性：
  $$\beta_t = \frac{\hat{b}_t}{r_t + \hat{b}_t \|k_t\|_2^2}$$
- 不确定性递推同样是**标量莫比乌斯映射**，支持扫描并行。

### 2.4 硬件高效实现
- 两阶段分块（chunkwise）算法：
  1. **增益阶段**：用莫比乌斯扫描并行计算所有卡尔曼增益；
  2. **内存阶段**：增益就绪后，内存更新为输入无关的非对称 Delta 规则，用 **compact-WY transform** 求解。
- 分块长度为 $C_g = 256$（增益），$C_m \in \{32, 64\}$（内存），在 fp32 下做归一化防溢出。

## 6. 主要结论与发现

1. **理论统一**：Delta-rule 模型是卡尔曼联想记忆的「固定增益、无协方差」特例，不确定性是它们缺失的状态变量。
2. **实证提升**：在 750M/50B 与 1.3B/100B 上，Iso-KDN 与 Diag-KDN 的 WikiText/LAMBADA 困惑度及六任务平均准确率一致优于所有评估的循环基线（KDA、Mamba-3、GDN-2 等）。
3. **检索能力突出**：Diagonal KDN 在 RULER 聚合分数上取得两规模纯循环组最高，尤其在 S-NIAH-3（长程多跳）上优势明显，说明逐通道不确定性对受干扰下的记忆保护有实际帮助。
4. **信息缩放的作用**：$\mu$ 是「未来写入保护」旋钮而非「当前写入增强」旋钮；$\mu = d_k$ 在部分指标上最优。
5. **效率与实用性**：不确定性递推坍缩为莫比乌斯映射后支持对数深度关联扫描；Iso-KDN 吞吐接近 KDA，Diag-KDN 接近 GDN-2 并保持线性缩放；各向同性 KDN 几乎无额外推理开销。

## 7. 优点

1. **理论优雅**：将 delta-rule、gating/decay 与卡尔曼滤波统一到一个状态空间骨架中，澄清了三类既有模型的关系与边界。
2. **推导扎实**：对角投影/各向同性投影均在变分推断框架下严格推导（Proposition 4.1/C.1），后验均值在条件于对角预测先验下是精确的。
3. **工程落地性强**：针对 GPU 并行与长序列压缩而设计——莫比乌斯递推 + compact-WY 两阶段分块算法，兼顾表达力与硬件实用性。
4. **实验相对严谨**：在多个维度做了参数匹配的受控对照，并附有写入行为分布的理论解释和实证支撑。
5. **分析深入**："覆盖-保护解耦"分析（附录 B）清楚解释了对角近似的过覆盖风险及信息缩放为何有效，兼具理论洞察与操作指导。

## 8. 不足与局限

1. **近似仍非精确最优**：对角的平均场投影丢弃键方向相关性，即使加入信息缩放依旧无法完全复现稠密协方差的效果；各向同性变体更退化为标量增益，理论表达力弱于精确滤波。
2. **算力信息缺失**：未报告训练集群的 GPU 型号/卡时等关键资源需求，不利于复现与效率评估。
3. **实验规模偏小**：最大仅 1.3B/100B，消融实验未覆盖 1.3B 规模；对于"更强的下游/长上下文能力"结论，需要在更大模型（如 7B+）与更长上下文上做更多验证。
4. **统计显著性缺失**：无多种子重复实验与方差报告，难以判断某些紧邻指标的差异是否稳定。
5. **混合架构收益不明显**：混合（+SWA）设置下 KDN 的优势较纯循环组缩小，甚至在部分列上被 KDA+SWA 追近/反超；说明不确定性感知的收益在已有滑窗注意力补偿时可能被稀释。
6. **框架适用范围**：观测噪声 $r_t$、过程噪声 $\omega_t$ 的参数化较简单，论文也承认固定两者有时能改善 WikiText 困惑度，说明噪声建模仍有进一步调优空间。
7. **开放方向未解决**：论文承认带旋转的转移算子（如 Mamba-3 的复数/旋转动力学）无法被当前扫描高效支持，精确过滤依然昂贵，未来空间仍大。

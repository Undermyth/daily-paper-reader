## 摘要
自注意力使大语言模型能够以细粒度、依赖查询的方式访问上下文，但稠密的 token 交互会带来二次方的预填充成本，以及随上下文长度增长的键值缓存。因此，研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动态和异构机制组合。本综述将这些发展作为模型内部的上下文记忆进行分析。我们引入一个五维视角——记忆表示、记忆更新、访问、读出与整合——分别描述表示了什么、如何变化、什么可被查询、如何被读取，以及读出结果如何形成输出。该视角比较了相互重叠的研究路线，而不强加单一计算模型。我们使用来自 14 个主要模型谱系和 11 个高性能开放权重端点的 59 条发布级记录，重建机制层面的发展和架构采纳。第一，显式记忆和循环状态方法保留了不同的接口，但越来越多地控制重叠的记忆功能。第二，异构架构越来越多地跨网络深度进行协调：逐层组合将互补的记忆处理分布到不同表示阶段，而跨层复用则将选定的记忆和路由产物向前传递。因此，深度成为构建和管理上下文记忆的一个维度。第三，这些发展催生了一个有状态的多维记忆路由假说：持久记忆按时间范围、网络深度、基底类型和表示粒度进行组织，而协调的稀疏写入与稀疏读取决定了什么被维持，以及什么对每个查询有所贡献。总体而言，高效序列架构设计越来越关注上下文记忆的组织、生命周期和选择性使用，而非孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

## 2. 方法论：核心思想与关键细节

### 2.1 核心思想：五维记忆中心分析透镜

将任何序列机制视为"维护并使用内部记忆"的系统，围绕五个功能性问题展开（注意：是**功能角色**而非必须独立实现的五个模块，单一操作可同时承担多个角色）：

- **记忆表示（Memory Representation）**：过去哪些信息仍被保留、以何种形式、何种粒度、多大容量。用记忆模式 ρ 与状态空间 Mρ 表示，Mt ∈ Mρ。
  - 两个关键属性：**历史覆盖度**（多少前序序列可影响记忆）与**可寻址性**（某历史单元是否仍可被单独选取）。
- **记忆更新（Memory Update）**：新输入如何写入、保留、删除或修正旧记忆。抽象形式 M⁺ₜ = Update_ρ(M⁻ₜ, xₜ)，覆盖追加式 KV、循环状态转移、定容槽位合并、受控擦写。
- **访问（Access）**：哪些已表示的记忆单元/状态接口对当前查询"合格"。Ct = Access_ρ(qₜ, M̂ₜ)。可以是全部因果位置、结构约束子集、路由 Top-k、或循环状态接口。
- **读出（Readout）**：合格信息如何被加权、解码、聚合。rₜ = Readout_ρ(qₜ, Ct)。如 Softmax 归一化加权、核化状态收缩、结构化投影。
- **整合（Integration）**：一个或多个完成的读出如何变换/协调为模块输出。oₜ = Integration_ρ(rₜ; xₜ)。如多头拼接+输出投影、门控、路由、异构路径融合。

**关键区分**：Access 回答"什么可以被读"，Readout 回答"合格信息如何被读"；这使"改变候选集"与"改变读出规则"的方法能被分开比较。

### 2.2 五条研究路线与分类原则

- 四条机制中心路线 + 一条组合中心路线：
  - **Softmax Attention**：显式记忆单元 + 归一化查询—键读出。设计重心在表示与更新（MQA/GQA/MLA/跨层共享、有界循环记忆、动态分辨率摘要），以及读出与整合调制（Talking-Heads、DCMHA、Differential Attention、FoX、MoH、Gated Attention）。
  - **Sparse Attention**：保留显式内容记忆，限制每个查询的候选集。设计重心在 Access，按"证据来源"分为结构约束、自路由、辅助代理路由，并叠加"时间/跨层复用"这一横切属性。
  - **Linear Attention**：用循环关联状态替代逐 token KV 历史。设计重心在表示与更新，更新规则可分解为**保留/衰减、擦除/修正、写入/提交**三类角色。
  - **State Space Models**：结构化循环状态，从时不变结构化动态（S4/S4D/S5，HiPPO 初始化）到输入条件化动态（Mamba 选择性扫描、Mamba-2 SSD 对偶），再到读—写接口与更新几何的精化（Mamba-3 MIMO、MIMOMamba、HADES、MuonSSM）。
  - **Hybrid Architecture**：按组合粒度分为层间、头间、分支间、token 间四类。

### 2.3 关键技术细节举例

- **Softmax 侧**：KV 缓存规模 M_KV = 2·B·T·L_KV·H_KV·d_h·s；头共享（MQA→GQA）、通道压缩（MLA 低秩 latent，RoPE 需分离内容/位置分量）、层共享（CLA）分别降低 H_KV、d_h、L_KV，但**不改变对 T 的线性依赖**。长上下文下转向定容循环记忆（RMT、TransformerFAM、Trellis、Lattice）与动态分辨率记忆（KSA、HCA Core）。
- **稀疏侧**：统一选择式 Iₜ = Select(eₜ, Uₜ; bₜ)，随后候选局部 Softmax。代表：MoBA（块均值键打分 + Top-k）、NSA（压缩分支概率复用为路由证据 + 三路门控融合）、DSA（Lightning Indexer，MQA 式索引头 + KL 蒸馏）、MSA（每 GQA 组一个索引头，token 打分→块级 max-pool 选择）、QSA（对索引键做 micro-block 平均池化，**同时缩短索引扫描**）、CSA（内容与索引键均压缩）。复用类：ReTopK（时间复用）、TidalDecode/Kascade/IndexCache（跨层索引复用）、YOIO/CLSA、CSA2（Full/Reindex/Reuse 三模式）、HySparse/HySparse2。
- **线性注意力侧**：统一更新式 S̄ₜ₋₁ = αₜ ⊙ Sₜ₋₁，Sₜ = S̄ₜ₋₁ − Eₜ + Wₜ。衰减从无衰减→固定标量/通道→输入依赖；擦除从无显式擦除→耦合式 delta 修正（DeltaNet）→解耦擦除（RWKV-7、GDN2、EDA）；写入从直接写→受控修正写→擦写解耦。另给出**等价逐 token 优化目标**视角：Sₜ = S⁻ₜ − ∇Lₜ(S⁻ₜ)，早期方法为相关性最大化，delta 类为重构误差最小化。
- **容量/时间扩展**：SSE（分组稀疏状态扩展）、SDM（平坦行记忆 + PKM 读写路由）；Log-Linear（确定性多尺度 O(log t)）、DLA（内容自适应分段，Mₜ ≤ K）、MHLA（固定粒度平坦块）。
- **前向假说**：持久记忆地址空间 Aₜ = Tₜ × L × S × G（时间范围 × 网络深度 × 基底类型 × 表示粒度），配合**稀疏写入**（Wₜ ⊆ Aₜ）与**稀疏读取**（Ct = Access、rt = Readout、ot = Integration），形成"有状态多维记忆路由"——类似多维 Memory-MoE，但区别在于**持久性**：写路由决策会影响未来查询可用的信息，从而引入延迟依赖、陈旧性控制、长程信用分配等问题。

  - 前沿比较：11 个端点（Table 18）。

  - **无消融实验、无控制变量实验**（因非实验性论文）。
- **充分性**：
  - 优点：覆盖面广，时间跨度长（2022→2026.09），同时给出机制层与架构层的对照；对不可比对象（如 leaderboard 分数受规模、训练、后训练、推理预算影响）明确声明不做因果归因。

## 6. 主要结论与发现

- **机制层面（综合 1）**：显式记忆与基于状态的方法保留**不同的记忆接口与计算形式**，但两者都从各自初始重心向更广的功能集扩张，**显式控制范围日益重叠**——收敛点在于"对表示/更新/访问/读出/整合的显式设计控制范围"，而非共享的记忆基底或计算机制。
  - 显式记忆路线：从表示与访问效率扩展到有界更新、读出调制、输出协调。
  - 状态路线：从状态表示与循环更新扩展到多记忆单元、选择性访问、更丰富读出、协调整合。
- **架构层面（综合 2）**：**网络深度成为上下文记忆构建与管理的新兴维度**。
  - 层间组合决定"每一深度执行何种记忆处理"（能力放置）；
  - 跨层复用决定"哪些记忆/路由产物在深度上持续存在、何时复用或刷新"（产物生命周期）。
  - 盘点显示：59 条记录中 58 条可分类，32 条为单一注意力族，26 条为 Hybrid；Hybrid 占比从 2022–2023 的 0/6 升至 2024–2025 的 9/25、2026 的 17/27；跨层复用仅见于 5 条记录（GLM-5.2、GLM-5.3、DeepSeek-V4.1-Flash、LongCat-2.0、LongCat-Flash-Lite-Sparse）。
- **注意力设计是多样化而非收敛**：GQA 仍是广泛骨干，MLA 形成第二条主线，稀疏访问与循环状态并存；同一谱系还会转向（DeepSeek：MLA→MLA-based sparse→CSA/HCA→CSA2；Qwen：MHA/GQA→循环状态+全注意力→+稀疏；MiniMax：Lightning/Softmax 混合→全 GQA→dense/sparse；LongCat：MLA→LSA）。
- **前沿比较**：11 个高性能开放权重端点架构异质，Hybrid 显著但非普遍（K2-Horizon 用全 GQA，GLM-5.3 用单一 DSA 族）；**所有入选架构都保留了显式 token 检索路径**，说明循环状态与稀疏目前是**补充**而非统一替代 token 可寻址注意力。
- **稀疏注意力的现状判断**：训练无关的稀疏本质是近似、存在训练—推理失配，预算下降即质量退化；**原生训练**的稀疏（路由器端到端训练、预算匹配证据密度、加速比计入证据构建与索引流量）可达到与稠密相当、长上下文偶有超越的质量，但这一平价是**有条件的**。
- **总体结论**：高效序列架构设计的核心已从"优化孤立的 Attention 算子"转向"上下文记忆的联合组织、生命周期与选择性使用"。

## 7. 优点

- **分析框架创新**：五维透镜（表示/更新/访问/读出/整合）提供了跨机制族的共同词汇，能同时描述 Softmax、稀疏、线性、SSM 与混合架构，且不把它们化约为单一计算模型；有效区分了"改变候选集"与"改变读出规则"这类此前常被混为一谈的改动。
- **双重经验证据互补**：纵向盘点（时间维度、架构演进）与冻结前沿比较（横截面、性能前沿）互为补充，避免单一视角偏差；数据来源为官方文档，可追溯（Table S1 逐条给出出处）。
- **机制细节丰富且统一化**：把线性注意力的更新统一分解为保留/擦除/写入，并给出**等价逐 token 优化目标**（相关性最大化 vs 重构误差最小化）这一统一解释，把 DeltaNet、GDN、KDA、DeltaProduct、EDA 等放在同一坐标系中对比，洞察力强。
- **横切属性的显式建模**：把"时间/跨层复用"从方法族中剥离为**生命周期属性**，使其可叠加在任意证据来源之上，比传统分类更贴合工程现实。
- **对评估规范的批判性提示**：反复强调应同时报告质量、持久记忆、预填充与解码成本、检索行为、更新稳定性、路由开销与实测硬件利用率；指出"数值稀疏≠实际节省"（门控/路由需内核支持才能真正跳过计算），具有很强的实践指导意义。
- **前沿假说具可测试性**：多维记忆路由假说配有四条渐进式可落地研究方向（工作负载感知的差异化表示、非对称记忆构建与检索、增量记忆生命周期与可复用产物、任务条件化的记忆—计算联合路由），每条都给出已有部分证据与具体扩展路径。
- **坦诚的方法论声明**：明确非穷举、非市场份额加权、不做因果归因，学术态度严谨。

## 8. 不足与局限

- **无原创实验与定量验证**：作为综述，未提供任何自建实验、消融或受控对比；机制层面的复杂度均为理论量级，缺乏实测资源数据（GPU、时长、FLOPs、延迟）。
- **盘点样本的

选择偏差与代表性不足**：作者自述为"有意策展"，59 条记录中大量节点来自中国厂商（阿里、DeepSeek、月之暗面、MiniMax、美团 LongCat、智谱等）的公开技术报告，而部分闭源前沿模型（如未披露架构的 GPT/Gemini/Claude 系列）因"架构披露不足"被排除或标记为 Undisclosed，导致盘点结果对**披露充分的开源/开放权重谱系存在系统性过采样**，对闭源前沿的架构演进趋势可能失真。
- **五维透镜的边界模糊风险**：论文虽强调五维是"功能角色"而非独立模块，但在具体归类时仍存在歧义——例如"访问"与"读出"在某些核化线性注意力或路由式方法中难以截然分开，DSA 的 Lightning Indexer 究竟算 Access 还是 Readout 存在解释空间；分类一致性缺乏编码者间信度检验（no inter-rater reliability）。
- **对训练动力学与数据因素的淡化**：全文以架构机制为分析主轴，但作者在讨论稀疏注意力"训练无关 vs 原生训练"平价时已触及——质量差异很大程度上来自**训练配方、数据分布、后训练对齐**，而非注意力算子本身。论文未系统讨论这些混淆变量，可能导致读者高估架构选择的独立贡献。
- **成本模型停留于理论量级**：复杂度分析多为渐近阶（如 O(L²d)、O(Ld_KV)），但实际部署中**内存带宽、内核融合、批处理形态、prefill/decode 比例**往往主导真实延迟；论文虽在评估建议中列出这些维度，却未提供任何量化框架或实测基准。
- **缺乏统一的机制比较协议**：综述梳理了约 15 张对照表，但各表维度不一（有的按衰减、有的按擦除、有的按写入），未形成一套可跨路线打分的统一坐标；读者难以据此判断"某 Softmax 变体 vs 某线性注意力变体"在同一工作负载下的相对优劣。
- **假说的可证伪性未被操作化**：多维记忆路由假说配有四条研究方向，但未给出最小可验证实验设计、评价指标或预期效应量，仍偏概念性，距可执行的 research agenda 有距离。
- **时效性风险**：证据集冻结于 2026-09-22，而该领域迭代极快（论文自身盘点的 2026 年记录已占 27 条），结论可能在数月内部分过时；综述未提供持续更新机制。
- **图表与文本的可核对性**：作者提示"模型家族内部变体可能产生多个节点，图表并非与发布记录一一对应"，这虽诚实，但也增加了读者回溯核验的难度。

## 9. 对领域的影响与开放问题

- **概念贡献**：本文最有价值的贡献不在于罗列方法，而在于提出一个**跨机制族的共享分析语言**。"上下文记忆"作为统一对象、"表示—更新—访问—读出—整合"作为功能分解、"持久性"作为区别于 Memory-MoE 的关键属性，为后续研究提供了可复用的概念脚手架。
- **实践启示**：
  - 架构选择不应只看"注意力是否高效"，而应看**记忆接口的设计是否与工作负载匹配**（短上下文高吞吐 vs 长上下文检索密集 vs 流式持续输入）；
  - "数值稀疏 ≠ 实际加速"，路由与门控必须有内核级支持才能兑现理论收益；
  - 跨层复用作为横切属性，是当前被低估但已在少数前沿模型中显现的优化维度。
- **开放问题（由本文内容可自然引出）**：
  - 显式 token 记忆与循环状态的最优**混合比例与放置位置**如何随任务、上下文长度、推理预算变化？
  - 持久记忆的**陈旧性控制与长程信用分配**如何形式化？写入路由的延迟依赖是否可训练？
  - 如何建立**统一的评测协议**，同时报告质量、持久记忆大小、prefill/decode 成本、检索行为与硬件利用率？
  - 原生训练稀疏的"条件性平价"边界在哪里——在何种预算、序列长度、任务类型下会失效？
  - 跨层复用的**生命周期管理**（何时复用、何时刷新、刷新代价）是否存在可学习的最优策略？

## 10. 总体评价

这是一篇**定位清晰、框架创新、证据扎实但非实验性**的综述。其核心价值在于：把 2022–2026 年间纷繁的注意力与序列混合器进展，收束到"上下文记忆的联合组织与生命周期"这一统一视角下，并用"纵向架构盘点 + 横截面前沿比较"两套证据集加以锚定。五维透镜与线性注意力更新的三类角色分解（保留/擦除/写入）、等价优化目标视角、以及"深度作为记忆管理新维度"的判断，均具有较高的分析深度与迁移价值。

其局限也与其定位共生：无原创实验、无实测算力、样本存在披露偏差、分类存在主观空间、成本模型停留理论。因此，**它更适合作为研究者的"地图与词汇表"**——用于快速建立领域全景、理解机制间的功能对应关系、发现尚未被系统化的横切维度；而**不适合作为"某机制优于某机制"的选型依据**，作者本人对此亦有明确声明。

总体而言，在高效序列建模综述已相当密集的当下，本文凭借**统一分析框架 + 双证据集 + 坦诚的方法论边界声明**，仍占据了差异化且难以替代的位置。

## 摘要
线性注意力模型已成为标准注意力的高效替代方案，但有效管理其固定大小的循环记忆仍然颇具挑战。为改进记忆，近期研究探索了两条不同的方向：用于精确校正与键相关联的值的 delta 规则变体，以及诸如 Gated Slot Attention 之类的槽式架构，以两阶段方式建模键记忆与值记忆。我们观察到这两个方向是互补的——delta 规则提供了有效的记忆校正，而两阶段结构则提供了一种自然的方式来对联想的两侧进行操作。基于这一洞见，我们提出了一种新的 Gated Oja Rule 用于键侧校正，并通过解耦的擦除与写入控制将其扩展为 Gated Oja Rule-2。随后，我们提出了 Gated Slot Attention-2（GSA2），它通过共享的潜在槽将用于键侧校正的 Gated Oja Rule-2 与用于值侧校正的 Gated Delta Rule-2 相结合。我们进一步推导出一种硬件高效的分块算法以支持并行训练。实验表明，GSA2 在多个基准上持续优于强线性注意力基线，同时保持线性时间的序列建模与常量内存的循环解码。

## Abstract
Linear attention models have emerged as efficient alternatives to standard attention, but effectively managing their fixed-size recurrent memory remains challenging. To improve memory, recent work has explored two distinct directions: delta-rule variants for precise correction of values associated with keys, and slot-based architectures such as Gated Slot Attention for modeling key and value memories in two stages. We observe that these directions are complementary--the delta rule provides effective memory correction, while the two-stage structure provides a natural way to operate on both sides of an association. Building on this insight, we introduce a new Gated Oja Rule for key-side correction and extend it with decoupled erase and write control to obtain Gated Oja Rule-2. We then introduce Gated Slot Attention-2 (GSA2), which combines Gated Oja Rule-2 for key-side correction with Gated Delta Rule-2 for value-side correction through shared latent slots. We further derive a hardware-efficient chunkwise algorithm for parallel training. Experiments demonstrate that GSA2 consistently improves over strong linear-attention baselines across benchmarks while retaining linear-time sequence modeling and constant-memory recurrent decoding.

- **两条已有路线**：
  - **Delta 规则变体**：如 DeltaNet、Gated DeltaNet、KDA、GDN2，主要对“键寻址到的值”进行显式纠错，侧重值侧校正。
  - **槽式两阶段架构**：如 Gated Slot Attention（GSA），用共享 latent slots 分别维护键记忆和值记忆，但主要依赖门控累加，缺少显式纠错。
- **核心洞察**：Delta 规则提供有效记忆校正，两阶段槽结构提供对联想“两侧”操作的自然接口，二者互补。
- **研究问题**：能否为槽式联想记忆的两个阶段同时配备互补的纠错更新？即键侧和值侧分别校正。
- **整体含义**：论文提出 GSA2，在 GSA 的共享 latent slots 上，第一级用 Gated Oja Rule-2 做键侧校正，第二级用 Gated Delta Rule-2 做值侧校正，从而形成“双边联想记忆校正”。

## 2. 方法论
### 2.1 核心思想
- 将键–值联想拆成两阶段：
  - 键 → 共享 latent slot：使用 **Gated Oja Rule-2** 校正键侧。
  - 共享 latent slot → 值：使用 **Gated Delta Rule-2** 校正值侧。
- 共享 slot 表示 \(w_t\) 同时作为第一阶段的“值侧向量”和第二阶段的“寻址键”，耦合两个记忆。

### 2.2 Gated Oja Rule 与 Gated Oja Rule-2
- **动机**：Delta 规则用键校正值；Oja 规则反过来，用值校正键。
- **Oja 校正目标**：
  \[
  L^K_t(S)=\frac12\|k_t-S^\top v_t\|_2^2
  \]
  即用值预测键，并最小化键预测误差。
- **基础 Gated Oja Rule**：
  \[
  S_t=(I-\beta_t v_t v_t^\top)\mathrm{Diag}(\alpha_t)S_{t-1}+\beta_t v_t k_t^\top
  \]
  其中 \(\alpha_t\) 为通道级衰减，\(\beta_t\) 为更新强度。
- **Gated Oja Rule-2**：仿照 GDN2 解耦擦除与写入：
  \[
  S_t=(I-v_t(b_t\odot v_t)^\top)\mathrm{Diag}(\alpha_t)S_{t-1}+v_t(c_t\odot k_t)^\top
  \]
  \(b_t\) 控制值侧擦除，\(c_t\) 控制键通道写入。
- **定位**：OJA2 与 GDN2 互补：OJA2 校正“值关联的键”，GDN2 校正“键关联的值”。

### 2.3 GSA2 两阶段共享槽更新
- 状态：
  - \(S^{(1)}_t\in\mathbb{R}^{M\times D_k}\)：键–槽关联。
  - \(S^{(2)}_t\in\mathbb{R}^{D_v\times M}\)：槽–值关联。
  - \(w_t\in\mathbb{R}^M\)：共享 latent-slot 表示。
- **第一级：键侧 OJA2 校正**
  \[
  S^{(1)}_t=
  (I-w_t(b^{(1)}_t\odot w_t)^\top)
  \mathrm{Diag}(\alpha^{(1)}_t)S^{(1)}_{t-1}
  +w_t(c^{(1)}_t\odot k_t)^\top
  \]
- **第二级：值侧 Gated Delta Rule-2 校正**
  \[
  S^{(2)}_t=
  S^{(2)}_{t-1}\mathrm{Diag}(\alpha^{(2)}_t)
  (I-(b^{(2)}_t\odot w_t)w_t^\top)
  +(c^{(2)}_t\odot v_t)w_t^\top
  \]
- **读取**：
  \[
  h_t=\mathrm{silu}(S^{(1)}_t q_t),\quad o_t=S^{(2)}_t h_t
  \]
  GSA2 用 SiLU 替代 GSA 的 softmax，使校正后的槽可独立贡献，而非在归一化单纯形上竞争。
- **门控设计**：两阶段拥有独立的衰减、擦除、写入门，将解耦擦写控制扩展到两个记忆阶段。

### 2.4 硬件高效 chunkwise 训练
- 直接采用 GDN2 的硬件高效实现处理值侧 Gated Delta Rule-2。
- 为 Gated Oja Rule 与 Oja Rule-2 推导对应的 WY/UT 风格 chunkwise 形式。
- 利用 rank-one 状态变换的紧凑 WY 表示，将通道级衰减吸收进因子，辅助矩阵通过三角求解与 UT 变换计算。
- 分块边界更新和块内输出均由稠密矩阵乘法主导，因此保留线性时间序列建模、常数内存循环解码与并行训练能力。
- 架构上：GSA2 token mixer 与 MLP、Sliding-Window Attention 交错，形成 hybrid backbone；q/k/v 经线性投影、短卷积、SiLU，q/k 做 L2 归一化；共享槽分支使用低秩投影、短卷积、SiLU、L2 归一化。

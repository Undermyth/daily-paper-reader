## 摘要
线性注意力通过将历史压缩为循环状态，实现了高效的长上下文自回归解码，但这种压缩可能使得对稀疏且遥远信息的选择性访问变得困难。现有的基于分块的扩展提升了记忆容量，然而学习到的分块混合系数可能相对于输入内容保持固定，因此无法针对每个查询自适应地访问历史。我们提出混合线性注意力（HLA），一种面向 Gated DeltaNet（GDN）的查询相关分块级注意力机制。HLA 将每个已完成的分块表示为精确的仿射状态转移，并从紧凑的、自注意力池化的代表中计算内容相关的路由门控。每个门控将相应的历史转移与恒等映射进行插值，从而同时控制该分块的加性记忆及其对更早状态的变换。有效支撑正则化进一步鼓励稀疏推理中的集中路由。我们在预训练适配和从头训练两种设置下评估 HLA。在从 0.8B 到 9B 的 Qwen3.5 模型上，HLA 相比原生 GDN 和固定分块混合持续取得提升，在 LongBench-V2 上最高提升 5.57 个百分点，在 RULER 上提升 3.97 个百分点。在受控的从头训练 1.3B 设置中，使用 4K 上下文训练 100B token，HLA 还在 4K 到 32K 范围内提升了 RULER 性能，且增益从 4K 时的 0.83 个点增加到 32K 时的 4.22 个点。这些结果表明，循环记忆的查询相关组合能够改善长上下文建模，并且在使用紧凑的逐分块仿射摘要的同时，在训练上下文之外仍然有效。项目页面：https://caesarhhh.github.io/hla/

## Abstract
Linear attention enables efficient long-context autoregressive decoding by compressing history into recurrent states, but this compression can make selective access to sparse and distant information difficult. Existing chunk-based extensions increase memory capacity, yet learned chunk-mixing coefficients may remain fixed with respect to input content and therefore cannot adapt historical access to each query. We introduce \emph{Hybrid Linear Attention} (HLA), a query-dependent chunk-level attention mechanism for Gated DeltaNet (GDN). HLA represents each completed chunk as an exact affine state transition and computes content-dependent routing gates from compact, self-attentively pooled representatives. Each gate interpolates the corresponding historical transition with the identity map, controlling both the chunk's additive memory and its transformation of earlier states. Effective-support regularization further encourages concentrated routing for sparse inference. We evaluate HLA under both pretrained adaptation and from-scratch training. Across Qwen3.5 models from 0.8B to 9B, HLA consistently improves over native GDN and fixed chunk mixing, with gains of up to 5.57 percentage points on LongBench-V2 and 3.97 points on RULER. In a controlled from-scratch 1.3B setting trained for 100B tokens with a 4K context, HLA also improves RULER performance from 4K to 32K, with gains increasing from 0.83 points at 4K to 4.22 points at 32K. These results demonstrate that query-dependent composition of recurrent memory improves long-context modeling and remains effective beyond the training context while using compact per-chunk affine summaries. ## 2. 方法论

### 2.1 核心思想
- 将 GDN 的递归改写为**逐块（chunk）精确仿射状态转移**，并让每个查询自行决定每个历史分块的转移如何作用于当前状态：用查询相关的 sigmoid 门在“原始分块转移”与“恒等映射”之间插值。
- 关键差异：门控不只是缩放分块的读出（readout），而是同时调制分块的**加性记忆项 Bⱼ** 和它对更早状态的**乘性变换 Aⱼ**，从而让历史 GDN 转移的组合方式显式依赖当前查询。

### 2.2 关键技术细节与流程
- **Token 级 GDN 转移**：`S_t = A_t S_{t-1} + B_t`，其中 `A_t = exp(g_t)(I − β_t k̄_tᵀ k̄_t)`（衰减 + delta 修正），`B_t = β_t k̄_tᵀ v_t`。
- **分块化**：将长度 T 的序列切成 N=⌈T/L⌉ 个块，块内 token 级仿射映射的复合仍为仿射映射，因此整块效果可精确摘要为 `(A_j, B_j)`，满足 `S_j = A_j S_{j-1} + B_j`。
- **池化代表（pooled representatives）**：每个已完成分块划分为 P=L/p 个不重叠窗口（窗口长 p），对窗口内卷积前的 key 做**窗口内自注意力 + 行均值池化 + 输出投影**，得到每个窗口一个代表键 `k̄ʳ_{j,b}`（引入可学习投影 W^rQ、W^pK、W^pV、W^pO）。池化虽为双向，但只在分块完成后使用；当前分块只依赖其因果前缀。
- **分块级注意力权重**：查询与代表的相似度用 **log-mean-exp** 聚合为 `s_{i,j}`，再取 `w_{i,j} = σ(s_{i,j})`。采用独立 sigmoid 而非 softmax 归一化，因为 GDN 是状态转移的**串行复合**而非输出混合，不应有 sum-to-one 约束。当前分块权重固定为 1，未来分块掩码为 0。
- **查询条件化的历史状态构造**：从 `S_{i,0}=0` 起按时间顺序应用
  `S_{i,j} = [(1 − w_{i,j})I + w_{i,j} A_j] S_{i,j−1} + w_{i,j} B_j`，
  再乘上当前分块的因果前缀转移 `(A_{c(i),≤i}, B_{c(i),≤i})` 得到 `S^HLA_i`，最后沿用原生 GDN 读出与门控归一化/输出投影。当所有权重为 1 时精确退化为原始 GDN。
- **训练目标**：`L = L_LM + λ_b L_budget + λ_s L_support`。`L_budget` 惩罚历史路由总质量 `G_i` 超预算 K_b；`L_support` 基于 Hill 的 order-2 有效数 `K_eff = (Σπ²)⁻¹`，惩罚有效支撑超过 K_s，鼓励路由集中（两项均排除当前分块）。
- **推理稀疏化**：训练使用连续权重；推理时把低于阈值 θ=0.1 的权重置零且**不重新归一化**，零权重的恒等转移可被精确跳过，从而降低仿射状态的内存访问与计算。但被跳过的分块摘要仍需缓存，因为后续查询可能赋予不同权重。
- **复杂度**（单层单头，d_k=d_v=d）：预填充 `O(Tpd + TNPd + TMd²)`；解码 `O(pd + NPd + Md²)`；缓存 `O(N(d² + Pd) + Ld)`。附录给出训练/预填充（Algorithm 1）与动态解码（Algorithm 2）伪代码，解码时历史扫描需**从新到旧**。

- **效率**：分块仿射状态存储随分块大小近似反比下降（L=128 与 KV cache 持平，256/512/1024 分别为 50%/25%/12.5%）；默认 L=256 在保持最佳精度的同时将历史状态存储减半。延迟开销中等：预填充 1.098×–1.149×，解码 1.139×–1.188×，且相对开销随模型增大而下降。

## 7. 优点

- **动机有实证支撑**：用三张诊断图分别量化了 GLA 的累积保留衰减、GDN 的分块贡献衰减、以及固定混合的输入无关性，问题定位清晰。
- **方法设计精巧且“无损”**：把门控施加在**完整仿射转移**（A 与 B 同时调制）而非仅缩放读出，数学上权重全为 1 时精确还原 GDN，是一个优雅的泛化形式；用独立

sigmoid 而非 softmax 也是基于"状态转移是串行复合而非输出混合"的机理判断，而非经验性调参。

- **推理稀疏化具有真实工程价值**：把低于阈值 θ 的权重置零且**不重新归一化**，使零权重分块的恒等转移可被精确跳过，在不改变语义的前提下减少内存访问；同时论文诚实地指出被跳过的分块摘要仍需缓存（因为后续查询可能给出不同权重），没有夸大节省幅度。
- **效率开销披露相对完整**：给出了预填充/解码两个阶段的复杂度公式、实际延迟倍数（1.10×–1.19×）、以及分块仿射状态存储随分块大小的缩放比例，并明确指出"相对开销随模型增大而下降"，便于读者判断部署可行性。
- **从头训练对照实验设计规范**：与 GDN 共享 token 预算、训练上下文、全局 batch 与优化预算，并**主动关闭路由正则**（避免用额外正则项换取不公平优势），这是此类"轻量增强"论文中较难得的严谨处理。
- **长度外推的增益方向符合机理预期**：4K 训练、32K 评测时增益反而扩大（+4.22 点），且单针任务从 11.2 提升到 67.4，说明收益并非来自过拟合训练长度，而是来自路由机制本身对远距离证据的可访问性。
- **机制可解释性分析到位**：不只报精度，还通过远半段贡献占比、贡献加权平均源距离、按距离分桶的检索曲线、逐层贡献图四条独立证据链交叉验证"收益来自远距离历史访问"这一核心假设，且声称对每个被分析层与原始前向做了数值校验。

## 8. 不足与可改进之处

- **与主流混合架构缺乏直接对比**：只对比 Native GDN 与 MHLA，未纳入 softmax 注意力层、3:1 交错式混合架构（如 Kimi Linear、Ring-linear 类方案），因此无法回答"在同等 KV cache 预算下，HLA 是否优于保留少数 softmax 层的做法"这一关键实践问题。
- **消融实验的尺度覆盖不明**：分块大小、池化窗口、内存缩放等消融很可能仅在 0.8B 上进行，结论能否迁移到 9B 或从头训练设定未经验证；论文也未报告消融的多次运行方差或显著性。
- **预训练适配设定存在"冻结骨干"的天然限制**：只训练路由与池化模块，虽有利于低成本验证，但无法说明当骨干与路由联合微调时收益是否会被稀释或放大；这一设定也可能低估 MHLA 的潜力。
- **任务级失败缺乏解释**：VT、CWE、FWE 上 HLA 变差，论文仅以"改进是任务相关的"一笔带过，未分析这些任务（多值聚合、聚合类）与"查询相关稀疏路由"之间的机理冲突——例如多值任务可能恰恰需要均匀而非稀疏的历史访问。
- **推理稀疏化的实际加速未量化**：论文只给出理论上的"可精确跳过"，但没有报告 θ=0.1 时实际被跳过的分块比例，以及稀疏化前后的端到端延迟与显存对比，读者难以评估该机制的净收益。
- **正则化权重敏感性缺失**：λ_b、λ_s、K_b、K_s 均只给单一取值，未做敏感性分析；由于这两项直接控制路由的稀疏程度，其对"精度—效率"权衡的影响应当被系统刻画。
- **资源与可复现性信息不足**：未披露 GPU 型号/数量、总训练时长、能耗，也未提及代码或权重是否开源；从头训练的 100B token 实验无法被独立复现。
- **写作与格式瑕疵**：图 1(c) 标题混用 HLA/MHLA，表 2 出现"79.141"这类异常数字格式，正文与附录的符号定义偶有不一致；标注发表时间为 2026 年 10 月（未来日期），进一步降低了结果的可核查性。

## 9. 与相关工作的定位

- **相对线性注意力家族**：HLA 不改动 GDN 的递归骨架，而是通过"查询条件化的分块转移插值"在其内部增加一层可学习的稀疏路由，属于对现有线性注意力层的**模块化增强**，可与 GLA、GDN、Mamba 类状态空间模型组合。
- **相对混合架构路线**：Kimi Linear、Ring-linear 等通过"少数层保留 softmax 注意力 + 多数层线性注意力"获得表达力，代价是仍保留部分 O(T) KV cache；HLA 走的是"全层线性 + 层内稀疏路由"路线，理论上可将缓存压到 O(N(d²+Pd))，两者是不同权衡点，但论文未做正面比较。
- **相对分块/稀疏注意力**：MHLA 等固定分块混合方案的权重与输入无关，HLA 的关键差异是**查询相关**（跨样本分块模式不同），因此在"同一模型需服务异构查询分布"的场景下更具适应性。
- **相对检索增强（RAG）**：HLA 在模型内部完成稀疏历史选择，无需外部向量库与检索器，路由信号直接由查询驱动，属于"内生检索"范式。

## 10. 总体评价

论文针对线性注意力"表达能力受限于固定尺寸循环状态"这一公认瓶颈，提出了一个动机清晰、数学优雅、工程可行的解决方案。其最大贡献在于把"查询相关的稀疏历史访问"从架构层面（保留 softmax 层）下沉到**层内机制**：用 sigmoid 门在原始分块仿射转移与恒等映射之间插值，既保证权重全 1 时精确退化为 GDN（无破坏性），又通过独立 sigmoid 而非 softmax 尊重了状态转移的串行复合语义。这一设计在 0.8B–9B 四个尺度的预训练适配、以及 1.3B 从头训练的长度外推实验中均取得一致增益，且增益随上下文长度增大而扩大，配合远半段贡献占比、源距离、距离分桶检索曲线等多条证据链，机制归因具有较强说服力。

主要局限在于评测基线的选择偏窄（缺少与 softmax 层/混合架构的正面比较）、消融尺度不明确、以及部分任务上的退化未获解释；此外，训练资源、稀疏化实际加速、正则敏感性等可复现性信息缺失。若后续工作能补齐"同等 KV cache 预算下的横向对比"与"多值/聚合类任务的失败机理分析"，HLA 有望成为线性注意力增强方向上一个被广泛采纳的基线组件。

## 11. 对后续研究的启示

- **门控位置的迁移性**：将"查询相关门控作用于完整状态转移（A 与 B 同时）"这一思路迁移到其他递归结构（Mamba-2、RWKV、RetNet）是否同样有效，是一个低成本的直接验证方向。
- **正则化的理论刻画**：L_budget 与 L_support 分别从"总路由质量"和"有效支撑数"两个角度约束稀疏性，其与注意力熵、Hill 有效数之间的理论联系值得进一步形式化。
- **稀疏化与硬件协同**：零权重分块可精确跳过这一性质与 block-sparse 内核天然契合，若能与分块式 KV/状态缓存管理（如 PagedAttention 类方案）结合，可能带来超出论文报告的实际加速。
- **失败案例的诊断价值**：VT/CWE/FWE 的退化提示"稀疏路由"与"需要均匀聚合多值证据"的任务之间存在张力，针对这一冲突设计自适应稀疏度（而非全局固定 K_b/K_s）可能是自然的下一步。
- **评测协议的改进**：未来此类工作宜同时报告"精度—缓存—延迟"三元帕累托前沿，而非仅报精度增益与单一延迟倍数，以便与混合架构在同一坐标系下比较。

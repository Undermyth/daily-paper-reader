## 摘要
自注意力使大语言模型能够以细粒度、依赖查询的方式访问上下文，但密集的 token 交互会带来二次方预填充成本，以及随上下文长度增长的键值缓存。因此，研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动力学以及异构机制组合。本综述将这些进展作为模型内部的上下文记忆进行分析。我们引入一个五维视角——记忆表示、记忆更新、访问、读出与集成——用以描述表示什么、如何变化、哪些内容可被查询、如何被读取，以及读出如何形成输出。这一视角比较了相互重叠的研究路线，而不强加某一种计算模型。我们利用来自 14 个主要模型谱系和 11 个高性能开放权重端点的 59 条发布级记录，重构机制层面的发展和架构采用。第一，显式记忆方法与循环状态方法保留了不同的接口，但日益控制着相互重叠的记忆功能。第二，异构架构日益在网络深度上进行协调：逐层组合将互补的记忆处理分布到不同表示阶段，而跨层复用则将选定的记忆和路由产物向前传递。因此，深度成为一个构建和管理上下文记忆的维度。第三，这些发展催生了一个有状态的多维记忆路由假说：持久记忆在时间范围、网络深度、基底类型和表示粒度上得到组织，而协调的稀疏写入和稀疏读取则决定哪些内容被保持，以及哪些内容对每次查询有贡献。总体而言，高效序列架构设计日益关注上下文记忆的组织、生命周期和选择性使用，而非孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

## 2. 论文提出的方法论

### 2.1 核心思想：五维记忆中心分析视角

论文将上下文记忆定义为**模型内部、依赖输入、在处理序列过程中保持可用的信息**（不包括预训练参数、外部检索语料或生物记忆）。其形式可表示为 token KV 表示、压缩 token/块、记忆槽、联想矩阵、结构化循环状态或异构组合。围绕此提出五个功能维度：

1. **记忆表示（Memory Representation）**：过去哪些信息仍被表示、以何种形式表示？关注**历史覆盖度**（history coverage）与**可寻址性**（addressability）两个属性。形式化记为 $M_t \in \mathcal{M}_\rho$，其中 $\rho$ 为记忆模式（类型、组织、粒度、容量、持久性）。
2. **记忆更新（Memory Update）**：当前输入如何添加、修改、压缩或覆写记忆？抽象为 $M_t^+ = \mathrm{Update}_\rho(M_t^-, x_t)$，涵盖追加式 KV 缓存、循环状态转移、定容槽压缩、受控擦除–写入等。
3. **访问（Access）**：哪些被表示的信息有资格参与当前读取？形式为 $C_t = \mathrm{Access}_\rho(q_t, \tilde{M}_t)$。Softmax Attention 暴露全部因果位置，局部/块稀疏只暴露结构允许的位置，学习式稀疏用路由器/Top-k 构造查询相关候选集，循环机制则暴露状态接口。
4. **读出（Readout）**：如何对合格信息加权、解码或聚合？形式为 $r_t = \mathrm{Readout}_\rho(q_t, C_t)$。
5. **集成（Integration）**：一个或多个已完成的读出如何变换或协调成模块输出？形式为 $o_t = \mathrm{Integration}_\rho(r_t; x_t)$，包括拼接+输出投影、门控、路由、异构路径融合等。

**关键说明**：五维是功能角色而非强制计算图阶段；单一操作可同时承担多个角色，改变表示可能影响可访问性，输入相关的状态转移可同时影响表示与更新。

### 2.3 各机制路线的关键技术细节

- **Softmax Attention（第 3 节）**：围绕三个优化方向展开——① 记忆表示效率（头共享 MQA/GQA、通道压缩 MLA/TransMLA、跨层共享 CLA，保持 token 级可寻址性）；② 序列表示压缩（定容循环记忆如 RMT、TransformerFAM、Trellis、Lattice；动态分辨率记忆如 KSA、HCA Core）；③ 读出与集成调制（Talking-Heads、DCMHA、Differential Attention、FoX 的分数调制；MoH、Gated Attention 的头路由与门控）。
- **Sparse Attention（第 4 节）**：核心是访问干预，按证据来源分为——① 结构约束（架构预设的 Longformer、BigBird、Sparse Transformer、LongNet、PowerAttention；事后发现的 StreamingLLM、LM-Infinite、MInference）；② 自路由（动态 token 分组 Reformer、Routing Transformer；块聚合 Quest、XAttention、MoBA、NSA；摘要 token Landmark Attention、GSSA、HiLS）；③ 辅助代理路由（token 粒度 TokenButler、DSA、LSA、SAS、HashAttention、HATA；块/压缩条目粒度 SeerAttention、MSA、QSA、CSA）；④ 时间与跨层复用（ReTopK 的"先召回再重排"；TidalDecode、Kascade、IndexCache、YOIO/CLSA、CSA2、HySparse）。
- **Linear Attention（第 5 节）**：以 $\bar{S}_{t-1} = \alpha_t \odot S_{t-1}$，$S_t = \bar{S}_{t-1} - E_t + W_t$ 统一分解更新为保留/衰减、擦除/纠正、写入/提交三部分。演进从无衰减（Linear Transformer）→ 固定衰减（RetNet、RWKV-5）→ 输入相关衰减（GLA、GDN、HGRN2、RWKV-6/7、KDA）；从无显式擦除 → 耦合纠正擦除（DeltaNet、GDN、KDA、DeltaProduct）→ 解耦擦除（RWKV-7、GDN2、EDA）。此外还分析了基于损失优化的等价视角，以及容量扩展（SSE、SDM）、时间扩展（Log-Linear Attention、DLA、MHLA）和辅助协调（SLA、CLVR）。
- **State Space Models（第 6 节）**：从结构化时不变动力学（HiPPO、LSSL、S4、S4D、S5）到输入条件动力学（Mamba、Mamba-2 的 SSD），并给出 SSD 核的因果矩阵视角；随后讨论状态组织与读写精炼（Mamba-3 MIMO、MIMOMamba 的多通道接口，HADES 的头组织，MuonSSM 的更新几何）。
- **Hybrid Architecture（第 7 节）**：按组合粒度分为——层间（预定义分配、直接诊断选择、对齐式选择、迭代蒸馏引导选择）、头间（固定分配、功能感知选择、输入自适应路由、深度自适应分配）、分支间（读出级融合、输出级融合）、token 间（时间边界分配、内容分数分配、学习式操作分配）。

- 两项分析均为描述性：用于刻画架构采用与共存，**不用来推断注意力机制导致模型质量差异的因果关系**。

### 2.5 前瞻性假设

提出**有状态多维记忆路由（Stateful Multidimensional Memory Routing）**假设：持久记忆按四坐标组织——时间范围 $\tau$、网络深度 $\ell$、基底类型 $s$、表示粒度 $g$，即 $A_t = T_t \times L \times S \times G$；由协调的**稀疏写入**（$W_t \subseteq A_t$，决定哪些地址保留新信息）和**稀疏读取**（决定哪些已表示单元贡献给查询）共同治理。并给出四个可测试方向：工作负载感知的差异化记忆表示、非对称记忆构建与检索、增量式记忆生命周期与可复用产物、任务条件下的记忆与计算联合路由。

## 6. 论文的主要结论与发现

- **机制层面（综合 1：记忆控制范围的重叠扩大）**：
  - 显式记忆路线与状态路线保留不同的记忆接口和计算形式，但都从各自初始重点（表示/访问效率 vs. 状态表示/更新）扩展到**日益重叠**的记忆功能集合。
  - 显式记忆方法向有界更新、读出调制、输出协调扩展；状态方法向多记忆单元、选择性访问、更丰富读出、协调集成扩展。
  - 收敛之处在于**显式设计控制的范围**，而非共享的记忆基底或计算机制。
- **架构层面（综合 2：网络深度成为新兴的记忆组织维度）**：
  - 层间组合决定每个深度执行何种记忆处理；跨层复用决定哪些记忆/路由产物跨深度持续存在。
  - 纵向清单显示：单一家族记录从 2022–2023 年的 100% 降至 2026 年的 37%，Hybrid 记录从 0 升至 63%；跨层复用从 0 升至 19%（5 条记录，涉及 GLM、DeepSeek、LongCat 三套架构模式）。
  - 高性能开放权重模型前沿**仍保持架构异构性**，且**每个选定架构都保留了显式 token 检索路径**，说明循环状态和稀疏性目前是补充而非统一替代可寻址注意力。
- **前瞻层面（有状态多维记忆路由假设）**：
  - 持久记忆可跨时间范围、网络深度、基底类型、表示粒度联合组织；稀疏写入与稀疏读取协调决定维持什么、什么贡献给查询；由于写入决策影响未来可用信息，路由不仅分配当前资源，还协调记忆的未来生命周期。
- **总体结论**：高效序列架构设计日益关注上下文记忆的**联合组织、生命周期和选择性使用**，而非孤立注意力算子的优化；不应仅以渐近复杂度评价注意力架构，而应综合考虑模型质量、持久记忆、预填充/解码成本、检索行为、更新稳定性、路由开销和实际硬件利用率。

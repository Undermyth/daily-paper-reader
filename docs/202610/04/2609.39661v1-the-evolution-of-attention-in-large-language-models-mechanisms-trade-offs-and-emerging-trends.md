## 摘要
自注意力使大语言模型能够以细粒度、依赖查询的方式访问上下文，但密集的词元交互会带来二次预填充成本，并产生随上下文长度增长的键值缓存。因此，研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动力学以及异构机制组合。本文将这些发展作为模型内部的上下文记忆进行分析。我们引入一个五维视角——记忆表示、记忆更新、访问、读出与整合——分别描述表示了什么、它如何变化、什么可被查询、它如何被读取，以及读出如何形成输出。该视角能够比较相互重叠的研究脉络，而不强加单一计算模型。我们利用来自14个主要模型谱系和11个高性能开放权重端点的59条发布级记录，重建机制层面的发展与架构采纳。第一，显式记忆与循环状态方法保留了不同的接口，但日益控制重叠的记忆功能。第二，异构架构日益在网络深度上进行协同：逐层组合将互补的记忆处理分布到不同表示阶段，而跨层复用则将选定的记忆与路由产物向前传递。深度因此成为构建和管理上下文记忆的一个维度。第三，这些发展引出一个有状态的多维记忆路由假说：持久记忆按时间范围、网络深度、基底类型和表示粒度进行组织，而协同的稀疏写入与稀疏读取决定哪些内容被保持，以及哪些内容对每个查询有所贡献。总体而言，高效序列架构设计日益关注上下文记忆的组织、生命周期和选择性使用，而非孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

## 2. 方法论：核心思想与关键技术细节

### 2.1 五维分析透镜（核心贡献）

以"处理到第 t 个词元、已处理前 t−1 个词元"为统一设定，提出五个功能维度：

| 维度 | 回答的问题 | 形式化 |
|---|---|---|
| **Memory Representation** | 过去哪些信息仍被表示、以何形式 | M_t ∈ M_ρ（ρ 为记忆 schema：类型/组织/粒度/容量/持久性） |
| **Memory Update** | 记忆如何被写入、保留、修改或覆盖 | M⁺_t = Update_ρ(M⁻_t, x_t) |
| **Access** | 哪些已表示信息对当前查询"有资格"参与 | C_t = Access_ρ(q_t, M̂_t) |
| **Readout** | 有资格的信息如何被加权、解码、聚合 | r_t = Readout_ρ(q_t, C_t) |
| **Integration** | 一个或多个完成的读出如何转化为模块输出 | o_t = Integration_ρ(r_t; x_t) |

- **关键立场**：五维是**分析性角色（analytical roles）**，不是强制的计算图或固定执行顺序；单个操作可同时承担多个角色，改变 Representation 也可能连带改变 Access。
- **两个反复出现的表征属性**：*history coverage*（历史覆盖范围）与 *addressability*（可寻址性）——固定尺寸状态可覆盖全历史但丧失词元级可寻址性；显式 KV 保留可寻址性但随长度增长。

### 2.2 五条研究脉络的组织

- **四条机制中心线**：Softmax Attention、Sparse Attention、Linear Attention、State Space Models。
- **一条组合中心线**：Hybrid Architecture。
- 各线在五维上的侧重不同：Softmax 重 **Representation/Update**；Sparse 重 **Access**；Linear/SSM 重 **Representation/Update**（状态的组织与演化）；Hybrid 以 **Representation** 为首要族级轴，其余维度视组合粒度而定。

### 2.3 各机制线的关键技术细节

**（1）Softmax Attention（显式记忆谱系）**
- 记忆表示效率：头共享（MHA→MQA→GQA 连续谱）、通道压缩（MLA 低秩 KV 潜变量 + 内容/位置分量分离、TransMLA 的 GQA→MLA 转换）、跨层共享（CLA，源层 KV 被 c 个消费者层复用）。
- 序列表示压缩：固定容量循环记忆（RMT 记忆词元、TransformerFAM 反馈记忆；Trellis/Lattice 的 KV 槽记忆，含遗忘、低秩与正交更新）；动态分辨率记忆（KSA 摘要记忆、HCA Core 压缩全局条目）。
- 读出/整合调制：Talking-Heads、DCMHA、Differential Attention（双路径相减，权重可负）、FoX（数据依赖遗忘门）；MoH（头级路由，属 Integration）、Gated Attention（sigmoid 门控头输出）。

**（2）Sparse Attention（Access 干预）**
- 统一形式：I_t = Select(e_t,:, U_t; b_t)，随后做候选局部 Softmax：r_t = softmax(q_t K_I^T/√d) V_I。
- **结构约束型**：架构预设（Longformer 滑窗+全局、BigBird 局部/全局/随机、Sparse Transformer、LongNet 膨胀注意力、PowerAttention 幂次偏移）；事后发现（StreamingLLM 注意力汇+滚动窗口、LM-Infinite Λ 形掩码、MInference 离线剖析出 A 形/垂直斜线/块稀疏族）。
- **自路由型**：动态词元分组（Reformer LSH、Routing Transformer 在线球面 k-means 质心路由，代价 O(L^{3/2}d)）；块聚合（Quest 上界估计、XAttention 反对角统计、MoBA 均值键打分+Top-k 块、FlashMoBA 分块 Top-k、**NSA** 压缩/选择/滑窗三分支并用压缩概率作路由证据）；摘要词元编码（Landmark Attention、gist tokens、HiLS 用熵偏置构造 LogSumExp 线性代理并让代理质量参与概率分配）。
- **辅助代理路由**：独立参数化的轻量 indexer（TokenButler 蒸馏、**DSA/Lightning Indexer** KL 蒸馏+稀疏继续训练+stop-gradient、LSA 流式感知+分层索引、SAS 端到端耦合、HashAttention/HATA 二进制代理；SeerAttention/SeerAttention-R/SpotAttention 块级插件式；**MSA** 每个 GQA 组一个索引头+token 级打分 max-pool 成块分；**QSA** 对 index key 做微块平均池化，是三者中唯一缩短索引扫描的；**CSA** 连内容一并压缩）。
- **时间与跨层复用**：ReTopK（先召回后重排，历史支持仅作候选，失败回退全量 Top-K）；TidalDecode、Kascade、**IndexCache**（F/S 层角色，S 层继承最近 F 层的 Top-k 索引）、YOIO/CLSA（共享跨层 KV 与单次索引）、**CSA2**（Full/Reindex/Reuse 三模式，共享主 KV 与索引键并选择性重索引）、HySparse/HySparse2。

**（3）Linear Attention（替换记忆基底）**
- 规范算子：S_t = S_{t−1} + φ(k_t)v_t^T，z_t = z_{t−1} + φ(k_t)，读出 o_t = φ(q_t)^T Ŝ_t /(φ(q_t)^T ẑ_t + ε)。
- **更新的三段分解**：S̄_{t−1} = α_t ⊙ S_{t−1}，S_t = S̄_{t−1} − E_t + W_t。
  - *Retain/Decay*：无衰减（Linear Transformer、DeltaNet）→ 固定头级标量（RetNet、Lightning Attention-2）→ 固定通道向量（RWKV-5）→ 输入依赖头级（GDN）→ 输入依赖通道级（GLA、RWKV-6/7、HGRN2、KDA、GDN2、EDA）；HGRN2 给出随深度单调递增的通道级保留下界。
  - *Erase/Correct*：无显式擦除 → 耦合纠正式（DeltaNet 的 E_t = β_t k_t(k_t^T S̄_{t−1})）→ 解耦擦除（RWKV-7 归一化移除键、GDN2 的 b_t⊙k_t、EDA 秩二预擦除+校正）。
  - *Write/Commit*：直接写入 → 纠正式写入（β_t k_t v_t^T）→ 擦写解耦（GDN2 的值侧门 w_t⊙v_t 等）。
- **损失视角**：把每步更新写成对单位步梯度的等价目标 S_t = S⁻_t − ∇L_t(S⁻_t)，揭示"相关最大化→重建误差最小化"的两阶段演化。
- **容量扩展**：SSE（固定分组+组内 Top-k_g，分层规则）、SDM（扁平行表 + Product-Key Memory 独立读写路由器，更自由但协调更难）。
- **时间扩展**：Log-Linear（位置决定的 Fenwick/幂次多尺度，O(log t) 状态）、DLA（内容依赖分段与信息密度合并，M_t ≤ K）、MHLA（固定粒度扁平块 + 查询块条件混合）。
- **辅助协调**：SLA（特征头间的写入门与查询门）、CLVR（跨层值路由，把记忆派生信号经残差流传给后续层）。

**（4）State Space Models**
- 基础核：h_t = Āh_{t−1} + B̄x_t，r_t = Ch_t；展开 r_t = Σ C Ā^{t−i} B̄ x_i（卷积视图/循环视图）。
- 时间不变结构：HiPPO（多项式投影的最优历史保持）、LSSL、S4（对角+低秩结构，HiPPO 初始化）、S4D（对角）、S5（MIMO + 并行扫描）。
- 输入条件化：Mamba 使 Δ_t、B_t、C_t 由输入生成，Ā_t = exp(Δ_t A)，需 selective scan；Mamba-2 的 SSD 给出 H_t = a_t H_{t−1} + b_t u_t^T，r_t = H_t^T c_t，展开为"读写匹配 × 中间衰减"的下三角矩阵形式，与 Linear Attention 的联想计算相联。
- 读写接口与状态组织：Mamba-3 MIMO 增加 R 个读出方向（代价 O(NPR)）、MIMOMamba（矩阵值注意力、多项式代数）、HADES（共享低通 + 专家高通的自适应滤波器组）、MuonSSM（动量通路 + Newton–Schulz 正交化注入几何）。

**（5）Hybrid Architecture（组合粒度）**
- **Layer-wise**：预定义配比（Griffin ≈2:1、Jamba ≈1:7、Samba、Zamba/Zamba2 共享注意力块+LoRA、HySparse/HySparse2）；直接诊断选择（LightTransfer 识别"懒惰层"、Priming 块重要性+谱初始化）；对齐后选择（Jet-Nemotron/PostNAS、HypeNet/HALO）；迭代蒸馏引导（KL-Guided Layer Selection 逐层恢复并用 KL 下降估重要性）。
- **Head-wise**：固定配比（Hymba、Falcon-H1 约 1:2）、功能感知选择（DuoAttention 检索头/流式头、HydraHead 转 GDN）、输入自适应路由（Elastic Attention 测试时路由）、深度自适应分配（H_FA^(ℓ) : H_Eff^(ℓ) = k_ℓ : 1）。
- **Branch-wise**：读出级融合 r^hyb = Fuse_r({r^(p)})（Block-Recurrent Transformer、Memorizing Transformer、Infini-attention 的 σ(β) 门控、DART 的标量门残差修正）；输出级融合 o^hyb = Fuse_o({o^(p)})（Titans-MAG）。
- **Token-wise**：时间边界分配（LoLCATs、Native Hybrid Attention）、内容分数分配（LoLA 自召回误差、STILL 自显著性，z_i ∈ {KV_recent, KV_salient, S_compressed}）、学习型算子分配（NAtS-L 在 Softmax/GDN 间搜索）。

### 2.4 前瞻性假说（方法论层面的理论延伸）

- **多维记忆地址空间**：A_t = T_t × L × S × G（时间范围、网络深度、基底类型、表示粒度），M_t = {M_t[a] | a ∈ A_t}。
- **稀疏写入**：W_t ⊆ A_t，M⁺_t = Update_ρ(M⁻_t, x_t; W_t)——不同基底保留各自更新规则。
- **稀疏读取**：C_t = Access_ρ(q_t, M̂_t) → r_t = Readout_ρ(q_t, C_t) → o_t = Integration_ρ(r_t; x_t)。
- 类比"多维 Memory-MoE"，但与普通 FFN MoE 的关键区别是**持久性**：写入路由决策会影响未来查询可用到的信息，因此引入延迟依赖与长程信用分配问题。
- 四个可落地方向：① 工作负载感知的差异化记忆表示（typed memory constructor）；② 非对称的记忆构建与检索（预填充轻量、解码粗到细升级）；③ 增量式记忆生命周期（reuse/refresh/transform/invalidate 控制器）；④ 任务条件化的记忆与计算联合路由。

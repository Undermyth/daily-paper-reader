## 摘要
长上下文序列模型面临一个根本性权衡：softmax 注意力以二次代价实现灵活的词元级交互，而线性注意力通过将历史压缩为固定大小的状态，获得线性时间训练和常数时间解码。在本工作中，我们探究能否通过一种可调的结构概念将这两类范式联系起来。为此，我们提出结构化矩阵注意力（SMat-Attention），它通过一族具有结构化长程路由的因果掩码实现，其行支撑集具有 VC 维 d。在我们的构造中，d=1 可恢复标准因果掩码，而增大 d 则允许更丰富的子集路由模式。我们给出分块式前向与反向算法，以实现硬件高效性。对于长度为 T 的序列，在给定掩码族下，硬路由构造尽管掩码是稠密的，仍需要 O(T^{2-3/d}+T) 的工作量。在固定视界流式处理中，经过远距离前缀后的解码每词元仅需常数时间，并使用 O(T^{1-1/d}) 个缓存状态。因此，SMat-Attention 使 VC 维成为一个显式旋钮，用以调控访问模式复杂度、预填充成本和解码内存。在实证方面，子集路由与规则辅助的多键检索实验展示了这些掩码的路由表达能力。将该方法扩展到 Mamba-2 和 Gated DeltaNet，并使用带 top-k 查询读取的学习路由后，仍保持次二次预填充，在若干设置中较骨干模型提升召回准确率，并取得可比的小规模语言建模性能。

## Abstract
Long-context sequence models face a fundamental tradeoff: softmax attention uses flexible token-level interactions at quadratic cost, whereas linear attention obtains linear-time training and constant-time decoding by compressing history into a fixed-size state. In this work, we ask whether we can connect these regimes through a tunable notion of structure. To this end, we introduce Structured Matrix Attention (SMat-Attention) via a family of causal masks with structured long-range routing whose row supports have VC-dimension $d$. In our construction, $d=1$ recovers the standard causal mask, and increasing $d$ permits richer subset-routing patterns. We give chunkwise forward and backward algorithms to enable hardware-efficiency. For sequences of length $T$, the hard-routing construction takes $O(T^{2-3/d}+T)$ work, despite the mask being dense, for our prescribed family. In fixed-horizon streaming, decoding after the distant prefix takes constant time per token using $O(T^{1-1/d})$ cached states. SMat-Attention therefore makes VC-dimension an explicit knob governing access-pattern complexity, prefill cost, and decoding memory. Empirically, subset-routing and rule-assisted multi-key retrieval experiments illustrate the masks' routing expressiveness. Extensions to Mamba-2 and Gated DeltaNet using learned routing with top-$k$ query reads retain subquadratic prefill, improve recall accuracy over the backbones in several settings, and achieve comparable small-scale language-modeling performance.

## 1. 核心问题与整体含义

- **研究动机**：长上下文序列建模存在根本权衡：
  - Softmax 注意力支持灵活的词元级交互，但预填充成本随长度 \(T\) 二次增长，解码 KV 缓存随 \(T\) 线性增长。
  - 线性注意力、SSM、Mamba-2、Gated DeltaNet 等将历史压缩到固定大小状态，实现线性训练与常数解码，但固定状态限制了对长上下文中大量独立信息的关联召回能力。
- **核心问题**：能否把“长程访问模式的组合丰富度”做成一个显式、可调的架构参数，并同时给出计算与内存保证？
- **整体含义**：论文提出 **SMat-Attention（Structured Matrix Attention）**，用因果掩码行支撑集的 **VC 维 \(d\)** 控制长程路由复杂度。\(d=1\) 退化为标准因果掩码；\(d\) 增大允许更丰富的子集路由。它在 softmax 注意力与线性注意力之间提供连续谱系，把 VC 维变成控制访问模式、预填充成本和解码内存的“旋钮”。

## 2. 方法论

### 2.1 核心思想

- 构造一族因果掩码 \(M^{(d)}\)，其块形式为：
  \[
  M^{(d)}=
  \begin{pmatrix}
  L_n & 0\\
  G & L_m
  \end{pmatrix}
  \]
  其中 \(L_n,L_m\) 是普通因果下三角掩码，\(G\) 编码所有长程交互。
- \(G\) 由有限域 \(\mathbb F_q^{d-1}\) 上的点-超平面关联定义：
  - 远距离 key \(j\) 被赋予 profile：\(\mathrm{prof}(j)\in \mathbb F_q^{d-1}\)；
  - 近期 query \(i\) 被赋予 type：\(\mathrm{type}(i)\in\{0,\dots,B-1\}\)，对应一个仿射超平面；
  - \(G_{ij}=1\{\mathrm{prof}(j)\in H_{\mathrm{type}(i)}\}\)。
- 取 \(q=\Theta(n^{1/d})\)，则 profile 数 \(P=\Theta(T^{1-1/d})\)，超平面数 \(B=\Theta(T^{1-1/d})\)。
- 关键性质：\(VC(M^{(d)})=d\)，且尽管掩码非零元数为 \(\Theta(T^2)\)，仍可借助代数重用实现次二次计算。

### 2.2 分块前向/反向算法

- 将掩码拆成两个独立因果掩码与长程块 \(G\)，由于加性核注意力对掩码线性，可分别计算后相加再归一化。
- 长程块分解为：
  \[
  G=RCE^\top
  \]
  - \(E^\top\)：把远距离状态按 profile 池化为 profile 表 \(F_x\)；
  - \(C\)：通过关联矩阵生成 type 表 \(U_h\)；
  - \(R\)：每个近期 query 按自身 type 读取对应 \(U_h\)。
- 关联矩阵 \(C\) 不显式物化：对每个归一化方向 \(a\)，按偏移 \(b=a^\top x\) 分组累加 profile 状态。
- 因果分支采用 chunkwise 线性注意力形式：分块摘要、exclusive prefix scan、块内因果注意力。
- 复杂度：
  - 前向/反向工作量：
    \[
    O\left((T^{2-3/d}+T)rp+\frac{T}{c}(r+p)\right)
    \]
  - 工作内存：
    \[
    O\left((T^{1-1/d}+T/c)rp+c^2\right)
    \]
  - 对 \(d\le 3\)，硬路由前向为线性时间；对 \(d>3\)，为 \(O(T^{2-3/d})\)。

### 2.3 门控与流式解码

- 引入逐 token 标量衰减门 \(a_t\)，用 \(\exp(\lambda_i-\lambda_j)\) 加权掩码，不改变支持集与复杂度。
- 固定视界解码：预先确定远/近边界 \(n\)，处理远距离块后缓存 type 状态 \(\{U_h\}\)，丢弃 profile 状态；近期 token 维护一个 running state \(S_t\)。
- 每个后续 token 解码成本 \(O(rp)\)，与 \(T\) 无关；缓存 \(B+1=O(T^{1-1/d})\) 个状态。

### 2.4 扩展到 Mamba-2 / Gated DeltaNet

- 将 profile 组织扩展到循环骨干：
  - 远距离 token 更新 profile 记忆 \(F_x\)；
  - 聚合为 type 摘要 \(U_h=\sum_x C_{hx}F_x\)；
  - 近期 query 通过 top-4 学习选择器读取 type 摘要，softmax 加权。
- 学习内容哈希：
  - 短因果卷积得到写表示；
  - 线性投影 + 正态 CDF + floor 量化到有限域；
  - 用 straight-through 估计器训练离散地址，并加负载均衡损失。
- 学习路由开销：
  - 每 query 对 \(B=\Theta(T^{1-1/d})\) 个 type 打分，总评分成本 \(\Theta(T^{2-1/d})\)；
  - type 摘要构建 \(O(T^{2-3/d}rp)\)；
  - 保持次二次预填充。
- 学习掩码的 VC 维仍为 \(O(d)\)；top-4 读取下 \(VC(\widetilde M_4)\le 25d-24=O(d)\)。

## 3. 实验设计

### 3.1 数据集与任务

- **Subset Routing**：合成任务，\(T=1024\)，\(k\le 6\) 个 landmark，查询指定子集，输出对应 payload；测试掩码能否实现 VC 维预测的子集选择模式。
- **Multi-key subset recall / MKAR**：\(T=1024\)，随机放置 8 个 key-payload 对，查询要求检索 \(k=1,2,3\) 个 key，报告 exact-support accuracy。
- **MQAR**：Zoology 混合任务，4–64 个 key-value 对，长度 64–256，评估 held-out 1000 例/负载。
- **Joint Context–Key Recall (JCKR)**：改编自 Zhan et al. 2025，context-key-value 记录，key 跨 context 重复，需联合识别；5 种负载，长度 64–3076。
- **PG-19 语言建模**：GPT-2 tokenizer，16K/32K 上下文；300M token 训练；另做 750M token、16 层、宽度 768、16K 上下文的大一点规模实验。
- **Horizon-free decoding 实验**：MQAR 长度泛化、placed layout gap sweep、PG-19 byte-level 训练 2048 评估 16384，比较不同边界调度。
- **端到端成本测试**：单层 SMat 预填充、训练、解码、缓存、峰值内存。

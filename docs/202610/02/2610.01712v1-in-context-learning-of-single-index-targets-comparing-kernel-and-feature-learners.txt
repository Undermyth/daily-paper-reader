Abstract 

In-context learning (ICL) enables a pretrained model to infer a task from demonstrations without updating its parameters. While much of the existing theory focuses on linear target functions, in this paper we study nonlinear cases by comparing two one-layer attention architectures on the same family of single-index tasks. A kernel learner first maps inputs through a fixed nonlinear feature map and then applies linear attention, whereas a feature learner applies attention to the original input, followed by a learned nonlinear readout. We derive predictions for their memorization and generalization errors using the replica method, retaining the effects of pretraining size, task-pool diversity, and training and inference context lengths. The resulting predictions closely match numerical experiments across a broad range of regimes. Our analysis yields phase diagrams that characterize when each architecture is advantageous as the amount of pretraining data, task diversity, and context lengths vary. We further identify qualitatively different context-length scalings for the two learners. Together, these results clarify how architectural choices interact with the dataset and govern nonlinear in-context learning. 

# 1 Introduction 

In-context learning (ICL) is the ability of a pretrained model to infer a task from examples provided in its input context and make predictions without updating its parameters. This behavior is one of the most distinctive capabilities of modern Transformers [7, 10], and has motivated a growing theoretical literature that studies ICL in controlled problems. Early work showed that Transformers trained on families of synthetic tasks can learn new functions from demonstrations [15], and connected it to familiar learning algorithms such as gradient descent, least squares, and ridge regression [2, 36, 4, 25]. These results established that attention-based models can implement nontrivial learning procedures within their forward pass. A more recent line of work asks how such in-context algorithms are acquired during pretraining. For linear attention, whether a model memorizes the pretraining tasks or generalizes to unseen tasks depends jointly on the number of pretraining prompts, task diversity, and the number of demonstrations available at inference time [33, 30, 17]. Recent high-dimensional analyses make these dependencies quantitative and characterize how the shared task structure affects in-context generalization [24, 37, 35, 21, 22]. Other works also study the learning dynamics of ICL [34, 39] and the influence of various factors including data structures, distribution shift, hyperparameters and so on [11, 35, 21, 22, 6]. Most of this theory, however, focuses on linear targets. Nonlinear tasks introduce an additional question: beyond aggregating demonstrations in context, the learner must determine how the nonlinearity on the input should be learned. Single-index models provide a natural setting for this question, and create a classical separation between fixed-kernel methods and feature-learning methods [16, 5, 3, 8]. ICL introduces a further distinction: the relevant direction changes between tasks and must be extracted from the demonstrations

Recent work has shown that pretrained Transformers can exploit low-dimensional structure to learn single-index targets efficiently in context [32], and that nonlinear Transformers can perform inference-time feature learning on single-index tasks [31]. Our goal is thus to compare fixed-kernel methods and feature-learning methods across various amounts of pretraining data, task diversities, and context lengths. We consider two learners that use the same one-layer attention but place the nonlinear transformation on opposite sides of attention. The kernel learner first maps every input through a fixed nonlinear feature map and then performs linear attention in the resulting feature space. In contrast, the feature learner performs attention directly on the original inputs and applies a learned nonlinear readout after attention. We study the two architectures on the same learning problem. Pretraining prompts are generated from a finite pool of tasks, allowing us to separately measure performance on tasks that appeared during pre-training and on fresh tasks drawn from the underlying task distribution. We refer to these quantities as the 

memorization error (on seen tasks) and the generalization error (on unseen tasks), respectively. Varying the task-pool size therefore lets us study how architectural choices interact with the memorization–generalization tradeoff emphasized in previous work [33, 24, 17, 35, 13]. For analytical tractability, we instantiate the kernels using spherical harmonics and analyze both learners using the non-rigorous yet well-established replica method [27, 38]. The comparison is defined for common values of the input dimension d, feature dimension D, pretraining size N , task-pool size N0, and context lengths L, eL. We validate these predictions numerically over a broad range of parameters. Our main contributions are threefold. • Comparison of kernel and feature learners on the same dataset. We formulate the two learners on a common learning problem, with the same task pool, pretraining prompts, and inference prompts, and characterize their memorization and generalization performance as functions of d, D, N 0, N, L, eL.For each learner, we derive replica-based predictions and the resulting formulas accurately predict the performance of both learners over a broad range of regimes. • Phase diagrams for when each architecture is advantageous. We map out how the relative performance of the two learners depends jointly on problem parameters. The feature learner benefits from its lower-dimensional representation and typically reaches low error with fewer pretraining prompts, while the kernel learner can achieve lower memorization error when the task pool is small and pretraining is sufficient. We further identify regimes in which context-length mismatch changes the relative advantage of the two architectures. • A theoretical characterization of context-length scaling. In the large-pretraining and large-task-diversity limit, we prove explicit context-length scaling. For a kernel learner containing degree-k spherical harmonics, recovering that component requires a context length of order dk, which produces a stage-wise learning curve. By contrast, the feature learner exhibits a single transition at L = Θ( d) and can exploit all Hermite components of the teacher at the same time. We also rigorously characterize the behavior when the training context length and the test contest length are different.

## 4.1 Varying the number of training prompts 

We first compare the numerics and the replica prediction with different numbers of training prompts. We fix N0 = 24 and α = eα = 32 , and vary N from 288 to 1200000 . Increasing N allows us to compare the two learners both before and after their interpolation peaks. In Figure 2, we can observe a good agreement between the numerics and the replica prediction. In Appendix C.1 we further check the consistency of corresponding order parameters between experiments and replica prediction. The feature learner, linear attention and kernel learner all show the familiar double-descent behavior [24], with interpolation peaks near d2 and D2, respectively. Stage II substantially reduces the interpolation peak for the feature learner, although a smaller peak remains. Our main interest, however, is the relative performance of the two learners across the different data regimes. We highlight the main observations below. • The feature learner reaches low error earlier. After its first interpolation peak, the feature learner (red line) reaches low error well before the kernel learner (blue line), since D ≫ d. ## 4.2 Varying task diversity and context lengths 

The previous comparison uses a fixed value of N0, α, eα. In this section, we vary these hyperparameters to obtain a more comprehensive phase diagram (Figure 3). Figure 3(a,b) shows that the kernel learner has a memorization advantage when the training set size N is large and the task pool N0 is small. Increasing N0 removes this kernel memorization advantage. At smaller 

N , the relative performance is further affected by the two interpolation peaks near N ∼ d2 and N ∼ D2.Hence, the kernel learner has a generalization advantage only in the low-N regime, where the feature learner is affected by its N ∼ d2 interpolation peak. This is consistent with the observation in Figure 2. We next vary the training and inference lengths in Figure 3(c,d). 

Longer training prompts do not always improve inference performance. Figure 3(c,d) suggests that the relative advantage depends strongly on the training and inference context lengths. Two regimes can favor the kernel learner. First, under a large context-length mismatch, the feature learner can deteriorate (see Theorem 1). Second, when both α and eα are large, the kernel learner can reconstruct the teacher with smaller fluctuations (see Theorem 1), since the kernel basis is complete. Overall, these replica predictions show that the relative advantage of feature and kernel learners depends jointly on the amount of pretraining data N , task diversity N0, and the training and inference context lengths 

α, eα. Additional numerical results are provided in Appendix C.2, where we compare the replica prediction with the experiments with different N0.

Using replica calculations, we char-acterized how their memorization and generalization errors depend jointly on pretraining size, task diver-sity, and the training and inference context lengths. In the population limit, we rigorously prove two context-scaling mechanisms.

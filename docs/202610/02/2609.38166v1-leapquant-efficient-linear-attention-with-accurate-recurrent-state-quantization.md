## 摘要
最近的 LLM 越来越多地采用混合设计，用线性注意力替代标准注意力，例如 Gated DeltaNet (GDN) 和 Kimi Delta Attention (KDA)。尽管它们将上下文压缩为固定大小的循环状态，并大幅降低长上下文处理成本，但反复读取和更新该状态仍是推理的主要瓶颈。量化提供了降低该成本的自然途径，但由于舍入误差的累积以及状态中异常值行和列的存在，可能会显著降低模型质量。为应对这些挑战，我们提出 LeapQuant，一种无需训练的方法，在 8 比特循环状态量化下实现近乎无损的性能。首先，为缓解误差累积，我们提出逐窗口量化，即跨越一个 token 窗口，仅在其末尾对状态量化一次。在窗口内，输出由固定的低比特状态以及高精度缓冲更新共同计算得到。其次，为减少每次量化引入的误差，LeapQuant 将状态中最大的异常值保留为少量高精度补偿 token（Compensator Tokens），它们与真实 token 共享更新路径。然后，我们在量化前平滑剩余残差，以进一步降低误差。在 Qwen、Kimi 和 GLM 模型系列上的大量实验表明，LeapQuant 显著降低了推理过程中的内存和计算成本。在精度与 FP32 基线相当的情况下，它在 NVIDIA B200、RTX PRO 6000 和 RTX 5090 GPU 上实现了内核级别平均 2.05--3.70 倍的加速，以及端到端推理 1.47 倍的加速。

## Abstract
Recent LLMs increasingly adopt hybrid designs that replace standard attention with linear attention, such as Gated DeltaNet (GDN) and Kimi Delta Attention (KDA). Although they compress the context into a fixed-size recurrent state and substantially reduce the cost of long-context processing, repeatedly reading and updating that state remains a major inference bottleneck. Quantization offers a natural way to reduce this cost, but can significantly degrade model quality, due to the accumulation of rounding errors and the presence of outlier rows and columns in the state. To address these challenges, we propose LeapQuant, a training-free method that achieves near-lossless performance under 8-bit recurrent-state quantization. First, to mitigate error accumulation, we propose per-window quantization, which leaps over a window of tokens and quantizes the state only once at its end. Within a window, outputs are computed from the fixed low-bit state together with high-precision buffered updates. Second, to reduce the error introduced by each quantization, LeapQuant retains the state's largest outliers as a few high-precision Compensator Tokens, which share the update path of real tokens. We then smooth the remaining residual before quantization to further reduce the error. Comprehensive experiments across the Qwen, Kimi, and GLM model families show that LeapQuant substantially reduces memory and compute costs during inference. With accuracy comparable to the FP32 baseline, it achieves average speedups of 2.05--3.70$\times$ at the kernel level and 1.47$\times$ for end-to-end inference on NVIDIA B200, RTX PRO 6000, and RTX 5090 GPUs.

- **核心瓶颈**：虽然状态尺寸固定，但**每个解码步都要把整个状态矩阵从 HBM 读出、做轻量更新、再写回 HBM**。该过程的算术强度极低（读取/写入字节数远大于计算量），因此推理吞吐被 HBM 带宽卡住（roofline 分析）。
  - 论文实测：GLM-5.3-Flash-NVFP4 在 B200、batch size 256 下，线性注意力耗时占比随上下文增长基本恒定，是解码时间的重要组成（图 1a）。
  - 前缀缓存场景下，服务系统需为每个缓存前缀保留独立状态，显存占用随缓存 token 数快速膨胀（图 1b）。
- **量化是自然解法，但直接量化会严重掉点**，原因有二：
  1. **误差累积**：每步更新都从已量化的状态出发，再量化又引入新的舍入误差，误差沿生成轨迹逐步偏离 FP32 参考轨迹（附录 B.1 给出误差传播公式，见式 8）。
  2. **离群值（outliers）**：状态中少数行/列存在极大值（论文实测可达中位数的 176 倍），拉大量化范围，迫使其余小值落入粗糙的量化级。
- **整体含义**：LeapQuant 提出**免训练（training-free）、无需校准数据**的循环状态量化方案，在 8-bit 下实现近乎无损精度，把"低精度循环状态"变为长上下文混合模型服务的可行默认选项。

## 2. 方法论：核心思想与关键技术

### 2.1 问题形式化（预备知识）

论文统一建模的递推形式（式 1）：

$$S_t = \mathrm{Diag}(\alpha_t) S_{t-1} + k_t\big(v_t - S_{t-1}^\top \beta_t\big)^\top,\quad o_t = S_t^\top q_t$$

- $\mathrm{Diag}(\alpha_t)$ 为对角衰减，$k_t$ 为写 key，$\beta_t$ 为读向量（$\beta_t=0$ 表示无 delta rule），$k_t u_t^\top$ 为秩一更新。
- 附录 A 的 Table 4 证明 Linear Attention、RetNet、Mamba2、GLA、RWKV6、HGRN2、DeltaNet、GDN、KDA、DeltaProduct 均可写成该形式（RWKV7 等擦除方向与写 key 不同者，可拆为两个子步）。
- 定义量化误差 $E_t = \mathrm{dequant}_b(\hat S_t) - S_t^{\text{FP32}}$。

### 2.2 关键技术一：逐窗口量化（Per-window Quantization）

- **朴素做法（逐 token 量化）**：每步先由 $\hat S_{t-1}$ 算出全精度 $S_t$，再整体量化回 $\hat S_t$——**每个 token 都注入一次新误差**。
- **LeapQuant 做法**：把 $p$ 个连续 token 组成一个窗口，只在窗口边界量化一次。
  - 窗口内保持量化边界状态 $\hat S_0$ **固定不变**，把每个 token 的三元组 $(\alpha_i, k_i, u_i)$ 以**高精度缓冲**（其中校正向量 $u_i = v_i - S_{i-1}^\top \beta_i$）。
  - 引入累积衰减 $\Gamma_{a:b}$，窗口内任意步 $\ell$ 的状态可展开为（式 4）：
    $$S_\ell = \Gamma_{1:\ell}\hat S_0 + \sum_{j=1}^{\ell}\Gamma_{j+1:\ell}\,k_j u_j^\top,\quad 1\le \ell \le p$$
  - **只有 $\ell=p$ 时才物化 $S_p$ 并量化**得到 $\hat S_p$，用于下一个窗口。
- **效果**：量化频率降低 $p$ 倍；且因为误差仅在边界产生，误差累积远低于频率降低带来的线性收益（附录 B.1 指出逐 token 的舍入误差彼此相关、会相干叠加）。
- **代价**：每个活跃请求需一个 FP16 更新缓冲；对 $128\times128$ 状态、$p=16$ 时约 8 KiB/头/层，开销边缘化。

### 2.3 关键技术二：补偿 Token（Compensator Tokens）

- **动机**：状态的少数奇异分量携带绝大部分能量（图 5：top-4~8 奇异值即占 ~80–90% 能量），这些离群结构主导量化 scale。
- **做法**：在量化 $S_p$ 之前，先拟合一个秩一（可扩展到 $r$ 个）矩阵 $\tilde k \tilde u^\top$ 捕获主导大值结构，只量化残差（式 5–6）：
  $$(\tilde k,\tilde u)=\arg\min_{k,u}\|S_p - ku^\top\|_F,\quad R_p = S_p - \tilde K\tilde U^\top,\quad \hat R_p = \mathrm{quant}_b(R_p)$$
  $$\tilde S_p = \mathrm{dequant}_b(\hat R_p) + \tilde K\tilde U^\top$$
- **与窗口量化的自然融合**：补偿 token 与真实 token 的更新形式相同（同为秩一 + 单位衰减），因此可**直接塞进窗口的更新路径**，由解码 kernel 按真实 token 一样处理，无需额外 kernel 或独立的循环状态更新。它在下一窗口内被排在真实 token 更新之前。
- **重构流程**：每个窗口末尾，由量化残差 + 旧补偿 token + 本窗口真实 token 更新重构 $S_p$，丢弃旧补偿 token、用幂迭代（power iteration）在 tensor core 上重新拟合新的 $\tilde K\tilde U^\top$，再量化新残差，作为下一窗口初值。
- **效果**：离群幅度由 176× 中位数降至 47×（图 6a→6b）。

### 2.4 关键技术三：残差平滑（Residual Smoothing）

- **动机**：补偿 token 之后，残差在 key 维度上仍存在行幅度不均（少数大 key 通道主导 scale），图 6b。
- **做法**：令平滑向量 $c\in\mathbb{R}^{d_k}_{>0}$ 的每个元素为该 key 行平均绝对值的平方根（加小正下限防除零），$C=\mathrm{Diag}(c)$，量化前左乘 $C^{-1}$ 平衡行幅度，量化后乘 $C$ 还原（式 7）：
  $$\hat R_0^C = \mathrm{quant}_b(C^{-1}R_0),\quad S_p = \Gamma_{1:p}\big[C\,\mathrm{dequant}_b(\hat R_0^C) + \tilde K\tilde U^\top\big] + \sum_{j=1}^{p}\Gamma_{j+1:p}k_j u_j^\top$$
- 变换本身可逆，仅中间的量化引入近似；平滑 scale 在每个窗口内固定、每个边界按新残差重算。附录 B.3 推导了带平滑的读出形式（式 10），保证读出时不必物化完整 $d_k\times d_v$ 中间状态。
- **效果**：离群幅度进一步由 47× 降至 5.3×（图 6c）。

### 2.5 算法流程概览

1. 窗口起始：持有低精度边界状态（INT8 残差 + 平滑 scale + 补偿 token）。
2. 窗口内每个 token：用固定低精度状态 + 高精度缓冲更新计算输出 $o_t = S_i^\top q_i$（式 9/10 的增量读出形式，每步开销 $O(d_k+d_v)$）。
3. 窗口末尾（$p$ 个 token 后）：重构 $S_p$ → 重新拟合补偿 token → 量化残差 → 作为下一窗口初值。

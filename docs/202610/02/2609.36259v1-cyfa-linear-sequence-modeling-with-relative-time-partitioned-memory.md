## 摘要
线性RNN能够提供线性时间的序列处理和恒定内存的解码，但其固定大小的循环状态必须容纳所有过去的键值关联。现有的遗忘机制和Delta规则更新通过选择性地清除或校正状态来减少干扰，但较早的关联仍可能难以检索。我们提出CyFA（Cyclic Flow Attention，循环流注意力），一种具有相对时间分区记忆的线性RNN。在每一步，一个可学习的时钟控制在当前键值对进入零龄槽之前联合施加于键状态和值状态的循环传输，从而将存储的关联组织到不同的相对时间槽中。我们进一步推导出一种到绝对时钟坐标的精确变换，将CyFA表示为两个标量衰减的线性注意力递推式，并支持高效的分块训练。在循环状态大小匹配的400M--1.4B预训练实验中，CyFA提升了召回密集型性能，同时保持有竞争力的语言建模和高计算效率。在400M规模下，CyFA在FDA上优于KDA（42.60 vs. 26.07），而分别仅需KDA前向和后向核心算子执行时间的46.7%和48.3%。我们的代码已公开于 \href{https://github.com/Chyxx/CyclicFlowAttention}{此 https URL}。

## Abstract
Linear RNNs offer linear-time sequence processing and constant-memory decoding, but their fixed-size recurrent states must accommodate all past key--value associations. Existing forgetting mechanisms and Delta Rule updates reduce interference by selectively clearing or correcting the state, yet earlier associations can still become difficult to retrieve. We introduce CyFA (Cyclic Flow Attention), a Linear RNN with relative-time-partitioned memory. At each step, a learned clock controls the cyclic transport applied jointly to the key and value states before the current key--value pair enters the age-zero slot, thereby organizing stored associations across relative-time slots. We further derive an exact change to absolute-clock coordinates that expresses CyFA as two scalar-decay linear attention recurrences and enables efficient chunk-wise training. Across 400M--1.4B pretraining experiments with matched recurrent-state sizes, CyFA improves recall-intensive performance while maintaining competitive language modeling and high computational efficiency. At 400M, CyFA outperforms KDA on FDA (42.60 vs. 26.07) while requiring only 46.7% and 48.3% of KDA's forward and backward core-operator execution times, respectively. Our code is publicly available at \href{https://github.com/Chyxx/CyclicFlowAttention}{this https URL}.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：Transformer 在长序列建模中因自注意力二次复杂度与线性增长的 KV 缓存而受限；线性 RNN（线性注意力、现代状态空间模型）通过将序列前缀压缩到固定大小的循环状态，实现线性时间处理与常数内存解码。
- **核心矛盾**：固定状态容量有限，每个新写入都更新同一个循环状态，导致越来越多的键值关联相互干扰；已有的遗忘门（标量/向量衰减）和 Delta Rule 更新只是"选择性擦除/校正"状态，当大量历史关联需同时可检索时，早期关联仍难以召回。
- **研究问题转向**：现有工作都聚焦于"新写入到来时该擦除什么"，本文提出一个互补问题——**能否在相同固定状态预算下，通过更好地组织记忆本身，让更多关联在被遗忘之前保持可区分、可检索？**
- **整体含义**：论文提出 CyFA（Cyclic Flow Attention，循环流注意力），用"相对时间分区记忆"沿模型年龄轴组织状态，在保持线性复杂度与常数解码内存的同时，显著提升召回密集型任务性能，并兼顾语言建模与训练效率。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将循环状态的行视为**相对时间槽**：每次写入前，对键状态和值状态施加**相同的循环传输**（cyclic transport），把已有内容推向更大的"模型年龄"，再把当前键值对写入"零龄槽"。
- 用一个**可学习时钟**控制每次传输量，使相邻写入的间距随输入内容自适应，而非固定窗口。

### 2.2 关键技术细节
- **循环传输构造**：
  - 把滑动窗口的移位矩阵 Z 封闭为循环置换矩阵 P（将末行回送到零龄槽），从而无固定窗口边界地复用有限行。
  - 通过实 Fourier 基 Φ 将 P 扩展为分数循环移位：`U(τ) = 1 ⊕ ⊕ⱼ Rot(2πjτ/m)`，`P(τ) = ΦU(τ)Φᵀ`，满足 `P(τ₁)P(τ₂)=P(τ₁+τ₂)`、`P(τ+m)=P(τ)`、正交且可逆。
  - 相对时间槽数 m 取奇数（实现 m=127 个活跃槽，m*=128 存储行，填充行被 mask）。
- **相对时间分区记忆更新**（式 15）：
  - `Kt = αt P(δt) Kt−1 + βt e₀ kᵀt`
  - `Vt = αt P(δt) Vt−1 + βt e₀ vᵀt`
  - 其中 δt 为可学习时钟增量（(0,1)），λt = λt−1 + δt 为累积时钟；αt 为标量遗忘门，βt 为写强度；同一传输与衰减同时作用于键和值，保持配对对齐。
  - 展开后每个写入 i 的相对时间轮廓为 `P(λt−λi)e₀`，其分数移位由 Dirichlet 核 `sin(π(τ+s−r))/(m sin(π(τ+s−r)/m))` 给出。
- **绝对时钟坐标变换（关键计算创新）**：
  - 在 Fourier 坐标 `K̂t=ΦᵀKt` 下，稠密行混合变为独立二维旋转 `U(δt)`；再令 `Kt = U(−λt)K̂t`（绝对时钟坐标），得到**标量衰减递推**：
    - `Kt = αt Kt−1 + βt U(−λt)b kᵀt`
    - `Vt = αt Vt−1 + βt U(−λt)b vᵀt`
  - 时钟只影响"时间写向量" `U(−λt)b`，状态本身只做标量衰减；坐标变换严格等价于原相对时间更新（含时钟原点不变性证明）。
- **读取（readout）**：
  - 学习读出矩阵 R（初始化为单位阵），`ot = (RVt)ᵀ softmax(RKt qt)`；R 只影响检索，不影响状态递推。
- **两趟分块计算（two-pass chunk-wise）**：
  - 关键趟：`ScalarGatedLA({qt, kt, βtU(−λt)b, αt})` → o′t = Kt qt；
  - 中间 token-wise 变换：`o″t = U(−λt)ΦᵀRᵀ softmax(RΦ U(λt) o′t)`；
  - 值趟：`ScalarGatedLA({o″t, βtU(−λt)b, vt, αt})` → ot。
  - 两趟均复用现成 ScalarGatedLA 的高效 chunk 算子，无需物化每步的相对时间状态；累积时钟 λt 通过并行前缀和得到。
- **网络设计**：
  - 每头独立参数化 q/k/v、δ、α、β，以及读出矩阵 R；m=127 活跃槽。
  - αt = exp(−A·softplus(Wαxt+bα))；q/k/v 加 ShortConv，Q/K 做 RMSNorm，头级 RMSNorm + 低秩 sigmoid 输出门；LLaMA 风格 pre-norm 主干与 SwiGLU 交替。
  - **时钟梯度稳定**：对时钟增量投影的输入做 stop-gradient：`δht = σ((Wδ sg(xt)+bδ)h)`，阻断累积时钟梯度回流到残差流，避免损失震荡与梯度尖峰。
- **与 BLA 关系**：固定速率时钟 δt≡1/ρ 时，CyFA 的相对时间轮廓退化为 BLA 的 Fourier–Dirichlet 窗；CyFA 进一步引入输入依赖时钟、独立标量遗忘与学习读出矩阵 R。

## 6. 论文的主要结论与发现

- **召回密集型任务显著提升**：所有三个规模上 CyFA 都是最强循环模型；400M 时比次优循环模型在 FDA 高 16.53 分、SWDE 高 7.77 分；1.4B 平均召回 43.47，高于 KDA 的 37.73 与公开 Transformer 的 41.41。
- **语言建模与常识保持竞争力**：三个规模平均常识准确率均为最高（400M: 42.47；800M: 48.16；1.4B: 53.19）；困惑度与 KDA 相当或更优（1.4B Wiki ppl 15.47 vs 15.97）。
- **长上下文能力**：LongBench 在 800M/1.4B 平均分最高（800M 15 项中领先 10 项，1.4B 领先 11 项），代码任务优势最大（1.4B LCC 53.60 vs KDA 46.34）；RULER 中多键任务 MK-NIAH-1 退化更平缓，4K 内明显领先。
- **效率**：端到端吞吐在 8K 起超过 Transformer，8K 时为 KDA 的 1.37×；400M 训练形状下核心算子前向/反向仅为 KDA 的 46.7%/48.3%。
- **消融结论**：标量遗忘门贡献最大（去掉后 LAMBADA ppl 从 48.17 翻倍到 115.89，召回降 5.20）；输入依赖时钟贡献 2.93 分，R 学习贡献 1.46 分；QK Norm 对召回影响大于 ShortConv；SiLU 提升困惑度但降低召回；召回对槽数最敏感（m=63 → 26.68，m=255 → 34.83）。
- **时钟机制**：96 个头中 56 个（58.3%）时钟接近 1，40 个（41.7%）输入依赖；输入依赖头中当前 token 身份解释 49.4% 变异，上下文解释 50.6%；干预实验表明模型确实利用了时钟与上下文的对齐（移位干预 NLL 上升最多 +0.1238）。
- **梯度稳定**：stop-gradient 是训练稳定的关键；无 sg 时全局梯度范数升至 12.006（KDA 为 2.309），且非时钟部分随序列长度放大到 KDA 的 4.58×。

## 7. 优点

- **问题视角新颖**：从"擦除什么"转向"如何组织记忆"，与主流细粒度遗忘/Delta Rule 路线正交，可组合。
- **数学构造严谨**：Fourier 分数循环移位、群律、正交性、Dirichlet 核、时钟原点不变性、绝对时钟坐标等价性均有完整证明（附录 A），理论闭环完整。
- **计算可行性高**：绝对时钟坐标变换把稠密 m×m 传输化为标量衰减 + 时间写向量，使两趟计算都退化为标准 ScalarGatedLA，直接复用高效 Triton 算子，实测前向/反向耗时仅为 KDA 的一半左右。
- **实验公平性强**：严格对齐循环状态规模、统一主干与实现库、区分自训与公开 checkpoint。
- **分析与消融扎实**：不仅有性能对比，还有时钟梯度路径分析、时钟输入依赖性量化、多类干预实验，支撑机制解释。
- **与 BLA 的关系清晰**：给出固定速率退化为 BLA 轮廓的严格特化，明确了继承与改进边界。

## 8. 不足与局限

- **规模仍偏小**：最大仅 1.4B 参数 / 100B tokens，未验证在更大模型（如 7B+）与更长上下文（>8K 训练）下的可扩展性；长上下文仅续训 1024 步。
- **超参数与结构敏感**：m 的选择对召回影响很大（63→255 提升 8 分以上），论文未给出 m 的自适应或缩放规律；填充行、奇数槽限制等实现细节带来工程约束。
- **时钟训练脆弱**：必须依赖 stop-gradient 才稳定，说明时钟分支的梯度路径本身存在病态；其他模型/任务上是否同样需要该技巧、是否影响最终性能上限，尚不清楚。
- **对比覆盖有限**：800M 规模仅与 GDN/KDA/Transformer 对比；BLA 无官方实现、由作者自行以 GSA 形式复现，可能不完全反映原方法性能；Mamba-3 等新方法未在所有规模出现。

## 摘要
设计兼具强表达能力与高效推理的序列层，仍是现代机器学习中的一个核心挑战。标准 softmax 注意力通过丰富的非线性 token 交互实现了优异的序列建模性能，但它需要随序列长度线性增长的键值缓存，这限制了其可扩展性。线性注意力能够以恒定的内存占用实现高效的循环计算，但其表达能力降低，往往导致建模性能较差。我们提出切换线性注意力（Switching Linear Attention, SwiLA），一种新颖的序列层，它在保留线性注意力固定大小循环状态的同时增强表示能力，从而弥合这一差距。我们从测试时回归框架推导出 SwiLA 的循环更新，将状态更新规则视为线性回归混合模型中的在线期望最大化。在测试时，每个输出维度根据输入在多个线性注意力组件之间动态选择。在联想回忆、上下文语言学习和语言建模基准上，SwiLA 表现出强劲性能，缩小了与 softmax 注意力的差距，甚至在一些设置中超过它。

## Abstract
Designing expressive sequence layers with efficient inference remains a central challenge in modern machine learning. Standard softmax attention achieves excellent sequence modeling performance through rich nonlinear token interactions, but it requires a key-value cache that grows linearly with sequence length, limiting its scalability. Linear attention enables efficient recurrent computation with a constant memory footprint, yet its reduced expressivity often yields inferior modeling performance. We introduce Switching Linear Attention (SwiLA), a novel sequence layer that bridges this gap by enhancing representational capacity while retaining the fixed-size recurrent state of linear attention. We derive the SwiLA recurrence from the test-time regression framework, casting the state update rule as online expectation-maximization in a mixture of linear regressions model. At test time, each output dimension dynamically selects among multiple linear attention components based on the input. Across associative recall, in-context language learning, and language modeling benchmarks, SwiLA shows strong performance and narrows the gap to softmax attention, even surpassing it in several settings.

# 《Switching Linear Attention（SwiLA）》论文总结

## 1. 核心问题与研究动机

- **核心张力**：现代序列建模需要在**表达能力**与**推理效率**之间取舍。
  - **Softmax 注意力**：通过非线性 token 交互（核平滑器）实现强表达力，但需要随序列长度线性增长的 KV 缓存，长上下文代价高。
  - **线性注意力**：将注意力改写为常量内存（状态规模 O(D²)）的线性循环，但每个时刻只做一次"查询→输出"的线性映射，难以捕捉多样的、依赖上下文的检索模式，导致联想召回能力不足（在 Zoology 等召回基准上持续落后）。
- **理论视角**：作者采用 Wang et al. (2025) 的**测试时回归（Test-Time Regression, TTR）**框架，把联想召回拆解为"记忆=在线回归"与"检索=函数求值"两步：
  - 记忆：拟合回归器 `m_t ≈ argmin Σ ‖v_i − m(k_i)‖²`；
  - 检索：`o_t = m_t(q_t)`。
  - 现有层是该框架的特例：线性注意力=带白化设计矩阵的线性回归；DeltaNet=用 SGD 拟合的线性回归；Softmax 注意力=非参数核平滑。
- **整体含义**：SwiLA 通过在 TTR 框架中引入**混合线性回归**，把单一线性映射升级为**分段线性映射**，从而在保留固定大小循环状态的同时逼近 softmax 注意力的表达力，填补两者之间的空白。

## 2. 方法论

### 2.1 核心思想
- SwiLA 是 TTR 的一个新实例，其设计选择为：
  - **回归模型**：混合线性回归（mixture of linear regressors）；
  - **优化算法**：在线期望最大化（online EM）。
- 关键创新：**组归属（mixture assignment）按输出维度 d 独立选择**，因此有效混合数呈指数增长 `O(J^D)`，而参数量仅多项式增长 `O(JD²)`——一种"廉价的状态扩张"。

### 2.2 概率模型与公式
- 隐变量 `z_td ∈ {1,…,J}` 表示第 t 步、第 d 个输出维度的组归属：
  - 先验：`p(z_td | k_t) = Cat(z_td | π_jd(k_t))`；
  - 似然：`p(v_td | z_td=j, k_t) = N(v_td | w_jd^T k_t, 1)`。
- 边际对数似然（式 3.2）：
  `ℓ_td = log Σ_j π_jd(k_t) exp(−½(v_td − w_jd^T k_t)²) + c`。

### 2.3 在线 EM 推导出的循环更新
- 对"快权重" W 做一步随机梯度上升，得到 **SwiLA 循环（式 3.3）**：
  - `w_tjd = w_{t−1,jd} + β_tjd · r_tjd · δ_tjd · k_t`
  - `δ_tjd = v_td − w_{t−1,jd}^T k_t`：预测误差（delta 规则形式）；
  - `r_tjd`：**后验责任度（responsibilities）**，即"该维度由第 j 个专家生成"的后验概率（式 3.4），形如对负平方误差做 softmax。
  - 注意：责任度依赖**上一时刻状态**，因此 SwiLA 的循环对 W **非线性**（区别于 MoM/SSE 等线性循环路由）。
- **检索（式 3.5）**：`o_td = Σ_j π_jd(q_t) · w_tjd^T q_t`，即按查询侧先验加权多个线性回归器的预测。

### 2.4 两项模型扩展
- **Temporal SwiLA（时序持续性）**：
  - 动机：上下文常跨多个连续 token 持续（如段落中讨论同一人物），但原始 SwiLA 的混合归属是"无记忆"的。
  - 做法：用可计算近似替代 HMM 滤波——维护每个维度的运行概率分布 `r̄_td`、`ρ̄_td`，与当前输入产生的新分布做**凸组合**：
    `r̄_tjd = (1 − g_td) r_{t−1,jd} + g_td π_jd(k_t)`，其中门 `g_td = σ(θ_g^T x_t + b_g) ∈ [0,1]` 控制"粘性"。
- **Gated SwiLA（输入依赖门控/状态衰减）**：
  - 在快权重上放置高斯先验 `w_jd ~ N(0, λ_tjd^{-1} I)`，等价于权重正则（式 3.6）。
  - 两种形式（式 3.7 门在责任度之后 / 式 3.8 门在计算误差之前）；J=1 时两者仅差重参数化而等价，J>1 时不同。**实践中采用式 3.8**（对齐 GDN 实现）。
  - 门的粒度由精度 λ 的共享方式决定：可退化为 KDA 式的"每 key 维度一个门"或 GDN 式的"每 head 一个标量门"。

### 2.5 负载均衡（防止专家坍缩）
- **互信息辅助损失**：`L_MI = −λ_marg·H_marg + λ_cond·H_cond`，最大化 token 与专家的互信息（H_marg 鼓励使用均衡，H_cond 鼓励每 token 专精）。
- **输入依赖噪声注入**：训练时向专家 logits（key 侧、query 侧及 Temporal 门）注入可学习方差的高斯噪声（式 3.10）。

### 2.6 并行化理论贡献（附录 D）
- 证明 SwiLA 循环的雅可比为**单位矩阵减秩一扰动** `I − g_tjd k_t k_t^T`（式 D.4–D.5），恰好匹配 DeltaNet chunkwise 算法的结构。
- 提出**新颖的 chunkwise 并行牛顿迭代**：每次牛顿迭代用 DeltaNet 的分块算法求解，避免 pscan 需物化全部隐状态带来的 `O(TD²)` 内存瓶颈（属准牛顿，因忽略分母带来的跨专家耦合；准牛顿仍保证全局收敛）。
- **但所有实验均使用顺序（sequential）Triton 核**，chunkwise 并行仅为"原理上可用"，未做内核优化。

## 3. 实验设计

### 3.1 逼近 Softmax 注意力（合成回归任务，5.1）
- 目标函数为单头因果 softmax 注意力输出；D=32，32 个聚类中心，序列长度 512。
- 训练 65,536 条序列，验证/测试各 2,048 条；在固定状态预算 `B = H × J`（H=头数，J=混合数）下扫描所有因式分解，B ∈ {1,2,4,8,16,32}。
- 对比：DeltaNet（J=1）vs 多种 SwiLA 配置，指标为测试 R²。

### 3.2 合成基准（5.2）
- **CDAR（Context-Dependent Associative Recall）**：扩展 MQAR，同一 key 在不同上下文下映射到不同 value；C=4 上下文 × 32 对 KV（共 128 条关联），词表 8192，序列长 1024，查询位置服从幂律分布。
  - 对比：Attention（L=1/2）、DeltaNet（L=1/2）、DN-MoM（L=1/2）、SwiLA、Temporal SwiLA。
- **RegBench（In-Context Language Learning）**：基于随机概率有限自动机（PFA），模型需在上下文中学习 PFA 的下一 token 分布。
  - 对比 5 个 8 层模型：SwiLA、Temporal SwiLA、DN-MoM、DeltaNet、Transformer。

### 3.3 语言模型预训练（5.3）
- **规模**：374M 参数、24 层、hidden 1024，在 FineWeb-Edu 上训练 **15B token**。
- **对比 13 个模型**：Transformer++、FoX（softmax 类）、DeltaNet、Gated DeltaNet (GDN)、KDA、DN-MoM、GDN-MoM、SwiLA、Gated SwiLA、Temporal SwiLA、Gated Temporal SwiLA、Hybrid GDN、Hybrid Temporal SwiLA（3:1 混合 softmax 层）。
  - 所有循环模型**循环状态规模严格对齐**（8×4×64×64 = 8×128×128 = 131,072 标量/层）。
- **Benchmark 1｜常识推理**：Wikitext、LAMBADA、PIQA、HellaSwag、WinoGrande、ARC-Easy、ARC-Challenge、SIQA、BoolQ。
- **Benchmark 2｜召回密集任务**：SWDE、FDA、SQuAD、TriviaQA、NQ、DROP（输入截断至 2K token，用 contains 指标）。

### 3.4 效率与消融（5.4–5.5）

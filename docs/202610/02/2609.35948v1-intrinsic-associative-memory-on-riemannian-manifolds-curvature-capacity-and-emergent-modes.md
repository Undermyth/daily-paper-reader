## 摘要
几何不仅约束联想记忆：曲率决定了它记住什么以及它创造哪些状态。我们通过将记忆表述为 Epanechnikov 核密度众数搜索，构建了黎曼流形上的内蕴稠密联想记忆。我们比较测地能量与体积校正能量，并表明曲率会区分二者的行为。我们证明，测地记忆始终保留一个孤立模式，而校正记忆则服从一个尖锐的 Ricci 曲率阈值：正曲率在高维中可能抹除记忆，而负曲率会强化记忆。我们推导出测地容量标度：保留每个模式时为 $q_β^{-1/2}$，保留一个典型模式时为 $q_β^{-1}$，其中 $q_β$ 是成对核重叠概率。我们展示重叠如何创造新记忆：设计好的 $N$ 模式配置可实现全部 $2^N-1$ 个子集模式，但在存储阈值处的随机数据仅产生泊松数量。我们利用黎曼均值漂移建立了精确的一步召回。在模拟中，我们复现了预测的曲率转变以及每个设计模式。在 WordNet 的完整名词层次结构上，我们证明体积校正改善了低容量检索。总之，我们的工作表明，曲率是联想记忆的一个设计变量，而不仅仅是数据的一种属性。

## Abstract
Geometry does more than constrain an associative memory: curvature determines what it remembers and which states it creates. We develop intrinsic dense associative memories on Riemannian manifolds by casting memory as Epanechnikov kernel-density mode seeking. We compare geodesic and volume-corrected energies and show that curvature separates their behavior. We prove that geodesic memory always retains an isolated pattern, while corrected memory obeys a sharp Ricci-curvature threshold: positive curvature can erase memories in high dimensions, while negative curvature reinforces them. We derive geodesic capacity scalings of $q_β^{-1/2}$ for retaining every pattern and $q_β^{-1}$ for a typical one, where $q_β$ is the pairwise kernel-overlap probability. We show how overlap \emph{creates} novel memories: designed $N$-pattern configurations realize all $2^N-1$ subset modes, but random data at the storage threshold yield only a Poisson number. We establish exact one-step recall using Riemannian mean shift. In simulations, we recover the predicted curvature transition and every designed mode. On WordNet's full noun hierarchy, we demonstrate that volume correction improves low-capacity retrieval. Together, our work shows that curvature is a design variable for associative memory, not merely a property of the data.

## 2. 方法论

### 2.1 建模框架：两种内蕴 Epanechnikov 能量

- **几何三要素**：距离 $d(x,p)$（最短路径长度）、对数映射 $\log_x p \in T_xM$、指数映射 $\exp_x v$；核半径取 $h < \mathrm{inj}(M)$ 以保证支撑内测地线唯一。记 $\beta = 2/h^2$，$q_i(x)=\tfrac12 d(x,\xi_i)^2$，$a_i(x)=\theta_{\xi_i}(x)^{-1}$（$\theta_p$ 为指数映射的体积密度，平坦空间恒为 1）。
- **单核**：
  - 测地核 $K_{\text{geo}} = (1-\beta q_i)_+$
  - 体积校正核 $K_{\text{vc}} = a_i(x)(1-\beta q_i)_+$（取自 Pelletier 的流形 KDE 体积校正）
- **得分与能量**：$S_T = \epsilon + \sum_i K_T$，$E_T = -\beta^{-1}\log S_T$。能量极小 ⟺ 得分极大。核在距离 $h$ 处归零，**紧支撑**使远距离模式互不干扰，而支撑重叠可生成新模态。
- **记忆定义**：在某邻域内 $C^2$、$\nabla E_T = 0$、$\mathrm{Hess}\,E_T \succ 0$ 的点（非退化模态，排除平台与退化族）；距所有原始模式至少 $\eta$ 的称为 $\eta$-新颖记忆。

### 2.2 检索：黎曼均值漂移

- **算法 1（平坦权重黎曼均值漂移）**：活跃集 $A(x)=\{i: d(x,\xi_i)<h\}$；取 $v(x)=|A|^{-1}\sum_{i\in A}\log_x\xi_i$；更新 $T_t(x)=\exp_x(tv)$。空邻域返回查询点并标记 inactive。
- 这等价于 Epanechnikov 是平坦核的"影子核"（$-\kappa'(s)=\mathbf 1\{s<1\}$），即 Subbarao & Meer 的黎曼均值漂移在均匀权重下的特例；在注意力语言中即"按半径选键、等权聚合"。
- **定理 1（记忆保证）**：$\nabla S_{\text{geo}}=\beta k v$，故 $T_t$ 是带查询可算步长的梯度步；单点活跃时**一步精确召回**；只要 $0<t<2/\Lambda$，即使活跃集变化，得分仍严格上升（能量下降）；在记忆附近局部线性收敛，收缩率 $\le \max\{|1-tc|,|1-t\Lambda|\}<1$。
- 体积校正能量需要额外的体积梯度项（附录 O 给出方向 $v_{\text{vc}}$ 与 $\nabla E_{\text{vc}}=-W v_{\text{vc}}/S_{\text{vc}}$）；算法本身对等距变换等变。

### 2.3 稳定性与容量理论

- **定理 2（曲率改变稳定性而非驻点性）**：若模式间距 $>h$，两种能量在 $\xi_i$ 处梯度均消失，且
  - $\mathrm{Hess}\,E_{\text{geo}}(\xi_i)=\dfrac{g_{\xi_i}}{1+\epsilon}$（**永远稳定**）
  - $\mathrm{Hess}\,E_{\text{vc}}(\xi_i)=\dfrac{g_{\xi_i}-\mathrm{Ric}_{\xi_i}/(3\beta)}{1+\epsilon}$，故校正记忆稳定 **当且仅当** $\beta>\tfrac13\lambda_{\max}(\mathrm{Ric}_{\xi_i})$。
  - 单位球 $S^m$：$\beta>(m-1)/3$，即 $h^2<6/(m-1)$；双曲空间 $\mathrm{Ric}=-(m-1)g$，负曲率**强化**稳定性；等号处 Hessian 退化。
  - 曲率之所以出现：$\theta_p(\exp_p v)=1-\mathrm{Ric}_p(v,v)/6+O(\|v\|^3)$——线性项消失保驻点，二次项改变稳定性。低于阈值时球面校正核的极大值落在**偏离中心的壳层**上（非非退化记忆）。
- **容量（定理 M.1、命题 M.4）**：定义 $q_h=P\{d(X_1,X_2)<h\}$ 为核重叠概率。在这些尺度下，**保留 = 不存在距离小于 $h$ 的碰撞对**（几乎必然）。于是
  - 全模式保留：$N^2 q_h \to 2\lambda \Rightarrow P(A_T)\to e^{-\lambda}$，$N_\delta \sim \sqrt{-2\log(1-\delta)/q_h}$（$q_h^{-1/2}$ 标度）
  - 典型模式保留：$N_{\text{typ},\delta}\sim -\log(1-\delta)/q_h$（$q_h^{-1}$ 标度，正好差一倍指数）
  - 球面 $S^m$ 固定 $h<\pi/2$：$\log N_\delta^{\text{geo}} = -\tfrac{m}{2}\log\sin h + o(m)$，典型容量为其两倍；校正容量在 $\beta\le(m-1)/3$ 时为零。取 $h=c/\sqrt m$（$c<\sqrt6$）则 $\log N_\delta = \tfrac m4\log(m/c^2)+O(\log m)$。
- **存储 vs 密度一致性不相容（推论 Q.1）**：高概率全模式存储要求 $N^2h^m\to0$，而归一化 KDE 的均方一致要求 $Nh^m\to\infty$，二者无法在同一带宽下同时成立。

### 2.4 涌现记忆理论

- 用活跃子集刻画：$U_A=\bigcap_{i\in A}B_h(\xi_i)$，$C_A=\{x\in U_A: d(x,\xi_j)>h,\ \forall j\notin A\}$。
- **定理 3（每个活跃子集至多一个候选）**：在强凸支撑与校正核凹性假设下，测地候选满足 $\sum_{i\in A}\log_x\xi_i=0$，即**内蕴（Fréchet）均值**；校正候选满足带体积梯度力的平衡方程 (19)，一般不是普通 Fréchet 均值（平坦时 $a_i\equiv1$ 退化为欧氏子集均值）。候选成为记忆需落在 $C_A$。由此 $N_{\text{tot}}^T\le 2^N-1$，全保留时 $N_{\text{em}}^T(\eta)\le 2^N-N-1$；支撑域内无鞍点。
- **定理 4（设计 vs 随机的分野）**：
  - **设计**：在 $T_pM$ 上取中心化正单纯形并指数映射，只要 $h\le c_\tau/\sqrt N$（$2\le N\le m+1$），两种能量都精确实现全部 $2^N-1$ 个模态

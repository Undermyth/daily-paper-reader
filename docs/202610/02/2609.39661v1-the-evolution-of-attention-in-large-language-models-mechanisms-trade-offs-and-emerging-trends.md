## 摘要
自注意力使大型语言模型能够以细粒度、依赖查询的方式访问上下文，但稠密的 token 交互会带来二次方的预填充成本，以及随上下文长度增长的键-值缓存。因此，研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动力学以及异构机制组合。本综述将这些进展视为模型内部的上下文记忆并加以分析。我们引入一个五维视角——记忆表示、记忆更新、访问、读出与集成——分别描述：表示了什么、如何变化、哪些内容可被查询、如何被读取，以及读出如何形成输出。这一视角能够比较相互重叠的研究路线，而不强加某一种计算模型。我们利用来自 14 个主要模型谱系的 59 条发布级记录和 11 个高性能开放权重端点，重建了机制层面的发展和架构采用情况。首先，显式记忆方法和循环状态方法保留了不同的接口，但日益控制着相互重叠的记忆功能。其次，异构架构日益在网络深度上进行协调：逐层组合将互补的记忆处理分布到不同表示阶段，而跨层复用则将选定的记忆和路由产物向前传递。因此，深度成为构建和管理上下文记忆的一个维度。第三，这些发展促成了一个有状态的多维记忆路由假设：持久记忆按照时间范围、网络深度、基底类型和表示粒度进行组织，而协调的稀疏写入和稀疏读取决定维持哪些内容以及哪些内容对每次查询有所贡献。总体而言，高效序列架构设计日益关注上下文记忆的组织、生命周期和选择性使用，而不是孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

- **背景**：Transformer 以自注意力取代循环传播，使每个 token 能通过内容相关的直接交互聚合上下文，从而实现高度并行训练，成为现代 LLM 的计算基础。

- **深层问题**：更长的名义上下文窗口并不自动保证对远距离证据的可靠使用——候选集扩大反而增加检索干扰、削弱长程召回。

## 2. 方法论：五维记忆中心分析透镜

### 2.1 核心思想

将 Softmax Attention、Sparse Attention、Linear Attention、State Space Models 及 Hybrid Architecture 统一视为"模型内部上下文记忆"系统，用五个功能维度刻画每种方法对记忆函数的修改，而不强加单一计算模型。五个维度为**分析角色**而非固定执行阶段，同一操作可同时承担多个角色。

### 2.2 五维定义与公式

设模型已处理前 t−1 个 token，正在处理 token t，x_t 为当前输入，q_t 为查询表示，ρ 为记忆模式（记录类型、组织、粒度、容量、持久性），M_t 为 t 位置维持的记忆。

- **记忆表示（Memory Representation）**：过去哪些信息仍被表示、以何种形式。M_t ∈ M_ρ。引入两个关键属性——历史覆盖度（多少前序序列可影响记忆）与可寻址性（特定历史单元是否仍可单独选取）。
- **记忆更新（Memory Update）**：当前输入如何增删改写记忆。M⁺_t = Update_ρ(M⁻_t, x_t)。涵盖追加式 KV 缓存、循环状态转移、压缩到固定容量槽位、受控擦写规则。
- **访问（Access）**：哪些已表示信息对当前查询合格。C_t = Access_ρ(q_t, M̂_t)。Softmax Attention 暴露全部因果可用单元；局部/块稀疏仅暴露结构允许位置；学习式稀疏用路由器/Top-k 构造查询相关候选集；循环机制暴露当前状态接口。
- **读出（Readout）**：合格信息如何被加权、解码或聚合。r_t = Readout_ρ(q_t, C_t)。Softmax Attention 做归一化 query–key 加权；Linear Attention 通过核化收缩读取关联状态；SSM 通过结构化投影读取循环状态。
- **集成（Integration）**：一个或多个完成的读出如何变换或组合成模块输出。o_t = Integration_ρ(r_t; x_t)。多头拼接加输出投影、门控、路由、异构路径融合等。

### 2.3 研究路线分类

- **四条机制中心路线**：Softmax Attention（显式记忆单元，重点在表示与更新）、Sparse Attention（显式 token/块 KV，重点在访问）、Linear Attention（关联循环状态，重点在表示与更新）、State Space Models（结构化循环状态，重点在表示与更新）。
- **一条组合中心路线**：Hybrid Architecture（异构记忆基底，按层、头、分支、token 粒度组合）。

## 6. 主要结论与发现

- **注意力设计呈多样化而非收敛**：密集 MHA 演化为 MQA/GQA 减少 KV 头冗余；MLA 压缩每 token KV 表示；局部与稀疏注意力限制显式访问；Gated DeltaNet、Lightning Attention、KDA、Mamba 等循环机制以固定大小状态替代部分重复 token 检索。这些路线继续共存而非形成单一替代路径。
- **模型谱系非单调演进**：DeepSeek 从 MLA → MLA 稀疏检索 → CSA/HCA → CSA2；Qwen 从 MHA/GQA → 循环状态+全注意力 → 稀疏注意力；MiniMax 从 Lightning/Softmax 混合 → 全 GQA → 密集/稀疏注意力；LongCat 从 MLA → LSA。
- **混合化加剧，跨层复用兴起**：2026 年 63% 的可分类记录为 Hybrid，主要采用预定层间调度；跨层复用将检索索引、Top-k 候选决策、KV 表示跨深度持久化，但目前仅 5 条记录。
- **性能前沿保持异构**：11 个端点包含全 GQA、潜在压缩稀疏、块稀疏、局部/全局或压缩密集/稀疏混合、循环状态+显式检索；**所有选中架构都保留显式 token 检索路径**，表明循环状态与稀疏性目前是补充而非统一替代 token 可寻址注意力。
- **机制层面控制范围重叠**：显式记忆方法从表示与访问效率扩展到有界更新、读出调制、输出协调；状态方法从状态表示与循环更新扩展到多记忆单元、选择性访问、更丰富读出、协调集成。趋同在于**控制范围**而非共享记忆基底。
- **网络深度成为记忆组织的新维度**：逐层组合决定各深度的记忆处理，跨层复用决定哪些产物跨深度持久存在。

## 7. 优点

- **统一分析框架**：五维记忆透镜（表示、更新、访问、读出、集成）为历史上独立、术语各异的四条研究路线提供共同词汇，且明确声明维度是"功能角色"而非强制计算图，避免过度形式化。
- **公式化抽象适度**：Eq. (1)–(5) 用统一符号覆盖追加式 KV、循环状态转移、压缩槽位、受控擦写等多种机制，既保持可比性又不失具体性。
- **机制与架构双线结合**：方法级综述（第 3–7 节）与架构级清单分析（第 8 节）互补，既有技术深度又有实证采用图景。
- **前瞻假设具体可测**：多维记忆路由假设给出四坐标地址空间与稀疏写/读公式，并提出四条渐进式可测试研究方向（工作负载感知差异化表示、非对称记忆构建与检索、增量记忆生命周期、任务条件联合路由）。
- **学术严谨性**：反复声明描述性定位、排除因果归因、标记 undisclosed 记录、说明清单非穷举。
- **覆盖全面**：涵盖 Softmax Attention 的头共享/通道压缩/层共享、Sparse Attention 的结构约束/自路由/辅助代理/时序与跨层复用、Linear Attention 的保留-擦除-写入分解与容量/时序扩展、SSM 的结构化动力学与读写接口、Hybrid 的四种组合粒度。

## 8. 不足与局限

- **无定量实验验证**：作为综述，未在统一基准下对比各机制的实际质量-效率权衡，五维分析的"控制范围重叠"等结论主要为定性归纳。
- **清单选择偏差**：59 条记录为有目的性筛选，非穷举、非市场份额加权，可能遗漏重要架构；14 个谱系集中在主流开源模型，闭源模型覆盖有限。
- **前沿对比的因果风险**：排行榜分数受模型规模、训练数据、后训练、推理预算、系统实现等多因素影响，无法将性能归因于注意力设计；11 个端点的快照仅代表特定时间点。
- **跨层复用证据薄弱**：仅 5 条记录、3 种架构模式（GLM、DeepSeek、LongCat），论文自身承认"当前证据仍集中于少数架构记录"，结论的普适性有限。
- **前瞻假设未经验证**：多维记忆路由为设计假设，其价值取决于能否在匹配的记忆、计算、路由预算下改善实际质量-效率前沿；论文列举的延迟依赖、特征对齐、记忆归属、陈旧控制、有害写入恢复、负载均衡、长程信用分配等均为开放难题。
- **范围排除**：测试时学习、外部数据库检索、多模态特定记忆设计、纯实现优化被排除在核心分类之外，可能遗漏与上下文记忆语义直接相关的交叉方向。
- **未涉及算力与训练细节**：无法评估各机制在真实训练/部署中的资源开销对比。
- **分类主观性**：章节标签为"编辑归属"而非互斥划分，部分方法（如 NSA、CSA、QSA）同时涉及表示压缩与访问控制，归类存在解释空间。

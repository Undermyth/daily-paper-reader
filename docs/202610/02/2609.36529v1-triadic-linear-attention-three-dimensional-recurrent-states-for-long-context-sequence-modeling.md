## 摘要
循环神经网络（RNN）将历史上下文压缩为固定大小的记忆状态，从而支持常数时间推理。记忆状态的大小是其性能的关键因素，正如线性注意力的强劲表现与复兴所表明的那样：它将普通 RNN 的向量值隐状态扩展为矩阵值隐状态。关键在于，线性注意力以参数高效的方式实现这一点，特别是通过使用键向量与值向量的外积来写入矩阵值隐状态。我们推广了这一构造，并提出三元线性注意力：它将一个键、第二个键和一个值的三元外积写入三阶（即三维）张量状态，并通过用两个查询分别与两个键轴进行缩并来从中读取。因此，一个 $E$ 维的第二键使状态大小扩大为原来的 $E$ 倍，而仅增加两个投影。三元线性注意力与数据依赖的遗忘、delta 规则以及分块并行训练兼容。应用于 Gated DeltaNet 和标量门控线性注意力时，三元线性注意力显著改善了长上下文语言建模和召回，优于那些扩大状态的替代方案。

## Abstract
Recurrent neural networks (RNNs) compress the historical context into a memory state of fixed size, thus allowing for constant-time inference. The memory state size is a crucial factor in their performance, as exemplified by the strong performance and resurgence of linear attention, which extends the vector-valued hidden states of ordinary RNNs to matrix-valued hidden states. Crucially, linear attention does so in a parameter-efficient way, in particular by using an outer product of the key and value vectors to write to the matrix-valued hidden state. We generalize this construction and propose triadic linear attention, which writes the triadic outer product of a key, a second key, and a value, into a third-order (i.e., 3D) tensor state, and reads from it by contracting both key axes with two queries. An $E$-dimensional second key thus yields an $E$-fold increase in state size while adding only two projections. Triadic linear attention is compatible with data-dependent forgetting, the delta rule, and chunkwise-parallel training. Applied to Gated DeltaNet and scalar-gated linear attention, triadic linear attention substantially improves long-context language modeling and recall, outperforming alternatives that enlarge the state.

# 三元线性注意力（Triadic Linear Attention）论文总结

## 1. 核心问题与研究动机

- **背景**：循环神经网络（RNN）以固定大小的记忆状态压缩历史上下文，支持常数时间推理。线性注意力（Katharopoulos et al., 2020）将普通 RNN 的向量值隐状态提升为矩阵值隐状态，用键与值的外积（dyadic outer product）写入状态，从而以参数高效的方式扩大了记忆容量，使现代线性 RNN 能在保持可并行训练的同时超越经典 RNN。
- **核心问题**：状态大小决定了模型能召回多少上下文——固定状态甚至无法完成超过一定长度的复制任务（Jelassi et al., 2024），现代线性注意力在召回密集和长上下文任务上仍会退化（Arora et al., 2024；Hsieh et al., 2024）。
- **关键矛盾**：朴素地扩大状态会显著增加参数量——增加注意力头会扩大所有投影，增大 value 维度或增加 value 头同样会扩大 value 和输出投影。因此核心问题是：**如何以参数高效的方式扩大线性注意力的状态？**
- **洞察**：线性注意力通过两向量的二阶外积把经典 RNN 的向量状态"升一阶"得到矩阵状态；这可以推广到 n 个向量的外积，得到 n 阶张量状态。本文取 n=3，即**三元线性注意力**。

## 2. 方法论

### 2.1 核心思想

- 将状态从矩阵 $S_t \in \mathbb{R}^{d \times d}$ 扩展为三阶张量 $S_t \in \mathbb{R}^{d \times E \times d}$。
- 每个位置除产生 $q_t, k_t, v_t \in \mathbb{R}^d$ 外，额外产生第二键 $k'_t$ 与第二查询 $q'_t \in \mathbb{R}^E$（仅通过两个线性投影）。
- **写入**：用键、第二键、值的三元外积更新状态；**读取**：用两个查询分别收缩两个键轴：

$$S_t = S_{t-1} + k_t \otimes k'_t \otimes v_t, \quad o_t = S_t \times_1 q_t \times_2 q'_t = \sum_{s \le t} (q_t^\top k_s)(q'_t{}^\top k'_s) v_s$$

- $E=1$ 且 $k'_t=q'_t=1$ 时退化为普通线性注意力。
- **容量视角**：状态有 $d^2 E$ 个条目（$E=d$ 时对 $d$ 呈立方），但参数只增加两个投影，状态/参数比渐近提高。实际取小 $E$（如 8）使参数开销可忽略（$E=8$ 仅增约 1.2% 参数）。
- **理论解释**：在 Smolensky（1990）的张量积表示中，值（filler）被绑定到两个角色（key 与 second key）上，用两个查询解绑。正交角色下，n 阶张量积表示可精确存储 $d^{n-1}$ 个关联，故绑定第二键把容量从 $d$ 提升到 $d^2$。

### 2.2 关键技术细节

- **数据依赖遗忘**：沿第二键轴为每个切片 $S_t[:,e,:]$ 赋予独立的标量衰减门 $\alpha_{t,e}$：
  $$S_t = S_{t-1} \times_2 \mathrm{diag}(\alpha_t) + k_t \otimes k'_t \otimes v_t$$
- **Delta 规则**：先联合移除两个键下当前存储的值，再写入新关联：
  $$S_t = S_{t-1} + \beta_t k_t \otimes k'_t \otimes \big(v_t - S_{t-1} \times_1 k_t \times_2 k'_t\big)$$
- **与 GDN 等价的形式**：将两键外积展平为联合键 $\kappa_t = k_t \otimes k'_t \in \mathbb{R}^{dE}$，则更新等价于键维度为 $dE$、以联合查询 $q_t \otimes q'_t$ 读取的 Gated DeltaNet，并带每切片标量衰减。

### 2.3 高效实现（分块并行）

- **联合键内积分离**：$(q_r \otimes q'_r)^\top (k_s \otimes k'_s) = (q_r^\top k_s)(q'_r{}^\top k'_s)$，因此块内 masked attention 只需 $C\times C$ 矩阵 $R' = \mathrm{tril}(Q'K'^\top)$，计算量为 $C^2(d+E)$ 而非 $C^2(dE)$。
- **状态切片（tiling）**：把 $d\times E\times d$ 状态沿 value 轴切成 32 列一块，每个 thread block 在寄存器中保存自己列的全部 $E$ 个切片，从而任何 SM 都不必持有完整三阶状态（$E=8$ 时单头状态 FP32 占 512 KiB，超过 Hopper SM 寄存器文件，而一块仅 128 KiB）。
- **完整分块形式**（含遗忘与 delta 规则）：每切片有累积衰减矩阵 $\Gamma_e$，衰减后的联合键内积仍可分离为键项与第二键项；UT 变换矩阵 $T$ 对所有 $E$ 切片相同，由 $d$ 维键与 $R$ 的 $C^2E$ 项构成。
- **数值稳定性**：每个切片仅一个标量衰减，衰减因子直接以累积 log 门之差的指数计算，差值非正，永不溢出，无需 clamp；作者指出更省 exp 的"参考点"构造会引入正指数、在 FP32 下溢出，故逐元素构造 $R$ 与 $R'$。
- **Kernel**：用 CUTLASS CuTe DSL 为 Hopper GPU 实现，warp-specialized，前向保存每块起始状态的 BF16，反向做短反向递推，梯度按固定归约顺序可比特级复现，并已对 FP64 参考验证（相对 $\ell_2$ 误差 <1%）。

## 3. 实验设计

### 3.1 模型与训练

- **规模**：400M（24 层，$d_{model}=1024$，8 头）与 1.3B（24 层，$d_{model}=2048$，16 头），头维 $d=128$。
- **基础 mixer**：Gated DeltaNet（GDN）与 scalar-gated linear attention（sGLA，即去掉 erase 项的 GDN）。
- **训练**：每个参数 50 tokens（约 2.5× Chinchilla 最优），即 400M 用 20B tokens、1.3B 用 65B tokens；预训练于 Fineweb-Edu（4k 上下文），再在 Fineweb-Edu + PG19 + 科学 PDF 混合数据上扩展到 64k（每参数 5 tokens）；AdamW，峰值学习率 $3\times10^{-4}$（预训练）/ $10^{-4}$（扩展）。

### 3.2 数据集与 Benchmark

- **MQAR**（multi-query associative recall）：验证纯容量，$N$ 从 32 到 4096。
- **语言建模**：PG19（按上下文位置报告困惑度，分 ≤4k / 4k–16k / 16k–64k）、WikiText-2。
- **召回密集任务**：Arora et al. (2024) 的六个任务——DROP、NQ、TriviaQA、FDA、SQuAD、SWDE。
- **Zero-shot**：LAMBADA、HellaSwag、PIQA、ARC-Easy、ARC-Challenge、WinoGrande、OpenBookQA、SciQ、BoolQ、COPA（lm-eval harness）。
- **长上下文检索**：RULER 的八个 NIAH 任务（1k–64k）。

### 3.3 对比方法

- **Transformer 基线**：RoPE（预训练 base 10k、扩展 2M）+ QK-norm + GQA-8。
- **同状态大小下的扩大状态替代方案**：更大的头维（fewer heads）、更宽的 value 维度、每 key 多个 value 头（grouped values）、更多头。均在匹配参数量下比较（必要时缩小 MLP 宽度）。
- **消融**：固定联合键维度 $dk\cdot E=1024$ 下比较 $(dk,E)=(128,8),(64,16),(32,32)$ 及 tied keys；第二键/查询的激活函数（softplus、sigmoid、SiLU、无激活）。
- **Upcycling**：把预训练的 $E=1$ 模型扩展到 $E=8$，在长上下文扩展阶段适配。
- **Hybrid**：3:1 GDN/GQA-8 混合模型，对比放大 KV cache（GQA-4）与放大线性注意力状态（Triadic $E=4$）。

## 6. 主要结论与发现

- **容量确实扩展**：MQAR 中每翻倍 $E$ 使准确率曲线右移约一倍 $N$；$E=16$ 时约可存储普通线性注意力 16 倍的键值关联，而非嵌入参数仅增 1.08 倍。
- **长上下文语言建模显著改善**：GDN 约在 10k 处被 Transformer 反超，而 Triadic GDN $E=8$ 在 64k 仍优于 Transformer；Triadic 在 PG19 各区间和 WikiText 上均取得最低困惑度。
- **召回能力大幅提升**：在 6 个召回任务上优于所有同状态大小的替代扩大方案（尤其在 FDA、SWDE 等需从长文档复制信息的任务）。
- **优于其他扩大状态方法**：更大的头/更宽 value/更多 value 头/更多头在 2× 时几乎无提升，4× 时甚至在所有 PG19 区间退化（因需大幅缩小 MLP）；Triadic 因仅加两个小投影而保持完整 MLP。
- **Upcycling 可行**：把预训练 $E=1$ 模型在长上下文扩展阶段扩展为 $E=8$，可恢复从零训练 triadic 增益的一半到四分之三。
- **Hybrid 中更优**：3:1 Triadic GDN/GQA-8 在所有上下文区间困惑度最低、NIAH 最佳，且 4.6k tokens 后比 GQA-4

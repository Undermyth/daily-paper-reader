## 摘要
现代人工智能主要在针对稠密线性代数优化的计算架构上执行。尽管这促成了当代神经网络的成功，并推动了存内计算（CIM）架构的发展，但越来越多的人工智能（AI）工作负载依赖于联想检索，即通过内容或相似性而非显式内存地址来识别已存储的信息。此类操作是Transformer注意力、基于树的推理、基因组搜索及其他检索密集型应用的核心，但传统存储系统对其支持仍然低效。在本观点文章中，我们认为内容可寻址存储器（CAM）为AI中的联想处理提供了一种互补的硬件原语。我们综述了其执行大规模并行内存内匹配的能力，讨论了新兴存储技术如何提升密度和能效，并将层次化搜索、特定应用架构、硬件感知学习以及与CIM的异构集成确定为可扩展联想计算的关键方向。这些进展共同表明，联想检索应作为未来AI系统的基础计算原语，与线性代数形成互补。

## Abstract
Modern artificial intelligence is predominantly executed on computing architectures optimized for dense linear algebra. While this has enabled the success of contemporary neural networks and motivated compute-in-memory (CIM) architectures, a growing class of artificial intelligence (AI) workloads depends on associative retrieval, identifying stored information by content or similarity rather than by explicit memory addresses. Such operations are central to transformer attention, tree-based inference, genomic search, and other retrieval-intensive applications, yet remain inefficiently supported by conventional memory systems. In this Perspective, we argue that content-addressable memories (CAMs) provide a complementary hardware primitive for associative processing in AI. We review their ability to perform massively parallel in-memory matching, discuss how emerging memory technologies can improve density and energy efficiency, and identify hierarchical search, application-specific architectures, hardware-aware learning, and heterogeneous integration with CIM as key directions for scalable associative computing. Together, these developments suggest that associative retrieval should complement linear algebra as a foundational computing primitive for future AI systems.

## 2. 方法论：核心思想与关键技术细节

本文是 **Perspective（观点/展望）文章**，方法论体现为"跨层次框架构建 + 技术路线论证"，而非提出新算法。其核心框架如下。

### 2.1 CAM 的通用计算原理

- 两个基本构件：
  - **CAM cell**：存储 key，并将输入查询与 key 的关系评估为局部匹配信号 $m_{i,j}$。
  - **Match Line (ML)**：沿行汇总所有 cell 响应，形成字级结果。
- 汇总方式决定输出语义：
  - **NOR 型**：字级精确匹配（任一 cell 失配即整行不匹配）。
  - **ADD 型**：累加得到连续**相似度分数**。
- 匹配模态谱系：**Binary (BCAM) → Ternary (TCAM，含 "don't care" 状态 X) → Analog (aCAM，范围比较 $m = K_{LB} < Q < K_{HB}$) → 其他分级相似度度量**。

### 2.2 器件技术版图（按技术路线梳理）

- **SRAM TCAM**：工业标准，高速可靠、工艺成熟，适合网络/包分类/路由等延迟敏感场景，但**单元面积大、容量受限**。
- **DRAM CAM**：动态存储更紧凑，部分缓解面积问题，代价是鲁棒性/保持性/电路简洁性下降。
- **Flash / 浮栅**：非易失、多值、可密集堆叠（IGZO、MoS₂ 等薄膜氧化物与低维材料），可编程模拟阈值可直接定义 aCAM 的匹配边界，省去额外阈值电路；但匹配边界继承晶体管有限开关斜率与变异性，会"软化"阈值、限制可靠状态数。
- **FeFET**：以铁电极化而非浮栅电荷存储，避免电荷注入/隧穿，编程电压从数十伏/微秒级降到**几伏/纳秒级**，同样支持非易失多值阈值漂移。
- **忆阻器（相变、丝状阻变）**：高密度、非易失、模拟可编程；早期 memristor-CMOS 混合 CAM → 大量 BCAM/TCAM 架构 → 6T2M 型模拟 CAM（存连续匹配边界）。因是无源两端器件，需 CMOS 做阈值与增益，形成**密度–判别力权衡**。
- **Gain-cell aCAM**：紧凑动态存储 + 模拟联想搜索，写速度快、写耐久近乎无限，适合联想缓存层次；IGZO 等氧化物半导体平台可支持单片 3D 集成。
- **其他**：MTJ、铁电 memcapacitor（尚不成熟）；光/光电 CAM（利用光并行与波分复用，可高吞吐，但制造、热稳定性与光电集成限制其规模化）。

### 2.3 联想存储层次（关键架构思想）

- 沿用传统存储分层的逻辑：没有任何单一技术能同时优化密度、延迟、带宽、能效与保持性。
- 用雷达图沿三维（**密度、保持性、可编程性**）比较技术与应用；可编程性与密度基本互相张力：快写电荷型单元要么大（SRAM）要么易失（DRAM/gain cell），非易失高密度机制则编程慢、耐久受限。
- 简化为两个端点（作者明确承认这是刻意简化，中间层级很可能存在）：
  - **Tier-1 动态/写密集 CAM**：面向频繁更新的表征（embedding、描述子、传感状态），贴近加速器或传感前端；典型例：视觉位置识别（VPR，特征匹配占执行时间约 60–70%）、注意力与 token 复用、持续更新原型的学习硬件、两阶段基因组搜索的第二阶段。
  - **Tier-2 静态/搜索密集 CAM**：面向大容量、少更新、频繁查询的数据集，优先搜索能耗、密度与可扩展性；典型例：路由与包分类表、数据库检索、大规模最近邻、树推理、基因组。

### 2.4 缩放与三维集成

- 中心矛盾：**传感裕度 vs 存储密度**。裕度大需更多晶体管/隔离/增益级 → 面积大；紧凑单元裕度小、状态少 → 对变异与阵列寄生更敏感。大阵列中裕度、互连负载、ML 电容、搜索带宽成为耦合的系统级约束。
- **2D 材料**的价值：原子级薄体改善静电控制、抑制短沟道泄漏、降低寄生电容；最直接收益是每个 cell 挂在 ML 上的漏极电容——薄体在绝缘体上无体结可耗尽，降低 $CV^2$ 搜索能量与 ML 的 RC 延迟（前提是维持读电流）。读电流更依赖接触与界面而非沟道材料本身，半金属接触/边缘接触可降低接触电阻与费米钉扎。
- **BEOL 兼容 → 单片 3D 集成**：2D 沟道与薄膜氧化物半导体可把存储/搜索层直接堆在 CMOS 逻辑之上，缩短存储与外围电路布线、降低互连寄生；但不消除密度/保持/可编程/传感鲁棒性之间的根本折衷，最适合"受面积与布线而非单元本身限制"的场景。
  - 静态层 → 2D flash（双栅结构天然适合垂直堆叠互补单元，无需外部模拟反相器）。
  - 动态层 → IGZO 等氧化物半导体 gain-cell aCAM（低关态电流延长保持时间、放松刷新开销）。
- 真正的开放问题不是"这些材料能否演示 CAM 行为"，而是**能否制造成可扩展的 3D 联想系统**：稳定模拟可编程性、可控存储窗口、足够保持与耐久、低器件间变异，以及晶圆级合成、层间对准、热预算管理、选择器/灵敏放大器/数字控制的共集成。

### 2.5 应用映射方法（算法流程层面）

- **树模型推理**：每条根到叶路径映射为 CAM 一行；内部节点的"< / >"不等式映射为 CAM cell 中存储的范围；叶子区域/类别标签由后续 crossbar 取回。优点是可用标准算法离线训练后**一对一映射**，无需端到端可微内存访问；硬件挑战转为搜索边界的精确编程与验证。
  - **软决策树**：利用阈值可调器件的**内在软边界（sigmoid 形）**，将器件非理想性转为概率计算原语，输出 30%/70% 之类的连续匹配度，用于软决策树节点的门控函数。
- **基因组分析（按数据库规模选架构）**：
  - KB–MB（病毒）→ 高速 NOR CAM，序列顺序映射（内存冗余大）。
  - GB（人类基因组）→ 必须做搜索空间缩减：优化索引 + CAM 分区。
  - TB 级（宏基因组、蛋白结构预测）→ 高密度 NAND CAM + 软硬件协同（哈希表、minimizer）。
  - 精度/速度权衡：近似匹配通过调节灵敏放大器参考电压实现；NGS 低错误率（~0.01%）用组合逻辑容忍单个 indel（EDAM、Asmcap）；TGS 高错误率（可达 5%）用 ShiftCAM 的时域移位逻辑容忍多个 indel；Levenshtein 自动机直接映射到 TCAM 可精确计算编辑距离但需迭代、牺牲速度；定向测序用 LSH-TCAM 直接从纳米孔原始信号提取二值特征（最快但损精度）。
- **Transformer 注意力**：把 QK 查找直接实现在 CAM 内，避免显式大矩阵乘与 softmax，从而简化 CIM 硬件。挑战与路径：
  - 预训练模型不能直接迁移，需重训练；梯度优化需要可微内存访问，而多数 CAM 操作不可微且无自然反向路径，现有做法依赖代理模型/近似梯度，可能降低训练稳定性、可扩展性与精度。
  - 替代范式：**非可微的检索式注意力**（kNN 式 Memorizing Transformers、选择性取回 KV 条目的稀疏注意力），把联想查找与梯度传播解耦，特别适合 CAM 硬件。
  - CAM 可作**预选器/排序引擎**，先筛出相关 KV 条目；进一步用层次化联想结构逐步路由查询到更小的记忆子集，减少无效阵列激活。
  - 理论观察：注意力几乎只用缩放点积相似度，可能更多反映其在 GPU 线性代数上的高效映射，而非联想检索意义上的内在最优；Manhattan/Euclidean 距离等替代度量在鲁棒性与记忆容量上可能更优。
- **与 CAM 相关的机器学习方法**：
  - 离线路线：树模型常规训练 + 边界感知编程/验证（利用器件与 CMOS 变异是静态的这一性质，逐 cell 校准到目标不等式边界，而非追求相同物理状态）。
  - 代理模型路线：TorchCAM 用浅 sigmoid 建模边界并在训练中逐步锐化，提供代理梯度；L2S 用可微代理电路模型计算梯度优化忆阻器电导，可在训练中补偿 ML 串扰等非理想性。
  - 在硬件内学习：需可微 CAM（平滑浅边界），但可微性提升通常以**存储容量与选择性下降**为代价；全硬件反向传播需 cell 级电路改造支持转置 CAM 操作，面积开销剧增。替代方案：Hebbian 式局部更新、频分复用梯度下降、节点扰动训练等前向/局部学习规则。

### 2.6 从阵列到系统架构

- **设计自动化**：Eva-CAM（跨抽象层次的异构 CAM 技术感知评估）、X-TIME（树模型到 aCAM 的硬件感知映射）、C4CAM（把高层程序编译到异构 CAM 加速器）——类比 GPU 生态中编译器与编程框架的角色。
- **应用专用架构**：
  - ShiftCAM 两阶段：第一阶段时域移位容忍 indel 做粗筛，第二阶段用 TCAM + Levenshtein 自动机做精细编辑距离匹配；因候选位置随查询变化，需动态存储，可用 IGZO/2D 材料的 BEOL 兼容性通过高密度 3D 集成实现。
  - **Soft CAM**：候选路径映射为行，cell 响应评估软节点条件，模拟信号沿 ML 累加，每行携带类概率置信度，经校准传感后用 **winner-take-all** 硬件读出；关键要求是保持行级概率的相对次序（而非只最大化二值匹配判别度）。
- **与 CIM 异构集成（两种方向）**：
  - **异联想记忆**：CAM 存 key 做匹配 + crossbar 存 value 做取回，共同实现硬件查找表（LUT），类比注意力机制；MLSA/TIA 的模拟输出可直接驱动 CIM 阵列，省去中间 ADC，保持端到端模拟通路。已用于有限状态机、注意力、决策树（CAM 判规则、crossbar 取类标签）、KAN（CAM LUT 编码非线性激活）；网络化的 LUT 原则上可实现任意计算，FPGA 是最接近的实用范例。
  - **NL-DPE（非线性点积引擎）**：反向整合——crossbar 先做模拟点积，aCAM 取代 ADC 与数字后处理，把模拟输出直接与存储的可编程阈值/区间比较，输出落在哪个非线性区段的二值码；概念上类似 flash ADC，但比较电平是存储驻留、可编程的，可适配目标激活函数、信号统计甚至 DPE 校准。是否有利取决于所需

## 摘要
我们提出了一种基于几何的容量理论，用于压缩的有限特征 Hebbian 联想记忆中的精确键检索。对于随机或近似各向同性的值，检索干扰可分为有限特征噪声和结构干扰：前者随特征维度增加而减小，后者由存储键之间核重叠的平方决定，并在无限特征极限下依然存在。这产生了对检索质量的免拟合预测，揭示了依赖几何的容量上限，并预测了达到目标检索质量所需的特征预算。当存储值相关时，我们表明检索联合依赖于键核与值 Gram 矩阵，并推导了能够刻画这种相互作用的有限特征近似。我们在合成、视觉和医学图像表示上验证了该理论。总体而言，该框架将表示几何与记忆容量直接联系起来，并区分了何时可以通过增加特征预算来提高性能，以及何时必须改变表示本身。在这些设置中，预测的检索曲线与经验行为高度吻合，并正确识别出首选记忆设计的变化。

## Abstract
We develop a geometry-based capacity theory for exact-key retrieval in compressed finite-feature Hebbian associative memory. For random or approximately isotropic values, retrieval interference separates into finite-feature noise, which decreases with feature dimension, and structural interference, which is determined by squared kernel overlap among stored keys and persists in the infinite-feature limit. This yields a fit-free prediction of retrieval quality, reveals a geometry-dependent capacity ceiling, and predicts the feature budget required for a target retrieval quality. When stored values are correlated, we show that retrieval depends jointly on the key kernel and value Gram matrix, and derive finite-feature approximations that account for this interaction. We validate the theory on synthetic, visual, and medical-image representations. Overall, the framework links representation geometry directly to memory capacity and distinguishes when performance can be improved by increasing the feature budget and when the representation itself must be changed. Across these settings, the predicted retrieval curves closely match empirical behavior and correctly identify changes in the preferred memory design.

## 2. 方法论
### 2.1 核心思想
- 将有限随机特征 Hebbian 记忆视为“核加权的值混合器”：
  \[
  M=\sum_{j=1}^N \phi_R(k_j)v_j^\top,\quad
  \hat v_i=M^\top\phi_R(k_i)=\sum_{j=1}^N \hat K_{ij}v_j
  \]
  其中 \(\hat K_{ij}=\phi_R(k_i)^\top\phi_R(k_j)\)，检索质量用归一化余弦
  \[
  C_i(R)=\frac{\langle \hat v_i,v_i\rangle}{\|\hat v_i\|\|v_i\|}
  \]
  衡量。
- 对随机或近似各向同性值，干扰可分解为：
  - 有限特征项 \(\approx (N-1)/R\)；
  - 结构干扰项 \(I_{\text{struct},i}=\sum_{j\ne i}K_{ij}^2\)。

### 2.2 关键公式与流程
- **随机值容量律**：
  \[
  C_i(R)\approx \left[1+\frac{N-1}{R}+\sum_{j\ne i}K_{ij}^2\right]^{-1/2}
  \]
- **无限特征上限**：
  \[
  C_{i,\infty}\approx \left[1+\sum_{j\ne i}K_{ij}^2\right]^{-1/2}
  \]
  增加 \(R\) 只能降低有限特征噪声，不能消除结构干扰设定的上限。
- **目标余弦边界**：给定目标 \(C^\star\)，求解平均理论余弦 \( \overline{C}(R/N)=C^\star\)，得到所需 \(R/N\)。当结构干扰可忽略且 \(N\) 大时，\(C^\star=0.95\) 对应 \(R/N\approx 9.26\)。
- **随机特征细节**：使用 RBF 核，自动核尺度 \(\gamma_0\) 基于中位距离；广泛验证使用随机相位 cosine RFF 后行归一化；协方差分析使用成对 sine/cosine RFF，因其二阶矩有闭式表达。

### 2.3 相关值扩展
- 当值相关时，无限特征检索向量为核加权混合：
  \[
  y_{\infty,i}=\sum_j K_{ij}v_j
  \]
  定义 \(a_i=\langle y_{\infty,i},v_i\rangle\)，\(b_i=\|y_{\infty,i}\|^2\)，值 Gram 矩阵 \(G_{j\ell}=\langle v_j,v_\ell\rangle\)。
- 无限特征余弦精确为：
  \[
  C_{i,\infty}=\frac{a_i}{\sqrt{b_i}}
  \]
- 有限 \(R\) 近似：
  \[
  C_i(R)\approx \frac{a_i}{\sqrt{b_i+(N-1)/R}}
  \]
- 协方差感知修正：
  \[
  C_i^{\text{cov}}(R)\approx \frac{a_i}{\sqrt{b_i+2D_i/R}}
  \]
  其中 \(D_i\) 由成对 RFF 二阶矩和值 Gram 矩阵共同决定，主要用于设计边界比较，而非通用绝对容量预测。

# A Geometry-Based Capacity Theory for Finite-Feature Associative Memory 

## Jianhai Zhang *, Donghao Zhang, Pattarawut Charatpangoon, Bijoy Menon, M. Ethan MacDonald, Wu Qiu, and Aravind Ganesh *

## ✦

Abstract —We develop a geometry-based capacity theory for exact-key retrieval in compressed finite-feature Hebbian associative memory. For random or approximately isotropic values, retrieval interference separates into finite-feature noise, which decreases with feature dimension, and structural interference, which is determined by squared kernel overlap among stored keys and persists in the infinite-feature limit. This yields a fit-free prediction of retrieval quality, reveals a geometry-dependent capacity ceiling, and predicts the feature budget required for a target retrieval quality. When stored values are correlated, we show that retrieval depends jointly on the key kernel and value Gram matrix, and derive finite-feature approximations that account for this interaction. We validate the theory on synthetic, visual, and medical-image representations. Overall, the framework links representation geometry directly to memory capacity and distinguishes when performance can be improved by increasing the feature budget and when the representation itself must be changed. Across these settings, the predicted retrieval curves closely match empirical behavior and correctly identify changes in the preferred memory design. 

Index Terms —Associative memory, Hebbian memory, random features, representation geometry, kernel methods, memory capacity, visual representations, medical imaging.

Rather than treating capacity as an abstract storage quantity, we define it op-erationally through how many separable feature patterns can be preserved while maintaining acceptable retrieval or classification quality. In practical AI systems, this asks whether increasingly diverse image, patient, or other sample representations can be compressed into a fixed memory without losing the information that distinguishes them. This paper focuses on a compressed finite-feature regime. A collection of key–value pairs is aggregated into a fixed Hebbian matrix through additive outer products of nonlinear random-feature addresses. This storage rule is closely related to classical correlation-matrix memories and to fast-weight or linear-attention memories [14]–[19]. Prior work has already shown that finite-dimensional fast-weight memories degrade as many nonorthogonal keys are accumulated. Recent and concurrent work studies related aspects of this problem through self-recall diagnostics and sparse caching in linear attention, spherical-packing and Welch-bound analyses of linear-attention capacity, sharp pattern-count thresholds for linear associative memories, and Hebbian fact-storage models that allow arbitrary input/output geometry [20]–[24]. We therefore do not claim that nonorthogonality, geometry dependence, or capacity limits in linear memories are new phenomena. Our focus is narrower: we derive a quantitative item-wise law that uses the measured kernel geometry of the stored representations, separates deterministic overlap from finite-feature approximation noise, and remains applicable when stored values are correlated. We study exact-key retrieval, q = ki, so that the analysis isolates cross-talk caused by compressed storage. Throughout, capacity is operational: for a fixed set of N stored keys, it refers to the feature budget R/N required to reach a specified retrieval cosine, or equivalently the retrieval cosine attainable at a fixed budget. In practical terms, this asks: for a given representation and target retrieval quality, how large must the compressed memory be, and when does increasing the feature budget stop helping because the remaining interference is caused by the representation geometry itself? This is not an asymptotic pattern-count capacity claim for recurrent or explicit-storage memories. Robustness to corrupted, partial, or shifted queries is outside the scope of the present analysis. Random Fourier features (RFFs) provide a convenient finite-dimensional approximation to shift-invariant kernels arXiv:2610.09056v1 [cs.LG] 6 Oct 2026 2

[25]. Their approximation error has been studied extensively through structured constructions, variance reduction, and statistical guarantees [26]–[29]. In a compressed associative memory, however, accurate kernel approximation does not remove all cross-talk. If stored keys remain similar under the kernel, off-target values still contribute to retrieval even in the infinite-feature limit. This motivates separating two sources of error: finite-feature noise and structural interfer-ence caused by the geometry of the stored representations. This distinction is practically useful because the two failure modes require different remedies. Finite-feature noise can be reduced by increasing the feature budget, whereas structural interference requires changing the representation, kernel, or storage organization. This structural term is especially relevant for learned visual representations, whose pairwise geometry can vary substantially with architecture, training objective, centering, whitening, and kernel scale [30]–[34]. Effective rank summa-rizes spectral concentration [35], [36], but it does not describe the pairwise similarities seen by a particular memory kernel. We therefore work directly with the kernel matrix of the stored keys. Once the kernel, stored keys, number of items N , and feature budget R are specified, no coefficient is fitted to the measured retrieval curve. This matters because two representations with the same nominal dimension, or even a similar effective rank, can require very different memory budgets if their pairwise kernel geometry differs. We first test this law on i.i.d., clustered, low-rank, and anisotropic synthetic keys, and then on learned visual representations. ResNet50 and ViT-B/16 embeddings [37], [38] are evaluated under RAW, CENTERED, and PCA-WHITENED geometry interventions and across multiple kernel scales. CIFAR-10 and STL-10 provide additional data and background conditions for fit-free boundary prediction, while DINOv2 ViT-B/14 [39] and CLIP ViT-B/16 [40] extend the analysis to self-supervised and vision-language repre-sentations. As a public structured-domain stress test, we use the SynthRAD2023 Task-1 MRI–CT training data [41], comprising 180 brain and 180 pelvis pairs. We then use 445 spatially aligned brain NCCT–CTA pairs as an independent clinical cohort. These experiments test whether the same analytic dependence on measured kernel geometry holds across substantially different representation regimes. The medical settings are especially informative because anatomi-cally similar observations, adjacent slices, or patient-derived representations may coexist in the same finite memory. Their structured similarity can increase interference even when the nominal feature dimension is large. Real learned values require an additional step. When values are correlated, the infinite-feature retrieval vector becomes a kernel-weighted mixture of stored values, so its target cosine depends jointly on the key kernel and the value Gram matrix. We characterize this deterministic joint key–value geometry exactly and approximate only the finite-R perturbation. Aligned, permuted, and random-value controls then test whether value similarity is consistent with the neighborhoods defined by the key kernel. Repeated permutations are used to measure the stability of this effect rather than relying on a single random shuffle. Finally, we ask whether the theory can guide memory design rather than only explain observed retrieval behavior. Candidate preprocessing and kernel choices are ranked using their predicted capacity curves, and the predicted RAW-to-WHITENED transition is compared with the empirical crossover. More broadly, the framework separates two different remedies for poor retrieval: increasing the finite feature budget when approximation noise dominates, or changing the representation when structural interference sets the limiting ceiling. A covariance-aware finite-R term is not uniformly better for absolute-capacity prediction, but in our aligned real-value experiments it improves crossover prediction. The main contribution is therefore analytical rather than architectural: a geometry-dependent capacity law for compressed finite-feature memory, an extension to correlated values through joint key–value geometry, and a test of whether the same quantities can guide memory sizing and representation selection. ## 2 RELATED WORK 

2.1 Classical associative and correlation-matrix memo-ries 

Associative memory predates modern deep learning, with early distributed memories [1], persistent-state models [2], and Hebbian learning [3]. Particularly close to the stor-age rule studied here are early linear heteroassociative or correlation-matrix memories, which store key–value asso-ciations by additive outer products and retrieve a value by multiplying the resulting matrix by a cue [14], [15]. Hopfield networks introduced recurrent attractor dynamics [4], and classical statistical-mechanical and coding-theoretic analyses quantified storage transitions for random patterns [5]–[7]. Sparse coding can substantially alter capacity scaling [8], while sparse distributed memory provides a high-dimensional alternative [42]. Dense associative memories increase capacity by modifying the interaction or energy function [9], [10], with later work relating large-capacity models to hidden-unit constructions [11]. Our setting is clos-est to correlation-matrix memory, but replaces the original address vectors with a finite random-feature map and asks how the resulting kernel geometry controls cross-talk and exact-key retrieval quality. 

2.2 Fast-weight memories and linear attention 

Fast-weight models use rapidly changing matrices to store recent associations without retaining an explicit list of all past activations [16], [17]. This viewpoint is especially relevant to linear attention: kernelized linear Transformers rewrite attention as a feature-map outer-product memory that can be updated recurrently [18], and Schlag et al. showed the formal equivalence between such linearized attention and fast-weight programmers [19]. Their primary goal is efficient approximation of normalized attention, whereas we study exact-key retrieval quality of a fixed compressed Hebbian matrix. More recent work makes the memory-collision issue still more explicit. LoLA uses self-recall error to identify key– value pairs that a recurrent linear-attention state remembers poorly and protects them with a sparse cache [20]. KATA formulates associative recall as a spherical-packing problem and characterizes a capacity–interference trade-off through a Welch interference floor while designing new feature maps [21]. Complementary capacity analyses derive sharp pattern-count thresholds for linear associative memories under winner-take-all or strict-separation criteria [22], [23]. Concurrent Hebbian constructions for Transformer MLPs analyze decoding-margin storage scaling under arbitrary key and value geometries [24]. These results are closely related in mechanism or terminology, but address different observables and capacity notions. To our knowledge, they do not provide an item-wise, kernel-conditional normalized retrieval-cosine law for compressed finite-random-feature Hebbian memory that separates finite-feature approximation noise from deterministic key overlap, extends quantitatively to correlated values, and predicts finite-memory design choices directly from measured representation geometry. Our narrower question is therefore how measured key geometry determines exact-key retrieval cross-talk in this compressed storage rule, how finite-feature noise enters separately, and how the analysis changes for correlated values. 

2.3 Explicit neural memories and modern Hopfield net-works 

Memory Networks and end-to-end variants introduced learned read/write mechanisms over explicit external memo-ries [45], [46]; product-key memories provide efficient access to very large learned tables [47]. Transformer attention [48] and modern continuous Hopfield networks are closely related mathematically [12], while Universal Hopfield Net-works cast several memory models as similarity–separation– projection systems [13]; sparse distributed memory has also been connected to attention [49]. These methods typically retain, address, or parameterize individual memory items and therefore differ from the fixed-size compressed matrix analyzed here. We use them as contextual baselines rather than as storage-equivalent comparators. 

2.4 Random features and scalable kernel approximation 

Kernel methods provide a natural language for nonlinear similarity [50]. Low-rank Nystr ¨ om approximations [51] and random Fourier features (RFFs) [25] are canonical routes to scalable kernel learning. Subsequent work developed structured fast transforms [26], quasi-Monte Carlo maps [52], orthogonal random features [27], sharper approximation-error analyses [28], [53], kernel-ridge guarantees [54], general-ization bounds [55], quadrature connections [56], unified risk analyses [57], and random-matrix characterizations of high-dimensional random-feature models [58]. A TPAMI survey reviews this broader area [29]. Recent data-aware random-feature attention further adapts the projection distribution to anisotropic pretrained queries and keys to reduce Monte Carlo variance [59]. Our finite-feature term is related to this RFF approximation-noise problem. The structural term is distinct: it is determined by off-target kernel overlap among stored keys and remains even when the kernel itself is evaluated exactly. 

2.5 Representation geometry, whitening, and similarity structure 

Learned representations can differ substantially in anisotropy, spectral concentration, and pairwise similarity structure [60]. Decorrelation has been used as an explicit regularizer in supervised networks [30] and as a central ingredient of self-supervised methods, including whitening-based learn-ing [31], Barlow Twins [32], VICReg [33], and feature-decorrelation analyses [61]. Contrastive and non-contrastive 4

objectives such as SimCLR and BYOL provide distinct representation-learning regimes [62], [63]; subsequent work has explicitly analyzed alignment, uniformity, whitening, and dimensional collapse [31], [34], [64]. DINOv2 [39] and CLIP [40] provide additional self-supervised and vision-language representation families used in our evaluation. Neural and dimensional collapse give further examples of geometry changing independently of nominal dimension [34], [65]. Effective rank formalizes continuous dimensionality [35] and has been used to assess self-supervised representations [36]. Representation-comparison methods such as SVCCA [66] and centered kernel alignment (CKA) [67] use subspace or Gram/kernel structure rather than ambient dimension alone; spectral analyses of self-supervised learning likewise emphasize pairwise relations and task alignment [68]. In our setting, these geometric descriptors motivate the analysis but do not substitute for the memory-specific quantity P

For the headline capacity-boundary evaluation, empirical retrieval is evalu-ated on a fixed R/N grid shared across conditions rather than at theory-centered probes. Two discovery RFF seeds are used only to identify empirical bracketing intervals on this fixed grid, and 20 independent confirmation seeds are then used to estimate the final boundary by linear interpolation within the discovered brackets. 5.7 Finite-R covariance is regime dependent 

The simple finite-R correction gives the lowest global error over the tested range of R/N . A covariance-denominator correction improves aligned real values but can over-correct permuted values. A second-order delta expansion was also tested and had larger global error, particularly at small R/N ;it became competitive only at very large R. We therefore do not use higher-order delta terms in the main theory. Accordingly, Eq. (6) is used as a targeted design-boundary correction rather than as a replacement for the simpler absolute-capacity approximation.

## 6 DISCUSSION 

The experiments separate two effects that are often conflated in finite-feature associative memory: approximation noise from the finite random map and deterministic cross-talk induced by stored representation geometry. With correlated values, the relevant deterministic object expands from the key kernel to joint key–value geometry. This separation has a direct design consequence: poor retrieval caused by finite-feature noise calls for more memory, whereas poor retrieval caused by structural overlap calls for a different representation, kernel, or organization of stored items. The main implications are summarized below. 

6.1 Geometry, rather than nominal dimension or rank, controls the structural ceiling 

Our ResNet experiment gives a direct counterexample to dimension-only reasoning: PCA whitening reduces nominal dimension from 2048 to 256 while increasing the mean item-wise infinite-R ceiling from about 0.65 to about 1.0. Effective rank is informative about spectral concentration [36], but it is not sufficient either. Representations with similar ef-fective rank can have different structural interference, and changing kernel scale can reverse capacity while leaving rank unchanged. 6.2 The infinite-R ceiling and finite-R noise are distinct 

Structural interference remains even with an exact ker-nel, whereas finite random-feature noise decreases with increasing R. This separation explains why some geometries improve with additional feature budget while others saturate below a target cosine. It also clarifies the operational meaning of the capacity boundary used here: the required R/N 

depends on both finite-feature noise and the structural ceiling of the measured key set. In practical terms, the theory can indicate whether additional feature dimensions are expected to yield useful improvements in retrieval quality or whether the system has already entered a geometry-limited regime in which extra memory has diminishing benefit. 

6.3 Anatomical clustering recurs across public and independent medical data 

The public SynthRAD2023 experiment extends the geometry test beyond natural-image classification benchmarks with a publicly available paired medical dataset. At matched 

N , concentrating the memory on multiple adjacent slices from fewer subjects lowers mean item-wise C∞ across brain/pelvis, CT/MRI, and DINOv2/CLIP conditions; an independent NCCT–CTA cohort shows the same pattern. This is consistent with the clustered-key mechanism observed synthetically: same-patient anatomical clustering changes the kernel-overlap distribution without changing nominal embedding dimension or the number of stored items. Be-cause subject diversity and within-patient sampling vary together, these experiments do not isolate the effect of slice adjacency alone. Instead, they test whether stronger similarity among samples from the same patient leads to greater kernel overlap and retrieval interference at fixed 

N . The resampling intervals describe variability within the observed cohorts rather than uncertainty for new patients. The goal is not to define a modality-specific capacity law, but to test whether the same geometry–interference relationship extends to structured medical-image data. For imaging systems, the practical concern is that large collections can contain many highly similar anatomical observations, so the number of images or feature dimensions alone may overstate how much distinct information a compressed memory can preserve. 

6.4 Correlated values require joint geometry, while de-sign comparisons are more sensitive 

With correlated real values, cross-talk can reinforce or oppose the target. The kernel-weighted mixture y∞,i makes this 14 

dependence explicit, and the aligned/permuted controls show that the relevant object is the alignment between key-kernel neighborhoods and value similarity. The DINOv2– CLIP permutation analysis reduces concern about depen-dence on a single favorable shuffle. The simple joint finite-R

law is accurate over most tested conditions, whereas the covariance-aware correction is useful mainly for closely matched design curves: small systematic errors that barely affect global MAE can still move a RAW-to-WHITENED crossover. This distinction is relevant when theory is used for configuration selection, because the practical question is often not only whether retrieval can be predicted accurately in absolute terms, but whether two competing designs can be ordered correctly at the available memory budget. 

6.5 Practical interpretation for retrieval-oriented AI sys-tems 

In a deployed retrieval system, structural interference means that many stored cases occupy similar neighborhoods under the chosen representation and kernel, so a query can retrieve a mixture of several plausible cases rather than a clean match. This is relevant to tasks such as retrieval of similar prior images, cross-modal image–report or image–image recall, and case-based reasoning, where memory quality depends not only on the number of stored cases but also on how distinctly they are represented. The theory therefore suggests a practical sequence for system design: first measure kernel overlap in the intended representation, then use the predicted capacity curve to determine whether the target retrieval quality is reachable at the available feature budget. If finite-feature noise dominates, increasing R is the natural remedy; if the structural ceiling is already limiting, changing preprocessing, representation, kernel scale, or the composition of the stored set is more appropriate than simply allocating a larger memory. 

6.6 Scope relative to other memory regimes 

Modern Hopfield networks and attention-based memories explicitly retain or parameterize stored patterns and therefore operate in a different storage regime [12], [13]. Direct MLP mappings are also not storage-equivalent comparators for the fixed compressed matrix studied here. Likewise, the negative controls do not support a generic orthogonality advantage: square orthogonal value codebooks are lossless rotations, optimizer-dependent code differences largely collapse un-der SGD, sparse compositional codes do not outperform Gaussian codes, and learned orthogonal addressing does not consistently beat a noise-trained direct MLP. Our re-tained claim is narrower: measured kernel geometry predicts interference and target-cosine capacity in this compressed finite-feature regime. 

## 7 DISCUSSION 

A practical extension is retrieval from noisy or incomplete queries, which are common in clinical settings because repeated or multimodal observations rarely produce identical representations. In such cases, retrieval error would combine query mismatch with the storage interference studied here. This distinction may also matter in applications such as similar-case retrieval or multimodal recall, where failure can arise either from limited memory resources or from overlap among clinically similar representations. Extending the present analysis beyond exact-key retrieval could therefore help separate these sources of error and guide whether to increase memory capacity, change the representation, or improve query matching. 

## 8 LIMITATIONS 

The analysis is restricted to exact-key queries; robustness to corrupted, partial, or shifted cues is not modeled. Extending the framework to noisy or incomplete queries is a natural next step for clinical retrieval settings, where the query representation may differ from any stored case because of acquisition variability, pathology, or missing information. Capacity is defined operationally through target retrieval cosine and feature budget R/N , not as an asymptotic pattern-count capacity for other memory mechanisms. The finite-budget derivation is specific to random-feature Hebbian retrieval, and the real-data experiments use pretrained embeddings rather than an end-to-end learned memory. The covariance-aware correction remains approximate and retains residual crossover bias, while the simple finite-R

law is less accurate for strongly correlated values at very low R, where expectation-of-ratio effects are non-negligible. The medical stress tests use 2-D axial slices and general-purpose encoders rather than 3-D or medically specialized representations, and they evaluate representation geometry and memory interference rather than clinical prediction; therefore, the present results should not be interpreted as evidence that the capacity law directly improves diagnostic or prognostic performance. The public experiment is limited to the SynthRAD2023 Task-1 training split. Additional modal-ities, 3-D encoders, non-visual data, and end-to-end learned memories would provide more stringent tests of generality. 

## 9 CONCLUSION 

For exact-key retrieval in compressed random-feature Heb-bian memory, retrieval interference separates into a finite-feature component and a structural component determined by kernel overlap among stored keys. The resulting law predicts target-cosine capacity across synthetic, natural-image, and medical representation geometries, including a public matched-N SynthRAD2023 MRI–CT stress test and an independent NCCT–CTA confirmation. For correlated values, the deterministic retrieval geometry is governed jointly by the key kernel and value Gram matrix, while only the finite-

R perturbation is approximated. The same quantities can also estimate the memory budget required for a target retrieval quality, rank candidate representation and kernel configu-rations, and localize design crossovers. Within this storage regime, the practical value of the theory is therefore not only to describe capacity but also to distinguish when a system is limited by insufficient finite-feature budget from when it is limited by representation geometry itself. Measured kernel geometry is consequently a more informative guide to memory sizing and representation selection than nominal dimension or effective rank alone. 15

The main equations should be interpreted at three levels. First, the identities defining y∞,i , ai, and bi are exact once the kernel, keys, and values are specified, and Di is an exact paired-RFF second-moment quantity once the shift-invariant kernel and its spectral construction are specified. Second, the RFF variance and covariance expressions in Appendices B and D are exact for the paired sine/cosine feature construction under independent frequency sam-pling; they are not asserted as exact for the separately row-normalized random-phase feature map used in the broad capacity validation. ## APPENDIX FNEGATIVE RESULTS AND SANITY CHECKS 

F.1 Orthogonal value rotations 

Square orthogonal value codebooks do not create additional representational capacity by themselves. One-hot, signed permutation, Hadamard, and Haar codebooks are related by orthogonal transformations. Apparent differences under AdamW were strongly optimizer/coordinate dependent and largely disappeared under SGD. 

F.2 Learned orthogonal addressing 

Orthogonal learned addressing outperformed Gaussian ad-dressing in some noisy associative-address experiments, but it did not consistently outperform a noise-trained direct MLP. This result motivates studying address geometry but does not support a universal superiority claim. 

F.3 Sparse compositional codes 

Random sparse signed compositional addresses behaved similarly to Gaussian random codes and did not produce a general capacity advantage, so this mechanism is not used in the main analysis. 18 

F.4 SimilarityCE and soft retrieval 

Similarity cross-entropy improved rotational invariance but weakened alignment for linear Hebbian readout. For square orthogonal address matrices A, soft retrieval satisfies 

pA (A⊤V ) = pV, 

so the orthogonal memory cancels algebraically and the operation becomes ordinary value attention. 

F.5 Hybrid objectives 

Combining similarity cross-entropy, cosine alignment, and margin objectives produced a trade-off: better rotational invariance came with weaker linear Hebbian alignment. No tested setting improved both. 

F.6 Higher-order finite-R expansions 

A second-order delta expansion involving additional numerator–denominator covariance terms has larger global error than the first-order approximation, particularly at low 

R/N . It becomes competitive only at large R and is not part of the main theory.

## 摘要
自注意力使大语言模型能够以细粒度、依赖查询的方式访问上下文，但密集的词元交互会带来二次方的预填充成本，以及随上下文长度增长的键值缓存。因此，研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动力学和异构机制组合。本综述将这些发展视为模型内部的上下文记忆。我们引入一个五维视角——记忆表示、记忆更新、访问、读出与整合——分别描述表示了什么、它如何变化、什么可被查询、它如何被读取，以及读出如何形成输出。该视角比较相互重叠的研究路线，而不强加单一计算模型。我们利用来自14个主要模型谱系和11个高性能开放权重端点的59条发布级记录，重建机制层面的发展与架构采用情况。第一，显式记忆与循环状态方法保留不同的接口，但日益控制重叠的记忆功能。第二，异构架构日益在网络深度上进行协同：逐层组合将互补的记忆处理分布到不同表示阶段，而跨层复用则将选定的记忆与路由产物向前传递。因此，深度成为构建和管理上下文记忆的一个维度。第三，这些发展促成了一个有状态的多维记忆路由假说：持久记忆按时间范围、网络深度、基底类型和表示粒度进行组织，而协同的稀疏写入与稀疏读取决定什么被保持以及什么对每次查询有贡献。总体而言，高效序列架构设计日益关注上下文记忆的组织、生命周期与选择性使用，而非孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

## 2. 方法论：核心思想与关键技术细节

### 2.1 五维分析视角（核心透镜）

将每种机制视为维护并使用内部记忆的系统，围绕五个功能问题组织：

- **Memory Representation（记忆表示）**：过去哪些信息仍被表示、以何形式、何种粒度、多大容量。形式化记为 $M_t \in \mathcal{M}_\rho$，其中 $\rho$ 为记忆 schema（类型、组织、粒度、容量、持久性）。
  - 两个关键属性：**历史覆盖度**（history coverage）与**可寻址性**（addressability）。
- **Memory Update（记忆更新）**：当前输入如何添加、修改、压缩或覆盖记忆，抽象为 $M_t^+ = \mathrm{Update}_\rho(M_t^-, x_t)$。涵盖追加式写入、加性写入、乘性衰减、输入依赖保持、delta 校正、显式擦除–写入。
- **Access（访问）**：哪些表示信息对当前查询**有资格**参与，$C_t = \mathrm{Access}_\rho(q_t, \hat{M}_t)$。对应全局/局部/Top-k/路由等候选构造。
- **Readout（读出）**：如何对合格信息加权、解码或聚合，$r_t = \mathrm{Readout}_\rho(q_t, C_t)$。Access 回答"可读什么"，Readout 回答"如何读"。
- **Integration（整合）**：一个或多个完成的读出如何被变换或组合成模块输出，$o_t = \mathrm{Integration}_\rho(r_t; x_t)$，如拼接+输出投影、门控、路由、融合。

> 强调：五维是**功能角色**而非强制计算图，单一操作可同时承担多个角色，维度之间并不正交。

### 2.3 各路线关键技术细节

- **Softmax Attention**：三条优化方向——(a) 表示效率（MQA/GQA 头共享、MLA 通道压缩、CLA 跨层共享）；(b) 序列表示压缩（固定容量循环记忆 RMT/TransformerFAM、KV 槽位 Trellis/Lattice；动态分辨率记忆 KSA/HCA）；(c) 读出与整合调制（Talking-Heads、DCMHA、Differential Attention、FoX、MoH、Gated Attention）。
- **Sparse Attention**：围绕"证据来源"与"选择决策有效期"两轴分类——结构约束型（Longformer/BigBird/Sparse Transformer/LongNet；StreamingLLM/MInference 事后发现）、自路由型（Reformer 哈希、Routing Transformer 聚类、Quest/XAttention、MoBA、NSA）、辅助代理路由型（TokenButler、DSA Lightning Indexer、MSA、QSA、CSA）、时间与跨层复用（ReTopK、TidalDecode、Kascade、IndexCache、YOIO/CLSA、CSA2、HySparse）。
- **Linear Attention**：以 retain/decay、erase/correct、write/commit 三分解释更新规则演化：
  - 无衰减 → 固定衰减 → 输入依赖细粒度衰减；
  - 无擦除 → 耦合校正擦除（DeltaNet 秩一）→ 解耦擦除（RWKV-7、GDN2、EDA 秩二）；
  - 直接写入 → 校正写入 → 擦除–写入解耦。
  - 容量扩展（SSE 分组、SDM 扁平行）；时间扩展（Log-Linear 多尺度、DLA 内容自适应、MHLA 固定块）；辅助协调（SLA 特征头、CLVR 跨深度）。

  - 架构级结论依赖**公开披露质量**，未披露者被标记而非推断，可能引入选择偏差。
  - 排行榜分数受模型规模、训练、后训练、推理预算、系统工程影响，**不能因果归因于注意力机制**——作者对此有明确免责声明。
  - 跨层复用证据仅集中在 5 条记录 / 3 种架构模式，样本极小。
  - 缺乏受控的消融实验或匹配预算下的质量–效率对比。

## 6. 主要结论与发现

- **机制层结论（综合 1）**：显式记忆方法与基于状态的方法保留**不同的记忆接口与计算形式**，但两者都从各自初始重心向更广、且**日益重叠**的记忆功能集合扩展（表示、更新、访问、读出、整合）。收敛发生在**显式设计控制的范围内**，而非共享的记忆基底或计算机制。
- **架构层结论（综合 2）**：
  - 注意力设计呈**多样化而非收敛**：GQA、MLA、稀疏注意力、循环状态等多种路线持续共存；模型谱系还会改变方向（如 DeepSeek 从 MLA → MLA-based sparse → CSA/HCA/CSA2）。
  - Hybrid 记录显著增加（2026 年占可分类记录的 63%），主要通过**预定义的逐层调度**实现。
  - **跨层复用**作为独特协调形式出现：GLM（IndexShare/IndexCache）、DeepSeek-V4.1-Flash（Full/Reindex/Reuse 模式）、LongCat（Cross-Layer Indexing）。
  - 由此，**网络深度成为构建与管理上下文记忆的一个新兴维度**：逐层组合决定各深度的记忆处理，跨层复用决定产物的生命周期。
- **前沿观察**：11 个高性能开放权重端点架构仍高度异构，但**每一个都保留了显式词元检索路径**，表明循环状态与稀疏化目前是**补充而非统一替代** token-可寻址注意力。
- **前瞻假说（有状态多维记忆路由）**：
  - 地址空间 $A_t = \mathcal{T}_t \times \mathcal{L} \times \mathcal{S} \times \mathcal{G}$（时间范围 × 网络深度 × 基底类型 × 表示粒度）。
  - 协同的 **Sparse Write**（$W_t \subseteq A_t$）与 **Sparse Read**（Access → Readout → Integration）分别控制信息写入何处与哪些单元贡献于查询。
  - 类似于"多维 Memory-MoE"，关键区别在于**持久性**：写路由决策会影响未来可用信息，产生延迟依赖。
- **总体判断**：训练原生稀疏注意力在路由端到端训练、预算匹配任务证据密度、且速度增益计入证据构造/索引流量/聚集成本时，可与密集注意力质量相当甚至更优；但这种等价性是**有条件的**，取决于任务、预算与实现。

## 7. 优点（方法或实验设计的亮点）

- **统一分析透镜**：五维视角（表示/更新/访问/读出/整合）为历史上彼此独立甚至重叠的研究路线提供了**共同词汇**，且明确强调角色不等于强制计算图，避免了过度形式化。
- **多标签而非硬性分类**：章节标签用于可读的历史技术组织，五维用于对单个方法做多标签功能描述，二者分工清晰，避免把方法强行塞进互斥类别。
- **覆盖面与时新性**：文献覆盖至 2026-09-22，纳入大量最新工作，包括 2026 年发表的 QSA、CSA2、SSE、SDM、DLA、MHLA、MuonSSM 等。
- **机制 + 实证双层证据**：既有机制层面的公式化梳理（如统一更新分解 $\bar{S}_{t-1} = \alpha_t \odot S_{t-1}$，$S_t = \bar{S}_{t-1} - E_t + W_t$），又有 59 条发布记录 + 11 个前沿端点的架构级实证，形成"理论—落地"闭环。
- **损失视角的独到处理**：将循环更新规则解释为逐 token 在线优化目标，给出统一表格（表 8），揭示方法差异在于**优化对象、优化步数与擦除/写入是否共享地址与目标**。
- **诚实的免责声明**：反复强调清单为策展性质、排行榜分数不可因果归因、跨层复用证据有限，学术态度审慎。
- **前瞻假说可落地**：不仅提出多维记忆路由假说，还给出四条**渐进可测试**的研究方向（工作负载感知的差异化表示、非对称构造与检索、增量生命周期与可复用产物、任务条件化的联合路由）。

## 8. 不足与局限

### 8.1 实验覆盖

- **无受控实验**：作为综述，没有匹配预算下的质量–效率对照实验，所有架构级结论均为**描述性**，无法验证机制与性能的因果关系。
- **清单非穷举**：59 条记录为策展性质，未做市场份额加权，可能存在选择性偏差；2026 年数据仅截至 9 月 22 日。
- **跨层复用证据薄弱**：仅 5 条记录、3 种架构模式，作者自己也承认该方向证据集中且有限。
- **披露依赖**：架构分类完全依赖公开文档，未披露者被标为 Undisclosed（如 Kimi k1.5），导致可分类样本减少。

### 8.2 偏差风险

- **"存活者偏差"**：清单偏向公开披露充分、知名度高的模型谱系（Llama、Qwen、DeepSeek、GLM、Kimi 等），可能系统性忽略未公开或小规模但架构上有价值的设计。
- **时间近因偏差**：Hybrid 与跨层复用的增长趋势部分可能反映披露实践的变化，而非纯粹的技术演进。
- **前沿对比的混淆**：Artificial Analysis 分数受规模、训练、后训练、推理预算、系统工程等多因素影响，作者虽声明不可因果归因，但读者仍可能误读。

### 8.3 应用限制

- **假说未验证**：有状态多维记忆路由仍是设计假说，其价值取决于能否在匹配记忆/计算/路由预算下改善质量–效率前沿，论文未提供实证。
- **工程可行性未量化**：稀疏路由、跨层复用的实际加速依赖 kernel 支持与硬件实现；论文多次指出"名义稀疏性不等于墙钟时间节省"，但未给出系统性的硬件评测。
- **多模态与外部记忆排除在外**：测试时学习、外部数据库检索、多模态特有记忆设计、纯实现层优化不在核心分类内，除非直接改变上下文记忆语义。
- **评估

- **评估**：现有长上下文基准多聚焦"能否取回"（needle-in-a-haystack 类），而对"检索干扰""证据密度""多轮对话中的记忆生命周期"等真实负载特征刻画不足，导致各机制的质量–效率权衡难以跨研究横向比较；论文呼吁的工作负载感知评测尚未落地。
- **部署门槛**：跨层复用、稀疏路由、状态–注意力混合等设计对推理引擎（KV 缓存管理、前缀复用、批处理调度、投机解码）提出了新的耦合要求，论文未讨论这些设计在现有 Serving 栈中的兼容成本。
- **训练侧代价未纳入**：路由网络的端到端训练稳定性、辅助损失权重、索引结构的可微近似等工程细节，综述层面仅做提示，未给出可复现的训练配方。

### 8.4 表述与结构层面的小问题

- 五维视角虽强调"角色不等于计算图"，但在跨章节映射到具体方法时，个别归属（如某些读出调制操作同时被归入 Integration）仍存在一定的解释弹性，读者需自行判断边界。
- 章节标签（Softmax/Sparse/Linear/SSM/Hybrid）与五维透镜并行使用，虽有分工说明，但对初次接触该领域的读者仍可能造成"两套分类体系"的认知负担。
- 大量 2025–2026 年方法尚缺乏独立的第三方复现与消融，综述所引结论部分依赖原论文自述，存在"作者声明即事实"的潜在风险。

## 9. 对后续研究的启示与开放问题

### 9.1 设计层面的启示

- **记忆生命周期应作为一等设计对象**：写入时机、驻留时长、淘汰策略与读取资格不再是被动副产物，而应与表示形式联合优化。跨层复用的出现说明"记忆产物的复用范围"本身是一个可调维度。
- **深度是尚未充分开发的资源**：逐层调度与跨层共享表明，网络深度不仅是容量堆叠，也可承担"记忆分工"——浅层做局部聚合、深层做全局整合，或反向调度，均可纳入统一设计空间。
- **稀疏性是条件性的**：只有当路由成本、索引维护成本与聚集成本之和低于所节省的注意力计算时，稀疏才转化为实际收益；否则只是"名义稀疏"。这一判断对硬件协同设计提出明确要求。
- **状态与检索的互补性**：前沿端点无一放弃显式词元检索路径，说明循环状态擅长压缩统计规律，而精确、可寻址的远端证据仍需 token 级通路，二者是分层而非替代关系。

### 9.2 开放问题清单

- **可证伪的等价性边界**：在何种任务分布、证据密度与预算约束下，训练原生稀疏注意力可稳定匹配密集注意力质量？目前只有方向性结论，缺少边界条件的定量刻画。
- **路由的可学习性与稳定性**：写路由（Sparse Write）会改变未来可用信息，形成延迟依赖，其信用分配与训练稳定性尚无系统方案。
- **跨层复用的最优粒度**：复用索引、复用缓存还是复用读出结果？共享范围（相邻层、组内层、全局）与模型深度、头数的关系缺乏理论指导。
- **记忆容量与泛化的关系**：固定容量循环记忆的压缩损失如何随任务复杂度增长，是否存在可预测的容量–性能标度律，仍待回答。
- **评测框架**：如何构建同时度量质量、延迟、内存与"证据利用可靠性"的统一基准，是推动该领域从描述走向因果的关键前提。

### 9.3 方法论建议

- 在报告新机制时，应同时给出**匹配预算**（FLOPs、KV 内存、墙钟延迟）下的质量对照，并区分"算法复杂度"与"实际加速"。
- 架构级比较需明确披露层级（骨架、训练数据、后训练、推理配置），避免将综合榜单分数直接归因于注意力设计。
- 对未公开细节应显式标注为 Undisclosed，而非通过性能反推结构，本文在此点上的处理值得作为规范参考。

## 10. 总体评价

本文是一篇**组织框架清晰、时效性强、态度审慎**的注意力机制演进综述。其核心贡献不在于提出新方法，而在于：

1. 用五维功能视角（表示/更新/访问/读出/整合）为分散的研究路线建立共同语言；
2. 通过 59 条发布级架构记录与 11 个前沿端点的双重实证，把机制分析与产业落地连接起来；
3. 提出"有状态多维记忆路由"这一可渐进检验的前瞻假说，并配套给出四条研究方向。

其主要短板在于：作为综述缺乏受控实验与因果验证，架构清单为策展性质、存在披露与存活者偏差，跨层复用等新兴趋势的证据样本偏小，多维路由假说尚未获得实证支撑。总体而言，本文更适合作为**研究地图与问题清单**使用，而非对"哪种注意力更好"给出定论的裁决性文献；其价值将主要体现在为后续受控实验与系统级评测提供概念坐标。

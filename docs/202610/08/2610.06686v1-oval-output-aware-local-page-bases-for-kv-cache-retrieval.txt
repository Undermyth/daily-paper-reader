## ABSTRACT 

Long context inference with large language models becomes increasingly expensive as attention must operate over an ever growing KV cache. Page sparse attention reduces this cost by representing each KV page compactly and retrieving only a subset for each query. Existing retrieval methods are designed to estimate attention scores or page relevance, but their objectives do not directly account for how approximation errors affect the resulting value weighted attention output. We introduce OVAL, an output aware page encoding derived from the joint structure of keys and values while preserving the key information needed for accurate retrieval. OVAL is training free and requires no additional value dependent statistics at inference time. Once constructed, its stored representation has the same size and decode time scoring cost as a key only spectral representation. Across long reasoning, long context understanding, and long generation benchmarks, OVAL consistently improves over the key only spectral baseline and performs competitively with recent KV cache compression and retrieval methods. On long reasoning benchmarks, it achieves strong avg@ k performance across model benchmark pairs, while matching or surpassing leading baselines on several long context understanding and generation settings with modest decoding overhead. ## 1 Introduction 

Large language models rely on self attention to retrieve information from increasingly long sequences, enabling applications from long document understanding and multi turn dialogue to code generation and extended reasoning [1–4]. This flexibility comes at substantial computational cost. For a sequence of length n, standard self attention compares every query with every key, giving quadratic complexity during full sequence processing [1, 5]. For contexts spanning tens or hundreds of thousands of tokens, attention therefore incurs substantial storage and bandwidth costs [3, 6]. Autoregressive inference avoids recomputing previous representations by maintaining a key value cache, or KV cache. At each layer, keys and values from previous tokens are stored and reused during generation. For a new query q,the model scores the cached keys, normalizes the logits into attention weights, and forms the output as a weighted combination of the corresponding values. Although this removes redundant computation, the KV cache grows linearly with sequence length, number of layers, batch size, and number of KV heads [7, 8]. Each decoding step must also read and score the cached history, making long context inference increasingly dominated by KV access costs [9–11]. In practice, this history is not managed as an unstructured collection of tokens. Modern inference systems group consecutive KV entries into fixed size blocks, or pages , which form the natural unit of cache management and sparse retrieval [12]. Page retrieval methods first identify a small subset of relevant pages and then perform exact attention over the tokens they contain. To do so efficiently, they maintain a compact summary for each page and use it to estimate relevance to the current query [9, 10]. The effectiveness of this pipeline therefore depends critically on what information the page summary preserves. arXiv:2610.06686v1 [cs.LG] 5 Oct 2026 October 6, 2026 

Existing methods answer this question primarily through the keys. They estimate page importance using extrema, low dimensional key representations, geometric statistics, or spectral summaries [9–11, 13–15]. This is natural because keys determine the attention logits. However, preserving logits is not the final objective of an attention layer. What is propagated to the rest of the network is the attention output. Let o(q) = P

A large logit error may have little effect when attention is redistributed among tokens with similar values, while a small error along a weak key direction may substantially change the output if it shifts probability between very different values. Thus, a high variance key direction can be unimportant to the output, while a lower variance direction can be critical. Any criterion based only on key geometry cannot distinguish these cases. This motivates the central question: what information should a page preserve to maintain the attention output? 

Our key observation is that not all attention score errors matter equally. An error matters only when it redistributes attention between tokens whose values are meaningfully different. Therefore, the importance of a key direction cannot be determined from the keys alone; it depends on how keys and values vary together within the page. Guided by this observation, we construct each page summary jointly from its keys and values, prioritizing the directions that matter most to the resulting attention output rather than simply preserving the dominant variation in key space. Output fidelity, however, is only one role of a page summary. Before a page can contribute to the output, it must first be retrieved, which requires an accurate estimate of its attention mass. We show that these two objectives have different local sensitivities: conditional attention output error is generically first order in discarded logit directions, while page log mass error is locally second order. This motivates a hybrid objective that combines output sensitivity with the conventional key covariance. The resulting basis is obtained through a small page local eigenproblem. At one endpoint, it reduces to ordinary page local key PCA; moving away from this endpoint introduces value information according to its effect on the attention output. We call the resulting method OVAL. OVAL uses both keys and values when constructing each page basis, but stores no value statistics and requires no value dependent computation during retrieval. Values are accessed only when a completed page summary is constructed. At decode time, the summary has the same dimensionality and scoring complexity as a key only spectral page summary. Across long reasoning, long context understanding, long generation, and efficiency benchmarks [3, 4, 11, 16], the output aware component consistently improves over the key PCA endpoint on long reasoning tasks and yields strong performance against contemporary KV cache compression and retrieval methods. 

Our main contributions are: 

• We identify a mismatch between key driven page retrieval objectives and the attention output that ultimately matters, and derive the exact sensitivity of the conditional attention output to within page logit perturbations. • We derive a query free output aware rank r page basis governed by centered key value coupling, and combine it with key fidelity through a single normalized parameter η, yielding a closed form spectral construction. • With the best evaluated η, OVAL achieves the highest avg@k among compressed methods in all long reasoning settings (+3.7–3.9 points) and the best LongBench v2 Overall score on two of three models. • We study practical selection of η using a disjoint calibration set and evaluate how well a single calibrated value transfers across tasks relative to the per setting η⋆.

## 2 Related Work 

KV cache compression. Several complementary approaches reduce the KV cache footprint. Grouped query attention shares KV heads across queries [7], quantization lowers the precision of cached entries [17], and low-rank methods such as STAR-KV project the cache onto an adaptively ranked subspace [18]. Eviction methods keep only part of the history based on attention importance, recency, or prompt observations [8, 19–21]. CriticalKV grounds eviction in attention output perturbation and shows that value states matter beyond attention weights [22]. In all of these, evicted information cannot be recovered if its relevance changes later in generation. 

Sparse attention and KV retrieval. Retrieval methods instead estimate which cached regions matter for the current query and attend only to the selected subset [9, 10, 13, 21, 23]. At page granularity, Quest bounds page scores with coordinatewise key minima and maxima [9], ArkVale summarizes pages with compact geometric representations [13], and UNIQUE uses key mean and dispersion statistics [9]. At token granularity, several methods score keys cheaply in a reduced space. SparQ uses a subset of query components [24], Loki uses a PCA basis of keys [25], ShadowKV reconstructs selected entries from a low-rank key cache [10], and InfiniGen prefetches entries predicted from partial key information [21]. Other methods borrow from vector search. Its retrieval summary has the same format as key PCA. Throughout, keys and queries include the model’s positional transformations, including RoPE. 4.3 Selecting η in practice 

The results above report η⋆, the best value in the evaluated grid for each task. Because this value is selected using evaluation scores, these results characterize the attainable performance of the representation rather than a practical parameter selection procedure. We therefore select one ˆη per model using a disjoint calibration pool of 40 problems, with 20 from MATH500 and 20 

from GPQA. We evaluate η ∈ { 0, 0.25 , 0.5, 0.75 , 1} on this pool, select the value with the highest mean calibration performance, and freeze it across MATH500, AIME24, and GPQA. Calibration problems are excluded from all scores in Table 3; AIME24 contains no calibration problems, so its evaluation set is unchanged. On these matched held out examples, frozen OVAL averages 53 .69 versus 50 .42 for FreeKV on Llama 8B, improving on all three tasks, including AIME24, which was absent from the calibration pool. On Qwen 7B, calibration selects ˆη = 0 .25 and frozen OVAL averages 54 .28 versus 54 .72 for FreeKV: it improves AIME24 slightly but trails on MATH500 and GPQA. Task specific sweeping reaches 55 .75 and 57 .78 , leaving gaps of 2.05 and 3.50 points. Calibration therefore transfers well on Llama 8B, while on Qwen 7B the 40-problem pool does not identify the best setting; more robust selection of η is an important direction for future work.

## 5 Conclusion 

We introduced OVAL, an output aware page representation for sparse KV retrieval that combines key fidelity with value dependent output sensitivity. It preserves the summary format and decode time scoring complexity of key only spectral retrieval while better aligning retrieval with the attention output. Across long reasoning, long context understanding, and long generation, OVAL improves over the key only endpoint and performs strongly against recent sparse KV baselines with modest decoding overhead. We further show that η can be selected from held out calibration data, which transfers well on Llama 8B and leaves substantial headroom on Qwen 7B. Overall, the results support incorporating output sensitivity into compact retrieval representations and designing sparse attention summaries around downstream approximation error rather than key geometry alone. 7October 6, 2026

## B Rank and Page Budget Ablations 

We further evaluate sensitivity to the representation rank and sparse KV budget on GPQA using DeepSeek R1 Qwen 7B. For the rank ablation, we fix the budget to 2048 tokens and vary r ∈ { 1, 4, 8, 16 }. For the budget ablation, we fix r = 8 

and vary the retrieved KV budget over {512 , 1024 , 2048 , 4096 } tokens. All other settings follow the main experiments. The rank ablation measures the sensitivity of retrieval quality to the capacity of the page representation, while the budget ablation measures the effect of increasing the number of retrieved KV tokens. Together, these experiments test the robustness of the default configuration r = 8 with a 2048 token budget used in the main evaluation. 

## C InfiniteBench Results

D.7 Corrections to the reference harness 

1. Index range selection does not slice metadata. 

Prompts are sliced but the associated metadata is not, so generations from a selected subrange are evaluated against another example’s expected structure. We correct the metadata indexing together with the prompt range. 

2. Head reordering can duplicate columns. 

When full and dynamic attention masks overlap, the reconstructed output projection can exceed nheads d. On Qwen2.5 14B we observe width 5151 rather than 5120 . The issue occurs only under multi GPU sharding. We therefore derive the GQA group size from the reordered projection instead of q_proj /k_proj , validate the resulting width, and fail explicitly on mismatch. 

D.8 Scope and reported quantities 

What OVAL changes. Only the page representation used for retrieval . After top k selection, attention is computed using the original keys of the selected pages, exactly as in the compared retrieval baselines. 

In the accuracy harness, the full KV cache remains resident and page summaries are additional state. These experiments therefore quantify sparse retrieval rather than compressed key attention.

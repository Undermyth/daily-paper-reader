## 摘要
循环模型必须遗忘才能记住，然而现有技术决定擦除什么时并不参考已存储的内容——门控只看到达的令牌，而不看即将修改的记忆。这种记忆盲门控是领先的delta规则架构(GDN-2)中三个耦合缺陷之一：值轴擦除掩码在值投影的规模上浪费参数，并且——正如我们所证明的——数学上阻止了使循环训练与Transformer具有竞争力的WY形式三角形分块求解器。我们引入CARVE（内容感知循环与值效率），通过一个原则解决了所有三个问题：仅在键轴上擦除。这被证明是WY形式求解器保持有效的充分必要条件。在其中，CARVE重用循环输出张量——已经写入GPU内存——作为擦除门的自由内容信号，并用每个头的单个标量替换每个值的写入门投影。在初始化时，CARVE与GDN-2位相同；任何质量差异都源于内容门学习的内容。在100B令牌上训练的1.3B参数上，CARVE实现了WikiText困惑度15.72（比GDN-2低0.18，4.5个标准差效应），在九个常识推理基准上领先所有循环基线，并在每个RULER检索探针上达到最新技术水平——以0.4%的吞吐量开销、13%的低峰内存和19%更少的参数。六个形式化定理涵盖了内存容量、李雅普诺夫稳定性、梯度流、表达性分离、帕累托最优块大小和混合最优性。

## Abstract
Recurrent models must forget in order to remember, yet the state of the art decides what to erase without consulting what is stored -- the gate sees only the arriving token, not the memory it is about to modify. This memory-blind gating is one of three coupled defects in the leading delta-rule architecture (GDN-2): the value-axis erase mask wastes parameters at the scale of the value projection, and -- as we prove -- mathematically prevents the WY-form triangular chunk solver that makes recurrent training competitive with Transformers.   We introduce CARVE (Content-Aware Recurrent with Value Efficiency), which resolves all three problems through one principle: erase only on the key axis. This is provably necessary and sufficient for the WY-form solver to remain valid. Within it, CARVE reuses the recurrent output tensor -- already written to GPU memory -- as a free content signal for the erase gate, and replaces the per-value write-gate projection with a single scalar per head. At initialisation CARVE is bit-identical to GDN-2; any quality difference emerges from what the content gate learns.   At 1.3B parameters trained on 100B tokens, CARVE achieves WikiText perplexity 15.72 (minus 0.18 vs. GDN-2, a 4.5-sigma effect), leads every recurrent baseline on nine common-sense reasoning benchmarks, and sets state of the art on every RULER retrieval probe -- at 0.4% throughput overhead, 13% lower peak memory, and 19% fewer parameters. Six formal theorems cover memory capacity, Lyapunov stability, gradient flow, expressivity separation, Pareto-optimal chunk size, and hybrid optimality.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：现有循环序列模型（如GDN-2）在维护固定大小的状态矩阵时，需要决定遗忘哪些内容，但现有的门控机制存在三个耦合缺陷：
  1. **记忆盲门控**：擦除和写入门仅由当前输入token计算，无法观察已存储的记忆状态，导致选择性遗忘无法基于内容；
  2. **值轴擦除的参数浪费**：写门投影与值投影具有相同参数规模（dv维），但实际仅需每头标量即可实现核心关联召回（理论证明）；
  3. **破坏分块并行训练**：GDN-2的逐元素矩阵擦除作用于值轴，使得WY形式三角形分块求解器必须为每个值通道独立求解，退化到序列递归复杂度。
- **整体含义**：CARVE通过**仅在键轴上擦除**这一约束，同时解决上述三个问题，在保持与Transformer相当的训练效率的同时，实现内容感知的门控、减少参数和内存，并在大规模语言建模和检索任务上取得领先性能。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **键轴擦除约束**：证明键轴擦除是WY分块求解器保持有效的充分必要条件（Theorem 11）。所有门控（擦除、衰减）仅在键轴（dk维度）作用，使得分块内耦合矩阵与值索引无关，从而单个三角形求解即可处理所有值通道。
- **内容感知擦除**：复用递归输出张量`ot = St-1 qt`（已写入HBM），计算前一块的输出均值`mc = mean(ot of chunk c-1)`，作为零额外成本的记忆信号。将该信号通过零初始化的低秩投影`Ub`加到擦除门偏置上，使门在训练中逐渐激活记忆条件化能力（`bc,t = σ(bx,t + Ub(mc))`）。证明错位近似误差为O(1/√L)。
- **标量值写门**：用每头单个标量`wh,t`替代dv维写门投影，降低dv倍参数（如12头、dv=768时从589,824降至9,216），并证明对单槽关联召回无损（Theorem 15）。

### 关键技术细节
- **状态更新公式**：
  ```
  Sc,t = Sc,t-1 · diag(exp(gc,t)) · diag(1 - bc,t) + wh,t · (vc,t - Sc,t-1 kc,t) k^T_c,t
  ```
  其中`diag(exp(gc,t))`为键轴衰减门，`diag(1 - bc,t)`为内容感知擦除门，`wh,t`为标量写门。
- **输入投影**：q、k、v通过SiLU激活；门预激活（衰减logits f、擦除偏置bx、写预激活ŵ）通过线性投影得到。
- **内容信号提取**：每块结束后，对块内L个输出求均值，传递给下一块。
- **WY形式分块求解器**：保持未修改的算法2，计算累积键轴保留向量γt，构建值索引无关的下三角耦合矩阵M，通过一次三角形矩阵求解得到所有值通道的校正值。
- **门融合**：衰减激活`gc,t = -exp(A) ⊙ softplus(fc,t + τ)`在Triton内核内计算，消除一个BF16激活张量存储。

### 算法流程（文字描述）
1. 输入隐藏状态序列h[1:T]，初始化状态S0=0，内容信号m0=0。
2. 计算所有token的q、k、v及门预激活。
3. 对每个块c：
   - 从块起始到结束，用当前块内容信号mc通过低秩投影Ub得到块级偏置，加到擦除门偏置上，经sigmoid得到`bc,t`；
   - 写门`wh,t`由ŵ经sigmoid得到；
   - 调用WYChunkDelta内核（算法2）：累计γt，计算预测误差rt，构建耦合矩阵M，求解三角形系统得到U，然后计算输出ot并更新状态Sc；
   - 计算块内输出均值作为下一块的内容信号mc+1。
4. 最终输出经过RMSNorm和输出投影得到y[1:T]。

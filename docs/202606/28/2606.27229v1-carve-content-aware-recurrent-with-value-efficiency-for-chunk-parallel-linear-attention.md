## 摘要
循环模型必须遗忘才能记住，然而现有技术在决定擦除什么时并不参考已存储的内容——门控只看到到达的令牌，而不是即将修改的记忆。这种记忆盲点门控是领先的delta规则架构（GDN-2）中三个耦合缺陷之一：价值轴的擦除掩码在价值投影的规模上浪费参数，并且——正如我们证明的那样——在数学上阻止了使循环训练与Transformer相竞争的WY形式分块求解器。我们提出CARVE（内容感知循环与价值高效），通过一个原则解决所有三个问题：仅在键轴上擦除。这对于WY形式求解器保持有效是必要且充分的。在此原则下，CARVE重用已写入GPU内存的循环输出张量，作为擦除门控的免费内容信号，并将每个价值写门控投影替换为每个头的单一标量。在初始化时，CARVE与GDN-2完全一致；任何质量差异都源于内容门控学习到的内容。在100B个令牌上训练的1.3B参数模型中，CARVE在WikiText上达到了15.72的困惑度（比GDN-2低0.18，即4.5西格玛效应），在九个常识推理基准上领先所有循环基线，并在每个RULER检索探测上达到最先进水平——吞吐量开销仅0.4%，峰值内存降低13%，参数减少19%。六个形式化定理涵盖了存储容量、李雅普诺夫稳定性、梯度流、表达能力分离、帕累托最优分块大小和混合最优性。

## Abstract
Recurrent models must forget in order to remember, yet the state of the art decides what to erase without consulting what is stored -- the gate sees only the arriving token, not the memory it is about to modify. This memory-blind gating is one of three coupled defects in the leading delta-rule architecture (GDN-2): the value-axis erase mask wastes parameters at the scale of the value projection, and -- as we prove -- mathematically prevents the WY-form triangular chunk solver that makes recurrent training competitive with Transformers.   We introduce CARVE (Content-Aware Recurrent with Value Efficiency), which resolves all three problems through one principle: erase only on the key axis. This is provably necessary and sufficient for the WY-form solver to remain valid. Within it, CARVE reuses the recurrent output tensor -- already written to GPU memory -- as a free content signal for the erase gate, and replaces the per-value write-gate projection with a single scalar per head. At initialisation CARVE is bit-identical to GDN-2; any quality difference emerges from what the content gate learns.   At 1.3B parameters trained on 100B tokens, CARVE achieves WikiText perplexity 15.72 (minus 0.18 vs. GDN-2, a 4.5-sigma effect), leads every recurrent baseline on nine common-sense reasoning benchmarks, and sets state of the art on every RULER retrieval probe -- at 0.4% throughput overhead, 13% lower peak memory, and 19% fewer parameters. Six formal theorems cover memory capacity, Lyapunov stability, gradient flow, expressivity separation, Pareto-optimal chunk size, and hybrid optimality.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：循环语言模型需要遗忘旧信息才能记住新信息，但现有最先进的 delta-rule 架构（GDN-2）在决定擦除哪些内容时 *不看自己已经存储了什么*（记忆盲点门控）。门控仅由当前输入 token 决定，无法感知循环状态矩阵中的内容。
- **三个耦合缺陷**：
  - **记忆盲点擦除**：擦除门和写门都只基于当前 token，无法根据已存储的关联调整。
  - **写门带宽浪费**：每个值通道独立写门造成参数开销与值投影同级，徒增内存带宽而无实质收益。
  - **价值轴擦除破坏分块并行性**：GDN-2 的擦除作用于整个矩阵，导致 WY 形式三角形求解器无法共享，训练退化为串行循环。
- **整体含义**：现有递归模型在表达能力、训练效率和硬件效率之间面临根本性权衡。CARVE 旨在通过“仅在键轴上擦除”这一单一原则同时解决三个问题，同时保持 WY 形式分块求解器不变。

## 2. 方法论：核心思想与技术细节

### 2.1 核心思想
- **仅键轴擦除**：所有擦除（遗忘）操作只作用在键维度上，使得分块内耦合矩阵与值索引无关，从而维持单个 WY 形式三角求解。
- **输出重用（Output Reuse）**：利用分块内核已经写入 HBM 的循环输出张量 `o`（`Sq`）的块均值作为内容信号，**零额外 HBM 读取**。
- **标量写门**：每个头用一个标量（而非每个值维度一个）控制写入强度，参数减少 d_v 倍。

### 2.2 关键技术细节
**状态更新公式**：
Sc,t = Sc,t‑1 · diag(exp(gc,t)) · diag(1 − bc,t) + wh,t · (vc,t − Sc,t‑1kc,t)kc,t⊤

- diag(exp(gc,t))：键轴指数衰减门。
- diag(1 − bc,t)：内容感知擦除门。
- wh,t：标量写门（每个头一个标量）。

**内容感知擦除门**：
bc,t = σ(bx,t + Ub(mc))，其中 mc = 1/L ∑_{t∈c−1} ot（前一块输出均值），Ub = WU2 tanh(WU1 m) 且 WU1, WU2 零初始化。

**门控计算融合**：
- 衰减门 gc,t = −exp(A) ⊙ softplus(fc,t + τ) 在 Triton 内核内部计算，避免存储激活张量。

### 2.3 算法流程（文字说明）
1. 输入隐藏状态，计算 q, k, v 以及门控预激活值 f, bx, ŵ。
2. 初始化内容信号 m0=0。
3. 对每个块 c：
   - 通过低秩投影 Ub 将 mc 映射到键维度的偏置。
   - 计算擦除门 bc,t = σ(bx,t + Ub(mc)) 和标量写门 wh,t = σ(ŵh,t)。
   - 调用标准 WY 形式块求解器（Algorithm 2）获得输出和更新状态。
   - 计算块输出均值 mc+1 作为下一块的内容信号。
4. 输出经过 RMSNorm 和输出投影。

## 摘要
本文提出了一种混合ANN-SNN流水线，有效利用预训练人工神经网络（ANN）的丰富嵌入，以实现高性能脉冲神经网络（SNN）。该架构将预训练的EfficientNet编码器与CoLaNET脉冲分类器相结合。我们通过率编码将编码器的激活转换为脉冲序列，并使用局部、生物启发的学习规则训练后续的SNN分类器，绕过了端到端梯度传播。该方法在64类ImageNet基准上达到了99.09%的准确率，展示了与传统深度网络相当的性能。该工作为将强大的预训练编码器适应于下游脉冲神经网络任务提供了一个生物 plausible且高效的框架。

## Abstract
This work proposes a hybrid ANN-SNN pipeline that effectively leverages the rich embeddings of pretrained artificial neural networks (ANNs) to enable high-performance spiking neural networks (SNNs). The architecture couples a pretrained EfficientNet encoder with a CoLaNET spiking classifier. We convert the encoder's activations into spike trains via rate-coding and train the subsequent SNN classifier using local, biologically inspired learning rules, bypassing end-to-end gradient propagation. This approach achieves 99.09% accuracy on a 64-class ImageNet benchmark, demonstrating performance on par with conventional deep networks. The work presents a biologically plausible and efficient framework for adapting powerful pretrained encoders to downstream spiking neural network tasks.

### 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将特征提取与决策分离——ANN编码器（EfficientNet-B3）负责从高维图像提取紧凑语义向量；SNN分类器（CoLaNET）用局部可塑性规则对这些向量进行脉冲分类，避免端到端反向传播。
- **关键技术细节**：
  1. **编码器**：使用预训练的EfficientNet-B3（10.8M参数，1.8B FLOPs/图），取全局平均池化层输出的1536维向量作为特征表示。编码器权重冻结，不参与后续训练。
  2. **激活到脉冲转换（Rate-coding）**：
     - 将负激活置零（等效ReLU）。
     - 设定阈值：激活值≥阈值则每个时间步都发放脉冲；低于阈值则线性映射到0–10个脉冲数（10个时间步内）。
     - 最终产生与激活幅度正相关的脉冲序列。
  3. **SNN分类器**：采用CoLaNET架构，包含多个列（与类别数相同），每列有多个L神经元（对应子类）和一个输出神经元。训练基于三种局部机制：
     - **反赫布可塑性**（anti-Hebbian）：弱化权重。
     - **多巴胺调节可塑性**：通过标签提供的多巴胺脉冲，强化获胜神经元在近期活跃的突触。
     - **周期性突触重归一化**：保持每个神经元的总突触权重恒定，实现竞争。
  4. **训练流程**：单次在线学习，每个样本仅呈现一次；无epoch重复。标签作为第11时间步的单脉冲输入，激发对应列的BIASGATE神经元，触发WTA竞争与突触更新。
- **算法流程（文字说明）**：
  1. 输入图像 → 预训练EfficientNet → 1536维特征向量。
  2. 特征向量经rate-coding转换为15时间步的脉冲序列（10步呈现+5步静默）。
  3. 脉冲序列输入CoLaNET；分类器使用局部规则更新突触（L神经元到输入层的权重）。
  4. 推理时，每个列统计输出脉冲数，取脉冲最多的列作为分类结果；最终由15个独立CoLaNET组成集成，采用多数投票。

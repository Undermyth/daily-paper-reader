## 摘要
通过考虑视觉刺激的相似性（输入）与海马活动模式相应的相似性（输出）之间的关系，海马体在解决记忆干扰中的作用得到了极大的阐明。然而，这些输入-输出函数可能呈现出令人惊讶的不同形式。在此，我们通过考虑海马体在不同学习阶段优先考虑视觉相似性的不同维度的可能性，来调和看似矛盾的发现。首先，我们从两个视觉类别生成一组自然场景图像，并使用多种方法严格表征视觉相似性：神经网络、人工智能模型以及人类的感知和记忆决策。然后，我们确定了视觉相似性的两个正交维度，每个维度都能预测记忆干扰，但在不同的学习阶段起作用。通过使用高分辨率功能磁共振成像，我们测试了海马体内维度特异性的输入-输出函数。在CA3和齿状回（CA3/DG）中，我们发现在学习阶段，当视觉相似性的维度导致记忆干扰时，这些维度被反转（排斥）。相反，当维度不导致干扰时，CA3/DG则保留相似性。这些发现表明，海马体对视觉相似刺激的表征是高度动态的，并且关键取决于当前导致记忆干扰的相似性维度。

## Abstract
The role of the hippocampus in resolving memory interference has been greatly elucidated by considering the relationship between the similarity of visual stimuli (input) and corresponding similarity of hippocampal activity patterns (output). However, these input-output functions can take surprisingly different forms. Here, we reconcile seemingly conflicting findings by considering the possibility that the hippocampus prioritizes different dimensions of visual similarity across different stages of learning. First, we generated a set of natural scene images from two visual categories and rigorously characterized visual similarity using a wide array of methods: neural networks, artificial intelligence models, and human perceptual and memory decisions. We then identified two orthogonal dimensions of visual similarity that each predicted memory interference, but that did so at distinct stages of learning. Using high-resolution fMRI, we then tested for dimension-specific input-output functions within the hippocampus. Within CA3 and dentate gyrus (CA3/DG), we show that dimensions of visual similarity were inverted (repulsion) at stages of learning when they contributed to memory interference. In contrast, CA3/DG preserved similarity when dimensions did not contribute to interference. These findings reveal that hippocampal representations of visually-similar stimuli are highly dynamic and critically depend on the dimensions of similarity that currently contribute to memory interference.

### 6. 主要结论与发现

1.  **存在两个正交的、行为相关的相似性维度**：视觉相似性可以被分解为低层感知结构相似性（PC1）和高层语义概念相似性（PC2），两者都能独立预测记忆干扰。
2.  **学习阶段动态改变干扰维度**：记忆干扰并非同时由所有维度引起，而是**顺序出现**。在学习早期，感知维度（PC1）主导干扰；在学习后期，语义维度（PC2）主导干扰。
3.  **海马CA3/DG“按需”反转干扰维度**：海马体（特别是CA3/DG）的表征会**动态地**、**维度特异性地**适应干扰焦点：
    - **当维度导致干扰时**：CA3/DG会**反转**该维度（负的输入-输出函数），即视觉上越相似，神经表征差异越大（“排斥”或“分化”），这是一种自适应地增加记忆区分度的机制。
    - **当维度不导致干扰时**：CA3/DG会**保留**该维度（正的输入-输出函数），即视觉上越相似，神经表征也越相似。
    - 这种效果完美地和行为数据对齐：在低训练阶段，PC1（感知维度）导致干扰，CA3/DG反转PC1；在高训练阶段，PC2（语义维度）导致干扰，CA3/DG反转PC2。
4.  **效应特异于CA3/DG**：这种维度特异性的动态转换效应在CA1、EVC和PPA中并未观察到，突显了CA3/DG在模式分离和解决记忆干扰中的核心作用。

### 7. 优点

1.  **创新的方法论**：首次系统地通过多模态度量（人类+AI模型）对视觉相似性进行分解，提取出正交的行为相关维度，而非依赖单一度量。这为解决海马体“输入-输出”函数问题提供了新的分析工具。
2.  **调和矛盾发现**：成功解释了以往研究中观察到的海马体相似性函数（正、负、平坦）为何会存在，指出其关键在于学习阶段和所考察的相似性维度不同。这是对经典模式分离/完成理论的重要补充与细化。
3.  **紧密的行为-神经关联**：将海马体的神经表征变化直接与逐时（trial-by-trial）的行为干扰表现联系起来，证实了海马体变化的适应性功能。即“神经反转”是为了解决“当前”的“行为”问题。
4.  **统计方法严谨**：使用了能处理多层嵌套数据的线性混合效应模型，并合理包含了随机效应，使得统计推断更加可靠。

### 8. 不足与局限

1.  **维度的普适性**：通过PCA提取的PC1和PC2维度，其解释（感知 vs. 语义）依赖于本实验所用的特定刺激集（海滩和凉亭）。作者也承认，在不同的任务和刺激集下，优先处理的维度可能会变化（如受任务需求影响）。该结论的“一般原则”（即每次只解决一个维度的干扰）可能成立，但维度的具体内容可能不具迁移性。
2.  **因果性证据不足**：研究揭示了**相关性**（行为干扰模式与神经表征模式之间的耦合），但无法直接证明是海马体的“反转”操作**导致**了行为干扰的解决。可能存在一个上游或并行的机制同时驱动两者。结论中提到“海马体适应性地...”，暗示了因果，但实验设计并未提供强因果证据，如通过神经调控实验进行验证。
3.  **测量局限**：
    - fMRI的时间分辨率有限，无法区分“暴露阶段”中场景呈现时的表征是反映了过往经验（记忆）的在线提取，还是瞬时的新表征构建。
    - 暴露阶段任务是被动的新旧判断，而非主动的记忆检索，这可能无法充分引发干扰过程。
    - 统计模型中，对比高/低训练的条件，虽然性能差异显著，但高训练条件下的干扰错误数可能较少，影响了评估该条件下维度影响的统计功效（尽管作者做了排除高表现者的分析）。
4.  **外部效度**：研究使用了高度相似的、同类别内的自然场景，这种精细的区分需求可能激活了海马体特定的模式分离机制。对于更广泛、差异更大的记忆干扰场景（如语义相关的不同事件），其结论的普适性有待进一步检验。

## 摘要
循环模型必须遗忘才能记忆，但现有技术在决定擦除什么时并未咨询存储内容——门控仅看到输入的标记，而非它即将修改的记忆。这种记忆盲门控是领先的delta规则架构（GDN-2）中三个耦合缺陷之一：价值轴擦除掩码在价值投影的规模上浪费参数，且——正如我们证明的——在数学上阻止了使循环训练与Transformer具有竞争力的WY形式三角块求解器。我们引入CARVE（内容感知循环与价值效率），通过一个原则解决所有三个问题：仅在关键轴上擦除。这对于WY形式求解器的有效性是必要且充分的。在其中，CARVE重用已写入GPU内存的循环输出张量，作为擦除门的免费内容信号，并将每个值的写门投影替换为每个头的单个标量。初始化时CARVE与GDN-2逐位相同；任何质量差异源于内容门所学的内容。在1000亿标记上训练13亿参数时，CARVE在WikiText上达到困惑度15.72（比GDN-2低0.18，4.5-sigma效应），在九个常识推理基准上领先所有循环基线，并在每个RULER检索探针上创下最新技术水平——吞吐量开销仅0.4%，峰值内存降低13%，参数减少19%。六个形式化定理涵盖记忆容量、李雅普诺夫稳定性、梯度流、表达能力分离、帕累托最优块大小和混合最优性。

## Abstract
Recurrent models must forget in order to remember, yet the state of the art decides what to erase without consulting what is stored -- the gate sees only the arriving token, not the memory it is about to modify. This memory-blind gating is one of three coupled defects in the leading delta-rule architecture (GDN-2): the value-axis erase mask wastes parameters at the scale of the value projection, and -- as we prove -- mathematically prevents the WY-form triangular chunk solver that makes recurrent training competitive with Transformers.   We introduce CARVE (Content-Aware Recurrent with Value Efficiency), which resolves all three problems through one principle: erase only on the key axis. This is provably necessary and sufficient for the WY-form solver to remain valid. Within it, CARVE reuses the recurrent output tensor -- already written to GPU memory -- as a free content signal for the erase gate, and replaces the per-value write-gate projection with a single scalar per head. At initialisation CARVE is bit-identical to GDN-2; any quality difference emerges from what the content gate learns.   At 1.3B parameters trained on 100B tokens, CARVE achieves WikiText perplexity 15.72 (minus 0.18 vs. GDN-2, a 4.5-sigma effect), leads every recurrent baseline on nine common-sense reasoning benchmarks, and sets state of the art on every RULER retrieval probe -- at 0.4% throughput overhead, 13% lower peak memory, and 19% fewer parameters. Six formal theorems cover memory capacity, Lyapunov stability, gradient flow, expressivity separation, Pareto-optimal chunk size, and hybrid optimality.

## 1. 核心问题与整体含义

- **研究背景**：递归序列模型（如 Delta-rule 族）通过固定大小的状态矩阵压缩历史上下文，实现线性的训练/推理成本，但必须执行“遗忘”机制以更新状态。当前最优的 GDN-2 采用元素级矩阵门控（擦除门和写门），虽性能强，但存在三个结构性缺陷：
  - **记忆盲门控**：擦除门仅基于当前输入 token 计算，无法查看已存储的状态内容，导致选择性遗忘能力缺失；
  - **写门带宽瓶颈**：写门投影维度与值投影相同（dv×dk），参数开销大且表达收益低；
  - **值轴擦除破坏并行性**：WY 形式三角块求解器要求耦合矩阵与值索引无关，但 GDN-2 的值轴擦除导致每个值通道需独立求解，性能退化至串行递归成本。

- **问题含义**：这三个问题相互耦合——更丰富的门控、更低的带宽和块并行训练无法在 GDN-2 的现有设计中同时实现。CARVE 旨在一次性解决这三个问题，同时保持甚至提升性能。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **唯一约束**：**仅在键轴（key axis）上执行擦除**。论文证明这是 WY 形式块求解有效的充要条件（定理11）。该约束不限制门控的表达力，反而为擦除门的设计腾出两个自由度（内容感知低成本实现、标量写门控）。

### 2.2 关键技术细节
- **内容感知擦除门（Content-Aware Erase Gate）**：
  - 直接读取状态矩阵 St-1 会加倍显存访问。CARVE 利用 Triton 内核必须写出的循环输出张量 ot = St-1 qc,t，取其块均值 mc（零额外 HBM 成本）。
  - 通过零初始化的低秩投影 Ub: Rdv → Rdk 将 mc 映射为擦除偏置，与 token 驱动的偏置 bx,t 相加后经 sigmoid 得到擦除门：
    ```
    bc,t = σ(bx,t + Ub(mc))
    ```
  - 初始化时 Ub=0，与 GDN-2 逐位一致；训练后 ub 逐渐激活，引入记忆条件的选择性。
  - 命题14证明：单块滞后导致的门控扰动为 O(1/√L)，实验实测偏差仅 0.18% 且与块长度 L 无关。

- **标量值写门（Scalar Value Write Gate）**：
  - 将每头每个值通道的写门投影替换为**每头单个标量** wh,t ∈ (0,1)，广播到所有 dv 通道。
  - 参数减少 dv 倍（如 H=12, dv=768 时从 589,824 降至 9,216），定理15证明对单槽联想召回无任何损失。

- **状态更新公式（仅键轴）**：
  ```
  Sc,t = Sc,t-1 · diag(exp(gc,t)) · diag(1 - bc,t) + wh,t · (vc,t - Sc,t-1 kc,t) kc,t^T
  ```
  其中 gc,t 为键轴衰减门（指数衰减），bc,t 为键轴擦除门，wh,t 为标量写门。所有门控均为键轴后乘，保证 WY 求解器有效。

### 2.3 算法流程（文字描述）
- **输入投影**：从隐状态计算 q, k, v 及门控预激活（衰减 logits f、擦除偏置 bx、标量写预激活 ŵ）。
- **内容信号生成**：对前一块的输出均值 mc（无额外 HBM 读取），通过低秩投影 Ub 得到内容偏置。
- **擦除门**：bx + Ub(mc) → sigmoid → bc,t，作用于键轴。
- **写门**：ŵ → sigmoid → wh,t，标量广播到所有值通道。
- **衰减门**：基于 f 和可学习振幅 A、偏置 τ，在 Triton 内核内融合计算：gc,t = -exp(A) ⊙ softplus(fc,t + τ)。
- **WY 形式块求解**：执行一次三角形 GEMM（与值索引无关），计算输出和更新状态。

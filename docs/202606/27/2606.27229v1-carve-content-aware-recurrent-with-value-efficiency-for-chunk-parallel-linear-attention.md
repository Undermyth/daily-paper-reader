## 摘要
循环模型必须遗忘才能记忆，然而当前最先进的方法在决定擦除什么时并不参考已存储的内容——门控仅看到到达的令牌，而非即将修改的记忆。这种记忆盲门控是领先的delta规则架构（GDN-2）中三个耦合缺陷之一：值轴擦除掩码在值投影的规模上浪费参数，并且——如我们证明——数学上阻碍了使循环训练能与Transformer竞争的WY形式三角块求解器。我们提出CARVE（具有价值效率的内容感知循环模型），通过一个原则解决了所有三个问题：仅在键轴上擦除。这被证明是WY形式求解器保持有效的充分必要条件。在此原则下，CARVE重用已写入GPU内存的循环输出张量作为擦除门的免费内容信号，并将每个值的写门投影替换为每个头的单个标量。初始化时，CARVE与GDN-2比特一致；任何质量差异源于内容门的学习。在1.3B参数、100B令牌训练下，CARVE在WikiText上达到困惑度15.72（相比GDN-2降低0.18，具有4.5西格玛效应），在九个常识推理基准上领先所有循环基线，并在每个RULER检索探针上达到最先进水平——吞吐量开销仅为0.4%，峰值内存降低13%，参数减少19%。六个形式化定理涵盖了记忆容量、李雅普诺夫稳定性、梯度流、表达能力分离、帕累托最优块大小和混合最优性。

## Abstract
Recurrent models must forget in order to remember, yet the state of the art decides what to erase without consulting what is stored -- the gate sees only the arriving token, not the memory it is about to modify. This memory-blind gating is one of three coupled defects in the leading delta-rule architecture (GDN-2): the value-axis erase mask wastes parameters at the scale of the value projection, and -- as we prove -- mathematically prevents the WY-form triangular chunk solver that makes recurrent training competitive with Transformers.   We introduce CARVE (Content-Aware Recurrent with Value Efficiency), which resolves all three problems through one principle: erase only on the key axis. This is provably necessary and sufficient for the WY-form solver to remain valid. Within it, CARVE reuses the recurrent output tensor -- already written to GPU memory -- as a free content signal for the erase gate, and replaces the per-value write-gate projection with a single scalar per head. At initialisation CARVE is bit-identical to GDN-2; any quality difference emerges from what the content gate learns.   At 1.3B parameters trained on 100B tokens, CARVE achieves WikiText perplexity 15.72 (minus 0.18 vs. GDN-2, a 4.5-sigma effect), leads every recurrent baseline on nine common-sense reasoning benchmarks, and sets state of the art on every RULER retrieval probe -- at 0.4% throughput overhead, 13% lower peak memory, and 19% fewer parameters. Six formal theorems cover memory capacity, Lyapunov stability, gradient flow, expressivity separation, Pareto-optimal chunk size, and hybrid optimality.

# CARVE 论文中文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的 gated delta-rule 循环架构（如 GDN-2）存在三个耦合的结构性缺陷：
  - **记忆盲门控（memory-blind gating）**：擦除门仅依赖于当前输入令牌，无法感知已存储的记忆内容，导致选择性遗忘能力不足；
  - **值轴写门带宽浪费**：写门为每个值维度独立投影，参数规模与值投影相当，但实际语言建模证明这种每通道路由对核心关联召回任务并非必要；
  - **值轴擦除破坏分块并行性**：GDN-2 同时沿值和键轴施加擦除门，导致 WY 形式三角块求解器无法共享，必须为每个值维度独立求解，退化为串行循环成本。
- **研究动机**：如何在不牺牲硬件效率（分块并行训练）的前提下，让循环模型能够“查看自己的记忆后再决定遗忘什么”，同时减少参数和内存占用。
- **整体含义**：CARVE 通过统一的原则——仅在键轴上擦除——同时解决了上述三个问题，首次在 gated delta 一族中实现了内容感知门控、完整 WY 形式分块并行训练和更低的参数量，并提供了六个形式化定理的理论保证。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **仅在键轴上擦除**：这是 CARVE 唯一的架构约束，被证明（Theorem 11）是 WY 形式块求解器保持有效的**充要条件**。所有擦除操作只作用于键轴（key axis），值轴维度不受影响。
- **输出复用实现内容感知擦除**：循环核函数必须将每步输出 $o_t = S_t q_t$ 写入 HBM，CARVE 复用这些已经写入的值，计算上一个块的均值 $m_c = \frac{1}{L} \sum_{t \in c-1} o_t$ 作为内容信号，通过零初始化的低秩投影 $U_b$ 注入擦除门：$b_{c,t} = \sigma(b_{x,t} + U_b m_c)$。初始化时 $U_b=0$，与基线比特一致。
- **标量值写门**：用每头单个标量 $w_{h,t} \in (0,1)$ 替代 $d_v$ 维的每通道写门，广播到所有值通道。Theorem 15 证明对单槽关联召回任务是无损的，实际 $d_v$ 倍参数减少（从每层 589,824 降至 9,216）。

### 技术细节
- **状态更新公式**：$$
S_{c,t} = S_{c,t-1} \cdot \text{diag}(\exp(g_{c,t})) \cdot \text{diag}(1 - b_{c,t}) + w_{h,t} \cdot (v_{c,t} - S_{c,t-1}k_{c,t}) k_{c,t}^\top
$$  
  其中 $g_{c,t}$ 是指数衰减门（在核内计算并融合），$b_{c,t}$ 是内容感知擦除门，$w_{h,t}$ 是标量写门。
- **WY 形式块求解**：块内求解器（Algorithm 2）利用键轴累积留存向量 $\gamma_t = \prod_{s=0}^t (\exp(g_s) \odot (1 - b_s))$，构建与值索引无关的耦合矩阵 $M \in \mathbb{R}^{L \times L}$，通过单个三角 GEMM 完成求解，复杂度 $O(d_v d_k L + L^2 d_k)$，与 $d_v$ 无关。
- **输出复用内容读出**：块均值从核已经写出的输出张量中计算，零额外 HBM 读取。Proposition 14 证明一个块的延迟所引入的门扰动为 $O(1/\sqrt{L})$，实验中测量偏差仅 0.18%。
- **核内门融合（gate-in-kernel fusion）**：衰减激活 $g_{c,t} = -\exp(A) \odot \text{softplus}(f_{c,t} + \tau)$ 在 Triton 核内计算，节省一个 BF16 激活张量（约 100 MB），提升吞吐 1.2K tok/s。

### 算法流程（Algorithm 1）
1. 输入隐状态，计算 q, k, v 及门预激活值（$f, b_x, \hat{w}$）。
2. 初始化内容信号 $m_0 = 0$。
3. 对每个块 $c$：
   - 计算低秩内容投影 $u_b = W_{U2} \tanh(W_{U1} m_c)$。
   - 生成内容感知擦除门 $b_{c,:} = \sigma(b_{x,c_0:c_1} + u_b)$ 和标量写门 $w_{c,:} = \sigma(\hat{w}_{c_0:c_1})$。
   - 调用 WYChunkDelta 核（未修改的标准 WY 形式求解器）获得输出 $o_{c,:}$ 和更新状态 $S_c$。
   - 计算下一块内容信号 $m_{c+1} = \text{mean}_L(o_{c,:})$。
4. 输出层：$y_{1:T} = W_O \text{RMSNorm}(\text{reshape}(o_{0:T}))$。

## 7. 优点
- **方法创新点**：
  - 将分块并行训练的充要条件精确定位为“值轴擦除为零”，从而在保持效率的同时引入内容感知门控。
  - 零额外成本的输出复用内容读出机制，在实际硬件中实现门控对记忆状态的依赖。
  - 标量写门大幅减少参数且理论保证无损联想能力。
- **理论贡献**：六条形式化定理为设计选择提供数学基础（如 Chunkability Boundary、Lyapunov Stability 等），这在硬件高效的循环模型文献中少见。
- **实验严谨性**：三种子重复、位精确初始化控制、机制消融归因、吞吐/内存/数值精度全方面测量，可信度高。
- **实际效益**：同时改善质量、减少参数、降低内存消耗，且不牺牲吞吐，具有直接部署价值。

## 8. 不足与局限
- **实验覆盖**：
  - 仅在 1.3B 规模测试，更大规模（如 7B、70B）和更长训练（如 1T tokens）的表现尚不清楚。
  - 仅评估了英文预训练场景，未涉及微调（instruction tuning）、多模态、代码生成等任务。
  - RULER 和 JRT 检索数据集的最大上下文长度为 8K，未测试更长上下文（如 32K、128K）。
- **方法局限性**：
  - **短序列缺陷**：当序列长度小于两个块（2L tokens）时，内容信号 $m_c$ 无效（首块初始为零）；Proposition 14 的误差界假设超过 2L 长度。
  - **内容信号一个块的延迟**：虽然理论证明误差 $O(1/\sqrt{L})$ 且实验偏差仅 0.18%，但对某些细节敏感的任务（如精确位置定位）可能仍有影响。
  - 标量写门在更复杂的任务（如多步推理中需不同值通道独立调节）是否始终无损需要更多验证。
- **可解释性**：内容门具体学习了什么模式未做深入分析。
- **训练计算量**：虽然未报告训练 GPU-hours，但从 100B tokens/1.3B 参数估算成本不菲，可能对资源有限的团队构成障碍。

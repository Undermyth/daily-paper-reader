## 摘要
长上下文大语言模型推理受到键值缓存的内存占用和解码成本日益严重的制约，限制了其在资源受限硬件上的可持续部署。现有的KV缓存淘汰方法通常对基于分组查询注意力的大语言模型中所有注意力头应用启发式令牌评分。这些方法忽略了不同注意力头的不同功能，导致关键令牌被淘汰，从而降低大语言模型性能。为解决这一问题，我们提出CompressKV，一种用于基于GQA的大语言模型的资源高效KV缓存压缩框架。CompressKV不聚合所有头的注意力分数，而是识别语义检索头——这些头捕获提示的初始和最终令牌以及语义重要的中间上下文证据，并利用它们来选择应保留其KV对的令牌。此外，CompressKV根据逐层离线估计的淘汰误差在各层间分配缓存预算。在LongBench和Needle-in-a-Haystack上的实验表明，CompressKV在不同内存预算下始终优于现有KV缓存淘汰方法。值得注意的是，在LongBench问答任务中，仅使用3%的KV缓存即可保持全缓存性能的97%以上，而在Needle-in-a-Haystack上仅使用0.7%的KV存储即可达到90%的准确率。这些结果表明长上下文LLM推理的资源-性能权衡得到改善。我们的代码公开在：https://github.com/TUDa-HWAI/CompressKV

## Abstract
Long-context large language model (LLM) inference is increasingly constrained by the memory footprint and decoding cost of key-value (KV) caches, limiting sustainable deployment on resource-constrained hardware. Existing KV cache eviction methods typically apply heuristic token scoring over all heads in GQA-based LLMs. These methods ignore the different functionalities of attention heads, leading to the eviction of critical tokens and thus degrading the performance of LLMs. To address this issue, we propose CompressKV, a resource-efficient KV-cache compression framework for GQA-based LLMs. Instead of aggregating attention scores from all heads, CompressKV identifies Semantic Retrieval Heads (SRHs) that capture both the initial and final tokens of a prompt and semantically important mid-context evidence, and uses them to select tokens whose KV pairs should be retained. Furthermore, CompressKV allocates cache budgets across layers according to offline estimates of layer-wise eviction error. Experiments on LongBench and Needle-in-a-Haystack show that CompressKV consistently outperforms existing KV-cache eviction methods across memory budgets. Notably, it preserves over 97\% of full-cache performance using only 3\% of the KV cache on LongBench question-answering tasks and achieves 90\% accuracy with just 0.7\% KV storage on Needle-in-a-Haystack. These results demonstrate an improved resource--performance trade-off for long-context LLM inference. Our code is publicly available at: https://github.com/TUDa-HWAI/CompressKV

# CompressKV 论文详细中文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：长上下文大语言模型（LLM）推理中，键值缓存（KV cache）随序列长度线性增长，导致巨大内存开销和慢速解码，严重制约了模型在资源受限硬件上的部署。
- **现有方法局限**：当前主流的 KV 缓存驱逐方法（如 StreamingLLM、SnapKV、CAKE 等）通常对所有注意力头统一评分（如跨头求和），忽略了注意力头的功能异质性。特别是在分组查询注意力（GQA）模型中，存在所谓的“流头”（Streaming Heads），它们只关注 prompt 的首尾 token，而“检索头”（Retrieval Heads）则能捕捉中间关键语义信息。当流头占主导时，统一评分会导致中间关键 token 被错误驱逐，严重损害模型性能。
- **本文目标**：提出一种语义检索引导的 KV 缓存压缩框架 **CompressKV**，通过识别并利用“语义检索头”（Semantic Retrieval Heads, SRH）来精准选择关键 token，同时基于离线逐层误差估计自适应分配缓存预算，从而在极低内存预算下保持高精度，改善资源-性能权衡。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 不聚合所有头的注意力分数，而是仅使用语义检索头（SRH）来指导 token 选择，避免流头主导导致的关键信息丢失。
- 引入离线逐层误差估计，将有限缓存预算优先分配给压缩误差大的层。

### 2.2 关键技术细节

#### (1) 语义检索头（SRH）识别
- **定义**：SRH 是能够捕捉整个答案跨度（span）语义信息的注意力头，不仅限于严格的复制-粘贴行为（top-1 命中），也包括对答案周围语义上下文的关注。
- **识别方法**：使用校准数据集（与文献[27]相同），在模型生成正确答案 token 时，对每个头 $h$ 计算 SRH 分数：
  $$ S_{SRH}(h) = \sum_{t=1}^N \mathbb{1}\{y_t \in \mathcal{A}\} \sum_{j \in \mathcal{A}} a^{(h)}_{t,j} $$
  其中 $\mathcal{A}$ 为答案跨度，$a^{(h)}_{t,j}$ 是头 $h$ 在第 $t$ 步对第 $j$ 个 token 的注意力权重。得分越高的头越能捕捉语义信息。
- **与传统检索头的区别**：传统方法（如 HeadKV）要求精确 top-k 命中，而 SRH 通过聚合整个跨度，能识别出那些关注“eat”、“thing”等语义线索但从未达到单 token top-1 的头。

#### (2) 基于 SRH 的 token 选择
- 每层选择 top-4（实验确定最优数量）的 SRH，将所有注意力头的选择统一到这些 SRH 上。
- 对 SRH 的注意力分数矩阵进行观测窗口内求和、池化，然后平均得到每个 token 的重要性分数，保留 top-N 个 token 的 KV 对，其余驱逐。

#### (3) 误差感知的逐层缓存分配
- **离线误差估计**：在解码阶段，计算每一层 $l$ 使用压缩缓存与全缓存时注意力块输出的 Frobenius 范数相对误差：
  $$ e^{(l)} = \sum_{t=1}^T \frac{\|\Delta O^{(l)}_t\|_F}{\|O^{(l)}_{\text{full},t}\|_F + \epsilon} $$
  归一化得到 $\tilde{e}^{(l)}$。
- **分配策略**：给定总预算 $B_{\text{total}}$，先为每层分配最小保留数 $m=32$ 和最大保留数 $M = 3 \times B_{\text{per-layer}}$，剩余预算按归一化误差比例分配。此过程完全离线完成，在线推理无额外开销。

### 2.3 算法流程（文字说明）
- **离线阶段**：用校准数据识别每层 top-4 SRH → 在极小缓存（如每层 32 个 token）下计算每层离线误差 → 根据总预算和误差分配各层缓存预算。
- **在线推理**：预填充阶段，对每层只用该层的 top-4 SRH 计算 token 重要性，保留预算数量的 token → 解码阶段复用相同 KV 缓存（驱逐后固定），无需动态调整。

## 6. 主要结论与发现

- **性能优越**：CompressKV 在所有模型和预算下均优于所有基线，尤其在小预算下优势显著。在 LongBench 上，仅用 3% KV 缓存便保持 97% 以上全缓存性能；在 NIAH 上，仅用 0.7% KV 存储便达到 90% 准确率。
- **SRH 关键性**：因果掩码实验表明，掩码少量 SRH 会导致 NIAH 性能大幅下降（top-30 掩码下降 73.81%），而掩码传统检索头仅下降 13.30%，证实 SRH 对忠实检索至关重要。
- **组件互补性**：SRH 驱动选择 + 误差感知分层分配均贡献正向增益。
- **正交性**：CompressKV 可与预填充加速、量化、头级分配等方法无缝集成，进一步提升效率或性能。

## 7. 优点

1. **新颖的 SRH 定义**：提出基于跨度聚合的语义检索头，克服了传统 top-1 命中标准对短答案和稀疏注意力场景的局限性，能识别更多蕴含语义的头。
2. **离线分配节省在线开销**：层预算分配完全离线完成，不增加在线推理负担，与依赖注意力统计的在线方法（如 CAKE）相比更高效。
3. **显著改善流头主导问题**：通过仅使用 SRH 进行 token 选择，有效防止流头淹没中间关键信息。
4. **极强的记忆效率**：在极低预算下仍保持高精度，实用价值高。
5. **通用性和正交性**：能在不同规模模型（7B~32B）上工作，并能与多种已有加速/压缩技术结合。

## 8. 不足与局限

1. **依赖校准数据集**：SRH 识别需要预定义校准数据（沿用文献[27]），若校准集与部署数据分布差异大，可能降低效果。未讨论该敏感性和鲁棒性。
2. **离线预计算成本**：虽然在线无开销，但离线阶段（计算每层 SRH 和误差）需要一次模型推理和额外存储，文中未量化该成本。
3. **模型范围有限**：仅在 Llama、Mistral、Qwen2.5 系列上测试，未覆盖其他架构（如 GPT-NeoX、Falcon、Mixtral MoE），可能存在偏差。
4. **评估指标单一**：LongBench 只报告平均分，未细致分析各子任务差异；NIAH 仅测量检索准确率，缺少对推理任务（如多跳 QA、长文档摘要）的深入分析。
